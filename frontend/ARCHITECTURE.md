# 前端架构

前端使用 Vue、TypeScript 和 Vite，浏览器与 Qt WebEngine 共用同一应用。规则见 [AGENTS.md](AGENTS.md)，整体进程和模块执行归属见[总架构](../ARCHITECTURE.md)。

## 启动和公共工作台

[src/main.ts](src/main.ts)先安装页面缩放并等待 initializePlatform，再挂载 App。桌面连接失败时显示错误，避免把未接通的桌面窗口当成完整能力环境。

[AppShell.vue](src/app/AppShell.vue)维护侧栏、标签、当前模块、帮助、设置及关闭保护；[registry.ts](src/app/registry.ts)维护 M01–M19 的稳定 ID 和分组。页面有同步与按需加载两种方式，不为各模块建立独立宿主。切换/关闭时协调未保存状态、播放、录音租约及更新退出确认。

[announcements.ts](src/platform/announcements.ts)按进程合并固定官网公告清单读取，限定64KiB、3秒、20条，严格解析纯文本与官网HTTPS链接。已读ID和最近成功清单保存在设备localStorage，不跟账号或研究项目上传；成功空清单撤回公告，首次离线不显示。AppShell只在首页与录音/实验及已有弹层安全条件满足时认领一次性提示，公告中心复用公共ModalDialog。没有候选时不常驻扫描DOM或轮询，挂载与项目切换不重复拉取。

| 目录 | 主要内容 |
| --- | --- |
| src/app/、src/layout/ | 工作台装配、模块容器、标签及可调整面板 |
| src/modules/ | 各模块页面、业务状态、控制器、领域 port 与模块 README |
| src/platform/ | 桌面/浏览器文件、任务、设备、导出、更新、论文等适配 |
| src/account/ | 账号与项目上下文，构建服务模式的研究文件入口 |
| src/components/ | 共用音频、波形、参数、对话框、设置与引用组件 |
| src/state/、src/design/ | 跨模块播放/工作区/偏好状态、主题、字体和公共样式 |
| src/manual/ | 结构化说明书类型、校验、只读渲染、搜索与媒体协调 |
| src/generated/、src/assets/、public/ | 生成目录与来源数据、字体/图标、静态阅读和声道资源 |

`account/ServerPage.vue`在 `/server/` 使用同一个AppShell，新增注册/邮箱验证/密码恢复和临时工作区状态。能力选项显式确认启用后才附着工作区并每30秒心跳；关页不调用退出或删除，过期须用户明确开始新的工作区。邮件令牌在读取后从地址栏fragment移除，并响应同页链接变化。MFA服务器模式改为桌面引导，桌面页保持原入口。

登录后自动取得工作区的默认项目并直接进入AppShell，多标签通过服务端原有写事务避免重复创建。没有项目时创建默认项目，已有项目使用最早建立的一项，改名不改变身份。文件与空间入口打开紧凑管理窗，工作台保持挂载；文件/任务分开查看，本机导入与项目分组折叠，需要时才切换项目。

登录和文件管理的官网风格由 `account/account-web.css` 限定在 `account-surface` 内，科研工作台仍使用原主题与字体偏好。`ModalDialog` 的 `confirm` 尺寸仅由网页关闭草稿/删除文件调用，原桌面默认对话框不变。`WebCapacityStatus` 共用额度与工作区接口显示在线数、剩余容量、限时申请和审批回复，另显示聚合任务运行/等待数及可用的CPU/内存采样。状态不能用于推断固定最高在线人数。

M15在网页按owner/project命名IndexedDB和会话锁，M17以相同上下文区分草稿；项目ID由服务器绑定工作区，桌面原数据库名和草稿键保持。旧公共本地资料不自动认领到网页登录者。已下载资料和客户端实验数据不参与服务器TTL。

## 浏览器科学执行

`platform/browser-science.ts`为每个账号/项目维护两条按需Worker通道：交互预览与小型重建各串行执行，避免GL阻塞EGG和录音。每条队列最多8项、单输入100 MB、含初次下载的超时120秒；取消或退出终止Worker并拒绝在途/排队请求。参数先固定为普通JSON快照，避免Vue响应式数组无法跨Worker传递。运行库和原始Praat绑定只加入网页版候选，不进入桌面public资源树。

`serverFiles`接入按账号与项目隔离的 IndexedDB 文件库，导入材料、本机计算结果、任务记录与录音恢复快照保留本机，读取核对 SHA-256。默认临时项目使用账号内稳定本机分组，退出重登创建新服务器工作区后仍可使用。`local-asset-transport.ts`只在服务器计算请求或预览回退中准备其引用输入，传输分块、摘要与幂等键保持，服务器副本失效后可从本机重新准备；本机存储失败或取消不触发上传回退。已有服务器文件正常读取，首次读取的完整结果校验后缓存到本机。公共/录音语谱、参数表、EGG交互、图片参数预测和录音处理继续优先复用原Python核心，原生操作继续使用服务器。

`browser-jobs.ts`管理小型GL与频谱编辑：设备报告至少4线程/4 GB、时长不超过5秒、GL不超过64次、小图片/音频及配置预算内才启用。四个原始结果和任务快照写入本机文件库，不受服务器工作区TTL清理。刷新从本机元数据恢复历史，当前账号/当前服务器项目的旧快照身份接续到稳定本机分组，失去执行页面的旧任务标记中断，计算失败可重试改用服务器，本机保存失败优先恢复本机保存；活动/待保存任务提醒保留网页。录音工程仍沿用既有版本、撤销和CAS保存协议。

普通浏览器启动只异步裁剪当前应用图标，完整图标库在图标设置激活后按两路读取，不阻塞登录/工作台。桌面仍在启动读取全部内置图标。

`browser-m14.ts`包裹原M14Port，在批计算Worker运行原表格读取/归纳/文档生成；输入与三份导出结果保存在本机，源身份/摘要检查及页面草稿保持。新读取器不加载Pandas，旧读取器需要时补载。`browser-m06.ts`将元音生成和≤3秒Klatt合成放入同一批计算通道，参数提取/长合成保持原端口。取消不会转为服务器任务，输出保存失败不重复计算。LPC同样使用原完整计算器和字体，BrowserJobs按独立文件集合/操作类型恢复历史；首轮字体按需下载，同服务器字体SHA。运行资源只在具体操作需要时加载，不读取用户电脑上安装的Python库。

## 两层平台接口

M10 使用 `browser-vocal.ts` 与独立 `vocal.worker.ts`，在既有 Pyodide 执行共用声道状态机和锁定 VTL/m10-r18 动态库。首次装载失败才选择服务器会话，本地计算途中失败不静默切换。长渲染以终止Worker取消并恢复已确认编辑，短PCM操作完成当前块后停止，保留引擎与缓存；PCM优先于排队的显示请求。浏览器默认65截面、持续发声及12秒序列，服务器科学回退仍受限。F0和气压双曲线独立编辑，微扰与种子随6版文件保存，设置接账号白名单。几何、合成、动作、监测和文档在客户端，MP4仍由服务器有界转码。vocal-wasm运行包及对应源码独立于桌面资源，初轮对照见[报告](../docs/testing/m10-wasm-report.md)，能力接入见[计划](../docs/plans/2026-10-18-vocal-browser-controls.md)，线上c5及明确源回退、性能和设备边界见[当前验收](../docs/testing/web-vocal-browser-controls.md)。

`state/web-settings.ts` 为18模块声明设置字段，`platform/account-preferences.ts` 将这些字段按账号/模块保存到服务器。ServerPage登录后先读取设置，再挂载AppShell；换浏览器或设备使用同一账号恢复服务器记录。全局主题、字体、显示样式及模块栏宽也接同一持久层。首次升级只在服务器尚无该模块记录时导入旧账号专属的本地设置，不认领匿名全局资料；已有服务器记录始终优先。

页面按200毫秒合并修改，只发送实际变化的字段；服务端修订号冲突后重新读取，并合并待保存的字段，保留其他设备的独立更改。未获服务器确认的修改留在当前标签的待同步队列，网络失败显示重试，恢复连接后续传。主动退出先补存并等待确认，失败时保留登录状态。M10同源iframe通过父页读写设置，不再以自身localStorage为主存储；M18自动获取/间隔及PDF显示选项使用同一账号记录。设置不含文件或结果，退出/到期只清服务器临时副本；桌面与匿名预览保持原行为。

基础 [types.ts](src/platform/types.ts)定义 HostCapabilities、FileProvider、ProjectStore 和 AudioAsset，主要供基础音频预览/工程状态使用。这里的 jobs/capture 标记不代表整套研究任务接口。

研究模块使用 [research.ts](src/platform/research.ts)中的 ResearchContext、ResearchFiles 和 ResearchTasks：
- ResearchContext 固定当前上下文 key、显示标签及可选 owner。
- ResearchFiles 负责列表、读取、TextGrid/参数/语谱预览、目录选择、会话释放，并提供可选 M05/M06/M07/M08/M11/M14 与 annotation ports。
- 浏览器上下文通过可选 `ResearchFiles.upload` 和共享 `ResearchUpload` 导入本机文件，接口名称兼容既有模块。预览的 `add` 和桌面的目录授权保持独立；导入后刷新同一项目资源。文件管理合并显示本机文件与服务器临时文件，导出本机 Blob，ZIP 打包也在本机执行。
- ResearchTasks 负责批次提交、查询、取消、重试与结果读取；输入通过文件 ID/摘要引用，配置来自版本化契约。
- DirectoryGrant 只传不透明 ID、标签和用途，不允许页面拼接本机绝对路径。

[desktop.ts](src/platform/desktop.ts)握手 QWebChannel 的 files/updates/papers，对请求分配身份、安装各模块 port，并把回调转为 Promise。[browser.ts](src/platform/browser.ts)提供基础浏览器能力；previewFiles 支持本地预览，serverFiles(owner, project, ...)通过 /api/v1/ 接服务端并处理失效账号和资源。可选 port 缺失时由模块呈现明确限制。

桌面通过coalesced-requests合并尚未结束的同参数语谱图和白名单只读任务，仍经原串行任务队列。写操作清除后续查询的合并关联，不取消先前调用；完成或失败后移除关联，新请求重新校验。仅有多个调用者时复制返回值，避免相互修改。参数表/重建预览、任务/批次读取可合并，提交/取消/导出/录音/下载及有状态EGG交互不合并。

桌面 M10 使用 vocalRequest，网页版由 ResearchFiles.vocal 注入 vocal.ts，同一 iframe 的请求转到账号/登录会话/项目隔离的同源接口，AudioContext接收服务器PCM，按实际播放位置同步动作和输出监测；文件由浏览器选择/下载，构形与关键帧使用当前标签页的项目快照。网页默认33/可选65，129/257禁用并引导桌面下载。网页版仅1秒固定构形发声，生成/播放时锁姿势，持续发声置灰，关键帧/视频最多5秒；桌面保持原策略。M16 使用 recordingPort，M18 使用 papers channel。它们各有协议和生命周期，不能强行当成同一种批任务。网页版 M16 在同一 RecordingPage 注入 browserRecordingPort，AudioWorklet采集用户设备float32 PCM，原始采样经统一文件接口保存本机。browser-recording-project管理受管版本、CAS快照、任务选用和恢复片段，剪辑/降噪/增益/格式导出通过recording-server接既有服务器任务。波形/试听在客户端，实时与录后Praat显示使用受限服务器预览。录音期间每131072帧保存本机恢复片段，完整采样和快照提交后才清理恢复副本；本机快照和录音不受服务器工作区30分钟期限清理。桌面工程文件夹导入校验f32摘要和EDL，完整ZIP备份可解压后用桌面工程读取。设备生命周期跟随原采集租约和关闭保护，桌面仍用原端口。M10和MFA未具备网页能力时保留真实界面并展示主题遮罩；M10 presentation只加载原生参数元数据，不制造科研结果。具体代码和操作说明由[模块导航](../docs/modules/module-migration.md)进入。

M18 网页通过 `ResearchFiles.papers` 注入 `papers-server.ts`，复用同一论文页及 PDF 阅读器，桌面继续使用原 channel。浏览器文件选择/下载接同源论文接口，状态与文档存于既有配额资产；自动检查、流式进度与取消随端口生命周期管理。网页回收站可恢复，服务器副本随工作区到期清理，见[论文网页验收](../docs/testing/web-paper-reading.md)。

## 状态、显示与保存

`state/audition.ts` 管理 APP 级试听自动增益及持久设置，`platform/playback-gain.ts` 提供播放端峰值增益规则。共用 PCM 播放与 `state/media-audition.ts` 的媒体输出图接入同一开关；M16 独立录音输出、M10 本机与浏览器流式输出显式传递该开关。媒体增益读取/解码有界，失败保留原始音量并显示提示，关闭或卸载终止在途读取。M15 正式调度只读取实验配置的 `playbackVolume`，项目和会话快照保留该值，不读取试听开关。采集、科学计算、输入数组和导出文件均不通过试听增益。

录音页的工程快照回写通过`recording/state.projectSelection`保留用户选定的任务，只有打开/初始化工程时恢复最近录音；保存新任务不选回旧条目。录音请求在自动保存清单前固定任务ID。Ctrl＋滚轮在波形与语谱容器转换为有界整数帧窗口并合并预览，普通滚轮保持滚动。五种导出范围在网页适配和桌面执行端保持相同语义，批量范围不依赖当前任务已有录音，全部历史禁用单一版本选择。

工作区与模块状态保留当前输入、选区、配置草稿、未保存状态和任务归属。输入切换后的旧异步结果不得覆盖新输入。公共 audio 状态与 capture lease 协调播放和设备占用，模块自己的播放器仍须遵守活动页/关闭边界。

参数估计页与其他已打开工具一样保留组件实例，切换标签仅隐藏，关闭标签才释放并忘记工作区。共用波形与科学图窗忽略隐藏时的零宽度，沿用最后可见尺寸；SVG 图线按数据与坐标缓存，选区、光标与事件标记更新不重建静态图线。实际视野、尺寸或科学数据变化仍使对应图线与语谱图预览失效。

参数显示、录音、F0对比与变调历史图同样缓存静态图线，各专用图窗忽略隐藏零尺寸。PDF阅读器保留可见宽度和同分辨率页面缓存，停用时停止预取，恢复时按当前视野补齐。参数估计、EGG、LPC、变调、语谱图重建和录音在隐藏且空闲时暂停自动查询，有实际任务/录音/播放时继续跟踪；返回页面立即核对状态。声道监视器只在实际可见时请求实时分析。账号工作区心跳、必要设备/任务监控及未保存内容的保护不按空闲页面处理。

参数显示的右栏直接编辑当前PlotGroup.parameters，没有独立待分配选择。点击图窗/标题或下拉框切换选择，各窗独立，新窗为空；保存格式保持原groups结构。ParameterFigure在现有SVG中计算紧凑图例的文字宽度及曲线避让，PNG与SVG共用布局，白底PNG使用固定科研配色。

M12 的 `annotation/history.ts` 复用 `LocalAssets` values 存储，按 owner、稳定本机项目、文件身份和音频摘要隔离。原始与最近 50 次不同内容快照通过 CAS 写入；切换前先提交文字并等待 TextGrid/唇偏回执，历史失败或原生写入失败均保留当前编辑。历史恢复产生新的当前版本。桌面扫描只提供不可逆稳定身份，网页 `annotationScope` 沿用本机项目分组，不引入数据库 schema。

M12 同一编辑器维护三个可见全域区间层的角色、层间关联组与独立吸附设置，未选层和点层随文档保留。关联组共同约束重合边界的移动，词层整体编辑按关联携带下层区间；第三层显示存于录音视图，关联/吸附通过既有本机/账号设置保存。浮动音标键盘独立按需加载，符号和布局由 M17 权威 catalog 生成精简投影，共用 Unicode 插入和字体；拖动/面板大小只更新容器样式，不推进标注 revision 或重算主图，按键不使用全局磨砂壁纸。

文件读取、受管计算结果、草稿和用户导出是不同生命周期。取消原生保存后，页面保留可重试的结果；持久草稿恢复按模块显式处理。M15 的试次、恢复和提交使用 IndexedDB、事务及并发控制，不依赖后端研究任务库，详见[M15 决策](../docs/decisions/ADR-M15-client.md)。

M08 共用多值参数表单，语速和所选音高方式在前端展开为现有单配置任务，不改变 m08/1 科学协议。最近提交批次以任务 ID 汇总跨来源成功结果，完成后打开保存选择；同源历史的删除/重命名范围保持独立。任务逐版本选择按来源 ID 或名称加摘要定位原音，切换先处理未保存编辑。浏览器在用户保存点击内先请求 WAV/ZIP 保存位置，缺少选择器时使用既有下载。

M13的命名字表复用LocalAssets现有values存储，网页版按账号隔离并固定在独立的本机字表分组，不随临时项目过期。桌面使用宿主持久浏览器配置。库内记录两列原值、类型、名称、可选内容修订号/声调处理设置与最近自定义选择，替换沿用ID、删除回退内置标准，CAS成功后才应用，字表和自定义ID不进入账号设置。导入保留原表行列坐标，按用户选列/起始行抽取；声调默认原样，调值转五度符号，调类可保留或显式映射，原始音标不覆写，后续编辑同样递增revision。XLSX读取按需复用现有锁定SheetJS，CSV/TSV在本机校验；Windows、macOS与网页共用转换、导入、草稿和PNG路径。PNG导出窗读取当前背景状态快照，独立设置图片/纯色及模糊/不透明度，不回写全局外观。背景先合成，之后绘制清晰文本，预览/下载共用Blob，临时URL按对话框生命周期释放。

波形与图表根据当前视野采样显示，原始时间、采样率、缺失值和后端信息沿数据传递。界面默认、尺寸与主题统一见[UI 规范](../docs/design/UI_SPEC.md)，模块 README 只记本模块例外。

M19 语言地图三端共用 `groups.ts` 的大类成员表、地点去重及例外处理，细类字典与原始观测独立保留。资料通过实例级 `GeoPort` 读取，Windows 可用 EXE 旁资料；三端均支持本机目录导入。导入校验固定清单、哈希和数据结构后，以 LocalAssets 的既有 values 存储原子替换资料值。持久资料与内存缓存均按研究工作区 scope 隔离，模块实例随 scope 更换；工程 JSON 只记录个人编辑及显示状态，不内嵌底层资料或书页。

## 资源和生成物

- contracts/generated/api.ts 由 OpenAPI 快照生成，业务代码消费类型，不直接改生成文件。
- scripts/generate-ui-data.mjs 从参数目录和统一来源登记生成 src/generated/parameters.json、sources.json。
- 说明书源工程位于 manual/，发布阅读资源生成到 public/manual；当前可编辑源稿和生成副本不能混用。
- public/vocal-tract 是 M10 现有嵌入界面及资源，由适配与 Vue 模块协作；不能误判为可删除的重复整套应用。
- 独立作者编辑器导入共用 ManualDocument/公式组件，前端产品不导入 tools/manual-studio。公式由受限 KaTeX 渲染，失败时显示源文本和提示。

## 验证入口

package.json 定义 typecheck、test、contracts:check、ui-data:check 和 build。按改动运行需要的检查，平台交互另外使用模块 E2E/Qt 脚本。构建成功只证明静态产物可生成，不能替代受管任务、保存、设备或最终 EXE 验收。

独立反馈管理页面的用户反馈与WebOperations使用原生DOM容器切换，不能在含ModalDialog的多根组件上直接使用v-show。会话和草稿保持挂载，主区域min-height:0，聊天记录滚动且输入框保留。运维页仅激活且可见时30秒拉取，审批确认期间不自动刷新选中对象。管理端样式限定组件，不影响主工作台。

## 私测平台修复

参数显示的server适配通过源音频SHA取得最近成功参数表并再次验证资产身份，同名匹配保留为无计算来源时的回退；不重新估计参数。网页反馈使用账号专属通道转发到web-feedback，邮箱仅由服务器决定，桌面通道及首次邮箱验证保留。共用反馈弹层使用紧凑尺寸和滚动区域，MFA引导保留两个等高操作按钮。M10通过账号设置webNoticeSeen记录首次说明，只有网页试听改为0.5秒，桌面仍为1秒及实时发声。

M10多套构型UI仅调用共享Runtime的library操作。vocal-profile.ts复用LocalAssets的IndexedDB values，以账号/项目隔离并CAS写整个profile；vocal.ts串行化保存、失败回滚计算状态，关闭不删持久数据。会话旧记录仅在无持久记录时接续，损坏原文可导出。
