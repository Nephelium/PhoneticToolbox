# 说明书共用阅读层

继承 frontend 的约束。这里只包含结构化内容类型、只读渲染、目录与搜索、媒体播放协调和主题语义样式。独立作者工具可以导入本目录，产品不得反向导入作者工具。

- 权威 JSON 格式为 `ptb-manual/1` 与 `ptb-manual-chapter/1`，兼容 Tiptap 标准节点；扩展节点须显式处理。
- 使用 Vue 文本/节点渲染，禁止任意脚本及未过滤的 HTML。媒体只通过资产清单和发布相对路径引用。
- 章节按需加载，全文搜索使用生成索引。未知节点和缺少素材明确显示，保留原内容供作者修订。
- 播放默认关闭，说明书与工作台播放互斥，录音限制沿用公共设备租约。
- 本目录只承担阅读层职责；宿主入口、模块帮助映射和公共主题在各自目录维护，修改范围按当前任务授权确定。
- 定向验证：在 frontend 中运行 `node --test tests/manual-reader*.test.ts`；类型检查使用既有 `npm run typecheck`。
