# 生理参数合成 · M10

本目录是桌面与网页版共用声道工作台的界面适配层，模块名称为生理参数合成，持久模块 ID 为 `M10`，见[模块注册表](../../app/registry.ts)。[说明书章节源文件](../../../../manual/chapters/m10.json)已有操作正文，随当前功能持续修订。本页记录当前工程与验证边界。

## 功能概览

声道页面的面板、工具栏、分析窗与控件通过宿主主题桥同步浅深配色，器官颜色和科学图像保留原有含义。贯穿的参数侧栏单独接收公共 rail 底色，内部控件与卡片保留 panel 底色。

当前模型加厚后卷舌尖并保留圆顺过渡，舌叶圆点绑定实际表面。前部气腔按组织剖面补足重建细缝，声学积分保留同一剖面的窄缝，舌腹沿下颌内壁和下牙表面回接口底，整块显示舌体避让上下牙，软腭背侧使用平顺连接。桌面默认使用 65 个纵向截面（64 段），浏览器Wasm也默认65截面、可选33/65/129/257；服务器回退默认33、可选65，横向仍为 96 点，几何方法 m10/r21 与采样变化可以改变声管面积及谱峰。当前导出版本8，旧1–8版继续读取，旧几何文件提示按当前方法重算。R21 在原生接触约束前平滑舌面/舌叶局部连接，显示与合成采用同一几何。

区段特征按 48 kHz 最近采样点的半开区间生效，F0、气压、构音和试听补偿均遵守同一边界。序列生成完成、取消或失败后恢复原舌根模式，持续发声开始时重新同步当前模式。男女模型的内置起点加载完整构形、模型默认 F0 和声源，已有作者预设仍优先。改变当前声管或声源开度时重新计算 F0 试听补偿，并复用已有参考缓存。

同步视频的 F0 曲线及字幕读取合成后的控制轨迹和画面状态，包含手绘曲线、全局调整及区段特征，静音和零振动声源留白。显示的是合成控制 F0，声学测量仍以输出波形为准。本轮验证与平台边界见[五项审查验收](../../../../docs/testing/m10-review-fixes.md)。

现有嵌入工作台连接 VocalTractLab 2.4 原生引擎，提供二维与三维构形观察、器官参数控制、浊声/清声/耳语近似声源、面积与传递函数显示、关键帧、F0 控制和同步视频保存。一个普通关键帧也可按停留时长播放并保存同步视频，一个静音帧保持构形并输出静音。单帧支持 0.05–3 秒，当前源码的桌面与浏览器 Wasm 序列上限为 60 秒。

舌面与舌底新增两个随形控制点。局部偏移 `tongue_shape` 保存四个 cm 值（舌面前后/高低、舌底前后/高低），缺省全零，19 项 VTL 参数顺序不变。舌面偏移作用于原生目标曲线并重算截面和合成声管；舌底偏移作用于受上下牙和口底限制的可见组织回接，不另造舌下声学分支。重置舌头恢复局部偏移为零，撤销与保存均保留它。

已存构型表点亮内置及用户构形，保存面板采用同样的明暗标记，未保存音标保持可点击。设置常用可增减底部快捷按钮。t、l 默认使用作者保存的完整构形，n 沿用 t，保留局部舌形、唇宽、舌根模式、喉部高度、F0 和声源。默认数据位于 `frontend/public/vocal-tract/default-presets.json`，与个人构形库分开；s 暂从默认及常用选择中移除。默认保留原 11 个快捷起点。常用 ID 顺序随套装保存，允许空列表；旧 `favorites.json` 仍可只读接续。

不再提供添加送气帧按钮，新编辑通过正负 VOT 控制送气与浊音起始。旧文件的送气帧继续兼容，保存 `{aspiration:true,duration,name}`，名称默认 ʰ，可直接编辑，没有独立姿势。普通帧起始时刻为姿势插值节点，夹在其中的送气帧延长前后节点间的同一平滑过渡，送气区间使用清声。时长 0.01–3 秒，缺一侧构形时保持另一侧，至少需要一个普通或静音构形帧。原生音频块在送气边界切开，并以零长度更新切换声源，保留声管状态。F0 图和视频时间轴将送气区间留白。

构形和交互包括：

- 小舌、上下唇及其他正中控制点在二维、三维常驻，无须先选器官；侧缘只在三维和横截面调整，正中矢状图保留 11 个控制点，三维保留 14 个。原生牙齿保持刚性，下牙仅随下颌运动。二维采样气腔按实际口腔边界裁切，并单独保留鼻腔及后方连接，防止越界盖掉灰色组织；隐藏牙齿按刚性轮廓独立补绘头部底色。重建舌腹和封盖避让牙齿体积，下牙牙冠的支撑向前延续，消除舌底越过牙齿后突然下坠的台阶；隐藏牙齿仍保留约束。软腭只描绘暴露轮廓，头部组织内部封闭线不再显示为突起。
- 前侧缘向上可形成两侧支撑与中央沟槽，向下可形成中央接触与双侧通路；仍沿用后、中、前三组左右联动控制。气腔按开放采样区域分离、汇合，并扣除上下牙齿实体，隐藏牙齿不解除约束。舌下口底附着参考已向舌根方向后移，相对下颌固定，舌腹端随构形变形。参考点为模型近似，不是 JD2 个体的舌系带测量位置。
- 舌叶内凹受随舌背与舌尖变化的支撑线约束，过渡保持平滑；抬高的舌尖可后缩，保留硬组织及口底限制。后卷采用后上方切线和前侧回接，避免整圆绕回及舌腹自交。参数模型可以形成后卷构形，具体语音类别仍需独立声学及听辨依据。

- 小舌本体沿原生表面保持固定形状和尺寸，接触舌面时整体止抵，软腭附着部分过渡。剖面融入头部背景，拖动点常驻，选中时显示细边界。显示舌面保留原生三角形，口鼻连接固定前后对应关系，参考截面由口腔正中连续过渡到鼻腔旁中线 5 mm。原鼻腔和头壳资源不缩放重写。
- 舌尖可以前伸出口，舌叶放宽过严的构造限制，拖动从引擎实际位置开始。保留模型中的硬腭、门齿、口底和后咽壁约束。
- 独立声门高低默认为 0，可在 −1 至 1 cm 模型范围内调节。舌骨与会厌附着点固定，几何、声道长度、截面、传递函数、试听和动作合成使用同一偏移。
- 三维默认显示半侧组织及口鼻气腔，显式勾选显示完整模型后解除裁切。选择会随本机视图偏好保存。
- 面积图的实线为几何截面积，虚线为合成使用的声学修正面积。正中接触且有侧通路时说明通路仍开；全截面闭塞显示 0，声学求解器保留数值下限。

- 顶部恢复 `/a/` 按钮、来源弹窗中的布局标签与下拉框已移除。底部 `/a/` 预设、器官局部重置及撤销/重做保留。模型与来源按钮使用公共按钮尺寸。
- 布局仍读取既有 `two`、`three`、`auto` 偏好，默认自适应窗口；本文不提供已经移除的布局选择步骤。
- 保存/加载构形弹窗直接复用 M17 的完整扩展辅音目录，包含 14 列、13 类、186 个可点击辅音表项，另有 28 个元音按钮、20 个其他辅音按钮与自定义区。186 包含组合示例，不代表 186 个独立基本字母；总计为 218 个不同符号、234 个按钮位置。
- 音标表为当前构形提供名称。保存音标不自动生成对应标准发音，也不构成听辨通过的证据。

桌面采样设置保存在当前本机工作台偏好中，启动时恢复；调整后重新计算真实截面、中线、声管面积和传递函数，并使已有动作缓存失效。65 截面降低计算量，但更容易漏掉局部狭窄。科研比较须固定并记录截面数。129 和 257 分别对应 128 和 256 个相邻截面间隔，界面标注截面数。

面积图实线连接各原生截面位置的几何面积，虚线显示声学修正后每个合成声管段的恒定面积，不从虚线的边界拟合实线。

## 输入与输出

| 类型 | 当前工程边界 |
| --- | --- |
| 前端输入 | 桌面 `vocalRequest` 或网页版账号项目 `vocal` 能力、公共主题/字体/按钮设置、M17 音标目录；不接收任意服务器文件路径 |
| 构形库 | 桌面本机 profile 的 `preset-libraries.json`，`version: 1`；保存各套装器官参数、声源、F0、常用项及当前套装。未有新文件时只读旧 `presets.json` v1/v2 与 `favorites.json`，既有名称和记录继续兼容 |
| 关键帧缓存 | 本机 profile 的 `keyframes.json`，当前写入 `version: 3`，包含帧序列与 F0 曲线；由桌面 profile 适配器读取 |
| 关键帧交换文件 | `.ptb-vocal.json`，`format: phonetic-toolbox-vocal-tract`；当前写 `version: 8`，记录 JD2/W02 说话人及 `geometry_method: m10/r21`，微扰另记录 `m10/source-1`。旧1–8版可读，旧几何提示重算，不能据此逐样本复现旧音频 |
| 视频与音频 | 同步动作默认保存为 `.mp4`（H.264 / AAC），复用已有隔离 PyAV 编码运行时；合成与试听由桌面原生运行时及媒体适配器处理，Vue 层不实现科学算法；网页版优先本地Wasm计算，浏览器播放，MP4由服务器有界转码；运行包不可用时选择受限原生服务器回退 |

关键帧交换文件由[纯核心文档校验](../../../../packages/phonetic_core/src/phonetic_core/vocal_tract/document.py)检查，桌面再由[桌面文件适配器](../../../../desktop/src/ptb_desktop/vocal_tract/files.py)执行选择与保存，网页版由浏览器选择与下载，当前文件容量上限为 8,000,000 字节。用户取消选择返回取消状态；导入模型、参数顺序或范围不符时明确拒绝，不能静默夹紧后替换原构形。构形库及缓存由[ProfileStore](../../../../desktop/src/ptb_desktop/vocal_tract/profile.py)维护，与只读引擎资源分开。

分享页列出当前模型的自存与内置构型，默认选中自存项。可全选、全不选、刷新选择自己的构型或逐项勾选后导出。构型包要求相同模型、摘要及参数顺序。已知旧几何包可预览，勾选按当前几何重算后导入；新包记录当前几何。

序列页的全局调整和超音段特征均可选择 jitter/shimmer，支持固定值与相对偏移。区段可按关键帧或起止时间选择，使用 0–100 声源调节强度并沿用序列种子。该强度不等同于音频分析测得的 jitter/shimmer 百分比。

## 快速流程

从底部载入预设或拖动器官，选择采样截面数，再到关键帧页签保存姿势、设置过渡或停留时长。一个关键帧即可播放或保存 MP4。普通帧与非末尾静音帧都平滑移至下一姿势，静音帧只关闭声音；末帧保持构形。详细操作见[生理参数合成操作章节](../../../../manual/chapters/m10.json)。

## 格式与限制

- 桌面通过 `vocalRequest` 调用本机引擎，网页版优先在独立Worker调用同一核心与Wasm组件，首次装载失败才选择同源服务器会话。服务器须显式配置经过验证的 `vocal_resources`，无服务时显示载入失败及重新打开入口。
- 服务器回退试听先缓冲一秒或整段较短音频，再启动浏览器播放时钟；后续分块保留更充分的网络余量。服务器生成的PCM、音量、包络和按实际播放采样推进的动作时间轴保持，停止或关闭期间到达的旧分块不再启动播放。
- 浏览器Wasm默认65截面，可选择33、65、129、257。服务器回退只允许33/65，129/257置灰；桌面默认与既有偏好保持。
- 网页保留当前构形0.5秒测试发声，浏览器Wasm开放持续发声与60秒序列。仅服务器科学回退禁用持续发声并限制5秒；固定构形试听期间锁定编辑。服务器视频编码独立允许60秒，保持原有尺寸、字节和执行预算。
- 网页关键帧/构形/常用快照按账号与项目保存在当前标签页，刷新恢复，离开工作区清除；长期保留请导出 `.ptb-vocal.json`。音量、视图等外观设置按公共账号设置机制保存。
- 当前序列文档绑定 VTL 2.4 的 JD2 或 W02 模型，导入前切换对应模型。头壳为外观参考，平均鼻腔为独立研究数据的显示配准；二者均不能视为 JD2 同一个体的 MRI，鼻腔显示开关与 VTL 声学鼻腔管道需分别解释。
- 面积与传递函数是当前模型的计算结果。F0 曲线是合成控制轨迹，不能称为输出音频重新测量得到的 F0。清声/耳语近似无周期振动部分也不能据此赋予实测基频。
- VTL 2.3 手册仅作补充参考，具体参数与模型行为以当前 2.4 引擎、源码和对应证据为准。
- 持久构形键、既有文件和来源保留；近期界面检查不等于实体音频、跨平台或完整成品验收。

## 源码结构

| 文件 | 职责 |
| --- | --- |
| [VocalTractPage.vue](VocalTractPage.vue) | 装载同源 iframe，核对消息来源，转交桌面或服务器请求，同步主题/字体/按钮与音标表，连接未保存状态、引用和关闭事件；失活发送 `deactivate`，卸载发送 `shutdown` |
| [ipa-chart.ts](ipa-chart.ts)、[preset-chart.ts](preset-chart.ts) | 从 [M17 目录](../ipa-plus/catalog.ts)构造扩展辅音、元音、其他辅音和中文名称，保留 Unicode 原文 |
| [index.html](../../../public/vocal-tract/index.html)、[app.js](../../../public/vocal-tract/app.js) | 嵌入工作台布局、参数、视图、声源及关键帧的界面编排 |
| [platform.js](../../../public/vocal-tract/platform.js) | iframe 与父页面的 `m10-request` / `m10-response` 消息端口，不自行开 socket 或选择原生路径 |
| [presets.js](../../../public/vocal-tract/presets.js)、[layout.js](../../../public/vocal-tract/layout.js) | 构形命名/保存加载及既有布局偏好读取 |
| [桌面平台接口](../../platform/desktop.ts)、[Qt 宿主](../../../../desktop/src/ptb_desktop/host.py) | 经 QWebChannel 调用本机桥，原生文件选择与视频写入由宿主处理 |
| [client.py](../../../../desktop/src/ptb_desktop/vocal_tract/client.py)、[runtime.py](../../../../desktop/src/ptb_desktop/vocal_tract/runtime.py) | 每个拥有窗口的原生进程、请求归属、受限启动/关闭、profile、试听与动画缓存；只管理本应用拥有的进程 |
| [科学核心](../../../../packages/phonetic_core/src/phonetic_core/vocal_tract/) | VTL 原生接口、声源、轨迹、合成与文档校验；不依赖 Qt 文件对话框或数据库 |
| [原生资源](../../../../resources/vocal_tract/) | VTL 2.4 DLL、speaker、几何桥接、来源锁、许可和重建材料 |

调用方向为嵌入界面 → `VocalTractPage` → 桌面能力 → 原生运行时与 `phonetic_core`。网页版同一界面经 vocal.ts 优先调用独立 Worker 的同源 Wasm 运行包，首次不可用才经 vocal API 使用独立原生进程，视频编码始终使用服务器端口。页面不依赖用户运行桌面软件。科学状态机在 core/session.py 只维护一份，音频/配置和文件端口由各执行端注入。当前原生几何版本 `m10/3` 与运行时 API 握手 `m10/1` 是不同标识，不应合并为同一版本字段。整体职责见[前端架构](../../../ARCHITECTURE.md)和[总架构](../../../../ARCHITECTURE.md)。

## 开发与定向验证

从[统一源码入口](../../../../docs/development/source-entry.md)启动，[Start-M10-Workbench.ps1](../../../../scripts/Start-M10-Workbench.ps1)是直接打开 M10 的快捷入口。主环境绑定当前 core/backend/desktop 源码，不依赖早期同步到环境中的项目副本；启动器不自动构建、安装或迁移数据库。

```powershell
npm --prefix frontend run build
& './scripts/Start-M10-Workbench.ps1'
```

[m10_recording_entry.py](../../../../scripts/m10_recording_entry.py)保留录制/冻结程序的 M10 专用入口，在既有运行环境中装载 `frontend/dist` 和显式声道资源。它不代表另一套前端或科学算法，也不应绕过项目的环境配置直接复制到任意机器运行。

按改动选择类型检查、前端测试、构建、`ui-data:check` 与对应 Qt/原生检查。实体音频、物理 DPI/DWM、长期运行、Linux GUI 和当前冻结成品完整科研流程需要独立证据，模型构形也不等于医学真实性或听辨通过。

## 网页重复试听与背景

网页版每次0.5秒测试发声独立开始，等待音频设备时清除上一段完成状态，换姿态或再次合成前确认上一段播放结束。服务器准备/拉取PCM期间显示正在准备声音；浏览器仍负责实际输出。右侧卡片随宿主背景透明，保留卡片边框；科学图窗和组织颜色不随透明规则改变。[当前网页验收](../../../../docs/testing/web-private-repair.md#2026-10-17--生理合成背景重复试听与移动端桌面布局)分别记录真实HTTPS、模拟视窗和实体设备边界。

## 浏览器 WebAssembly

2026-10-18 起增加本地验证的浏览器执行端口。同源运行库可用时，独立 Worker 在 Pyodide 中直接运行既有 Engine/Runtime，ctypes 调用锁定 VTL 2.4 与 m10/r21 Wasm 动态库，几何、声源、关键帧、监测和文档算法共用。首次装载不可用时回到服务器，已开始的本地会话失败不静默丢弃状态切换。停止长计算会销毁 Worker，再恢复已确认的编辑。

本地构建和准备命令见[实施计划](../../../../docs/plans/2026-10-18-vocal-wasm.md)，功能/科学对照及性能见[Wasm 验收](../../../../docs/testing/m10-wasm-report.md)。初轮编译验收保留的33/65与5秒策略已由本次浏览器能力接入扩展：浏览器默认65截面，可选33/65/129/257，支持持续发声和桌面一致的60秒序列；0.5秒测试保留。服务器科学回退仍为33/65、固定姿态0.5秒及5秒序列，视频编码独立允许60秒。已部署的 `public-c5-browser-vocal-recovery` 仍是此前的 12 秒版本；本次 60 秒及 R21 仅完成本机候选，尚未部署。此前实际HTTPS、性能与设备边界见[网页验收](../../../../docs/testing/web-vocal-browser-controls.md)。

平板双指在头部缩放模型，其他区域缩放网页，单指仍可调音或移动视图。切换到设置/其他工具时隐藏完整声道页并保留实例。当前验证与实体设备边界见[交互验收](../../../../docs/testing/web-private-repair.md#2026-10-18--ipad-设置切换音标键盘与声道双指缩放)。

## 手绘气压与声源抖动

关键帧支持蓝色F0（Hz）与橙色驱动气压（Pa）两条曲线，分别绘制、撤销和恢复逐帧值，随时长等比例伸缩。气压直接作用声源，静音段保持静音，送气段可绘气压。当前 R21 统一导出 8 版文档，旧 1–8 版继续读取。早期 5/6 版的气压与抖动字段按原含义兼容。

jitter和shimmer分别控制基频与声门振幅微扰，强度0–100与声学分析得到的百分比不同。默认保留模型原有jitter、shimmer为0；调整后种子随文件保存，同种子可重复合成。持续发声时改姿态不重置随机序列。手绘F0/气压控制慢变化，微扰不修改已绘曲线。设计与验证边界见[决策](../../../../docs/decisions/ADR-M10-pressure-perturbation.md)。

若浏览器组件装载失败且账号保存了自定义微扰，旧服务器会保留配置和文件导出，并提示重新打开模块重试。只有用户明确点击恢复模型默认后才允许使用旧声源合成，避免静默丢失微扰控制。

## 当前共享扩展（2026-10-18）

顶部选择男性 JD2 或女性 W02，分别保存构型库、常用项和序列；新姿态默认 120/200 Hz，已有姿态基频保留。W02 使用自身声道与声门解剖，显示头壳仍是共同外观参考。器官页展开“上下唇独立调整”，或直接拖动上下唇，分别修改前后/高低。接近门齿可形成唇齿狭窄，继续闭合会停止口腔通流。

- **IPA 序列**：输入当前模型已存音标。缺少构型时一次列出，整批暂不添加。默认按音类设置时长，逐项可改，也可显式统一时长。塞音、擦音、元音的默认值分别从 80、160–180、200 ms 开始，其他音类由解析器分类。
- **爆破时序**：展开相应帧，设置闭塞、释放及正负 VOT。闭塞允许10–2999ms、释放1–50ms、送气0–1000ms，三者合计不超过单帧3秒；3秒浊塞音可保留2992ms闭塞、8ms释放和负VOT。释放后的送气与正 VOT 联动。总时长为闭塞＋释放＋释放后送气，前浊计入闭塞；负 VOT 时送气为零。修改送气会令 VOT＝释放＋送气，修改释放时保留 VOT。界面显示释放、浊音起始和结束时刻。时序说明及编辑说明默认折叠，点击展开。启用时合并紧随其后的旧送气帧，以后续普通构型为释放目标，原声源保持。负 VOT 在浊音起始前内收声门，再用2ms过渡起振，闭塞期前浊由原生求解产生。VOT仍是起振指令，声学测量的起点需从输出波形判断。输入“ta”时可自动为 t 启用快速释放。旧普通过渡不自动改变。
- **超音段特征**：点击“添加超音段特征”，选择参数与固定值/偏移，再勾选帧或输入起止秒数。可叠加、停用、编辑、移除。相对偏移相加，最后添加的固定值优先，再叠加偏移并限幅。选帧跟随排序，按时间选择保持秒数。全局构音调整先作用于整段，原始构型不改写。
- **分享构型**：在“已存构型”中进入分享，勾选所需音标导出 `.ptb-poses.json`。别人选择相同声道模型导入，默认另存命名套装，也可合并当前套装并决定保留或替换同名项，即可从 IPA 输入调用。接收方需要支持当前几何与包版本的应用。
- **曲线和声音**：空列表先添加姿态，再画 F0 或驱动气压。固定声管改变 F0 时补偿试听电平，气压、shimmer 和原始计算输出保留。播放与视频准备上限 60 秒，原受限服务器科学回退保持 5 秒。

界面、Python 计算和原生补丁维护一份源码，Windows DLL、浏览器 Wasm、macOS dylib 分别构建。[本轮报告](../../../../docs/testing/m10-shared-controls.md)记录源码/平台验收，现有 EXE、Mac 应用及公开网站不会因本地源码修改自动更新。

本轮 R21 的验证边界与详细代码审查见[舌部与分享验收](../../../../docs/testing/m10-smoothing-review.md)。Windows/本机Chrome已验证，Mac构建入口同步，原生R21重建待恢复环境。

## 多套构型

在已存构型面板选择套装。填写套装名称后可新建空套装、复制当前套装或重命名。每套保存独立构型与常用栏；不同套装可以保存同一个音标的不同姿势。切换后IPA输入使用所选套装，已有关键帧继续保留其原姿态。男女模型各有自己的套装。

分享默认选择当前套装自存项，可勾选内置项。导入默认创建新套装，名称重复时自动建议新名称，可自行修改。切换到当前套装导入时，可选择保留或替换同名项。管理已存名称可以修正旧命名冲突；内部空格允许保存和分享，IPA自动分词仍只识别可匹配的音标键。

网页保存于本浏览器的IndexedDB，按账号和项目隔离，关闭标签页再打开可恢复，退出工作区不会删除。换设备或浏览器时使用构型包交换。另一窗口已写入时，旧窗口会提示冲突；保存失败可重试，解析失败可导出恢复副本。浏览器清除站点数据仍会清除本机保存记录。

桌面当前目录优先，无新套装文件时只读旧presets/favorites与legacy目录，原文件保留。用户编辑后原子保存preset-libraries.json，不执行旧数据迁移。详见[设计](../../../../docs/decisions/ADR-M10-preset-libraries.md)。

关键帧自动保存失败时，仍可导出当前完整草稿，导出不会把未保存状态标记为已保存。舌侧缘前/中/后按钮会同步切换截面滑块、位置文字、上下轮廓和查看器。

中途停止播放会保留停下时的完整姿态，后续持续发声使用相同姿态。关键帧文件导入先保存序列再应用抖动，保存失败保留当前序列及设置，应用失败恢复原值。端点口腔通路保护只在准备过程中临时切换舌根模式，正常、取消和异常均恢复。三端同步及故障回归见[审查修复验收](../../../../docs/testing/m10-review-fixes.md)。
