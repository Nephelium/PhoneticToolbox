# 参数显示 · M02

本目录读取已有参数表并组织时间对齐的图窗，不重新执行参数估计。名称与持久模块 ID 见[模块注册表](../../app/registry.ts)，逐控件操作见[说明书章节](../../../../manual/chapters/m02.json)。本文依据 2026-10-18 当前源码与已记录的模块报告整理，说明书遵循[V2 对照规范](../../../../manual/V2_STYLE_GUIDE.md)及[逐章编写约定](../../../../manual/AUTHORING.md)。

## 功能概览

- WAV、表内文字标注、可选 Praat 语谱图和参数曲线共用查看时间窗与试听选区，两组时间状态分别操作。
- 多曲线同区叠加。点击图窗切换当前选择，右侧勾选立即绘制、取消立即移除；支持搜索筛选、新建、清空、合并及删除图窗。
- Windows 本机读取 M01 主表和 EGG 原始周期表，按当前时间窗查询长结果。
- 保存单个参数图 PNG/SVG，或包含波形、标注、已开启语谱图及当前参数图的整幅 PNG。

## 输入与输出

| 类型 | 内容 |
| --- | --- |
| 输入 | WAV、XLSX、`.ptb.sqlite` / `.ptb.sqlite3`；可读参数表内文字列 |
| 唇形输入 | `.lip.json`，桌面受控读取 V2 数值 PKL |
| 新多表输入 | M01 `m01-bundle/2`，主表和周期表按各自时间绘制 |
| 输出 | 白底 300 dpi PNG、当前样式 SVG；本机保存图窗分配配置 |

同名自动关联依次寻找 `.ptb.sqlite`、`.ptb.sqlite3`、`.xlsx`、`.lip.json`、V2 数值 `.pkl`，重名歧义需手动选择。递归时匹配根目录下的相对名称。自动关联只依据名称，不证明 WAV 与参数表同源。重新打开音频目录会回到同目录参数选择；独立参数目录需重新指定。

本页不直接读入独立 TextGrid，也没有 TextGrid 层级下拉框。文字标签来自已关联参数表的文字列，经勾选分配后显示；独立标注可先在 M01 形成带文字列的结果。时间连续且相同的文字帧合并显示一次，空白间隔后的同名标签分别显示；本机流式表与旧行表使用相同规则。表内标注边界受分析帧和显示抽样约束，原始精确边界应在 M12 核查。

## 快速流程

1. 选择音频和参数目录，核对同名关联。没有参数表仍可试听 WAV。
2. 首次默认空图窗。点击图窗或在右侧选择当前图窗，再搜索并勾选参数，曲线或文字立即显示。
3. 在图面拖动选择试听范围，Ctrl+滚轮缩放查看时间窗。在参数图中用 Shift+拖动平移；波形或语谱图使用时间窗起点字段/滑条平移。双击恢复全长视野，底部“全部”恢复全长选区。
4. 新建图窗后立即切到空选择。各窗独立，同一参数可在多个窗中显示。清空勾选移除当前窗全部曲线与文字，合并回首图保留并去重参数，删除不转移参数。放大仅扩大当前面板并隐藏其他参数窗，右侧仍可编辑及切窗。
5. 等待当前视野数据读取完成，再保存当前图或整幅 PNG，另行保存绘图配置与复现记录。

右侧勾选直接对应当前图窗。新工作区 `reaper=true`、`correction=false`，前者仅筛列名中的 `rF0`，后者筛星号 `*`。搜索或筛选保留已绘参数；全选可见参数只追加当前候选，清空勾选也移除隐藏项，仅作用于当前窗。M02 试听第 1 声道，“显示两个声道”只增加第 2 轨波形，没有本页音频/EGG角色或试听声道切换。

## 格式与限制

- 曲线保留原列名、时间、数值和缺口。自动双轴是显示规则，不归一化数据。
- 新本机多表文件限 4,000,000,000 字节、每表 200 万行、总 1.8 亿单元格、30 分钟；单次窗口查询最多 128 个不同分配列，读取进程受 300 秒/1 GiB 预算限制。旧单表限 16,000,000 字节、20 万单元格、256 列；网页仍使用旧单表入口。
- 全长图的像素抽样保留极值和缺口代表点，逐周期细节需放大。显示抽样不改文件。
- 纵轴判定用可见窗口完整有效值的平均绝对值，沿用量级规则，不按物理单位识别；缩放后范围与轴归属可能变化。
- 两个 PNG 入口均使用白底导出配色；SVG 保留当前样式。PNG 按 300/96 倍栅格化，单边上限 16,384 像素、总像素上限 3,200 万，超限明确拒绝。
- 图线采用固定参数配色、细线及较淡的水平网格，右轴虚线与图例轴归属对应。紧凑无边框图例优先放在无曲线穿过的角落，空间不足时放到图上方；名称完整换行，PNG/SVG及整幅图共用布局。
- SVG 内嵌 Doulos SIL 与 OFL；其他自选字体仍依赖阅读设备。固定外观分享可使用 PNG。
- 保存绘图配置写入图窗 ID、标题和各窗的参数选择，空窗/零窗也恢复；恢复后右侧勾选与当前窗一致。不保存音频、表、目录授权、时间窗、选区、筛选或图片格式。重开后需重新加载源文件，缺失列会从恢复选择中移除，网页账号设置仍按既有策略保存。
- 外部表的算法来源需要独立确认，显示成功不能证明其测量方法正确。

## 方法与来源

曲线方法随原参数来源，M02 负责读取和呈现。参见[来源映射](../../../../docs/modules/evidence/M02-source-map.md)与[统一来源登记](../../../../third_party/source-registry.json)。解析与图形导出不新增声学测量结论。

网页版默认关联所选音频最近成功的参数估计任务输出，优先SQLite，其次XLSX；依据音频SHA及任务来源，不要求结果改成音频同名。没有对应任务时继续按同名匹配，也可手动更换参数表。参数显示读取结果，不重新执行参数估计。
