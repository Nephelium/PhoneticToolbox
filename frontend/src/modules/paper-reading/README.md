# M18 语音学论文精读

## 阅读与批注

左侧按栏目发布日期选论文，右侧连续阅读原文和中文译文。详细论文信息默认折叠，题名栏保留许可及引用入口。支持全屏、上下滚动连续翻页、左右方向键、页码跳转、适宽和缩放。PDF 文本层可直接选择及 Ctrl+C 复制，本页文字提供纯文本视图。切换语言分别保留当前标签内的页码，译文与原文分页可能不同。

选择文字后可加黄色、绿色或粉色荧光笔，或填写文字批注。批注按 PDF SHA 单独持久保存，原文与译文分开，支持编辑、删除和多窗口保存冲突检测。PDF 导出通过原生保存窗口选择位置，可以导出原文件或带标准 PDF 批注的副本，保留原文字和矢量内容。pypdf 6.19.0 为项目本地依赖，见[依赖声明](../../../../requirements/requirements-m18.in)。

右上角帮助跳转到使用说明 M18 章。引用格式提供 GB/T 7714—2015、ASA（美国社会学会）、MLA 9、APA 7 和 BibTeX，引用固定版本原文，提供纯文本复制。作者姓名与目标期刊排版需复核。

论文标题下显示作者、原稿日期、固定版本、原文链接及许可链接，并说明翻译的来源与修改。首篇为 arXiv:2610.00735v1，CC BY 4.0；中文译文采用双栏排版，保留公式、图表及参考文献，图内英文标签保留。

## 内容分发与持久数据

桌面首次启动包含此能力的版本时记录日期，之后升级不会重置。打开模块检查新内容，模块处于前台时每 15 分钟检查一次，也可手动检查。默认下载首次日期当日及之后发布的论文，下载后离线可读。获取往期允许指定包含当日在内的起始日期，显示总篇数、待下载篇数与预计大小。往期选择不会更改默认起点。

论文保存在固定用户目录的 `papers` 子目录，不随 EXE 打包。当前浏览器预览仅显示桌面能力提示。清除启动运行缓存不会删除论文或首次日期。重装系统或手动删除整个用户数据目录将失去此记录。
