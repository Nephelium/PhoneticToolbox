# M18 语音学论文精读

## 服务器推荐与个人 PDF 库

顶部以服务器推荐、我的 PDF 分开管理内容，共用右侧阅读器。左侧目录采用 34 px 单行题名，支持题名搜索、年份、月份及收藏夹筛选。推荐论文按栏目发布日期筛选；个人文件按文件修改日期筛选，题名取 PDF 文件名，不解析论文发表时间。

论文库边界复用 resizablePanels，支持左右拖动与键盘调整，默认250 CSS px，允许190–480 px，阅读区保留440 px。宽度独立保存，切换论文来源或工作台标签继续沿用，窗口临时变窄不覆盖偏好。

服务器推荐的自动获取默认开启。每次应用启动检查一次，持续运行时默认每 6 小时检查并获取新论文，间隔可设为 0.25 至 720 小时。关闭后停止论文的定时检查与后台获取，仍可手动点击检查新论文或获取往期。应用启动仍会检查并取得尚未删除的栏目自有说明，说明不计入论文数量，在推荐目录顶部以请看这里~单独显示。可右键删除本机说明，删除状态在重启和目录更新后保留，需要时从获取往期重新勾选获取。首次启动日期持续保留，默认获取该日期当日及之后发布的推荐，升级及往期选择不会重置起点。

点击检查新论文完成后，反馈区分新获取论文篇数与已有论文内容更新数，无需下载时显示服务器目录篇数。已有条目补充译文、解读或修订 PDF 时沿用同一论文 ID，按栏目内容更新日期发现变化，只获取缺失或变化的文件。已校验的原译文可继续阅读，解读未获取时可稍后补齐；文件内容发生变化时，原批注仍按旧 PDF 摘要保留，不自动映射到新版本。栏目论文内容由服务器独立分发，获取内容不更新应用 EXE；应用功能升级仍通过软件更新入口完成。

获取往期同时列出栏目说明，可按发布日期找回；说明只下载单份 PDF，已获取时同样隐藏并禁选。左栏按年份、月份筛选，右栏显示可勾选的中英文题名；悬浮或聚焦题名可看双语摘要。全选当前筛选只影响当前范围的未获取论文，跨月份已有勾选保留，获取已选只下载勾选内容。已获取论文默认隐藏，可展开查看且禁选；预计大小包含目录中提供的原文、译文及独立解读。

我的 PDF 使用原生窗口选择已有根文件夹，并直接列出其中的 PDF 与普通子文件夹。导入时先选目标收藏夹，再以原生多选窗口选择 PDF；复制保留来源，拒绝覆盖同名文件。当前导入接受不超过 200 MB、1 至 1000 页且未加密的 PDF，各文件失败分别报告。

个人收藏夹对应根下真实子文件夹，移至收藏夹移动库内实际 PDF，并拒绝覆盖目标同名文件。更换文件夹只切换根目录，不搬迁原库。根目录及库内操作拒绝符号链接、联接和越界路径；在外部移动或修改文件后可刷新目录。服务器推荐的收藏夹只保存本机标签分组，与个人文件夹库和服务器论文缓存分开。

选择一个具体收藏夹后，左侧下拉旁的垃圾桶按钮可用，名称为删除收藏夹；未选具体收藏夹时禁用。点击后核对确认窗口，再选择删除收藏夹并保留文件。服务器推荐只移除本机分类，论文与批注保留，原分类中的条目转为未收藏。我的 PDF 先把该子文件夹内的所有文件和子文件夹移到上一级，完成后移除空收藏夹；上一级存在任何同名项时预检整批停止，不合并或覆盖，处理冲突后可重新确认。个人根文件夹不能删除，PDF 内容未变时批注继续使用。移动失败会尝试恢复原位；若提示部分文件留在上一级，应刷新后检查原收藏夹和上一级两个位置。取消确认保留原分类和文件位置。

在推荐论文行上右键选择删除本机副本，核对题名后确认，只清除已获取的原文、译文与解读，批注保留；该条目从推荐目录隐藏，自动检查不会重新下载。需要恢复时，从获取往期勾选该论文重新获取。在个人 PDF 行上右键选择移入回收站，确认后将库内实际文件移入系统回收站，导入前的来源文件与批注保留；无法使用回收站或文件被占用时显示失败并保留文件，不改为永久删除。可关闭其他阅读窗口后重试，或在系统回收站恢复后刷新论文库。

## 阅读、解读与批注

推荐论文的信息默认折叠，题名栏保留许可及引用入口。展开后可查看中英文题名、作者、原稿日期、固定版本、原文与许可链接、翻译说明和阅读导引。已收录示例为 *Articulatory Source-Filter TTS: Physically Grounded Control through Vocal Tract Kinematics*（arXiv:2610.00735v1，CC BY 4.0）。中文译文保留公式、图表和参考文献，图内英文标签保留。服务器目录提供独立解读 PDF 时，阅读器增加论文解读标签；其分页与原译文独立，获取后共用连续阅读、选字、批注及导出流程。

栏目第二篇选用 *Towards a Quantitative Analysis of Coarticulation with a Phoneme-to-Articulatory Model*，中文题名为《基于音素到构音模型的协同发音定量分析》。[固定版本 arXiv:2408.05641v1](https://arxiv.org/abs/2408.05641v1)于 2024-08-10 提交，原文许可为 CC BY 4.0；栏目新收录日期为 2026-10-10。原文、全文译文和独立解读由论文服务分发，栏目新收录不表示论文刚发表。题名引用年份使用原稿日期，目录筛选仍使用栏目日期。

阅读器支持上下滚动连续翻页、左右方向键、页码跳转和全屏。缩放下拉保留适宽及 25% 至 300%。在页面上按住 Ctrl 滚动鼠标滚轮，可围绕指针所在位置放大或缩小；普通滚轮继续上下阅读，应用整体缩放保持。独立适宽按钮已移除。页面随显示器像素比例、应用页面缩放与 PDF 缩放重新渲染，旧图在高清图完成前继续显示，附近页面按像素预算加载。可选文字层仅承担选择与复制，页面字形由原生 PDF 图像呈现，选择范围与批注单独着色。各文档保留当前模块标签内的页码。附近页面按需加载，文字层只挂载阅读位置附近页面；远页跳转可能有短暂等待。

PDF 文本层可直接选择及 Ctrl+C 复制，本页文字提供纯文本视图。扫描图片无 OCR，公式、音标及双栏复制结果需对照原文件。点击批注打开右栏，可直接添加本页笔记，无须先选文字；拖选文字后可加黄色、绿色或粉色荧光笔，或添加选文批注。右栏可定位、编辑和确认删除记录。批注按 PDF 内容 SHA 持久保存，库内移动保持 PDF 内容时继续使用，保存冲突会提示重新载入。批注不写入来源 PDF，也不上传服务器。

PDF 导出通过原生保存窗口选择位置，可选择原文、中文译文、论文解读或当前本地 PDF，并导出原文件或含标准 PDF 批注的副本。本页笔记、选文批注和荧光笔均可随所选文档导出，不映射到其他语言或版本。pypdf 6.19.0 为项目本地依赖，见[依赖声明](../../../../requirements/requirements-m18.in)。外部阅读器的批注显示与打印方式须在副本中确认。

右上角帮助跳转到使用说明 M18 章。服务器推荐的引用格式提供 GB/T 7714—2015、ASA（美国社会学会）、MLA 9、APA 7 和 BibTeX，以原稿日期引用固定版本原文，提供纯文本复制。引用预览跟随应用字体，多作者按原文署名顺序生成，列出人数由各引用格式决定。学校或期刊指定版本、姓名拆分、斜体及排版需复核；个人 PDF 不自动生成文献元信息或引用。

## 持久数据与验证范围

推荐文件、首次日期、自动获取偏好、推荐收藏分组与批注保存在固定用户目录的 `papers` 子目录，论文文件由服务器独立分发，不随 EXE 打包。个人 PDF 保存在用户所选根目录，批注仍保存在应用数据目录。清除启动运行缓存不会删除论文、个人文件或这些记录；备份个人 PDF 时还应导出需要保留的批注副本。普通浏览器预览仅显示桌面能力提示。

已完整获取的推荐与本地 PDF 可离线阅读。联网检查失败保留现有有效目录和文件，获取失败可重试；缺失或校验失败的推荐文件需要重新获取。当前源码包含本轮库管理、调度和第三文档通道，具体行为验收以对应报告为准。本 README 的源码核对不构成本轮实际 Qt、最终 EXE、跨平台或长期运行通过记录。
