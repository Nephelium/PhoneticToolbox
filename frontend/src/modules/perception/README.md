# 感知实验 · M15

本目录实现纯客户端实验设计、刺激预检、正式运行、本机恢复与结果导出。名称和持久模块 ID 见[模块注册表](../../app/registry.ts)，操作见[统一说明书章节](../../../../manual/chapters/m15.json)。说明书的合成刺激和自动按键演示不属于真人研究数据，不构成实体听辨或端到端计时精度验证。

## 功能与实际行为

- X 为单刺激，支持本机音频、图片及 UTF-8 TXT。AX、ABX、AXB 仅接受音频，实际顺序分别为 A→X、A→B→X、A→X→B。
- 以 X 数量按角色组位置生成试次；支持逐行素材关联、指导语、排序、拖动、上下移动、复制和移除。XLSX 导入替换当前试次表，资源模板仅提供路径文本。
- 全局或闭区间洗牌使用 `mulberry32-v1` 和显式 32 位种子，保存算法、前后试次 ID 与最终顺序。相同种子需要相同起始顺序才能复现；不会每位被试自动洗牌。
- 全局/分段反应键支持英文字母、数字和空格。重叠按键范围首匹配优先，空分段键回退全局。长按、组合键、IME 及作答开放前旧事件不计作答案。
- 全量素材预检后按预算采用全量或试次间分块解码。修改配置、开始预览、再次预检或复核时撤销旧试音确认。
- 每位被试建立独立 `participantId` / `sessionId` 和设计快照。运行保存每个 attempt，暂停/异常重呈现保留旧 attempt，当前没有独立的无记录重听按钮。
- 自然完成自动请求 XLSX。点击结束实验先保存，成功后返回初始素材页并保留设计、素材和最近结果；下一被试空表单并重新预检、试音、确认环境。自然完成保持 `completed`，提前结束为 `ended`。
- 结果用格式选择和一个导出按钮，支持完整 JSON 与分析 XLSX/CSV。活动实验导出会暂停。下载请求与用户确认实际保存分开，新反应/中断/活动恢复撤销旧确认。
- 保存失败留在运行页，保留内存结果与 Web Lock，可导出内存记录并重试本地保存。成功退出等待锁真正释放；同一会话不能同时在两个标签运行。
- 恢复终态会话只读取已有边界，不修改 revision、不重复自动下载。活动恢复不续接旧 RT，继续前复核刺激、试音和明确重新呈现。

## 输入、预算与输出

| 类型 | 实际边界 |
| --- | --- |
| 素材输入 | 本机 File/Blob；id、SHA-256、相对路径和 A/B/X 组共同追踪，自动重新关联及 XLSX 匹配限定对应角色组 |
| 素材预算 | 最多 2000 份，单文件 64 MiB、原始总量 512 MiB；TXT 1 MiB，图片 1600 万像素，解码缓存与单试次合计 128 MiB |
| 试次 | 1–10000 个；ISI 与试次间隔允许 0–3600000 ms；手动推进不依赖自动 ITI 倒计时 |
| 项目输入 | `ptb-m15-project/1` JSON，不包含刺激；旧格式只能恢复实际保存的内容，丢失的复杂角色需重建 |
| XLSX 输入 | 第一工作表，最大 16 MiB / 10000 数据行 / 31 列；ZIP 最多 2000 条目、64 MiB 解压总量 |
| 本机存储 | IndexedDB 项目、按 hash 独立存储的刺激 Blob、`ptb-m15-session/1` 会话；revision CAS + Web Locks |
| 结果 | `ptb-m15-results/1` JSON 保留设计/问卷、实际顺序、attempt、角色 hash、RT 与时钟诊断；XLSX/CSV 一行一个 attempt |

新项目默认 X、1000 ms 试次间隔、500 ms ISI、自动推进/自动播放/提示音开启、文件名和全局试次间展示语关闭，F/J 的错误/正确标签是可编辑示例。加载项目恢复已保存值。分段、问卷与表格列的完整说明见统一章节。

## 完整流程

1. 选择范式并导入对应角色组素材，预览关键材料。
2. 核对试次配对、指导语、参数、按键、问卷与最终顺序；保存本机项目并导出项目 JSON。
3. 停止其他播放、录制和重型任务，预检与试音，人工确认设备与环境。
4. 填写被试信息、建立独立会话、阅读指导语并明确开始；等待请作答后使用指定键。
5. 完成或提前结束后保存结果，检查自动 XLSX，另导出 JSON 与需要的分析格式，回读后确认文件已保存。
6. 中断时保留页面，失败先导出内存记录并重试保存；刷新后从本机记录恢复。继续活动会话需重新复核/试音，重呈现生成新 attempt。
7. 下一被试重新预检并填写空表单。跨设备另带原刺激，配置 JSON 不代替素材。

## 方法与平台限制

- M15 无 Python 科学任务、服务器 API、账号或服务数据库前置依赖，素材、问卷与结果不自动上传。
- RT 是作答窗口开放到按键处理的 `performance.now` 差值。音频整段结束后开放，图片/TXT 经过读取、解码和两次呈现帧回调后开放；不代表物理耳机、屏幕或键盘延迟测量。
- `Is_Valid_Key=TRUE` 对应 `completed`，不等于答案正确。中断和无效 attempt 应与完成反应分开分析，模块不自动计算正确率、条件平衡或 RT 排除标准。
- 浏览器解码可能重采样；记录原 WAV 采样率与实际解码率，无法可靠取得的压缩格式原率为空。不自动裁剪、归一化或改声道。
- 网页资源和刺激已准备后可断网完成。浏览器关闭后断网冷启动尚未提供；Qt 使用内置资源。不同浏览器、站点和桌面配置目录各自保存数据。
- 当前结果 JSON 没有导入会话入口。本机恢复依赖仍存在的本机记录，浏览器存储可能被清理，需显式导出文件。
- 实体音频、硬件端到端计时、DPI/DWM、Linux/macOS GUI 和浏览器离线冷启动分别待验；最终 Windows EXE 仅按 Preview 1 报告中实际执行的客户端流程判断，不扩大到全部科研和硬件环境。
