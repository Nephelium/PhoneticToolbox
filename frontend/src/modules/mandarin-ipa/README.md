# 汉字转国际音标 · M13

本目录负责本机逐字查表、按文本位置人工选读、字音排版、本机草稿和 PNG 导出。模块由[注册表](../../app/registry.ts)与[工作台宿主](../../app/AppShell.vue)接入共用界面，不向外部服务上传文本，不创建服务器科学任务。面向使用者的完整操作见[可编辑使用说明章](../../../../manual/chapters/m13.json)，历史模块说明见[原说明页](../../../../docs/manual/mandarin-ipa.md)。

## 职责与入口

- `MandarinIpaPage.vue` 负责输入、设置、结果、多音窗和平台保存反馈，使用公共 ModuleFrame/Toolbar/Section/Status 与字体组件。
- `state.ts` 负责不可变字符索引、十一项转换标准、按位置选择、声调显示、Unicode 编辑后选择迁移及草稿校验。
- `export.ts` 负责等待字体、绑定导出快照、本机 Canvas 排版与 PNG 编码，通过浏览器下载入口交给当前宿主保存。
- 从工作台首页/侧栏打开汉字转国际音标。开发态沿用[共享源码启动器](../../../../scripts/Start-M16-M17-Workbench.ps1)，无独立服务器入口。此启动器委托已有研究工作台并非只开放 M16/M17。

## 输入、输出与当前默认

| 项目 | 行为 |
| --- | --- |
| 输入 | Unicode 文本，汉字、标点、拉丁字符、空白、换行和表情符号都按字符处理，无文件导入/执行转换按钮。 |
| 转换 | 十套 IPA 列与汉语拼音，共十一项；初始 `Standard Chinese (Beijing)`，同字默认字表第一条读音，逐位置人工选择。 |
| 新建页面 | 空文本、Beijing 标准、空位置选择；合法已存排版偏好可沿用。切回仍打开的标签保持编辑。 |
| 初始排版 | 字音同显、左右排布、汉字 24 px、音标 16 px、间距 0 px、行距 1.8、声调开启，粗/斜体及下划线关闭。未手调的仅音标为 28 px；手调后模式切换沿用。 |
| 字体与颜色 | IPA/拼音映射层固定 Doulos SIL。结果汉字层和原样字符可用本机字体；汉字/音标色独立，初始随主题。字样式不改变 IPA 层。 |
| PNG | 白底图片，标题及当前标准名、逐位置读音和导出开始时的排版快照。默认建议名 `ipa_output_<timestamp>.png`。不是可编辑工程。 |
| 本机草稿 | `mandarin-ipa.v1.<stateKey>`，默认 stateKey 为 M13，使用公共 ProjectStore；同一工作区为一个最新草稿槽。保存与恢复为显式操作，PNG 导出不保存草稿。 |

字符计数按 Unicode 字符计算，含标点与换行。未收录字符按原样保留；只有已收录读音在所选 IPA 列缺值时显示 `?`。上下排布只改变工作台输入/结果位置，设置栏仍在左侧。

## 完整工作流与恢复

1. 新建页面输入短文本，选择标准，核对实时结果。
2. 点击结果中带 ▼ 的字组，在近旁多音窗根据拼音与声调编号选择该位置读音。同字不同位置须分别检查。
3. 文本编辑后复核多音位置。未变化公共前缀/后缀的选择保留并平移，替换区选择清除；这个机制不作上下文判断。
4. 调整字音显示、声调、排布、字号/间距/行距、汉字样式、两种颜色和汉字字体，检查附加符号与白底对比。
5. 点击保存本机草稿并确认未保存标记消失。重新打开仍为空文本，通过恢复本机草稿读取完整记录。
6. 点击保存为 PNG，按浏览器下载或桌面保存流程完成，打开实际文件核对内容。

恢复只在存有非空草稿时显示，当前 dirty 时禁用。**保存当前编辑会替换原草稿**。需要读回旧草稿时，先外存当前原文本和必要读音决定，再关闭标签选择放弃草稿并关闭，重开后恢复。关闭框的保存草稿并关闭失败会留在原标签，当前编辑继续保留。草稿不是云端备份。

## 显示与导出的边界

- 单字映射不做词级多音消歧、语流变调、轻声词法判断、儿化组合或连读，不输出实际录音的测量转写。
- 关闭声调只去掉 IPA 末尾 `˥˦˧˨˩`，拼音不加调标，音段附加符号保留。显示拼音先把字表 `v` 规范为 `ü`，如 `略` 为 `lüè`，隐藏声调为 `lüe`。多音窗仍保留编号/轻声标签。
- 汉字字体选择影响结果汉字层，不改变输入框或 IPA 固定字体。桌面优先列实际名称并过滤空项/去重，枚举失败可用常见候选和自定义输入；菜单候选不保证导出可加载。
- PNG 按结果区宽度在 420–1200 px 的逻辑范围重新排版，通常 3 倍像素输出，单边预算 16384 px。长图可降低倍率，仍超限则要求分段；不声明固定纸张尺寸或 DPI。
- 白底固定，未自选的汉字色为深色，自选颜色精确保留。字体不可用、绘图/编码失败、内容过长都会保留当前文本并给出状态区错误。页面没有成功文件路径清单，须实际确认保存。
- 本机 Canvas 导出不依赖 html2canvas、CDN、后端截图或外部转换接口。本页无映射自由编辑、字表导入、批量标准导出、音频或 PDF 导出入口。
