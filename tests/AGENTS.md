# tests — 工作规则

继承 [根 AGENTS.md](../AGENTS.md)，先读本目录 [ARCHITECTURE.md](ARCHITECTURE.md)。当前仅规划阶段；本文件不构成开始业务编码、安装依赖或部署的授权。

- 负责：功能、数值、跨用户和发行验证。
- 允许依赖：公开合成 fixture、经许可的最小样例、忽略的本机语料引用和测试工具。
- 禁止：把用户语料直接提交、删改失败用例、用宽容差掩盖差异、用 mock 成功替代真实原生验收。
- 每次开始定位总计划任务 ID、相关文件、来源和验收项；已有可用代码优先迁移并保留证据。
- 每个用例关联 Rxx/Mxx/验收编号；期望结果来自独立记录的 v2/上游/解析公式，不能直接调用 v3 生成自己的 expected。区分原生设备实测、模拟、WSL 和 Mac 构建证据。
- 预定验证：按任务运行最窄相关检查；在阶段门运行集成/全量/打包；证据写入忽略的 output/validation/。这些命令需要相应计划中的脚手架先实现，当前不声称可运行或通过。
- 改动边界/算法/平台承诺前同步 ADR 和任务；不通过放宽检查来获得“完成”。
