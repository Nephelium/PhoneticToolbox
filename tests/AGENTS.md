# 回归与验收 — 工作规则

继承[根规则](../AGENTS.md)，结构见[本目录架构](ARCHITECTURE.md)。这里只补充本目录约束。

- 用例关联需求/模块/验收编号，expected 来自独立 v2、上游或解析基准，不调用待测实现生成自身期望。
- 不提交用户语料，不删改失败用例、放宽容差或用 mock 成功替代真实原生验收。分别标注设备、模拟、WSL、桌面与成品证据。
- 按 [验证策略](../docs/testing/verification-plan.md)运行最窄相关检查，阶段门再执行集成或发行验证。
- 测试 WAV、长音频、独立测试工程与可重建临时数据按根规则用后清理；记录生成条件和必要结果，保留活动任务、构建依赖与用户原件。
- 新增或维护验证脚本使用 [产物生命周期](../docs/development/artifact-lifecycle.md)：临时对象进入 scratch，证据单独保存，收尾失败留下可处理回执。
