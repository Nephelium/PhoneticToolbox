## 输入、输出和边界
输入来自版本化 contracts 或本组件明确定义的配置；输出为同一协议可理解的结果、错误、状态和可归属的资源。跨边界错误需含机器可读 code 与用户可理解 message，不暴露完整服务器路径或个人语料。

每个用例关联 Rxx/Mxx/验收编号；期望结果来自独立记录的 v2/上游/解析公式，不能直接调用 v3 生成自己的 expected。区分原生设备实测、模拟、WSL 和 Mac 构建证据。
