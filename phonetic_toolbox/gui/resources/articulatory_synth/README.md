# 发音物理模拟器资源目录约定

本目录存放“发音物理模拟器”的纯前端资源。该模块以本地 HTML 方式运行，不依赖外部网络资源。

## 文件职责

- `articulatory_synth.html`: 页面结构和资源入口。
- `articulatory_synth.css`: 页面样式，不写交互逻辑。
- `articulatory_synth.js`: UI 状态、键盘控制、Canvas/SVG 可视化、导出逻辑，以及 AudioWorklet 不可用时的兼容音频引擎。
- `articulatory_audio_worklet.js`: AudioWorklet 实时音频处理器，只放音频线程需要的 DSP 代码。

## 维护约定

- 新增图片、字体或示例数据时放在本目录下的子目录中，并使用相对路径引用。
- 不从 CDN 加载脚本、字体或样式，确保打包和离线运行稳定。
- 声学合成逻辑优先保持可解释；若未来接入后端或三维求解器，应通过新的 service/API 层接入，不直接从网页绕过项目分层。
- 该网页展示的是实时近似物理模型，不应在界面或文档中称为完整三维有限元仿真。

## 参考边界

- 交互范式参考 Pink Trombone 的“拖动声道形状并实时发声”思路。
- 声道面积函数与发音参数映射参考 Maeda/VTCalcs、VocalTractLab 等发音合成模型的公开说明。
- 当前实现不复制外部项目代码、图像或数据；若未来引入实际模型数据，必须先检查许可证并在本目录记录来源。
