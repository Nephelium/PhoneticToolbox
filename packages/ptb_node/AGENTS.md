# 外部节点客户端 — 工作规则

继承[根规则](../../AGENTS.md)，结构见[节点架构](ARCHITECTURE.md)。

- 本包维护节点配置、协议绑定、传输和生命周期，科学算法复用既有 adapter，跨组件修改按当前任务范围处理。
- 使用标准库 Python 3.11+，Linux 为首个目标，测试使用公开合成数据。
- 服务端已有版本化协议，客户端仍须完成显式 binding 和资源/模块准入，不猜测 API，不从任务动态导入模块或命令。
- 凭据、运行目录及验收输出放仓库外或忽略目录。在本包目录运行 `python -m unittest discover -s tests -v`，客户端 fake 不替代实际服务端联调。
