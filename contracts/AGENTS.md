# contracts — 工作规则

继承 [根 AGENTS.md](../AGENTS.md)，先读本目录 [ARCHITECTURE.md](ARCHITECTURE.md)。2026-09-09 已获 P02 工程骨架实施授权，范围见根规则与 P02 计划；不扩大为全面业务迁移或部署授权。

- 负责：跨端数据协议与兼容策略。
- 允许依赖：声明式 schema、数据字典、生成脚本及协议测试。
- 禁止：GUI、计算实现、数据库连接与独立手改生成的客户端。
- 每次开始定位总计划任务 ID、相关文件、来源和验收项；已有可用代码优先迁移并保留证据。
- OpenAPI 由后端模型生成、契约目录保存审阅快照，前端类型只从固定快照生成。JSON Schema 为独立跨进程数据结构；若与 OpenAPI 相同模型，单一生成源避免双份手写。
- 预定验证：协议 schema 校验；生成后工作区无漂移；前后端契约测试；单位/NaN/时间轴样例往返测试。这些命令需要相应计划中的脚手架先实现，当前不声称可运行或通过。
- 改动边界/算法/平台承诺前同步 ADR 和任务；不通过放宽检查来获得“完成”。
