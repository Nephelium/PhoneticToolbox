# 反馈收件箱

电脑双击 `反馈收件箱.exe`，手机安装 `反馈收件箱.apk`。两边查看和回复同一批留言，无需为回复另开邮箱。当前新版在 `output/feedback-manager/1.1.3`。电脑更新时先在旧工具的设置中退出，再双击新版；手机直接覆盖安装，保留登录。

## 第一次连接手机

1. 在已连接的电脑收件箱打开 **设置 → 生成配对码**。
2. 打开手机收件箱，输入这组八位数字。配对码五分钟有效，只能使用一次。
3. 允许通知，开启后台接收。之后关闭再打开应用、重启手机或直接覆盖安装新版，均可继续使用，无需重复输入。

主动退出登录、清除应用数据、卸载，或在电脑设置中撤销手机后，需要重新配对。手机丢失时，在电脑 **设置 → 已配对设备** 撤销对应设备。

## 小米／红米的提醒设置

在手机收件箱 **设置** 中打开通知、自启动和电池设置入口。允许通知与自启动，将应用的省电策略设为 **无限制**；系统菜单名称会随 HyperOS 版本略有变化，也可以在最近任务中锁定收件箱。

开启后台接收后，通知栏会保留接收状态。新留言会有单独提醒，点开后查看和回复。电脑关闭窗口会收到系统托盘，仍能接收提醒；需要停止时选择 **设置 → 退出工具**。

服务器每天北京时间 09:00 补充检查，在线工具还会接收新留言的即时提醒。断网时留言保存在服务器，恢复网络后补收。手机被系统强行停止、禁用通知或限制后台运行时，提醒可能延迟，打开应用仍能读取留言。

## 查看与回复

### 删除、回收站与恢复

收件箱会检查服务器是否已启用回收站。尚未启用时，删除和回收站入口不可用，并提示先更新反馈服务；原有查看和回复继续使用。服务更新后点击刷新即可识别，无需重新登录。

打开会话，点击 **删除会话 → 移入回收站**。会话从普通列表移除，可在 **回收站** 中查看原有消息、图片、来源信息和永久删除时间，30天内点 **恢复会话** 即可继续回复。用户再次提交新留言时，会话也会自动恢复。取消删除会保留会话和草稿。

移入回收站后，排队中的回复邮件停止投递；恢复不会补发旧邮件，新回复按原邮件设置发送。回收站只供查看和恢复。满30×24小时后，服务器清除消息、图片、会话事件及相关投递记录，不能再恢复；服务停机期间未执行的清理会在重启后补做。邮箱验证身份保留，用户以后仍能重新留言。

Windows标题栏显示当前未读数，读完会话后自动清除数字。历史通知重连时会核对当前未读状态，回收站中的会话不计入未读提醒。

会话列表和头部显示最近一条用户留言的来源，每条用户留言旁保留当时的信息：网页版，或版本号与安装版／免安装版。同一用户升级或改用网页后，历史留言仍保留原信息。旧记录没有上报的信息显示未记录，源码启动显示源码运行。完整版本与安装形式需要用户使用已接入上报的新主程序，并更新反馈服务器；只更新收件箱不能补齐历史记录。

选择会话，输入文字或添加截图，点击 **发送回复**。每次最多四张 PNG、JPEG 或 WebP 图片，每张最多 2 MB。发送失败时保留草稿，恢复网络后重试。可按邮箱搜索，筛选未读、待处理和已解决的会话。

回复先保存在服务器，再同步到用户应用。联系邮箱已验证的用户还会收到回复邮件；邮箱未验证的旧会话仍能在应用里交流。邮件投递失败时，电脑和手机均能看到状态并重试。

电脑包适用于 Windows x64，手机包要求 Android 8.0 或以上。当前验证覆盖 Windows 11 与安卓模拟器；小米实体手机上的长期后台提醒仍需实际使用确认。

## 回复与邮件提醒

井韶子的名字和头像会显示在回复中。每条回复先保存在服务器，并同步到用户应用。用户可在问题反馈页面关闭「回复时发邮件提醒」，工具会显示用户关闭提醒的状态；应用内交流照常。开启时每条新回复发送一封邮件，正文为对应回复，重新开启不会补发旧消息。已经投递的邮件无法撤回。

## 扩容与服务器

默认打开用户反馈。点击顶部“扩容与服务器”查看资源与申请，两页独立显示，切回会话保留回复草稿。选择待审申请后，可调整批准总额度和当日/7天/30天期限，并留言批准或拒绝。审批前会再次显示账号、额度与期限。常规额度设置在页面底部折叠区，调低不会自动删除已有文件。

指标每30秒刷新，显示采样时间。当前1.1.0本地包已准备好，生产服务器管理接口仍待启用；接口未连接不影响用户反馈。Windows最终包已验，新APK构建与静态检查已过，实际手机端待验。
