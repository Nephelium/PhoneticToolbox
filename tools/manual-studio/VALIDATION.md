公开内容包与 `--distribution public` 构建均排除 software-only/git=false 素材及未引用旧文件，源工程不回写。软件阅读版包含已授权素材。公开输出目录如果残留未列入的旧受限文件，会报错要求新目录，不自动清理。

没有修改最终章节或媒体、没有公开 Git/推送、没有删除用户文件、安装全局依赖、修改系统或数据库。随后更新功能由主代理另行分配目录与协议，不混入此项作者工具验收。

## 2026-10-06 P10-R3 启动回报与标签页关闭

状态：verified，限定本机 Windows PowerShell 5.1、Node.js 和 Chrome。井井反馈双击无反应，并要求关闭标签页时退出服务器。

原因为旧标签页关闭后，PID 57712 的作者服务仍持有工程锁；第二次启动在隐藏子进程内报 423，PowerShell 未检查服务就绪结果。启动器现在等待独立结果文件，失败由 CMD 窗口显示；依赖检查与旧构建策略保留。所有 PowerShell 源文保持 ASCII 与无 BOM，运行时错误显式按 UTF-8 读取和显示。

新版服务在 Git 忽略的 `.runtime` 保存本机重开信息。重复启动须同时匹配 PID、当前工程锁、作者目录和认证服务身份，再打开同一会话。旧版或篡改记录不允许自动接管，不结束任何未确认关闭的编辑会话。重开文件不进入工程导出或产品分发，普通启动日志不含会话能力。

每个页面有独立的流式连接和带同源、会话校验的关闭通知。最后一个页面离开后约 3 秒退出服务并释放工程锁，断开连接可覆盖关闭通知未送达的情况；刷新重新衔接会话，页面加载与重开时有短期启动预留。关闭其中一个标签页保留其他页。关闭不会生成一次新的正式保存，但会等待已经提交的请求与保存队列完成。未保存内容的浏览器离开确认保留，取消离开后不结束连接。退出工具的只读切换关闭 Tiptap 更新事件，避免误记为新编辑。
