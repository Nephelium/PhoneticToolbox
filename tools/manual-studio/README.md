# PhoneticToolbox 说明书作者工作室

这是独立的中文富文本作者程序。它在当前电脑运行，不进入 PhoneticToolbox 产品构建。正文与图音素材保存到磁盘工程，实时预览直接使用 `frontend/src/manual/ManualDocument.vue`，与软件中的阅读端同源。

## 打开与建立工程

双击本目录的 **打开说明书编辑器.cmd**。启动器使用已有 Node.js 和本目录已锁定的依赖，隐藏后台控制台，在默认浏览器打开作者工具。默认工程是仓库根的 `manual`。不会安装全局依赖或自动改动其他工程。

依赖遗失时，在本目录运行 `npm ci --ignore-scripts`，然后 `npm run build`。需要直接指定工程，可运行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File tools/manual-studio/Start-Manual-Studio.ps1 -Project 'D:\你的说明书工程'
```

界面左下可填写另一个工程的绝对目录，再点切换工程。新建和导入工程包须使用空目录，已有工程不会被覆盖。右上 **退出工具** 会保存待提交编辑，释放工程锁并结束本次后台服务。

关闭最后一个编辑器标签页或整个浏览器后，服务器约 3 秒自动退出并释放工程锁。刷新页面会衔接原会话；打开了多个编辑器标签页时，关闭其中一页会保留其他页的服务。未保存内容仍有浏览器离开提示，取消离开会继续编辑。自动退出会等待已经提交的保存完成，不把关闭标签页视为新的正式保存。

重复双击启动器会验证当前工程锁和服务身份，再重新打开同一会话。启动结果由后台回报，失败会在启动窗口显示原因。先前版本留下的服务无法提供重开信息时，会明确提示回到原页面保存并退出；不会自动结束可能含未保存内容的旧会话。启动信息只保存在 Git 忽略的本机 `.runtime`，不进入工程包或产品 EXE。

## 日常编辑

- 排版、素材、文献栏默认隐藏。点击顶部 **编辑工具** 展开，再选择对应页签。点击栏内 **收起** 或再次点击顶部按钮关闭，正文和预览会使用腾出的空间。窄窗口中工具栏覆盖在右侧。
- 工作室固定在浏览器可见高度内。章节目录、正文、预览与工具栏分别滚动，整页不会继续滚到工作室下方的空白区域。
- 左侧管理章节，可新增、改名、复制、上移、下移、拆分、合并下一章和撤下。拆分从光标所在的顶层块开始，新章有新 ID。合并保留正文锚点并记下旧章节重定向。撤下仅移出目录，原章节文件及素材仍在磁盘。**撤销编排** 恢复本次会话的章节操作。
- 中间使用 Tiptap/ProseMirror 富文本编辑器。工具栏提供粗体、斜体、下划线、删除线、上下标、IPA、字体、字号、字色、背景强调、标题、对齐、列表、引用段、分隔线、代码、公式、交叉引用、文献、脚注、提示框和双栏。
- 普通文字直接输入。文字编辑撤销/重做在工具栏，支持常规 Ctrl+Z/Ctrl+Y。保存形成撤销分组边界，保存后输入的新文字可独立撤销。
- 选中媒体、公式、引用或正文块，点击 **编辑工具 → 排版** 调整图注、替代文字、尺寸、对齐、稳定锚点、LaTeX、引用目标、行距、段前段后和缩进。表格可增删行列、合并/拆分单元格、切换表头和拖动列宽，表题与表注在表格属性中修改。
- 图片、音频、视频通过工具栏选择文件。图片也可拖入或从剪贴板粘贴。文件复制到工程 `assets`，以内容哈希生成稳定引用。原文件之后移动，工程仍可显示。图片原图、音频时长、WAV 采样率及声道等元数据保存在素材登记中。
- **素材** 可编辑标题、说明、来源类型、来源说明和分发范围，查看正文引用位置，并再次插入。把原音与处理结果放入两栏，可构成音频比较组。音频处理由实际科研模块完成，作者工具不改录音。
- **文献** 管理书目信息和来源链接，然后插入引用。站内引用通过章节 ID 与稳定锚点定位，重排不会改变 ID。
- **结构源码** 用于高级调整 JSON。应用前检查节点、属性、结构和安全链接。发现未支持节点、属性或样式时保留原始 JSON，暂不进入可视化编辑，可下载原稿供维护。不会把不认识的结构静默丢掉。

段落内引用和独立成块的交叉引用、文献引用均可编辑。选择引用后在 **排版** 中调整显示文字与目标。保存仍使用原有章节格式，保留引用位置及已有稳定锚点。列表上的稳定锚点也会保留。

富文本格式与表格、媒体说明都能编辑。公式源文可编辑，阅读器和作者预览使用本地 KaTeX 离线排版，无法解析时保留源文并提示。图片保留原图和尺寸/对齐，首版尚无交互裁切；HTML/DOCX/Markdown 文件导入也未提供，完整工程导入使用下述工程包。

## 保存、冲突与恢复

自动保存默认开启，编辑后约 1.2 秒提交到正式工程；**保存 Ctrl+S** 可立即提交。两者使用相同保存流程。编辑后先写磁盘恢复稿，浏览器 sessionStorage 仅保存临时会话能力，不承担正文存储。

保存前检查整个当前工程的内容哈希，写入暂存文件并原子替换。写入期间在 `.studio/history` 暂存旧内容，在 `.studio/transactions` 记录事务；保存成功并回读后清除这些旧副本。`.studio/recovery` 默认只保留最后一份自动恢复稿，新稿写入成功后才清旧稿。写入失败时显示错误，保留页面、最新恢复稿和未完成事务所需的历史，供检查恢复。

另一个作者实例会被工程锁拒绝。外部修改导致内容哈希变化时，当前稿保留到磁盘恢复区，拒绝覆盖较新的磁盘内容。点击 **磁盘恢复稿** 可加载最近稿，检查后再正式保存。异常退出的旧进程锁可在下次打开时恢复，未完成的事务有完整恢复稿可供选择。

清理结果原位写入 `.studio/retention-report.json`。文件占用、联接或未完成事务会留下明确原因，不宣称已删除。未编排的正式旧章及未引用素材仍须逐项审核，自动保存清理只作用于 `.studio` 中可识别的副本。

## 工程包与阅读版

**导出完整工程** 生成 `.ptbmanual.gz`，含工程索引、所有已编排章节、工程中保留的旧章节文件与全部素材。每个文件有 SHA-256。锁、自动恢复区和磁盘历史属于本机作者状态，不进入移交包。导入到新的空目录后校验全部文件哈希，恢复章节及素材相对位置。

**导出公开内容** 排除 `distribution=software-only` 或 `git=false` 素材，也不带未引用旧文件。正文保留稳定素材 ID，阅读端明确显示缺失媒体占位。公开导出不会改变源工程。

素材默认仅可随软件分发，`git=false`。作者核实可公开后，才把范围改为可公开内容。私有绝对来源路径只放仓库忽略的本机来源配置，不写进工程登记或公开内容。

**生成阅读资源** 使用同一校验和构建脚本，在当前工程 `.studio/reading` 生成软件阅读版，预览下拉切到 **已生成阅读版**。随后继续改稿，可切回 **源稿实时** 并再次生成。应用内发布使用：

```powershell
python scripts/manual/validate.py --project manual --strict
python scripts/manual/build.py --project manual --output frontend/public/manual --distribution software
python scripts/manual/build.py --project manual --output output/manual-public --distribution public
```

软件版包含已授权的 software-only 素材。新版生成成功后只清上一版索引/构建报告共同登记、当前不再引用且 SHA 未变的阅读副本，正式源素材保留；未知或已变化的旧输出会报错并保留。公开版过滤受限素材，仅用相对路径。两种输出请使用独立目录。公开目标若含上一次软件版的旧文件，构建会拒绝并要求新的空目录，不会自动删除旧文件。

源工程结构是 `project.json`、`chapters/*.json` 与 `assets/**`，版本为 `ptb-manual/1` 和 `ptb-manual-chapter/1`。权威 schema 位于 `frontend/src/manual/schema-*.json`，附加审计字段原样保留。

## 验证与范围

```powershell
npm --prefix tools/manual-studio run typecheck
npm --prefix tools/manual-studio test
npm --prefix tools/manual-studio run build
node tools/manual-studio/tests/browser.mjs
node tools/manual-studio/tests/lifetime-browser.mjs
```

浏览器测试使用专用工程和独立 Chrome，实际最大化后采集浅深截图，执行真实富文本编辑、媒体导入、保存重开、表格操作、章节重排、工程导出迁移及生成正式预览。记录保存在本目录忽略的 `test-output`。

测试结果按具体报告的平台和对象解释。合成音频只证明解码与往返，实体 IME/DPI、跨平台 GUI、听辨和大工程压力须分别验证。完成后按根规则清理独立测试工程和可再生 WAV。单元/浏览器测试共用 `tests/artifacts.mjs`，报告和必要截图留在运行目录，工程与导出副本放 `scratch/` 并在句柄/进程结束后清理。正式工程按上述最新恢复稿策略维护。构建器应保留草稿/预留章节提示，空正文不标为已完成。

编辑依赖采用官方 Tiptap 3.31.4 MIT 包，公开说明见 [Tiptap Vue 文档](https://tiptap.dev/docs/editor/getting-started/install/vue3) 和 [官方许可](https://github.com/ueberdosis/tiptap/blob/main/LICENSE.md)。准确依赖、包内许可及哈希见本目录 `THIRD_PARTY.json` 和 `licenses/`。
