## 正文与编号

- 阅读器按 `project.json` 顺序自动显示章节号。`heading` 的 level 2 是 `X.1`，level 3 是 `X.1.1`，可继续使用 level 4/5。**标题文本和图片图注不手写编号**；保留帮助跳转使用的稳定英文 ID。标题依真实任务顺序组织，避免每章同样的八段模板。
- 每个实际操作写明“准备条件 → 点击/输入的位置和内容 → 界面立即反馈 → 生成/保存结果 → 失败恢复”。连续动作使用有序列表；可选模式、文件类型和并列控件使用无序列表；参数单位、默认值、作用可用表格。一个段落只讲一个动作或判断，避免整屏连续散文。
- 写当前界面准确可见的按钮或菜单文案。关键操作适当加粗，参数键与文件名使用行内代码；真实命令和代码才使用 codeBlock 并注明语言。不要整段加粗。估计值与测量真值、科学方法与软件显示明确区分。
- 图紧邻首次解释的动作或结果。每个主要状态说明界面应看到什么，必要时再用局部放大图。图注只写画面与观察点，阅读器统一生成“图 X-Y”；表注同理。图片必须有替代文字，表格有表头。截图来自**先最大化的 V3 应用窗口**；局部裁图保留完整窗口原图、尺寸、主题与版本记录。源图保留，打包时生成压缩副本。
- 只在应用处理或合成前后有可听差异的地方插音频。例音跟在操作与结果解释之后，成组比较按“原音/基线 → 设置 A → 设置 B → 听辨重点”排列。单纯导入/分析 EGG、LPC、MFA 不为展示源音而增加播放器。例音真实可播放，记录来源、处理设置和解释范围。源 WAV 保留，软件包可生成压缩副本。
- 对缺少素材或尚未核验的操作明确记录缺口，不把计划、推断、模拟测试或 V2 旧行为写成 V3 已验证。M05 真人视频由作者后续提供，其他正文以当前能力和素材为准。
