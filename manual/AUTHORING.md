# 说明书编写约定

正文依据当前应用，V2 的讲解深度和章节对应见 [V2_STYLE_GUIDE.md](V2_STYLE_GUIDE.md)。工程与素材保留边界见 [AGENTS.md](AGENTS.md)。本页按主题维护，章节完成状态记在工程与对应审计中。

## 内容与协作

- 说明书任务只修改被指派的正文、工程索引、媒体及登记，不据此修改应用 UI、功能、阅读器或科学算法。未验能力明确记录，不写成可用。
- 章节写作沿用每位子代理一个模块、GPT 6.1 Sol / xhigh、同时最多两位章节子代理的约定；主代理集中制作/登记媒体、维护 project.json、统稿及生成资源。此分工只适用于说明书内容任务。
- 章节作者修改被指派的 chapters/mXX.json、对应模块 README 与忽略目录下的 chapter-audit-mXX.json，避免并发覆盖其他模块或索引。
- 使用清楚、亲切的中文，可适量用语气词和颜文字，保持客观视角，不出现私人称呼，不自造术语。围绕操作流程减少长篇原理和重复总览。
- M10 已解除早期正文留空约束，M18 按已实现能力编写；M05 真人视频继续预留。不得用过时预留要求覆盖已有正文。

## 步骤与排版

- 按实际操作顺序组织，不套固定八段模板。主要小节用 heading level 2，流程用 3，必要时用 4/5。标题、图表采用稳定 ID，显示编号由阅读器生成，不手写编号。
- 每项操作写准备条件、点击/输入、立即反馈、输出与失败恢复。连续动作用有序列表，并列条件用无序列表，参数多时用表格；默认值、单位和控件名核对当前源码。
- 代码用注明语言的 codeBlock，参数键可用行内代码，引用/跨章/媒体使用既有 citation、crossReference、assetId 节点。表格有表头，图片有替代文字和图注，不用假路径填素材。
- 图和例音紧邻对应步骤与结果，有比较意义时组织原音/基线与处理后声音并说明设置和听辨重点；不为单纯导入分析增加无用播放器。
- 重点可加粗、高亮或红字，自定义文字/背景色须提供浅深成对颜色并实际检查，避免整页强调。表格不写死配色。
- 不把估计值当真值，不混同合成控制 F0 与重新测量 F0。文献、算法与界面事实分别核实。

## 截图与素材

- 最终截图采用已确认的浅色、2560×1600、有效 DPI 150%（Qt DPR 1.5）、页面 100% 和最大化窗口。模块操作收起全局侧栏，导航教学可展开；不再为凑尺寸改变字号、系统缩放或用户应用设置。
- 原图记录实际尺寸、DPI、主题、版本与摘要。Qt 取整为 2561×1601 时只裁右/下各 1 像素，不整体拉伸。局部图、红圈或圆角框从完整原图派生，不改写控件和结果。
- 已确认布局参照图 SHA256：`9bd0c4e0cf7862374bc828e6747eed87ad07c40580bc9aba685be9cb195ef401`。仅作用于独立截图实例，旧诊断图不当作最终素材。
- 自然录音及处理结果仅供软件分发，不进 GitHub；媒体标记 software-only/git:false。私有原路径与审计放忽略目录，章节作者不复制原始语料或自行批量制作媒体。
- 正式原图/原音保留，发行压缩只发生在构建快照。正式工程只维护当前版本，自动恢复稿默认保留最后一份，成功保存后清历史与已提交事务；失败所需恢复证据和未引用正式素材不自动删除。作者状态留本机并由 Git 忽略。每次实际修改同步更新任务台账对应条目。

## 交付核对

对受影响章节检查 JSON、稳定 ID、目录编号、表格、真实控件/默认值、帮助目标、图注与媒体读取。审计写已读 V2 章节/摘要、V2 到 V3 对应、具体差异、素材位置和待补证据，主代理复核后标 reviewed/verified。

说明书允许持续追加，未完章节、预留演示和媒体数量变化不阻止打包。只改正文/素材时核对受影响内容及基本可用性，不要求每次全书完稿或全书人工验收。
