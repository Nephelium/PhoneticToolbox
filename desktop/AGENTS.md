# desktop — 工作规则

继承 [根 AGENTS.md](../AGENTS.md)，先读本目录 [ARCHITECTURE.md](ARCHITECTURE.md)。2026-09-09 已获 P02 工程骨架实施授权，具体边界见根规则与 P02 计划；不扩大为全面业务迁移或部署授权。

- 负责：桌面窗口、本地服务生命周期、文件/设备和发行适配。
- 允许依赖：contracts、phonetic_core、Qt 与各平台原生适配器。
- 禁止：再实现声学算法、要求用户登录云端才能离线分析、运行 Vite/npm 作为发布态、全局杀进程。
- 每次开始定位总计划任务 ID、相关文件、来源和验收项；已有可用代码优先迁移并保留证据。
- 产物中包含前端静态文件和 Python/原生运行时。系统设置走用户目录；升级不覆盖旧语料。单文件与安装版共用版本/核心/前端 manifest。
- 预定验证：python -m pytest desktop/tests -q；发布态离线/非项目目录启动；双实例、退出、相机/音频测试；分平台构建。这些命令需要相应计划中的脚手架先实现，当前不声称可运行或通过。
- 改动边界/算法/平台承诺前同步 ADR 和任务；不通过放宽检查来获得“完成”。
