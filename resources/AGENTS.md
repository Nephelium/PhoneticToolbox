# resources — 工作规则

继承 [根 AGENTS.md](../AGENTS.md)，先读本目录 [ARCHITECTURE.md](ARCHITECTURE.md)。当前仅规划阶段；本文件不构成开始业务编码、安装依赖或部署的授权。

- 负责：版本化资源、字典、字体、图标、原生组件清单。
- 允许依赖：来源明确且经过发行审查的资源文件。
- 禁止：完整第三方仓库、个人研究语料、环境缓存、未知来源可执行文件、把当前下载 HEAD 当实际使用版本。
- 每次开始定位总计划任务 ID、相关文件、来源和验收项；已有可用代码优先迁移并保留证据。
- K2 主图在 16/32/48/256 像素验证辨识；ICO/ICNS 按平台生成。VTL 与 REAPER 记录 ABI、编译选项和实际依赖。PDF 默认外链，不以下载全文作为资产完整性的条件。
- 预定验证：文件 hash/许可/架构检查；离线加载；包内资源存在性；来源登记双向检查。这些命令需要相应计划中的脚手架先实现，当前不声称可运行或通过。
- 改动边界/算法/平台承诺前同步 ADR 和任务；不通过放宽检查来获得“完成”。
