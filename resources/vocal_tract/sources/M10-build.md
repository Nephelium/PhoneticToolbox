# M10/3 对应源码说明

当前 M10-R14 在 R13 后应用 `m10_r14_patch.py`：后卷舌尖半径连续补偿最多 0.18 cm，并将接入位置平滑移到后侧圆弧，避免仅增大半径仍留下薄片。`p4_blade_rib()` 返回舌叶曲线中点对应的原生分数肋位，显示控制点从最终表面插值。原生纵向截面默认 257，横向仍为 96 点；`p4_section_count()` 导出数量供动态分配。桥接、Python 与公共前端应作为同一源码快照构建。`build_m10_geometry.py --sections 129 --output-dir <审计目录> --no-install` 可保留独立对照构建，默认命令生成并安装项目内 257 档 DLL。声管面积及谱峰会随采样改变，见 `docs/testing/2026-10-07-m10-r14-report.md`。

原版 VTL 2.4 C++ 保留在 `VTL2.4-API-source.zip`，SHA-256 为 `aa696bf4cf5c44cbd433304943aebb241e5ea3064b949daf5ea09f96567cff9b`。原版 API 与 Analysis DLL 未改动。

M10-R13 在 R12 后应用 `m10_r13_patch.py`。辅助舌尖切线点使用稳定的圆顶部高度，避免控制点横向进入构造圆时发生平方根斜率突变。下压舌叶采用端点与椭圆/圆相切的五次曲线。抬高舌尖按弧长与转角分配原有 33 条动态肋线，目标圆弧加密，原生拓扑及 `m10/3` 布局不变。舌腹按末端方向衔接。几何精细化可改变声管面积，不能将 R12 的标准预设数值不变结论沿用到 R13。当前构建依次应用 R11/R12/R13，具体有限验证见 `docs/testing/2026-10-07-m10-r13-report.md`。

M10-R12 继续使用 `m10/3` 数据布局，在 R11 后应用 `m10_r12_patch.py`：舌尖与舌背的构造间距考虑相对高度，抬高的舌尖可后缩；舌叶可下压，切线求解使用可行的辅助点，实际曲线保留下压控制点。后卷时选择上后方圆切线，防止负角绕回整圆；末端与舌腹向前绕过舌叶，避免自交。口底、硬腭与牙齿的原生约束继续生效，再统一计算表面、中线、截面及声管。这些是当前参数模型的构形修正，不等同于卷舌音的自然听辨验证。

`geometry_bridge.cpp` 是实际桥接源码，增加手动舌根及前部侧缘实际拟合。拟合强度随 TS3 从 -0.15 至 -1.0 增大，后部不变，前部中央最多抬高 0.08 cm，左右最外缘最多降低 0.60 cm，然后重新计算中线与截面。默认启用，`p3_lateral_fit(0)` 仅供基准对照。

`M10-geometric-readout.patch` 对原版 `VocalTract.h/cpp` 新增默认关闭的 geometric 参数。仅 `p3_profile` 的显示读数启用 1e-6 cm 阈值，避免窄缝被原生 0.1/0.01 cm 显示过滤抹去；默认的声学管道计算阈值不变。该变化与实际侧缘拟合分别记录。

M10-R11 新增 `m10_r11_patch.py`，按明确上下文修改原生构造约束：舌尖前部边界延续至口外，舌背仍用原边界；舌叶以椭圆切线可行性替代原 45° 构造锥。TTX 上限为 7.5 cm，TBX 为 6.5 cm。这些数值是该参数模型的工作范围，不是人体普适生理极限。

`p4_larynx` 设置独立声门高低偏移，范围 −1 至 1 cm，默认 0。桥接对喉部下方三排表面平滑变形，保留舌骨及会厌附着点，计算半表面和镜像显示表面使用同一组变形前锚点。变形后刷新上/下壁、舌面轮廓及快速相交缓存，再重算中线、截面、声管与传递函数。`p2_update` 对完全没有有效开放采样的截面取消经验补面积，真正的侧通路保留。声学求解器仍保留 0.0001 cm² 数值下限。

小舌接触约束对原生 UVULA_TWOSIDE 与舌背三角形的 x/z 投影重叠区域求最大竖向侵入量，整体抬起 UVULA 和其双侧表面，保持其形状与尺寸。软腭附着行 9–12 按权重过渡到固定的第 13 行，舌体保持原位。之后统一重算轮廓、截面和声学几何。`p4_uvula_contact()` 导出本次止抵量，快照字段为 `uvula_contact_lift`。显示重建保留舌背原三角形对角线，小舌直接细分原生多边形边，避免显示与计算表面偏离。

项目中的 `scripts/build_m10_geometry.py` 从原压缩包提取必要源文件，逐处断言匹配后应用几何读数补丁和 R11 适配，用已有 MSVC x64 工具链编译桥接。不要直接套用旧原型构建命令。完整目录重建步骤见 README.md；这些修改继续适用 GPL-3.0-or-later。当前二进制摘要以 `../bundle-manifest.json` 为准，R11 的源码及有限验证见 `docs/testing/2026-10-06-m10-r11-report.md`。
