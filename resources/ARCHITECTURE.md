# 版本化资源、字典、字体、图标、原生组件清单 · 组件架构

D0.3 / 2026-09-09 / 实现提案。上级约束见 [总架构](../ARCHITECTURE.md)。

## 职责与依赖
版本化资源、字典、字体、图标、原生组件清单。允许依赖：来源明确且经过发行审查的资源文件。禁止依赖或行为：完整第三方仓库、个人研究语料、环境缓存、未知来源可执行文件、把当前下载 HEAD 当实际使用版本。

## 目标代码位置
brand/；fonts/；dictionaries/；native/<platform>/<arch>/；resource-manifest.json

这些是待实现的文件/目录，不是本轮已完成的业务代码。必须按主计划逐任务建立，不能创建空实现让导入测试假通过。

## 输入、输出和边界
输入来自版本化 contracts 或本组件明确定义的配置；输出为同一协议可理解的结果、错误、状态和可归属的资源。跨边界错误需含机器可读 code 与用户可理解 message，不暴露完整服务器路径或个人语料。

K2 主图在 16/32/48/256 像素验证辨识；ICO/ICNS 按平台生成。VTL 与 REAPER 记录 ABI、编译选项和实际依赖。PDF 默认外链，不以下载全文作为资产完整性的条件。

## 实施与验证
文件 hash/许可/架构检查；离线加载；包内资源存在性；来源登记双向检查。

测试状态与实现状态分别记录。涉及科研参数时附源版本、参数和数值差异；涉及界面时附浅深色/空态/错误态；涉及文件写入时覆盖失败、取消、额度和清理。组件未通过自身验收不得只靠上层 UI 掩盖问题。
