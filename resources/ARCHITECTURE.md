# 资源架构

共用边界见[总架构](../ARCHITECTURE.md)，修改约束见[本目录规则](AGENTS.md)。本页说明结构，不记录逐次验收。

| 位置 | 职责 |
| --- | --- |
| `manifests/` | 模块资源和分发身份清单。 |
| `vocal_tract/` | 声道模型、原生组件、可重建来源与许可。 |
| `m05/` | 唇形模块所需模型、浏览器资源和回退组件。 |

资源由 manifest 定位，记录路径、版本、SHA 和来源。依赖同名不表示同字节，裁剪必须沿真实调用链核查。授权范围决定软件分发与公开仓库边界，不能将研究语料混入程序资源。其余静态图标/字体位置以实际清单为准。
