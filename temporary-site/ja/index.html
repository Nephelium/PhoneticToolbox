01 / こちらの声から、あちらの声へ

音にも、グラデーション。

〰

同じ母音を含む、基本周波数の異なる二つの SCSC 録音です。元音声を聴いてから、それらをもとに作った発声様式と基本周波数の九段階連続体を聴き比べてみてください。

この音声はどう作ったの？

九段階の音声は、発声様式と基本周波数を同時に変化させてアプリから出力したものです。基本周波数は Praat / Parselmouth で 40–300 Hz の範囲を解析し、周期エネルギーと出力振幅のマッチングを有効にしています。元音声の F0 中央値は約 128 Hz と 94 Hz、処理後の各段階の F0 中央値は順に約 127、122、118、112、106、102、100、97、94 Hz です。

九段階は処理比率を表しており、知覚上の違いが等間隔とは限りません。第 1・9 段階も処理結果なので、上の元音声と比較できます。

A FEW SMALL QUESTIONS

よくある疑問を、
ここで解決。

?
01ポータブル版とインストーラー、どちらを選ぶ？+

使えるツールは同じです。ポータブル版は取得後すぐに起動でき、インストーラーは設定とショートカット作成を案内します。現在は Windows 10 1809 以降と Windows 11 向けの x64 版を提供しています。

02ウェブ版は今使える？+

ウェブ版は公開ベータテスト中です。トップページの「ウェブ版を開く」からアクセスできます。このページでは機能紹介、音声実験の試聴、デスクトップ版のダウンロードも利用できます。

03録音や研究資料は自動でアップロードされる？+

デスクトップ版はローカルで処理し、ファイルを自動アップロードしません。フィードバック送信、部品のダウンロード、論文資料へのアクセス時には通信します。添付前に個人情報などを確認してください。

04MFA に別のコンポーネントが必要なのはなぜ？+

MFA の実行環境、音響モデル、発音辞書は独立したコンポーネントです。初回は MFA 強制アラインメントの「コンポーネントのインストールと環境検査」を開き、案内に従って取得するか、ダウンロード済みのパッケージを選んでください。

05自動アラインメント後も手作業で確認する？+

はい。MFA は音声と既存テキストを対応づけますが、自動境界の確認は必要です。TextGrid アノテーションで、波形とスペクトログラムを見ながら調整できます。

06各ツールの操作とパラメータはどこで調べる？+

アプリ左下に全体のユーザーガイドがあり、各ツールの右上にも「ヘルプ」と「手法と引用」があります。該当章を確認して、資料に合わせて設定してください。

今回の更新では中国語・英語・日本語のインターフェースを追加し、分析、待ち行列、ファイル管理に関する問題をまとめて修正しました。

音響分析

  • 重要：Intensity の基準値を修正しました。 基準音圧を 20 μPa に変更しました。同じ入力と分析窓では、エネルギーがゼロでないフレームの値が旧版より約 5.0309 dB低くなります。デジタル無音は欠損値になり、過去の結果は引き続き読み込めます。新旧の結果を比較する際は計算バージョンを確認し、同じバージョンでの再分析をおすすめします。（追記：通常の録音の振幅は音圧校正されていないため、Intensity の値を実際の音圧レベルとして直接扱うことはできません。音圧レベルの計算には、マイクの詳細な特性と話者の唇からマイクまでの距離が必要です。）
  • 重要：無効な補正値が有効な結果に混ざらなくなりました。 Iseli 補正に無効な帯域幅などが入力された場合は欠損値を返し、未完了の補正をゼロ補正として扱うことを防ぎます。
  • 低サンプリング周波数の音声で分析が失敗する問題を修正しました。 8 kHz などの録音では、測定可能な帯域を超える高周波パラメータを欠損値とし、残りの測定可能なパラメータは引き続き計算します。

  • インポートしたコピーを整理する任意の設定を追加しました。 初期状態では無効です。ツールボックスのキャッシュ内の参照されていないコピーだけを対象にし、実行中タスク、待機中バッチ、保持している結果とその依存ファイルは残します。元のフォルダーにある原本は削除しません。
  • キャッシュの繰り返し書き込みと無効な記録の蓄積を減らしました。 新規注釈の保存中にプロセスが異常終了するとロックが残り、再保存を妨げる問題も修正しました。所有元を確認できない旧版のロックは残します。

Web 版とその他の修正

スペクトログラムから音声へ
モデルを学習中✦

スペクトログラムから音声を再構成する精度を高めるため、小さなモデルを学習しています。画像と時間・周波数の校正情報から、作成時の STFT 窓長とダイナミックレンジを推定し、その値をもとに再構成設定を調整します。

位相の再構成では、青木（Naofumi Aoki）による短窓スペクトログラムの研究を参考にしています。周波数方向に和を取り、時間投影のピークからパルスを抽出して励振信号を作り、その位相を Griffin–Lim の初期値に使います。反復には Perraudin らのモメンタム加速も用い、隣り合う反復間の変化を生かして位相推定を目標へ近づけます。現在のモメンタム係数は 0.99 で、通常は収束を速められます。

初期波形から Mel スペクトログラムを求め、目標 Mel スペクトログラムを参照して条件付き NAFNet を学習し、再構成で生じるスペクトルのずれを修復します。ぼやけや歪みを減らし、自然音声に近い構造を目指しています。修復後は学習済み BigVGAN ボコーダーが最終波形を生成します。既に学習した音声の規則性を利用する段階で、雑音低減やエコー除去と似た考え方です。

この比較はどう作ったの？

五つの経路は同じ画像、時間・周波数校正、Hann 窓を使用します。GL の設定はすべて フレームシフト 1.5 ms、反復 32 回です。以下の順に処理を一つずつ加えます。

  1. 基本 GL：固定の 10 ms の窓長、60 dB のダイナミックレンジ、ランダム位相初期化、モメンタム 0。
  2. モメンタム GL：第一経路の設定とランダム位相の初期値を保ち、モメンタムだけを 0.99。
  3. 推定パラメータ＋モメンタム GL：モメンタム 0.99 とランダム位相を保持し、モデルの推定窓長・ダイナミックレンジを使います。窓長は整数ミリ秒に四捨五入します。
  4. 推定パラメータ＋青木初期化＋モメンタム GL：第三経路の推定値とモメンタム 0.99を保ち、 青木パルス初期化。
  5. Mel 修復とボコーダー：第四経路から出力した同一の音声を直接読み込み、 80 帯域 NAFNet による Mel 修復と BigVGAN ボコーダー。

最初の三経路は固定済みの音声を保持し、再生時には五つを同じ RMS レベルに減衰します。ポップアップは実際の出力音声のスペクトログラムを表示し、10 ms Hann 窓、1.5 ms フレームシフト、60 dB の表示ダイナミックレンジを共通に使います。同じ例では周波数範囲と振幅基準も共通です。ボタンに重ねると、対応するスペクトログラムを強調します。窓長とダイナミックレンジはモデルの推定値です。再構成結果を交互に聴いて比べられます。
