# 官网维护约定

继承根目录规则。首页内容维护 `scripts/build_website_expansion.py`，运行后检查生成幂等；CSS、JS按各自维护源修改。

## 六图试听的基础 GL 对照

- “原始 GL”固定为基础 GL：10 ms Hann 窗、60 dB（−60～0 dB）幅度映射、固定随机种子20261015、随机相位初始化、32次迭代、momentum=0。沿用冻结的时间/频率标定、16 kHz/512 FFT/24样本帧移，试听为24 kHz PCM16。
- 禁用青木/Aoki脉冲或自动相位策略、动量加速、参数预测、Mel修复、声码器、去噪及其他重建优化。不得根据听感、损失或最新模型自动更换、重算或挑选处理前音频。
- `assets/spectrogram-examples/basic-gl-baseline.json`锁定六段音频及输入图SHA-256。页面构建、音频导入和发布前运行 `python -B -X utf8 scripts/website_audio_baseline.py`，不一致必须停止，不得重写摘要或绕过检查以通过验证。
- 更新处理后、模型、图标、文案、网页或部署时，处理前沿用原字节。试听响度只允许明确记录的衰减，不把波形处理混入基线。改变基线必须有井井对具体变更的最新明确授权，同时更新规则、来源、锁定清单及验收。
- 六图当前四路依次为原始GL、固定参数动量GL（0.99）、预测窗宽/dB的动量GL、同一预测动量GL接NAFNet与BigVGAN。前两路固定10ms/60dB，后两路使用stream-v5预测值，窗宽按整数毫秒四舍五入。四路均固定随机相位、seed20261015、hop24/16kHz和32次，禁用Aoki。第四路读取第三路实际导出的PCM，不另跑GL。参数权重7ac61f07、修复第6000步a60a3587与既有BigVGAN固定，四路锁在four-way-baseline.json，三路旧锁/61旧WAV保留。常规构建只验证/复用，不自动生成；四路展示四按钮，不生成波形。
- 青木启发式脉冲初始化作为独立研究方向说明。研究项目的默认推理策略不覆盖本官网的固定对照规则。

2026-10-16井井明确将对照迭代次数由256改为32。使用独立32i文件名重建三路18段，256次历史文件保持原字节；只允许显式--migrate-to-32迁移一次，迁移后重新锁定，常规构建不得重新生成。

2026-10-16后续井井取消切回256，明确仍为32次并扩展到四路，恢复参数预测这一独立步骤。原始GL与固定参数动量GL沿用，新增预测GL及其声码器结果共12段，所有旧文件原字节保留。
