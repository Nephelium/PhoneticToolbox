# Windows 发行 — 工作规则

继承[根规则](../AGENTS.md)。构建与验收要求唯一维护在 [PACKAGING_RULES.md](PACKAGING_RULES.md)，入口见 [README](README.md)。

- 使用同一冻结源码与实际应用，不以旧候选的成功结果代替本次最终字节验收。科学环境真实随包并核对工程外绑定。
- 说明书执行基本可用性检查，内容可继续追加；不使用固定章节/素材数量或全书完稿门槛。
- 构建输出用新目录，成功后按根规则和 cleanup_old_builds.ps1 清理旧包；失败、占用目录、运行时及用户数据保留。
- 主入口从首次写入记录生命周期；`-PlanOnly` 可核对旧包候选与 incomplete 目录。清理回执列出失败/占用原因，处理方式见[产物生命周期](../docs/development/artifact-lifecycle.md)。
- 程序、对应源码、受限例音分别盘点；作者编辑器和私有审计不进普通应用包。设置、更新、安装及卸载不删除研究数据。
- 历史服务器上传授权不延伸到当前任务。上传、公开发布和 Git push 各按当前明确授权执行；不保存连接凭据，不修改现存库 schema。
