# PhoneticToolbox 3.1.3

今回の更新では中国語・英語・日本語のインターフェースを追加し、分析、待ち行列、ファイル管理に関する問題をまとめて修正しました。

## 音響分析

- **重要：Intensity の基準値を修正しました。** 基準音圧を 20 μPa に変更しました。同じ入力と分析窓では、エネルギーがゼロでないフレームの値が旧版より約 **5.0309 dB**低くなります。デジタル無音は欠損値になり、過去の結果は引き続き読み込めます。新旧の結果を比較する際は計算バージョンを確認し、同じバージョンでの再分析をおすすめします。（追記：通常の録音の振幅は音圧校正されていないため、Intensity の値を実際の音圧レベルとして直接扱うことはできません。音圧レベルの計算には、マイクの詳細な特性と話者の唇からマイクまでの距離が必要です。）
- **重要：無効な補正値が有効な結果に混ざらなくなりました。** Iseli 補正に無効な帯域幅などが入力された場合は欠損値を返し、未完了の補正をゼロ補正として扱うことを防ぎます。
- **低サンプリング周波数の音声で分析が失敗する問題を修正しました。** 8 kHz などの録音では、測定可能な帯域を超える高周波パラメータを欠損値とし、残りの測定可能なパラメータは引き続き計算します。


## インターフェースと説明書

- **重要：中国語・英語・日本語のインターフェースを追加しました。** ホーム画面と設定で言語を切り替えられ、選択は保存されます。英語・日本語のオフライン説明書は個別にダウンロードしてインポートできます。標準では中国語の説明書が付属します。
- **ファイル読み込み中の画面の停止を軽減しました。** フォルダーの走査、ファイルの読み込み、TextGrid の解析をバックグラウンドで実行します。
- **一部の操作・表示の問題を修正しました。** EGG パラメータの保存失敗、PDF の全画面表示を終了した後のウィンドウ状態、言語切り替え後に更新されない一部のメッセージなどが対象です。

## タスクとファイル管理

- **重要：タスク履歴が増えると新しいタスクを送信できなくなる問題を修正しました。** 終了済みのタスクは実行中タスクの枠を消費しません。待機時間と実際の実行時間を分けて計算し、開始前に実行時間の上限を使い切ることを防ぎます。
- **バックグラウンドタスクの復旧を改善しました。** 異常なタスク、ワーカープロセスの予期しない終了、非常に大きなバッチのスナップショットに対応し、後続タスクが待ち行列に止まり続ける状況を減らします。
- **インポートしたコピーを整理する任意の設定を追加しました。** 初期状態では無効です。ツールボックスのキャッシュ内の参照されていないコピーだけを対象にし、実行中タスク、待機中バッチ、保持している結果とその依存ファイルは残します。元のフォルダーにある原本は削除しません。
- **キャッシュの繰り返し書き込みと無効な記録の蓄積を減らしました。** 新規注釈の保存中にプロセスが異常終了するとロックが残り、再保存を妨げる問題も修正しました。所有元を確認できない旧版のロックは残します。

## Web 版とその他の修正

- **複数ユーザー利用時のファイル読み書きを改善しました。** 異なるアカウントの通常のファイル操作を並行処理し、上限のあるプールでデータベース接続を再利用します。大きなファイルの転送と対話的なリクエストは別に処理します。ダウンロードでは引き続き各チャンクで本人確認と有効期限の確認を行います。
- **ログインとプレビューの問題を修正しました。** 特定のユーザー名への繰り返しログイン試行による誤ったロックを減らし、ログイン成功後のカウンターの異常を修正しました。別のユーザーが EGG プレビューを開いても、既存のセッションを直接終了させなくなりました。
- **待機と終了時の処理を改善しました。** タイムアウトの案内、子プロセスの終了処理、保守タスクの異常からの復旧を追加しました。更新インストーラーが長時間応答しない場合はエラーを表示します。ページが非表示になると、フィードバックの会話の定期更新を一時停止します。

今回の更新は Windows 版と Web 版が対象です。Mac 版の新しいインストーラーはまだありません（まだ Mac サーバーを借りていなくて……Mac はだいたい二回の更新に一回くらいになりそうです。皆さんごめんなさい）。ほかにも問題があれば、ツールボックス内のフィードバックから韶子に教えてくださいね~
