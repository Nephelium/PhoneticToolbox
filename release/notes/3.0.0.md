## v3 到底升级了些什么呀？

### 工具们终于住到一起了

v2 里各有各的窗口和入口，v3 把它们整理成了共同的侧栏和标签页。配色、字体、页面缩放、文件操作和说明书也统一了。打开几个模块比较结果时，操作方式更一致，切换起来也更顺手。

波形、语谱图、参数轨迹和 TextGrid 在相应工具中共用时间位置。定位到一小段语音以后，就可以围着这一段看信号、核对标签和读数值啦。

### 从录音到实验，多走几步也有地方落脚

- **录音有了独立的工作台。** 可以自由录音，也可以按任务清单逐条录制，剪辑、调节增益、降噪，再导出 WAV。任务和录音工程可以保存，继续录的时候再接着做。
- **TextGrid 标注接到统一工作台了。** 音频、标注层和唇形曲线可以一起查看，编辑边界和文字，保存后再交给下一步分析。
- **MFA 自动标注有了组件安装和环境检查。** 准备好音频与转写，就可以做强制对齐，结果接着在 TextGrid 工具里人工复核。
- **感知实验也回到了工作台。** X、AX、ABX、AXB 范式都能设计，支持刺激关联、试次洗牌、问卷、反应键、暂停恢复，以及结果导出。

韶子想要的就是：材料准备好了，就顺着自己的研究流程往下走。少在几个互不认识的小工具之间搬来搬去，2333。

### 合成和变调，可以边改边看结果

参数估计、参数显示、EGG 和 LPC 保留在同一个分析流程里。合成这边也有声学参数、生理参数和发声类型几条路线，可以按需要编辑参数或制作刺激。

变速变调可以直接编辑 F0、导入基频序列，也可以批量生成，查看原音、合成波形和实际输出的 F0 对比。语谱图转音频支持图片重建、图片涂鸦，以及在音频频谱中绘制信息。声道工作台则可以调整构形、编排关键帧、生成声音和动作视频。

**想做连续统、想改一条调型、想看看一张频谱能变成什么声音，都有对应的操作入口。** 具体参数和方法来源可以在模块的帮助与引用里查到。

### 音标和方言字表，也一起收拾好了

**国际音标表Plus** 可以查看 IPA、扩展国际音标和 VoQS，查符号、听例音、组合音标，再把内容导出。汉字转国际音标支持字音同显、声调与排版设置，多音字可以逐个选择读音。

音系归纳按导入、调类、声韵整理、结果预览逐步操作，可以调整分类与顺序、搜索记录，生成两种排列的同音字表 DOCX 和二维声韵表 XLSX。字表一长，能直接在结果里找字就很有用了……（盯着几千行表格缓缓失去眼神.jpg

## 下载哪个呀？

目前提供 **Windows 10 1809 及以上 / Windows 11 的 x64 版本**。在下面的 Assets 下载，或者去[官方网站](https://www.phonetictoolbox.com/)。

| 想怎么用 | 下载这个 |
| --- | --- |
| 装好后日常使用 | `PhoneticToolbox-3.0.0-windows-x64-setup.exe` |
| 放到自己的目录，双击就跑 | `PhoneticToolbox-windows-x64.exe` |
| 解压使用，或获取更新用的完整包 | `PhoneticToolbox-3.0.0-windows-x64-portable.zip` |

三个下载包各约 497–499 MB。第一次打开会准备运行文件，请给展开后的程序留些磁盘空间。安装版按当前用户安装，装好后从开始菜单或桌面快捷方式打开就好啦。

**MFA 组件单独安装。** 应用里提供 MFA 3.3.8-r1 Windows x64 CPU 组件下载，也支持同版 ZIP 离线安装，附默认普通话模型和发音词典。组件下载约 813 MB，安装后约 2.81 GB，解压过程还需要临时空间。

这一版还处理了科学运行库在中文及较长路径下的加载问题，更新检查也能识别历史 v2 发布。安装、更新时保留研究文件、设置和已安装的 MFA 组件。
