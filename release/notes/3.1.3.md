# PhoneticToolbox 3.1.3

这次更新补上了中、英、日三语界面，然后也集中修了一批分析、排队和文件管理的问题。。

## 声学分析

- **重点：修正 Intensity 的参考值。** 参考声压改为 20 μPa。在相同输入和分析窗口下，非零能量帧的数值比旧版降低约 **5.0309 dB**。数字静音改为缺失值，历史结果仍可读取。比较新旧结果时，请留意计算版本，建议统一版本重新分析。（p.s.普通录音的幅度通常没有经过声压标定，Intensity 数值不能直接当作实际声压级。如果要计算声压级，需要知道麦克风的详细参数以及发音人唇部距离麦克风的距离）
- **重点：无效校正不再混入有效数值。** Iseli 校正遇到无效带宽等输入时，返回缺失值，避免把未完成的校正当作零校正。
- **修复低采样率音频分析失败。** 8 kHz 等低采样率录音中，超出可测频段的高频参数记为缺失值，其余可测参数继续计算。


## 界面与使用说明

- **重点：新增中、英、日三语界面。** 可以在主页和设置中切换语言，并保存选择。英语、日语离线说明书支持单独下载导入，默认随应用附带中文说明书。
- **减少读文件时的界面卡顿。** 目录扫描、文件读取和 TextGrid 解析改为后台处理。
- **修复部分操作和显示问题。** 包括 EGG 参数保存失败、PDF 退出全屏后窗口状态不正确，以及部分提示切换语言后没有同步更新。

## 任务与文件管理

- **重点：修复任务越用越多后无法继续提交的问题。** 已结束的历史任务不再占用活动任务名额；排队等待与实际运行时间分开计算，避免任务还没开始就耗尽运行预算。
- **改善后台任务恢复。** 处理异常任务、后台工作进程意外退出和超大批次快照，减少后续任务一直停在队列中的情况。
- **新增可选的导入副本清理。** 该选项默认关闭，仅处理工具箱缓存中的无引用复制件，保留活动任务、待处理批次、仍保留的结果及其依赖文件，不删除来源目录里的原文件。
- **减少缓存反复写盘和无效记录积累。** 同时修复新建标注保存锁在进程崩溃后残留、阻止再次保存的问题。旧版无法确认归属的锁仍会保留。

## 网页版与其他修复

- **改善多人使用时的文件读写。** 不同账户的普通文件操作可以并行处理，数据库连接有界复用；大文件传输与交互请求分开安排。下载仍逐块检查身份和有效期。
- **修复登录与预览问题。** 减少针对某个用户名反复尝试登录造成的误锁，修复成功登录后的计数异常；其他用户打开 EGG 预览时，不再直接挤掉已有会话。
- **完善等待与退出处理。** 补充超时提示、子进程收尾和维护任务异常恢复；更新安装器长时间无响应时明确报错。页面隐藏后，反馈对话暂停定时刷新。

本次更新面向 Windows 版和网页版。Mac 版暂不提供新的安装包（还没租Mac服务器……Mac大概每两个版本更新一次叭，sorry各位）。大家在使用中如果还遇到问题，欢迎通过工具箱里的问题反馈告诉韶子~
