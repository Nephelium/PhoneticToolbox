# PhoneticToolbox 3.1.1

- **语言地图交互优化**：减少鼠标移动、拖动和缩放时的重复计算，双图、四图对照也能复用底图与样式。
- **地图支持全屏**：单图、双图和四图都可以全屏查看，按 Esc 退出，保留原来的地图位置和缩放。
- **底图与多级边界**：底色只保留一层，自动模式随缩放切换省、市、县，手动选择优先。可同时显示省、市、县轮廓，分别以粗、中、细线区分。
- **地图导出选项**：SVG、PNG 可选择分类图例、比例尺、地名及多级边界，地名可仅显示已选点。默认带比例尺、不带图例和地名，边界沿用当前页面。
- 清除筛选后恢复全部调查点，地图上方显示正在生效的筛选；修复语言现象类别影响方言相似性的情况。
- 修复地图下方表格滚动时正文与表头重叠的问题。
- 地图来源小窗、鼠标悬停的地名提示框和比例尺增加不透明背景，开启背景图片时也能清楚阅读；导出图片中的比例尺同步调整。
- 方言分布增加点颜色说明：彩色小点表示当前层级的单一分类，蓝灰色大点表示同一地点兼有多类。
- 网页切到后台时，暂停容量、服务器负载、文件列表和反馈未读数的定时查询，返回页面后刷新，减少重复请求。
- 国际音标表修正一处笔误：将 n̠ʲ̊ 改为 n̠̊ʲ，让清化圈标在 n 上方，显示与点击输入同步修正。
