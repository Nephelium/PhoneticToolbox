# PhoneticToolbox 3.1.3

This update adds Chinese, English and Japanese interfaces, and fixes a batch of analysis, queueing and file-management issues.

## Acoustic analysis

- **Key change: corrected the Intensity reference value.** The reference sound pressure is now 20 μPa. For the same input and analysis window, nonzero-energy frames are approximately **5.0309 dB**lower than before. Digital silence now produces a missing value; historical results remain readable. Check the calculation version when comparing old and new results, and preferably reanalyse them with one version. (P.S. Ordinary recordings usually have no sound-pressure calibration, so Intensity values cannot directly be treated as actual sound pressure levels. Calculating sound pressure levels requires detailed microphone parameters and the distance between the speaker’s lips and the microphone.)
- **Key change: invalid corrections no longer enter valid results.** Iseli correction now returns a missing value for invalid bandwidths and similar inputs, so an unsuccessful correction is not treated as a zero correction.
- **Fixed analysis failures with low sample rates.** For recordings at 8 kHz and other low sample rates, high-frequency parameters outside the measurable range are marked missing; the remaining measurable parameters are still calculated.


## Interface and documentation

- **Key change: Chinese, English and Japanese interfaces.** Switch languages on the home page or in settings; your choice is saved. English and Japanese offline manuals can be downloaded and imported separately. The Chinese manual is included by default.
- **Less interface freezing while reading files.** Directory scanning, file reading and TextGrid parsing now run in the background.
- **Fixed several controls and display issues.** These include EGG parameters failing to save, an incorrect window state after leaving PDF full screen, and messages that did not update after switching languages.

## Tasks and file management

- **Key change: fixed new submissions being blocked as task history grew.** Finished tasks no longer consume active-task slots. Queueing time and actual running time are counted separately, so a task does not exhaust its runtime budget before it starts.
- **Improved background-task recovery.** Handles abnormal tasks, unexpected worker exits and very large batch snapshots, reducing cases where subsequent tasks remain stuck in the queue.
- **Added optional cleanup of imported copies.** Disabled by default. It only removes unreferenced copies in the toolbox cache, retaining active tasks, pending batches, retained results and their dependencies. Original files in source directories are never deleted.
- **Reduced repeated cache writes and accumulation of invalid records.** Also fixed locks left behind after a process crashes while saving a new annotation, which could block later saves. Older locks whose ownership cannot be established are retained.

## Web version and other fixes

- **Improved file access for multiple users.** Ordinary file operations for different accounts can run concurrently; database connections are reused within a bounded pool. Large transfers are scheduled separately from interactive requests. Downloads still check identity and expiry for each chunk.
- **Fixed login and preview issues.** Reduced unintended lockouts caused by repeated attempts against one username, and fixed counters after successful login. Opening an EGG preview for another user no longer directly evicts an existing session.
- **Improved waiting and shutdown handling.** Added timeout messages, child-process cleanup and recovery from maintenance-task errors. The update installer reports an error if it remains unresponsive for too long. Feedback conversations pause periodic refreshes while the page is hidden.

This update is for Windows and the web version. There is no new Mac installer yet (I haven’t rented a Mac server… Mac releases will probably come every two versions; sorry, everyone). If you run into any other problems, please let Shaozi know through the toolbox’s feedback feature~
