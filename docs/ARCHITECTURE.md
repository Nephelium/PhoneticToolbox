# 文档架构

共用边界见[总架构](../ARCHITECTURE.md)，修改约束见[本目录规则](AGENTS.md)。本页说明结构，不记录逐次验收。

| 位置 | 职责 |
| --- | --- |
| `requirements.md、design/、specs/` | 用户需求、视觉标准和数据/流程规范。 |
| `project-status.md` | 当前已实现部分、验证边界与后续清单。 |
| `plans/、modules/` | 任务台账、实施计划及迁移基线。 |
| `decisions/、testing/` | 独立设计取舍与限定范围的验证证据。 |
| `development/、deployment/、references/、baseline/` | 开发/运维入口、来源审计与只读历史基准。 |

导航统一在[README](README.md)。当前规范按主题原位更新，历史计划/报告保留其证据边界，默认阅读只进入当前任务相关材料。历史目录只按需检索，临时日志、私有审计及可再生数据放忽略目录。说明书正式内容在 manual/，本目录 docs/manual/ 保留既有 Markdown 操作材料，当前可编辑正文权威源为 manual/chapters/。正式说明书的保留安排见根规则，不将旧材料当作当前实现状态。
