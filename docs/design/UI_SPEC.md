# UI 与交互规范

现行主题、字体、布局与组件规则按主题维护。早期设计图仅供视觉参考，不用示例数字或旧截图证明功能。接口细节见[公共布局契约](module-layout-contract.md)，科研行为见[模块入口](../modules/module-migration.md)。

## 视觉与主题

- 使用紧凑工作台、浅/深主题、侧栏和标签页。装饰集中在品牌与空态，科研图保持清晰的轴、单位和图例；避免卡片层层嵌套、巨大留白和假数据。
- 配色定义在 frontend/src/design/themes.ts 与 tokens.css，默认 Codex，浅深与跟随系统偏好独立保存。保留用户选择，不在文档复制一套易过期的色值表。
- 状态、选区、禁用及强调文字分别检查对比度，不能只靠颜色传达含义。曲线保留科学语义配色和图例，深色模式逐项设计，不能简单反相。
- 波形支持默认蓝色、跟随主题及自定义 HEX，独立 waveform 令牌只控制音频/录音波形，其他曲线不被覆盖。M10 接同一主题桥，导图按明确选择应用颜色。
- 按钮默认按重要性高亮，另有全部高亮/全部普通、阴影与悬停光效偏好。效果不改变尺寸或位置，关闭后保留焦点/选择状态，尊重减少动态效果。

## 字体与导出

- 默认中文宋体、英文/数字 Times New Roman、代码 JetBrains Mono，IPA 固定随包 Doulos SIL，不提供替换音标字体的选项。已保存的显式选择优先；系统字体缺失须提示回退，不能擅自打包其字体文件。
- 中文、英文/数字、代码/等宽、IPA 分角色。图表与导出默认继承，可独立配置中英文字体与字号；普通数字优先等宽数字，英文设置不覆盖音标字段。
- 候选字体按渲染端实际可用性呈现，预览、应用、取消和恢复默认可用；改变字体保留草稿、选区和任务，偏好跨启动保存。原生系统对话框和窗口装饰遵循平台能力。
- 所有图与导出消费公共配置，字体就绪后测量排版并验证实际 PNG/SVG。SVG 可编辑文本说明跨设备依赖，固定字形策略单独验证。
- 整幅图刻度、音标、图例、分区标签统一基础字号，总标题不超过 1.2 倍。300 dpi 只换算像素尺寸，不额外放大某一区域；旧 SVG 属性不能覆盖所选字号。
- 后台导出绑定提交时快照，不读其他用户或后改偏好；精确解析失败返回 font_unavailable，不静默换字体。显示变化不改变音频、参数、时间、CSV 或旧产物。
- 科学曲线导出白底、中性色文字、居中小标题，去除重复操作说明和界面按钮，保留曲线身份、坐标、单位、色标及标注。多行同域图的时间范围与绘图区边界对齐；音标表、截图和视频不强套曲线图模板。

## 工作台与模块布局

- 首页为默认页，仅展示真实最近记录，不自动分析样例或发声。模块名称由标签显示，内容区不重复大标题、副说明、Mxx 眉题和关闭按钮；关闭仍有保存/放弃/取消及失败恢复。
- 导航侧栏可拖动，展开/收起按钮带明确提示，收起时隐藏搜索。分组和模块来自公共注册表，不在规范中冻结旧模块数量；设置、说明书使用唯一标签，关于、更新和方法引用使用公共入口。
- 页面缩放在外观设置中控制 70%–150% 并可恢复 100%，本机记忆。Ctrl+滚轮禁止触发整页默认缩放，仍交给图表；弹窗按缩放后视口限制大小，首尾操作可见。
- 内容顺序为紧凑操作行、资源/绘图/参数区、任务与结果。目录/导入/刷新放相关工具组，帮助与方法引用使用页内公共入口，保存紧邻被保存对象，不改变文件或科研语义。
- 已接 unified 布局的模块左右侧栏默认各 300 CSS px，用户宽度优先。当前公共基准：控件高 30 px、模块内边距 10 px、区块间距 8 px、控件间距 6 px；普通工具栏按钮至少 88 px，侧栏长文字可换行。
- 三栏侧框等高、内部独立滚动，单侧参数栏靠左；M03 左侧参数/试听/任务、右侧四图及总览。M10/M17 的专用结构不强套统一列数，M12 保留图窗优先，M13 窄窗可横向滚动，不能靠压小字号隐藏内容。
- 侧栏边界共用 resizablePanels，支持指针和键盘，按模块/账号保存逻辑宽度；窗口临时缩小不覆盖偏好，保存失败反馈。宽度属于 UI 偏好，不进入科学配置。
- 分析/合成/重建按钮靠近相应参数/结果，图窗导出靠近图窗，M12 的 TextGrid 保存、M16 的工程/采集编辑、M15 的工程组和 M13 的即时转换保留各自对象关系。
- EGG 保留 v2 四图及总览的位置关系，见[布局参照](m03-v2-layout.md)，同时从第一版使用公共主题、字体、控件和播放；旧 Qt 图仅作行为/位置基准。

## 交互与状态

- 文件选择、播放、波形/选区、参数、任务、错误、结果与确认框复用公共组件。波形使用真实时间，选中与批量范围分别说明，不能在多模块同时播放。
- 常规页面覆盖 empty/loading/ready/running/succeeded/failed，按能力补取消、排队、满额、到期和离线。缺文件、算法不可用、设备未授权、无有效有声段分别表达。
- 当前任务显示提交时配置，编辑可作为下次草稿。错误给恢复入口且保留已有结果，取消只作用于本任务，未完成批次清楚标 incomplete。
- 方法与引用按 module_id 展示实际来源，学术与软件分组，学术在前；保留搜索、作者、关系、版本、许可和引用复制，来源分类由登记生成。
- 网页才提供账号、空间与到期界面，本机研究不受其登录/额度干扰。空间显示实际 used/reserved，删除成功再释放占用，到期显示时区，下载 ZIP 同样预算；下载不续期，也不强迫先下载再删除。

## 窗口与可访问性

普通滚轮滚内容，二维科学图 Ctrl+滚轮缩放，三维模型保留自身手势。主区有溢出滚动兜底，弹窗正文可滚。桌面初始 1440×900、最小 800×500 逻辑像素，适配实际屏幕；声道页保持最小可读高度与外层滚动，不压扁图形。

按影响检查常用窗口、DPI、页面比例、大字号、浅深主题、Tab 焦点、非输入焦点下 Space 播放及 Esc 取消。长表/大波形按需绘制，减少动态效果，既有编辑和科学数据在切换中保持。WCAG AA 对比度须实际核查，截图不能代替无障碍或实体设备证据。

图标使用既有品牌源生成平台尺寸，保留来源原件。安装界面与应用同一品牌，安装/卸载明确位置和选项，研究数据的清理由用户单独选择。
