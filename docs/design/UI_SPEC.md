### 2.1 全局字体与图像导出（P04-FONT）

2026-09-12井井确认将全应用中文、英文及导出字体配置纳入公共规范。随后井井明确全部IPA用Doulos SIL，并授权接入已完成模块。当前Windows开发态已接通公共设置、M01/M02/M09/M10及M03后台字体快照，限定证据与未测范围见[实施报告](../testing/p04-fonts-report.md)。详细边界、分步接入和F01–F12验收见[字体设计计划](../plans/2026-09-12-global-fonts-design.md)。既有P04与模块验收不自动包含此新增功能。

- 设置入口为工作台设置中的外观/字体。中文、英文与数字、代码/等宽文字、IPA分为四种角色，统一控制所有应用自绘页面、控件、表格、弹层与图表。系统原生文件选择框及窗口装饰遵循系统能力，不承诺覆盖其字体。
- 图表与图像导出默认跟随全局字体，可独立设置中文、英文及字号。IPA固定为Doulos SIL，设置中只读显示。英文和数字角色不覆盖语义明确的音标字段，普通中英混排保留缺字回退。代码字体只控制代码/等宽文字，普通数值表优先等宽数字特性。
- 宋体、楷体、思源宋体、Times New Roman、Consolas、JetBrains Mono、Cascadia Code作为候选名称，按当前渲染端实际可用性呈现。此名单不表示已安装、已随包或已核准再分发。缺失或无法确认时标明状态、提供回退，不静默显示已生效。
- 通过预览按钮预览中文、英文、数字、IPA、代码和图表标签，支持应用、取消及恢复默认。应用后更新已打开页面与图表，保留未保存编辑、选区和任务状态，偏好跨启动保存。
- 所有图中文字和导出路径消费同一字体配置，禁止模块硬编码另一套字体。字体加载完成后再测量排版与导出，分别校验实际PNG和SVG。SVG可编辑文字模式必须说明跨设备字体依赖，便携外观需要明确的字形固定策略与验证。
- 整幅导出中，刻度、音标、图例和分区标签使用同一基础字号，总标题最多为基础字号的1.2倍。从计算样式获取字号，禁止SVG旧属性覆盖用户字号。300dpi只换算像素尺寸，不额外放大某一分区。大小字号都必须实际导出检查。
- 字体变化只影响呈现及重新生成的图片，不改变音频、时间、参数值、CSV数据或已有产物。后台导出使用提交时的字体快照，不读取其他用户或后续更改的偏好。本机所选字体不可用时拒绝应用。后台精确解析失败返回font_unavailable，不静默替代；服务器提交前可用性预检随M03页面接入，目前尚未提供。记录实际渲染配置。
- 后续模块从第一版接入公共字体规则；已有模块纳入专项回归。字体改变后的浅深主题、缩放、窄窗、图例、坐标轴、中文与IPA无裁切/错位属于退出门，不能仅检查设置下拉框。

## 3. 全局布局
- **2026-09-26 现行模块框架要求：** 取消模块内容区独立的大标题/副说明/Mxx 眉题行，以及“关闭模块”按钮。保留工作台顶部模块标签和标签关闭入口。此条覆盖下方及旧模块规格中的“页面标题栏”摆放建议，原科学功能不删除。2026-09-29 P04-RESIZE 补齐 M02、M10 与公共占位页面，限定证据见[报告](../testing/p04-resize-report.md)，不扩大其他模块的算法验收。
- 2026-09-14 页面缩放统一在设置的外观区域提供 70%–150% 按钮及恢复 100%，本机记忆。阻止 Ctrl＋滚轮触发整页默认缩放，事件仍交给图表自己的缩放处理。公共弹窗需按缩放后的可用视口限制尺寸，标题、关闭及底部操作保持可见。
- 导航侧栏默认 224 px，可拖动调整为 184–360 px，收起约 56–64 px；顶部有品牌、折叠按钮。搜索仅在展开时显示，手动折叠及窄窗口自动折叠均隐藏搜索框。
- 分组固定：分析与采集、合成与操控、标注与实验；保留 15 个明确模块入口。
- 首页是启动默认页；首次启动仅首页标签，无样例文件自动分析、无自动播放、无虚构最近使用。
- 标签页标题唯一、可切换；模块状态独立保留。关闭有未保存编辑时提示保存/放弃/取消，不能强行覆盖。
- 底部常驻设置、使用说明、检查更新、关于。2026-09-19 按井井要求移除独立主题入口，浅色、深色与跟随系统统一在设置中切换，偏好跨启动保存。
- 2026-09-29 设置、使用说明使用唯一工作台标签，切换保留编辑。设置的字体应用失败不得关闭标签或丢弃编辑；主题、页面缩放仍即时保存。检查更新、关于、方法引用继续使用公共弹层。
- 网页登录后增加账号与存储入口；显示已用/预留空间和最近到期。桌面没有网页配额和强制登录。
- 浏览器页面不画假的 Windows 最小化/关闭按钮。桌面标题栏使用真实系统行为，macOS 保留平台窗口习惯。

### 3.1 模块公共布局与控件迁移（2026-09-26，planned）

内容区采用相同顺序：紧凑操作工具栏 → 资源/绘图区/参数区（按模块需要选用）→ 任务与结果。没有数据时使用统一空态，耗时、错误和可恢复操作采用同一组件。图窗内部仍保留必要的轨道名称、轴/单位和科学图例。

| 原位置/功能 | 新位置与约束 |
| --- | --- |
| 模块大标题、副说明、Mxx 眉题 | 从内容区移除，名称由标签显示；辅助说明入当前模块帮助；保留无障碍可访问名称 |
| 关闭模块 | 移除页面独立按钮；只保留工作台标签关闭，不改变未保存提示/写入失败处理 |
| 方法与引用/方法与来源 | 当前模块统一工具菜单，固定语义与位置，打开现有按 module_id 过滤的 MethodReferences；不删除致谢能力 |
| 保存参数草稿/绘图配置 | 参数区或配置工具组，清楚表示保存对象与未保存状态 |
| 选择目录、刷新、声道交换、批量分析 | 公共工具栏或关联资源组，顺序一致；EGG 原页首里的操作必须迁移 |
| 保存 TextGrid、分析/重建、导出结果 | 紧邻编辑/参数/结果区域，保留原目标、确认与文件语义 |

公共实现候选为 ModuleFrame、ModuleToolbar、ModuleSection，命名由 UI 负责人冻结；模块不得另建同义公共壳。内容内边距建议统一 12 px，区块间距 12 px，控件组间距 8 px，工具栏控件沿用 32–36 px。普通控件 14 px、辅助信息至少 12 px、区块标题 14 px/加粗，均通过公共角色令牌，图表使用既有 figure-size，IPA 用 Doulos SIL。移除大标题不代表取消图表/导出标题的科学要求。

不强制全部页面同列数：M01/M02 可资源-图-参数，M03 保留四图，M12 保留 R6 图窗优先。列宽与折叠按公共断点/最小绘图区约束，小窗可滚动，禁止按钮被挤出可访问范围。保留单一播放器和任务生命周期，避免页面与壳各生成一套操作。

2026-09-29：所有现有侧栏及工作台导航栏接入同一 `resizablePanels` 边界拖动控制器，M10 同源 iframe 复用它。分隔边界提供鼠标、触控指针和键盘语义，浅深主题沿用公共令牌，取消独立宽度滑块。逻辑像素宽度按模块/账号存入本机 ProjectStore，不混入科研参数或未保存状态；临时窗口收缩不覆盖偏好。拖动放开自动保存，失败显式提示。M01 默认左右 220/250 px，M02 默认 220/260 px；保留各模块原有小窗堆叠/横向滚动规则。实际触屏设备和 Linux GUI 尚待专项，不将指针接口支持等同设备实测。

验收覆盖各模块浅深主题、70/100/150% 页面大小、常用系统 DPI、空态/有数据/运行/错误、中文/IPA、大字号与窄窗口，另测关闭取消/保存成功/保存失败、切换模块/主题不丢编辑。先用真实 M01/M03/M04/M09/M12 展示前后效果，再按任务归属推广。

## 6. 页面状态与信息优先级
每个页面至少覆盖 empty/loading/ready/running/succeeded/failed；有取消的页面覆盖 cancelling/cancelled；Web 增加 queued/quota_exceeded/expired/offline。
“缺文件”“算法不可用”“用户未授权摄像头”“无有效有声段”分别表达，不统一成“未知错误”。
运行期间参数可编辑为下一任务草稿，但当前任务始终显示其原参数快照；避免结果配置混淆。
错误有解决入口，不自动抹掉此前成功结果。取消只影响本任务，批次不完成时 manifest 标 incomplete。
语料名单、配置、曲线与结果从真实数据读取。示意截图标“示例”，不得混入实际验收报告。

## 7. 15 模块的页面保留
逐页功能、控件、特殊语义见 [模块迁移规格](../modules/module-migration.md)。原 D0.1 的 83 功能组和 197 验收项继续作为基础，不以新导航概念删掉旧入口。

## 8. 登录、空间和到期的视觉
登录页延续蓝白/蓝灰面板，用 K2 小图标和明确标题；不把学术工具包装成广告落地页。
账号空间页按输入/结果/临时分类，支持按体积和到期时间排序、批量选择下载/删除。
空间满提示示例：“空间不足：已用 0.8 GB，本次预计需要 0.3 GB。清理至少 0.1 GB 后可继续。”实际数字来自服务器，计入预留空间，不能用预估当实际已用；新账号目标额度为 1 GB，运行时迁移见 P07-POLICY。
删除可直接进行，不要求先下载；删除进行中仍显示占用，完成后刷新。到期列表展示明确日期/时间和时区。
一键下载全批次要预估 ZIP 或采用流式打包，不因下载复制文件把磁盘撑满。
状态标签同时有文字和颜色；运行和满额不应让用户以为必须购买会员。

## 9. 窗口、响应和无障碍
普通滚轮滚动内容，二维科研图统一 Ctrl＋滚轮缩放。main 必须提供溢出滚动兜底，独立列滚动可以保留。弹窗正文滚动，首尾操作可见。桌面初始 1440×900、最小 800×500 逻辑像素，按屏幕可用区域减去边框余量限制；小窗口不以缩小字体或压扁图形解决溢出。声道三维交互独立保留，页内最小可读高度 640px，外层滚动兜底。
桌面主验收视窗：1280×800、1440×900、1920×1080；另验证 125%/150%/200% 缩放。小窗口收起次要面板或抽屉，不截掉确认/取消/播放。
宽屏保持文件栏、工作区、设置栏；窄屏设置进入抽屉，主图最小可读。网页桌面浏览器为首期主要研究场景，手机支持查看/下载与简单编辑，复杂多轨操作能力明确提示。
表格和长列表按需虚拟化；不要每次缩放重绘全部采样点。
焦点可见、Tab 顺序合理、Space 只在非输入焦点时控制播放、Esc 关闭当前可取消弹层。颜色对照度按 WCAG AA 核查，不能仅凭截图宣称达标。
尊重减少动画偏好；不做持续波形背景、装饰粒子或自动发声。

## 10. 图标与发行
K2 原始图保留不改；从它制作 ICO/ICNS/PNG 多尺寸版本。小尺寸简化波形线条，避免脸部糊成噪点；系统浅/深背景和任务栏实际验证。
安装向导同一品牌、简短文案，明确安装位置/快捷方式/启动选项。卸载默认保留用户数据；主动清除需单独明确选择。便携版和安装版版本号、核心与图标一致。

## P04 审阅补充：分组致谢与逐页验收

学术来源与软件来源独立分组，学术在前且默认打开；两组均保留搜索、模块筛选、作者、原关系类型、版本、许可与链接。科学软件的代码实现归软件组，其论文记录归学术组。分类由来源登记生成，不混用论文和代码的授权含义。

P04 的共同预览不冻结各模块最终布局。每个模块迁移时，以实际 v2 操作和 [功能矩阵](../modules/legacy-acceptance.csv) 建立“旧操作 → 新位置 → 行为/结果证据”的逐项对照；密集控件可分组或折叠，但必须可发现、可操作，不得删功能来适配模板。每完成一页即审阅浅深主题与真实科研操作，不推迟到全部页面结束后统一调整。
