2026-09-12，井井明确要求排版布局尽量贴合v2、功能囊括v2，随后强调v3统一UI规范与可复用组件必须同时遵守。**v2决定功能完整性和主要位置关系，v3 UI_SPEC及实际公共组件决定视觉与共同交互。统一风格从页面第一版落实，不在最后补做。** 此要求覆盖早期将全部设置迁至右侧的概括设计。状态：设计约束 documented，v3页面 planned。

依据：说明书3.1–3.4、原v2 `EGGWidget.init_ui`、M03-A原始Qt控件离屏实测。离屏截图用于核实相对位置，不作为完整v2应用主题、字体或设备显示验收。捕获器仅为离屏字体回退读取现有Windows微软雅黑，不安装字体、不改原源码。

## 必须保留的位置关系

| 位置 | 内容 | 联动 |
| --- | --- | --- |
| 顶部工具栏 | 打开WAV、交换声道、批处理、帮助 | 当前文件、声道角色和分析状态可见 |
| 左上 | CQ/SQ双纵轴 | 与左下共享主ROI与定位线 |
| 左下 | 语谱图、顶部色条、两类F0叠加 | 保留谱窗、dB范围和独立F0开关 |
| 右上 | 音频微观波形 | 与右下共享微观中心和毫秒窗口 |
| 右下 | EGG微观波形及GCI/GOI | 图上方保留原始/滤波切换及高通滑条 |
| 图下第一参数行 | 起点、时长、微观缩放、更新、播放、停止、保存、声门移动、逆滤波及阶数 | 不把常用操作藏入设置抽屉 |
| 图下第二参数行 | 峰门限、自动、谷门限、谱窗、Praat F0、GCI F0、GCI/GOI方法、谱图dB上下限 | 字段完整，方法分别可调 |
| 最下方 | 60秒总览、ROI色块、长文件导航 | 总览、主ROI、微观窗口分别持有时间状态 |

单文件初始GCI斜率、GOI尺度，微观50ms，范围10–200ms；总览60秒，主ROI初始0–0.5秒。原声门移动功能保留，但标明F0变化启发式。

## 可自主优化的范围

- 使用U2共同侧栏/标签页、完整浅深主题和共享播放能力，保留EGG内部的上述位置关系。
- 优化间距、字级、对齐、键盘输入、长文件名、错误和重算状态。参数可在窄窗顺序换行，不能依赖横向裁切才能操作。
- 窄屏可按主分析组和微观组纵向排列，但同组图与相关控制保持相邻。桌面常用宽度优先保持两列四图。
- 批处理和逆滤波对比作为共同工作台内独立子视图，保留完整选项与输出，不再创建独立网页宿主。
- 对导出文件名、冲突保护、部分失败提示作明确改进，不能静默改变算法、单位、阈值、时间网格或缺失规则。

已读取[UI_SPEC](UI_SPEC.md)、frontend规则、tokens及下列实际源码。公共规范中列出的目标组件并非都已实现，此表只把现存文件标为可复用。

| EGG部分 | 现存实现 | 使用与适配边界 |
| --- | --- | --- |
| 外壳、导航、标签、主题切换 | `frontend/src/app/AppShell.vue` | 在现有模块注册处接入EGG页，延用标签草稿和关闭流程 |
| 字体、色彩、按钮、表单、间距与焦点 | `frontend/src/design/tokens.css` | 复用实际CSS变量和全局控件规则，按钮/输入当前由CSS统一，并非已有独立Button组件；不复制v2 Qt样式 |
| 图标 | `frontend/src/components/AppIcon.vue` | 与其他模块同一图标来源、尺寸、语义 |
| 选区、播放、停止、音量、快捷键 | `frontend/src/components/AudioTransport.vue`、`frontend/src/state/audio.ts`、`frontend/src/state/workspace.ts` | 承接EGG音频角色与归一化音频；旧起点+时长与公共起点+终点之间显式适配，唯一播放状态，不能另造播放器 |
| 波形和时间交互 | `frontend/src/components/WaveformViewport.vue`、`frontend/src/platform/wav.ts` | 共用时间状态、选区和采样包络工具；EGG微观事件叠加与总览/ROI/微观三层需要适配，不能只换标题即宣称满足 |

| 任务、取消、重试、错误 | `frontend/src/components/TaskPanel.vue` | 映射实际M03持久任务快照和进度，不另建视觉样式或假进度 |
| 弹层与焦点恢复 | `frontend/src/components/ModalDialog.vue` | 批处理/IF需要弹层时复用，沿用Esc、焦点与操作按钮规范 |
| 模块引用 | `frontend/src/components/MethodReferences.vue` | 使用moduleId=M03和共同来源清单，保留学术/软件分组 |
| 工作区分栏 | `frontend/src/components/WorkbenchColumns.vue` | 当前硬编码文件/主区/参数三栏，不能直接套成EGG四图。EGG四图使用模块组合层，必要的通用容器扩展先保留现有页面回归 |

`ParameterDrawer`是既有声学参数选择器，`SettingsDrawer`有现有设置语义，须核实适用字段后复用，不能把EGG常用两行参数机械塞入不相干的选择器。尚未独立实现的DirectoryOrAssetPicker、ResultBrowser等名称只代表规范目标，不能在交付中声称已直接使用。

页面内应只新增EGG独有的布局组合、CQ/SQ与GCI/GOI图层、参数绑定、批处理选项和IF结果编排。图表背景、坐标、网格、选区、文字、禁用和错误态从两主题取值；新增科学曲线颜色在公共tokens登记并带图例，不另起一套局部调色板。原v2的绿色帮助按钮、默认Qt控件和硬编码图线颜色不作为v3外观标准。

## 页面退出门

除[30项功能验收](../plans/2026-09-12-m03-implementation.md)外，页面第一版即同时与v3相邻模块比较主题、字号、控件高度、留白、图表和状态样式，与原v2比较四图和两行参数位置。优先核实UI_SPEC的1280×800、1440×900、1920×1080及125%/150%/200%，另覆盖1000宽和390窄窗、中文/IPA、空态、长文件名和焦点。独立Qt/Chrome真实交互后才能标页面verified；本文件与旧界面截图均不代表新页面已实现。不得先完成旧样式页面、再把统一风格留作收尾事项。
