# 浏览器研究文件本机保存验收

日期：2026-10-18。任务：`WEB-LOCAL-FILES`。井井明确授权实现、测试和直接同步服务器。决策见[ADR](../decisions/ADR-browser-local-research-files.md)。

## 实现范围

- `local-assets.ts` 保存账号/本机项目隔离的 IndexedDB Blob、SHA-256 和事务性工程指针。默认临时项目使用稳定的本机分组，服务器项目换号后仍能读取本机文件。
- `local-asset-transport.ts` 将既有文件接口接到本机存储。导入、标注、录音版本/恢复快照、浏览器任务与导出不上传。只有服务器计算/预览需要输入时才按引用上传，保留分块、幂等与摘要校验，有效副本复用，工作区更换或副本失效后重新准备。文件名和标签中的普通字符串不会触发上传。
- 公共研究端口、M11/M14/论文端口使用同一传输层。M07/M08在实际请求服务器操作时解析服务器输入ID，保持其原有结果关联。TextGrid 使用已有客户端解析器，参数表、LPC、音系等仍使用原科学核心。账号设置接口保持。
- 文件管理显示本机文件与服务器临时文件，可导出、确认移除及本机 ZIP 打包。容量说明明确仅计算服务器空间。本机文件不受服务器 TTL 清理，清理浏览器站点数据会移除本机库。

PDF 服务、原生参数提取、变速变调、长合成和视频转码等现有服务器计算继续使用原端口，本轮不新增科学算法。服务器结果在首次完整读取并校验后缓存本机。本机文件限于当前浏览器和设备，跨设备恢复的是账号设置。
