# M10-R11：生理参数、固定小舌接触与口鼻连续显示

2026-10-06。状态：**限定 Windows 源码及实际 Qt verified**。按井井最终取舍，正中观察中的软腭/小舌融入头部背景，选中时保留细边界和拖动点。小舌本体保持形状和尺寸，接触舌面时止抵，附着软腭负责过渡。原有 EXE 未重新打包。源码入口为 [Start-M10-Workbench.ps1](../../scripts/Start-M10-Workbench.ps1)。

## 交付行为

| 问题 | 最终实现 |
| --- | --- |
| 小舌下降穿入舌头 | 原生 UVULA 与舌背三角形求接触，整体抬起小舌至接触位置，保留其尺寸及舌体位置，再重算截面和声学管道。显示层保留原生小舌边及舌背三角形，避免显示与计算表面不同。 |
| 小舌忽大忽小 | 移除随腭咽开口裁窄小舌的操作，口鼻开口在背后空间中调整横向宽度。小舌本体刚性移动，硬腭连接处仍允许柔性过渡。剖面按用户要求使用头部背景，三维保留组织辨识颜色。 |
| 咽壁旁交叉、口鼻断裂 | 连续距离上的局部连接网格替换旧咽壁折返，网格焊接；小开口时明确保持前后对应关系，避免最近点匹配接反。二维从口腔正中连续过渡到鼻腔旁中线 5 mm，在同一网格上取参考截线，不再分别封口。 |
| 舌尖伸不出口、舌叶不跟手 | 延伸舌尖前部边界，移除门齿前方虚拟封墙；舌叶以椭圆/舌尖切线可行性替代过严构造锥。拖动从实际受限位置起算，减少反向拖动空行程。 |
| 声门只能随舌骨移动 | 独立声门偏移 −1 至 +1 cm，提供滑条和底端控制点。舌骨、会厌附着点固定，下部喉腔平滑变形，几何、截面、声管、传递函数及合成同步。 |
| 三维另一半仍可见 | 默认统一裁切头壳、组织、口腔/鼻腔气腔及连接体。勾选显示完整模型后才解除，同时隐藏剖面封盖。 |
| 接触与面积曲线不一致 | 实线显示同源几何截面积，虚线显示合成管道面积。全截面闭塞为 0，声学计算保留 0.0001 cm² 数值下限。正中接触而侧面有通路时保留非零面积，并明确提示。 |

TTX 上限 7.5 cm、TBX 上限 6.5 cm、声门偏移范围均为当前参数模型的工作范围，不代表人体普适极限。仍保留硬腭、牙齿、口底和后咽壁约束。

小舌止抵后，/a/、VO=1.5 cm² 的旧穿模闭塞消失，侧面保留真实通路，不能继续把该旧构形当作全截面闭塞证据。全闭塞回归改用真实唇部闭塞，侧通路回归使用 /l/。没有把所有正中接触强制画成面积 0。

## 实现和兼容

- [原生桥接](../../resources/vocal_tract/sources/geometry_bridge.cpp)、[上下文补丁](../../resources/vocal_tract/sources/m10_r11_patch.py)、[重建脚本](../../scripts/build_m10_geometry.py)：使用已锁定 VTL 2.4 源码和现有 MSVC x64。变形后刷新轮廓与相交缓存，再重算声学几何。`p4_uvula_contact` 导出止抵量，快照为 `uvula_contact_lift`。
- [显示解剖](../../frontend/public/vocal-tract/anatomy.mjs)、[表面接触](../../frontend/public/vocal-tract/surface-contact.mjs)、[连接网格](../../frontend/public/vocal-tract/geometry.mjs)：保持原生小舌及舌背接触面，重建软腭附着层和局部连接。中线软腭轮廓直接取同一网格的中间顶点列，避免退化截线产生内部封口线。
- 几何版本 `m10/3`，桌面 API 握手仍为 `m10/1`。独立 `larynx_height` 贯通姿势、实时合成、轨迹、撤销、构形、关键帧和交换文件。
- 本机构形库 `presets.json / version: 1` 与关键帧缓存 `version: 2` 继续兼容，缺失声门偏移按 0 读取，不迁移或覆盖用户历史文件。
- 交换文件在旧范围、零声门偏移时继续写 `version: 1 / VTL-2.4-JD2`；扩展舌位或非零声门偏移写 `version: 2 / VTL-2.4-JD2-M10-3`，拒绝旧标识下的扩展数据。
- 既有 `.venv/m09-ui` 仅同步 5 个 M10 核心 Python 文件及对应安装记录，原字节备份在 [runtime-before](../../output/validation/m10-r11/runtime-before/)，其余 66 个已安装核心文件摘要不变。[同步记录](../../output/validation/m10-r11/runtime-sync.json)。没有安装依赖。启动器明确使用当前核心和桌面源码。
- 模块开发说明、重建说明、3 条来源记录及 M10 资源摘要已同步。冻结说明书与 M10 待写正文不改。
