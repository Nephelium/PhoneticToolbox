# 生理参数合成：牙齿邻域、舌底衔接、常驻控制点与已存构型

2026-10-12，`M10-R19` 在 Windows 当前源码、前端构建及独立 Qt 范围内完成定向验证。未重新打包 EXE。

## 修改范围

- `frontend/public/vocal-tract/scene.js` 在牙齿刚性截面内独立重绘背景与头部底色。灰色牙齿区域不再仅依靠舌体和气腔遮罩留下空白，显示牙齿时仍使用原有牙齿颜色。原生牙齿、鼻腔模型、接触和声学计算均未修改。
- 后续扩大检查到牙齿外侧，发现采样气腔超出实际口腔边界，直接盖掉灰色组织。`sampledAirwayClip` 将前方填色限制在原生口腔轮廓内，鼻腔截面和后方连接单独保留。测试通过移除该裁切复现旧填色错误，再核对相同位置修复后的实际 Qt 像素。
- `floor-contact.mjs` 将下牙牙冠支撑按当前下颌位置向前延续，二维轮廓和三维舌底共用，消除越过牙齿前缘后下降的台阶。保护原生背侧面、固定口底附着和声学数据。定向测试改为要求前方连续支撑，并增加随颌位置、横向范围和三角面内部检查。
- 按最终澄清，二维 11 个正中控制点常驻，小舌、上下唇无需先选器官；平面图不显示侧缘。三维 14 个控制点常驻，侧缘也继续支持横截面调整。
- 默认改为 64 段、65 个采样截面，界面使用准确的截面数。旧自动保存的默认 129 首次转为 65，旧 65/257 选择保留；本版之后选择的 65/129/257 均按新偏好键持久化。核心引擎离线基准默认值未改，界面通过已有 pose 参数切换真实采样。
- `default-presets.json` 保存作者指定的 t、l 完整设置，n 按后续明确要求逐字段沿用 t。`app.js` 载入全部参数、局部舌形、唇宽、舌根模式、喉部高度、F0 与声源。其他内置起点保留原有行为。
- 按后续要求移除 s 的默认可选构形及本机 s 常用 ID。个人库没有独立的 s 记录，其他个人构形和常用项保留。底层 VTL 的 s 科研基准没有删除。
- `presets.js`、`index.html` 将入口及面板改为已存构型。`v3.css` 用是否已有构形决定明暗，与按钮是否可点击分开。保存面板中的暗色音标仍可保存，保存后在两种面板中点亮。
- 模块 README 与正式说明书操作正文同步，阅读资源及前端重新生成。

## 鼻腔截图问题

前一轮测试通过 `viewer.setOptions({nose:false})` 临时隐藏鼻腔以隔离牙齿检查，但保留了页面中已勾选的鼻腔开关。展示这张测试截图造成了鼻腔被删除的印象。产品鼻腔模型与正常开关逻辑并未删除。

最终测试全程开启鼻腔进行牙齿检查，截图前恢复完整标注，并断言勾选框、viewer 状态和鼻腔路径一致。另用实际鼻腔开关比较画面像素，检查二维、三维切换和舌尖连续编辑后仍显示鼻腔。
