# M06-R2 AV 修复与 F0 保形预设

2026-10-02。**本次授权范围 verified，限定 Windows 开发态和下述纯核心/合成输入证据。** 井井明确要求直接修复原错误，未实现旧错误算法切换。新配置为 m06/2，计算版本 klatt/2，任务传输仍 m06/1，不涉及数据库 schema。

## 用户要求与实现

- AV 默认 60，图轴/输入范围 0–80 dB。AV=0 关闭周期声源；新增 AH 气流噪声控制，范围同为 0–80，AH=0 关闭噪声源。AVS/AF=0 也真正关闭其源，普通增益的 0 dB 仍为单位增益。
- 修复噪声累加器为 one-zero FIR `x[n]+x[n-1]`；恢复前级 −60 dB；去掉经验式 `AH=130−HNR`，采用独立的数字声源参考校准。源参考、固定输出增益和最终防溢出衰减保存在结果元数据中。
- 去掉引擎峰值归一化、自动 RMS 增益、分段 RMS 拉齐及多次峰值归一化。最后仅在峰值超过 .95 时整体衰减并提示，正常情况下 AV 的振幅作用保留。Slope 不再在声源和频域重复施加。
- 内部采样率改为 20 kHz，覆盖最高 6 kHz 共振峰，避免旧 10 kHz 内部采样导致 F5 折叠；仍按配置采样率进行抗混叠重采样。
- 发声预设移除全部 F0 常数。假声将基础曲线按 Hz 整体上移，使时间加权平均值至少为 300 Hz；嘎裂整体下移至平均约 70 Hz，最低点以 20 Hz 为保护边界。宽起伏曲线可能无法同时满足低均值和最低点约束，此时只限制整体偏移，不逐点截平。
- 常态浊声、耳语、气声撤去偏移。平移后可直接编辑，编辑保留到回切后的基础曲线；重复应用同一类型不会叠加偏移。覆盖的 F0 常量在平移时转换为可编辑曲线。
- 纵轴通常保留，使曲线在图中直接上下移动；仅越界时扩展轴。偏移/类型、实际曲线随 CSV/JSON/草稿保存，真实任务使用图中数值。
- 生成元音保留 F0 及已应用的声源预设。分段覆盖的数值越界现在原子拒绝，避免生成已不可保存的半成品配置。

## 当前五类预设

| 类型 | AV | AH | Jitter % | SHR | H1–H2 | Slope | F0 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: | --- |
| 常态浊声 | 60 | 0 | .5 | 0 | 0 | −10 | 撤销偏移，保留基础曲线 |
| 耳语 | 0 | 40 | 0 | 0 | 0 | −10 | 同上，周期声源关闭，F0 曲线仍保留 |
| 气声 | 55 | 30 | 0 | 0 | 10 | −10 | 同上 |
| 嘎裂 | 60 | 0 | 3 | .8 | −10 | −10 | 整体下移，目标均值约 70 Hz |
| 假声 | 60 | 0 | 0 | 0 | 0 | −15 | 整体上移，目标均值至少 300 Hz |

所有预设 Shimmer=0、HNR 扩展处理=60（中性间隙增益）。HNR/H1–H2/Slope 是原项目扩展，不声称对应 Klatt 原生输入或保证输出测量值。五类预设是可编辑的合成起点，没有做生理模型或听辨分类验证。

## 标尺与来源边界

AV 的 0–80 范围和典型 60 依据 [Klatt 1980 原论文](https://doi.org/10.1121/1.383940) 表 I 与 p.987。本工具继续使用 MIT tdklatt 衍生的声源/谐振器，不冒称恢复了 Dennis Klatt 的全部原始实现。

绝对数字幅度没有通用的跨实现常数。`source_levels.py` 明确采用：60 dB 时，120 Hz、无扰动、默认声门极点/零点的稳态周期源 RMS=.01；噪声按单位高斯输入及 FIR 的理论 RMS 标定到同一 .01 参考。周期源参考由独立 LTI `lfilter` 计算，缓存固定参考，不归一化用户声音。正值每增加 20 dB 振幅乘 10，0 作为关闭特例。输出使用固定增益 64，此后仅做防溢出衰减。该标尺是可复现数字参考，与物理 SPL、不同 Klatt 实现的绝对输出分开。

提取阶段不再把录音能量直接写入 AV：有声帧相对能量以其中位数对应 AV60 初始化，裁入 1–80，无声帧 AV=0；AH 初始化为 0，用户可自行调整。它是编辑起点，尚无经验证的 AV/AH 逆估计。提取会清除预设 F0 偏移状态。

旧 m06/1 配置和不含新完整快照的 CSV 会明确拒绝，保留原文件/当前编辑；旧草稿保留存储并提示使用新默认配置。没有把 AV200 静默截成 80 或平移成 60。历史 WAV 不被重新计算或替换。
