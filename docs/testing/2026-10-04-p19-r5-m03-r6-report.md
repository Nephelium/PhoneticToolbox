## 全局时间精度与音频选区追加

- 秒输入最多 5 位小数，毫秒最多 2 位，不补零。覆盖公共播放/分析设置、EGG、标注、唇形偏移、参数显示、感知实验、发声/语音合成、拐点编辑、语谱重建以及 M10 原生关键帧输入。同期新增的联合 EGG 平滑与最大间隔框也接入毫秒规则。标注微调输入下限改为 0.01 ms，与两位小数一致。
- 原始科研数据、TextGrid、计算时间轴不由显示格式回写。程序填入 14.985544858 s 显示 14.98554 s，原状态仍为完整值。用户输入或粘贴过多小数时四舍五入，再送给原编辑事件。部分小数、清空、尾零及指数输入已定向覆盖。Hz、帧数、采样点及无量纲值保留原行为。
- 每个模块框架独立管理音频选区，重复视图视为同一份状态。多音频加载/生成不默认全选，用户拖动或编辑某条选区时清除其他选区。空格仅传给当前音频，再按停止。鼠标选择波形时转移焦点，避免旧按钮抢占空格。独立模块互不清除状态。
- M08 原音播放改用实际鼠标选区，原音/合成音目标随手势切换。计算和合成当前视野仍使用原可见范围，不因试听选区改变科研范围。EGG 持久结果中的可试听音频也接入同一选择方式，文件与任务结果不改写。
- 波形空态复用真实波形组件的图框、轴及控件。M07 F0、M08 编辑 F0、M06 预览及 M09 图像空态使用对应绘图区占位。公共科学图原本已有等高空态，保留该行为。M07 波形空态/有数据同为 456×192 CSS px，M08 波形同为 456×418.5，F0 同为 456×399.31。本次几何为 1600×1000 Chrome 合成单声道输入。
