# M06 说明书与例音修订验证

`M06-MANUAL` 为 `verified`，范围为当前源码说明书、实际 Qt 合成与原生导出、正式媒体及独立 Chrome 阅读播放。旧 a/i/u 文件字节各异，但三份合成快照的 F1–F3 都是默认的 500/1500/2500 Hz。旧素材制作只改变了输入序列，遗漏生成元音曲线，因此无法提供说明书所称的三元音对照。本次修复素材制作流程与说明，不改变算法、科学默认值或产品 UI。现存冻结 EXE 未更新。

## 正文与素材

对照当前 M06 页面、状态、平台适配、Klatt API、解析器及合成核心，复核本章操作、预算、预设、文件兼容、保存与旧结果归属。用户提供的 V2 临时 HTML 地址已不存在，改为只读参考工程内 `Phonetic_Export/index.html` 的同一锚点及完整章节，没有修改相邻 V2。

正文保留既有稳定 ID 与引用，明确输入序列后须等待生成元音成功，再等待合成成功，最后试听或导出。说明区分当前编辑配置、生成曲线与最后一次采用的合成结果，补充显式应用预设、参数单位、连续元音、停顿、时长权重与振幅淡化。模块 README、简版说明及 M06 目录和搜索索引同步。

实际 Qt 工作台重新制作常态 a/i/u 与气声 a，F0 控制值 150 Hz、0.8 秒、淡入/淡出 50/100 ms、平滑点数 5。每例显式应用预设、生成自己的曲线、合成并通过原生保存导出 WAV。

| IPA | F1 / Hz | F2 / Hz | F3 / Hz |
| --- | --- | --- | --- |
| a | 730 | 1090 | 2440 |
| i | 270 | 2290 | 3010 |
| u | 300 | 870 | 2240 |

以上为实际配置中的合成控制值。气声 a 使用相同 a 规则，另应用气声预设。保留四组 WAV/MP3 的既有资产 ID 和路径，替换两个对应 a 截图。WAV 为 16000 Hz、单声道 PCM16，各 12800 帧，数字样本均有限；三元音输出摘要与波形各异。原例频谱高度相近的量化记录在 `baseline-spectra.json`，修订后记录在 `corrected-spectra.json`。频谱距离不作为人类听辨证据。

### 复杂时长语法

新增实际输入 `a-i/- ///u+/e++o/-` 的图音。元音与内部空格初始权重为 1，`+ - * /` 按从左到右依次乘以 1.1、0.9、2、0.5。总时长 2 秒时：

| 段 | 权重 | 时长 / 秒 | 结束边界 / 秒 |
| --- | --- | --- | --- |
| a | 0.9 | 0.488467 | 0.488467 |
| i | 0.45 | 0.244233 | 0.732700 |
| 空格静音 | 0.125 | 0.067843 | 0.800543 |
| u | 0.55 | 0.298507 | 1.099050 |
| e | 1.21 | 0.656716 | 1.755767 |
| o | 0.45 | 0.244233 | 2.000000 |

总权重 3.685，按未舍入权重分配总时长，表格显示舍入值。实际 Qt 配置的累计边界与计算值最大差约 `2.22e-16` 秒。V2 旧例中 i/o 的 0.4、空格的 0.175、e 的 1.2 已纠正为当前解析器的实际结果。截图选择 F1，展示共振峰轨迹、边界与静音底色，附 32000 帧的实际输出。

### 渐入渐出

新增 `a a`、总长 1 秒的两组波形与例音，对照 100/100 ms 和 30/80 ms，均显式应用常态浊声预设、F0 控制值 150 Hz。两段 a 与中间静音各约 1/3 秒，每组 WAV 为 16000 帧。

说明明确淡化单位为毫秒，采用半余弦振幅包络，作用于连续有声段两端。无静音的相邻元音不会逐元音重新淡化；时长超过段长时截到段长，重叠包络相乘。平滑点数控制重新生成的 F1–F3。只修改淡化数值可直接重新合成，无须重新生成元音。

数字抽查两组中间静音样本峰值均为 0。首段 10–25 ms 的 RMS 除以 120–220 ms 的 RMS，分别为 0.08118 和 0.58025，符合不同淡入设置的预期。该抽查是输出验证，未据此声称自然度或感知显著性。实际随机种子分别登记，未声称两组使用相同种子。

新素材登记在 `manual/assets/software-only/m06-examples/`，三组各含 PNG、WAV、MP3，共九个资产。MP3 为实际 WAV 的有损试听副本，登记原 WAV ID 和摘要。四组修订例音与三组新例音均验证 MP3 解码帧数一致，WAV 与解码 MP3 的样本相关系数大于 0.97。素材维持 `software-only` / `git: false`，未上传外部服务。
