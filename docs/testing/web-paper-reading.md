# 网页论文精读验收

2026-10-16。范围为当前源码、本机独立 PostgreSQL/HTTP/Qt PDF/Chrome，以及后续获准接续的既有 Linux 私有内测实例。正式网站、公开反馈服务、现存数据库 schema 和最终 EXE 未替换。

## 实现与操作对应

网页与桌面共用 `PaperReadingPage.vue` / `PdfReader.vue`。网页从 `ResearchFiles.papers` 注入同源端口，桌面继续使用 QWebChannel。`ptb_documents` 随 desktop Python 包提供共享目录许可校验、下载校验、个人库、QPdfDocument 渲染和 pypdf 标准注释导出。桌面原模块为兼容入口。

| 操作 | 网页实现 |
| --- | --- |
| 推荐、说明、往期、日期筛选、选择下载、删除恢复 | 原目录与内容摘要规则，当前项目受管缓存，原页面操作 |
| 原文、译文、解读 | 同一 Qt PDF 渲染实现，分页、选字、本页文字、连续阅读、缩放、全屏 |
| 收藏夹、个人 PDF 导入与移动 | 浏览器选择原文件，服务器临时论文库；同名拒绝覆盖，删除收藏夹保留内部文件 |
| PDF 删除与恢复 | 网页论文回收站，恢复原位置，保留按内容摘要绑定的批注 |
| 笔记、选文批注、荧光笔、编辑删除 | 同一校验与版本冲突规则，保存冲突保留编辑并提供重新载入 |
| 原件及含批注导出 | 同一 pypdf 实现，经现有鉴权下载接口交给浏览器保存 |
| 自动获取与间隔、引用 | 原页面设置和引用生成；网页定时任务随页面生命周期停止 |

网页文件选择、下载及回收站使用浏览器可提供的入口。服务器 PDF 副本与批注按当前工作区期限管理，桌面文件夹及离线缓存仍按原规则保存。网页单文件沿用当前上传上限 100 MB，桌面保持 200 MB。当前网页使用服务器阅读，不提供断网离线阅读。

## 资源与数据边界

- 无数据库 schema 迁移。论文状态、设置、批注和内容引用保存为既有私有配额资产，按项目及账号鉴权；批注保存采用快照 CAS，跨进程冲突拒绝覆盖。
- 下载、导出与新状态预留空间，子进程内存上限 1 GB、单请求 180 秒、单实例一个论文处理槽；繁忙时明确返回并短时重试。渲染宽度、页数、像素、输出和路径继续受限。
- 临时解析目录在受管资产同卷，通过硬链接重用 PDF，不复制全部库。请求结束关闭本次子进程并清理目录；带实例/进程标记的崩溃遗留在服务维护时检查回收。活跃进程、其他实例及联接路径保留。
- 请求期间及发布前重查工作区和账号，退出/到期后不发布迟到结果。网络取消保留已经完整获取的 PDF，工作区失效仍优先阻止保存。
