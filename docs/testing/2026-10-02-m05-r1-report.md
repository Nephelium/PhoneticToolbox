## 实现及审查结果

| 问题 | 原因与修复 |
| --- | --- |
| 采集状态在右侧，参数离视频太远 | 状态及保存动作移入左栏。画面使用实际宽高比，去除视口高度留下的空白，九项数值按三列均匀分布。四条曲线为 area、outer_width、open、circularity，紧接画面；修复公共图标 CSS 将 SVG 高度压成 20 px，曲线保留独立纵轴和实际时间。 |
| 离线视频正常，网格动画很慢 | 原 `timeupdate` 事件低频，且动画使用曲线抽点。现在用视频逐帧回调，按实际 PTS 查找完整 `frames.jsonl`；90 帧一页，最多 3 页缓存，文件索引最多 8 份。曲线计算与播放帧状态分离。旧任务完整结果可直接读取，不需要重算。 |
| 停止后出现推理已停止，无法再次录制 | 忽略正常停止后的过期 Worker 异常，释放旧回调/计时器，重置收尾 Promise，按会话代次识别迟到响应。新增保存并开始下一次，取消保存保留原会话；设备断开明确标记不完整并收尾。 |
| 保存只有 WebM，音频不易找到 | 桌面统一保存 H.264/AAC MP4、独立 PCM16 WAV、候选与计时记录；回读检查视频帧数/PTS、音频流/采样数及文件哈希。内部浏览器采集采用 Opus，避免 Chromium 原生 AAC 的样本时间戳问题。无 MP4 能力的独立浏览器明确报能力限制。 |
| 浏览器音频时间戳有抖动 | 修复两个已量化 PTS 作差的舍入界限。录制导出显式使用 decoded_samples 时钟，保留每个解码样本，另记 PTS 残差；不以包抖动补静音或删除样本。任意外部视频的正式分析保留 container_pts 审计策略。后续对新录制的正式分析使用已核对的保存 MP4，输入来源可追溯。 |
| 保存偏移未被下游读取 | 偏移原先只写 `aligned.lip.json`。现在自动关联的 `audio_recording.lip.json` 含本次 offset，原始内容保留为 `unaligned.lip.json`，另有保存清单与哈希。 |
| M02 无法直接显示保存的唇形 | M02 复用既有受控唇形解析器，直接提供 LipArea、LipWidth、LipOpen、LipCirc；同名参数表优先，然后同名安全 JSON/V2 PKL。缺失值断线，排序、音频锚点、偏移和 M12 共用规则。 |
| 其他审查修复 | 第一份结果与历史切换正确加载完整帧；迟到帧不能覆盖新结果；重试读取失败可恢复；批量结果只保留当前曲线快照；保存失败释放上传会话且保留内存录制；正偏移前的画面不提前显示网格。 |

## 指定真实输入与音频

井井提供的视频仅只读使用，私有文件名不写入项目文档。原文件 SHA-256 为 `d947fe73fa18400ad890932d94dd7739c88f14119c42beda1d09526d821fbe40`，结束时复核一致。

- 167 个 VP9 视频帧，首尾 PTS 为 0 和 6.112 秒，按 `(帧数−1)/(末帧−首帧)` 得到约 27.1597 fps。采用实际变帧率时间，未用标称 30 fps 代替。
- 原 WebM 已包含 48 kHz 双声道 Opus。解码得到 296,640 个采样帧（每声道 6.18 秒），首个解码音频 PTS 为 0.008 秒。因此原始媒体有音频，旧界面缺少直观的独立音频保存入口。
- 实际 MP4 转换保持全部 167 帧及 PTS，WAV 保留解码后的样本。MP4 视频/AAC 是有损转码，独立 WAV 是解码 PCM，不声称恢复录制编码前的无损信号。
- 正式 legacy FaceMesh 分析、完整结果保存、125 ms 偏移写入和下游回读通过。原输入和 V2 源码未修改。

## V2 与下游兼容证据

`scripts/prepare_m05_r1_compat.py` 只读提取原 V2 `lip_gui.py` 的 `_save_offline_recognition`，调用原保存函数生成 NumPy 数组、landmarks、时间戳与 metadata，再由既有受控本地解析器读取。原 V2 源文件哈希 `6656012fb4469466d3a41ec9eb36c139be63b6cf058906b8d3bcf6dd7e6fbc79`。验证材料由原保存器生成，未声称已遍历全部历史私人数据。

- M01：安全 JSON 与旧 NumPy PKL 共用现有时间轴及 LipArea/LipWidth/LipOpen/LipCirc 插值核心，125 ms 偏移只应用一次。本轮验证读取/插值链，没有另跑整套声学参数计算。
- M02：实际 Qt 打开配套 WAV，分别自动关联 `.lip.json` 和 `.pkl`，四参数可选择并画出曲线。
- M12：实际 Qt 完成配套 WAV/唇形读取，核对关联选项、125 ms 偏移，截图可见唇开/唇宽与声谱同轴。
- 浏览器候选仍标识不同模型，`candidate.lip.json` 需要显式选择。未通过与 legacy 的科学等价门，不把格式兼容解释为算法等价。
