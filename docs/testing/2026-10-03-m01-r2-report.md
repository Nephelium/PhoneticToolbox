# M01-R2 参数估计布局与新旧唇形关联

日期：2026-10-03。状态：verified，限定 Windows 开发态与以下证据。授权与验收范围见[计划](../plans/2026-10-03-m01-r2.md)。

## 本轮变更

- TextGrid 切分层、参数切分来源与保存操作整体移至最左侧栏分析设置下方。删除完整标签列表，保留图中标注与点击选区。
- M01 输出参数弹窗桌面采用四列，700px 窗口两列、480px 窗口一列。全部80项、搜索、全选/全不选、取消和草稿应用保留。其他模块未传列数时仍采用原列数。
- 删除中央关联说明与旧文件兼容区。唇形下拉同时支持新 `.lip.json` 与旧 `.pkl`，排除 `_timestamps.pkl`。
- 顶部关联唇形按钮选择独立唇形目录，为全列表匹配同名数据，与切分勾选无关。递归时按相对路径匹配，同名 JSON 优先于 PKL，多个同级候选提示逐条选择。未匹配项保留已有单条选择。单条改选或不关联在刷新后保留，再次批量关联可恢复成功匹配项。
- 本地提交旧 PKL 时，复用既有 Windows 有界转换子进程与本地 JSON 任务输入。原目录不生成转换文件，音频起点、伴随时间戳后备和手动偏移保留。没有修改科学算法或请求 schema。原显式转换平台能力仍保留供其他入口使用。
- 唇形关联歧义单独记录，不会清除 TextGrid 读取错误；唇形错误仅阻止声学分析，不阻止与唇形无关的音频切分。
