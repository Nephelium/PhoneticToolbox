# M03-R8：四图布局、微观范围与共用 F0 上下限

2026-10-10。状态：**verified，限定 Windows 源码工作台、实际科学子进程、独立 Chrome 和实际 Qt，以及下述定向检查**。本次未构建或验收冻结 EXE。

## 行为与兼容性

- 隐藏 CQ/SQ、归一化音频、滤波/原始 EGG 的辅助图例，以及实时语谱图顶部的 colorbar。空出的高度用于绘图区。开启 F0 后仍显示来源图例，静态语谱 PNG 仍保留色标。
- 自动 dB 与谱窗位于同一行，dB 下限/上限在下一行并列，原自动/手动色阶行为不变。
- 音频、EGG 微观标题显示总窗长（ms）。左侧 CQ/SQ、语谱/F0 显示以微观中心为轴的半透明范围矩形，范围为中心 ± 总窗长/2，超出图面部分裁剪。中心红线保留，右侧红线表示 0 ms。点击、拖动、滚轮和数值输入同步更新范围和标题。
- 左栏增加共用 F0 下限/上限，实际传入 Praat AC 与原生 REAPER。新配置仍为 30–800 Hz、10 ms 步长。两值须在 10–2000 Hz 内且下限小于上限。GCI F0、CQ/SQ、滤波、事件、波形和 PSD 不因这组参数而改变。
- 短会话改变范围时清除两种音频 F0 缓存，长会话按范围与视野区分缓存。改变范围不重新准备整段信号。单文件/完整录音任务、来源 JSON 和参数草稿保留实际范围。批次使用自己的配置，主页面范围不隐式带入。
- API 新字段允许缺省/null，历史 `legacy/1` 保留 75–600 Hz，`audio-f0/2` 保留 30–800 Hz。旧请求的规范哈希省略两个 null 字段，旧任务恢复时显示其有效范围。契约与 TypeScript 类型通过现有生成器更新。

改动限于 M03 模型/科学调用/会话缓存、前端参数与四图，以及共用绘图组件的可选图例和范围属性。共用组件默认行为保留。没有新增外部算法、依赖或素材授权。
