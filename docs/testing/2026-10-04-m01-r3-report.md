# M01-R3 独立关联目录与两种参数表保存

日期：2026-10-04。状态：verified，限定 Windows 开发态。授权与验收见[计划](../plans/2026-10-04-m01-r3-directories-exports.md)。

## 结果与边界

- 选择关联目录拆为选择TextGrid目录、选择唇形目录。两者初始跟随音频目录，选独立目录后显示名称，重置恢复默认。默认目录随音频目录变化；独立目录保留。取消不改变选择。
- 各类关联只在对应目录匹配，不混入另一个目录的同名文件，也不导入关联目录内的其他 WAV。接受目录后重新匹配该类关联；刷新保留逐条手动选择与不关联。关联唇形按钮使用当前目录重新匹配全列表，不再弹出目录选择。新 JSON 优先于旧 PKL 与相对路径匹配保留。
- M01 桌面保存与网页下载提供 XLSX、SQLite；TextGrid 切分另提供 WAV。不自动导出 JSON，不删除已有 JSON。内部任务三件套、来源与版本记录、最近同源结果查找继续保留，契约与科学算法未改。
- M01 同名不同内容改为名称末尾 `(2)` 等数字。整组参数表以及切分 WAV/参数表使用同一后缀；同内容重复保存复用，旧文件保持原样。仅 M01 改此规则，EGG/LPC 等其他模块仍沿用既有命名与保存。
- XLSX 与 SQLite 均从同一参数表生成。实际列名、时间、参数、标签与缺失值等价；Excel 序列化可能有浮点末位差异，核验容差沿用 `1e-12`。无穷值分别为 XLSX `inf`/`-inf` 与 SQLite 数值无穷。JSON 额外保留计算设置、输入哈希、实际后端、计算版本和非有限值状态，独立参数表不包含全部来源元数据。
