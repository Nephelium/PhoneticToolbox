# M06-R4 可选 WORLD / PSOLA 重合成

日期：2026-10-04。状态：**verified，限定 Windows 开发态与 WSL 纯核心**。自然语料听辨、物理音频设备、DPI、Linux 正式任务/GUI 和 EXE 均未验证。

井井要求按 [M06-R3 核查](../references/m06-r3-resynthesis-audit.md)实施。现已保留 Klatt，并加入 WORLD、Praat overlap-add（PSOLA）、Harvest F0、方法配置保存和四文件导出。GlottDNN 等声门模型保持 planned。源码入口：[Start-M06-Workbench.ps1](../../scripts/Start-M06-Workbench.ps1)；[使用说明](../manual/speech-synthesis.md)；[方法与边界](../decisions/ADR-M06-R4.md)。旧 EXE 未重打。

## 1. 已实现行为

| 内容 | 当前实现 |
| --- | --- |
| 方法切换 | 顶部 Klatt / WORLD / Praat PSOLA。Klatt 保留原 24 参数、AV/AH、元音与发声类型预设；切换自然路径时显示实际支持的控制量 |
| F0 | Praat CC、Praat AC、原生 REAPER、WORLD Harvest。默认 CC，不静默回退。每次重合成按当前设置重新分析原 WAV；更新编辑曲线需点击提取参数 |
| 默认保留音高 | 自然路径默认原 F0，编辑器与覆盖按钮只读。显式选编辑 F0 后才使用手绘/覆盖值 |
| WORLD | CheapTrick 全谱包络、D4C 非周期幅度比、原清浊掩码；可改 F0、统一时长比例、整体包络频率比例和非周期幅度比例 |
| PSOLA | Praat Manipulation 的源脉冲、替换目标 PitchTier 和 DurationTier。源脉冲独立估计，顶部选择 REAPER 不表示使用了 REAPER 脉冲 |
| 源/结果 | 源录音只读，保持采样率，输出单声道。结果与参数快照绑定，修改参数/源文件后旧结果明确标记，迟到结果不能覆盖新编辑 |
| 恢复草稿 | 保存方法、F0、控制量和源 SHA-256。重新关联同哈希原录音保留编辑曲线，任务仍校验实际源哈希；不匹配时拒绝 |
| 试听/保存 | 沿用横跨模块底部的共享播放条。桌面保存 WAV、JSON、CSV、NPZ 四件套；分析数据可单独下载；同名保存沿用既有防覆盖逻辑 |

自然路径只从原录音提取编辑所需 F0，并保留源时间/有声掩码。未将 WORLD 谱包络或噪声比伪装成 AH/HNR；Klatt 的其他经验映射保持 R3 行为。新计算版本为 `m06-world/1`、`m06-psola/1`，自然提取为 `m06-natural-extract/1`。旧 `m06/2` 文件缺 `render` 时在内存补 Klatt 默认，不改原文件；旧 `m06/1` 的 AV 标尺拒绝策略保留。

新路径不做幅度放大或峰值归一化，输出超过 0.99 才衰减，实际系数入元数据。自然路径输出 FLOAT32 WAV，Klatt 原 PCM16 保存链保持不变。Praat overlap-add 的随机数在隔离任务中单独设种子并记录，重复相同种子可复现 WAV。

Parselmouth 所含 Praat 会对 Manipulation 源信号减均值，可能令数字零暂停出现小幅常数残留。本轮只恢复原输入中至少 40 ms 的严格数字零区间，保留边缘 10 ms 及内侧 5 ms 渐变，按时长比例映射；不使用能量阈值抹除低幅语音。源均值和处理区间保存，详见 ADR，不能把它描述为未经处理的上游输出。

## 4. 失败与修正

- 最初 PSOLA 独立比较受 Praat 自身随机数影响，固定 NumPy 种子仍不一致。核对官方 Praat 接口后在隔离任务适配层增加 Praat 种子，精确比较通过，未通过放宽容差掩盖问题。
- 数字零暂停检查发现减均值残留，核查内嵌源码并增加上述严格零区间恢复，保留低幅语音与过渡。处理明确入元数据，未声称纯上游逐样本等价。
- 首次 Windows 环境没有 pip 模块，改用现有 uv 安装已核验 wheel；WSL Python 构建配置期望的 clang++ 不存在，改用已有 GCC/G++ 的单命令设置。未安装或切换系统编译器。
- Chrome 最初等待原生 option 可见，修正为存在等待。主题测试原先只改 DOM 属性会被全局外观状态覆盖，改由设置页切换并核查实际 CSS token；第一次错误查询不存在的 token 已修正。最终结果均来自修正后的真实主题检查。

## 5. 限制

输入仅为项目合成夹具与新增谐波/噪声/静音组合。未指定或读取用户自然录音及论文目录；未声称声音已更自然、嘎裂/气声识别可靠或实验感知等价。真实录音盲听和按不同发声类型评估仍待输入。

WORLD 输入 16–48 kHz；新路径 F0 范围/非零目标值 40–1000 Hz、时长比例 0.5–2、源/输出最多 10 秒和 480000 样本，WORLD 谱矩阵最多 1000000 个格点。范围检查会明确拒绝，不自动改采样率或换后端。这些是当前有界本机任务限制，不能据此声称可处理任意长录音。

保留 V2、用户数据、旧包、历史参数和工作树同期其他修改。未执行现存库 DDL、push、公开发布、删除用户文件或全局依赖安装；新增项目局部依赖已在第 2 节逐项列出。
