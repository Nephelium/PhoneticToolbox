# P18 跨模块布局验收

日期：2026-10-03。状态：`verified`，限定 Windows 开发源码、独立 headless Chrome 和下列实际检查。真实 Qt、真实音频与最终生产构建由同轮主代理集成报告单列。未重打 EXE。

## 最终视觉规范

M01–M09、M11–M16 默认侧栏统一为 300 CSS px。三栏左右外框贴齐工作区上下边界，内部卡片按内容高度排列，长表单在栏内滚动。两栏的单个操作栏在左，M03 参数、试听和任务整体移左，M13 上下排布时设置移左。M10、M17 未启用本轮统一布局。

顶部文件与刷新入口靠左，保存参数/编辑草稿、帮助与引用靠右。主要分析、合成、重建按钮位于右栏且占满当前区块宽度。沿用现有 30px 控件高度和 U2 色彩、字体；外框内边距 8px、区块内边距 10px，卡片间距 8px。图形的时间轴、比例、科学默认值及操作手势保持。

## 实施与回归修复

- 公共外观通过 `ModuleFrame/ModuleWorkbench unified` 显式选择，未以覆盖全应用 CSS 改造 M10/M17。自有 M12/M13/M16 布局使用同一默认宽度、主题边框和滚动规则。
- M03 历史记录同时包含 `--panel-left:250` 与 `--panel-right:350`，新左栏恢复实际旧右栏的 350px，键盘调到 360px 后重开仍360px。M03 原来共用 M01 key，本轮提供旧key首读回退和独立新key，旧 M01 值保持不变。只创建实际存在插槽的拖宽面板，旧“右栏收起”不再隐藏已迁入左栏的控件。
- M12 保留原拖宽下限180/210px，新默认300px不强制覆盖已有偏好。M16 保留既有localStorage拖宽逻辑。M13切换上下布局时分隔方向同步，历史保存变量仍保持。
- M11 Beam参数作为左栏独立区块，浏览器验证未展开环境版本详情也能看到唯一一个Beam输入，默认值10。避免把参数嵌入运行时详情或版本循环。
- M01 空态中心表面补齐高度，已加载波形组件本身高度未改变；主要分析按钮全宽。M14 生成与完整结果保存按钮也遵循全宽规则。
- 本轮70/150%矩阵暴露 ScientificPlot 同步 ResizeObserver 测量回写产生浏览器循环错误。改为合并到下一动画帧，卸载取消待执行帧；坐标公式与事件不变。修复后矩阵及单独图表测试没有pageerror或window error。
