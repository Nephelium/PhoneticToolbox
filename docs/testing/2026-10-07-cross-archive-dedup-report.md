## 发现的问题与处理

首候选 R1 的计算任务、依赖恢复已经通过，但 M05/M07 书稿中编辑器生成的可选 `id:null` 被生产阅读器拒绝。仅在生成阅读副本时省去空键，真实锚点、文字、作者文件和原媒体保留；随后 R2 的完整成品验收通过。旧验收写死 M08 三个例音，当前书稿已含九个，现改为本包实际引用与身份逐项核对。没有通过删断言或忽略缺文件取得通过。

早期启动脚本借用了旧 M13 专项验证，遇到旧的固定 240px 布局断言；该结果保留为失败诊断，未计入最终速度数据。后改为普通无参数启动、首页响应及实际转换操作，测量范围明确为隐藏软件渲染。原生 Qt 成品验证另行执行，未使用关闭 GPU 的结果代替原生窗口验证。

部分原媒体仍有原有 libpng profile/tRNS 警告，离屏测试存在 Qt 软件渲染相关日志，未隐藏。全库文档检查仍有 214 条历史链接错误，主要为旧归档 README 和按授权清理的旧包；本次新增规则与决定链接无错误，不声称全库文档全绿。
