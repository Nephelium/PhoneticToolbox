## 实现与边界

- 注册沿用账号、Argon2id、Cookie 和 CSRF。邮箱验证后创建账号，重发使旧链接失效，密码重置撤销旧登录。验证令牌只存摘要，注册链接30分钟、重置链接15分钟，一次有效。邮箱和实际请求来源共同限流，重复/未知账号使用统一回应。SMTP 复用独立适配器，测试只使用本机收件替身。
- `008_web_identity.sql` 新增邮箱与令牌表，`009_web_workspaces.sql` 新增临时工作区、项目绑定和数据库写入检查。仅在用户明确允许的全新临时 PostgreSQL 中执行，没有启动时自动 DDL。
- 同一登录 Cookie 的页面共享工作区。每30秒心跳，只用 PostgreSQL 时间续到1800秒；标签离开不发送删除指令。刷新恢复原工作区，其他设备使用独立登录会话。过期后先显示结束状态，用户明确开始新的工作区才重新创建。
- 退出事务关闭工作区、增加代数、取消任务/批次、撤销文件访问，清理器随后删除实体。读写、分块下载和结果发布都核对有效期。上传/最终确认/科学结果的到期时间不晚于工作区截止，下载和任务心跳不续期。数据库检查同时阻止旧执行器重新发布。
- 删除失败保留 `delete_failed` 和占用，重试成功后删除项目、文件、任务、事件及结果历史。无内容的工作区墓碑只保留到原登录会话失效；过期邮箱令牌和限流桶定期回收。API 内存中的 EGG 预览另由资源检查定时释放，不能在工作区结束后继续使用。
- `server.py` 和现有 P15 宿主增加显式开关，API/worker/cleaner 使用同一工作区策略。公开注册必须配合临时工作区。旧模式默认行为与桌面 LocalRetention 保持，旧研究项目不会被自动认领到新工作区。
- 使用同一 AppShell。网页 MFA 显示桌面下载入口，后端拒绝对齐提交及旧任务重试。M15 IndexedDB/会话锁和 M17 草稿按账号、项目区分；随机项目 ID 绑定工作区，桌面原键保持。旧无主本地记录不自动归入网页登录者。
