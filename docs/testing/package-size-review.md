本次删除的旧 packed/png-safe 是阅读生成目录的未引用残留。EXE 构建从正式阅读索引选择源素材，再在冻结快照中生成所需派生文件，部分派生文件可能与旧副本同名同字节。因此删除这些本机副本不会直接少打 158 MB，后续包仍须保留正文需要的媒体。
