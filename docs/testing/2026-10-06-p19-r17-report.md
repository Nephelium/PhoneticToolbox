# P19-R17 导航边框与页内帮助

2026-10-06。井井要求按截图恢复侧栏及标签选中样式，移除应用顶部模块使用说明，在每个模块页面内提供帮助。限定 Windows 源码、当前构建及本轮受影响界面为 verified；本轮未重打 EXE 或上传发行渠道。

## 最终变化

- 侧栏保留选中色块、单一边框及左侧 3 px 标记，去掉公共样式叠加的外置焦点框。顶部标签保留整体标签和底线，标签名称与关闭按钮不再各带阴影/焦点框。
- 导航样式不受普通按钮的全部高亮/全部普通模式覆盖。导航键盘焦点采用文字下划线，其他普通按钮、输入等控件保留原焦点提示。
- 删除 `AppShell` 顶部的模块使用说明入口。原九个模块的页内帮助沿用现有章节映射，缺少入口的 M01/M02/M04/M09/M12/M13/M16 补在方法与引用旁边。
- M10 在模型页右侧参数面板的操作行加入帮助，通过已有同源 iframe 消息检查跳转对应章节；浏览器不可用提示区也提供帮助。模型页两个相邻按钮高度相同，未新加应用级顶部工具条。
- 17 个模块页面均有一个可见帮助入口，打开对应说明书章节，返回按钮继续回到原模块。帮助没有触发文件导入、参数计算、录音或播放。
- 入门章节和权威工程索引中的旧顶部入口描述同步修正，重新严格校验并生成软件阅读资源。

本轮主要实现位于 `frontend/src/design/buttons.css`、`tokens.css`、`AppShell.vue`、八个缺入口模块页面及 M10 独立文档。没有修改科研算法、草稿键、数据协议、录音租约、实验专注状态限制或更新渠道。
