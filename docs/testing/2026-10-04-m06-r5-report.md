# M06-R5：移除重合成分支、音频选择与元音规则修复

2026-10-04。状态：**verified，限定 Windows 开发态与 WSL 纯核心**。井井要求删除本模块 WORLD/PSOLA，把音频选择移至左栏最上方并改为手动提取，随后追加元音规则紧凑化与复制修复。

入口：[Start-M06-Workbench.ps1](../../scripts/Start-M06-Workbench.ps1)。前端生产构建已更新，旧 EXE 未重打。当前操作见[使用说明](../manual/speech-synthesis.md)。

## 实现

- 删除 M06 WORLD/PSOLA 后端、对应任务动作、编辑设置、分析数组入口和专用依赖声明，同时移除依赖 WORLD 的 Harvest 选项。现在只有 Klatt，F0 可选 Praat CC、Praat AC、REAPER。独立变速变调模块的 PSOLA 未改。
- 删除已撤回功能的专用实现与测试文件，新增退役兼容检查。R4 报告/ADR/计划标为 Superseded，历史许可、来源和验证记录保留，已退役的四条 WORLD 来源不再出现在当前界面。
- 从 `.venv/m09-ui` 和既有 WSL `/home/ninfer/ptb-m06-20260927` 卸载 PyWORLD 0.3.5。卸载前核对实际安装路径，卸载后 `find_spec('pyworld') is None`。共享 Parselmouth、NumPy、SciPy 与 WSL 构建工具未改，无全局环境操作。
- 左侧首项为普通音频文件下拉框，顶部保留打开目录并补刷新文件。选择 WAV 仅解码原波形、启用试听，参数和总时长保持；源预览使用原音频时长。显式点击提取参数才运行原 `m06-extract/2` 并提供提取后的源语谱图。
- 未选择、正在读取、读取失败、清空选择时禁用提取按钮；重新选文件中止前次读取，并以独立序号丢弃迟到预览。目录刷新移除已消失/已变更的选择。参数提取、Klatt 合成和 AV/AH 科研公式保持原版本。
- 元音表单元格上下内边距改为 2 px，音标按钮最小高度 24 px。默认字号实际行高不超过 36 px。复制调用公共 `copyText`，桌面走已存在的 Qt 原生剪贴板接口，避开截图中的 WebEngine 权限错误；成功/失败在弹窗顶部显示。浏览器拒绝权限时提供可选择文本框，不再把原始权限异常写到右栏。

## 文件兼容与边界

配置仍为 `m06/2`，Klatt 计算为 `klatt/2`。R4 Klatt 快照的 `render` 字段在内存移除，其余参数继续读取；纯核心不改输入对象。包含已退役方法或 Harvest 的文件明确拒绝，不静默换算法。源文件、草稿及历史结果不删除，旧四文件结果清单仍可解析。当前新合成继续导出 WAV、JSON、CSV 三件套。
