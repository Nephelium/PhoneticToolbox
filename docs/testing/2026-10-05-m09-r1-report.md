## 完成内容

- 顶部顺序按井井最后指示调整为图片重建、图片涂鸦重建、音频藏信息。
- 原图与四点校正只留一个 h2 标题，空态展开、结果后折叠。结果明确显示整图或四点透视校正及输出尺寸。

- 共用任务历史、底部播放及四文件导出。输出 JSON 含完整原参数、四点、笔迹、方法、源哈希和增益。图像使用旧灰度映射，音频绘图使用幅值 20 log10 与 60 dB 显示范围，分别记录。

## 失败记录与边界

- 早期截图发现公共 tool-group 样式碰撞导致按钮撑高，已改为模块自己的类名；固定画布视口并加稳定滚动槽，修复 ResizeObserver 循环警告。最终 Chrome 无页面错误，Qt 各按钮高度小于 50 px。
- 大笔迹测试最初得到 503，根因为旧任务表 16 KiB 约束。完整笔迹文件化后，1500 点 HTTP 幂等/重试及 8192 点真实任务均通过，无放宽 DB 检查。
- 一次独立原生脚本误用相对 PYTHONPATH，子进程进入 scratch 后加载了已安装旧包，缺少新增 geometry 元数据而失败。换成绝对源码路径后五组全部通过，另提供专用源码启动器。该失败不计入通过证据。
- 测试使用合成音频与图片、已有测试 SQLite 的隔离副本，无现存库 schema 修改。实际 Qt 隐藏窗口、静音，不操作用户桌面截图或实体声卡。Qt 保留既有 PNG/GLES 初始化警告，没有把它们扩写为实体显示稳定性结论。
- 预览子进程当前仅实现 Windows 有界运行。Linux 预览直接返回平台未验证错误，Linux GUI、实际 PostgreSQL/远程上传、完整 30 秒高采样率材料、实体音频听辨及多屏 DPI 均未验收，不能标为全平台 verified。
- 修改复频谱后不一定满足 STFT 一致性，输出再分析会偏离绘制目标。两图使用同标度展示实际差异；不承诺无损藏信息、隐蔽性或压缩保真。
- 原始图片重建保留 v2 数值算法及随机种子行为，透视函数仅抽取共享。科学来源沿用已登记 NumPy/SciPy/OpenCV/SoundFile 与 Griffin–Lim 文献，新增用途写回登记，未复制外部代码或新增依赖。来源与限制见 ADR 中官方文档。
