## 问题与修复

失败任务实际使用 `mandarin_mfa.zip` 和 `mandarin_mfa.dict`，组件管理中的 `mandarin.zip` 与 `mandarin_pinyin_tab.dict` 只处于选文件阶段。原任务副本的摘要与旧登记完全一致。转写中的 `dai1`、`tai2`、`tai1` 在指定拼音词典中均存在，原始 LAB 保留。

- 声学模型下拉框增加桌面原生导入入口。词典也在上方原生选择，下方移除重复的模型与词典文件入口，仅保留环境和离线组件管理。网页模型仍由管理员登记，未开放账号上传模型执行。
- 新资源显示待检查，在检查通过或取消选择前阻止提交。检查成功后切换到实际登记组合，清除先前自定义词典覆盖，记住资源选择；检查失败保留原登记和待检查文件，允许更正或取消。导入取消保持原选择。
- 检查可以复用当前已验证环境及已登记模型/词典。宿主按登记 ID 和原生文件授权解析资源，校验复用模型/词典摘要；前端不接受任意路径。新增内部词典授权读取保持 16 MB 有界读取、角色校验及空文件拒绝。
- `/a/` 类公开合成探针明确支持 `a`、`啊`、`a1`。不猜选任意首词，不改写词典发音。收据记录实际探针词条，完整原生 MFA 检查继续拒绝不兼容音素。
- 已应用词典摘要跟随实际词典。复用管理目录中的摘要文件重新检查时保留原资源名称。科研对齐设置、输入转写、原模型和词典内容保持。
