# M08-R2：图窗、选框、小数点与保存位置

2026-10-05。**verified，限定Windows源码工作台、合成输入、独立Chrome与实际隐藏Qt窗口。** 使用[Start-M08-Workbench.ps1](../../scripts/Start-M08-Workbench.ps1)。旧EXE未更新，未做push、公开发布、安装依赖或现存数据库迁移。

## 修改结果

1. **历史F0图窗**：无结果时使用公共PlotPlaceholder，不显示空数据坐标轴；生成后保留实际输出重新提取的F0与零点对齐。编辑图和历史图共用图面容器、背景、圆角和底栏布局。宽桌面四张图窗外框等宽等高，窄窗按原布局滚动。
2. **批量删除选框**：长文件名单独换行，复选框禁止flex压缩，固定16×16px。保存、重命名和文件批量列表沿用同一规则。
3. **生成与保存位置**：生成完成后提示结果保留在任务历史，独立WAV需要通过保存合成音或批量保存选择输出目录。原生导出报告追加可选directory元数据，来自实际授权目录；右栏显示最近成功保存的完整目录，展开可查看最终文件名。取消、全部失败不伪造新的成功记录。网页只提示下载列表，旧桌面adapter缺字段时提示刚才选择的目录。
4. **小数点输入**：M08的语速、轴范围、参考线、音高倍率/偏移和拐点时间采用文本编辑状态，保留0.与负号等输入中间态。明确操作时校验为数值并构造原配置快照。时间仍使用现有秒5位精度指令，草稿保存/恢复兼容旧数值配置；空白及非法输入不能提交。

原因：原type=number触发Vue的自动数值转换，时间指令与响应式更新进一步归一化输入中间态；长文件名和原生checkbox处于同一flex行，默认收缩导致大小不同。科学算法、默认值、音频数值与原始输入文件未改。

范围：[M08-R2计划](../plans/2026-10-05-m08-r2-input-layout-save.md)。接口补充：[ADR-M08-R1](../decisions/ADR-M08-R1.md)。操作说明：[变速变调手册](../manual/pitch-manipulation.md)。

- 用户原始历史、语料与V2保留。测试使用既有SQLite的隔离副本，无现存库DDL；只有原R1回归在本轮新建fixture内验证明确ID删除。无用户文件清理。
