## 实现范围

- Vue 声道页面继续装载桌面相同的 iframe。桌面使用原 QWebChannel，网页通过账号、登录会话及项目绑定的同源 HTTP 接口调用服务器原生进程。
- `phonetic_core.vocal_tract.session.Runtime` 为两端唯一状态机。桌面注入本机音频及 ProfileStore，网页注入内存配置及浏览器 PCM 端口。声源、轨迹、截面、传递函数、动作缓存和试听变换保持共享。
- 网页默认 33 截面，可选 65；129、257 原生菜单项置灰，旁边提供下载桌面版入口。服务器只接受整数 33/65。桌面保留原 65/129/257 选项及默认策略，现有桌面 DLL 未替换。
- 网页持续发声按钮置灰，悬停提示服务器性能限制和桌面版。单姿势仅合成1秒，生成和播放期间禁止构形/声源/截面编辑，实际播放结束后恢复。关键帧播放与视频导出最多5秒，超限仍可编辑/保存文档；服务端拒绝持续发声、其他试听时长、发声期间改姿势和超限序列/视频。桌面保持原策略。
- 浏览器 AudioContext 接收 48 kHz float32 PCM，实际播放位置确认后提交输出历史；同步画面按 PCM 时间运行，网络缓冲间隙不计入音频位置。停止、失活、关闭和刷新释放音频及自有进程。设备切换使用浏览器实际支持的音频输出能力。
- 构形库、常用、关键帧、曲线及音量在当前标签页内按账号/项目命名空间保存并重新经 core 校验；离开工作区清除这份标签页快照。关键帧文件在浏览器选择和下载，携带实际截面数，异采样导入提示重算。
- 视频保留桌面的 WebCodecs VP8/Opus 中间包、共享 WebM 封装及 H.264/AAC 转码，最终 MP4 从浏览器下载。服务器临时文件归会话所有，取消或进程回收后清理。

## 边界与预算

接口为 `/api/v1/vocal/sessions`，只在宿主显式配置 `vocal_resources` 时启用。请求核对 Cookie、CSRF、Origin、账号、项目与工作区，原生结果返回前再次核对身份。客户端不能指定资源、Python、文件路径、命令或导出目标。

默认最多两个原生会话、一个科学计算槽，每进程 1 GiB 硬内存预算。Linux 另限 CPU 总时间 600 秒、文件大小 128 MB、64 个句柄且禁止 core dump；Windows 使用拥有的 Job Object。空闲会话 1800 秒回收，账号撤销/工作区失效由周期维护提前回收；显式关闭立即回收。网页请求 JSON 上限 9 MB，原视频单包、累计 64 MB 及帧数限制继续执行。宿主级配额和实际并发容量仍须在目标 Linux 实例验证，当前预算不代表容量承诺。
