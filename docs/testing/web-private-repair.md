## 根因与修复

- 语谱图参数预测原先直接拒绝非Windows，Linux没有固定重建入口且缺OpenCV；声学参数合成、变速变调，以及扩大检查发现的发声类型合成和音系归纳，同样有Windows准入残留。现登记固定Linux入口，以当前运行时/真实报告准入，科学核心和参数保持。
- EGG持久任务已支持Linux，交互预览却仍使用Windows Job/管道。网页改为账号与会话令牌限定的有界单次子进程，原始双声道WAV只保留在所属临时槽，更新保留滤波/换声道/选区与Praat、REAPER，释放/空闲过期清除。
- 参数表预览原Linux路径没有带入固定profile的项目依赖。现走已登记入口。参数显示按源音频SHA查询最近成功估计任务的SQLite/XLSX，继续检查资产归属/项目/摘要/期限；不再要求结果与音频同名，也不受最近100条任务列表限制。没有计算来源才按原同名规则回退，手动更换保留。展示可读期限与计算所需5分钟预留分别处理，不重新估计参数。
- 唇形报错是WASM编译被CSP阻止。仅/app/的script-src增加`wasm-unsafe-eval`，不增加JavaScript的`unsafe-eval`。使用实际MediaPipe模型验证；依据[MDN script-src说明](https://developer.mozilla.org/en-US/docs/Web/HTTP/Reference/Headers/Content-Security-Policy/script-src)，两种许可范围不同。
- 网页反馈使用账号Cookie/CSRF，服务器查询当前已验证邮箱，再走固定回环内部桥；浏览器不能指定邮箱、会话所有者或反馈token，不再次填邮箱、注册或收验证码。复用已验证反馈身份，不认领同邮箱未验证身份的旧内容。桌面原邮箱验证保留，无schema变更，内部桥公网404。
- 反馈弹窗去除大面积空白，浅/深主题与窄屏验证。MFA下载改为真正的按钮外观，与使用说明固定等高。M10首次打开说明固定姿态后发声、实时合成使用桌面版，确认随账号保存；网页测试发声固定0.5秒，姿态锁持续到播放完成。桌面1秒试听及实时发声保持。
