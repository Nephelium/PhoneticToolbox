# M11 独立组件、简化安装与下载反馈

范围为 Windows 当前源码、本地交付包、独立 Chrome/Qt 和公开合成对齐。沿用 MFA 3.3.8 CPU，未改科学默认值、全局环境、系统 CUDA、原 auto_alignment 或相邻 v2。官网上传由用户操作，当前没有公开下载端到端验收，也未重打主 EXE。

## 来源材料

重新核验既有来源准备记录，193 个 Conda 包精确二进制归档 SHA 与实际安装元数据一致，保留各配方和补丁。36 项原生/Qt/PyQt 等源码绑定逐 SHA 通过，模型与词典绑定官方 v2.0.0a 及 CC BY 4.0 原文。历史 mandarin.zip 未打包。

复核发现 Conda 不把 `info/licenses` 安装进 env，部分新格式包把该目录放在 pkg tar 而非 info tar。构建器因此从已核验的原始二进制归档中读取两个 tar，补齐 207 份许可原文，并附配方通知。最初构建因主测试环境缺 zstandard、随后只读 info tar 的完整性断言失败，均保留错误后修正；最终通过已有 MFA Python 的 zstandard 只读打包，无全局安装。补齐后重新生成最终包与程序内置摘要，不沿用早期候选身份。

发布者同时提供组件与源码 ZIP 下载链接，许可通知保留在组件内。现有材料不声称第三方 wheel 已逐字节重建，也不把整个项目或其他旧模型的许可未决项标为通过。

## 行为变化

- 普通用户从官网下载并安装、选择一个 ZIP 或选择已解压根文件夹即可。应用内固定版本摘要自动验证来源和内容，不再展示 JSON/SHA 手填项。首次安装自动使用包内模型/词典，无需先选择模型。
- 已解压目录先验证清单、完整文件集合和逐项 SHA，拒绝额外可执行文件/字节码/链接。通过真实自检后直接登记该位置，用户应保持位置不变。原有环境接入收进高级选项。
- 下载显示实际接收字节、总字节、进度和速度。续传前已有字节不计入本轮速度，3 秒无数据时速度归零。解压按展开字节显示，自检/无确定总量的校验阶段使用活动进度。安装有独立任务锁，界面仍可每秒读取状态，避免长任务阻塞进度队列。
- HTTPS 固定来源，拒绝重定向，已有下载只在精确 Content-Range 匹配时续传。中断保留可续传内容，完整坏摘要缓存隔离后允许重新下载。服务器 404、断网、空间不足及目录内容改变给出可操作错误，失败保留原登记。
- 新增下载声学模型（官方）和下载发音词典（官方），分别打开官方 acoustic/index.html、dictionary/index.html。官网目录已于 2026-10-11 读取确认；新增链接不自动下载/执行第三方模型。模型需兼容 MFA 3.3.8 且与词典语言、音素集匹配。
- 说明书 M11、模块 README、帮助、开发文档同步，保留稳定标题与既有例音。当前章补包含官方资源按钮的新安装截图（2560×1600、DPR1.5、浅色、页面100%、最大化）；与旧图对应的旧正式素材保留。

## 验证

定向 Python：`pytest -o addopts= backend/tests/test_m11.py backend/tests/test_m11_delivery.py backend/tests/test_m11_r2_probe.py desktop/tests/test_m11_r1.py -q`，54 项通过。项目测试环境没有旧根配置需要的 pytest-cov 插件，覆盖参数不继承，断言未跳过。两条上游弃用提示记录于 `output/validation/m11-delivery/python-tests.log`。

前端 MFA 5 项、说明书阅读器 13 项通过，类型检查、契约一致性、UI 来源数据一致性、正式构建与生产说明书解析通过。Vite 大 chunk 提示沿用现状。浏览器验证使用独立 Chrome 和测试配置目录，实际 Vue 配模拟传输，覆盖进度/速度更新、ZIP/文件夹参数、取消选择无副作用，以及两个官方下载链接的点击目标、浅深主题与两种窗口。证据 `output/validation/m11-delivery/browser-05c51e229148410b93ea30fc2659bcc0/`。这不是已上传官网的真实流量测试。

早期候选通过实际 Qt/native grant/API/真实 MFA ZIP 与文件夹自检，证据 `output/validation/m11d-3ef0ae/`。最终补齐许可的 ZIP 在 `output/validation/m11d-837a69/report.json` 中 `success=true`，ZIP 安装与已解压文件夹接入均执行真实 MFA 并成功，首次 ZIP 安装至应用约 147.31 秒（本机后台验证条件，不作新电脑速度承诺）。两次登记仍保持同一运行环境身份。浅深主题实际 Qt 截图通过。探针使用公开合成词条，证明该运行组合能完成一次对齐，不代表自然语料精度。原生窗口隐藏并使用软件渲染，Qt GPU 上下文回退日志与 MFA 的 CPU 算法无关。

文档校验检查 1882 个文件、410 条来源和 71 项任务，`errors=[]`，历史快照失效链接单列。定向 `git diff --check` 通过。

原生测试退出前的清理因 Qt 子进程仍活动而保留 scratch，保留原清理错误；进程退出后由同一归属检查脚本重试，最终清理结果见各运行的 cleanup.json。只清理本任务的合成 WAV、展开测试副本、临时配置/数据库/浏览器目录，原 auto_alignment、正式组件、用户数据与正式说明书素材保留。

## 发布与未验范围

官网固定目录 `https://www.phonetictoolbox.com/releases/components/mfa/3.3.8-r1/`。发布者按上传说明保留文件名，将组件与源码 ZIP 同渠道提供，检查 HTTPS、200/206、长度与 SHA。应用安装通过内置摘要验证，不要求普通用户上传清单。旧主 EXE 不会自动得到新的组件界面，可解压后从已有环境入口选择 env 及配套模型/词典。

尚未验另一台无开发环境 Windows、其他平台、真实公网完整下载、全部官方语言资源。新版 MFA-R1 主 EXE 已完成真实缓存安装、普通话探针、说明书打开与正常退出，并与安装版同字节交付，见[当前成品报告](windows-current-release.md)。本轮主应用体积和更新机制仅作只读核查，见[包体与组件方案](package-size-review.md)，没有改动全量更新和缓存保留协议。
