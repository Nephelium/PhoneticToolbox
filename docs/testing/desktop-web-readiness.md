# 桌面遗留项与网页登录上线准备

本页按主题维护。核查对象为当前源码、Startup-20261008-R1 免安装 EXE、现存安装交付与部署适配。结论仅覆盖只读审阅和下列定向检查，不代表重新验收全部模块、设备或真实站点。本轮未修改产品代码、构建策略、数据库或服务器。

## 当前判断

可以继续修改模块与说明书。本轮未发现需要先停止开发的新增桌面阻断。网页版已有账号、项目、文件与任务基础，尚不能直接把桌面全部功能作为已可用的登录网站发布。现在保持平台接口、账号数据归属和能力边界；真实部署与数据库操作集中在上线前实施。

进一步缩包按井井最新要求暂不推进，之前候选只保留核查证据，不列为下一次交付必做项。

## 网页版已有基础

- `backend/src/ptb_api/auth.py` 已实现登录、会话撤销、登录限速、Origin/CSRF 校验与 Secure/HttpOnly/SameSite Cookie，无需重建一套 token 登录。
- `ServerPage.vue` 已有登录、项目、账号变化通知；`serverFiles` 通过同源 API、owner/project 和资源 ID 访问受管文件。部分模块草稿已有账号/项目 key。
- `scripts/p15_staging/host.py` 已有 HTTPS/代理信任、维护/排空、预算、允许操作和运行时身份门。首期科学候选仅 M01/M03/M04，菜单存在更多模块不表示 Linux 生产计算已可用。
- 历史 P15-F01 的 ZIP 宣告与执行不一致已在当前源码修复：资源 profile 与部署允许操作共同过滤。本轮相关测试通过。旧报告保留历史发现，真实站点仍未验收。

## 现在应预留的边界

| 优先项 | 具体发现 | 建议与验收条件 |
| --- | --- | --- |
| 账号与本地研究数据归属 | M15 使用固定 IndexedDB `ptb-m15-local-v1`，列出全部本地项目/会话，页面不接 owner。AppShell 给 M17 固定 `local:M17`，草稿按此 key 读取。退出只清 M01/通用 workspace，没有针对上述库的账号隔离 | 登录版启用这些模块前明确本地独立模式与账号模式。账号模式按 owner/project 隔离，旧无主记录显式认领/导入，不自动分配给下一个登录者。验证同浏览器 A→退出→B、多标签、到期、迟到响应与未保存状态。此为源码确认的缺口，未实测生产数据泄露 |
| 平台能力分离 | M10 依赖 vocalRequest，M16 依赖 recording port，M18 依赖 papers channel；M05 浏览器账号适配也没有完整桌面能力 | 后续业务继续通过 port/context，不直接绑定 Qt 或本机路径。新增功能标明桌面、纯浏览器、登录服务器的能力；无需现在实现全部 Web adapter |
| 前后端能力同步 | 后端已过滤 capabilities；研究工作台仍登记全部模块。serverFiles 构造多个可选 port 不等于服务已准入 | 上线前用实际 capability 提示/禁用操作，后端继续逐请求鉴权与准入，不能仅靠隐藏按钮 |
| 草稿、正式项目与临时结果分开 | 服务器已有 1 GB/3 天政策，M15 本地实验记录独立持久化 | 保持存储语义与协议版本，三天清理不能波及正式工程、实验原始记录或本机原录音，不改变科学默认值 |
| 说明书复用及分发 | 正文/阅读器共用，已有 software/public 构建；软件专用自然素材标记不等于已确认网页公开分发范围 | 继续相对资源、稳定 ID，并标明桌面专属操作。上线选择获准的网页素材，不直接公开作者工程、恢复稿、测试目录或整份桌面静态目录 |

M15 原设计为纯客户端、文件不上传，可以保留。账号隔离需单独补齐，无需为本地命名空间把实验计时搬到服务器，见 [M15 决策](../decisions/ADR-M15-client.md)。

## 可以后做、上线前必须完成

1. 明确首期模块和账号来源。当前只有管理员建号后的登录，没有自助注册/找回入口。邀请制可沿用管理员流程；若面向公众注册，再实现验证、找回和滥用防护。
2. 对具体目标库做政策迁移、停写/恢复及回滚演练。1 GB/3 天代码与隔离验证已有证据，本轮未连接目标库，不能把迁移脚本存在说成线上生效。
3. 用最终源码重建 Linux 运行时与验收记录，只启用通过验证的模块；复验实际输入、取消/失败、配额、到期、并发和任务公平性。历史短合成输入 30 分钟负载不能代表新版本容量。
4. 真实 HTTPS/PG/代理下做双账号隔离、会话到期、上传下载与 Range、磁盘满、重启、清理及备份恢复。保留安全 Cookie 和逐请求授权，依据 [OWASP 会话管理](https://cheatsheetseries.owasp.org/cheatsheets/Session_Management_Cheat_Sheet.html)及[授权指南](https://cheatsheetseries.owasp.org/cheatsheets/Authorization_Cheat_Sheet.html)。
5. 若首期开放网页录音/摄像头，单独实现并验证权限、格式与设备限制。[MDN getUserMedia](https://developer.mozilla.org/en-US/docs/Web/API/MediaDevices/getUserMedia)要求安全上下文和用户授权，桌面设备验收不能替代。
6. 部署前核对公开文件、来源/素材范围、日志隐私和数据删除说明。可信外部节点可后做，首期单机服务无需等待；若首期依赖节点，则先完成实际领取、取消、离线和回传验收。
