# 论文翻页片头与语谱图重建流程视频

日期：2026-10-15。范围为本地视频制作，未修改应用、网站或研究训练流程，未公开上传。

## 内容与来源

- 片头使用井井提供的《The Sound Spectrograph》31 页 PDF，展示真实页面翻动、寻找附加材料、图片无法播放及 PhoneticToolbox 登场。依照用户修正，主体为翻页过程，不制作独立谱图展示。
- 算法段依次解释 GL、Aoki 的短时窗脉冲相位初始化、GL 声音转 Mel、条件化 NAFNet 修复以及 BigVGAN 合成。Aoki 初始化发生在 GL 迭代之前。当前研究工程的 `conversion-rules.md`、`convert_paper_spectrograms.py`、`visible_mel_reconstruction.py` 已只读核对。
- 原理论文为 Griffin & Lim (1984), DOI `10.1109/TASSP.1984.1164317`；Aoki (2023), DOI `10.1250/ast.44.186`，后者使用用户提供的三页 PDF。NAFNet 与 BigVGAN 的官方仓库已核对。算法画面是流程示意，谱图来自可复现合成脉冲信号，无模型改善数据或听感比较。
- 使用官网现有品牌图、ZCOOL KuaiLe 字体、奶油白／紫／黄色板式。线上 r4698051b31a01f4e 的 CSS 与本地 `temporary-site/site.css` SHA-256 一致。配乐与音效由制作脚本合成，无旁白。
- 同日按井井反馈修订：翻页从向内缩短改为朝镜头的真实透视投影，纸页外缘变高、书脊固定，绘制范围随投影扩展。仅底部叙述字幕改为系统楷体 `simkai.ttf`，字号36；其他标题、标签、品牌及论文原页文字保持。

## 生成与交付

脚本：`scripts/build_creative_video.py`。先运行 `python -X utf8 -B scripts/build_creative_video.py --preview`，检查分镜后运行无参数入口。

本地交付位于 `output/creative-video-20261015/`：28 秒片头、94 秒算法段，1920×1080、30 fps、H.264 / AAC、yuv420p、48 kHz 双声道，MP4 含 faststart。同目录有可离线观看页、字幕、配音稿、分镜、来源摘要与最终成片检查记录。PDF 和视频不进入公开源码。

## 验证范围

Windows 当前环境执行 FFmpeg 完整解码，ffprobe 逐帧计数与时长／画幅／编码检查，音轨有限数值和峰值检查，抽样动态帧差、场景文本边界检查。最终编码帧另行抽取成检查拼图。具体字节数、SHA-256、峰值和帧数以同目录 `validation.json` 为准。

修订版重导出后完整解码与媒体检查通过：片头840帧／9,151,589字节，算法段2820帧／10,426,539字节。AAC解码峰值分别为0.18392与0.06165，无削波；最终编码关键帧与分镜相符。楷体字幕全条目边界通过；翻页前后半程8个角度的外缘高度均大于固定691像素的书脊，最大约775像素，绘制不裁切且不侵入字幕。最终编码9.2秒与12.8秒分别查看前／后半程。初版文档检查2052文件／111任务无错误；修订文档执行定向差异及链接检查，交付MP4沿用现有output忽略规则。
