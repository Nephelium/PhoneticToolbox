| 耳语太小 | 原生耳语 /a/ 稳态 RMS 约 0.000221，浊声约 0.027577，相差约 42 dB。R4 为耳语增加显式 24 dB 试听补偿，保留原生波形与几何声门参数，未叠加假噪声。播放/视频共用试听变换。补偿后试听标准差 >0.005，闭合对照 20 Hz 以上可听频段稳态 <1e-6。未将低频压力松弛或静态偏移当成气流噪声。 |
| 重播慢 | 规范化姿势、时长、声源、F0 等共同生成缓存指纹。停止后相同请求复用动作/音频；参数、曲线、声源等八类修改分别触发重算。Qt 第二次播放实际返回 cache=hit。音量/监听增益即时作用于缓存。 |

| 面积命名 | 统一改为口腔声道面积函数，仍为原生口腔管道数值，不把鼻腔参考网格计入面积图。 |

显示鼻咽补片、唇红体积与参考头壳属于观察适配，不据此宣称个体解剖重建。舌背目标限制会改变超边界输入接受的构形，已与纯显示修订分开说明。声学引擎 API 2.4 与原生桥接 m10/2 二进制均保持 R3 字节，未为试听或显示改变原生管道面积。听感仍需使用者在实际播放设备上判断。

最终包从系统临时目录启动，分别执行 `PhoneticToolbox-v3-M10-R4.exe --self-test-r4 output/validation/m10/exe-r4` 和 `--self-test output/validation/m10/exe-r4-base`（实际传入输出绝对路径），退出码均为 0，结果均记录 `frozen: true`。R4 验证包含 3 帧与 201 点曲线文件往返、静音 F0 拦截、缓存命中、两种视频及取消；基础验证包含三列真实并排、编辑/历史/滚动/主题及设备输出。真实 WASAPI 在零试听音量下生成 22,080 样本、0 次 underflow，不能据此代替实际设备听感验收。

静止截图的一次失败伴随测试窗口尺寸变化，检查了保存的截图后，为独立 Qt 测试窗口固定尺寸并禁止抢焦点和接收实际鼠标输入，再执行同样的八次像素一致性检查。最终 EXE 放大 F0 哈希为 `2fbc568ebdb66afd0e98217b6bb3857cabec8724bd3877e3f6a0c1deb4721251`，静止三维哈希为 `460e8271668f2fcd0fe25215ad6c75c2858f3c84a19f1b17cc00043229d66e63`，三维渲染计数保持 16。此结果限定该窗口、驱动和场景，未放宽比较断言。

验证中发现两项实际问题后修复：逐段 flush Opus 会反复插入尾部填充，现改为单次结束 flush；容器需分别处理 CodecDelay 与末包 DiscardPadding，修订后音轨解码长度和波形对齐检查通过。未放宽音轨长度或同步断言。

短帧追加后另检查了浮点时长累计：三个默认 0.2 秒帧按 48 kHz 采样时钟得到恰好 0.6 秒、18 帧视频，避免 `0.2+0.2+0.2` 的浮点尾差多生成一帧。40 个 0.3 秒帧的 12 秒上限也按同一精度验证。
