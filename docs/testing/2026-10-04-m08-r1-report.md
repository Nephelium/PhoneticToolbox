# M08-R1：变速变调生成、试听与保存整理

2026-10-04。**verified，限定 Windows 源码工作台、合成输入、Chrome / 实际 Qt 和 WSL 文件处理检查。** 入口：[Start-M08-Workbench.ps1](../../scripts/Start-M08-Workbench.ps1)。本轮未重打 EXE、push、公开发布、安装依赖或执行数据库 DDL。

## 问题与结果

1. **手绘合成缺少历史曲线**：原 `/m08/history` 仅返回 `saved=true` 的批量结果和复制任务。去掉此 UI 历史过滤条件，普通手绘、导入 F0 后的成功合成与批量生成统一进入历史。保留原字段、老任务、PCM16 输出及重新提取的实际 F0。即时完成和异步完成两种前端返回路径均刷新历史。
2. **播放按钮只切换状态**：播放当前视野原音直接播放可见源区间；播放合成音播放完整输出；试听此版本加载并立即播放所选音频。公共 AudioTransport 新增可选 `externalPlayback` 和事件，其他页面默认行为不变。M08 播放选区绑定最后鼠标选择的波形，直接试听不改写选区；迟到版本读取不能覆盖后续播放。
3. **生成与保存混淆**：左侧改为批量生成；批量基频区域默认展开，仅保留编辑拐点表入口，表内仍能添加 / 删除行。右侧删除本批次音频、批量重命名下方新增批量保存。移除保存并编号，单音频统一保存合成音。历史区默认展开，长文件名两行显示，悬浮可查看全名。
4. **重复历史及保存冲突**：新保存入口直接导出现有 WAV，不创建复制任务，不增加历史或改变到期时间。一次选择输出目录，逐项报告成功 / 失败，取消保留全部结果，失败项保持勾选供重试。同名文件独占创建并加数字后缀，本次会话同一 ID / 目录的未变化副本复用。网页 adapter 生成单个 WAV 或 UTF-8 ZIP，256 项 / 64 MB 有界。旧保存 API 留作兼容。
5. **管理流程**：删除后立刻清除已删曲线与当前结果，刷新失败也会释放 busy。管理弹窗固定打开时的结果集合。同一结果在多个目录的本会话副本均保持显式关联，外部改动拒绝管理和复用。单个 / 同名手绘结果重命名保留扩展名并生成不同后缀，长度对齐后端 180 字符约束。

计划：[M08-R1](../plans/2026-10-04-m08-r1-workflow.md)。交互决定：[ADR-M08-R1](../decisions/ADR-M08-R1.md)。当前操作说明：[变速变调](../manual/pitch-manipulation.md)。
