## 已实现行为

- 三列容器：宽屏各列独立滚动；三列内容都溢出时改成工作区共同滚动；窄屏自然纵向排布。导航、标签栏、播放条不随内容移动。M01 使用该容器，其他模块的专属布局没有被强制替换。
- 标题和目录条压缩；目录/输出控件在空间足够时同排，宽度不足再换行；右侧集中参数、设置和批量操作。试听声道并入显示选项，关联解释可展开。
- 每条波形下紧贴秒刻度、保留 172px 高波形、显示播放游标。Ctrl+滚轮以鼠标位置为锚点缩放，双击全长，按钮与时间窗平移仍保留。普通滚轮滚动所在内容区。
- 公共播放条有当前选区内的进度滑块：暂停时定位，播放时拖动后从新位置继续；拖动期间播放计时不会抢回滑块位置。原始 WAV、声道、采样率、科学计算不变。加载过程用不定进度指示，未虚构百分比。
- 音频列表支持勾选全选以及焦点位于列表时 Ctrl+A。批处理仍覆盖整个列表；当前试听和切分勾选范围分开。
