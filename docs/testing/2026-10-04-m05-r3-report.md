2026-10-04。状态 **verified，限定 Windows 开发态和下列合成输入验证**。实体摄像头/麦克风同步、实体 DPI、长时间录制、Linux GUI 与完整独立浏览器导出不在 verified 范围。未生成新 EXE。

## 完成内容

- 删除仅保存候选参数记录、录后 V2 重算两个按钮。顶部顺序为模式、开始、结束录制、另存录制、放弃未保存内容、检查偏移量。
- 仅三种模式。实时预览结束清除临时测量，不写盘。实时录制另存默认勾选视频/动画，音频及完整唇形数据始终保存。高帧率模式只保存视频/音频及回执，保留已有视频离线计算入口。
- 视频位于右栏最上方，中央面部按画布约 94% 范围放大。视频播放/暂停/拖动与面部回放共用播放器时钟，检测缺失留空。下方参数名/数值对齐，四曲线保留。
- 偏移弹窗显示真实解码音频与任选参数，横轴对齐。输入 ms、左右键 1 ms 与按键重复、拖动参数图、时间缩放、应用/取消可用。归一化仅用于比较显示。人工偏移在当前录制和各离线结果分别保存。
- 修复录制起点与视频首帧重复叠加、离线回放首帧时间重复叠加。新记录明确保留估算起点的不确定性。异常视频时间戳可以保留原始编码文件，音频/唇形独立保存。算法与证据详见[时间审计](../references/m05-r3-timing-audit.md)。
