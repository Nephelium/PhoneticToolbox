## 为什么需要独立变更

003 将资源限定为 input，没有任务与文件的持久关联。不能把 ZIP、分析结果或临时输出伪装成上传文件，也不能只存在进程内，否则取消、到期和旧 worker 恢复时无法可靠追踪。

根目录 [AGENTS.md](../../AGENTS.md) 要求数据库实际迁移遵守会话授权边界；此前确认具体限定为 003 的三张新表。本次增加任务关联和约束，属于新增 schema 操作，并非已批准 003 的重复验证。
