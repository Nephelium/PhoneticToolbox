## 请求与实现

| 要求 | 实际行为 |
| --- | --- |
| 审阅仅在第 4 步 | 前三步不挂载审阅组件。第 1 步仅显示用于选列的原始样例，第 4 步可展开全部记录的分页审阅。 |
| 任意列与开始行 | 字头、IPA、备注列可选，备注可不使用。行列从 1 开始，默认从第 2 行开始。先 inspect 原始表格，确认成功才替换当前数据。 |
| 更多导入格式 | XLSX/XLS/CSV/TSV/TXT 加 DOCX 表格。Excel/DOCX 可选工作表或表格，文本可选 BOM/UTF-8、GB18030/GBK、UTF-16 与分隔符。 |
| 四步重新排版 | 左栏步骤与文件，中央任务内容。导入参数仅第 1 步显示，生成与文件仅第 4 步显示，复用现有主题、字体与工作台。 |
| 当前页修改保存 | 调类表及声韵双列表直接编辑。上下移动、Ctrl/⌘/Shift、多项拖动、页内归并目标与影响提示、取消、撤销、还原和保存。编辑弹窗不再使用，帮助仍使用公共弹窗。 |
| 三种预览与定位 | 声母→韵母、韵母→声母、二维表三个按钮。搜索全部字头、原始 IPA、归并声韵及组合 IPA，支持 NFD 等价形式，命中定位到页/单格并高亮。 |
| 成果与设置一致 | 生成时保存不可变配置与分析快照。继续编辑明确标记旧成果，尚未保存设置时禁用生成。现有文件可保存，不将新设置套到旧文件上。 |

结果文档每页显示 100 条，矩阵每窗口 12 韵母×10 声母，每个单格 60 条分页。搜索覆盖全部记录，验证命中超过第 200 条及矩阵单格首屏的字。页面核对分组、调类顺序、内容与备注，DOCX 的纸张分页以实际文件为准。

页内保存更新当前工作草稿，顶部保存草稿同时合入尚未保存的调类/声韵编辑并写入本机。切换步骤保留输入，未确认归并或待导入文件须先完成或取消。失败保留编辑，重开恢复已保存内容。

## 解析与导入核查

新页面显式使用 `computation_revision=m14/2`。API 默认和历史执行仍为 `m14/1`，原独立 V2 基准保持通过。旧草稿可恢复查看，需要重新导入才使用新解析生成。原始 IPA 文本保留，分类符号使用 NFD，未用 NFKC 改写修饰符。

| 可复现输入或边界 | 修复后结果 |
| --- | --- |
| `tsã35` 与 `tsã35` | 均分为 `ts`、`ã`、`35`，预组鼻化字符不再误分到辅音路径。 |
| `t͡s55`、`t͜sʰ55` | 连音符保留，整体识别为单个塞擦音，按所选单辅音策略归类。 |
| `t͡ʃa35` | 声母 `t͡ʃ`、韵母 `a`、调值 `35`。 |
| `cç55` 与 `cç55` | 将塞擦音候选同样规范分解，避免输入已分解但候选未分解的漏匹配。 |
| `ɹa55`、`ɻa55` | 元音前近音作为声母；`zɻ55` 仍保留 `ɻ` 韵母，孤立近音仍按所选策略。 |
| `ma⁵⁵`、全角数字 | 末尾上标/全角数字作为调值，原输入不重写。 |
| `ˈma55`、带外层斜线与重音 | 不把开头重音标记纳入声母。 |
| `m̩55`、`kŋ̩55` | 成音节标记保留，两种单辅音策略及辅音+成音节鼻音均有独立预期。 |
| 缺字头/IPA、空备注、字面 NA | 各格式保留原列位置，备注不会补位成为 IPA，NA 不被数据框自动解释为缺失。 |
| 引号内逗号/换行 | 按 CSV 记录读取，来源行使用物理起始行。开始行落在跨行记录内部明确拒绝。 |
| 多音节、只有调值或重音符号 | 跳过并列明来源行和原因。含 `?` 或替换字符的记录保留并提示人工核对。 |
| 无表头、10,001 条有效记录 | 拒绝超过 10,000 条的有效记录，不将额外预留的表头行当作有效行预算。 |

上述为规则和边界回归，未声称对所有方言或自然语料完成准确率验证。多音节检测属于启发式诊断，未知符号仍须人工核对。继续保留默认辅音策略、字头/整词备注规则、重复记录和三件导出文件。

导入依然受限于 2 MB、10,001 个读取记录、64 列、单元格 512 字符。压缩文档展开预算 32 MB/512 个项目，公式 XLSX 拒绝。矩阵、单格与总输出预算不变，重型解码/导出仍在受限 child 中，API 不直接执行文档计算。

## 接线问题与收尾

- DOCX 接收曾被旧 table 格式白名单拒绝，已补齐本地/托管适配。Qt 原 blob 下载白名单也未允许 DOCX，本轮补齐并核对真实下载字节。
- 切换到窄列首表后，暂时重叠的列设置曾拦截 inspect。inspect 仅读取样例，正式分析/导出仍严格验证列互不重叠。真实二次选工作表已验证。
- 同一命中在搜索文本只增加空格时曾回到首页，已让查询变化始终定位命中。声韵拖动记录来源列表，跨列表误拖不改变另一列表。
- Qt 测试脚本的重复几何字段和带引号选择器已修正，未降低断言。隐藏窗口过渡截图增加等待绘制；GLES 与既有 PNG warning 仍记录，不外推实体 DWM 稳定性。文本编码为明确保留的用户选项，测试在切换回 UTF-8 样例时显式恢复自动编码。
- 契约生成必须使用明确指向当前 core/backend 的 PYTHONPATH。缺少该路径的一轮检查使用了其他环境的导入，出现无关漂移；按正确环境复验无漂移，未手改生成文件。
- 文档检查扫描 1,514 个文件，本轮 M14 文档/入口/截图链接通过。全仓检查仍因 16 条非本轮 EXE 缺链失败，历史快照缺链另列，未跨任务清理或补造旧包。
