# M10-R9 完整扩展辅音表与 Plus 入口精简

2026-10-05，verified，限定 Windows 源码和实际隐藏 Qt。

## 实现

井井要求声道保存/加载弹窗采用图示的 Plus 完整辅音表，并移除 Plus 页的相关扩展表输入整行及查看所选介绍按钮。本轮直接复用 M17 `extended` 目录，不再仅筛选基本肺部气流辅音。

- 完整保留 14 个构音部位、13 类辅音和 186 个辅音表项的顺序、中文名及 Unicode 文本，包括 111 个完整组合示例。186 是可点击辅音表项数，不能称为 186 个独立基本字母。
- 保留 28 个元音按钮、20 个其他辅音按钮，以及自定义输入和下方显示区。原 107 个基本符号均保留，总计 218 个不同的可保存符号、234 个按钮位置；部分其他辅音也出现在矩阵中。
- 弹窗最大宽度从 860 调整到 1360 CSS px，并限制在当前声道工作台视口内。辅音符号默认 18 px，随正文设置放大至 24 px。单格可换行，标签和说明最低 12 px。表最小宽度 1080 px，窄窗横向查看全列，弹窗纵向滚动到元音和自定义区，顶部操作保持可见。
- 两种弹窗共用完整目录。旧自行输入的扩展音标若已存在于表中，会在对应格子显示其原构形；其他自定义名称继续留在下方。名称与 id 的更新规则、`presets.json` version 1、全部声源/F0 保存加载保持原实现，无数据迁移。
- Plus 删除指定行和按钮，并同步清理失效的样式、事件及帮助/说明书文字。悬停、右键与 Alt+Enter 介绍入口保留。

图表用于给当前构形命名。点击音标不会自动构造其标准发音，保存也不表示通过听辨验收。
