# M03-R3：EGG 控件、逆滤波图形与显示范围

2026-10-04。**verified，限定 Windows 开发态源码、独立 Chrome、实际 Qt 离屏和以下输入/检查。** 井井追加的 F0 动态纵轴与逆滤波横轴对齐已纳入。科学算法审查完成，算法替换方案为 planned，未把显示改进称为科学有效性验证。

## 已实现

1. 左栏数字框约 30 CSS px 高，字段按可用栏宽排一或两对。WAV 下拉框移至左栏顶部并自适应宽度。交换声道紧邻刷新，CSV/三图、LP 阶数和 IF 提交移到顶栏。修复窄栏播放器原 220 px 最小宽度导致的横向溢出。
2. 逆滤波支持全部分开 6 图、音频+IF 4 图、EGG+IF 4 图、全部叠加 2 图。PNG 按当前组合输出，并可保存单图。保存完整结果与返回分析移到顶部，与 PNG 保存同行。
3. 音频蓝色实线、IF 橙色虚线、EGG 紫色点线，线宽增强；导图使用独立深色白底配色。双信号波形保持左右轴，三信号波形按各自中心窗峰值归一化并明确标识。频谱和原始结果不做该归一化。
4. 各图共用最大纵轴标签留白，双纵轴右侧空间同步给其他图，确保上下时间轴和频率轴分别对齐。界面和 PNG 使用同一几何。
5. 新结果 JSON 保存同次任务完整选区的滤波 EGG，可在结果下方勾选显示。原音频与 IF 两条试听保留。旧任务缺少数组时不伪造 EGG，新增字段均可选。
6. 自动 dB 使用同一选区实际 PSD 的可见频带峰值和 50 dB 范围，一次回填后保留手动编辑。全零数据不猜数值。F0 右轴自动覆盖已选曲线的当前可见有限正值，包含低于 50 / 高于 500 Hz 的数据，留边距，无有效值时隐藏。新三图 PNG 同步动态 F0 标尺，F0 计算参数不变。
7. 公共导图去掉重复彩色说明，标题居中。M02 当前/整幅 PNG 与 M08 历史图同步改善。M02 参数/IPA 与 M08 文件名曲线对应仍保留为必要内容，文字使用中性色。M03 后端三图标题精简；M04 现有标题已经居中。没有改写历史图片。

## 算法审查结论

完整定义、公式、48 组显著度检查、6 个 LP 阶数及原始来源见 [算法核查](../references/m03-r3-algorithm-audit.md)。

实际录音 40–40.5 s 中有 226 个 GCI 起点，225 个固定 3 ms 窗覆盖下一检测 GCI。原实现未使用 GOI 确认闭相。此问题不能通过选一个新的默认 LP 阶数解决。新结果明确显示实际跨周期计数，仍标 IF 估计。科学核心 `egg-legacy/1` 保留，未来替代方法需独立版本和真值验证。

峰自动只作用于峰，手动谷仍默认 0.01。不同片段的阈值敏感性不同，目前没有证据指定通用最优值。自动 dB 属于显示范围建议，不代表声压校准。上述边界已写入用户说明。

## 测试失败与修正记录

- 早期侧栏检查通过直接写 CSS 变量尝试改宽，被组件宽度控制器恢复。改为实际拖动边界的键盘接口后发现并修复窄栏播放器溢出。
- PNG 虚线样式同时有 SVG 属性和浏览器计算样式，测试改为核对真实导出属性及文件，未降低线型要求。
- Qt 宿主没有 Pillow，测试采用其既有 QImage 解码。测试目录选择器曾按错误对话框标题匹配，完整结果保存进测试输入副本目录；检查器修正为匹配实际结果目录标题后通过。个人原录音未被写入。
- 部分初跑 Python 漏设 PYTHONPATH，或在科学环境运行需 FastAPI 的宿主测试，导致收集失败。按既有科学/宿主边界分别运行后通过。未安装依赖。
- M08 独立导图测试最初用另一 Vue 导入实例挂载，引起测试 ref 无归属，已用正常 Vite 页面入口复验。
- WSL 发行版实际名为 NInfer，既有环境没有 Pydantic/Matplotlib。本轮只执行可运行的真实显示函数和文件检查，不冒充完整 Linux 科学任务验证。
