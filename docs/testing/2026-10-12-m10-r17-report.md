# 生理参数合成：舌形、窄缝与实时交互验证

2026-10-12，`M10-R17` 在 Windows 当前源码、原生几何 DLL 与独立 Qt 工作台范围内 `verified`。本轮没有重打包 EXE、公开发布或执行实体耳机听辨。

## 变更与原因

- 口底附着从下颌参考肋 12 后移到肋 10。参考点随下颌移动，舌头调整时保持不变，舌腹仍随构形返回该点。极端舌叶测试发现旧回程控制线在后移后可能自交，已调整舌腹返回方向，相关用例重新通过。
- 舌叶内凹以移动的舌背/舌尖支撑线约束，最大下偏采用 0.3 cm 工程尺度，过渡权重改为平滑函数。保留向外凸起的原有工作范围。这是当前模型的形状约束，不代表测得的人体普适极限。
- 原先显示启用 geometric 剖面，声学仍经过 VTL 的 0.1/0.01 cm 窄缝过滤。当前声学积分和显示共用 geometric 剖面并按构形缓存，保留经验面积修正和真实闭塞。129 截面、i 起点 `TCY=-0.2, TS3=0` 的第 85 截面，旧剖面积为 0，新几何面积为 0.044038104 cm²，声学读数为 0.044038 cm²。相邻 86/87 截面也恢复正面积。
- 横截面侧缘拖动按实际返回的参数和表面高度修正增益，使用固定的画布坐标比例，改善饱和段反向操作。左右继续联动。
- 原生横截面只计算一次，二维鼻腔参考预筛选实际相交面，复用已计算的软腭，减少牙齿裁切和气腔网格中的对象分配。三维使用完整鼻腔，选择的 65/129/257 截面和声学采样不变。
- 实时波形与语谱图共享 Ctrl＋滚轮时间缩放，范围 0.001–12 秒，以指针处时间为锚点，随播放更新。双击或重新选择显示时长恢复范围，展开图同样可用。窄窗口增加图表最低空间，避免坐标轴挤占波形绘图区。

方法号变为 `m10/r17`，数组布局保持 `m10/3`。新交换文件版本 4，版本 1–3 保留参数并提示按当前几何重算。旧音频不可据此逐样本复现。取舍见 [几何决定](../decisions/ADR-M10-tongue-transverse-and-floor.md)，操作见 [模块说明](../../frontend/src/modules/vocal-tract/README.md)及正式说明书。

## 擦音检查

原生 VTL 摩擦噪声发生器仍启用，噪声受气流、狭窄面积和前侧缘参数影响。检查没有修改噪声发生器、增加替代噪声或自动归一化输出。以下为清声模式的数字输出，≥3 kHz 能量比例由 Welch 谱计算，不是实体听辨结果。

| 构形与设置 | RMS dBFS | ≥3 kHz 能量比例 |
| --- | ---: | ---: |
| 标准 s，800 Pa | -51.13 | 98.86% |
| 标准 s，400 Pa | -65.42 | 98.85% |
| s，前侧缘 TS3=-0.6，800 Pa | -66.63 | 2.13% |
| s，前侧缘 TS3=0.8，800 Pa | -50.38 | 99.23% |
| 闭塞 t，800 Pa | -189.21 | 接近 0 |
| s，0 Pa | 全零输出 | 0 |

该结果支持窄缝和侧缘设置会影响擦音。截图不能直接证明气流处于层流，当前程序也未做三维流体模拟。清声界面增加保留中央窄缝、抬高前侧缘及弱音增益的操作提示。被移除的 s 快捷预设没有重新加入界面，验证通过引擎既有构形输入进行。

## 下颌、下牙与真实波形缩放补充验证

2026-10-12 用户先后指出舌底越过下颌、前伸舌体包住下牙，以及波形放大后只有竖线。现已修复：

- 舌腹按原生下颌内壁和移动下牙的三角面约束，分割面内部后贴合，避免仅检查顶点却跨过牙冠。完整显示舌体扣除上下牙，不再豁免舌背面。矢状面保留下门齿侧壁两侧的接触高度，隐藏牙齿仍保留接触。
- 45 组构形通过面内部与下颌/下牙上包络的相交检查，以及整个显示舌体与上下牙实体的避让检查。含 a/i/u/s/l/t、3 档下颌 × 4 档舌尖前后 × 3 档舌尖高低、3 档侧缘。原生舌背顶点及中线口底参考保持。没有将二维侧方投影相交误判为三维穿透，也未声称覆盖全部三维自交。
- 二维延后完整舌腹网格计算，先生成同一接触平面上的矢状轮廓及舌背接触面。45 组二维/三维轮廓和软腭网格逐点一致。打开三维重新生成完整舌体，并在实际 Qt 切换时核对。新增约束未优化时同机二维更新为 208–289 ms，延后完整表面后为 111–134 ms；这些是选定构形探针，不是持续帧率承诺。
- 原波形将整段音频压为最多 700 组峰谷值，缩短时间轴无法还原周期。现在按当前视窗提取 PCM，近距离返回最多 8192 个原始采样点连续绘制，长时窗按画布宽度返回峰谷包络并保留单点尖峰。时间范围扩展至 1 ms–12 s，波形纵轴可自动或固定 ±1，刻度显示真实振幅，播放与导出样本不受显示比例影响。
- Qt 实际 Ctrl＋滚轮、双图时间一致、展开视图和深浅主题通过。解析夹具为振幅 0.004 的 150 Hz 加振幅 0.001 的 300 Hz，经过生产分析函数与父子页面端口，不向声卡发声。约 10.66 ms 窗口显示 511 个连续原始点，纵轴 ±0.005；1 ms 窗口恰为 48 点。两种纵轴切换通过。窄栏刻度随可用宽度减少，避免高精度时间标签重叠。
- 原三档原生采样、12 组显示几何与气腔等价性复查通过。下牙这项修复不改变原生 DLL、面积函数、方法号或交换版本。波形接口只新增显示视窗字段，不改变分析窗/步长语义。
