## 实现与原因

- 原生后卷舌尖根据抬高、前后关系及舌叶下降程度连续增加构造半径，最大增加 0.18 cm。舌叶接入点向后侧圆弧平滑过渡，避免曲线直接进入圆顶造成细颈。构造、限位与声管计算使用同一半径。报告构形 TTX=1.5、TTY=0.25、TCY=−2.1、TBX=2.6、TBY=−1.3，在 TTY 水平的正中尖端宽度由 R13 的 0.2201 cm 增至 0.7533 cm。这是同一模型构形的数值对比，不是人体尺寸标准。
- 舌叶圆点原先直接使用 TBX/TBY 曲线构造坐标。现在原生导出曲线中点对应的分数肋位，二维与三维均插值实际接触处理后的舌面。拖动按中点控制权重补偿增益，保持原 TBX/TBY 存储语义。碰到参数或组织限位时仍可能无法一比一跟随鼠标。
- 灰色窄片来自横截面拼接的气腔边界与陡峭舌面之间的差距。前部口腔剖面使用原生上下壁和内唇缘外边界，扣除当前舌体正中切面、牙齿及软腭，补足近似重建空隙。后部继续用原焊接口鼻参考，避免数学软腭连接边进入显示。三维气腔仍为横截面重建参考，面积与声音仍使用原生求交结果，不从二维着色推算。
- 默认纵向截面由 129 增至 257，横向 96 点不变。原生查询返回数量，Python 动态分配缓冲区，前端端点、初始位置、侧缘定位及动画/运行时相应适配。原生舌面拓扑、声学管段数量、构形及关键帧格式保留。

仅增大半径的早期候选仍出现 41–44° 局部尖折，未通过原有 <40° 回归，后改为后侧圆弧接入。截面密度变化后，旧闭塞/边通路测试原先以 129 档绝对下标选截面，已按原相对轴向位置换算下标，闭塞和侧通路断言保持。早期候选截图及失败日志保留，最终以上述目录为准。

## 129 / 257 实测

同一最终 R14 源码分别构建 129 与 257 档，7 个构形各 5 轮，先预热，关闭音频输出。计时包括原生表面、中线、截面、传递函数及 Python 快照整理，不含 Qt、进程传输及绘制。

| 指标 | 129 截面 | 257 截面 |
| --- | --- | --- |
| 原生快照中位耗时 | 28.25 ms | 38.00 ms |
| 第 95 百分位 | 30.01 ms | 39.53 ms |
| /a/ 轴向间距中位数 | 1.251 mm | 0.629 mm |
| /a/ 未压缩 JSON 大小 | 300016 字节 | 498539 字节 |

本机中位计算耗时增加约 34.5%。实际 Qt 四方向拖动的构形计算约 39.3–41.1 ms，不作为整条输入到屏幕延迟。对照两档的原生组织轮廓逐点相同；截面求积、中线与声管结果不同，七构形逐项面积/谱峰差异见[完整记录](../../output/validation/m10-r14/resolution-benchmark.json)。这项验证支持当前本机默认 257 档，不宣称比率适用于所有设备或医学精度翻倍。
