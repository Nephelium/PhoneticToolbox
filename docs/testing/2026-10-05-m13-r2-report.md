## 完成行为

- 输入框下方转换设置按钮已移除，设置栏始终显示，忽略旧折叠偏好。
- 重新创建页面时输入为空，标准默认 `Standard Chinese (Beijing)`。排版偏好可保留，原草稿不删除，顶部恢复按钮显式加载。未保存编辑时禁用恢复按钮，工作台标签切换不丢当前编辑。
- 汉字样式下方新增两种颜色与汉字字体下拉菜单，桌面直接读取既有本机字体列表。汉字字体只作用于结果汉字层，IPA 固定 Doulos SIL。
- 显示声调按钮默认开启，关闭时保留音段附加符号。多音读音窗口仍显示声调编号，供人工区分。开启/关闭对预览与 PNG 一致生效。
- 侧栏采用 6px 分组外距、滑条 18px 高、紧凑控件。小窗口保留设置栏滚动，实际桌面字体标签固定横向。
- PNG 保持白底，自选颜色和汉字字体精确采用，默认汉字墨迹适配白底。不存在的自定义字体报明确错误并保留文本。

## 查到的缺陷与修复

1. 旧草稿文本与标准自动读入：拆分启动偏好和完整草稿恢复。
2. 汉语拼音 `略` 显示为 `lvè`：先将字表键盘记法 v 规范为 ü，再添加声调，输出 `lüè`。隐藏声调时输出 `lüe`。
3. 文本修改后，多音选择仍按旧位置应用：选择跟随 Unicode 公共前缀/后缀，替换区选择清除。补充 emoji 前置和重复字边界。
4. 仅音标模式实际默认 28px，标签/滑条仍显示 16px：统一采用实际字号，显式用户字号保留。
5. 导出硬编码音标/汉字颜色：新增选择随显示快照导出。白底默认汉字继续深色，避免深色主题白字不可见。
6. 已加载内置 Doulos 与同名 CSS 字体并存，离线导出仍发起多余字体读取：在本模块导出中复用已加载 FontFace，未就绪仍加载和验证。旧 Chrome 流程复现失败，诊断记录同名字体同时有 loaded/error；修复后同流程通过。公共字体模块未修改。
7. 实际 Qt 完整字体列表使新增字体标签挤成竖排：覆盖组件根标签布局为横向标题、整宽下拉，加入 Chrome/Qt 几何断言并回看真实截图。
