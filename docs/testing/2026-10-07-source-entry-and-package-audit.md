## 已完成修改

1. 14 个 PowerShell 入口共用 `Start-Research-Workbench.ps1`，模块入口仅转发初始模块和参数。统一 Python 入口在应用导入前绑定当前 core/backend/desktop，子进程沿用相同项目源码；发现已载入旧项目包时明确失败。增加不打开窗口和数据库的 `-CheckOnly`，父终端环境变量保持原值。
2. 主环境采用现有 m14。实际 NumPy、SciPy、Pandas、OpenCV、Parselmouth、Qt 文件与 m09-ui 指向同一位置，核查的 448 个原生文件无替换；m14 增加当前 M14 所需 docx/xlrd。EGG/LPC 和唇形的第三方环境继续独立，不修改其库、原生构建或科学公式。
3. 原总入口此前可能读取 m09-ui 中旧的 phonetic_core，现已绑定工程源码。构建器此前复制源码后仍用工作目录进行依赖分析，现将脚本入口、分析搜索路径、隐藏模块收集与独立工作进程源文件统一到冻结快照；版本文件、来源登记、REAPER 和验收样例也先复制后收集。逐文件 SHA 清单及清单 SHA 保留，构建前后核对快照。
4. 排除旧版 `docs/manual` Markdown，以及 `contracts` 下开发说明/生成 TypeScript 声明。应用内书稿、引用素材、JSON 契约、运行元数据、版权通知、原生对应源码材料和成品自检保留。排除策略集中在 `release_content_policy.py`，构建输出排除清单。
5. 新增实际 EXE 的只读审计脚本，输出完整成员、压缩/展开体积、相同字节依赖、MFA 环境与旧安装项目代码候选。根规则、开发说明和发行规则已更新。

## 实际验证

证据目录：`output/validation/p19-source-entry-20261007/`。

- 原生身份：`host-runtime-comparison.json` 记录两主环境实际导入位置与 448 个原生文件的身份，没有安装或升级环境。
- 回归：使用 v3 的 `tests/pytest.ini` 和统一源码绑定执行 `desktop/tests`、后台源码绑定与最初入口/快照测试，299 passed、2 个平台条件 skipped，其中桌面 290 项、后台绑定 2 项、初始定向 7 项。补充父环境与资源保留用例后，最终 10 项定向检查通过，与前一组部分重叠。
- 入口：14 个脚本从另一目录运行 `-CheckOnly`，四个项目包均来自本工程。无效外部 PYTHONHOME/PYTHONPATH 不改变结果，父 PowerShell 的原变量保留。模拟旧包、已加载旧模块与缺失源码均按预期处理。
- 真实计算：`actual-3/report.json` 中 EGG/LPC 使用原有 MKL 环境，M05 使用原有唇形环境。通过实际固定 bootstrap/child，记录实际导入的 phonetic_core 和 ptb_worker 路径，均为当前工程；EGG/LPC 输出全体字节数及 SHA 回读、12 帧公开合成视频分析与唇形表格输出通过。
- 文档与 Qt：M14 真实生成并回读两 DOCX 和一 XLSX；Windows 原生 Qt 隐藏窗口验证 M14/M01/M05/M10/M16/M17 初始页、本地服务健康及实际声道进程启动，两个自有服务正常退出为 0。未关闭 GPU，未访问摄像头、录音或用户项目。
- 冻结机制：`snapshot-proof/result.json` 对一个合成最小程序实际调用 PyInstaller 并运行生成的测试 EXE。冻结之后修改原工程，测试 EXE 仍输出冻结时内容。该探针验证构建机制，不代表完整 PhoneticToolbox 已重新打包。

- 文档与语法：本轮 Python AST、启动脚本 UTF-8 无 BOM、相关 diff 空白检查通过。全库文档检查 1716 个文件，仍有 211 条历史缺链，其中归档 README 195 条、旧成品报告 16 条，本轮新增链接无错误。完整列表见 `docs-validation.json`，不宣称全库文档全绿。
