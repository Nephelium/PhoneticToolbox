## 分块、数值语义与内存

输入通过 1 MiB 流式传输和受控临时文件进入科学子进程。新的 RIFF/RIFX/RF64 读取器支持 PCM 8/16/24/32、FLOAT 32/64 和适用的扩展格式，不依赖科学环境中不存在的 SoundFile。全局扫描两声道峰值及线性趋势，随后按需读取样本，时间数组以虚拟索引生成。各声道始终使用全录音的峰值归一化至 0.7，块之间不会独立归一化。

全局滤波使用 20 秒块及重叠上下文，四阶 Butterworth SOS 双向滤波后仅保留所属块。上下文根据极点衰减至 `1e-10` 确定，至少 1 秒、最多 30 秒，缓存最多 3 块。极端无效滤波配置明确失败。全局事件按半开采样区间归属，避免块接缝重复记录。Praat 和 REAPER 分块使用 1 秒上下文，仍记录真实时间网格。

局部 CQ 的 ±100 ms 重复滤波、微观事件的 ±50 ms、微观波形的 ±100 ms 分别保留。长文件的这些局部滤波也使用 SOS。实际检查发现 96 kHz / 1 Hz 高通的旧直接多项式系数会产生异常幅度，新增回归确认长路径波形有限且有合理周期。短文件系数形式未改变，冻结回归保持通过。

实时 GCI F0 的异常值参考当前视野事件网格，完整导出参考全文件事件网格。边缘事件、分块 F0 与筛选结果可有差异，不宣称新长路径与旧整段算法逐位相等。局部 CQ、全局事件与微观图原本采用不同取窗规则，这些差异继续在来源元数据中记录。

完整三图的波形最多 4096 个 min/max 箱，PSD 最多 2048 个时间列按最大功率聚合。屏幕 PSD 栅格最多 1024×512。微观抽点、频谱抽点和图形压缩只用于显示，不用于完整 CSV 或 IF WAV。

实时会话缓存当前图面及最多 3 个 F0 视野。调整微观位置复用 CQ/PSD/F0，调整滤波复用音频 F0。完整 CSV 的数值轨迹及 pandas 外连接表仍驻留科学子进程，序列化尚未改为逐行流式，因此完整导出的内存高于实时交互。传输及原生保存采用分块。科学任务资源预算为 3,000,000,000 字节、1800 秒，上游截止 3600 秒。
