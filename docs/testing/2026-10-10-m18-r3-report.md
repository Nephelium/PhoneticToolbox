# M18-R3 论文库、自动检查和解读分发

状态：verified，范围为 Windows 当前源码、实际 Qt、隔离 Chrome、授权论文内容服务。最终 EXE 和其他平台不在本轮验证范围。

## 结果

- 自动获取偏好持久保存。每次应用启动检查一次，持续打开默认每 6 小时检查，可设 0.25–720 小时，关闭后停止后台检查和下载。Qt 宿主持有定时器，切换模块不重复启动。
- 往期按年份、月份筛选，显示中英文题名及悬浮双语摘要，单篇勾选和当前筛选全选，只下载勾选项。已完整获取项默认隐藏，主动显示时禁选。
- 推荐和个人 PDF 分开。个人库由原生窗口选定根文件夹，导入复制源文件，收藏夹为真实子文件夹，整理实际移动库内文件。拒绝同名覆盖、越界和联接，批注按内容摘要保留。推荐收藏关系独立存储。
- 左侧单行目录高度 34 CSS px。删除独立适宽按钮，保留缩放菜单的适宽选项。连续阅读使用累积页高及二分定位，附近最多五层文字，原生限两个文档、十二页或 48 MB 图像缓存，网络与阅读分开排队。
- 已有论文追加可选解读资产时保持稳定 ID，按 `updatedAt` 获取更新，跳过已校验 PDF；原译文已获取时不因解读缺失而无法阅读。
