# 全项目数值输入检查

2026-10-13，`P04-NUMERIC-INPUT` 为 `verified`，限定 Windows 当前源码与独立 Chrome 键盘输入。源任务为[语谱图小数输入](m09-decimal-input-report.md)，井井后续明确要求所有同类框避免吞小数点，并检查其他框。

## 发现与修复

| 路径 | 已验证原因与处理 |
| --- | --- |
| 公共时间精度指令 | 同值回写会清掉 Chromium 数字框内部的未完成小数。前轮修改改为只写实际变化的显示文本，覆盖所有使用该指令的页面。 |
| EGG 选区时长等延迟提交框 | 单向 value 绑定在无关刷新时覆盖编辑文字。修改前 EGG 时长逐键输入 `1.`、刷新、再输入 `2`，实际得到 `102`。改为 `v-model.lazy.number` 与原提交逻辑的可写计算值，真实外部变化仍同步。 |
| 发声类型合成的 F0 表 | 文字在每次输入后变成数字。单纯连续输入可以暂时成功，编辑中的对齐模式刷新则把 `150.25` 变成 `15025`。分别维护编辑文字与数值，保留光标与未完成小数；重新分析／替换控制点时同步文字，空白仍映射为0。 |
| 公共播放时间框 | 清空后 number 模型暂成空字符串，播放位置的 toFixed 显示抛异常。改为编辑期间保留本地文字，提交后才更新科研选区，沿用原选择归属、停止、限幅与排序逻辑。 |
| 提交后的限幅／整数值 | 新增 syncNumberInput，仅在提交后的显示值与接受的模型不同才回写，确保重复输入非法范围或需取整值时仍正确显示，编辑期间不调用。 |

延迟提交统一涉及公共播放条、背景模糊／透明度、EGG 时长、参数显示时间窗、标注唇形偏移、国际音标字号、MFA Beam、PDF 页码与录音帧选区。F0 表单独保留文字草稿。单位、默认值、后端契约和计算方法未变。

## 核查与验证

`node tests/e2e/numeric-inputs.cjs` 解析当前 Vue 模板，登记27份文件中的96处数值输入声明（87处 number、9处数值／时间 text 声明，排除滑块）。动态列表每个声明只计一次，F0 表的重复行另外在实际页面检查。原生声道页面源码核查确认可打字的数值框为动态生成的关键帧时长，其余数值操控使用滑块；实际原生关键帧输入也纳入回归。纯文字数值入口如合成范围与曲线覆盖、变速变调频率列表保留现有文字草稿／显式应用路径。Vue 数字框不得回退成没有编辑模型的单向 value 绑定，脚本对此作静态断言。

- Windows 独立 Chrome 两种主题256项检查通过，涉及23个 Vue 页面／组件视图与原生关键帧。逐键输入小数、中途无关刷新、删除重输、文字框中间插入、源／目标 F0 草稿数值保存、空白／非法 F0 拒绝、范围限幅和字号取整通过。播放条验证编辑空白不进入科研状态，聚焦时真实外部更新能显示且保留源数值精度。全部视图有实际启用数值框，未跳过。
- `npm --prefix frontend test`：397项通过，0失败、0跳过。新增提交显示检查核验相同文本不回写；现有音频归属、F0／MFA／录音／IPA、时间精度等回归保持。
- `npm --prefix frontend run typecheck`、`contracts:check`、`ui-data:check`、`build` 通过。构建保留原大块体积提示。
- `node tests/e2e/time-precision.cjs`：公共时间与原生关键帧的既有4组回归通过。`node tests/e2e/m09-decimal-input.cjs`：语谱图原问题浅深10组通过。
- F0 表浅深截图已核查；这些是合成控制点与输入校验状态，用于检查输入行为，不用作科学分析结果。
- `python -B -X utf8 scripts/validate_docs.py`：2027文件／427来源／109任务，errors为空；既有历史快照链接单列。定向差异检查与新增浏览器脚本语法检查通过。

## 边界与收尾

所有媒体、控制点、录音条目及 PDF 页面均为内存合成夹具。部分页面以测试专用模型注入显示数据依赖的字段，论文渲染为内存 channel；没有访问用户语料、数据库、硬件录音或科学重建。首次录音夹具漏了 started_at，导致渲染失败，补齐原类型字段后通过。脚本关闭自有浏览器与服务，再按清单清理 scratch，失败证据保留。

PDF 合成夹具在两种主题中有 ResizeObserver 通知循环诊断，Vite 有输出，数值输入与校验断言通过。该布局诊断未作为输入修复隐藏或修改，也不把输入回归扩大为 PDF 布局验收。实际 Qt、最终 EXE、IME 组合输入、实体键盘／DPI、跨平台及科学任务本轮未验，未重打包、发布或推送。
