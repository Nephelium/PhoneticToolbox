# M16-R3 录音模块打磨验收

2026-10-04。状态：verified，限定 Windows 开发态、合成采集设备与本轮列出的功能。完整录音硬件/平台状态不扩大。

## 交付

1. 删除顶部任务清单按钮，任务侧栏保持可见。删除任务入口置于新增/编辑/复制旁，立即保存、切换相邻任务；失败保留草稿，录音、历史版本和任务快照继续保留。新任务/复制任务清空上一条录音显示，自动编号避开已有录音快照的编号。
2. 导入入口先说明用途、CSV/TSV/XLSX/JSON 格式、中文列名、必需字段、编号与文件名规则，并提供 UTF-8 CSV 示例下载。预览映射使用中文字段名。
3. 提示卡右侧依次放录音、停止、播放、下一条、跳过。录音按钮突出，播放按钮有强调色，试听版本与声道有独立明确标签。
4. 剪切至恢复原始的工具放在清空选区后，小窗口换行。双声道第 1/2 输入称左声道/右声道，EGG/其他角色额外标注。复选框 14×14 CSS px，数值输入不再覆盖复选框尺寸。
5. 降噪区说明先选背景噪声，再将选区设为噪声样本，再对勾选声道整段降噪。增益明确保存新版本。角色未变时保留用户勾选状态。后台进度为 4 px 细线，无底部文字，× 取消入口保留无障碍名称。
6. 修复录后只计算窗口前 2 秒的语谱。完整可见时间窗与波形对齐，0–5000 Hz，谱图可同步拖选，非零起点放大范围正确。原始采样、EDL、降噪与增益算法均未修改。
7. 修复窄窗导出结果挤占状态行，以及停止录前检测后仍显示未保存检测波形。Qt 提示文字增加底部字形留白，消除单行文本 1 px 溢出滚动条。清空/切换到无录音任务会使旧预览响应失效；关闭检查等待所有在途预览结束。

源码入口：[Start-M16-M17-Workbench.ps1](../../scripts/Start-M16-M17-Workbench.ps1)。本轮前端构建已更新，旧 EXE 未重新打包。

## 失败记录与修正

- 新增谱图覆盖回归先在旧实现失败：11 秒输入只返回 96000 帧显示谱。最终覆盖完整 528000 帧，非零起点/短片段另验。
- 初次实现将实时列数一并提升，原有最多 128 列回归失败。最终实时仍为 128，录后最多 640；原测试上限未放宽。
- Qt 首次扩展检查返回 DOM 元素，Qt JavaScript 回调不能直接序列化该对象，导致等待超时；页面已存在。改为明确布尔断言后通过，失败证据保留在 `qt-r3-1563d2baf9ad4647adfff4648b94db71`。
- 一次 Chrome 复跑被同期其他模块文件变化引发的 Vite 热重载打断，设备选择重置。只在本轮独立测试服务器关闭文件监听，复跑最终通过；产品代码和其他开发服务器不变，失败目录 `chrome-fad25ea932844aae8273ae54644aa4cd` 保留。
- Qt 离屏输出保留 GPU context 回退日志，最终功能/几何/截图通过，不将其称为实体 GPU 验收。

## 显示方法与剩余边界

显示谱使用已有 NumPy/SciPy：1024 帧周期 Hann，每个时间单元取中心窗，边界补零，实际 FFT 频率至 5000 Hz。实时最多 128 列，录后最多 640 列，谱窗缓存上限 2.5 MiB，不随录音长度增长。频率低于 10 kHz 的采样率只显示至奈奎斯特频率。长窗口时间抽样可能遗漏短事件，界面提示放大查看；此图不作为完整逐 hop 科学输出。没有新增第三方依赖或来源许可。

所有本轮输入为隔离合成信号，未读取或改写井井真实录音/论文资料。未测试实体声卡、麦克风、EGG 接线、物理音频听感、实体 DPI、多屏、Linux GUI 或 60 分钟墙钟。没有 DDL、环境安装、EXE、push、公开发布或删除用户文件。工作前已有的 recording service 后台发布修复及页面统一侧栏差异保留，同期其他模块改动未归入本轮。
