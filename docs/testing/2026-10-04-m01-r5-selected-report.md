# M01-R5：分析选中文件

2026-10-04。限定Windows开发态 verified。井井要求在“开始全列表分析”下方增加“分析选中文件”。入口仍为[源码工作台](../../scripts/Start-M01-M02-Workbench.ps1)，本轮未打EXE。

## 改动

- 第二个按钮只提交左侧复选框勾选的音频，未勾选时禁用，点击文件名试听不会代替勾选。
- 已选文件按当前列表顺序提交。复用原任务提交、参数快照、关联文件、EGG逐文件声道覆盖及保存流程，声道覆盖随本次子列表重新编号。
- 原全列表按钮仍处理全部音频。复选框继续支持TextGrid切分，说明和无障碍名称更新为通用选择音频。
- 两个按钮全宽上下排列，任务栏显示勾选数量。科学算法、任务契约与保存格式未改变。
