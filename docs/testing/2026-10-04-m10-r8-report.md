# M10-R8 可读字号、紧凑参数与固定截面比例

2026-10-04。**verified，限定 Windows 源码工作台、原生引擎与独立测试配置。** 本轮没有重打 EXE。

## 本轮行为

- M10 控制文字、按钮、提示和 canvas 图表标注采用 12 CSS px 下限，参数主标签默认 14 px，现有正文/图表字号设置仍可放大。最低值仅适用于 M10，未修改全局偏好范围。模型 SVG 的原生几何及观察缩放保留。
- 参数标签到滑条的行间距为 2 px，参数网格行间距为 4 px，滑条容器高度从输入框的 30 px 收紧为 18 px。缩小分组、复选标签、唇部正面图与提示周围留白，较大字号标签可换行。
- 横截面使用固定 7 × 7 cm 视野、原生厘米原点及横纵等比例变换。缩放只依赖图窗尺寸，标尺始终为 1 cm；同一图窗下切换构形、截面、修改参数或显示空截面均不自动适配轮廓大小。
- 截面说明固定占两行高度，较长说明可滚动，不挤压图窗。截面 canvas 和 SVG 拖动层共用完整绘图区尺寸，修复原 120 px canvas 与较高 SVG 层的错位。
- 短窄窗的大字号图表标题/共振峰允许换行，横轴末端文字向内对齐，避免加大字号后跨列或被裁切。

原生横向采样坐标沿用既有 `7/96` 映射，未改变轮廓数组、科学计算、源参数或本机构形文件。`packages/phonetic_core/src/phonetic_core/vocal_tract`、桌面原生声道代码、模型资源和 `scene.js` 无差异。无新增第三方来源。
