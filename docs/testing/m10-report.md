## 基准与来源

VTL 2.4 API/Analysis DLL 原样保留，二者 SHA-256 均为 `caaab296b4c2362ada1a5d94aaffe6c1804b3ed8279c04427bcca1ac348e2407`。原生几何桥接为 `m10/2`，SHA-256 `3a3bb343af6671cd786b46de67d499f3d8c72264ff2320f1a4877af5760406b2`。原始 API 源码压缩包 SHA-256 `aa696bf4cf5c44cbd433304943aebb241e5ea3064b949daf5ea09f96567cff9b`。桥接、显示读数补丁、源码、许可、MSVC 重建说明均随资源保存。

关闭新增侧通路拟合后，旧 JD2 的 lateral/fricative/closure 三个最窄面积分别回归 0.20、0.15、0.0001 cm²。最后一项是数值面积下限。无振动、800 Pa、48 kHz 合成一秒后，以末 20000 样本计算闭塞 RMS，基准约 3.5e-11。启用拟合后，以实际横截面与声学面积联合验证；不把光滑显示轮廓当成精确解剖或人类感知证据。

实际 VTL 2.4 侧缘实现与 2.3 参考手册的负向面积数值有差异，按本地 2.4 C++ 分别记录。Three.js 0.180.0、CC0 头壳、Brüning 等平均鼻腔 v4 CC BY 4.0 继续分别署名。统一登记含 324 条来源；M10 只更新对应路径与适配说明。当前为本地验证产物，未解决的全项目再分发事项不因本轮标为通过。
