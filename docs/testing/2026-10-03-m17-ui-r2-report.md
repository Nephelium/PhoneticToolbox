# M17 UI R2：扩展基础表与统一字号

日期：2026-10-03。状态：**verified，限定 Windows 开发态实际 Chrome、下列检查与截图**。Qt/冻结 EXE 由同轮统筹和桌面子任务分别验收，本报告不提前代替其结论。

## 实现

- IPA 只保留 `base` 基础图表与 `marks` 附加符号与韵律两个视图。基础图表接来源代理生成的14部位×13发音方式 `extended` 矩阵，包含肺部、非肺部和原107个补充组合入口。现有符号按同一发音方式与部位排列，未将两张旧卡片简单堆到页尾。
- 基础页含 `extended` 186入口、`vowels` 28入口、`extras` 9入口，共223入口。其余128入口在附加符号与韵律页。每个IPA入口仅出现一次。所有三表总625入口不增删，组合示例保持浅色。`extras` 放置跨部位构音、喷音号及连音线等未强行放入单一格的输入。矩阵空格不宣称该构音不可能，分类与中文来源详见同轮来源报告。
- 1366×768：矩阵使用表区整行宽度，元音与其他符号在下一排，可纵向滚动。1920×1080：矩阵在左，元音和其他符号在右。编辑框及编辑操作始终固定在表区下面。字号较大时允许表区二维滚动，不裁剪符号或删入口凑单屏。
- 顶部唯一“字号”控件范围18–54，编辑框默认26px，普通表项默认20px，独立完整例示和特殊长模板保留较小层级。原默认分别28/22px，均约减2px。一个控件同步改变表内所有音标与编辑框，名称及解释字号保持稳定。底部重复字号控件已移除。
- 草稿增加可选 `textSizeVersion:1`。旧草稿的默认28迁移为26，旧版非默认34等选择保留；用户在新版主动选择28后再次打开仍为28。输入超范围时有界截取，空输入恢复26。草稿存储沿用原IndexedDB结构，无数据库schema变更。
- `copyAll` 调用平台 `copyText`，使用桌面子任务提供的原生剪贴板桥。网页继续使用浏览器剪贴板；失败时保留原文字、全选并提示手工复制。
- 附加符号维持名称+符号多列，名称简释悬浮，符号完整介绍悬浮。54px测试发现长重音例词及extIPA节奏模板超过按钮，已按字素自然换行，保留全部输入字符。
