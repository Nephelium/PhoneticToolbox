# M04 纵轴、语谱图刷新与统一播放栏修复

日期：2026-10-04。状态：**verified，限定 Windows 开发态及下表范围**。需求与边界见[本轮计划](../plans/2026-10-04-m04-display.md)，使用说明见[LPC 谱图](../manual/lpc-spectrum.md)。

## 完成内容

1. 删除左栏动态纵轴复选框，在频谱图下按适合频率范围、动态纵轴、固定纵轴排列按钮，选中模式使用 `aria-pressed` 和高亮。两种纵轴即时使用当前1024点谱值，切换不创建分析任务。固定轴采用左栏 dB 数值，动态轴沿用频率范围内最小/最大值各留5dB规则，恢复固定模式保留原手动值。
2. 独立保存 PNG 以及网页单独 PNG 下载使用保存点击时的纵轴。复用已有字体、SVG转canvas和PNG pHYs工具，固定2400×1350、300DPI、白底黑线、完整任务频率范围和任务字体快照，不受当前水平缩放或主题影响。导出不改谱值、JSON或历史任务文件。完整结果目录继续保存任务生成时的PNG/WAV/JSON，界面及手册明确该区别。
3. 原左栏时间范围、播放选区和停止移入底部，与参数估计复用同一 `AudioTransport` 及公共样式。包含时间选区、起点/终点秒、全部、播放选区/暂停、停止、播放进度、音量。移除清除选区按钮。窄窗仅滚动工作区，播放栏保持可见。
4. LPC预览加载器随文件改变，捕获对应源文件，避免同长度文件切换后保留旧预览。公共语谱图以实际100–1000像素请求宽度去重，旧计时器在新请求接管时清理，绘图前再次复核请求版本。canvas在加载/错误时保持布局占位并隐藏内容，状态和错误覆盖其上方，保留各模块已有高度，提示行也保持占位。
5. 已加载原音频时，共用原音频绝对秒数与试听声道。仅打开历史结果且未加载原音频时，保留任务单声道片段及相对时间试听，不因此开放新分析提交。

## 问题定位与结论边界

原纵轴绑定任务 `spectrum.amp_min_db/amp_max_db`，保存入口读取任务旧PNG，界面切换无法即时影响结果。现已将显示边界独立出来，并从已有谱值生成当前纵轴PNG；LPC科学计算未更改。

语谱图原有实现中，源文件不在LPC加载器的响应式身份内，旧异步请求及待触发计时器可交错，加载态与数据态布局也不同。本轮修复这些刷新风险，实际Praat预览通过连续改窗、迟到结果、忙碌重试、失败恢复与同长度文件切换验证。普通输入起终点的初始诊断没有逐步复现用户截图中的持续等待，因此不将上述风险宣称为该截图现场的唯一根因。测试语料为合成短音频，未读取截图所示用户WAV，也未扫描论文目录。

本轮未构建EXE、push、发布、部署、删除旧包、安装依赖或修改现存库schema。科学算法、任务协议、V2与用户原数据保持不变。原有同期公共布局、字体、主题、M01/M02/M03及其他改动保留。未验实体声卡、实际DPI、用户截图WAV完整复现、Linux GUI或生产网页。源码入口为 `scripts/Start-M04-Workbench.ps1`，既有EXE仍为原版本。
