# M17-R3：介绍避让、播放接口与源码内容维护

日期：2026-10-05。状态：verified，限定 Windows 源码、实际 Chrome、隐藏原生 Qt 与静态前端构建。具体声道动画为 planned，未打 EXE 或部署网页。

## 实现与范围

- 悬停介绍跟随当前符号及鼠标位置。先左右避让，侧向空间不足时改为上下放置，按实际高度及可视边界限制尺寸。符号和指针保持可见，浮窗可移入阅读、滚动。快速离开再返回也保留正确的延迟状态。
- 介绍中删除聊天图4编号、用户指定和名称取舍过程说明，保留科学解释、码位和简短图表引用。IPA 下方两组冗长中文依据段落不再出现在弹窗；完整书目及页码仍留在来源数据与来源入口。生成脚本同步修正，625 个稳定 ID、输入字符、目录和字体保留。
- 顶部点击播放默认关闭。开启时鼠标和 Enter 只激活演示，不插入或替换文字。原生 Qt 挂载面板曾使 textarea 选区重置，已补充无抢焦点的选区恢复。没有素材、文件失败及缺少动画渲染器均明确反馈，不回退输入。
- 支持独立音频、视频、音视频组合及可注册实时动画配置。音视频共同请求播放，配置单独音轨时视频静音。关闭、切换或离开模块会中止播放和渲染。动画只留接口，无具体声道动画或新科学结果。
- 内容覆盖保存为 `frontend/src/modules/ipa-plus/data/symbol-content.json`。专用维护工具选择625入口并编辑文本、媒体相对路径和动画配置，实际写入源码文件。工具只在单独启动的本机 Vite 服务中提供，回环地址、会话凭据、同源和格式校验、版本冲突保护均验证。普通产品构建不包含维护页面与写入服务。
