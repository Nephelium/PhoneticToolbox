# P19-R3 全局按钮外观与重要操作

状态：verified，限定 Windows 开发态、独立 Chrome 与实际 Qt 离屏宿主。井井要求左右栏按钮增加轻微光效和阴影，补齐重要操作的纯色高亮，并提供特效开关及全部高亮／全部普通设置。

## 完成内容

- 默认按重要性高亮，轻微特效开启。按钮采用小阴影、顶部内缘及悬停光晕，不改变尺寸和位置。纯色高亮使用当前配色的 accent/on-accent，无渐变填充。
- 设置外观栏新增按钮高亮三选一：按重要性高亮、全部高亮（纯色）、全部普通。按钮阴影与悬停光效独立开关，两项立即生效并在本机保存。保存失败提示当前生效但未持久保存。
- 17模块按[计划中的逐模块清单](../plans/2026-10-04-p19-r3-buttons.md)核对，在20份页面／组件文件中补充92个按钮标签的 primary 标记。保留既有标记；此次补充数不能当作全部重要按钮总数。帮助、刷新、清空、删除、取消与一般微调默认普通。
- 全部普通仍保留选中态与键盘焦点。全部高亮时选中态增加内缘轮廓。声道持续发声的 active 标记保留。禁用按钮无阴影。关闭特效去除阴影、光晕、明暗滤镜和过渡，减少动态效果时也不使用过渡。
- 全工作台使用 `frontend/src/design/buttons.css`，声道 iframe 通过现有主题桥接收同一CSS与外观偏好，已打开的声道页面会同步变更。原科研算法、任务处理和操作事件不改。
