# P10-R1 说明书高亮与三级目录跟随

2026-10-06。状态：verified，限定 Windows 源码、当前前端构建、独立 Chrome 与实际隐藏 Qt 的本轮阅读交互。现有 EXE、服务器文件未更新。

## 变化与原因

旧阅读器会把滚动位置更新到三级或更深标题，目录只渲染二级标题，导致目录没有对应高亮项。本轮用同一阅读节点解析所属二级与三级标题。

- 默认显示全书一级和二级标题。点击二级标题展开它下面的三级标题，点击另一组或跨章后收起旧组。上下滚动按正文阅读位置自动切换展开组。
- 所在章节及二级标题持续高亮，当前三级标题同时高亮。更深标题、搜索命中的段落、表格及交叉引用归入对应祖先。目录只在当前项离开可见范围时调整自身滚动位置。
- 点击跳转保留明确目标，避免短小节或章节末尾的滚动夹限覆盖选择。正文滚动按动画帧合并，正文尺寸变化后更新阅读位置。切回说明书优先恢复保存的 scrollTop，再计算目录位置。
- 缺失目标显示原提示并回到章首。快速跨章、迟到加载、失败章、空章继续沿用已有加载与取消边界。

代码：[阅读器](../../frontend/src/manual/ManualReader.vue)、[层级及阅读线状态](../../frontend/src/manual/navigation.ts)、[目录样式](../../frontend/src/manual/manual.css)、[回归测试](../../frontend/tests/manual-reader.test.ts)、[默认渲染检查](../../frontend/tests/manual-reader-render.test.ts)。

结构化说明书工程、冻结正文、搜索索引、素材、章节编号规则、播放租约、宿主及科研模块均无本轮编辑。无新依赖或外部来源材料。
