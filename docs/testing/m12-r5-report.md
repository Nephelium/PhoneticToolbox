## 用户请求

- 删除截图中的框选/微调工具行、重复选区读数及音频总览按钮行。微调步长移到右侧，Shift 框选和方向键保留。时间窗滑块、音量及已有导航保留。
- 强度输入框与波形/语谱/标注层选区双向同步，保留完整内部精度，选区下方显示六位小数。窄选区合并显示以避免两个标签重叠。
- 波形直接拖动词/音素边界，重合时优先音节。普通拖动移动公共边界，Ctrl 拖动按方向拉开一侧并插入空白区间，音节对应音素外边界同步，整个手势可一步撤销。
- 5/10/20/50/100 ms 语谱 Hann 窗，默认 20 ms。窗口按实际采样率取样，FFT 补零到二次幂。1024 点兼容选项保留，原 30 ms 相对强度显示保持。
- 波形、语谱、标注两行的空白音节位置均可双击新建，支持跨窗起终点。音素内部双击仍按原切分流程处理。
- Backspace 优先合并选中边界，无边界选择时保留清空区间文本。输入框正常退格。
- 重新打开优先加载同名原始 `.TextGrid`，不存在时才回退 `_自动保存.TextGrid`。恢复副本保留且可手选；手动覆盖原文件后实测重新加载其保存内容。

## 聚焦审查与修复

| 发现 | 原因与修复 | 证据 |
| --- | --- | --- |
| 强度起止框与选区不同 | 波形拖选更新输入框，标注选择只更新 wave；统一同步路径，并让手动数值输入更新 wave | Chrome 精确输入 0.345678/0.765432，与三图读数相等 |
| 音节与音素外边界可能错位 | 音节先移动，音素因越过内部边界拒绝移动；现在两者使用共同合法范围 | 1 秒公共边界往 1.5 秒拖动，在音素 1.2 秒内部边界前共同停于 1.199999 秒 |
| 页面缩放后边界命中偏移 | 只乘 devicePixelRatio 未覆盖 CSS zoom；改用实际显示矩形与画布尺寸换算 | 单元测试及 Chrome 150% 实际拖动保存回读 |
| 反向框选到 0 秒丢失范围 | `endTime || startTime` 把零当缺失；改用空值合并 | 从 1.5 秒到 0 秒选择两段的回归用例 |
| 合并后旧多选索引残留 | 删除边界改变数组索引却未清空 selectedIndices；合并时清理 | 代码检查及删除/撤销保存回读 |

第一次 Chrome 检查发现 Vue 数值输入会把 v-model 值转成 number，新增范围验证直接调用 trim 导致异常。已对输入显式 String 转换，修复后全流程通过。初次失败证据保留在 `output/validation/m12-ui/eaa75c56c75d448f9bb3302cf1706bcb`。
