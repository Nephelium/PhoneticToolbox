# M10-R6 音标构形库与右栏滚动

2026-10-04。**verified，限定 Windows 源码工作台、原生引擎与独立测试配置。** 本轮没有重打 EXE。

## 本轮行为

- 保存构形直接弹出紧凑元辅音表，点击音标保存当前构形、唇宽、舌根模式、完整声源设置与 F0。同一音标再次保存更新对应条目。
- 自存构形改为按钮，点击打开同一表，已保存音标带标记，未保存音标禁用，点击已存项恢复构形、清浊/耳语模式、声源参数和 F0。
- 直接复用 M17 国际音标 Plus 目录的中文名与图形位置，包含 107 个基本元辅音。用于连写的单独附加记号不作为独立构形键。Doulos 字体保持固定。
- 旧的裸音标、斜线与方括号名称可以在表中加载，其他名称保留在展开区。没有声源字段的历史条目保持当前声源。
- 删除独立顶栏与页脚，模型与来源并入参数控制标题，原自动/两列/三列选择移入来源窗口。
- 器官、声音、关键帧页签独立纵向滚动，修复内部 `overflow:hidden` 导致内容不可达。主模型与声学图不随右栏滚动。

原 `presets.json` version 1 已支持全部声源字段，此次只修复保存交互和加载行为，不变更持久化格式。VTL 科学核心、模型资源和 `scene.js` 本轮无差异。来源登记为已有 IPA 表、中文表与手册增加 M10 使用关系。
