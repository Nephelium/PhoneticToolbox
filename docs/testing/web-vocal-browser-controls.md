## 当前交付

服务器已部署 `web-browser-vocal-20261018-c5`，前端修订为 `public-c5-browser-vocal-recovery`。1979 项发布文件、765 项科学运行库摘要与九类科学准入回执均通过核对。运行时 SHA256 为 `48e5a60ac2f55fe641f6a55cf12623ca8b5612d9f482f44edbf514d9a2ea39d1`。旧 c3/r5、c4 与配置回退保留。沿用此前公开测试入口及注册/找回密码状态，没有数据库迁移、GitHub 推送或 EXE 重打。

浏览器复用既有 VTL 2.4、m10/r18 几何与 Python 状态机。默认65截面，支持33/65/129/257、持续发声及总计12秒关键帧。普通帧0.05–3秒、送气帧0.01–3秒，0.5秒测试保留。只有 MP4 编码继续交给有界服务器进程。首次运行组件不可用才回退原服务器计算，其33/65、0.5秒固定姿态及5秒科学序列限制保持，视频编码独立允许12秒。

蓝色 F0/Hz 与橙色驱动气压/Pa 分别绘制和撤销。气压直接作用声源，静音保持静音，送气段可调气压。jitter/shimmer 是独立的0–100强度，保留模型默认音色，修改后使用可保存种子在声源内产生微扰，不能解释为分析模块测量的百分比。无新增控制继续导出5版，含气压曲线或自定义微扰写6版，1–5版继续读取。科研含义及兼容方式已获井井确认，详见[ADR](../decisions/ADR-M10-pressure-perturbation.md)。

## 优化和科研检查

参考 [Pink Trombone 官方实现](https://dood.al/pinktrombone/) 的音频与界面分离、小块流式处理思路，没有复制其声道算法或代码。PCM 请求优先于排队的只读显示，浏览器流式音频提前量为0.24秒。只改变F0/气压时使用 source/update；查看截面在已有几何上完成。拖动保留最新待处理姿态。短音频停止保留已初始化引擎，长渲染取消则销毁 Worker 并恢复已确认编辑。

动画只复用完全相同的相邻几何输入，没有对近似姿态取整。独立冻结前后对照如下，PCM、试听PCM、时间轴与科学画面数据完全相同，比较排除计算耗时字段。
