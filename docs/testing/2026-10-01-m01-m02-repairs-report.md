# M01/M02-R1 试用反馈修复记录

2026-10-01。范围：参数估计、参数显示，以及两者使用的文件能力、分栏与切分核心。实现完成；下述 Windows 真实录音工作流 verified，真实大文件性能和跨平台范围仍待验。源码入口为 [Start-M01-M02-Workbench.ps1](../../scripts/Start-M01-M02-Workbench.ps1)。本轮未更新 EXE。

## 实现及根因

| 反馈 | 根因与修复 |
| --- | --- |
| 文件列表拖长页面 | M01 原三栏共同溢出时切换到整页滚动。移除该分支，两页面音频列表受工作区约束，内容在列内滚动；窄窗仍可纵向排布。 |
| 分析过程中按钮区域抽动 | 后台轮询每次都设置用户操作 busy，插入提示并禁用按钮。轮询使用独立请求状态和代次，实际操作提示预留高度，迟到结果不能覆盖新选择。 |
| 读取子文件夹 | 默认关闭的递归选项应用于音频和关联目录；显示相对路径、按路径关联。复用平台目录能力，链接、条目/目录预算和文件失效检查保留。递归同源保存按提交时来源目录分别写入。 |
| TextGrid 切分全部失败 | 实际 WAV 约数秒，TextGrid 空白末段可延伸到约10秒。旧代码在忽略空白前检查音频上界，拒绝整层。现在仍校验全层的有限/正向/按序/不重叠，但只对实际输出标签检查 WAV 上界。带标签越界仍失败，无裁剪、平移或采样规则变化。 |
| 管理图窗 | 清空指定图窗保留空窗；删除图窗移除该窗及曲线分配，其他图窗不变。保留合并行为，最后一个窗可删除、保存零窗配置、随后新建。 |
| 当前图默认 SVG | 默认300dpi PNG，SVG 在格式选择中显式指定。整幅 PNG 保留波形/语谱/标注/参数组合。 |
| 大 WAV 不能预览 | 两模块显式使用桌面分块转换能力。保留完整时间轴、全部声道、原 SHA256，按需生成有界轻量预览。预览格式直接显示，计算/切分仍读取原文件。仅缓存一份字节，切换模块后可以重建已授权的预览，访问前重新检查源身份。 |

架构方向保持共享前端 → 平台能力 → 本地服务/科学核心，前端不接触任意文件路径，切分规则位于纯核心。复用既有 SoundFile/SciPy，未增加依赖或修改科学参数默认值。决策见 [ADR-M01-M02-R1](../decisions/ADR-M01-M02-R1.md)。

## 诊断、限制与交付边界

早期隐藏Qt检查曾在刷新期间点击disabled文件按钮导致探针超时，已修正为等待可操作状态。后续真实录音探针调低通用文件预算时也限制了参数表读取，已将测试注入限定于预览转换；M01文件按钮包含文件元数据，探针改为匹配文件名部分。截图增加绘制等待，避免将过渡帧作为视觉结果。这些失败记录保留，不记为成功验收。Qt离屏日志含现有libpng profile/GLES fallback警告，限定该验证环境，不冒充声卡或GPU设备验收。

桌面长预览源 WAV 最大2GB、8–96kHz、最多8声道，派生预览64MB/3200万采样值，最低8kHz仍超预算时提示分段。轻量预览的试听与语谱图可能经过降采样/16位量化；原始科研输入不被替换。切分和科学任务原有预算不随预览放宽。网页大文件预览仍沿用服务器64MB能力限制。

WSL NInfer 无 Python/Node，Linux科学/界面运行尚未验证；macOS、实际远程服务器和冻结EXE均未验。当前共享工作树存在P04/M03/M04/M13/P16同期修改，本轮保留原差异，未提交、push、修改V2/环境/CI、执行数据库迁移或公开发布。
