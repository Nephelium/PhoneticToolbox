## 修复原因与实现

- R12 用辅助点求切线后，直接将控制点下压，使舌叶曲线的端点方向失去相切关系。R13 的下压曲线采用五次 Bézier，端点方向与舌背椭圆、舌尖圆衔接，内部点承担下压控制。另将辅助点的舌尖高度改为稳定圆顶，消除控制横坐标进入构造圆时的平方根斜率突变。
- 等弧长分配的 33 条动态肋线，在后卷圆头处只剩少量采样。R13 保留原生拓扑，抬高舌尖时根据弧长和转角分配肋线，目标圆弧由 8 点加密至 32 点。末端及显示舌腹按进入方向回接。此变更作用于真实原生表面，声管随之重算。
- 软腭背侧原先在到达腭咽口之前就向硬腭转弯，与口鼻连接面之间形成假凹口。现在使用两段相切曲线，经腭咽口前缘再接硬腭。二维遮罩来自同一三维软腭剖面，原生小舌形状、原始鼻腔网格与鼻腔声学参数保留。
- 牙齿刚性、显示舌腹避让、声门点常驻及已有保存格式保留。新增[上下文补丁](../../resources/vocal_tract/sources/m10_r13_patch.py)，通过[原构建入口](../../scripts/build_m10_geometry.py)重建，原版 API DLL、speaker 与锁定 VTL 源码压缩包未修改。来源说明仍按 GPL-3.0-or-later 保留。
