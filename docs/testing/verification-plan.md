# 验证与科研回归策略

本页维护验证方法，任务是否通过查对应报告和[台账](../plans/task-ledger.json)。按改动影响选最窄必要检查，阶段门再做集成/发行验收，不因文档出现命令就声称已运行。

## 基准与数据

产品 EXE 身份、源码快照身份和独立科研数值基准分别记录。预期来自固定输入、参数、环境下的 v2/上游结果或解析公式，不能让 v3 生成自己的 expected。私有语料只读且不提交，记录保存在忽略的本机证据目录。

优先公开合成或获许可的最小 fixture。覆盖持续元音、清浊/静音、嘎裂/气声、双声道 EGG、TextGrid、多声道/采样率、短/空/损坏文件、长录音/批次、合成连续统、音系表格、唇形视频、声道关键帧、MFA 模型/词典、实验刺激/种子及 Unicode/IPA。

临时生成或复制的 WAV、长音频和完整测试工程用后清理，保留生成条件、摘要和结论；原始录音、正式说明书素材及活动任务不删除。测试数据库与运行副本只有确认归属且停止后才清理，不能将整个 output/validation 当作可删目录。

新增或维护验证脚本时采用[测试产物生命周期](../development/artifact-lifecycle.md)，把可再生对象放 scratch，finally 关闭自有进程后清理。检查 cleanup.json 的 deleted/retained，清理失败不得省略。

## 检查入口

Python 命令使用该模块已验证的解释器和测试配置，环境见[源码入口](../development/source-entry.md)。

| 影响范围 | 定向入口 |
| --- | --- |
| 科学算法/模型 | packages/phonetic_core/tests、tests/parity |
| 接口/任务/配额/文件 | backend/tests、tests/contracts、tests/security |
| 桌面桥/设备/生命周期 | desktop/tests 及相关实际 Qt 脚本 |
| 前端 | frontend 的 typecheck、相关 test、ui-data:check、contracts:check、build |
| 实际交互 | tests/e2e 与 scripts 下对应 launcher；不假设存在 test:e2e 命令 |
| 架构 | scripts/check_architecture.py、tests/architecture |
| 文档与来源 | scripts/validate_docs.py、frontend 的 ui-data:check |
| 最终 Windows 成品 | [严格打包规则](../../release/PACKAGING_RULES.md) |

检查脚本可能启动服务、生成大文件或写测试库，运行前核对范围。失败记录根因，既有问题单列，不能删除断言或用 mock 代替实际原生链路。

## 科研比较

- 固定版本、参数和输入，比较 shape、时间数组、有效/缺失 mask、单位、参数键与顺序。各模块已冻结的精确比较或容差优先，不能降低已有门槛。
- 未建立专门基准时，纯数组迁移可从 rtol=1e-7、atol=1e-10 起评估，PCM16 量化从最多 1 LSB 起评估；浮点、随机生成和原生跨平台输出须另定有依据的精度/seed 规则。
- 选区、TextGrid、帧数、文件数量、时长和参数选择要求语义正确，不用数值容差掩盖边界错误。v2 缺陷另建 ADR 并按科研修正授权处理。
- Jitter/Shimmer 区分周期检测及变体，IRAPT 回退记录实际后端；CPP/HNR 核对窗、频带和缺失值。校正公式与文献误年分开处理。
- 发声合成核对 samples 单位、源/目标方向、步数、输出组、随机参数、端点和取消；TextGrid/唇形核对真实起点与共享 offset，标注保存与偏移保存分开。
- 感知实验验证刺激预加载、客户端时钟与后台标签行为；声道区分来源几何、显示变换、计算管道和真实音频输出，设备时延另测。

## 界面、平台与负载

- 按受影响页面验证浅/深主题、空态/有数据/运行/失败/取消、中文/IPA、大字号和窄窗口，切换不丢草稿或任务归属。真实数据截图不与设计示意混用。
- 典型视窗为 1280×800、1440×900、1920×1080，按改动追加 70/100/150% 页面缩放和 125/150/200% 系统缩放，记录实际 DPI。字体变更检查实际 PNG/SVG、后台快照、缺字/裁切与科学值不变。
- 源码、独立浏览器、实际 Qt、最终 EXE、模拟、实体设备与各平台证据分别记录。Windows 通过后，适用模块另做专用 WSL 或已授权 Linux 服务验证；WSL 不代替 Linux/macOS 桌面。
- 网页按 10 人轻交互、已准入单计算槽加其他人交互、批次竞争、额度触顶、到期/崩溃及可信节点离线/旧租约回传测试。记录硬件、CPU/内存/磁盘/带宽、p50/p95/p99、等待/执行、错误率和公平性。
- 性能初始目标为轻 API p95≤500 ms、典型交互反馈≤100 ms；计算时长单列，实际准入预算按 P11 证据确定。网页 1 GB/3 天覆盖旧策略兼容、原子预留和物理删除。

发行需标明版本、平台、源码/资源摘要、依赖、命令、结果和未验项。Windows、macOS、Linux 桌面与服务器分别验收，构建成功、可用性验证和公开发布分别记录。
