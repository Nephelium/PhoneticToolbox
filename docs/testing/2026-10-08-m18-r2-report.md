# M18-R2 连续阅读、批注与导出

2026-10-08，限定 Windows 当前源码与实际 Qt 操作 **verified**。井井授权修改论文精读及对应使用说明。本轮没有重打 EXE、上传软件或修改服务器论文。

## 最终行为

- 论文详细信息默认折叠，可整体展开题名、作者、版本、翻译说明和导读。紧凑栏常驻许可及引用入口，右上角帮助跳到 M18 说明书。
- 原译文采用连续滚动页面，按视野预取附近页并限制图像缓存。支持左右键、页码、缩放和全屏。原译文分别保留标签内页码；全屏内切换语言仍保持全屏。退出恢复先前普通窗口或最大化状态。
- QtPdf 提取的行文本和页面几何叠加于原 PDF 渲染上，可直接拖选、Ctrl+C 或复制选文。保留本页纯文本入口。扫描图片无 OCR，复杂公式、双栏顺序和 PDF 自身异常字符仍须回看核对。
- 黄色、绿色、粉色荧光笔和选文批注，列表支持定位、编辑、确认删除。按 PDF SHA 保存于固定用户目录，原译文和不同 PDF 内容分开。QLockFile 与 revision 检测多窗口冲突；失败保留已存记录与当前编辑输入。
- 原生保存窗口可选择原文或译文，原样导出或生成含标准 Highlight/Text 批注的副本。原样导出字节一致，批注导出保留原页面文字和矢量内容，原下载文件不变。外部阅读器的批注弹窗及打印行为可能不同。
- 引用格式提供 GB/T 7714—2015、ASA（美国社会学会）、MLA 9、APA 7、BibTeX 的纯文本复制。按 arXiv 固定版本和原稿年份引用，不使用栏目日期冒充出版日期，不补造卷期与期刊。学校或期刊指定版本、标题大小写、姓名拆分和斜体等仍应按其要求复核。
