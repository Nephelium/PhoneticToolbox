# M10-R7 自定义音标构形

2026-10-04。**verified，限定 Windows 源码工作台、原生引擎与独立测试配置。** 本轮没有重打 EXE。

## 本轮行为

- 保存构形弹窗右上方增加输入音标按钮，点击展开紧凑输入行，可输入组合音标、附加符号或自定义名称。保存按钮和 Enter 均可提交。
- 自定义音标直接显示在其他辅音下方。保存模式点击更新对应构形，加载模式点击恢复构形、完整声源设置及 F0。
- 同名保存沿用原 id，更新一条构形；输入已有基本表音标时使用该表项。旧自由名称并入自定义区，原加载入口保留。
- 首尾空白去除，组合字符按原 Unicode 码位保存；沿用原单行 80 字限制，空输入、超长和控制字符明确拒绝。
- 短窄窗口中弹窗可滚动，自定义区可以到达。未新增录音、联网或剪贴板操作。

基础表继续复用 M17 国际音标 Plus 目录，固定 IPA 字体保持。沿用 `presets.json` version 1 和原声源字段，没有格式迁移。VTL 科学核心、原生模型资源与 `scene.js` 无差异，无新增外部来源。
