2026-10-05。状态：verified，限定 Windows 最终源码、独立 Chrome 与实际隐藏 Qt。本轮未生成或验收 EXE。用户明确授权参考 v2、审阅当前模块并修复问题。

## 问题与修复

| 问题 | 已核实原因 | 修复后行为 |
| --- | --- | --- |
| 三处结果 JSON 按钮 | 顶部工具栏、运行栏、底部结果栏分别调用同一 exportResult | 结果格式选择 + 一个导出结果按钮，保留 JSON/XLSX/CSV。项目 JSON 单独保存设计 |
| 结束实验停在结束页 | 按钮只调用 Runner.end，没有设计页导航 | 会话提交成功后返回初始素材页，保留设计、素材和最近结果 |
| 自然完成被改成强制结束 | end 无条件调用 interrupt 再写 ended | completed 保持 completed；仅提前结束写 ended；重复结束幂等 |
| 强制结束保存失败后重试仍暂停 | retrySave 只识别 completed，漏 ended | 重试后正确回到终态，再允许返回 |
| 保存失败仍退出，可丢内存答案 | dispose 无条件释放锁；页面无条件清空 runner | 返回成功/失败结果，失败时保留运行器、内存结果与锁；允许导出内存 JSON |
| 刚退出立即恢复误报占用 | resolve 锁回调后没有等待 Web Locks request 完成 | dispose 与临时结果操作等待锁实际释放，立即重新获取通过 |
| 结束期间迟到保存回调继续推进 | finishTrial 保存后没有核对运行 epoch；begin 的中断路径又追加一次保存 | 回调核对 epoch 后退出，结束后不继续呈现，也不追加迟到写入 |
| 旧导出可确认新数据 | confirmExport 未校验当前 revision；内容更新未撤销导出标识 | 仅当前结果请求可确认，新增反应/中断/活动恢复撤销旧标识 |
| 恢复完成会话重复下载、改 revision | 恢复一律追加 recovery 并 commit，completed watcher 自动 XLSX | 终态只读恢复，不追加恢复事件、不改 revision、不重复下载；活动会话完成仍自动请求 XLSX |
| 下一被试继承上一份信息 | answers 与预检确认没有在返回时清理 | 下一份被试表单为空，重新预检/试音/环境确认，独立 participantId/sessionId |
| 再次预检失败仍显示旧准备状态 | checked/heard 只在成功后更新 | 预检、复核、预览开始即撤销旧确认，失败时保持禁止开始 |
| 恢复缓存可能积累所有刺激 | 新 MediaBank 默认 all，未预检的恢复运行器缺少已解码全集 | 默认分块释放前一试次；复核后按预算选择全量/分块 |
| 同内容跨 A/X 素材关联歧义 | relink、XLSX resolver 在全部组按 hash/name 匹配 | 限定对应组，已存在有效 id 优先；同组真实歧义仍要求用户选择 |
| 正式专注页原生 Enter 被吞 | 全局捕获对所有按键 preventDefault | 原生按钮/输入及 Tab 保留默认事件，试次区继续执行反应键规则 |

运行结果收紧为紧凑卡片，导出和结束按钮集中到顶部。截图回看追加修正 24px/900px 时标题被其他控件挤成逐字换行。科学 RT 起点、有效反应、四范式顺序、素材内容、原文件、ptb-m15-project/1 与 ptb-m15-session/1 协议保持原有定义。
