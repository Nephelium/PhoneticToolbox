- CQ/SQ与语谱图绘图区同宽，语谱F0右轴常驻。
- 总览按当前视窗最大绝对值显示到半高90%，高度92 CSS px。原波形样本及科学峰值0.7规则不变。
- 草稿按钮在最顶端工具栏，移除声门活动按钮。交互不再追加任务记录，旧预览记录只隐藏列表，存储保留。
- 按井井追加要求，高通、低通均使用数值输入，页面及新建批次默认低通2000 Hz。明确保存的草稿、历史任务和底层V2兼容默认值保留。
- IF完成自动打开结果，四图高300 CSS px，线条不透明度0.62，可保存单图和四图白底300 dpi PNG。
- 审查补修：迟到响应归属、会话失效恢复、切文件后旧IF不弹出、快速声道往返保留试听、配置JSON大小限制、严格JSON坐标数组解码、失败时公开错误信息及进程回收。
