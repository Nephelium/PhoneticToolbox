## 用户可见行为

- 第一次启动、需要新增版本文件或修复损坏缓存时，显示中文准备窗口及阶段进度。已有完整缓存时直接验证并复用，不反复显示首次使用提示。
- 按内容清单 SHA 识别科学组件、主原生组件和应用。每次启动读取实际内容校验，同一硬链接只校验一次；不只相信版本号、长度或修改日期。
- 设置增加清除全部缓存。先确认，再走已有未保存检查及任务检查。取消关闭不删除缓存。安全退出后由最后一个活动实例清理运行文件、浏览器可重建缓存、可清理更新包及内部处理结果副本。
- 未导出处理结果清理后需要重新计算，界面已明确说明。原始输入、唯一唇形采集、设置、草稿、录音、工程和正式导出文件保留。活动任务、正在应用的更新或归属不明文件保留并报告。
- 安装版在安装阶段准备运行文件，首次打开复用。卸载先检查活动实例，再清理可清理缓存；应用仍在使用时阻止卸载，避免删掉在用文件。设置和研究资料有意保留，卸载不等于抹除研究数据。

## 失败、修正和限制

R1 缓存目录过长导致 M05 的 PyAV `motionvectors` DLL 加载失败。改为目录摘要前 32 位并继续验证完整 SHA，去掉多余目录层，随后 R2 和最终 R4 完整 M05 验收通过。初版重复验证每个祖先目录拖慢准备，改为仅在本次维护锁内缓存祖先检查，每个叶文件仍检查。准备窗口第一次测试的 Win32 类注销参数错误已修复，并以新的实际窗口证据通过。设置 UI 验证脚本初次使用错误的文字选择器，后按真实导航 title 和草稿未保存星号修正，取消与实际清理断言均保留。

此前 transient R2 的 WinError 5 位于目录 rename，相同操作后来成功，未确认占用者。保留诊断并加入有限重试，真实文件句柄占用回归通过，不将故障武断归因为杀毒软件。历史证据见[跨包去重报告](2026-10-07-cross-archive-dedup-report.md)。
