# M10-R12 控制点、舌位与组织接触修复

2026-10-07。状态 **verified，限定 Windows 当前源码、原生构形与实际隐藏 Qt 交互**。完成井井提出的声门点常驻、牙齿刚性、软腭翘片线、舌叶下压和舌尖后卷问题。没有重打完整 EXE。

## 改动及原因

| 问题 | 原因与修复 |
| --- | --- |
| 声门高低点需先点小舌 | 控制点归入软腭组后被器官选择过滤。二维、三维均独立显示该点，保留原拖动及撤销。 |
| 拖舌头时牙齿看起来变形 | 四预设共 32 个修复前快照中，舌位及软腭变化没有改变原生牙齿坐标。异常来自重建舌腹侵入牙齿。按原生牙列体积裁切三维舌腹与中线封盖，二维用原生门齿截面排除舌体，牙齿隐藏时约束仍生效。上牙固定，下牙随下颌作刚体变换。 |
| 软腭上方翘起薄片 | 内部封闭轮廓被描绘成了游离组织边界。保留封闭体积、口鼻遮罩和选择区域，仅描绘暴露的口腔及后侧轮廓，去掉内部上缘与根部封口线。 |
| 舌叶只能往上顶 | 原约束要求控制点始终高于舌背椭圆及舌尖圆顶部。实际可下压控制点与切线求解辅助点分开，同时保留口底边界。 |
| 舌尖后收过早受限 | 原生最小水平距离直接相加舌背与舌尖半径。改为考虑高度差的距离，抬高的舌尖可后收；修正后卷时切线跨零绕整圆和舌腹回接自交。 |

牙齿接触修复作用于显示层重建舌腹及封盖，未用显示裁切重写原生舌背。舌位自由度的修复位于原生构形代码，声管及传递函数随修正后的原生表面重算。两部分不可混同为完整软组织力学求解。

## 实现、来源与兼容

- [R12 原生补丁](../../resources/vocal_tract/sources/m10_r12_patch.py)在锁定的 VTL 2.4 源码及 R11 补丁之后应用，逐项核对原始上下文，使用[现有构建入口](../../scripts/build_m10_geometry.py)重建。原始 API DLL 与 speaker 未改。
- [刚性牙列裁切](../../frontend/public/vocal-tract/rigid-contact.mjs)、[显示几何](../../frontend/public/vocal-tract/geometry.mjs)、[剖面重建](../../frontend/public/vocal-tract/anatomy.mjs)、[交互与绘制](../../frontend/public/vocal-tract/scene.js)同步修改。动态裁切可改变三角形数量，三维缓冲及中线封盖随当前构形更新。
- 仍使用几何布局 `m10/3`、原有构形库与关键帧文件格式。新允许的下压/后收参数可保存、加载、写入关键帧。解除旧限位可能改变旧文件中被夹紧参数的输出，不承诺这些构形仍保持旧结果。
- 本轮对照 /a i u n/ 四个标准快照，受限参数、声管面积、牙齿坐标的最大差均为 0。
- 只更新 `SRC-VTL`、`PROJECT-M10` 的 R12 来源说明，保留 GPL-3.0-or-later 与原始来源。模块 README、构建说明、第三方声明及资源摘要同步更新。
- 最终 `geometry_p2.dll` SHA-256：`8680828ba875196947b63e8ce58a3aaa22980dd8dd5fa3f0793284c2ad67e2e3`。
