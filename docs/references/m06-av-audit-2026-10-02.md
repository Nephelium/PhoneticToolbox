# M06 AV 与 Klatt 原始模型核查

**后续状态：** 下文为 R1 原始核查记录。井井已授权直接修复，本节旧算法描述和待授权方案由 [M06-R2 实现与验证](../testing/2026-10-02-m06-r2-report.md) 更新，历史证据保留。新实现无旧错误算法模式。

2026-10-02。结论：**井井对 AV 标尺的疑问成立。当前 AV200/190 是旧版改造链中的经验增益，与 Klatt 1980 的典型设置不能直接对应。** 本轮完成只读溯源与可复现数值诊断，未静默改写科学引擎、默认值、预设或旧配置。

## 1. 原论文、上游代码、本地改造分别是什么

1. Dennis H. Klatt (1980), *Software for a cascade/parallel formant synthesizer*, JASA 67:971–995, [DOI](https://doi.org/10.1121/1.383940)，[USC 教学站点原论文 PDF](https://sail.usc.edu/~lgoldste/Ling582/Week%2012/klatt1980.pdf)。表 I（印刷页 976，PDF 第 6 页）的 AV 范围为 **0–80 dB**。印刷页 987（PDF 第 17 页）说明重读元音的 AV 约 **60 dB**。这是合成声源的控制量，不能解释为录音声压级或自动对应发声类型的阈值。已提取文本并渲染查看原页。
2. 实际 Python 实现来自 [guestdaniel/tdklatt](https://github.com/guestdaniel/tdklatt)，作者 Adrian Y. Cho 与 Daniel R Guest，MIT。本轮读取的 [固定 commit 源码](https://github.com/guestdaniel/tdklatt/blob/081f98431c2995187ecadb15d3667c7b6b7f8c73/tdklatt.py) 为 `081f98431c2995187ecadb15d3667c7b6b7f8c73`。它是现代 Python 重实现；不能叫 Dennis Klatt 1980 年原始代码。本项目最初引入的 commit 仍 unknown。
3. [Oxford 课程的 Klatt 结构页](https://www.phon.ox.ac.uk/klatt_structure) 提供 [simple_parwave.c](https://www.phon.ox.ac.uk/files/lecture_2/simple_parwave.c) 和 simple_klatt.c。已下载检查，属于教学用简化 C 实现，不能冒称 1980 原始版本。其源振幅通过 `DBtoLIN` 的查表与各声源校准系数转换，0 值关闭声源，AV 还经过本实现特定偏置。
4. [Berkeley Phonlab 参数说明](https://linguistics.berkeley.edu/plab/guestwiki/index.php?title=Klatt_Synthesizer_Parameters) 区分周期声源 AV、气流噪声 AH、湍流 AT 等，AH=0 表示关闭该声源。其参数集合包含其他 Klatt 版本，不把所有参数反套成 1980 版。

外部文件只用于本机核查，保留在忽略的 `output/validation/m06-r1/av-audit/`，未复制到产品、公开分发或运行下载的代码。来源 SHA 与 commit 在 `source.json`；论文 SHA-256 为 `ffb8fd1080dc7ecb9b16a9d3dfd10082241cfb918e4df074fdee715eb3351c27`。代码来源登记为 SRC-TDKLATT，论文登记为 REF-KLATT。

## 2. 本地链路的具体偏差

| 位置 | 本地实际行为 | 意义与来源 |
| --- | --- | --- |
| `klatt_config.py` / presets | AV 默认 200、范围 0–300，气声 190、耳语 120 | 旧版自定义标尺，原样迁移至 V3；与标准典型 60 不一致 |
| `engine.py::_synthesize_single_segment` | AV 原值直接送入 `kp.AV` | **没有隐藏的除法或 140 dB 单位换算** |
| `tdklatt.py::KlattNoise1980.do` | 噪声前级为 0 dB，上游为 −60 dB | 相同输入下噪声振幅提高 1000 倍，功率提高 10⁶ 倍；这是本地相对于所核查上游的明确改动 |
| `engine.py` | `AH=max(0,130−HNR)`，默认 HNR60 得 AH70 | 自定义经验映射；HNR 并非 Klatt 1980 表 I 的输入控制量，也不是输出测量结果的保证 |
| `Amplifier.amplify` | `sqrt(10)**(dB/10)`，等价于 `10**(dB/20)` | 公式作为普通线性振幅增益本身正确，问题在参考标尺与声源开关语义。0 dB 得增益 1，AV/AVS/AH/AF=0 不会自动关闭对应声源。该差异在所核查 tdklatt 上游已存在 |
| `Lowpass.filter` | `y[n]=x[n]+y[n−1]` | 实际是累加器，和注释所称 one-zero 滤波器不同；噪声尺度依赖有限序列与持续时间。该行为也存在于上游，不能全归因于本地改写 |
| 输出与 `SpectralFilter` | 引擎峰值归一化，H1H2/Slope/HNR 频域处理，AGC，再归一至 .95 | AV 无法作为最终输出声压或独立响度控制。HNR 同时影响 AH 和谱间隙增益 |
| `extract_parameters` | 将 `compute_energy` 的能量 dB 直接写进 AV | 录音能量与合成声源增益含义不同，没有已验证的逆映射；当前提取后重合成不能解释成等价复制 |

代码依据：`packages/phonetic_core/src/phonetic_core/synthesis/klatt/{engine.py,tdklatt.py,spectral_filter.py,klatt_config.py}`、`acoustic/energy.py`。本轮没有改变这些科研实现。Windows 28 项 V2 独立基准全部通过，确认本轮 UI 修复没有改变旧计算。

## 3. 为什么 200 与 190 的体验不同

两种预设并不只改 AV：

| 预设 | AV | HNR | AH（实际送入） | H1–H2 | Jitter |
| --- | ---: | ---: | ---: | ---: | ---: |
| 常态浊声 | 200 | 40 | 90 | 0 | 0.5% |
| 气声 | 190 | 20 | 110 | 10 | 0% |

仅比较 AV/AH 两项，周期声源减小 10 dB，噪声源增加 20 dB，两者相对比值变化约 **30 dB**，振幅比约 31.6 倍。后处理和 H1–H2 还会改变听感。因而 190 不能被当作独立、普遍的气声阈值。

固定 seed=20261002、0.5 s、F0=120 Hz、其余源级条件固定的局部实验得到：默认 HNR60 下，AV60/190/200 的声道滤波前周期源与气流噪声 RMS 比分别约 **−80.827 / 49.165 / 59.165 dB**。这不是最终音频 HNR，也不是 SPL。仅把噪声前级恢复 −60 dB 后，AV60 的该比值仍约 −20.827 dB，说明恢复这一项后仍需重新校准 AH/声源，无法靠统一减 140 得到标准标尺。

完整现行流水线、同种子、默认其他参数：

| AV | 最终峰值 | 最终 RMS | Praat CC harmonicity 均值（dB） |
| ---: | ---: | ---: | ---: |
| 0 | .95 | .22015 | 4.451 |
| 60 | .95 | .22062 | 4.448 |
| 120 | .95 | .25739 | 4.302 |
| 190 | .95 | .33294 | 30.312 |
| 200 | .95 | .33322 | 30.286 |

这组实验中单独 190/200 得到的该测量值接近，不能用它证明或否定井井的实际听感；实际预设还改变了其他参数。测量采用 `to_harmonicity_cc`，10 ms 步长、最低 75 Hz、静音阈值 .1、4.5 周期窗，排除 −200 无定义帧。没有做听辨实验，也没有把合成输入 HNR 当测量值。

复现：设置 `PYTHONPATH=packages/phonetic_core/src`（绝对路径），使用 `.venv/m09-ui/Scripts/python.exe -X utf8 scripts/audit_m06_av.py`。机器可读数据在 `output/validation/m06-r1/av-audit/metrics.json`。源级实验只改变 AV/HNR/前级增益，不包含预设 Jitter 的影响。

## 4. 建议的修正边界

**推荐新增有版本标记的 Klatt 标准控制模式，并明确保留 m06/1 旧版兼容路径。** 不能把已保存 AV200 的文件在导入时静默读成标准值，也不建议仅把标签改为 60 或把范围裁到 80。

1. 新版本独立 AV（周期源）与 AH（气流噪声），采用可追溯实现的增益校准；声源级明确处理 0=关闭。不要全局修改通用 Amplifier 的 0 dB 语义，否则噪声前级 0 dB 也会被误关。
2. 核对上游噪声整形、脉冲源、谱倾斜及归一化，选定一个明确版本作基准。H1–H2/HNR/Jitter 等扩展后处理单列，避免将经验处理写成 Klatt 原生控制。
3. 参数提取只能提供可辨认的目标特征；AV/AH 需要新的标定或优化过程，不能直接使用录音能量。旧提取保留兼容说明。
4. 在新模式上重新建立五种预设，并测量多元音、多 F0、多时长与固定随机种子；以源开关、dB 增量、噪声比例和输出指标分别验收，听感另验。
5. 审查时另见 F5 默认 5500 Hz 高于内部 10 kHz 的 Nyquist 频率，旧数字谐振器会发生频率折叠；应与新模式一同处理，不借 UI 修订静默改变旧音频。

这属于科研行为和旧文件兼容性的独立改造。当前研究结论已完成，标准模式实现为 **planned，待井井审阅上述方案**。M06-R1 仅落实已明确要求的 UI/交互修复与普通状态 bug；旧方案风险已在帮助和本说明中标明。
