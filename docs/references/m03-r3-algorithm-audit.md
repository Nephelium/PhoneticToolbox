# M03-R3：逆滤波、显著度与显示标尺核查

核查日期：2026-10-03 至 2026-10-04。结论以当前源码、官方方法说明和本机指定录音的敏感性检查为依据。科学核心仍为 `egg-legacy/1`。界面改进不等于方法有效性获得验证。

## 1. 结论与可用设置

- **现有逆滤波的主要问题是闭相区间没有得到确认。** 每个 GCI 后固定取 3 ms，未使用 GOI，也未避开下一 GCI。高基频片段中窗口可以跨越整个周期。调整 LPC 阶数无法消除这个问题。
- **当前自动 LP 阶数是历史经验公式，不能称为最优。** 44.1 kHz 对应 50 阶，3 ms 仅含 132 个样本。新界面显示实际自动阶数，并在提交前拒绝不满足窗口样本数条件的手动阶数。
- **峰自动、谷 0.01 可作为复查起点。** 峰自动只控制波峰。对嘈杂、弱幅度、不规则片段，应检查峰/谷标记及 CQ/SQ 稳定性，不能只凭波形好看选择阈值。本轮保留科学默认值。
- **dB 自动采用当前选区实际 PSD 峰值以下 50 dB。** 一次回填上下限，之后可手动修改。它只调整灰度显示，不改变 PSD 数值、F0 或事件检测。
- **F0 纵轴自动覆盖当前显示的有效正值并留边距。** 低于 50 或高于 500 Hz 的有效结果可以显示。不按分位数裁掉离群点，异常值仍应被检查。此处仅改变绘图范围，Praat 和 GCI 的既有估计规则不变。

## 2. 逆滤波实际做了什么

代码入口：[兼容核心](../../packages/phonetic_core/src/phonetic_core/egg/_inverse_legacy.py)、[有界接口](../../packages/phonetic_core/src/phonetic_core/egg/inverse.py)。

1. 对选区音频做系数 0.97 的一阶预加重。
2. 把检测 GCI 转为采样索引，从其下一个样本开始截取固定 3 ms。尾部不足时裁到选区末尾。
3. 每段至少需 `LP阶数+1` 个样本，使用自相关及 Toeplitz 方程求 LPC。至少三段成功才继续。
4. 对各段 LPC 系数作算术平均，得到声道模型。
5. 对整个预加重选区估计一阶谱倾斜模型，应用 `lfilter(A_tract, A_tilt, audio_preemphasized)`，再去加重。倾斜模型失败或输出非有限时包含旧版回退路径。

这套流程缺少以下保证：GCI/GOI 与声学信号之间的延迟校正、实际闭相确认、极短闭相的充分样本、逐段拟合质量和模型稳定性诊断。对整段系数平均也不等价于合并有效闭相样本重新拟合。去加重会在线性传递关系上抵消前置预加重，但模型系数是在预加重数据上估计，不能据此称预加重完全无效。当前输出只能标为 IF 估计，不应无条件标为物理声门流或其导数。

Drugman、Bozkurt 与 Dutoit 的比较研究把闭相定位误差和高基频下样本不足列为 CPIF 的关键困难，介绍了跨周期估计。该研究使用的 DAP 闭相模型和 IAIF 都与此处自相关系数平均有实质区别。文中 16 kHz / 18 阶设置不能直接套到本程序 44.1 kHz 输入。[作者公开稿，第 2.1 节](https://arxiv.org/html/2001.00840v1#S2.SS1)

### 2.1 本机证据

只读使用既有授权的 `EGG测试/3.wav`，77.249 s、44.1 kHz、双声道。SHA-256 为 `99091c2bfa40698e1d9e7ca35498eb826bacbe8f5756512534e15d82d2a23ce1`。未搜索其他个人目录。

40.0–40.5 s 选区，默认峰自动、谷 0.01、低通 2000 Hz：226 个 GCI 起点，其中 225 个固定 3 ms 窗覆盖下一检测 GCI，也覆盖检测到的 GOI。该段局部 GCI 间隔的中位数对应约 450 Hz，周期约 2.22 ms，短于固定窗。检测事件并非人工真值，但已足以反驳该输入上固定窗总能位于闭相的假设。

同一选区改变 LPC 阶数的结果如下。RMS 在本程序归一化输入标尺下计算，没有物理流量单位。

| LP 阶数 | IF RMS | 与 50 阶波形相关 |
|---:|---:|---:|
| 20 | 0.190945 | 0.923396 |
| 30 | 0.166126 | 0.946172 |
| 40 | 0.125267 | 0.995567 |
| 50 | 0.109643 | 1.000000 |
| 60 | 0.090316 | 0.994171 |
| 80 | 0.085445 | 0.974658 |

数据表明幅度明显依赖阶数。它不能证明 50 阶或其他阶数更接近真实声门源，因为没有对应流量真值。原始结果见 [敏感性数据](../../output/m03-r3/natural-audit.json)，复算脚本为 [verify_m03_r3_natural.py](../../scripts/verify_m03_r3_natural.py)。新结果窗口会显示实际固定窗跨下一 GCI 的计数；没有跨越也不代表闭相已成立。

### 2.2 阶数应该怎样选

阶数需要同时考虑分析带宽、采样率、目标共振峰数量和有效窗口样本数。Praat 官方文档以 5500 Hz 以下五个共振峰为例，先把 44.1 kHz 降采样至 11 kHz，再使用 10 或 11 阶。这个例子用于说明带宽与阶数的关系，不能把原采样率不变的本程序直接设成 10 阶并称为更准确。[Praat LPC 官方说明](https://www.fon.hum.uva.nl/praat/manual/Sound__To_LPC__covariance____.html)

当前兼容模式保留 `floor(fs/1000)+6`，手动值须为正整数，且小于 `floor(0.003*fs)`，上限仍为 256。该边界只排除数学上不足的片段，不保证拟合可靠。0.97 的预加重系数也依赖采样率，其等效转折频率约为 `-fs*ln(0.97)/(2*pi)`，44.1 kHz 时约 214 Hz，16 kHz 时约 78 Hz。

### 2.3 后续方法方案，状态 planned

如开展科学核心改版，建议保留 legacy 作为可追溯对照，再新增独立方法版本：明确分析带宽并做抗混叠重采样，核查声学/EGG 延迟与极性，使用检测闭相和相邻周期边界约束窗口，评估联合多周期估计或有明确出处的 IAIF。同时导出有效片段数、条件/残差、极点及回退状态。先用已知声门源的合成矩阵检验高低 F0、CQ、共振峰和噪声，再做有人工标记的自然录音检查。当前请求中的调研和界面调整已经实施，此方法替换尚未实施。

## 3. 峰、谷显著度

SciPy 的 prominence 衡量峰相对周围基线的突出高度，基线由两侧谷底中较高者确定。它与峰的绝对高度不同。谷检测对负信号使用同一机制。官方定义没有给出适用于所有 EGG 录音的固定推荐阈值。[SciPy peak_prominences](https://docs.scipy.org/doc/scipy/reference/generated/scipy.signal.peak_prominences.html)

当前 [events.py](../../packages/phonetic_core/src/phonetic_core/egg/events.py) 的具体规则：

- 各通道原先独立峰值归一化到 0.7，后续滤波会改变局部幅度，因此 0.01 是该处理链标尺下的幅度阈值。
- 峰自动使用 200 ms 窗、100 ms 步长，每窗阈值 `max(0.01, 0.6*max(abs(window)))`。手动峰值在开启自动时不参与峰检测，新界面将其禁用并明确写为峰自动。
- 谷仍独立使用手动阈值，默认 0.01。没有实施自动谷阈值。
- 名为 `max_f0=500` 的距离参数实际给出约 1 ms 最小峰间隔，即允许接近 1000 Hz 的峰间隔。`min_f0=50` 在该检测函数中没有实际约束作用。分窗峰合并仅删除距离不超过一个样本的重复点，未重新施加全局不应期。这些是历史行为，不能将其解释为严格 50–500 Hz 检测边界。
- GOI 斜率选项在下降候选区使用导数绝对值，局部反向突起可能影响选点。默认尺度 0.25 与文献 DECOM 也有区别。[既有原文核查](m03-method-audit.md)

### 3.1 阈值敏感性

对 20.0、40.0、55.0 s 起始的三个 0.5 s 片段，分别检查峰自动/手动，以及 0.003、0.005、0.01、0.02、0.03、0.05、0.08、0.1，共 48 组。手动模式同时改变峰和谷，自动模式仅谷的手动值有效。事件助手返回的 ±50 ms 扩展事件已裁回选区后统计。

| 选区起点 | 模式 | 阈值 | GCI 数 | GOI 数 | 相邻 GCI 推导 F0 中位数 |
|---:|---|---:|---:|---:|---:|
| 20 s | 手动 | 0.005 | 57 | 58 | 150.04 Hz |
| 20 s | 手动 | 0.010 | 23 | 24 | 44.30 Hz |
| 20 s | 手动 | 0.020 | 17 | 18 | 42.95 Hz |
| 20 s | 峰自动 | 0.010 | 14 | 15 | 38.28 Hz |
| 40 s | 峰自动 | 0.010 | 226 | 225 | 450.00 Hz |
| 55 s | 峰自动 | 0.010 | 120 | 120 | 300.00 Hz |

这些 F0 是本次敏感性审计由事件间隔直接推导的描述量，不代替页面完整 F0 管线，也不能当作感知音高或人工标注真值。40 s 片段在 0.005–0.03 之间事件数稳定，20 s 片段明显敏感，说明全录音单一绝对阈值可能不够。

**实际调整顺序：**先用峰自动、谷 0.01 检查稳定元音和弱声片段的事件标记。疑似多检时依次比较 0.02、0.03，疑似漏检时比较 0.005。自动峰明显漏掉弱周期时，关闭自动并从手动峰/谷 0.01 比较。以波峰波谷位置、周期一致性、CQ/SQ 对阈值的稳定程度共同判断。该范围是复查网格，尚无证据称其中某一点普遍最优。

## 4. dB 与 F0 显示规则

EGG 语谱采用 Matplotlib 的 PSD 路径，显示值为 `10*log10(power)`，基于归一化样本的功率谱密度。没有麦克风声压校准，不能标为 dB SPL，也不能直接与包含其他显示处理的 Praat 图上绝对数值比较。

自动按钮复用当前选区同一 PSD，取实际 0–5000 Hz 频点内有限值的最大值，向上取整为上限，下限为上限减 50。为遵守现有配置合法区间，上限限制在 −110 至 20 dB。全零或无有限值时不提供自动建议，不虚构一个范围。按钮按当前源文件、选区、谱窗与声道匹配数据，旧结果不能用于另一选区。填入非法手动上下限后也可用同一有效 PSD 恢复。

50 dB 是显示起点。Praat 官方 FAQ 给出标准 50 dB，并说明关注粗略共振峰结构或噪声较大时可缩到 40/30 dB。本次只借鉴动态范围，不移植 Praat 的预加重或压缩。[官方 FAQ](https://www.fon.hum.uva.nl/praat/manual/FAQ__Spectrograms.html)、[Paint 显示参数](https://www.fon.hum.uva.nl/praat/manual/Spectrogram__Paint___.html)

F0 右轴汇合已勾选的两类 F0 中当前可见时间内有限正值。边距为 `max(5 Hz, 0.1*(最大值-最小值), 0.02*最大值)`，上下界向外取整数且下界不低于零。无有效值时不显示 F0 右轴。界面与新生成的三图 PNG 遵循同一范围规则，历史 PNG 保留原状。
