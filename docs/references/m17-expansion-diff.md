日期：2026-10-03。目录版本 `m17/1.1.0-20261003`。

## 核对材料

1. 井井提供的 iPA Phonetics Pro 截图15：按可辨识的送气、清化、部位细分、近音、塞擦音、边塞擦音、清内爆音和挤喉组合补出输入入口。UI采用自有的分组卡片与命名行，未复制截图、音频、代码或完整表格美术布局。
2. 井井提供的截图16和17：定位当前附加、节奏、不确定性、其他声音的连续堆叠，重排为中文名、简释、符号/例示行。
3. 吕佳、江荻（2013）。《国际音标扩展表的分类、命名与功能》。《听力学及言语疾病杂志》，21(6)，665–668。[DOI](https://doi.org/10.3969/j.issn.1006-7299.2013.06.030)。指定PDF4页实际看图核对。Poppler文本提取报缺少Adobe-GB1映射，PyMuPDF文本也有乱码，未把乱码内容作为术语依据。页面渲染可读，p.665/668明确其解释2002表，p.666表5及p.667表8核对中文名称。
4. 当前基本表以 [IPA官方表](https://www.internationalphoneticassociation.org/content/ipa-chart) 和 [ICPLA资源页](https://www.icpla.org.uk/resources) 的2025 extIPA为准。官方网页本轮实际访问，extIPA原图沿用已下载的2025一页图逐格看图核对。原PDF均未随产品打包。

## 术语与版本处理

- 保留2025表的“部分去鼻化”，将旧文“非鼻化”“去鼻化”仅作为检索别名。未将旧图标签静默替代新图含义。
- 新增“强发音”“弱发音”“鼻漏气”“前浊音”“后浊音”“内吸气流”“前送气”等可追溯到论文的检索别名，中文解释为自写的简释。
- 旧文响度表的“高声/超高声”可能与音高混淆。现行界面保留“较响/更响”，说明为响度的语境相对变化，不据此指定声压阈值。
- 组合的单项解释按该项实际具有的附加号生成。无清化圈的r̪、r̠和ⱱ̟不套用清化定义。
- 截图里小舌/会厌特殊拍音的叠加细节和卷舌内爆音特殊字形未充分确认，未臆造或宣称补全该应用全部音标。唇齿、齿唇、舌唇组合与主表不同体系分别放到extIPA。
- VoQS全部65条数据、原图表结构、56个UntPhesoca中文译名逐项保持。原文讨论的早期VoQS不用于重写2016修订表。

逐入口来源和输入序列仍记录于 [m17-symbol-coverage.csv](m17-symbol-coverage.csv)。[两条新来源](m17-expansion-source-additions.json) 已由主代理合并统一登记及前端来源面板。
