# ADR-M06-R1：编辑时域与旧合成音频的时间一致性

2026-10-02 / accepted（用户明确交互要求）。

编辑配置的 duration 决定上下图显示域。旧结果 WAV 仍绑定原采样率、帧数及参数快照。调整时长后立即缩放编辑曲线/边界并重置显示域，波形超过旧文件尾部的区域留空，短于旧文件时按实际时间裁切显示；播放器和导出继续对应旧音频并显示过期提示。

公共 WaveformViewport 增加可选 timelineDuration，默认仍用音频长度。选择范围仍限制于实际音频，显示域不会改变音频、科研参数或播放速率。M06 三种图使用相同左右边距与时间换算，F1–F5 非当前曲线仅作不可编辑虚线参考，超出纵轴范围由图形裁剪。
