# M10-R12 舌位自由度与刚性牙齿接触

2026-10-07，状态 accepted，范围为井井当前授权的修复。

原生牙齿由固定上颌及下颌刚体变换生成。舌部控制导致的牙齿异常外观来自重建舌腹穿入牙齿。保留原生牙齿及其下颌运动，将牙列相邻横断面组成的凸体作为不可穿透体积，裁切重建舌腹与显示封盖。二维使用同一原生门齿截面作为组织排除区域。牙齿显示开关不取消接触约束。原生舌背继续使用原有硬组织约束。

软腭封闭网格保留用于体积、口鼻排除及三维显示；二维选择轮廓只画暴露部分，不把组织内部封闭边当作游离表面。声门控制点独立常驻。

舌叶下压和舌尖后卷需修正原生构形。舌尖与舌背的最小水平间距随相对高度调整，抬高的舌尖可以后收，同时保留口底、牙齿和硬腭约束。舌叶实际控制点与用于求解切线的辅助点分开，允许舌叶低于舌背构造椭圆。后卷时选择舌尖后上方切线，并从前侧回接舌腹，避免切线跨零后绕整圆及轮廓自交。桥接 DLL 重建后统一重算几何与声管。

原始 API DLL、speaker、持久化和交换版本保留。解除旧限位会改变受该限位影响的构形及其声学输出，不能承诺所有历史参数的输出完全相同。本轮 /a i u n/ 标准快照的受限参数、管道面积及牙齿坐标与修改前一致。

这是参数构形及显示接触修复，未引入软组织力学模拟。完整三维医学真实性、特定卷舌音的听辨归类和全参数空间接触均未验证。验证范围及证据见 [R12 报告](../testing/2026-10-07-m10-r12-report.md)。
