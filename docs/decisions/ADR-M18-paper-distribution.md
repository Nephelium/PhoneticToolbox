## 期刊DOI与旧客户端兼容（2026-10-21）

依据井井对TAPA论文审阅后的明确发布授权，沿用同一静态目录及下载流程，新增可选`journalPapers`列表。`papers`继续只承载固定版本arXiv，已有条目与`notice`保持；旧阅读器忽略新增字段，继续取得原有论文。新阅读器对两个列表一起校验身份、总数、许可、文件路径和摘要，并在状态、下载、阅读及收藏中合并呈现，磁盘目录仍保留两组原始结构，避免降级时旧阅读器误读DOI条目。网页预算同步涵盖期刊资产。

期刊来源使用规范`https://doi.org/10.…/…`链接，附`journal`元信息，记录刊名、实际发表日期、DOI及可选卷期、页码或文章号。引用按期刊发表日期与真实刊物字段生成，原稿收稿日期和栏目发布日期仍分别保留。元信息链接不作为服务器PDF下载地址，PDF仍仅从原固定同源地址按SHA取得。许可白名单、大小上限和重定向拒绝保持。

不采用把DOI直接混入旧`papers`的方法，该方法会令旧校验器拒绝整份目录。独立v2目录会增加双入口维护，本次采用旧校验器已经允许的可选扩展字段。发布以当前完整目录为基线，校验旧字段及旧资产不变，先写内容寻址资产，最后原子替换目录。新增期刊论文需要支持扩展的新阅读器，网页本轮同步更新，旧桌面成品不宣称无需升级即可取得期刊论文。

应用只携带阅读器。目录入口为 `https://www.phonetictoolbox.com/papers/catalog.json`，内容按版本与 SHA-256 定位，原生下载写入用户目录 `papers/files`。原始论文投稿时间和栏目发布日期分开，订阅以栏目发布日期为准。

`first-launch.json` 在桌面宿主初始化时独占创建，首次安装此能力的现有用户也从本次启动日期开始。单纯升级、切换安装/免安装入口和检查目录不改变日期。用户主动选择的历史下载不会改变默认订阅起点。离线保留最近成功目录和已校验文件。

使用现有 PyQt6.QtPdf 逐页解析、渲染和抽取文本，通过 QWebChannel 返回页面图像及文字。网络与渲染各自使用单独串行工作线程，下载不阻塞阅读队列。Qt 文档在阅读线程复用，缓存有数量及字节上限，关闭时仍在同一线程释放。宿主网络拦截规则保留。光栅按实际 DPR、应用 CSS 缩放和 PDF 尺寸计算，缩放/窗口变化按目标像素重绘；单页上限 4096 宽、6144 高、16777216 像素。前端缓存兼顾编码字节与估计解码占用，高倍缩放减少预取。可选文字层使用整体零透明度隔离字形绘制，实时选择矩形在独立层呈现，避免透明字体或组合音标再次叠加。Ctrl+滚轮只改变 PDF 缩放，保留指针锚点，范围 25–300%。页面不执行 PDF 链接、脚本或附件。Qt PDF 组件冻结收集需在未来 EXE 构建中实测。

译文保持完整正文、公式、图表编号和引用。可按论文版式采用双栏或清晰的单栏排版，改编说明记录重新编排。许可在模块常驻元信息与译文首页注明，翻译/导读明确为 PhoneticToolbox 的 AI 辅助改编，不暗示原作者认可。初期接收明确允许改编的 CC BY 4.0、CC BY-SA 4.0 或 CC0 1.0 内容；其他授权类型需另行审核扩展目录协议。
# M18-R2 阅读能力补充（2026-10-08）

沿用固定 HTTPS 分发及 QtPdf，新增文本几何层、有限页面缓存和本机批注。批注以 PDF SHA 绑定，原译文分开；QLockFile 与 revision 检查避免静默覆盖其他窗口。原文件保持内容寻址只读，导出目的地仅来自宿主原生保存对话框。新增项目环境 pypdf 6.19.0（BSD-3-Clause，无必需传递依赖）用于标准 PDF Highlight/Text 导出。全屏请求由已有 Qt 宿主受理并恢复之前窗口状态。此决定未改变软件公开发布权限或既有数据库。

## 论文库与检查周期

依据井井 2026-10-10 的明确要求，自动获取由 Qt 宿主维护：应用启动检查一次，持续运行默认每 6 小时检查，间隔和关闭偏好存本机 JSON，切换或重开模块不新增定时器。往期按年份、月份勾选下载，已完整获取的条目默认隐藏，可显示为禁选。

服务器推荐与个人 PDF 使用独立目录和收藏关系。个人库由原生选择窗口授予根路径，收藏夹为真实子文件夹，导入复制源文件，整理只移动根内的 PDF，拒绝覆盖、越界和联接。批注继续按内容摘要绑定，移动后的库内编号变化不丢失批注。此功能不引入数据库或迁移。

目录协议 /1 兼容可选双语摘要、`analysisPdf` 与 `updatedAt`，已有论文补充独立解读时复用稳定 ID，只下载缺失的资产。当前发布许可依据具体论文版本核验，与完整代码开放状态分别说明。


删除推荐收藏夹只移除本机分类及其对应关系，文件与批注保留。删除个人收藏夹先验证整个移动计划，将所有类型文件及子文件夹移到上一级；任一重名即整批阻止，不删除PDF，不允许删根或操作链接。移动失败尝试回滚，回滚失败明确提示检查原位与上一级。按内容摘要保留批注，并将当前阅读位置映射到移动后的库内编号。

## 本机移除与栏目说明（2026-10-12）

依据用户的明确要求，推荐论文行可删除本机缓存副本。删除先在同目录暂存文件，再原子保存 `removedRecommendations`，设置失败回滚文件。保留与其他条目共享的内容、批注和收藏归属，已移除条目在自动下载中跳过；往期显式勾选后恢复。并发下载提交前核对移除版本，避免正在下载的文件重新出现。个人文件使用 Qt 的系统回收站入口，失败时保留文件，不降级为永久删除。

目录 /1 新增独立可选 `notice`，字段为 `id/title/authors/publishedAt/updatedAt/pdf`。它用于栏目作者的说明，不伪造 arXiv 版本或论文许可。沿用相同文件路径、大小、SHA 与下载上限，单独置顶并排除在论文计数和往期列表之外。旧客户端继续读取原论文列表，忽略这个可选字段；新增置顶能力须更新应用。

栏目说明在每次应用启动检查一次，也由手动刷新更新，独立于论文首次订阅日期和自动获取开关。自动获取关闭时启动仅取得栏目说明，论文后台定时器停止，科学论文不自动下载。批注仍按文档 SHA 分开，本页笔记使用同一标准 Text 批注导出路径。内容 SHA 变化后重新创建阅读器并限制恢复页码，不把旧版批注套用到新版页码。
