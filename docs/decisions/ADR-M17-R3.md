# ADR-M17-R3：静态内容发布与开发专用维护

2026-10-05，按井井本轮请求实施。

内容用稳定 symbol ID 关联 `symbol-content.json`，不改变音标目录、输入协议和本机文本草稿结构。发行构建合并静态内容，普通使用者不能写入。维护工具为源码环境单独启动的 Vite 插件与页面，既不登记普通路由，也不放入 public。相较产品后台，此方案无需新账号、数据库或发布服务。

音频、视频路径限定项目公开资源的相对路径。实时动画采用 renderer ID、version、JSON 参数，注册器返回停止函数并接收 AbortSignal。现有原生声道引擎不复制、不改动，未来按具体科学语义接入渲染器。缺少素材/渲染器时保持文本不变并给出提示。
