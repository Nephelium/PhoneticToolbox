# ADR-M16：可恢复本地录音工程

2026-10-02，实施授权下采用。开发态实现，实体声卡和正式发行仍未准入。

M16 使用现有 Vue/PyQt6 宿主和独立本地桥。采集工程不加入账号配额、服务器任务、网页到期清理或现存数据库。没有上传回退、管理员 PIN、跨任务参数锁。当前只开放 Windows 原生采集，WSL 仅检验纯核心。

井井追加的默认值为双声道音频，两路均可接麦克风或线路。内部角色名沿用 `microphone`，不能据此把线路信号称为麦克风实测。EGG 由用户显式指定；选择单输入设备时明确切换单声道并提示。每个 take 固定设备身份、声卡、采样率、通道和角色快照，不拼接独立 USB 时钟。

采集回调只复制有界块并非阻塞入队，64 块队列独占写盘消费者。计量与显示由写盘线程分发，显示最多约 5 秒，语谱最多 128×128 显示网格，关闭后不计算 FFT。队列满、格式变化、非有限样本、驱动 overflow 或磁盘不足会标记不完整，保留已确认原始前缀。原始没有数字增益、归一化或软件 AGC。

原始格式为小端 float32 `.f32` 块，131072 帧一块，伴随通道、帧索引、SHA256。每块独占新建、flush/fsync 后才确认，`recovery/<id>/capture.json` 记录可恢复前缀。它避免大 RIFF 文件损坏使整段不可恢复。外部使用时通过 FLOAT/PCM24/PCM16 WAV 导出，单段不超过 256 MiB，连续帧索引进入清单；RF64 未开放。float32 不增加 ADC 的实际位深，不修复模拟削波。

工程用操作系统文件锁保证单写者，崩溃自动释放锁但保留锁文件。清单先写完整修订，再同卷原子替换 `project.json`。失败保留前一入口和新的未提交产物。新工程必须选择空目录。恢复只接回路径、大小、哈希都通过的已落盘前缀，不自动删除历史。

EDL 用 `[start,end)` 整数采样帧，所有通道同切点。撤销、重做和恢复原始都保留旧版本。剪贴板是工程内片段引用，跨采样率/角色结构拒绝，不冒充系统 WAV 剪贴板。模板使用 JSON 精确保留文本；CSV 的公式防护可能添加单引号，因此不作为无损文本往返格式。

首版降噪为 `ptb-spectral-subtraction/1`。Hann 1024、hop 256、均值噪声功率谱和带下限/三频点平滑的功率谱减法增益。处理在独立低优先级进程按 131072 帧中心块与 1024 帧 halo 运行，测试与整段算法最大误差低于 2e-6，EGG 与未勾选通道完全不变。它是自有保守实现，不宣称等价 AU 或标准 Wiener。取消/超时/崩溃不切换当前版本。

宿主采集所有权与 M05 互斥，隐藏标签继续采集并显示工作台指示。空格只试听/停止，输入框、输入法、长按重复、非激活页和录音中都不会启动录音或停止采集。关闭先等待操作结束，再停止设备并完成清单提交；失败留窗。无全局进程清理。

## 2026-10-04 M16-R3 显示修订

井井要求波形/语谱同一时间范围与 0–5000 Hz。取代录后仅前 2 秒的旧显示限制：实时与录后共用有界显示谱，实时维持最多 128 个时间单元，录后最多 640 个时间单元，每单元使用中心处 1024 帧周期 Hann 窗，短录音和边界补零。时间单元严格覆盖可见范围，保留该范围内至 5000 Hz 的 FFT 频点；时间抽样不重采样原音频。长时间窗允许时间细节抽样遗漏，界面说明可放大选区；不作为降噪输入或正式科研参数。录后随波形一次流式读取填充谱窗，内存不随总录音时长增长。纯核心计算与桌面文件读取维持原分层。

删除任务立即提交清单，已有录音/快照和原始文件继续保留，失败不清空用户编辑。表格说明与示例直接置于导入流程。其余行为与验证范围见 [本轮计划](../plans/2026-10-04-m16-r3.md)。
