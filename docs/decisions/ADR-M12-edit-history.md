# M12：切换保存、编辑恢复与历史版本

2026-10-19。状态：accepted。井井要求修复删除和切换后恢复初始状态，三端共用实现并在完成后重启源码工作台。

- 切换录音前提交输入文本，保存当前 TextGrid 与唇偏，并等待成功回执。失败留在当前录音。锁住切换入口，避免两次切换共享一次保存后同时打开。
- 已确认的工作版本优先于原始 TextGrid。每份录音有独立历史，保留原始标注和保存快照，可查看并恢复。恢复作为新编辑，后续保存产生新版本，不覆盖旧历史。
- 历史使用既有 IndexedDB 存储封装，Windows/macOS Qt 与网页共用前端。网页按账号、项目、文件身份与音频摘要隔离，桌面目录扫描提供不可逆的稳定文件身份，不向前端暴露路径。无旧快照时接续已有自动保存稿，原始标注仍可选择。
- 历史内容属于本机研究资料，不进入账号设置或 localStorage。每音频保留原始及最近50次不同内容保存，重复保存不产生重复版本。比较并交换拒绝陈旧窗口覆盖，本机历史失败不放弃编辑，也不切换；TextGrid写盘失败时历史仍可恢复，状态明确区分。
- Backspace/Delete 都支持删除。删除音节可截取跨界音素并保留未选区；剪贴操作仍要求完整边界。删除音节边界时同步去掉重合的音素分界，保留其余音素内部边界。音频外边界不删除，操作给出明确提示。

实现与验证范围见[M12报告](../testing/p17/M12-report.md)。三端共用源码不替代公开网页部署或最终应用成品的发行证据。
