# ADR：爆破时序与正负 VOT 修复

2026-10-19。井井要求删除添加送气段按钮，以VOT编辑，并明确负VOT缺少可听前浊、动作衔接及总时长错误。范围为三端共用源码，Windows/Web验证，Mac本轮仅源码。

- 时间原点为本帧开始，释放开始在closure，浊音起始在closure+vot。闭塞、释放、释放后送气三段只累计一次。前浊属于闭塞的一部分，不追加时长。
- 新编辑时：aspiration=max(0,vot-release)，总时长closure+release+aspiration。直接改送气会令vot=release+aspiration；改释放时保留VOT并重新计算送气。负VOT下送气为0，释放结束后进入下一帧。负VOT不得早于闭塞开始，不再静默限幅。时序帧最低10ms闭塞+1ms释放，普通帧仍至少50ms。
- 旧文件时序四个数值和总时长原样读取；用户再次编辑时应用上述联动。旧送气帧读取保留，创建按钮移除。启用时序可合并紧随旧送气帧；启用和关闭不再覆盖原声源。
- 负VOT浊音起始前增加声门内收：opening和posterior gap为0，vibration为0。浊音起始用2ms过渡到目标声源，保留作者压力。避免开放声门在闭塞中提前平衡压差。前浊来自原生声带/声道求解及皮肤辐射，未叠加录音或人工周期波，未在闭塞处打孔。
- 正VOT用独立清音准备态；浊音起始恰在帧末时，2ms声源起振过渡延续至普通后续帧，沿其实际声道轨迹运动。时序帧起止按采样点切块，块末取左极限，块开始以零长度原生更新切换声源，避免前后20ms块提前混入相邻声源。显示和合成共享采样。
- 时序方法升级m10/stop-timing/2。关键帧和包含时序的构型包写明方法；旧方法允许读取并提示重算，未知方法拒绝。参数库无数据迁移。

验收必须覆盖实际原生PCM前浊周期性、正VOT音频块不提前起振、双模型、精确采样总长、连续编辑联动、旧文件及原声源保持、实际Qt/Chrome UI与Wasm输出。结果见对应测试报告。
