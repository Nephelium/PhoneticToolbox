# ADR-M07-001 分析快照与六组独立发布

2026-09-27，accepted（本轮 M07 实施授权）。

使用既有 P06/P07 任务、资产和 fencing。分析结果为版本化有界 JSON 数值快照，只接受同 owner 的成功 M07 分析/apply 任务产物；重新校验两份原输入身份、配置和快照尺寸。文件读写与 F0 native port 留外层，纯核心接数组。不会反序列化对象或用户 pickle。

一次全部生成由前端协调六个独立正式任务，逐组提交并保留批次 ID 和不可变快照。共享协议无需父子任务与 DDL。组内全部 WAV、CSV、参数清单发布事务成功后才可见；组间允许部分成功。取消停止后续提交、取消当前任务，已成功组可下载，重试使用共享 retry/attempt fencing。页面重开从正式任务历史恢复已提交组，未提交组明确保留为未执行。

一次六组单任务发布会在末尾失败时回收所有成果，无法满足已完成组保留；新增父子任务需要扩大公共协议与数据库范围，故采用上述最小兼容方案。各组顺序为正向F0/发声/同时、反向F0/发声/同时，不乘以两种编辑对齐方式。

分析参数变化使分析失效。控制点应用创建新的不可变分析快照，沿用旧 LPC/残差/脉冲；生成/试听/导出绑定应用快照。只改生成参数不重分析。快照包含输入 hash、算法/运行时、配置、1ms网格与应用控制点，不包含服务器路径。

Linux/远程/服务器准入独立。remote/1 正式科学桥与受限 Linux 进程组未过门时保持不可用，不另建调度器，不把 Windows 验证当作服务器许可。
