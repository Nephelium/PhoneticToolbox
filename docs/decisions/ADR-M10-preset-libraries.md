# ADR：多套构型与持久保存

日期：2026-10-18。井井已授权落实上轮五项审查问题并支持保存、切换多套构型，本轮验证 Windows/Web，Mac 共用源码。

构型套装按说话人隔离，包含稳定 ID、名称、自存构型和常用栏。提供空白新建、复制、重命名、切换。已有关键帧是完整姿态快照，切换套装不改写它们。导入默认建立新套装，也可显式合并到当前套装并选择同名处理方式。内置起点始终可用，自存同名项优先。

纯核心统一名称、套装及构型包校验。名称允许单行自定义文本（含内部空格）；IPA 自动分词只匹配无空白名称。新写入不允许新增规范化重名；旧库多个重名组允许逐项减少冲突，直到完成修复。历史读取保留原记录，提供逐项更名入口，分享前须更名或取消重复项勾选。构型包写 v3，保留 v1/v2 读取；已知旧几何仅在模型摘要和参数一致时允许预览，显式勾选按当前几何重算后才写入。

桌面新增原子写入的 preset-libraries.json。无新文件时只读接续旧 presets/favorites，当前目录优先于 legacy 目录，保留原文件；旧常用项的失效引用按原界面行为不显示。读取不执行迁移，用户编辑时保存新格式。Web 复用已存在的 LocalAssets IndexedDB values，不改变数据库 schema，按账号/项目隔离整个 profile，以比较并交换防止旧标签覆盖新记录。旧 sessionStorage 仅在无持久记录时接续，原始记录保留，损坏时不静默重置。

保存队列从此前失败中恢复，但当前失败必须返回给用户。持久写成功后提交内存状态，失败回滚计算端的对应记录并保留编辑草稿。退出工作区不删除明确保存的数据。旧包重算和套装切换均使用共享 Runtime，平台适配器只提供文件/存储能力。

验证覆盖旧目录优先级与只读、两套相同音标隔离、男女模型隔离、新建/复制/重命名/切换、保存失败后重试、跨标签恢复/竞争、名称与包兼容、取消导入无写入，以及真实 Qt 和 Chrome/Wasm。几何算法及科研默认值本轮保持 R21。
