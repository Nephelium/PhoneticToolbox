# ADR-M01-M02-R1：列表、切分与长录音预览修复

2026-10-01；井井明确授权修复 M01/M02，implemented，验证边界见[报告](../testing/2026-10-01-m01-m02-repairs-report.md)。

- **布局和状态**：移除 M01 根据三栏溢出切换整页滚动的旧分支。两模块文件列表均受工作区约束。任务轮询与用户操作分开，用户操作仍互斥，刷新代次防止旧请求覆盖新任务。PNG 成为 M02 当前图默认，SVG 改为显式选择；清空、删除和原合并行为分别保留。
- **目录能力**：递归只由用户勾选启用，默认关闭。FileProvider 为下层目录建立能力，前端只拿不透明 ID 和相对名称。禁止链接、重解析点和硬链接文件，保留每次最多 10000 条、512 子目录、会话总记录预算。来源目录在提交时绑定批次，递归且结果同源时逐目录固定句柄保存，不覆盖已有不同内容。会话结束后不持久化任意目录权限，历史递归批次须重新选择独立结果目录。
- **切分科学语义**：真实 TextGrid 保留长于 WAV 的空白尾段。校验整层有限、正向、按序且不重叠；音频范围仅约束实际导出的有标签片段。空白和既有静音标签仍跳过。任何有标签越界继续失败，不截断、不平移。采样边界、声道、原帧参数切片和 acoustic/2 均未改变。这是对原拒绝行为的显式修复，不记为无行为变化迁移。
- **长 WAV**：两模块显式调用共享平台预览能力，桌面复用既有 SoundFile/SciPy 分块转换，保留全部声道。文件最大 2 GB、8–96 kHz、最多 8 声道；派生预览最大 64 MB 和 3200 万采样值，必要时降采样/16 位量化，最低 8 kHz。小文件按原始字节读取。原 SHA256、原时长与预览采样率分开，预览说明明确原始/派生格式。缓存只留一份，每次使用重新核对源授权及指纹。语谱图使用同一已标示的轻量预览，实际计算/切分始终读原文件。
- **限制**：预览通过不扩大科学计算或切分输入/输出预算。8 kHz 预览仍超预算时需分段。网页长文件仍走原服务器读取能力，其 64 MB 上限不在本次桌面能力修复中改变。无数据库/任务契约迁移、第三方升级、全局配置变动、EXE 或公开发行。
