# ADR-M10-R11：生理参数扩展与共享几何

2026-10-06，限定 Windows 源码 verified。包括用户追加的小舌接触、口鼻断裂、连接线交叉、尺寸保持与灰色显示要求。数值、兼容、来源及未验范围见[验证记录](../testing/2026-10-06-m10-r11-report.md)。

VTL 2.4 舌尖约束含经过门齿的虚拟竖直边界，舌叶控制为带角度限制的 Bezier 构造点。M10 的显示软腭独立于原生 UVULA，鼻咽连接仅以少量网格直接拼合。现有半侧裁切没有覆盖口鼻气腔。

保留原生接口与 19 个参数的顺序，新增独立喉部扩展值使用具名字段，默认零，旧文件读取不迁移或覆盖原文件。新增模型语义有显式版本标识。实际喉部几何与放宽的舌部几何进入原生截面/管道，不在前端另造声学公式。

显示改进服从几何边界，统一所有三维表面的裁切。口鼻显示配准保持来源区分。MRI 仅参考软腭连接与组织位置；不将平均鼻腔和外观头壳当作 JD2 医学扫描。

小舌在原生几何中整体止抵，不随开口裁窄。显示层复用原生小舌边和舌背三角形，软腭附着层可以过渡。按用户最终取舍，二维软腭/小舌融入头部背景，保留选中边界与控制点。口鼻连接使用统一网格及保持前后方向的插值，二维参考截面由正中连续过渡到鼻腔旁中线 5 mm，消除分开封口导致的假断裂。此参考截面不冒充整条正中医学切片。

几何版本使用 m10/3。旧范围且声门偏移为零的交换文件保持 version 1，扩展舌位或非零声门偏移使用 version 2 / VTL-2.4-JD2-M10-3；本机旧构形库和关键帧缓存继续兼容。完整实施、版本选择、差异和验证结果已在本轮报告登记。说明书冻结正文未扩写；模块开发说明和来源修改说明已同步。
