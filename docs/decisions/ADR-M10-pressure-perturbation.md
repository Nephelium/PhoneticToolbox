# ADR：声源气压曲线与可复现微扰

日期：2026-10-18。状态：井井已确认，已实现并通过[当前服务器网页版验收](../testing/web-vocal-browser-controls.md)。

驱动气压曲线为归一化时间上的 0–1600 Pa，线性插值，仅覆盖声源压力，不改变试听增益。F0 曲线仍为 60–350 Hz。静音帧保持静音，送气段允许编辑气压。空曲线保持旧计算路径。

抖动使用两个独立的 0–100 强度控件。jitter 保留 VTL 几何声门的 Schoentgen 随机相位模型及原强度标度。shimmer 是本项目新增的声门振动幅度微扰：独立随机序列在每个声门周期生成一个目标，使用半余弦平滑连接相邻周期幅度，最大偏移为基础振动幅度的 20%。二者均不标为分析模块测得的 jitter/shimmer 百分比。F0/气压曲线描述慢变化，微扰在声源内执行，不修改已绘制曲线或乘最终音频增益。无周期振动时 shimmer 不产生周期声。

默认继续使用原 speaker 的 jitter 和无新增 shimmer。用户调整后启用可复现模式，保存 32 位种子。自定义 jitter/shimmer 使用互不干扰的 xorshift32 序列；开始一次合成重置种子，连续发声的拉取和姿态更新不重置。上游湍流噪声保留其算法，在每次新合成播种，同平台输入、种子和引擎一致时检验重复性；跨编译器保留既有小浮点和噪声实现差异边界。

旧文档 1–5 继续读取，无新增控制导出为 5；含气压曲线或自定义微扰时写 6，模型与几何仍为 R18。旧程序明确拒绝新版，不能静默丢弃控制。此方案以及声源语义由井井在本次对话中明确批准。

Pink Trombone 仅作为公开源码的架构参考，不引入其代码。采用其音频与绘制分离、小块流式音频、复用缓冲和参数平滑思路，保留 VTL 科学算法。其缓慢音高摆动与 jitter 分开，本轮不擅自增加颤音或音高漂移。

验证须覆盖零新增控制旧行为、独立随机序列、相同种子复现、强度变化、静音/送气、连续拉取与改姿、两曲线及版本往返。构建记录上游归属、补丁和二进制摘要。不能由主观听感代替科学检查，也不能由本机性能推断真实设备表现。
