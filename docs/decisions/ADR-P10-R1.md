# ADR-P10-R1：说明书目录跟随当前阅读小节

2026-10-06，按井井本轮明确要求采纳。仅调整共用阅读器交互。

现有滚动追踪可选中三级标题，目录只渲染二级标题，导致当前位置没有对应高亮项。目录采用二级标题下的三级子目录，展开组由当前阅读节点的祖先唯一决定，不另存一份手动展开状态。一级及二级目录常驻，三级目录只显示当前组；更深正文归入对应三级目录。

点击、搜索与交叉引用保留稳定节点 ID。正文节点通过当前章节结构确定所属小节。显式跳转锁定实际落点，避免浏览器滚动夹限或旧滚动事件覆盖点击选择；正文发生新的滚动后恢复阅读跟随。滚动按动画帧合并，并在正文尺寸变化后更新。阅读恢复优先采用保存的 scrollTop，重新计算所属小节。

版本化内容协议、正文、搜索数据与播放租约保持兼容。无新增依赖或来源材料。
