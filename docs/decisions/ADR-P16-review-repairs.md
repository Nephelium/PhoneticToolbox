# ADR-P16：科学行为修正与平台边界

2026-10-01，accepted（井井授权逐条修复审查问题）。

1. 科学行为修正独立于原样迁移。声学窗口按 `round(k * fs * frameshift_ms / 1000)` 定位；共振峰数量原值传入 Burg。结果增加计算修订标记，旧结果无该字段时仍按历史版本解释，不改写历史数据。
2. 普通未估计值仍保留 NaN。计算阶段抛出的异常必须产生受控失败，不再发布貌似成功的全缺失结果；用户可明确选择的 REAPER 回退保留，但取消/预算中止不得触发回退。
3. REAPER 后端策略由 worker 适配器执行，核心不启动原生进程。原生文件缺失时 python_only 不依赖该文件。
4. 导出字体由渲染主机解析，结果记录请求字体与实际字体和文件哈希。允许缺失的屏幕字体回退至明确候选，不对缺少 IPA 字体静默替代。
5. capabilities 必须反映主机资源约束和当前部署允许表。未验证科学能力继续关闭。
6. POSIX 保存使用目录文件描述符和相对文件操作保持目标归属，不能简单去掉 Windows 目录锁。未实现的 macOS 科学沙箱显式报告不可用，不能误导入 Windows 代码。
7. 这次不承诺 macOS 完整发行，不修改线上配置、现存库或旧科学环境。Mac 原生库、Qt helper、设备、签名及完整离线包按目标平台实测验收。
