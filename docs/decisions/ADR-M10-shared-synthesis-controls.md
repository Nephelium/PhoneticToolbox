# ADR：三端共用的声道模型、IPA 序列与全局构音调整

日期：2026-10-18。状态：井井已确认，当前源码与原生候选已实施，平台验收见对应报告。任务：M10-SHARED-SYNTHESIS。

## 已核对的基础

网页、Windows 和 macOS 共用 `frontend/public/vocal-tract` 界面及 `phonetic_core/vocal_tract` 状态机。C++ 算法与补丁共用，分别编译 Wasm、DLL 和 dylib。修改源码后仍需重新生成运行包并分别验证，现有安装包不会自动改变。

并行任务 WEB-M10-BROWSER-CONTROLS 已实现气压双曲线与声源微扰。本任务沿用其[气压与微扰语义](ADR-M10-pressure-perturbation.md)，补齐原生平台接入，不重复实现。2026-10-18 只读检查时，正式 Windows `VocalTractLabApi.dll` 尚未导出 `vtlSetSourcePerturbation`，独立新声源构建已有该能力。

工程已包含 JD2、M01、W02 speaker 文件。[VTL 官方说明](https://vocaltractlab.de/index.php?page=vocaltractlab-examples)确认 JD2/M01 为男性说话人，W02 为女性说话人，三者来自 MRI 数据。W02 原文件默认 F0 为 223 Hz。当前 Windows R18 引擎载入 W02 后，a/i/u 各 4800 采样的短合成与几何计算成功且数值有限。这只证明接入可行，未完成 UI、跨平台、听辨或完整科研验收。

## 统一界面

左侧保持模型与科学图窗。模型区域顶部增加「声道模型：男性 / 女性」。右侧只保留三个页签：

| 页签 | 内容 |
| --- | --- |
| 器官 | 当前构型的器官、唇宽、软腭、下颌、喉位等控制，保存与载入构型 |
| 声音 | 当前 F0、气压、声门模式、持续发声和试听；jitter/shimmer 与种子收在可折叠区域 |
| 序列 | IPA 输入生成入口、同一套关键帧卡片、可折叠的全局构音调整、蓝色 F0 与橙色气压双曲线、播放和导出 |

IPA 不再另开一套合成页面。音标解析与缺失提示在输入区显示，关键帧使用现有编辑、排序、时长、静音和送气操作。宽窗口及放大编辑提供更多空间；窄窗口各组依次排列，不堆叠所有器官滑条。

## 女性模型与构型归属

使用 W02 原有解剖和声门参数。男性保持 JD2。按井井后续要求，新建姿态默认基频为男性 120 Hz、女性 200 Hz；已存基频保留，旧文件缺省 F0 仍按旧规则读取。切换停止播放并使旧计算缓存失效，载入所选模型自己的构型与序列。旧记录缺少 speaker 时归属于 JD2。女性不得自动套用作者在 JD2 上保存的构型；只使用 W02 原有起点或用户在 W02 下保存的构型。旧文件跨模型载入明确要求切换模型，不静默把坐标当作另一个说话人的发音。

每个模型分别保留构型、序列与常用项。模型选择和新增设置走现有本机 profile / 账号设置，不新增数据库表或迁移现存库。外部显示头壳是外观参考，不能当作 W02 MRI 数据。显示配准与实际声学边界分开检查。

## IPA 到序列

使用当前模型的已存构型名称作为可用词表，Unicode NFC 规范化，支持显式空格分隔及连续输入的最长匹配。组合附加符号、连接符和送气标记属于音标整体，不能通过丢弃未识别字符得到看似成功的序列。用户已保存的复合符号优先匹配；缺失项一次列出，不自动替换为相近音。解析成功后生成独立构型快照，随后修改构型库不会悄悄改变已有序列。

生成按音类提供可编辑起点：塞音 80 ms、塞擦音 140 ms、清擦音 180 ms、浊擦音 160 ms、鼻音 120 ms、近音/边音等 100 ms、闪音 60 ms、元音或未分类音 200 ms。送气标记增加 40 ms，长音/半长音按 2/1.5 倍处理；这组数值用于创作初始化，不是某语言的实测时长，也不等于 VOT。可显式选择统一时长。普通非末帧沿用过渡时长、末帧为停留；勾选塞音时序时，非末尾简单塞音改用下文闭塞/释放控制。生成追加到列表，缺失构型时整批不写入。桌面与浏览器 Wasm 播放/视频准备放宽到 60 秒，保留旧服务器科学回退 5 秒及消息/文件 8 MB 边界。

## 全局构音调整

每项可选保持原值、固定值、相对偏移。先按原关键帧时间网格插值得到姿态，再在同一个核心函数中应用全局操作，最后执行参数上限与几何接触限制。固定值覆盖该参数，相对值加到当时姿态，保持原值不改变它。所有设置为空时走旧路径。

覆盖喉位、腭咽开口、下颌、唇宽、唇开度/前突及舌部参数。「全局鼻腔关闭」使用腭咽开口固定为 0。舌位高低提供具体部位，防止把自动舌根模式下无效的舌根参数显示为已生效；编辑舌根时明确使用手动舌根。原始关键帧与构型库不改写。预览画面、截面积、音频和视频使用同一有效姿态，限幅结果可在预览中查看。

## 舌部平滑

在原生几何生成阶段修正不连续连接，优先处理舌背、舌叶、舌尖及舌腹相接处的切线与采样。继续保留牙齿、硬腭、口底、后咽壁接触和侧通路。舌面与舌叶的原生表面、截面积和声学同步更新。舌底沿用既有显示用腹面重建，不把该显示网格称为新增声学边界；本次使可见拖动锚点与边界一致，消除反向拖动死区。方法身份升级，旧文档保留参数并提示按新几何重新计算，旧音频不冒充逐样本可复现。

## 文件与平台

新增模型身份、全局调整和新几何需要新版交换文件，旧 1–7 版继续可读。旧程序明确拒绝新版，不能忽略新增控制。记录 speaker、几何/声源方法、曲线、随机种子、截面数和原始关键帧，保存和取消恢复均携带新增字段。

Windows 和浏览器本机候选分别验证，macOS 需要在已授权的 Mac 构建环境编译和验证。只读核对已有 Mac 交接材料后确定可用入口，不更改系统或安装全局依赖。本任务实施授权不扩展为公开部署、推送或 Release 发布。最终 EXE / Mac 成品与源码验证分别记录。

## 实施顺序与验收

1. 共用 IPA 解析与全局操作，验证 Unicode、缺失、空输入、限幅、不改原始输入和缓存身份。
2. 模型切换与按模型存储，验证 JD2 旧数据、W02 数据隔离、失败回退、导入和取消恢复。
3. 序列页整合，验证浅深主题、窄宽布局、键盘/触摸、单音时长编辑和缺失构型提示。
4. 原生舌部连接与声源构建，验证两模型的接触、闭塞、侧通路、面积和连续动作；零新增控制基线与同种子复现分开核对。
5. 同源码构建 Windows / Wasm / macOS，分别记录实际完成的平台及成品。按统一入口启动当前源码供井井检查，再按已授权范围交付。

原方案及后续追加已实现，实际验证和未验范围见 [本轮报告](../testing/m10-shared-controls.md)。最终 EXE / Mac 应用和公开站点不随源码修改自动更新。

## 2026-10-18 追加：爆破时序与独立唇部（已确认）

当前送气帧延长前后构型之间的连续插值，不能单独表达闭塞保持、短促释放和声门起振时刻。新增可选爆破音时序：分别编辑闭塞保持、释放过渡、送气及相对释放时刻的 VOT。负 VOT 允许闭塞期声源振动，正 VOT 在释放后起振。保留旧关键帧的过渡语义，不按名称暗改旧序列，也不简单叠加录音或噪声冒充原生爆破。保持原生压力/流量与噪声求解，释放阶段和起声的 2 ms 过渡用 1 ms 计算步长，其他区段沿用 20 ms 块。VOT 字段表示相对释放开始的声门起振指令，实际声学 VOT 仍须从输出测量。初始时长只作可编辑起点。

当前模型的 LP / LD 控制共同唇前突与唇间距。新增上下唇各自的前后、上下偏移，保留共同开合与前突作为基础。偏移在原生几何中实施，并进入接触限制、截面积和声学计算；保留牙齿 / 唇接触，不允许视觉穿透。零偏移保留原模型。参数需贯穿关键帧插值、全局调整、构型包及交换文档，并记录新方法身份，旧数据缺省为零。/f/ 的验收包括下唇接近上齿、狭窄位置和摩擦噪声，不能只凭画面宣称 /f/ 已完成。

井井已明确确认上述新增时序、声学与文件语义，已实施为 m10/r20。零唇部偏移保持既有几何；有偏移时重新求解唇面接触和辐射面。

新增区段超音段特征：添加按钮打开编辑器，可选择参数、固定值或相对偏移，并选帧或起止秒数。按帧范围使用持久化 frame_id，跟随排序与时长改变；按时间范围保留绝对秒数。原全局控制先作用于全段。同一区段的相对偏移相加，固定值冲突采用最后添加的一项，再叠加全部相对偏移，最后一次限幅。这组重叠规则已由井井明确确认。独立唇部、爆破时序、区域特征写交换文档 v8；旧 1–7 版仍可读并保留原字段。构型分享写 v2，保留模型与几何身份检查。

## 构型分享、音量与长序列

构型库提供选择部分音标导出 `.ptb-poses.json`，导入先预览，重名可保留本机或替换。导入项直接加入当前模型的 IPA 词表，新项分配本机 ID，替换项保留原 ID 与常用关系。包记录模型、speaker 摘要、参数顺序、几何方法和构型，不带用户本机路径或可执行内容。当前写包 v2，读 v1/v2 均检查模型和几何身份；旧 R19 包不能被当作 R20 精确复现。交换文档 v8 另保存整段曲线、全局及区段调整和帧身份。

F0 音量补偿使用独立分析库，在固定 800 Pa、无微扰的参考声源下比较同一声管的当前 F0 与模型参考 F0。仅补偿试听/导出增益，原始计算音频保留；实际驱动气压、音色和 shimmer 不被自动归一化。稳态每个 F0 比较先稳定 8 周期，再测 12 周期，缓存最多 512 项。连续变化使用采样锚点与增益插值，参考增益限于 1/16–16，不能视为完整时变感知响度归一化。

原 12 秒是一次性预计算声音和同步画面的资源限制，不是声学生理上限。本轮桌面/浏览器 Wasm 上限 60 秒；可取消计算，完成后保留末帧。视频上传的时长和包数上限同步更新，64 MB、画面尺寸与帧率等边界保留。长序列不会绕过权限或上传额度。空列表的曲线区显示“添加当前姿势”，有时长后才开放绘制。

## 同日追加：R21 与声源超音段

按井井手动拖动尖角及分享选择反馈，在原生接触计算前增加局部弧长平滑并升级为R21；分享目录采用自存优先的当前模型完整目录。jitter/shimmer纳入同一全局与区段特征契约，0–100强度、固定/偏移/限幅、沿用序列随机种子，区段边界更新不重置随机状态。合成结束、异常和取消后恢复原声源设置。旧序列允许提示后重算，旧构型包仍严格校验方法，跨版本导入政策仅提出审查建议。
