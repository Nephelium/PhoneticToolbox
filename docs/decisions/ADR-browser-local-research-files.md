# 浏览器研究文件本机保存

日期：2026-10-18。状态：已实施并在网页版上线。井井已授权实现、测试及同步线上，验证边界见[验收](../testing/web-local-files.md)。

浏览器已承担部分科学计算，原文件接口仍先上传输入并把本机结果上传后重新下载。本轮将文件传输与计算位置分开，不改变算法、参数或账号设置契约。

- 研究文件、浏览器生成结果、任务恢复记录与录音工程写入 IndexedDB，按账号和项目隔离。文件使用稳定标识及 SHA-256，跨模块共享同一库，刷新后重新读取。
- 服务器调用仅在确需服务器处理的操作中，将引用的本机输入按需上传，替换请求中的文件标识并保留内容摘要。有效服务器副本可复用，失效后从本机原件重新准备。服务器结果首次读取后保存本机副本。
- 账号设置继续使用现有账号偏好接口。退出、切换账号及服务器临时文件到期均不清理本机研究文件；本机存储错误直接提示，不将其当成上传回退理由。
- 文件管理分别显示本机文件及服务器临时文件。本机文件可导出、移除，清理浏览器站点数据会移除本机库。已有服务器文件仍可使用并按原到期规则清理。

选择 IndexedDB 是为了保存 Blob 和事务性恢复指针，避免 localStorage 容量不足及依赖用户授权目录。代价是数据只属于当前浏览器和设备，浏览器清理站点数据或配额限制仍可能影响保存；需要长期留存的材料可导出到电脑目录。不自动上传备份。

验证覆盖零文件上传的本机导入/读取/结果保存、账号项目隔离、刷新与跨模块恢复、服务器按需传输及摘要/取消/错误边界。候选和线上前端分别验证，保留科学运行库及服务配置。
