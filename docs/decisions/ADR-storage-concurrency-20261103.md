# A5 存储并发与连接复用

状态：2026-11-03 井井明确批准专项改造及独立 PostgreSQL 并发验证。

普通资产操作使用共享实例 OS 锁与 PostgreSQL 共享实例锁，再按账户、资产顺序取得 advisory 锁。写操作独占账户/资产，读取共享，跨账户可同时读写。维护、回收、跨资产发布和旧调用仍取独占实例锁。保留旧锁文件与 PostgreSQL 锁 ID，旧进程的独占锁仍与新版协调，不改现存 schema。磁盘新增预留另取短时全局预留锁，覆盖容量检查与预留提交，已有预留的块写入不取该锁。

worker 的逐块读写先只读查询不可变 owner，结束任务事务后才取存储锁，再重新校验 worker generation、输入与租约。顺序固定为实例、账户、资产、预留、任务事务，禁止持有任务事务后等待存储锁。发布仍在原事务内核对所有输出，不扩大科学任务的并行限额。

认证、工作区、任务库与存储共用每进程每 DSN 最多 8 条的惰性连接池，等待最多 5 秒，SQL/锁仍设超时。复用已有 psycopg，不增加外部依赖。归还时回滚残留事务并 DISCARD ALL，关闭自动 prepared statement 缓存，防止 session advisory 锁或只读设置污染下一调用。连接异常不自动重试业务写入，避免不确定提交后的重复操作。API 退出和进程退出回收连接，顺序测试库最多保留 4 个闲置池。

每个下载块继续检查登录会话、工作区、owner 和到期时间。不跨网络背压保留连接、锁或文件句柄，不使用鉴权缓存。改造减少物理连接建立及无关账户串行，不能保证目标服务器的绝对吞吐。

验证使用独立 initdb 和随机测试库，覆盖跨账户进展、同账户配额争用、重复/冲突块、维护排他、异常归还、池上限、失效会话/输入和发布栅栏。具体命令与结果写入本次复核记录。后台运行，无 GUI、线上连接或现存库迁移。
