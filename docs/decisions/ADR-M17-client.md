# ADR-M17：纯客户端符号表、Unicode 编辑与固定字体

- 日期：2026-10-02
- 状态：accepted，按井井完整实施授权落地；验证范围见报告。
- 模块：M17 国际音标 Plus

## 决策

采用 Vue 模块、静态版本化 JSON 目录、原生 textarea、单一自有编辑历史和 IndexedDB 草稿。所有插入、检索、解释、复制、TXT 导出均在客户端。无 Python 计算、任务 API、账号额度或后端数据模型。

对外接口为 `active:boolean`、`stateKey:string`，发出 `dirty:boolean` 与 `references`，暴露 `save():Promise<boolean>`。AppShell 用既有标签保护和 v-show 生命周期集成。模块不注册全局音频或空格快捷键，不更改公共字体。

目录以每个有转写意义的原表出现项为单位。独立标记、组合例示、范围模板分别编码。原始字节/码位优先，不自动 NFC/NFD 改写用户文本，不自动替换未知 PUA。`Intl.Segmenter` 在插入前防止切开代理对和组合字素；模板包裹选区，连线要求两个字素。IME 组合完成才提交一个历史记录。

草稿写入在同一 IDB readwrite 事务内比较 revision。恢复阶段不触发自动保存，避免打开第二个窗口即制造写入冲突。存储失败、未知版本或冲突停止覆盖，保留当前文字并提供独立另存。`save()` 合并并等待进行中的保存，供关闭标签保护使用。

## 布局与字体

用户要求默认桌面一页显示整表与编辑区，因此用横向分栏重排各类表区，保留肺部辅音矩阵、元音梯形及 VoQS 分类关系。以真正的 AppShell 可用区域验收，包含导航、标签、状态栏。较小窗口和高缩放保留滚动，不强行把字缩到不可读。

Doulos SIL 7.000 已覆盖新扩展拉丁字母和上标 VoQS，但缺少六种组合括号及圈围所需映射。模块内派生 PTB IPA Plus 1.000，原轮廓全部字节保留，新增 23 字形和 mark-to-mark/有限圈围连字，按 OFL 1.1 改名。仅实际使用的单个字体进入 assets。构建脚本与字体哈希公开，原项目 Doulos 未改。

多字符圈围未找到可直接表达原图跨度的已编码字符。两项显式使用 ⟅…⟆ 文本替代，注明其与标准图示的差别，不引入 PUA 或把提案码位当正式标准。13 个原表单字符圈围有真实圈形。字体 cmap 全覆盖只作为第一层门槛，还用实际 Chrome 字体来源、逐项形态图和 Qt 页面截图核对。

## 来源决策与边界

英文分类、符号与科学含义以 IPA/ICPLA 图表和 VoQS 论文为准；VoQS 中文名称按井井指定 UntPhesoca 文章严格对齐，56 项独立断言。论文年、图表年、中文译年分别标注。CIN 只作检索别名，原文件不打包、不修改。原 PDF/文章图片均不打包；符号事实、交互实现、自撰说明和来源许可证分别记录。

网页资源加载后支持断网，但没有浏览器冷启动 PWA 承诺。此次 Windows Chrome 与 Qt 证据不外推 Linux GUI、实体 DPI、物理输入法操作或冻结发行物。中文说明字体回退与音标字体来源分别检查，不能用系统字体补齐缺字来宣称覆盖。
