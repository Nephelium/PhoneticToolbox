# ADR-M11-001：可选运行时、旧运行适配故障与准入

2026-09-27，用户授权的独立组件架构。状态 in_progress。

主包仅含轻量宿主/页面，MFA 固定 3.3.8、模型独立。已有 Windows Conda 环境仅只读运行，不升级。包导入必须验证外部可信清单、拒绝路径穿越/链接，在最终独占版本目录完成实际任务自检后切换。无发布 URL 时不启用在线安装。

实际审计：旧 pipeline 给 PretrainedAligner 的 num_jobs/use_mp/temporary_directory/clean/verbose 参数在本环境被 MFA 警告忽略，实际配置 NUM_JOBS=3 / USE_MP=True。NUMBA_DISABLE_JIT=1 与当前 kalpy/librosa/numba 组合在 MFCC 报 `AttributeError: function has no attribute get_call_template`，最终 FeatureGenerationError。保留旧基准失败证据，不伪造数值相等。

修正与原样编码迁移分开：新外部 child 使用 MFA 3.3.8 实际 config.NUM_JOBS=1、USE_MP=False；移除禁用 JIT，使用任务独占 NUMBA_CACHE_DIR，禁止 pyc。此为运行适配修正，保持 Beam=10 / Retry=40、声学模型、文本、align/export 算法调用及原始输入不变。真实资源和输出仍需测量。公共合成输入只证明管线，不代表自然语料边界准确率。

每任务新 MFA_ROOT_DIR，不读取旧全局配置。3.3.8 默认 SQLite 独占数据库保持，无辅助 PostgreSQL 服务、无账号库复用。Windows 使用已有 Job Object，取消/超时停止整个本任务进程树，保留临时诊断/部分输出并明确其非完整成果。桌面保留目录需计入本机空间并显示。服务器执行在临时目录配额与 P11/远程准入未通过前关闭，不靠 num_jobs=1 宣称服务器可用。

P06-REMOTE 正式接线/可信节点仍未完成，M11 不创建第二套队列/认证。网页可以查看所需组件、登记模型并提交受管输入；无合格能力时留在既有任务队列的明确等待原因，旧本地 worker 不得误领。现存数据库无 DDL。

2026-09-27 实测补充：MFA 3.3.8 会忽略 TextGrid 的 notes、words/phones 参考层；只含此类层时显式拒绝，不自动改层。词典发音被模型排除和 OOV 均显式失败，作为行为保护修正单列。Windows 长目录曾令 numba 原生 DLL 加载失败，候选目录缩短且安装前检查原生文件路径，未改系统设置。状态原子替换对 Windows 短暂共享句柄冲突作有界重试，不忽略最终失败。

真实短路径离线导入与 Qt/正式任务通过；完整普通话词典小任务约 1.76 GB 峰值，超出初始服务器预算，继续禁用回退。实际 remote/1 与 Linux 仍未准入。详见 M11 报告。
