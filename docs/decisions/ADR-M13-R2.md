# ADR-M13-R2：显式草稿恢复与独立文字显示

日期：2026-10-05。状态：accepted，实施验证见[报告](../testing/2026-10-05-m13-r2-report.md)。范围来自井井本轮明确的界面修改和缺陷修复要求。

## 启动与草稿

重新创建 M13 页面时，保留已保存的排版偏好，文本与多音选择为空，转换标准设为 `Standard Chinese (Beijing)`。旧草稿原记录保留，通过顶部恢复本机草稿显式读入完整文本、标准、位置选择和排版。恢复按钮在当前编辑未保存时禁用，避免覆盖内容。已有标签之间切换仍保留当前页面。

版本继续使用 `mandarin-ipa.v1` / `version:1`，新增显示字段为可选兼容扩展，旧记录按默认显示声调、主题颜色和全局汉字字体解释。取消旧设置折叠状态的读取，设置栏始终显示。

## 显示与转换

音标颜色与汉字颜色独立。汉字字体复用公共 `FontFamilySelect` 和既有桌面字体枚举接口，IPA 固定 `PTB-Doulos`。页面文字样式只影响结果汉字层，其他模块和全局字体偏好不改变。

隐藏 IPA 声调只移除映射结果结尾 U+02E5–U+02E9 声调字母，保留音段附加符号和原始映射。汉语拼音关闭声调时不加声调符号，并把旧字表键盘写法 v 显示为 ü。开启时也先规范 v，修复 `lvè` 显示为 `lüè`。字表、候选顺序与逐字转换语义不变。

编辑文本时，已选读音跟随未改变的 Unicode 公共前缀/后缀移动，修改区域的旧选择丢弃。仅音标模式字号标签与滑条采用实际字号，旧自动 28px 规则保留。

## PNG

PNG 使用同一显示快照和固定 Doulos，明确选择的颜色与汉字字体精确应用。维持白底图片，默认汉字使用深色墨迹，避免深色主题白字落在白底上。选择不存在的自定义字体时显示可恢复错误，不清空文本。

导出字体就绪先检查已加载的内置同名 FontFace，复用其 `loaded` Promise。已有 CSS 字体声明与显式 FontFace 并存时，直接加载整个家族可能额外读取尚未加载的 CSS 字体，导致离线误报。没有可用的 Doulos 时仍加载并验证资源，失败维持错误提示，不改公共字体模块。

## 影响边界

无新依赖、后端计算、现存数据库变更、来源字表或字体资源变更。此前关于自动恢复草稿、旧默认严式标准与可折叠设置的行为由本决策替代。各平台和发行物的验证状态单列。
