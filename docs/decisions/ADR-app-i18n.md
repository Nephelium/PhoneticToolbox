# 应用语言与可下载说明书

状态：已接受方向，实施中。依据2026-10-30井井明确授权与后续截图/离线/交付范围澄清。

使用同一Vue工作台的响应式语言状态，不复制三套模块，也不通过整页刷新或DOM全文替换实现切换。模块/参数/任务身份与显示名称分离，使用按功能命名的稳定消息键。三个语言目录按公共功能与模块拆分，由生成索引和覆盖检查统一组合，源摘要记录译文待复核状态；默认中文，英文/日文按需加载并缓存，不随每次渲染重建整套词典。

Vue I18n提供语言作用域和回退。应用入口只加载当前语言，节点文字走正常文本渲染，命名插值不得执行HTML。公共API须兼容现有Node前端测试；生成显式资源导入，不能把Vite专用glob作为唯一运行方式。应用语言独立于论文的原文/译文选择、输入文字语言和实验材料。

Qt原生提示和声道独立页面采用同一locale，通过现有受控桥同步；不改变后台科学任务的参数、默认值、输出结构或数据代码。服务器用户的语言不能借全局变量互相污染，错误在展示边界使用稳定码和参数本地化，原始诊断按原身份保留。

中文说明书源工程继续唯一维护。英文/日文保留可复核的富文本译文和源摘要，构建资源包时保留章节/帮助/资产ID；对应语言真实截图作为覆盖资源，原音视频复用中文包。默认软件仅含中文，外语包由用户主动下载/本机导入后安装和离线阅读；包和清单使用大小/路径/版本/源摘要及SHA校验，安装采用完整验证后原子切换，失败保留原可用版本。Web用本机存储及阅读适配，桌面用用户缓存及现有异步桥，不新建独立阅读应用或服务。

性能与正确性一起验收：切换语言只更新展示，不重新提交科学计算、不重载iframe、不清空未保存状态；冷/热路径、请求次数和资源生命周期需有证据。Windows最终成品与网页候选分别试用，Mac仅同步源码，待具备环境后另验成品。此次不执行公开发布。
