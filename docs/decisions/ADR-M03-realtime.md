# ADR-M03-RT：自动刷新与保持科学输出的传输优化

2026-09-29，井井要求修复 EGG 加载慢、完成后空白，按 V2 实时更新，并追加代码审查及修复。此记录追加到 ADR-038/046，不覆盖原科学语义。

- 选择文件后自动分析，分析参数和手势采用 180 ms 防抖。正在提交、执行或读取结果时只保留一个最新更新意图。当前任务结束后补算最新配置。明确取消时清除更新意图和结果接收版本。
- 更新期间保留上一份完整图形，坐标、F0 开关、色阶均绑定该图的参数快照。界面说明尚在更新，旧图不能作为当前选区试听、导出或逆滤波依据。切换源文件清空图形，迟到结果不跨文件生效。
- 历史恢复保留原始浮点 ROI 配置。采样对齐后的实际选择元数据仍用于科研追溯，不用它覆盖原始配置并引发误失效。
- 同源 hash、声道顺序、采样率及帧数不变时，交互更新复用已验证的内存试听音频；切文件清空，历史恢复仍全量读取。正式结果继续保留完整 WAV。
- Windows 公共管道仅在无数据可读时等待，每轮仍检查取消、输出上限、进程状态和超时；不修改所有权与进程组回收。
- preview 未请求 GCI F0 时省略未被使用的全段事件检测。完整文件归一化、去趋势、滤波继续执行；CQ/SQ、微观波形及事件继续调用原局部计算。请求 GCI F0、导出和逆滤波仍保留全段事件计算。预览不提前导入 CSV 导出依赖。
- 本机 EGG 使用存储适配器原已允许的 1 MiB 读写块。临时文件与正式输出每块仍同步落盘、校验租约、核算预留，不取消 fsync 或事务。托管存储及其他模块保持原块大小。ManagedScratch 默认仍为 64 KiB，只增加显式有界参数。

不新增常驻科学服务、算法或数据库 schema，不改变现存数据保留规则。当前仍是受限独立任务，自动更新不构成毫秒级实时响应承诺。性能必须分别记录纯计算、受限子进程与完整 GUI，而不能混用。当前平台验证见专项报告。
