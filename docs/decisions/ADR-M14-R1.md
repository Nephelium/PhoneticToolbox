# ADR-M14-R1：可配置导入、页内归并与结果快照

2026-10-05，accepted。井井在四步改版方案后明确授权继续。

新页面导入显式使用 `computation_revision=m14/2`，修复 Unicode 规范等价、连音符、独立元音前的近音识别，并支持尾部上标数字。原 `m14/1` 的任务、解析及导入路径保留，旧草稿须重新导入才能使用新页面生成结果。原始 IPA 不改写，分类符号使用 NFD 规范等价。

导入增加受限 child 内的 inspect 操作，先显示原始表格样例，再以明确列号、开始行、编码、分隔符、工作表或 DOCX 表格索引正式分析。沿用已授权资产与持久任务，不增加数据库 schema 或独立宿主。文本空字段保留，六种格式使用相同列映射。

调类与声韵编辑在当前页完成，本次编辑和已保存配置分离。页内保存将编辑合入工作草稿，顶部保存草稿及关闭保护负责本机持久保存。归并取消、还原与循环检查保留。

三种预览以已确认分析和生成时配置的不可变快照分组，分组、调类顺序、重复记录和备注与 DOCX/XLSX 对照验证。三件交付文件不变。修改配置后标记旧成果，不能用新配置解释旧文件。搜索索引全部记录，显示采用有界分页，命中跳转至所在页或矩阵窗口。

Windows Chrome、真实 Qt 与 WSL 核心证据分别记录于[验收报告](../testing/2026-10-05-m14-r1-report.md)，视口截图不等同于实体 DPI 或 Linux GUI 验收。保留原 Word/XLSX 呈现与文件协议，源 IPA 不因 NFD 分类而重写。
