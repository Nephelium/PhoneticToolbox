# ADR-M06-R2：修正声源标尺并保持 F0 编辑

2026-10-02，accepted，已实施，验证边界见 [报告](../testing/2026-10-02-m06-r2-report.md)。井井授权直接替换错误的旧标尺，不实现旧算法模式。

AV 与 AH 分别控制周期源与气流噪声。0 表示该源关闭，其余正数每增加 20 dB 振幅乘 10。数值范围采用 Klatt 原论文 0–80，但本项目的 60 dB 数字参考使用独立、可复现的 120 Hz 参考声源 RMS 标定，与物理 SPL、不同 Klatt 版本的绝对输出标尺分开。声源关闭在专用放大器中实现，普通增益 0 dB 仍等于 1。

新配置 m06/2 保存 f0_transform（类型及 Hz 偏移）；曲线保存实际用于合成的已平移数值。撤销预设只减去偏移，不恢复过期快照，因此用户在平移期间的编辑不会丢失。F0 覆盖值在预设平移时实体化为可编辑曲线。边界通过限制整体偏移实现，不改变各点差值。

历史配置 m06/1 无可靠等价映射，导入需明确报错，原文件不变。历史结果 WAV 仍是历史计算证据。新结果记录计算版本、数字参考及最终防溢出衰减。旧 V2 逐位测试保留作为差异证据，新增解析/独立测量验收，不以旧声音一致性约束已经获准的修复。
