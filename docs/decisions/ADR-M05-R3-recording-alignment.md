# ADR-M05-R3 录制选项与对齐工作流

2026-10-04，accepted。来自井井本轮明确实施请求。替代 ADR-M05-R2 中的停止后直接保存、候选记录独立按钮、录后 V2 重算按钮及 82% 面部显示安排。原科研模型及依赖身份不变。

- 模式仅实时预览、实时录制、高帧率先录后算。预览只申请摄像头，结束清除临时帧。结束录制不自动写入用户目录。
- 另存时默认勾选视频与动画。音频及完整实时唇形记录始终保存，视频和动画按选项生成。高帧率模式不运行唇形模型，保存视频音频，使用已有视频离线入口后算。
- 检查偏移量复用公共 ModalDialog 与 ScientificPlot，第一图为真实解码 WAV 声道 1 的 min/max 波形，第二图显示任选参数的各轨归一化曲线。共用时间范围和边距。正值向右移，毫秒输入、键盘重复、拖动和取消均支持。归一化不写入科研数据。
- 录制及离线媒体驱动面部回放，面部占可用画布最大 94%，参数/四曲线固定在下方。右侧栏最上方放视频，1280×800 保持三栏。
- 新候选记录显式标注估算起点，与音频首解码采样的 PTS 相减。手工偏移只保存一次。异步录制起点、设备延迟及滤波延迟不冒充已校准。
- 原生检查与编码使用本操作拥有的临时目录和受控子进程，最终只发布所选文件及回执。正常视频转换为 MP4。遇到重复/倒退 PTS，保留原始容器和哈希并提示，不制造新帧时间。未选视频时不转码视频。正式分析的严格时序要求不放宽。

限定 Windows 开发态验证。独立浏览器宿主没有此完整本机导出适配器时明确拒绝不完整保存，保留内存录制；服务器计算、浏览器独立完整导出、实体设备与 Linux GUI 不在本轮 verified 范围。见[时间审计](../references/m05-r3-timing-audit.md)和[验证报告](../testing/2026-10-04-m05-r3-report.md)。
