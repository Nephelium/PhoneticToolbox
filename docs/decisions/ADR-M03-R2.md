# ADR-M03-R2：EGG 临时交互会话

2026-10-01。井井明确要求 V2 式实时交互，停止将每次手势记作任务。本记录取代 ADR-M03-RT 的交互提交方案，正式导出仍沿用 m03/1。

## 计算和平台边界

Vue → ResearchFiles.eggPreview → 桌面能力桥或已认证的资源接口 → API → 固定兼容环境内的受限子进程。Qt 无科学依赖，API 不做数值计算，纯核心没有增加文件/进程依赖。

会话仅驻留内存。一次上传并验证真实双声道数据，复用全文件预处理、已请求的 F0 和一个主视窗。微观中心/宽度更新调用原局部波形及事件函数。默认旧 preview_files 导出接口保持字节兼容。科学配置、声道、首尾采样范围和缓存键分开，归一化音频只在首次/换声道传输。

每个 API 实例最多一个科学会话，后续打开使旧票据失效。票据绑定账号和资源 ID，本机绑定当次目录授权与文件指纹。托管每次更新前后重新检查资源归属、到期及账号。源文件读入上限64 MB，配置JSON上限16 KiB，响应上限64 MB。独立 Windows Job 限内存（本机3 GB、托管1 GB）、单次调用30秒、闲置5分钟回收，显式关闭和API退出均回收。小型Linux服务器/共享准入配置保持禁用，未使用此会话绕过其共享进程预算。跨平台实时计算另行验收。

首次处理仍需加载与预处理。前端30 ms合并交互，只允许一个请求在途，保留最新意图，源文件/请求版本阻止迟到结果覆盖。坐标、中心线和已有曲线投影立即移动，新区域在局部结果返回后补齐。试听/导出需对应已完成的当前参数，状态占用固定位置。失效会话自动重新读取当前授权源，不产生任务历史；旧预览记录保留存储但从页面列表隐藏。

## 显示变更

EGG显式启用普通滚轮、持续拖动，其他模块默认手势不变。CQ/SQ和语谱图使用相同边距，F0右轴常驻。总览每个可见声道按视窗内最大绝对值显示到半高的90%，高度92 CSS px，不改变音频或科学归一化。IF四图300 CSS px高、线条不透明度0.62，公共字体快照绘制到白底PNG并写入300 dpi信息。共享PNG尺寸/编码帮助函数迁至design，参数显示保留原路径重导出，避免模块相互依赖。

移除声门活动UI与新会话启用入口，旧配置字段和历史结果保持兼容。IF完成自动打开窗口，但切源文件后不会弹出旧任务打断当前查看。见本轮[验证报告](../testing/2026-10-01-m03-r2-report.md)。

井井追加要求高低通均改为数值输入，低通默认2000 Hz。该变化在页面和新批次的明确配置中实现；历史任务、已有草稿的明确值、核心及协议的兼容默认1000 Hz保留。以同一2000 Hz参数对照原预览和新会话，避免把用户要求的默认行为调整与算法一致性混为一项。
