# M09 音频编辑图窗与笔迹坐标

日期：2026-10-18。状态：accepted，按井井本轮固定图窗、可调图高及频率上限的要求实施。

## 问题

0.576秒、16kHz音频在FFT1024时只有38×513个STFT单元。按矩阵比例撑满图宽会把图高放大到一万多像素，首屏只显示高频留白。直接缩小整张矩阵又会把时间轴压成细条，影响绘图。浏览器圆形画笔的抗锯齿还会使1px笔迹覆盖3×3个像素，与核心的像素距离规则不符。

## 决定

- 音频图窗宽度随工作区，高度默认320逻辑像素，用户可输入或拖动调整至180–800。载入源、切声道或FFT保持选定图高，完整时间范围映射到图窗横轴。
- 显示频率范围为0至用户选择的上限，初始5000Hz，按源Nyquist频率限制。改变上限及图高只重新投影已存笔迹，不清空笔迹、不重新分析音频。
- 新音频笔迹记录绘制时的逻辑画布宽高和显示频带比例，像素中心距离决定覆盖，整笔只混合一次不透明度。核心以面积积分把覆盖映射到原STFT单元，在灰度域混合后沿用原幅值映射、原相位及ISTFT路径。细于原网格的图形受原网格分辨率约束，显示缩放不新增科学分辨率。
- 旧笔迹缺失上述可选字段时按原网格执行，legacy画笔沿用原OpenCV语义，缺省字段不进入旧请求快照摘要。图片涂鸦继续以校正图像素为单位，新前端使用与核心一致的二值距离栅格化。
- Windows、macOS、网页共用Vue及Python源码。网页本机计算运行库从同一份源生成并锁定摘要；服务器回退沿用同一模型和核心，无新增页面服务或数据库迁移。

## 验证

解析的像素直径、分数单元覆盖、频带裁剪、图高变化后的时频位置及旧快照兼容性由定向测试核查。真实Qt和Chrome覆盖自动显示、固定图高、频率/FFT切换、原生拖动图高、指针笔迹及音频导出。范围和未验项见[验收](../testing/m09-canvas.md)。
