# ADR-M10-R14 舌体厚度、表面控制与 257 截面

2026-10-07，accepted。井井要求修复过薄舌尖、舌叶圆点脱离组织、灰色窄片，并明确选择 257 截面。

舌尖半径按抬高、后卷及舌叶下降程度连续补偿，最大增加 0.18 cm。后卷时接入圆弧后侧，保留完整圆头厚度。构造、硬组织限位及声管使用相同半径。此数值为模型调节，不是解剖统计结论。仅加粗二维线条或只扩大原圆弧半径无法解决细颈及局部尖折，未采用。

舌叶圆点绑定曲线中点对应的原生分数肋位，插值最终接触处理后的正中表面。共享坐标用于二维与三维，拖动仍保存 TBX/TBY 参数，以 1.6 倍增益补偿柔性曲线中点的 5/8 控制权重。硬组织接触及参数边界仍可限制跟手距离，不将鼠标坐标伪装成实际组织位置。

气腔重建用 129/257 个横截面形成近似体积，前部陡峭舌面容易留下灰色细缝。二维在硬腭起点之前保留现有鼻腔/软腭剖面，在其前方以原生上下壁和内唇缘构成口腔外边界，并扣除当前三维舌体的正中切面、牙齿及软腭。三维气腔仍为截面重建参考，面积图与声音继续取原生求交结果，不从着色面积计算科研输出。

原生纵向截面改为 257，横向仍为 96 个采样点。原生计数查询决定 Python 缓冲区和前端端点，不靠固定数组长度推断。声学管段数量、原始 API、speaker、构形/关键帧格式保持。细采样会改变中线、面积及传递函数，不能声称仅视觉变化。构建入口支持独立 129/257/513 档实验，产品默认 257，不新增用户设置。
