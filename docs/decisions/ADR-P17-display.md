# ADR-P17 统一显示与单页布局

2026-10-01，用户明确授权，实施中。

所有使用公共 WaveformViewport 的模块默认启用可见窗振幅定界、正/零/负轴刻度及原采样点连线。细节连线门限由每像素4点改为16点；按用户后续大屏要求，显示像素预算从1600提升到4096，最多约65,536个原始点，更密集视图保留峰值包络。这是显示规则修正，音频数组、科学参数、试听增益与数值导出不改变。EGG专属微观图由模块适配，保留其归一化量纲说明。语谱图显示画布随区域增长，科学预览自身既有时间/频率网格预算保持不变。

模块公共内边距/区块间距/控件高度改为10/8/30像素，字体与色彩角色保留。ModuleFrame提供可选fit高度，模块负责用可收缩图窗、独立列表/历史滚动和高级参数折叠容纳内容。禁止裁切功能来掩盖滚动。M10无专属修改。

## 用户追加后的三栏规范

井井看过实际截图后要求继续统一三栏，并指出顶部空行浪费高度。采用共享 `ModuleWorkbench`：左侧输入和常用参数、中间主要图窗或编辑区、右侧任务/处理记录/导出。无任务的模块放已有结果或辅助工具，不制造假任务。M12保留原有专业三栏但对齐顶部和辅助入口规则，M10独立。

备选方案包括继续压缩控件和把整页内容改为滚动面板，均不能解决图窗过小与左栏拥挤。三栏方案把有限高度优先分给图窗，长任务列表在右侧独立滚动。右栏默认展开，允许折叠及本机记忆；沿用公共可拖栏宽和键盘调整。内容宽不足1060px时右栏移到下方，不足720px时顺序堆叠，保证小窗操作可达。

模块上边距统一4px，网页项目返回按钮并入标签栏。不再保留仅右侧一个方法/引用按钮而独占整行的工具栏。常态提示移到右侧或现有紧凑行，错误和执行中状态仍可见。M06/M07/M08专用可编辑SVG使用真实容器尺寸计算坐标，保留图形字号，避免压缩SVG导致刻度难读。

井井随后指定EGG为两栏例外：主区四图与总览，右窄栏集中参数/操作/历史，优先增加子图实际绘图区。公共组件通过省略left插槽实现，不另复制布局框架。发声类型合成改为全页三栏，左侧F0数值表与分析，中间双波形和曲线，右侧生成与任务。

大屏以可用宽高布局，1920仅为最低目标。ScientificPlot增加可选fill模式，读取有界父区域的真实高度，扣除图例后设置SVG坐标系；原字号、坐标值和事件语义保留。模块用剩余空间分配图高和表格行数，不为1440/4K屏幕保留固定1080画布。

波形及其公共Praat语谱图的横向绘图区共用振幅轴预留空间，保证时间坐标对齐。科研专属图（F0、CQ、频谱等）仍保留自身科学语义。验收以P17总规则及真实录音报告为准。

## 本机语谱图预览会话

真实短/中/EGG输入测得原有每次启动进程的语谱图耗时0.50–0.67秒，前端另有250ms去抖。Windows本机API实例将持有一个懒启动的有界Praat预览子进程，只缓存当前一份解码音频，以内容SHA-256决定复用。保留原核心函数与JSON像素网格，不改变窗长/帧移/预加重/灰度。进程组上限1GB、单请求20秒、空闲60秒退出，API关闭必回收，验证失败重建。服务器及非Windows保留原独立计算路径，不扩大平台准入。本次无数据库或公开API schema修改。
