# 相同依赖只保存一份，原路径恢复

2026-10-07，井井授权实施。跨环境共享采用文件大小与 SHA-256 双重匹配，不能按文件名或版本号判断相同。

后续授权改为[持久启动缓存](ADR-persistent-startup-cache.md)，下述私有临时展开目录是本轮较早候选方案的记录。相同字节共享约束继续适用，最终生命周期按后续决定执行。

科学环境仍以原 XZ 分发。主环境 host-files/2 保留完整逻辑文件清单，sharedFiles 将主路径映射到科学文件；manifest 同时绑定科学 archive/manifest SHA。host-payload 只包含未共享成员，逻辑展开预算仍覆盖全部原路径。

首个 Python runtime hook 在 Qt 载入之前恢复科学文件、主环境独有文件与共享路径。优先在 bootloader 私有展开目录中建立同卷硬链接，失败时用独占新文件复制原字节并校验。共享源与目标禁止重解析点、路径别名和已有目标覆盖。完成标记覆盖主包和共享映射身份，只有全部恢复后发布，子进程复用已完成目录。

库原字节、相对位置、加载方式和科学环境隔离保持。主 Qt DLL 仍对指定宿主逐一验证。manifest v1 向后兼容，旧缓存不能被当作 v2 去重缓存直接复用。下载量与磁盘逻辑文件量、实际物理占用分别报告。
