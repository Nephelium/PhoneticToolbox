# M12：参考标注按时间交集复用与音频首尾定界

2026-10-19。状态：accepted，按井井本轮明确要求实施。

## 决定

- 参考层与当前同名层不再要求整体 xmin/xmax 相等。每层只替换复用模式选定范围、参考层时间域与当前层时间域的交集，跨界区间截取，保留原时间位置与标签，不拉伸、不平移。
- 参考未覆盖的时间段保留当前标注。点层沿用闭区间端点语义，仅替换交集中的点。无同名层、无交集、交集中的层类型不兼容分别提示；先计算全部层结果，再写入并创建一个撤销记录，失败不部分替换。
- 当前文件和各层时间域保持原值；输入框不必精确匹配音频末尾，超出当前范围的选择按文件域裁剪。与原范围相同的旧复用结果继续通过 V2 对照。
- 波形、语谱图、标注层双击时，距可见音频起点/终点 6 个 CSS 像素以内命中原音频端点。内部视窗边缘不吸附，普通点击、拖选和边界拖动不变。
- 命中音频末尾后，如 WAV 时长与已通过加载检查的 TextGrid 文件域只差最多 1 微秒，使用 TextGrid 原始终点建立区间。中间双击仍按既有六位小数秒精度定界，不修改源音频和文件时间域。

## 验证

定向测试核对四种模式的独立预期、长短域、局部层、点层、无交集/类型失败原子性和撤销，及首尾命中、内部视窗不吸附、WAV/TextGrid 舍入差异。独立 Chrome 使用合成 WAV 与 TextGrid 检查真实双击和保存。实际范围及未验项见[M12 验收](../testing/p17/M12-report.md#2026-10-19参考时间交集与首尾双击)。
