# ADR-M04-R1 空白 TextGrid 尾段与直接拖选

2026-09-29，按井井本轮明确修复要求实施。覆盖 ADR-049、ADR-056 中仅 M04 的 Shift 必须按住的手势约定。

TextGrid 可保留比裁切后 WAV 更长的空白域。LPC 只从实际 WAV 的合法 ROI 求解，TextGrid 用于标签。越界的空白或纯空白字符区间不再阻断任务；有内容的越界区间仍拒绝，不通过扩大容差掩盖错配。原始 TextGrid 的内容、哈希、标签拼接规则保持不变，界面提示空白域超出音频。标注点击只选中与音频相交的部分，完全在音频外的区间不生成非法选区。

M04 波形与语谱图均用左键直接正反向拖选，Shift 兼容拖选，Ctrl 滚轮缩放保持。移除 M04 页面传入的 `selectionRequiresShift`，公共组件及其他模块默认行为不变。时间范围、参数、分析/取消和试听集中在已有可调左栏，图窗和任务/结果留主区，窄窗自然堆叠。

科研核心、协议、数据库、默认阶数/频率/幅度、第三方依赖均不改变。验证范围见 [修复计划](../plans/2026-09-29-m04-repair.md)。
