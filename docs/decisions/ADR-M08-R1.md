# ADR-M08-R1：合成历史与外部保存分离

2026-10-04，按井井明确要求接受。

旧 history 仅返回 saved 标记为真的批量结果和复制任务，导致手绘普通合成没有对比曲线。旧试听只切换结果，外部保存与受管复制混在一起。

当前决定：历史收录所有同源、可读取、成功的合成结果，继续保留原始 saved 字段兼容旧 adapter。手绘目标 F0 和实际输出重新提取的 F0 保持区分。历史读取不新增任务、不重算、不迁移。

新保存入口导出现有 WAV，桌面一次授权目录并逐项落盘，网页有界 ZIP 下载。保留旧 save 协议供兼容使用，页面不再提供保存并编号入口。导出不刷新到期时间，不改算法、帧网格、PCM 格式或科研来源。

直接试听使用共享 AudioController。选区播放组件允许调用方声明当前为独立试听，保证点击播放选区从鼠标选区起点开始，且不改变原始或合成波形的选区。

同名输出独占创建并加数字后缀。同一结果在同一目录的未变化副本重复保存复用。删除 / 重命名仅涉及明确 ID 与本会话导出关联，外部改动先拒绝。旧会话文件不扫描关联。

2026-10-05 M08-R2 补充：按井井的保存位置反馈，原生导出报告追加可选`directory`显示元数据，值来自已授权且成功导出的本地目录。前端只展示该值，不用它读文件或建立新路径授权。网页报告不推测用户磁盘路径；旧adapter缺失该字段时仍兼容。数值编辑采用文本中间态，在明确操作时构造数值快照，科学配置类型和后端协议保留。范围与验收见[M08-R2计划](../plans/2026-10-05-m08-r2-input-layout-save.md)。
