# Preview 1 Windows 包装与独立科学环境

日期：2026-10-05。范围：井井要求的 Windows 免安装 EXE、当前用户安装 EXE、更新与数据保留。

完整应用展开约 5.28 GB，含三套有精确版本凭据的科学环境。首个目录构建实际出现宿主 Qt 6.11.2 与 MFA Qt 6.6.1 混入问题。修正为先冻结主宿主，再复制独立运行时，逐文件验证宿主 Qt 摘要。

免安装单文件采用一个自解压 EXE 交付完整目录。首次运行选择新目录、解压并启动。后续直接运行该目录内的主 EXE，不需每次重新展开 5 GB 环境。免安装包没有卸载器、安装登记、系统快捷方式或管理员要求，拒绝覆盖已有程序目录。该包装保留直接使用目标，但不声称只有一个文件长期驻留磁盘。完整 ZIP 同时保留，供手动解压和应用内增量版本目录切换使用。

当前用户安装版默认 `%LOCALAPPDATA%/Programs/PhoneticToolbox`，单独稳定 AppId，提供卸载入口及可选桌面快捷方式。两种包装共用固定用户设置、任务与工作台目录。安装、换版、卸载均不删除研究数据。

应用内免安装更新下载 ZIP 后创建新的版本目录，安装版更新运行安装 EXE。辅助程序先验证冻结启动资源，再等待真实旧进程句柄退出。旧版本目录保留，自动结果清理不涉及程序版本目录。

预览成品的科学任务、17 个帮助跳转、真实换版和固定用户数据保留分别核验。自解压包装还须验证目标拒绝覆盖、无安装登记与启动数据恢复。物理听辨、摄像头、实体 DPI、自然准确率和跨平台不在本轮通过范围。来源通知、对应源码与未决授权独立记录，预览标签不代替发行义务。
