# 语谱图自动重建独立组件

2026-10-15。按井井本次明确要求实施，使用现有宿主、任务、组件安装器和四件套输出，不改研究训练工程。

- 默认保留 Griffin–Lim，新增显式选择的 Mel 谱 → NAFNet → BigVGAN，前面共用 GL。默认 GL 32 次，允许 1–256 次。
- 时长、频带和线性/对数轴由用户填写。预测窗宽按最近整数毫秒、0.5 向上取整，帧移为实际窗宽的 1/4。以实际取整后的窗宽判定，小于 15 ms 使用 Aoki 投影峰脉冲初始化，达到 15 ms 使用固定种子随机相位。这是本次应用策略，研究项目旧 20 ms 规则不改。
- 参数模型只预测窗宽和动态范围 D，显示 −D 至 0 dB，不推断绝对声压。两种算法共用显式预测按钮，必须先填写时长/频率标定。一次点击只填入一次预测，重建发送实际手动值，不再自动预测。新UI固定reconstruction_profile=calibrated，修改预测值不会切回旧灰度映射或时间网格。旧快照省略该字段时保留legacy路径。Aoki初始化另设auto/pulse/random，auto才按15ms判断。
- 新链使用相对 20log10 幅值、Hann、快速 GL 动量 0.99；在不低于 24 kHz 的 4 kHz 整数倍内部网格计算，以精确表示整数毫秒和四分之一帧移，再按目标采样率重采样。保留请求时长，默认输出率为ceil(2×频率终点)，独立于内部计算率。最终频谱按输入时间/频率坐标重采样成同尺寸PNG，只显示所填频带。
- 保留 BigVGAN 的原生 22.05 kHz、80 Mel、1024/256 Hann 前端与频带覆盖掩码。修复条件沿用研究转换中的未知标记，不用错误的图片条件替代 GL 再分析条件。
- 图片最终输出做整体增益：RMS 目标 0.08，峰值最大 0.95；静音不放大。音频绘图保持原相位及现有通道语义。
- 窗长/动态范围联合预测模型以压缩 float32 NumPy 数组内置于 core 包，303856字节，worker 复用已有 Pillow 预处理和 NumPy 计算。预览不查询组件安装状态，重建在主应用预测后将实际参数交给可选组件。旧 r1 组件中的预测被显式关闭，避免两套模型重复运行。
- CPU组件保留独立下载，界面提示推理可能较慢。按本轮新增授权，GPU复用用户选择的已有Python：原生文件框发放临时授权ID，后台探测依赖/CUDA/真实修复与声码器，成功才原子保存用户级gpu-python.json。前端和HTTP不接受解释器路径。auto优先使用已检查GPU，cpu强制组件Python，cuda失败明确报错，不静默切CPU。GL与内置预测仍在CPU执行。应用自有适配代码从当前源码执行，组件只提供经固定manifest校验的依赖/权重，旧组件中的计算副本不再控制新任务。
- 新包未公开时 catalog published=false，界面显示未发布且禁止下载。旧已安装声码器按原摘要继续识别。公开上传需明确授权，并落实训练语料对权重分发的许可条件。

新笔迹记录size_unit=px，直径1–200个校正图像素，画布保持等比例显示。旧笔迹省略单位时保留旧光栅化，避免重试改变图形。
