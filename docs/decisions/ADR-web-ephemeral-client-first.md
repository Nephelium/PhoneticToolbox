# 网页临时工作区与浏览器计算分工

2026-10-16。状态：产品方向已确认，基础实现已进入隔离验证，生产与跨平台待验。用户已确认首期由服务器计算，浏览器算法迁移放到后续优化，Windows/Linux外接电脑仅预留接口且不作为上线依赖。开放自助注册、主动退出清理、直接关页/断网/崩溃最后心跳后30分钟及MFA仅桌面推理的要求保持不变。本页原位替代此前的浏览器优先决策。

## 2026-10-17 浏览器迁移授权

井井明确要求将适合的科学计算下放浏览器，并允许微小浮点差异。采用同源、按需、有界Worker复用原core，原版Praat6.1.38编译为WASM，不复制科学公式。交互与小型重建各一条串行通道；原生VTL/REAPER、长批次及未移植的原生操作保留服务器，MFA推理准入保持。旧原生回归不放宽，浏览器整数参数、时间网格、形状与掩码保持，数值误差单独记录。

浏览器重建四个结果和执行快照沿原资产API保存，按账号/项目恢复并沿用TTL，离开执行页的旧任务标记中断，不伪造服务器队列状态。账号退出终止Worker、在途/排队请求并清除进程内源字节缓存。访问仅nephelium，官网入口/注册/找回关闭。服务器科学计算集中使用CPU 1，P11共享一核总限额，API与网页服务保留另一核余量；生理合成独立进程须同样绑定计算核心。详见[迁移计划](../plans/2026-10-17-browser-compute.md)。下文首期服务器路线保留历史实现边界，由本段更新当前分工。

## 会话与关闭

所有模块的操作参数和显示设置随账号保存在服务器，不随上传或生成内容清理。2026-10-17按用户纠正，替代此前仅浏览器保存的不足实现。新增独立的账号设置表，不引用临时工作区、项目或资产，不设到期时间；换浏览器、换设备及清除站点数据后，登录仍从服务器恢复。登录读取成功后再挂载工作台，退出前等待待保存设置获确认。首次升级可将旧账号专属本地设置导入尚无记录的模块，已有服务器值优先。各模块明确声明设置字段，文件引用、曲线/图像编辑内容、实验刺激/回答、论文及批注继续使用原内容存储，不复制进设置。

服务器以修订号防止整份旧快照覆盖新数据，客户端只重放实际修改的字段；不同设备修改同一字段时以后一次成功写入为准。设置请求只要求有效账号及写入时的Origin/CSRF，不要求活跃内容工作区，也不为内容续期。新增011迁移先在全新隔离PostgreSQL验证，现存服务数据库迁移和实际部署范围另行核定。

账号身份长期存在，研究数据附属于短期工作区。授权身份、工作区心跳租约、科学任务 attempt/代数分别管理。工作区归属账号与当前浏览器会话；同一工作区的多标签共享存活判断，同账号另一设备的工作区不因本设备关闭而删除。

主动点击退出是可信结束动作。仅靠unload/pagehide或网络断开无法稳定区分关页、刷新和故障，hidden也可能是切换标签或最小化。用户已明确优先避免误删，因此当前实现不发送页面卸载删除请求，也不以页面关闭触发短延时或立即删除。直接关页、断网、休眠和崩溃统一使用服务器心跳租约，最后有效心跳后1800秒才清理。建议心跳30秒作为实现起点，按跨浏览器与负载实测调整间隔。

同账号同工作区在期限内重新attach可恢复，恢复后的旧关闭请求及迟到worker回传不能使新代数失效。服务端时间达到截止就原子关闭；运行任务自身、轮询/下载链接或重打ZIP不能充当用户心跳续存。多标签至少一页有效则工作区继续存活，服务器重启保留原last_seen，不重置30分钟。完整数据边界和事务见[账号规格](../specs/accounts-storage-jobs.md)。

依据：[MDN sendBeacon](https://developer.mozilla.org/en-US/docs/Web/API/Navigator/sendBeacon)说明卸载事件可能不触发、返回值仅表示排队；[Page Visibility](https://developer.mozilla.org/en-US/docs/Web/API/Page_Visibility_API)说明页面隐藏与后台计时器节流。上述租约与关页统一延时为本项目设计，不声称由浏览器原生提供可靠的关闭判定。

## 计算与分发

首期科学任务经同源API提交到有界队列，由服务器worker调用已有科学核心，统一执行资源、任务和存储准入。结果发布前校验账号、工作区存活、执行代数和输出配额，退出或到期后的迟到结果不得重新建立历史。所有开放操作必须有最终Linux与网页账号链路证据，不能把现有Windows或限定WSL结果扩大为生产可用。

共用Vue工作台，保留现成的播放、编辑、绘图、音标转换和客户端感知实验。浏览器文件选择/下载、麦克风/摄像头和桌面桥替换属于必要的平台适配；新增Worker/WASM/WebGPU科学算法移植放到后续，根据实际负载选择。原本留在客户端的材料不因服务器方案自动上传。

预留执行器能力查询、开始、进度、取消和结果提交接口，首期仅启用服务器执行器，不假设有外接电脑或GPU。未来Windows/Linux可信节点沿用任务快照、remote/1、归属/租约/发布校验及相同工作区期限，待硬件与实际科学链路验证后单独启用。

MFA在网页的前后端均关闭推理能力。桌面现有本机计算及保留策略不变。参数预测/修复等模型的下载与发布必须单独核实模型、训练来源与权重分发范围，不能因在浏览器运行而免除分发核对。

## 实施边界

注册与工作区基础实现使用008/009增量脚本，容量管理使用010增量脚本，已获准在新建隔离PostgreSQL验证。现有 storage_policy.py 保留 policy_version=2、259200秒兼容路径；新策略显式启用workspace_policy_version=1，用持久化工作区截止、项目映射、数据库写入检查及清理器实现。每个标签向同一登录会话的工作区发送心跳，无须用不可靠的关页事件统计最后一个标签。见[实施验收](../testing/web-launch-foundation.md)。生产数据库、旧资产和备份不因本决策自动删除。后续工作见[上线计划](../plans/2026-10-16-web-launch.md)。

## 容量管理补充

默认1 GB，管理员可调整默认值及单独账号值，用户申请后人工审核。额度只限制实际占用加预留，不预分配磁盘。暂不按在线人数自动缩额，不自动删除未到期数据；全站磁盘水位始终独立限制新写入。当前开放操作的单输入文件暂限100 MB，视频处理额度由逐模块峰值实测决定。在线人数使用90秒心跳窗口，账号去重，与1800秒恢复窗口分离。临时审批允许改批期限/额度及留言，过期恢复个人常规额度或当前默认，已接受的预留仍可完成，新增预留独立受额度和磁盘水位限制。
