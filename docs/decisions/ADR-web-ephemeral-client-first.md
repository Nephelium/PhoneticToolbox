# 网页临时工作区与浏览器优先计算

2026-10-16。状态：产品方向已确认，技术方案待实施验证。用户已确认开放自助注册，主动点击退出立即启动清理，直接关页/断网/崩溃统一从最后一次心跳起保留30分钟；MFA改用桌面推理，可在浏览器完成的工作优先本机执行。

## 取舍

| 方案 | 影响 | 决定 |
| --- | --- | --- |
| 保留旧1 GB/3天历史空间 | 实现已有基础，多人长期占用仍会累积 | 不再作为新网页版目标，保留历史兼容证据 |
| 所有操作强制浏览器执行 | 服务器负担最小，原生科学库/编解码/大型模型移植会阻塞交付 | 适用于已验证的客户端功能，暂不要求全模块一次完成 |
| 浏览器优先 + 会话临时服务器任务 | 已有前端能力先复用，必要任务按预算准入，结束或失联到期后回收 | 采用；MFA明确禁止线上推理 |

## 会话与关闭

账号身份长期存在，研究数据附属于短期工作区。授权身份、浏览器标签租约、科学任务 attempt/代数分别管理。工作区归属账号与当前浏览器会话；同一工作区的多标签共享存活判断，同账号另一设备的工作区不因本设备关闭而删除。

主动点击退出是可信结束动作。仅靠unload/pagehide或网络断开无法稳定区分关页、刷新和故障，hidden也可能是切换标签或最小化。用户已明确优先避免误删，因此自动页面关闭提示只标记标签离开，不触发短延时或立即删除。直接关页、断网、休眠和崩溃统一使用服务器心跳租约，最后有效心跳后1800秒才清理。建议心跳30秒作为实现起点，按跨浏览器与负载实测调整间隔。

同账号同工作区在期限内重新attach可恢复，恢复后的旧关闭请求及迟到worker回传不能使新代数失效。服务端时间达到截止就原子关闭；运行任务自身、轮询/下载链接或重打ZIP不能充当用户心跳续存。多标签至少一页有效则工作区继续存活，服务器重启保留原last_seen，不重置30分钟。完整数据边界和事务见[账号规格](../specs/accounts-storage-jobs.md)。

依据：[MDN sendBeacon](https://developer.mozilla.org/en-US/docs/Web/API/Navigator/sendBeacon)说明卸载事件可能不触发、返回值仅表示排队；[Page Visibility](https://developer.mozilla.org/en-US/docs/Web/API/Page_Visibility_API)说明页面隐藏与后台计时器节流。上述租约与关页统一延时为本项目设计，不声称由浏览器原生提供可靠的关闭判定。

## 计算与分发

客户端优先解析、播放、编辑、绘图、实验运行及有证据的科学计算。Worker减少界面阻塞，WASM/可选WebGPU分别验性能、算法一致性与设备支持。需要服务器的操作必须显式提交，统一受资源/任务/存储准入管理。失败不得静默上传研究材料，浏览器结果用于服务器后续任务时仍由后端校验格式、归属、大小和参数。

MFA在网页的前后端均关闭推理能力。桌面现有本机计算及保留策略不变。参数预测/修复等模型的下载与发布必须单独核实模型、训练来源与权重分发范围，不能因在浏览器运行而免除分发核对。

## 实施边界

本轮只更新需求、计划及任务状态。现有 storage_policy.py 仍是 policy_version=2、259200秒；不能仅把常量改为1800来实现会话语义。需覆盖工作区、标签租约、任务发布、缓存、审计与物理清理，提出新版本协议/数据库增量迁移后再实施。生产数据库、旧资产和备份不因本决策自动删除。后续工作见[上线计划](../plans/2026-10-16-web-launch.md)。
