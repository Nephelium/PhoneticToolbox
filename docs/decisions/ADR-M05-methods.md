# M05 方法身份与时间/缺失语义

2026-09-27，用户本轮要求内 accepted：指标不重设计；浏览器候选不能静默替换历史算法。

- 原检测是 MediaPipe legacy FaceMesh 0.10.14，单脸、refine_landmarks=true、检测/追踪阈值 0.5。候选 Face Landmarker Web 为独立 backend_id，模型 revision 与 SHA256 入元数据。相同 478 索引不证明同一检测算法。
- 原指标是屏幕二维投影：x*width、y*height，float32；面宽使用 x 差，面高使用 y 差。无头姿三维校正，无镜像/头姿旋转归一化。视频解码保留 V2 OpenCV 默认的容器显示旋转（0/90/180/270 度），不同于科研头姿校正。预览镜像不得进入测量坐标。
- 官方 Web 单脸 VIDEO 存在模型自身平滑。原 One-Euro/运动门控为额外后处理，必须记录两者，不把开关关闭称为关闭所有平滑。
- 原上传视频使用 frame_index/fps，原实时/高帧率保存实际采集时间。本轮真实解码 PTS 是用户明确要求，作为 `decoded-pts/1` 单列；不可宣称与旧离线时间轴完全一致。
- 原离线缺失采用前值保持，前导缺失用首个有效值回填；实时保存只对最多 2 帧短缺失插值。保留兼容轨及原始检测有效性，补全不计检测成功。原始测量轨保留缺口。
- 旧 offset 语义为对时间加 offset，原数据时间不重复平移。自动互相关只是建议，不能声明生理对齐。
- 本地浏览器采集默认不上传，保存至本地；覆盖旧计划中浏览器必经上传存储的描述。云端保存/分析需用户显式选择并走公共配额/TTL。
- 备选：全部浏览器正式分析尚无等价证据；全部远程实时推理违反本地优先与隐私要求。采用浏览器候选预览+原后端离线分析，能力逐平台准入。

官方说明：https://developers.google.com/edge/mediapipe/solutions/vision/face_landmarker/web_js

- 2026-09-27 实机纠错：V2 显示拓扑为 TESSELATION∪CONTOURS 的全部连线及 478 个点，不能以科学指标的三个轮廓代替。异步预览显示同一输入快照与其关键点，停止后使用该帧尺寸。此为绘制/时序修复，不改变指标规范。
