# M13 Unt 作者网站修订与可逆儿化组合

用户明确授权仅更新 Unt 宽、严式两列，补齐遗漏、同步引用及版本，并增加自动和手动儿化组合与拆分。作者记音修订保持其他八列IPA；用户随后授权已查证的字音错误统一修正。正常字音、汉字库存和读音顺序保持。

## 取值

以 https://phesoca.com/aws/268/ 在2026-10-11读取的正文为依据，更新记录末项为2024-10-11。正文文本摘要记录在规则资源中。采用正文的中派基准，自由变体取第一项，宽式上声214、严式中派上声213。不将新派值混入中派。轻声缺上下文时不猜声调，的/么等明确的轻声虚语素采用ə。

文章正文与更新摘要存在不一致，忠实采用正文并在规则说明记录，不机械全局替换。io、ê及成音节辅音未列儿化对应，不造值。hm/hng只出现在更新记录中，未给出现行音值，不据此添加汉字读音。统一恢复29条因旧表缺失值处理而丢失的nan拼音，不改其既有IPA；diu1、bei0、ashu、葛/be、额/ge及距/shu共10条异常读音依据官方字典修正至全部标准。补齐旧列时采用本列同音节的既有值，diu按di声母和liu韵母组合，不移植Unt记音。萡/be仍缺可靠读音而保留缺值。

## 操作与状态

组合是输入文字上独立的位置决定，原文本和每个字的多音选择保留。仅选择Unt宽式或严式时显示左侧儿化操作区和读音小窗的组合、拆分按钮。按钮一次组合所有可转写的相邻字＋儿/兒，点击结果字组可组合或拆分，另提供全部拆分。词义需人工判断，例如女儿和儿子。组合不跨标点、空格或换行，不重复把已组合的儿作韵腹。保留前字声调，不加儿的独立声调。切到其他标准时隐藏儿化控件并显示原逐字值，切回Unt保留组合决定。文本编辑只保留未变公共前缀/后缀内的完整字对。

旧v1草稿兼容，缺少组合状态视为空。显式恢复、保存和PNG快照均携带组合决定。开启仅音标或隐藏声调不改变决定。
