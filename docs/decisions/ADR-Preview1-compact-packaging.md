# Preview 1 单文件与必要运行时

2026-10-06。此决定按井井后续要求替代旧 Preview 打包 ADR 的 SFX 目录向导方案，版本仍为尚未公开发行的 `3.0.0-preview.1`。

2026-10-07 后续决定：生命周期改为[持久启动缓存](ADR-persistent-startup-cache.md)，首轮准备后保留并按内容校验复用，下述每次临时展开方案保留作历史记录。井井也明确要求说明书不再冻结，可持续追加、修订和预留内容，当前按[严格打包规则](../../release/PACKAGING_RULES.md)只验基本阅读与已有资源引用。

免安装版为直接启动的应用 EXE。安装版包含同一个应用 EXE，以当前用户方式安装。两种 EXE 上限均为 500,000,000 字节，更新 ZIP 也执行相同限制。不得以本机开发环境绑定或文件夹版代替这项要求。

MFA 独立环境、声学模型和词典排除。EGG/LPC 使用原 NumPy、SciPy 和 MKL 构建，唇形使用原 FaceMesh、OpenCV、PyAV 与必要模型。移除范围依据实际入口、导入和输出对照确定，包括未使用的 JAX/SciPy 唇形依赖、非 FaceMesh 模型、开发组件。正常导入所需的 NumPy testing 支持保留。

科学环境与宿主分别使用 XZ 压缩原字节。主程序保留解压所需的 CPython 与标准库原生模块，首个冻结启动 hook 校验并恢复宿主原生文件，之后再运行标准 Qt hooks。应用入口校验并展开科学环境。文件路径、Windows 别名、重复项、链接、预算和哈希均须检查。子进程复用父程序已完成的临时展开，正常退出由单文件 bootloader 清理。

压缩改变分发体积，不改变库版本、科研公式、原生模型或文件协议。代价是每次新启动需要解压和校验，临时空间约 2 GB。用户设置、草稿和研究数据仍使用原固定目录，与临时运行目录分开。

说明书内容和媒体冻结。构建快照只选取已被正文引用的媒体，保留其原字节和所有引用关系，作者工程及未引用的素材完整保留。此步骤不能宣称已解决说明书内容问题。

验收须同时包含大小和哈希、工程之外实际冻结运行、原完整环境输出对照、同包子进程、实际媒体导出、单个 EXE 无控制台启动，以及两种实际更新后的设置、草稿和工程摘要保留。隐藏窗口或合成设备检查不等于另一台干净电脑、实体声卡/摄像头、自然准确性或实体 DPI 验证。

服务器仅先私有暂存并回读哈希，GitHub 暂停。未明确的再分发许可和完整原生对应源码继续作为对应公开发行物的验收阻断项。
