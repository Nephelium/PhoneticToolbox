# ADR：反馈会话与管理员通知

状态：用户已批准实施，当前源码两端及服务器已实施；2026-10-11 用户提供客户端授权码后，邮件已接通。

反馈身份与研究账号分离。当前 SMTP 已接通，部署配置 `allowUnverified: false`，用户首次验证邮箱，验证过的邮箱可恢复其已验证会话。邮件暂停期间已建立的未验证会话由本机随机凭据与 Windows DPAPI 保护，保留原凭据后可继续访问及通过验证码升级原会话；邮箱验证后的会话使用180天滑动会话期限。相同未验证邮箱不合并身份，也不能靠填写邮箱读取其他设备的会话。邮箱已有其他已验证会话时明确拒绝静默替换当前历史。凭据丢失时不能仅凭未验证邮箱恢复。不以 IP、硬件序列号或设备指纹认人。

反馈数据库独立于科研任务数据库和资源额度，不运行现存库迁移。初次部署使用反馈 schema 2，入口拒绝自动升级旧测试库。消息、私有图片及回复邮件队列在同一事务提交。附件只允许解码成功的 PNG/JPEG/WebP，并重编码去元数据，限制数量、字节及像素。

管理员使用单独静态 Vue 页面和 Qt 宿主，无研究模块、无独立页面服务器。管理员凭据只保存在管理工具，不进入普通用户安装包。电脑主动建立 HTTPS SSE 通道，无需用户电脑开放端口。

Windows 独立 EXE 与 Android APK 共用管理页面。手机通过电脑生成的8位、五分钟、一次性配对码获得独立随机凭据，允许电脑撤销，关闭应用和重启后保留登录。服务端设备授权保存在同目录受保护 JSON 中，凭据只存 HMAC 摘要，不更改 schema 2。配对尝试和生成频率受限，撤销后既有 SSE 也终止。手机端用 Android Keystore 加密，关闭备份和迁移；独立签名保存在工程外。

每日检查在服务器按 Asia/Shanghai 日历执行，默认 09:00；一次事务保存日历检查回执与新增留言通知。通知持久保存，SSE 推送或重连补收；桌面关闭时不保证即时展示。邮件暂停期间的旧回复不自动补发；当前邮件开启且邮箱已验证后，新回复立即进入持久队列并重试，与每天提醒的日程无关。已有未验证邮箱的新回复继续保存在应用，验证后才对后续新回复发送邮件。

用户新留言另外在原消息事务中保存即时事件，幂等重试不重复。管理员回复生成会话变更事件，其他管理端同步更新。安卓用户允许通知后启用明确常驻的 remoteMessaging 前台服务，接收即时事件和每日补充通知，已读留言不再触发新提醒。电脑关闭窗口仍在托盘接收，主动退出才停止；手机强行停止、断网或 HyperOS 后台限制的恢复边界在使用说明中明确，不创建 Codex 自动化。

邮件使用用户指定脚本中的邮箱及授权码作为私有部署输入，只静态解析，禁止执行其批量发信逻辑。脚本原腾讯地址与当前中大学生邮箱平台不匹配，已按[校方SMTP设置](https://inc.sysu.edu.cn/cat/165)在服务器私有配置中更正为 `smtphz.qiye.163.com:465`，使用 TLS。凭据仅通过已认证SSH的输入流送入服务器，在原目录以0600权限原子更新，不复制整个脚本。不在日志记录邮箱、验证码、凭据或正文；业务库不持久保存 IP，反向代理与系统日志须部署现场核对。

## 回复邮件偏好

用户在会话中选择是否为每条回复接收邮件提醒，已有会话默认开启。设置由已认证用户令牌限定到本人的 owner，禁止管理员或其他用户代改。保存于现有私有 feedback-admin-devices.json 的 mailPreferences，沿用文件锁、0600 和原子写入，不修改 SQLite schema 2。关闭时将未投递/失败回复置为 skipped；过期投递租约恢复后也检查偏好。已开始交给 SMTP 的消息无法撤回，验证码邮件继续发送。关闭不影响应用会话、未读或管理端通知，重新开启不补发历史消息。
