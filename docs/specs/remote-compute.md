# 可信外接计算节点 · P06-REMOTE 设计

2026-09-27 更新：井井授权独立实现与合成故障测试，首轮允许个人电脑 WSL/Windows 节点。A 公共文件尚未释放，当前只推进独立部分。现行版本化接口与串行接线边界见 [remote/1](remote-protocol-v1.md)，调度决策见 [独立 ADR](../decisions/ADR-P06-REMOTE-001.md)。以下 2026-09-26 为历史初案，接口以 remote/1 为准。个人电脑不绑定主机/IP，实验室之后独立登记；现存库 DDL/凭据/生产部署仍需具体授权。

2026-09-26，`planned / proposed`。需求来自井井希望本地或实验室电脑自动领取云端数据、完成计算并回传。本文件是实现提案，尚无远程 worker API 或授权节点。总入口见[统筹计划](../plans/2026-09-26-server-coordination.md)。

## 1. 边界与复用

服务器保留账号、owner/project、配额、TTL、任务状态和结果发布权。节点复用同版 phonetic_core 和受限进程适配，仅计算获分配的任务。现有 `JobStore`、`fenced`、`FilePipeline` 和事务发布有可复用基础，当前 worker 仍需 DSN/共享存储且没有能力过滤，不能原样连接公网。

推荐 HTTPS 主动领取，使用有限长轮询或退避轮询。无需实验室路由器开放端口，也不依赖服务器主动连校园电脑。首期仅允许可信、登记并由管理员授权的节点，不做匿名志愿计算，不执行任意用户脚本或 PKL。

代价：实验室上传带宽和开机时间影响完成速度；远程电脑可以接触实际语料，节点程序无法从技术上保证控制该电脑的人没有复制数据。授权范围、参与者数据许可和缓存清理必须明确；UI 显示计算位置，不能暗中把所有人的语料发给任意登记电脑。

## 2. 最小协议草案

以下路径/字段均待实现；从后端模型统一生成 contracts，不手工维护两套 schema。

| 接口（建议 /api/v1/worker） | 意图与约束 |
| --- | --- |
| enrollment / revoke | 管理员登记节点，单次短效登记凭据换受限节点身份，可撤销/轮换；不复用用户浏览器 session 或数据库密码 |
| POST /poll | 请求任务，携带协议/core/adapter/OS/架构/BLAS、模块/模型/字体及资源能力；服务器与允许清单取交集 |
| POST /attempts/{id}/heartbeat | 带 attempt、lease generation、受限凭据；返回继续/取消/失效，服务器时间为准 |
| GET /attempts/{id}/inputs/{asset_id} | 只下载本次清单内的资产，分块/Range、尺寸/hash/到期/owner 授权逐次核查 |
| POST /attempts/{id}/outputs | 原子预留用户与全站空间，声明已批准的结果角色、预计大小、hash |
| PUT /attempts/{id}/outputs/{upload_id} | 有界可重试分块，offset/长度/hash 一致，相同块重传不重复收费 |
| POST /attempts/{id}/complete | 服务器验证完整产物并在同一事务中核对租约、取消、期限、额度和 manifest，原子发布 |
| POST /attempts/{id}/fail | 有界机器码与脱敏诊断；释放未发布结果预留，允许的重试策略由服务器决定 |

任务清单至少含：job_id、attempt_id、generation、lease_until、hard_deadline、module/operation、input asset IDs/hash/size/expires_at、参数与字体快照、科学版本/后端 fingerprint、输出角色与字节上限、资源 profile、policy_version。授权有效期不超过租约/输入剩余寿命，认证信息不进 URL/query、manifest、截图、日志。

节点下载只认固定服务 origin 和不透明 asset ID，不接收任意 URL 或路径；远程 manifest 中路径不作为本地写入目标。结果只接受已登记类型/数量/长度和内容解析预算，路径穿越与 ZIP 展开受限，不把节点输出当可信代码。

## 3. 调度与状态

1. 服务器鉴别节点身份、可处理 owner/project/模块、可用内存/CPU、后端版本、模型与字体。客户端自报能力仅用于筛选，不能自授权限；版本不匹配拒绝领取。
2. 数据库事务认领任务，增加 generation，建立 attempt。账户仍最多一个运行计算任务，节点并行独立受限，服务器资源与远程节点槽分开计量。
3. 节点下载输入并逐项核 hash，在固定版本受限进程运行。心跳独立于科学主循环，下载/上传阶段也覆盖；线程与 CPU/内存由节点本地可配置上限控制。
4. 节点可暂停领新任务、限制工作时段/资源，不抢占整台实验室电脑。已接任务完成或按取消流程终止；程序单实例，一键启动、托盘/状态页与明确退出。
5. 上传产物完成只进入临时状态。服务器复核且发布事务成功后才返回成功；节点重试同 complete 返回同一结果，无重复计费。

状态继续使用 queued/running/cancel_requested/succeeded/failed/cancelled/interrupted。等待能力、离线、配额可作为 queued 的结构化 reason，不随意添加不兼容顶层状态。远程 lease 建议先评估 60 秒、每 10 秒心跳，传输超时和任务 deadline 独立；现有 10 秒本地 lease 不全局替换。长轮询连接有上限，避免占满 DB 连接。

调度保证持久排队与公平性，重试采用有上限退避。租约丢失后允许任务再次执行，**只有一套获认可产物可发布**，不承诺计算绝不重复。旧 attempt 的输入下载、输出写入、seal/complete 一律失效。

## 4. 故障与必须验证的结果

| 场景 | 预期 |
| --- | --- |
| 电脑关机/休眠/断网 | 云端服务和旧结果下载正常；租约过期为 interrupted，再按策略排队；不能显示持续假进度 |
| 心跳拒绝/凭据撤销 | 节点停止自身子进程、停止下载上传；服务器拒收旧结果，记录撤销时间 |
| 网络临时断开 | 在有效租约内按 offset 重传；失去续租且接近安全截止时停止计算，不离线无限运行 |
| 取消与 complete 竞争 | 事务决定唯一结果；取消先成立则禁止发布，完成先成立返回既有终态 |
| 两节点竞争/旧节点回归 | generation fencing；最多一次发布和额度结算，重复执行有记录 |
| 输入到期/用户删除 | 立即拒绝下一块读取/最终提交并取消关联任务，不因租约而延长 TTL |
| 1 GB/全站容量不足 | 计算前尽量预留输出预算；回传仍再次核验，不能越额发布；保持可下载/删除 |
| 错 hash/截断/多余文件/超尺寸 | 明确失败，不发布半套结果，不执行节点提供的路径或命令 |
| 服务或节点重启 | 云端持久状态回读，节点先检查租约再处理残留；无旧任务冒认新任务 |
| 一个用户恶意请求另一个任务 | poll 分配、下载、上传、心跳、取消、complete 全部验证归属与节点作用域 |

## 5. 1 GB、3 天与节点临时副本

账号上传、结果、导出及服务临时文件继续计入 1 GB。节点临时存储单独记录实际复制成本，逻辑账号 reservation 只结算一次，避免同一传输双重扣额；也不能把云端临时占用因“外派”排除。

下载/重试不续期。副本保留至任务结束或输入到期较早者，完成后即时清理，异常重启优先清理遗留；节点日志不保存音频/完整标签。永久断电的外部节点无法保证在墙钟 3 天内完成物理删除，这是远程节点的明确限制。建议临时数据按 attempt 加密，短效解密材料不长期落盘，重启后过期缓存先清理；本措施不能保证可信电脑的管理员未主动复制语料。对严格禁止离线副本滞留的数据只使用受控在线计算环境或不外派。

服务器仍执行不可访问与物理删除的原有承诺。清理失败继续计量并报状态；不能为了通过到期测试把时钟前移后称三天自然过期。受控到期测试须标注注入方式。

## 6. 验证与科研可追溯

- 先用公开合成文件验证协议，再用获准语料做数值对照。
- Windows 原兼容节点与 Linux 节点分别登记运行时，记录 core version、科学配置、原生/BLAS 构建和输出 hash。
- 云端字体预检应针对将执行的节点/运行时快照，不能仅以服务器安装字体作判断。缺字体不静默换字；无图纯数据任务按既有语义处理。
- 端到端统计含排队、传输、计算、渲染、回传和发布。无可用节点时明确等待或不可执行；不自动退回超预算云端任务。
- 新建 `test_remote_worker` 契约、两节点故障集成和合成任务 E2E 后执行，现有 Windows 报告不能替代。

任何持久表/索引/新身份存储先交具体 schema 审阅。首期保留现有 PostgreSQL 队列，租约/结果发布沿用事务；不因加入远程节点而开放数据库公网或扩大节点账号权限。
