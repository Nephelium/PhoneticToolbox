## 选择文件与关联

桌面点击“打开音频目录”，默认读取该目录顶层的 WAV。TextGrid 和唇形默认都使用音频目录，自动匹配同名文件，无须再选择目录。“选择TextGrid目录”和“选择唇形目录”分别指定独立目录；指定后该类关联只在对应目录寻找，旁边“重置”恢复跟随音频目录。切换音频目录时，默认关联目录同步跟随，显式指定的独立目录保留。

勾选“包含子文件夹”后，同时扫描当前目录和下层目录，文件名显示相对路径，同名关联也按相对路径匹配。选项同样应用于另选的 TextGrid/唇形目录。扫描最多 10000 个条目、512 个目录，跳过链接和重解析点。同名 TextGrid、`.lip.json` 和旧 `.pkl` 自动关联，唇形有新旧两份时优先使用 `.lip.json`，也可在中央下拉框逐条改选。刷新列表会重新检查文件。取消目录选择保留当前目录与关联；接受新的关联目录会重新匹配该类关联。

网页版先登录、选择项目，在“项目文件”上传 WAV、TextGrid 或安全唇形文件，再点击“进入研究工作台 → 参数估计”。只读取当前账号当前项目的可用文件。文件已删除、内容变化或到期时，需要重新选择可用资源。

顶部“关联唇形”使用当前唇形目录，为整个音频列表重新匹配同名数据，不再弹出目录选择。包含子文件夹时按相对路径匹配。同级候选重名时提示逐条确认，未匹配的音频保留已有单条手动选择。中央“唇形数据”下拉只影响当前音频，改选或选择“不关联”后刷新仍保留；再次点击批量关联可恢复找到同名数据的音频。伴随 `_timestamps.pkl` 不列作唇形数据。

桌面默认读取 `.lip.json` 与旧 PKL，无需选择格式或先点转换。提交时旧 PKL 在受限子进程中转换为任务输入，不在原目录生成文件。支持 v2 的 NumPy 数值标量/数组，同名 `_timestamps.pkl` 为音频起点提供后备，优先使用 PKL 内的音频起点，保留手动偏移。只提取时间、面积、宽度、开度、圆度及对齐元数据，其余内容保留在原 PKL。原 PKL 上限16 MB、伴随文件2 MB，结构/数值/内存/20秒运行时间均有界；无法识别的对象拒绝，不执行反序列化构造器。没有唇形关联时不会伪造这四项结果列。

网页版仍使用 `.lip.json` 交换格式，不直接上传或执行 PKL。新旧自动读取与混合批量输入的本轮证据限定 Windows 桌面，见[2026-10-03 M01-R2 报告](../testing/2026-10-03-m01-r2-report.md)。

## 波形、语谱图与试听

- 默认显示一个声道；“显示两个声道”可展开双轨，试听声道单独选择。
- 波形下方显示真实秒刻度。按住 Ctrl 滚轮围绕鼠标位置缩放，双击恢复全长；也可使用 +/−、适合窗口和时间窗滑块。
- 普通滚轮滚动当前内容列。宽屏时文件、中央图形、右侧参数分别滚动，文件数量不会撑长页面。窄屏纵向排列，导航和公共播放条独立。
- 2026-09-29：文件栏与输出参数栏默认拓宽为 220 / 250 逻辑像素。拖动两侧与绘图区的边界可调整宽度，放开后自动保存，下次进入沿用。窄窗临时收缩或堆叠，恢复宽窗后使用保存的宽度，详见[公共布局验收](../testing/p04-resize-report.md)。
- 拖动选区或填写起止秒数，点击“播放选区”；进度条可在选区范围内定位。切换音频/标签会停止旧音频。空格播放/暂停只在焦点不位于输入控件时生效。
- “显示语谱图（Praat）”调用真实 Praat 分析，采用灰度显示。默认 5 ms Gaussian 窗、50 dB 相对动态范围和 6 dB/oct 显示预加重。它不是校准声压级，也不是参数计算结果。

绘图按像素聚合最小值/最大值。桌面长 WAV 会按需生成完整时长、保留全部声道的轻量预览，并显示原始与预览格式。派生预览可能降低采样率并转为16位，波形、试听及预览语谱图使用这份预览，科研计算和切分始终读取原文件。原 WAV 不被修改。预览源文件支持最大 2 GB、8–96 kHz、最多8声道；预览限64 MB、3200万采样值，最低8 kHz仍超预算时提示分段。网页读取仍限64 MB。旧切分路径限64 MB、3200万采样值，新本机同源结果切分使用有界读取，科学计算预算另见下文。

## 参数与设置

“选择输出参数”在桌面弹窗以四列显示，窄屏降为两列或一列。保留原 80 键目录，可全选、全不选和按项勾选；空选不能提交分析。取消关闭不会修改已应用项。

“编辑14项设置”包括静音阈值、能量窗、帧移、分析窗、声学平滑、唇形平滑、仅有声帧、周期数、共振峰数量与上限，以及 REAPER 最低/最高 F0、Hilbert 和高通开关。单位、范围和默认值由共同契约约束。2026-10-04 起，新草稿默认最小/最大基频为 **30–800 Hz**，供 Praat、REAPER、WM 链及相关基频指标共用。已保存的草稿和历史任务保留原值，需要时在 REAPER 设置页手动调整。默认帧移 **5 ms**、分析窗 **40 ms**；旧说明书中的 25 ms 和 ZCR 清浊判断不对应当前 v2 源码，不能据此更改公式。

“保存草稿”保存参数与设置，不保存文件读取权限、登录凭据或原始音频。已经提交的任务使用独立快照；之后编辑仅影响下一批任务。图中试听声道不等于修改科研算法的声道处理规则。

## 联合计算 EGG

本机左侧“分析声道”选择实际音频声道，勾选“联合计算 EGG”。默认音频在声道2、EGG在声道1。交换默认音频声道时，EGG随之交换；个别文件接线相反时，用“当前文件声道”单独覆盖。声道角色与试听选择互不影响。单声道文件跳过EGG，继续声学分析。EGG默认关闭，普通多声道音频默认维持全部声道混合。

EGG参数表有两种选择：

- **插值到主表，并保留原始周期表**：CQ、SQ、F0 - GCI对齐到主表时间网格。默认插值后平滑20ms，可调为0关闭。原始周期值仍保存在同一个文件中。
- **原始周期独立表（同一文件）**：主参数表按音频帧保存，EGG按周期保存，彼此不强行对齐。CQ/SQ使用周期起点，GCI F0使用周期中点。两层都可以在参数显示中勾选。

展开“EGG计算设置”可以设置高低通、GCI/GOI方法、突出度、音频静音阈值和最大插值间隔。默认最大插值间隔50ms，无效周期及长缺口保持为空，不向有效范围外延伸。低通必须低于该文件采样率的一半，高通必须低于低通。

“计算GCI F0派生声学参数”默认关闭。开启后添加 `(gF0)` 谐波、修正谱倾斜、CPP、HNR、SHR和Slope等列，pF0/rF0列保留。派生列仍计算音频声道，只把基频来源换为GCI；Jitter/Shimmer沿用现有方法。CQ和SQ延续EGG模块定义，SQ是 `(去接触时长−接触建立时长)/接触时长`，不应解释为通常的两段时长比。具体方法与版本见[ADR](../decisions/ADR-M01-R4.md)。

## 批量分析与导出

**“开始全列表分析”处理列表中的所有 WAV**，不受左列切分勾选数量影响。任务逐文件执行，一项失败继续后面的文件。处理记录显示总数、完成/失败/中断/未开始数量和各文件原因。

2026-10-04 R5：下方“分析选中文件”只处理左侧复选框勾选的一个或多个音频，未勾选时按钮置灰。点击文件名只用于试听，不会自动勾选。已选文件按列表顺序提交，沿用各自的TextGrid、唇形关联和EGG声道设置；结果保存与全列表分析一致。同一组勾选仍可用于TextGrid切分。

右栏的单文件进度区一直保留。计算时显示当前文件及阶段，完成显示100%，失败或中断保留最后进度与状态；上方/下方批次计数仍表示整个列表的完成情况。阶段百分数表示处理进度，不是剩余时间预测。

桌面保存和网页下载默认提供 **XLSX 与 `.ptb.sqlite`**。新本机结果标记 `m01-bundle/2`，每个文件包含主表 `params`、启用EGG时的 `egg_cycles` 和 `ptb_metadata` 来源信息。两种格式包含同一份数据，Excel数值序列化可能有浮点末位差异。超过100万数据行时XLSX自动分续表。缺失数值为Excel空单元格/SQLite NULL，无穷值以 `+Infinity`/`-Infinity` 文本保存。旧路径的单表格式及非有限值表示仍保留。

新本机结果在两个文件内记录输入校验和、配置、实际后端、计算版本和时间策略。应用内部 `.ptb.json` 保存来源及产物摘要，数值由配套SQLite保存，不再复制整张长表，也不自动写入用户结果目录。历史JSON及旧单表不改写。新多表XLSX应由本轮M02或支持此版本的工具读取，不能视为V2旧单表入口兼容文件。

旧请求沿用 `acoustic/2`，缺少版本字段的历史JSON按 `acoustic/1` 读取。新本机分段结果为 `acoustic-bounded/1`，全局帧网格、全局强度静音参考、带上下文的块计算均明确记录。基频路径和滤波端点有上下文依赖，不能将分段结果视为V2整段结果逐位相同。旧单表无法可靠推断计算版本，新多表可读取其 `ptb_metadata`。

桌面默认写回 WAV 目录，包含子文件夹时分别保存到各 WAV 所在目录；也可取消“结果与WAV同目录”后选择独立结果目录。提交时固定自动保存目标。文件名使用原音频名，不加任务编号；同名同内容文件复用，不同内容使用末尾数字，如 `声音 (2).xlsx`、`声音 (2).ptb.sqlite`，整组使用一致名称并保留旧文件。重开工作台后先选择结果目录，再点“保存已完成结果”，历史递归批次需选择独立结果目录。如果导出失败，完整缓存结果可重新保存；多文件导出不承诺硬断电时整体原子性。后台进度轮询不会再反复显示操作提示或禁用开始按钮，提交、取消等实际操作仍有忙碌提示。

网页在处理记录中按原音频名称下载结果。当前账号全部项目共享 1,000,000,000 字节（1 GB），上传、临时与结果占用均计量。新结果从生成成功起最多保留 259,200 秒（3 天），下载不延长截止时间；切分产物不晚于其输入的最早截止时间。既有文件按实际截止时间处理，不据新规则自动删除旧文件。需长期保留时自行下载。桌面缓存不套用网页到期清理规则。

## 按 TextGrid 切分

1. 选择音频与 TextGrid，在最左侧栏分析设置下方选定切分层；点击图中标注区间可试听。
2. 勾选需要切分的文件；文件列获得焦点后 Ctrl+A 可全选。没有勾选时只处理当前音频。
3. 点击“保存当前层切分音频”。批量文件按同一层名寻找区间；缺层、重叠或有标签片段越界会在对应文件报错，其他文件仍继续。空白或静音尾段允许延伸到 WAV 结束之后，因为不会导出这些片段；整层仍需有限、正向、按序、不重叠。
4. 空白、`sil`、`eps`、`<sil>`、`<eps>` 标注跳过。切片使用 `int(t * sample_rate)` 的半开样本范围，保留原采样率、声道和解码类型；名称包含原名、层、标签、时间与区间序号。用户目录保存 WAV，有参数时另保存成对的 XLSX/SQLite，切分来源 JSON 保留于应用内部。

勾选“同时切分参数结果”，参数来源默认“本应用最近一次同源完整结果”：寻找**同一个任务存储中、原 WAV 校验和一致的最近完整分析**，并核验采样率/样本数/声道。参数只截取原有分析帧，`Time_s` 减去切片实际首样本的时间，同时保留 `Source_Time_s`；不插值、不重新分析、不强制首帧为零。没有父结果时会提示并仅保存 WAV；区间没有原参数帧时明确记录 `no_frames`，不生成假表。

新同源结果同时切分主表与EGG周期表，保留原周期参数。周期按GCI起点归属片段，跨边界周期的下一GCI时间可能超过片段结尾，以保留该周期的完整来源。原始表为空时保留表头，不补造数据。新多表结果使用此默认同源入口，以下“指定历史参数表”仍只处理旧单表。

已有历史参数时，将来源改为“指定历史参数表（来源未核实）”，在相邻下拉框为每个待切分音频明确选择 XLSX / `.ptb.sqlite` / `.ptb.sqlite3`。桌面扫描音频或另选的 TextGrid 目录；网页先上传当前项目。未选表时停止提交，不静默变成只切音频。

旧表通常没有 WAV 校验和，选择表示用户确认其对应当前完整音频。输出 `segments.ptb.json` 记录旧表名称、SHA256 和 `user_associated_unverified`，不伪造原算法或原 WAV 来源。保留列、标签、缺失/无穷值和原时间行；要求 `Time_s` 有限、非递减且在当前音频范围内。已带 `Source_Time_s` 的切片不能再当完整父表输入。XLSX 需单工作表，SQLite 需普通 `params` 表；公式、外链、重复表头和生成列不受支持。读取上限16 MB、20万单元格及32 MB解压XML。CSV 和 M02 多轨结果显示不属于本次入口。

## 失败与恢复

新本机分析接受最长 **30分钟（1800秒，含端点）**、最多2GB的WAV，8–192kHz、1–8声道。自动按20秒输出块及两侧上下文处理，不需要先手动切文件。默认5ms帧移的30分钟录音产生36万主表帧。任务仍有2GiB进程树内存、6小时运行上限，每表200万行、总1.8亿单元格、单参数文件4GB和整组5GB输出预算。极小帧移或异常密集EGG事件仍可能超限，会报告具体原因。波形预览的采样率限制独立见前文。

旧请求和网页端仍沿用200万采样值、240秒、64MB结果及20万单元格预算，新联合分析尚未开放给远程计算。超过30分钟的文件需自行切分后再分析。

损坏 WAV、无效 TextGrid/唇形、空参数帧、采样/输出预算、缺失切分层分别显示具体原因。取消后保留完整结果，未开始项仍显示未开始；失败/中断/取消项可单独重试。网页刷新后可恢复持久记录。原生计算在独立受控进程中执行；不因一个音频失败关闭整个工作台。

实际计算阶段发生异常时，任务现在明确失败并显示对应阶段，不再将异常转成一组 NaN 后标为成功。正常静音、无声帧或算法无法估计的值仍使用 NaN。后端策略 `native_required` 必须成功调用原生 REAPER，`python_only` 仅运行 Python 实现，`native_then_python` 只在普通原生故障时允许 Python 回退；取消、超时和资源中止不触发回退。实际后端及回退原因记录在 JSON 中，不将两种实现当作数值等价。

## 方法与兼容边界

点击“方法与引用”查看参数对应论文、实现来源和实际后端。来源来自[统一登记](../../third_party/source-registry.json)，论文方法、移植代码与依赖许可分别记录；相关说明见[方法与学术致谢](methods-and-credits.md)。选择 80 项与旧服务无筛选的兼容调用不同：后者可能包含两个 SOE 扩展键。NaN/无声/失败不能一律解释为 0。

当前仍沿用原实现的共振峰候选分槽规则：F1 为 200–1200 Hz，F2 上限 3200 Hz，F3 上限 4600 Hz，F4 上限 6000 Hz。超出范围的候选可能被丢弃或放到后面的槽位，因此输出与 Praat 未筛选的同序共振峰不必一致，尤其需要留意儿童或高共振峰语料。本轮修复数量设置生效问题，没有重新设计这些科学阈值。

样式由全局主题、公共波形/播放控件和模块布局共同组成：修改公共组件会影响使用它的模块；M01 专属布局不会要求其他模块照搬。功能核对以[v2 说明书覆盖表](../modules/v2-manual-coverage.md)逐项执行。完整 M01、其他模块和跨平台发行的未完成项，以实际验收账本为准。

2026-09-12开发态字体接入：公共[字体设置](settings.md)统一调整已打开页面；所有IPA固定Doulos SIL。字体只影响呈现，不改变科研数值或音频。历史EXE未重新打包，限定验证见[字体报告](../testing/p04-fonts-report.md)。
