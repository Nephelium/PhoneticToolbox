# 参数估计 · M01

2026-09-10。适用于当前 Windows 开发工作台与本机网页验证入口；这是已实现操作的说明，不代表完整 v3 已正式发行。实现与未完成项见[联合审阅报告](../testing/m01-report.md)。

## 选择文件与关联

桌面点击“选择音频目录”，读取该目录顶层的 WAV。需要时另选关联目录；同名 TextGrid 和 `.lip.json` 自动关联，也可在中央下拉框改选。刷新列表会重新检查文件。取消目录选择保留当前目录。

网页版先登录、选择项目，在“项目文件”上传 WAV、TextGrid 或安全唇形文件，再点击“进入研究工作台 → 参数估计”。只读取当前账号当前项目的可用文件。文件已删除、内容变化或到期时，需要重新选择可用资源。

`.lip.json` 是版本化的唇形交换格式。桌面展开“关联说明与旧文件兼容”，选择旧唇形 PKL，点击“转换并保存 .lip.json”。新文件保存在 PKL 同目录并关联当前音频，已有同名文件不覆盖。可从另选的关联目录读取 PKL。转换支持 v2 的 NumPy 数值标量/数组；同名 `_timestamps.pkl` 为音频起点提供后备，优先使用 PKL 内的音频起点，保留手动偏移。

**旧 PKL 不作为网页计算输入**，先在桌面转换，再上传 `.lip.json`。转换只提取时间、面积、宽度、开度、圆度及对齐元数据，landmarks 等其余内容保留在原 PKL，不属于 M01 交换文件。原 PKL 上限16 MB、伴随文件2 MB，结构/数值/内存/20秒运行时间均有界；无法识别的对象拒绝，不执行反序列化构造器。没有唇形关联时不会伪造这四项结果列。

## 波形、语谱图与试听

- 默认显示一个声道；“显示两个声道”可展开双轨，试听声道单独选择。
- 波形下方显示真实秒刻度。按住 Ctrl 滚轮围绕鼠标位置缩放，双击恢复全长；也可使用 +/−、适合窗口和时间窗滑块。
- 普通滚轮滚动当前内容列。宽屏时文件、中央图形、右侧参数分别滚动；三列均超过可用高度时，内容工作区一起滚动。窄屏纵向排列，导航和公共播放条独立。
- 拖动选区或填写起止秒数，点击“播放选区”；进度条可在选区范围内定位。切换音频/标签会停止旧音频。空格播放/暂停只在焦点不位于输入控件时生效。
- “显示语谱图（Praat）”调用真实 Praat 分析，采用灰度显示。默认 5 ms Gaussian 窗、50 dB 相对动态范围和 6 dB/oct 显示预加重。它不是校准声压级，也不是参数计算结果。

长音频绘图按像素聚合最小值/最大值，保留窄峰；原音频、试听采样率和科研计算输入不会被显示降采样改变。预览与切分上限为 64 MB、3200 万采样值，科学计算预算另见下文。

## 参数与设置

“选择输出参数”保留原 80 键目录，可全选、全不选和按项勾选；空选不能提交分析。取消关闭不会修改已应用项。

“编辑14项设置”包括静音阈值、能量窗、帧移、分析窗、声学平滑、唇形平滑、仅有声帧、周期数、共振峰数量与上限，以及 REAPER 最低/最高 F0、Hilbert 和高通开关。单位、范围和默认值由共同契约约束。默认帧移 **5 ms**、分析窗 **40 ms**；旧说明书中的 25 ms 和 ZCR 清浊判断不对应当前 v2 源码，不能据此更改公式。

“保存草稿”保存参数与设置，不保存文件读取权限、登录凭据或原始音频。已经提交的任务使用独立快照；之后编辑仅影响下一批任务。图中试听声道不等于修改科研算法的声道处理规则。

## 批量分析与导出

**“开始全列表分析”处理列表中的所有 WAV**，不受左列切分勾选数量影响。任务逐文件执行，一项失败继续后面的文件。处理记录显示总数、完成/失败/中断/未开始数量和各文件原因。

每个成功分析产生 XLSX、`.ptb.sqlite` 和 `.ptb.json`：前两者为参数表，后者记录输入校验和、配置、实际后端与非有限值状态。XLSX 保留显示列名；SQLite 使用 `params` 表和 `Time_s` 时间索引。当前生成文件已用原 v2 读取函数逐值回读；历史表输入使用下述独立关联入口。

桌面默认写回 WAV 目录，也可取消“结果与WAV同目录”后选择独立结果目录。提交时固定自动保存目标；已有同名同内容文件可复用，不同内容另名保留。重开工作台后先选择结果目录，再点“保存已完成结果”。如果导出失败，完整缓存结果可重新保存；多文件导出不承诺硬断电时整体原子性。

网页在处理记录中按原音频名称下载结果。账号全部项目共享 5 GB；上传、临时与结果占用均计量。结果从生成成功起最多保留 7 天，下载不延长截止时间；切分产物不晚于其输入的最早截止时间。需长期保留时自行下载。桌面缓存不套用网页 7 天清理规则。

## 按 TextGrid 切分

1. 选择音频与 TextGrid，选定切分层；点击标注区间可试听。
2. 勾选需要切分的文件；文件列获得焦点后 Ctrl+A 可全选。没有勾选时只处理当前音频。
3. 点击“保存当前层切分音频”。批量文件按同一层名寻找区间；缺层、重叠或越界会在对应文件报错，其他文件仍继续。
4. 空白、`sil`、`eps`、`<sil>`、`<eps>` 标注跳过。切片使用 `int(t * sample_rate)` 的半开样本范围，保留原采样率、声道和解码类型；名称包含原名、层、标签、时间与区间序号。

勾选“同时切分参数结果”，参数来源默认“本应用最近一次同源完整结果”：寻找**同一个任务存储中、原 WAV 校验和一致的最近完整分析**，并核验采样率/样本数/声道。参数只截取原有分析帧，`Time_s` 减去切片实际首样本的时间，同时保留 `Source_Time_s`；不插值、不重新分析、不强制首帧为零。没有父结果时会提示并仅保存 WAV；区间没有原参数帧时明确记录 `no_frames`，不生成假表。

已有历史参数时，将来源改为“指定历史参数表（来源未核实）”，在相邻下拉框为每个待切分音频明确选择 XLSX / `.ptb.sqlite` / `.ptb.sqlite3`。桌面扫描音频或关联目录；网页先上传当前项目。未选表时停止提交，不静默变成只切音频。

旧表通常没有 WAV 校验和，选择表示用户确认其对应当前完整音频。输出 `segments.ptb.json` 记录旧表名称、SHA256 和 `user_associated_unverified`，不伪造原算法或原 WAV 来源。保留列、标签、缺失/无穷值和原时间行；要求 `Time_s` 有限、非递减且在当前音频范围内。已带 `Source_Time_s` 的切片不能再当完整父表输入。XLSX 需单工作表，SQLite 需普通 `params` 表；公式、外链、重复表头和生成列不受支持。读取上限16 MB、20万单元格及32 MB解压XML。CSV 和 M02 多轨结果显示不属于本次入口。

## 失败与恢复

当前一次科学计算最多 **200 万采样值（多声道合计）**、240 秒；切分任务有独立的60秒计算上限。成组结果最多64 MB，表格最多20万单元格。这是开发阶段的资源预算，不是声学方法的有效长度范围。例如44.1 kHz双声道达到采样预算时约为22.7秒，单声道约为45.4秒。长音频先按TextGrid切分，之后刷新列表分析片段。

损坏 WAV、无效 TextGrid/唇形、空参数帧、采样/输出预算、缺失切分层分别显示具体原因。取消后保留完整结果，未开始项仍显示未开始；失败/中断/取消项可单独重试。网页刷新后可恢复持久记录。原生计算在独立受控进程中执行；不因一个音频失败关闭整个工作台。

## 方法与兼容边界

点击“方法与引用”查看参数对应论文、实现来源和实际后端。来源来自[统一登记](../../third_party/source-registry.json)，论文方法、移植代码与依赖许可分别记录；相关说明见[方法与学术致谢](methods-and-credits.md)。选择 80 项与旧服务无筛选的兼容调用不同：后者可能包含两个 SOE 扩展键。NaN/无声/失败不能一律解释为 0。

样式由全局主题、公共波形/播放控件和模块布局共同组成：修改公共组件会影响使用它的模块；M01 专属布局不会要求其他模块照搬。功能核对以[v2 说明书覆盖表](../modules/v2-manual-coverage.md)逐项执行。完整 M01、其他模块和跨平台发行的未完成项，以实际验收账本为准。
