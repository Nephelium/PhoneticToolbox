# 声学参数合成

M06 当前完成 Windows 开发态迁移，使用工作台侧栏“声学参数合成”。新版纯核心已通过 WSL 定向检查，Linux 正式任务资格仍关闭。输入预算为 0.1–10 秒且最多 480000 样本，源 WAV 不超过 8 MB，完整参数 CSV 不超过 2 MB。编辑/保存配置可保留更长曲线，超预算配置不能提交正式计算。

Windows 当前源码入口为 `powershell -File scripts/Start-M06-Workbench.ps1`。它进入现有统一宿主、使用已有 m09-ui 科学环境并加载本轮源码，不安装依赖、不自动构建、不执行数据库迁移。进入后在侧栏选择声学参数合成。原 Start-Research-Workbench 仍可指向较早安装 wheel，本轮未覆盖它的运行环境。

## 常用流程

本模块使用 Klatt 参数合成。需要 PSOLA 变速/变调时，请使用独立的“变速变调”模块。

1. 填写总时长并点击“应用时长”。输入 IPA 元音序列，例如 `a i u`。空格生成静音段，`+ - * /` 分别改变前一段的相对时长，乘数为 1.1、0.9、2、0.5。
2. 点击“生成元音”更新共振峰和静音段，保留当前 F0 和已应用的声源预设。此操作不会生成音频。
3. 选择左侧参数，Shift 拖动绘制，Ctrl 拖动恢复该段默认值，普通拖动平移，Ctrl 滚轮缩放。“重置范围”恢复完整时间窗。
4. 顶部“曲线覆盖”输入单个数值后点击“应用覆盖”，会固定该参数并锁定手绘；“清除覆盖”恢复底层曲线。逗号连接值表示线性插值，分号划分等长区段。Shimmer 在界面用百分数，CSV/JSON 保持内部小数，例如 3% 保存为 0.03。
5. 设置淡入、淡出、平滑点数或应用 F0 范围，然后点击“合成音频”。公共任务区可取消，失败会保留前一个结果。
6. 在“合成结果”预览中选择波形/语谱图、窗长和试听选区。“导出音频”保存实际合成 WAV；桌面目录保存同时带上 JSON 元数据和 CSV 参数，同名文件会拒绝覆盖。顶部“导出参数”保存当前编辑配置。导出音频时附带的 CSV/JSON 则对应所保存结果的配置。

参数修改后会出现旧结果提示。新的配置需要重新合成，旧 WAV 的试听/导出不会被偷偷替换。计算过程中再次修改配置，迟到结果不自动应用。

## 加载音频与预设

顶栏 F0 算法可选 Praat 互相关（CC）、Praat 自相关（AC）和原生 REAPER。先选择算法再加载 WAV，或在加载后切换并点击提取参数。算法选择本身不会重算。F0 范围使用左侧已应用的上下限，帧移为10 ms。缺少所选后端时明确报错，无自动回退。算法选择随完整 CSV/JSON/草稿保存，旧 m06/2 文件缺该字段时使用原来的 Praat CC。

提取与参数估计共用底层函数，帧移、静音策略和测量到合成控制量的转换仍不同，不能直接当作同一套测量表。新提取保留实际 F0 时间与清音空缺，并修正 Shimmer 百分数到内部比例换算。提取结果元数据记录 `m06-extract/2`、实际F0后端、范围、原始有声掩码和测得轨迹。编辑曲线补齐的 F0 不表示在无声帧中测得了F0。全无声时 AV 全0，界面提醒调整范围或算法。

底部使用与参数估计、参数显示相同的完整播放条，横跨整个模块，包含时间选区、播放/停止、进度与音量。它随当前预览的源音频或合成结果切换，各自保留选区。语谱图的窗长标签与下拉控件横向排列。窄窗中间工作区可滚动，播放条保留在底部。右侧元音规则位于生成元音上方。

当前预设声源幅度：气声 AV65/AH35；常态浊声、嘎裂、假声 AV70/AH0；耳语保持 AV0/AH40。它们仍是可编辑的起点，尚未做自然发声类别听辨验证。[提取与自然度核查](../references/m06-r3-resynthesis-audit.md)区分已修问题与候选算法。

桌面先打开音频目录，然后在左侧栏最上方的“音频文件”下拉框选择 WAV。“刷新文件”重读目录。选择文件只加载原始波形和试听，不提交提取任务，也不改变已有参数或总时长。点击顶部“提取参数”才更新曲线与源语谱图；未加载、正在加载、读取失败或清空选择时该按钮禁用。网页使用已上传的 WAV 资源。源预览按自身时长显示；合成结果仍绑定最后一次合成快照。

顶栏“导出参数”右侧提供修订后的五类发声类型预设。点击“应用预设”后可确认或取消，只有该预设涉及的参数被覆盖。右侧“生成元音”上方输入元音序列，“元音规则”使用紧凑表格，点击 IPA 复制并在弹窗内提示。桌面通过原生剪贴板接口写入；浏览器拒绝权限时可选中弹窗内的音标文本框后按 Ctrl+C。旧辅音规则入口已移除。

提取/复制合成效果有限，输入参数也不必然等于对输出重新测量得到的数值；不能当作真实发声生理模型或感知验收。

## 参数文件和保存

“导出参数”保存当前完整编辑配置，CSV 保留四个传统字段和 `__PTB_CONFIG__` 完整快照。包括所有 24 条曲线、Override 下原曲线、采样率、时长、淡入淡出、平滑、F0 范围、静音区间、边界与 F0 平移状态。可导入该 CSV、完整配置 JSON 或保存目录中的 `m06.ptb.json` 实际快照。旧 m06/1 配置及不含新完整快照的 V2 CSV 使用旧 AV 标尺，无法可靠等价转换，新版明确拒绝并保留原文件。含完整快照的 CSV 以快照为准，手动改传统行不会覆盖快照。

2026-10-04 R5 已移除本模块 WORLD、PSOLA 和 Harvest。R4 保存的 Klatt 配置可继续导入，旧扩展字段在内存移除；使用已移除方法的文件会明确报错，不自动换成另一种算法。原文件和既有任务结果保留。

“保存参数草稿”写入当前设备、账号/工程作用域的本机草稿。关闭标签页时可保存、放弃或取消；保存失败保留页面。本机草稿并非云端结果备份。

服务端新计算结果按最终公共政策最多保留 3 天，下载不续期；纯复制/打包由公共平台继承来源截止，不由 M06 创建续期协议。桌面本地文件不受服务器账号额度/期限限制。页面字体跟随统一设置，IPA 固定 Doulos SIL。

## AV 参数的解释

新版 AV 默认 60，范围和图轴为 0–80 dB，0 关闭周期声源。AH 独立控制气流噪声，0 关闭噪声源；HNR 不再被转换成 AH。该数值使用工具内明确的数字参考校准，不代表物理 SPL，也不声称与原始 Klatt 全实现逐位一致。

去掉旧自动增益和多次峰值归一化，正常幅度下 AV 改变会反映到输出。仅当输出峰值超过安全幅度时整体衰减，界面提示衰减 dB，结果 JSON 记录实际系数。内部计算为 20 kHz，避免高共振峰在原 10 kHz 链路中折叠。提取 AV 使用相对能量初始化，AH 初始化为 0，仍需按需要编辑。

## 保留 F0 曲线的发声预设

常态浊声、耳语、气声保留基础 F0。假声整体上移，使基础曲线时间加权均值至少 300 Hz；嘎裂整体下移，目标均值约 70 Hz，最低点尽量保持 20 Hz。若曲线起伏过宽，最低点限制会使嘎裂均值高于 70，曲线不逐点截平。

切回常态浊声、耳语或气声时撤去偏移。用户在高/低 F0 状态的编辑会一同保留，不恢复过期快照。重复应用同一类型不会叠加偏移。图中通常保留纵轴，让曲线明显上移或下移；超出时再扩展轴。平移前的标量覆盖在应用时转成可以直接手绘的 F0 曲线，CSV/JSON/草稿均保留偏移状态。

耳语关闭周期声源，F0 曲线仍保留供后续切换。预设值、数字参考公式和验证边界见 [M06-R2 报告](../testing/2026-10-02-m06-r2-report.md)。这些预设是合成起点，尚未做物理设备听辨验收。
