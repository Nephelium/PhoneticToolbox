# 语音合成

M06 当前完成 Windows 开发态迁移，使用工作台侧栏“语音合成”。Linux 数值与任务资格尚未通过，能力关闭。输入预算为 0.1–10 秒且最多 480000 样本，源 WAV 不超过 8 MB，完整参数 CSV 不超过 2 MB。编辑/保存配置可保留更长曲线，超预算配置不能提交正式计算。

Windows 当前源码入口为 `powershell -File scripts/Start-M06-Workbench.ps1`。它进入现有统一宿主、使用已有 m09-ui 科学环境并加载本轮源码，不安装依赖、不自动构建、不执行数据库迁移。进入后在侧栏选择语音合成。原 Start-Research-Workbench 仍可指向较早安装 wheel，本轮未覆盖它的运行环境。

## 常用流程

1. 填写总时长并点击“应用时长”。输入 IPA 元音序列，例如 `a i u`。空格生成静音段，`+ - * /` 分别改变前一段的相对时长，乘数为 1.1、0.9、2、0.5。
2. 点击“生成元音”更新共振峰和 AV 曲线。此操作不会生成音频。
3. 选择左侧参数，Shift 拖动绘制，Ctrl 拖动恢复该段默认值，普通拖动平移，Ctrl 滚轮缩放。“重置范围”恢复完整时间窗。
4. Override curve 输入常数会覆盖曲线并锁定手绘；清空覆盖恢复底层曲线。逗号连接值表示线性插值，分号划分等长区段。Shimmer 在界面用百分数，CSV/JSON 保持内部小数，例如 3% 保存为 0.03。
5. 设置淡入、淡出、平滑点数或应用 F0 范围，然后点击“合成”。公共任务区可取消，失败会保留前一个结果。
6. 在“合成结果”预览中选择波形/语谱图、窗长和试听选区。“导出音频”保存实际合成 WAV；桌面目录保存同时带上 JSON 元数据和 CSV 参数，同名文件会拒绝覆盖。“导出实际合成参数”总是对应所保存结果的配置。

参数修改后会出现旧结果提示。新的配置需要重新合成，旧 WAV 的试听/导出不会被偷偷替换。计算过程中再次修改配置，迟到结果不自动应用。

## 加载音频与预设

桌面先打开音频目录，选择 WAV 后确认覆盖，自动提取参数；“提取参数”可再次执行。网页使用已上传的 WAV 资源。源音频保持原采样率，在“源音频”预览中试听和看图；“导出音频”仍导出最后一次合成结果，加载音频不会冒充新合成结果。

发声类型预设包含原版五类。点击“应用预设”后可确认或取消，只有该预设涉及的参数被覆盖。元音规则展示原表格，点击 IPA 可复制。辅音规则保留原版已移除辅音合成的说明。

提取/复制合成效果有限，输入参数也不必然等于对输出重新测量得到的数值；不能当作真实发声生理模型或感知验收。

## 参数文件和保存

“导出参数”保存当前完整编辑配置，CSV 保留四个传统字段和 `__PTB_CONFIG__` 完整快照。包括所有 23 条曲线、Override 下原曲线、采样率、时长、淡入淡出、平滑、F0 范围、静音区间与边界。可导入该 CSV、完整配置 JSON 或保存目录中的 `m06.ptb.json` 实际快照，也能读取 V2 CSV。旧文件未记录的设置使用原默认值，不能恢复旧文件本来就丢掉的数据。含完整快照的 CSV 以快照为准，手动改传统行不会覆盖快照。

“保存参数草稿”写入当前设备、账号/工程作用域的本机草稿。关闭标签页时可保存、放弃或取消；保存失败保留页面。本机草稿并非云端结果备份。

服务端新计算结果按最终公共政策最多保留 3 天，下载不续期；纯复制/打包由公共平台继承来源截止，不由 M06 创建续期协议。桌面本地文件不受服务器账号额度/期限限制。页面字体跟随统一设置，IPA 固定 Doulos SIL。
