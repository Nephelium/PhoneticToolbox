# EGG 信号分析（Windows 开发态）

从统一工作台打开 EGG 信号分析。本次修复的源码入口为 `scripts/Start-M03-Workbench.ps1`（读取当前源码及已构建前端，不安装依赖），需要既有本地任务库和项目内 M03 兼容科学环境。旧 Research-Fix1、M10-R5 EXE 没有本页。纯浏览器文件预览入口不提供科学计算；网页项目通过既有资源/任务接口使用同一核心。

## 文件与四图

打开音频目录，在下拉列表中选择双声道文件。选择后自动分析并显示四图。默认左 EGG、右音频，交换声道后自动重新分析。各声道独立归一化至峰值 0.7，原文件不改写。总览保留原文件音频声道；播放器读取本次计算生成的归一化音频。

- 左上 CQ/SQ 使用左右纵轴，缺失值分别留空。
- 左下语谱图来自旧版 Matplotlib PSD，顶部为 dB 色条。Praat F0、GCI F0 与 REAPER F0 默认关闭，可独立显示在右轴。Praat 和 REAPER 取音频声道，当前搜索范围均为 30–800 Hz、步长 10 ms；GCI F0 取 EGG 事件。Praat 使用实际帧时间，REAPER 使用原生 EST 时间，不人为移动到统一帧中心。右轴按当前可见的有效正 F0 自动缩放，保留边距和离群值，无有效值时隐藏；不再固定 50–500 Hz，GCI 方法保持原规则，搜索范围与动态显示范围分别处理。左右留白与上方 CQ/SQ 一致。点击图中时间可定位微观中心，红色定位线同步显示。
- 右上为音频微观图，右下为 EGG 微观图。GCI 实线、GOI 虚线共用实际事件时间。高通、低通与原始/滤波开关集中在 EGG 图上方。
- 最下方总览以较矮的图窗显示波形。每个可见声道按当前视窗最大绝对值归一化显示到上下半高的90%，仅改变显示，原音频和科学归一化不变。双声道开关、缩放与适合窗口集中在图下；单击可移动选区并保留时长，末尾贴边；拖动可另选区间，松开后更新。连续操作只保留最新意图，缓存内局部更新不写入处理记录。最大视窗 60 秒，长文件用下方滑条平移。起点、时长与总览相互对应，微观窗为 5–5000 ms，默认 50 ms。

旧版存在三种不同局部规则，本页保留且在四图悬停提示及帮助中说明：CQ 从 processed 信号做 ±100 ms 重复滤波，微观显示从 raw 信号做 ±100 ms 滤波后裁剪，事件从 raw 信号做 ±50 ms 分析。这些数值来源不能混为同一局部计算。

## 参数与操作

顶栏依次提供打开目录、刷新文件、批量分析、交换声道、CSV/三图导出、LP 阶数与逆滤波。文件选择下拉框位于左栏顶部并填满栏宽，时长、微观窗口、滤波和事件参数在左栏紧凑排列，根据栏宽每行显示一或两对字段。起点、终点、全部选区、播放/暂停、停止、进度和音量位于固定底栏，复用参数估计与参数显示的控件；编辑起终点与左栏时长、图中选区相互同步。窄窗口中参数和图表滚动，底栏保持可见。默认 GCI 斜率、GOI 尺度 0.25，高通 25 Hz、低通 2000 Hz，均直接输入数值。峰自动只调整峰阈值，启用时禁用手动峰输入，谷显著度仍手动，默认 0.01。自动 dB 默认开启，按当前实际 PSD 给出峰下 50 dB 范围，拖动、缩放或改变谱窗后持续更新。按钮使用勾选、底色、边框及状态提示区分开启和关闭，开启时上下限只读。关闭后可手动编辑，后续导航保留手动范围，重新开启恢复自动色阶。静音区间保留当前有限范围并提示。开关保存在本机，已提交历史任务的范围不变。阈值与逆滤波的依据见 [R3 参数核查](../references/m03-r3-algorithm-audit.md)。

四图内直接用滚轮缩放、按住左键拖动平移，图外滚轮滚动页面。聚焦后左右方向键平移，加减键缩放。左两图单击同步移动红线，右两图以红线对应的时间为中心向两侧展开。视窗即时移动，局部数据经30 ms合并更新。

编辑参数或选区后自动更新并暂停试听。交互使用临时内存会话，复用预处理和主视窗，首次加载仍需要时间。更新期间坐标和中心线先响应，已有数据按实际时间投影，新区域随后补齐。完成后可试听、导出或逆滤波。切换文件清空旧图并忽略迟到响应，失败时可重试预览。旧交互任务从页面记录列表隐藏，存储数据保留，正式导出、批次及逆滤波仍有持久处理记录。声门活动入口暂时移除。

新计算记录 `f0_policy=audio-f0/2` 和 `f0_analysis`：Praat AC / 原生 REAPER 的搜索范围为 30–800 Hz，REAPER 沿用项目已登记的二进制，内部转为 16 kHz PCM16，启用原生高通、关闭 Hilbert。短文件 REAPER 首次勾选计算整段音频，再按当前选区显示；长文件只计算当前最多 60 秒的视野并缓存，完整导出另按 20 秒块及 1 秒上下文计算全部轨迹；取消再勾选复用同源缓存，交换声道后重算。REAPER 不可用时明确报错，取消勾选可继续其他分析。静音或不足 100 ms 的文件不伪造 REAPER 有声帧。旧任务缺少该修订字段时按原 75–600 Hz Praat 读取/重试，旧结果不重写；工作台重新选择源文件采用新范围。

## 参数草稿与关闭

页面最顶端工具栏的保存参数草稿会保留分析设置和独立的 LP 阶数，空白表示自动。仅修改 LP 阶数也会提示未保存，同时保留当前四图和试听能力。关闭标签时，取消关闭或 Escape 保留编辑；保存草稿并关闭后重开可恢复，放弃草稿并关闭则恢复上次保存的值。存储失败会在确认框内说明并保留页面，可恢复存储后重试。草稿不包含音频，重开后需重新选文件，已有任务结果从处理记录查看。

## 保存与批量处理

保存 CSV / 三图提交当前选区任务。长文件另有保存完整录音 CSV / 三图按钮，使用全文件事件和 F0 网格。完成后在处理记录中查看；桌面选择一个输出目录保存完整结果，网页从该结果逐个下载。CSV 使用各自原时间网格的 outer join，并记录 sample-aligned/1。单文件始终保留 Praat 与 GCI 两类 F0；勾选 REAPER 时，CSV 另含 `F0_REAPER (Hz)`，语谱 PNG 同步绘制。此前 D 阶段关闭显示后导出的文件可能缺少相应 F0 列，重新导出可补齐，已有文件不会被改写。三个 PNG 使用提交时的公共导出字体快照；查看窗口中的图片是导出产物，界面四图另用当前公共主题和字体。

批量分析处理所选文件的完整滤波信号。高通、低通、交换声道、方法、三种 F0、静音阈值和可选三图可单独设置，采用独立参数草稿，不继承单文件选区、显示开关或滤波设置。初次默认高通 25 Hz、低通 2000 Hz、GCI 斜率、GOI 尺度、Praat / GCI F0 开启、REAPER F0 关闭、图片关闭。静音阈值为 20 ms 平均绝对振幅，仅遮罩批次 CSV。每个已提交任务独立持久保存，单个失败不影响其他文件。桌面可通过保存本次批量结果一次选择输出目录，保存本次所有已成功结果。关闭模块后可恢复已提交任务；未提交的本机选择不是持久服务器队列。

批量弹窗分为滤波与事件、输出选项及待处理文件，参数随窗口宽度换行，文件列表独立滚动。高通必须低于低通，低通还须低于每个文件采样率的一半。批次参数不合法时会在弹窗内提示原因，保留文件选择供修正。全部文件未能提交时也保留弹窗及上一批保存入口；部分提交成功时在工作台列出未提交文件和原因，已提交任务仍可在处理记录中查看。提交期间参数、文件选择和普通关闭暂时禁用，可点击取消提交返回工作台并停止后续文件；本轮已接收及迟到任务会请求取消，上一批结果不受影响。当前请求返回后可再次开启批次，已完成产物保留；任务计算期间也可在处理记录取消。小窗口下可用普通滚轮滚动弹窗正文，底部按钮保持可见。

查看任务结果时，窗口会显示读取状态。元数据、图片或音频读取失败会在窗口内说明，可点击重新读取结果，或返回分析查看其他任务。重新读取不会重新计算；结果确已到期时需要重新计算。已加载的部分结果可继续查看，读取期间保存和下载按钮暂时禁用。关闭结果窗口不会取消已经开始的文件保存或下载。

保存名称恢复源文件名与选区时间，如 `元音_0_10s_0_50s_DATA.csv`，批次使用 `元音_DATA.csv`。内部受控资源仍保持 `egg_DATA.csv` 等固定名，来源 JSON 同时记录建议保存名、输入 SHA-256 和参数。旧结果没有保存名映射时沿用旧名。已有同内容文件复用，不同内容另加前缀保留，过长名称截短并附摘要。保存成功、取消与错误直接显示在结果窗口。

## 逆滤波

选取稳定元音片段后点击逆滤波 IF，LP 阶数留空为自动，界面显示当前采样率的实际自动阶数。手动阶数为 1–256，且须低于固定 3 ms 的样本数。结果自动打开，保存 PNG、保存完整结果和返回分析均在顶部。

四个组合按钮分别显示：全部分开 6 图、音频与 IF 叠加 4 图、EGG 与 IF 叠加 4 图、三信号叠加 2 图。每组含频谱及中心总长 50 ms 的波形。双信号波形保留独立左右轴，三信号波形各自峰值归一化并明确标识，只供形状比较，频谱不做这种归一化。上下绘图区边界保持一致，PNG 按当前组合保存，也可保存单图。

音频实线、IF 虚线、EGG 点线，线宽和白底颜色增强。PNG 只保留居中小标题、坐标与图形，去掉重复彩色说明，标题中保留必要线型对应，导出 300 dpi。全段音频与 IF 查看/试听保留，勾选显示 EGG 波形可查看同次任务选区的滤波 EGG。旧历史任务没有该数组时明确提示，不能由当前文件补造。
两个 WAV 分别为归一化分析音频和简化闭相逆滤波估计，不表示原文件字节切片。结果窗口按文件角色显示原音频在前、IF在后。点击另一条的播放按钮会直接切换到该条选区起点，只有正在播放的那条显示暂停；同一条暂停后可继续。关闭结果窗口会停止试听。缺少足够有效周期时明确失败，不制造结果。

简化算法直接继承 V2：从每个 GCI 的下一个样本起取固定 3 ms 片段，用自相关 LPC 估计并平均系数，至少需要 3 个有效片段。它没有根据 GOI 确认闭相区间，固定窗口可能超出实际闭相；IF 应作为该算法的估计结果解释。自动 LP 阶数为 `int(采样率 / 1000) + 6`。完整预加重、倾斜模型与回退流程见[方法核查](../references/m03-method-audit.md)。

## 当前边界

Windows 本地单文件限 2 GB、30 分钟，采样率 8–96 kHz，须为双声道。逆滤波另限 10 秒、960000 帧，保持同一组平均 LPC 系数。超长文件需先切分。长路径采用 egg-bounded/2，全局扫描峰值与线性趋势，20 秒块及基于极点衰减的上下文做 SOS 零相位滤波并裁剪，缓存最多 3 块，局部 CQ/事件/微观滤波也使用 SOS 并保留既有取窗。保留旧短文件路径，长文件边缘数值不保证整段逐位等价。实时视野最多 60 秒，试听保持原采样率。长路径完整三图波形采用 4096 个 min/max 箱、语谱最多 2048 列最大 PSD 聚合，CSV 不做这些显示压缩。实时 GCI F0 使用当前视野的异常值参考，完整导出使用全事件网格，两者可有边缘和筛选差异。新本地任务结果集上限 256 MB，科学子进程 3 GB / 1800 秒，上游任务截止 3600 秒。大于 64 MB 的 CSV 通过选择目录保存完整结果流式导出。全文件导出时间和内存均高于实时交互。托管服务器长输入尚未扩容验收。长 CQ/SQ 散点用复合路径绘制，保留全部点，避免逐点创建大量界面节点。屏幕 PSD 栅格最多 1024×512，缩放只影响显示像素，不改变导出数值。

CQ 为接触阶段占周期的比例，仅严格保留 0.05 < CQ < 0.95。SQ 保留旧实现的不对称指标：(去接触时长 − 接触建立时长) / 接触时长，不能按通常的两阶段时长比解释；CQ 与 SQ 缺失值独立处理。

微观输入和图内普通滚轮均支持 5–5000 ms。宽窗口使用旧版二次幂抽点显示，图头注明步长；滤波和事件检测仍用完整数据，CSV/WAV 不受显示抽点影响。到达缩放边界后继续操作不会重复计算。

当前验证为 Windows 开发态 Qt 与独立 Chrome 接本机真实任务服务。本机托管网页登录/双账号隔离、受控配额/到期清理，以及两自然录音指定ROI已在E2验证。六功能组已有[开发态复核](../testing/m03-function-review.md)，实际声卡、原生多屏 DPI、生产与跨平台证据单列，EXE及打包按井井要求暂停。PENDING-EGG 的直接迁移来源已确认是 V2 本地源码，SRC-PRAAT 为依赖；最初文献对应及完整授权链尚待材料，参见方法与引用。

快速切文件会作废尚未返回的旧任务视图，避免覆盖新选择。网页文件失效或临近到期时需重新上传，空间不足时先清理不需要的项目文件，再重试失败任务。

方法书目和公式差异见[方法核查](../references/m03-method-audit.md)。原手册推荐论文已确认馆藏书目，其截图中的混合方法阈值与本程序 0.25 不同；默认值保留原程序行为。Henrich 等（2004）的 DECOM 属于方法审阅参考，本程序未实现该相关算法。
