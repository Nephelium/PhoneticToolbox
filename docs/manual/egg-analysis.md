# EGG 信号分析（Windows 开发态）

从统一工作台打开 EGG 信号分析。开发入口为 `scripts/Start-Research-Workbench.ps1`，需要既有本地任务库和项目内 M03 兼容科学环境。旧 Research-Fix1、M10-R5 EXE 没有本页。纯浏览器文件预览入口不提供科学计算；网页项目通过既有资源/任务接口使用同一核心。

## 文件与四图

打开 WAV 目录，在下拉列表中选择双声道文件。默认左 EGG、右音频，交换声道后必须重新更新分析。各声道独立归一化至峰值 0.7，原文件不改写。总览保留原文件音频声道；播放器读取本次计算生成的归一化音频。

- 左上 CQ/SQ 使用左右纵轴，缺失值分别留空。
- 左下语谱图来自旧版 Matplotlib PSD，顶部为 dB 色条。Praat F0 与 GCI F0 独立显示在右轴，Praat 使用实际帧时间。点击图中时间可定位微观中心。
- 右上为音频微观图，右下为 EGG 微观图。GCI 实线、GOI 虚线共用实际事件时间。高通、低通与原始/滤波开关集中在 EGG 图上方。
- 最下方总览可拖动选区、缩放和平移，最大视窗 60 秒。起点、时长与总览相互对应，微观窗为 10–200 ms，默认 50 ms。

旧版存在三种不同局部规则，本页保留且在四图悬停提示及帮助中说明：CQ 从 processed 信号做 ±100 ms 重复滤波，微观显示从 raw 信号做 ±100 ms 滤波后裁剪，事件从 raw 信号做 ±50 ms 分析。这些数值来源不能混为同一局部计算。

## 参数与操作

按钮区第一行按选区与更新、选区试听、导出与逆滤波分组。第二行按事件检测、语谱图与 F0 分组；窄窗按组换行。默认 GCI 斜率、GOI 尺度 0.25，高通 25 Hz、低通 1000 Hz。自动峰显著度与手动谷显著度沿用旧规则。

编辑参数或选区后，旧图立即失效并暂停试听。更新分析后才能使用当前结果试听、导出或逆滤波。任务执行期间可取消，处理记录支持失败/取消/中断项重试。声门活动标记是 F0 变化启发式，不能解释为解剖运动测量。

## 保存与批量处理

保存 CSV / 三图提交当前选区任务。完成后在处理记录中查看；桌面选择一个输出目录保存完整结果，网页从该结果逐个下载。CSV 使用各自原时间网格的 outer join，并记录 sample-aligned/1。三个 PNG 使用提交时的公共导出字体快照；查看窗口中的图片是导出产物，界面四图另用当前公共主题和字体。

批量分析处理所选文件的完整滤波信号。交换声道、方法、两种 F0、静音阈值和可选三图可单独设置，其余参数继承打开批次窗口时的页面值。静音阈值为 20 ms 平均绝对振幅，仅遮罩批次 CSV。每个已提交任务独立持久保存，单个失败不影响其他文件。桌面可通过保存本次批量结果一次选择输出目录，保存本次所有已成功结果。关闭模块后可恢复已提交任务；未提交的本机选择不是持久服务器队列。

输出采用 C 阶段通用名称，如 `egg_DATA.csv`。已有同内容文件复用，不同内容另加任务前缀保留；与旧版按输入文件名命名的差别仍列入 E 阶段联合收口。来源 JSON 记录输入 SHA-256 和参数。

## 逆滤波

选取稳定元音片段后点击逆滤波 IF，LP 阶数留空为自动，或显式填写 1–256。窗口提供原音频/IF 频谱叠加、中心 50 ms 双轴波形，以及 EGG 频谱和波形。旧标题声称 ±50 ms，但实际取窗总长 50 ms，本页保留采样并修正标签。

两个 WAV 分别为归一化分析音频和简化闭相逆滤波估计，不表示原文件字节切片。缺少足够有效周期时明确失败，不制造结果。

## 当前边界

单文件计算限 64 MB、60 秒、288 万帧，采样率 8–96 kHz；逆滤波另限 1 秒、48000 帧。长文件可先预览和导航，再在参数估计中切分。屏幕 PSD 栅格最多 1024×512，缩放只影响显示像素，不改变导出数值。

当前验证为 Windows 开发态 Qt 与独立 Chrome 接本机真实任务服务。生产网页登录/TTL联合验收、自然录音页面逐项复核、全部旧交互细节、原生多屏 DPI、完整 EXE 和跨平台发行仍需后续 E/F。来源关系为 PENDING-EGG 代码迁移与 SRC-PRAAT 依赖，完整学术来源/授权链尚未闭合，参见方法与来源。
