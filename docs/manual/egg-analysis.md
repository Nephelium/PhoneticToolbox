# EGG 信号分析（Windows 开发态）

从统一工作台打开 EGG 信号分析。开发入口为 `scripts/Start-Research-Workbench.ps1`，需要既有本地任务库和项目内 M03 兼容科学环境。旧 Research-Fix1、M10-R5 EXE 没有本页。纯浏览器文件预览入口不提供科学计算；网页项目通过既有资源/任务接口使用同一核心。

## 文件与四图

打开 WAV 目录，在下拉列表中选择双声道文件。默认左 EGG、右音频，交换声道后必须重新更新分析。各声道独立归一化至峰值 0.7，原文件不改写。总览保留原文件音频声道；播放器读取本次计算生成的归一化音频。

- 左上 CQ/SQ 使用左右纵轴，缺失值分别留空。
- 左下语谱图来自旧版 Matplotlib PSD，顶部为 dB 色条。Praat F0 与 GCI F0 默认关闭，可独立显示在右轴，Praat 使用实际帧时间。点击图中时间可定位微观中心，红色定位线同步显示。
- 右上为音频微观图，右下为 EGG 微观图。GCI 实线、GOI 虚线共用实际事件时间。高通、低通与原始/滤波开关集中在 EGG 图上方。
- 最下方总览直接显示波形，双声道开关、缩放与适合窗口集中在图下；单击可移动选区并保留时长，末尾贴边；拖动可另选区间，松开后更新。已有任务繁忙时保留选区并提示任务结束后更新。最大视窗 60 秒，长文件用下方滑条平移。起点、时长与总览相互对应，微观窗为 5–5000 ms，默认 50 ms。

旧版存在三种不同局部规则，本页保留且在四图悬停提示及帮助中说明：CQ 从 processed 信号做 ±100 ms 重复滤波，微观显示从 raw 信号做 ±100 ms 滤波后裁剪，事件从 raw 信号做 ±50 ms 分析。这些数值来源不能混为同一局部计算。

## 参数与操作

按钮区第一行按选区与更新、选区试听、导出与逆滤波分组。第二行按事件检测、语谱图与 F0 分组；窄窗按组换行。默认 GCI 斜率、GOI 尺度 0.25，高通 25 Hz、低通 1000 Hz。自动峰显著度与手动谷显著度沿用旧规则。

普通滚轮滚动页面，四图支持 Ctrl＋滚轮缩放、拖动平移，聚焦后左右方向键平移，加减键缩放。手势结束后提交一次更新，计算期间不重复提交。

编辑参数或选区后，旧图立即失效并暂停试听。更新分析后才能使用当前结果试听、导出或逆滤波。任务执行期间可取消，处理记录支持失败/取消/中断项重试。声门活动标记是 F0 变化启发式，不能解释为解剖运动测量。

## 保存与批量处理

保存 CSV / 三图提交当前选区任务。完成后在处理记录中查看；桌面选择一个输出目录保存完整结果，网页从该结果逐个下载。CSV 使用各自原时间网格的 outer join，并记录 sample-aligned/1。单文件始终保留两类 F0，页面显示开关只影响绘图。此前 D 阶段关闭显示后导出的文件可能缺少相应 F0 列，重新导出可补齐，已有文件不会被改写。三个 PNG 使用提交时的公共导出字体快照；查看窗口中的图片是导出产物，界面四图另用当前公共主题和字体。

批量分析处理所选文件的完整滤波信号。交换声道、方法、两种 F0、静音阈值和可选三图可单独设置，采用独立参数草稿，不继承单文件选区、显示开关或滤波设置。初次默认高通 25 Hz、GCI 斜率、GOI 尺度、双 F0 开启、图片关闭。静音阈值为 20 ms 平均绝对振幅，仅遮罩批次 CSV。每个已提交任务独立持久保存，单个失败不影响其他文件。桌面可通过保存本次批量结果一次选择输出目录，保存本次所有已成功结果。关闭模块后可恢复已提交任务；未提交的本机选择不是持久服务器队列。

批次参数不合法时会在弹窗内提示原因，保留文件选择供修正。全部文件未能提交时也保留弹窗及上一批保存入口；部分提交成功时在工作台列出未提交文件和原因，已提交任务仍可在处理记录中查看。提交期间参数、文件选择和普通关闭暂时禁用，可点击取消提交返回工作台并停止后续文件；本轮已接收及迟到任务会请求取消，上一批结果不受影响。当前请求返回后可再次开启批次，已完成产物保留；任务计算期间也可在处理记录取消。小窗口下可用普通滚轮滚动弹窗正文，底部按钮保持可见。

查看任务结果时，窗口会显示读取状态。元数据、图片或音频读取失败会在窗口内说明，可点击重新读取结果，或返回分析查看其他任务。重新读取不会重新计算；结果确已到期时需要重新计算。已加载的部分结果可继续查看，读取期间保存和下载按钮暂时禁用。关闭结果窗口不会取消已经开始的文件保存或下载。

保存名称恢复源文件名与选区时间，如 `元音_0_10s_0_50s_DATA.csv`，批次使用 `元音_DATA.csv`。内部受控资源仍保持 `egg_DATA.csv` 等固定名，来源 JSON 同时记录建议保存名、输入 SHA-256 和参数。旧结果没有保存名映射时沿用旧名。已有同内容文件复用，不同内容另加前缀保留，过长名称截短并附摘要。保存成功、取消与错误直接显示在结果窗口。

## 逆滤波

选取稳定元音片段后点击逆滤波 IF，LP 阶数留空为自动，或显式填写 1–256。窗口提供原音频/IF 频谱叠加、中心 50 ms 双轴波形，以及 EGG 频谱和波形。旧标题声称 ±50 ms，但实际取窗总长 50 ms，本页保留采样并修正标签。

两个 WAV 分别为归一化分析音频和简化闭相逆滤波估计，不表示原文件字节切片。结果窗口按文件角色显示原音频在前、IF在后。点击另一条的播放按钮会直接切换到该条选区起点，只有正在播放的那条显示暂停；同一条暂停后可继续。关闭结果窗口会停止试听。缺少足够有效周期时明确失败，不制造结果。

简化算法直接继承 V2：从每个 GCI 的下一个样本起取固定 3 ms 片段，用自相关 LPC 估计并平均系数，至少需要 3 个有效片段。它没有根据 GOI 确认闭相区间，固定窗口可能超出实际闭相；IF 应作为该算法的估计结果解释。自动 LP 阶数为 `int(采样率 / 1000) + 6`。完整预加重、倾斜模型与回退流程见[方法核查](../references/m03-method-audit.md)。

## 当前边界

单文件计算限 64 MB、120 秒、576 万帧，采样率 8–96 kHz；逆滤波另限 1 秒、48000 帧。预算内长文件可定位末尾、整段分析和导出。更长文件需先切分。每项任务保留 3 GB、240 秒资源上限，极端输入仍可能明确报超限。长 CQ/SQ 散点用复合路径绘制，保留全部点，避免逐点创建大量界面节点。屏幕 PSD 栅格最多 1024×512，缩放只影响显示像素，不改变导出数值。

CQ 为接触阶段占周期的比例，仅严格保留 0.05 < CQ < 0.95。SQ 保留旧实现的不对称指标：(去接触时长 − 接触建立时长) / 接触时长，不能按通常的两阶段时长比解释；CQ 与 SQ 缺失值独立处理。

微观输入和 Ctrl＋滚轮均支持 5–5000 ms。宽窗口使用旧版二次幂抽点显示，图头注明步长；滤波和事件检测仍用完整数据，CSV/WAV 不受显示抽点影响。到达缩放边界后继续操作不会重复提交任务。

当前验证为 Windows 开发态 Qt 与独立 Chrome 接本机真实任务服务。本机托管网页登录/双账号隔离、受控配额/到期清理，以及两自然录音指定ROI已在E2验证。六功能组已有[开发态复核](../testing/m03-function-review.md)，实际声卡、原生多屏 DPI、生产与跨平台证据单列，EXE及打包按井井要求暂停。PENDING-EGG 的直接迁移来源已确认是 V2 本地源码，SRC-PRAAT 为依赖；最初文献对应及完整授权链尚待材料，参见方法与来源。

快速切文件会作废尚未返回的旧任务视图，避免覆盖新选择。网页文件失效或临近到期时需重新上传，空间不足时先清理不需要的项目文件，再重试失败任务。

方法书目和公式差异见[方法核查](../references/m03-method-audit.md)。原手册推荐论文已确认馆藏书目，其截图中的混合方法阈值与本程序 0.25 不同；默认值保留原程序行为。Henrich 等（2004）的 DECOM 属于方法审阅参考，本程序未实现该相关算法。
