# 语谱图转音频

顶部从左至右提供图片重建、图片涂鸦重建、音频藏信息。图片根据灰度频谱近似重建声音，图片中没有原始相位。音频模式从原文件计算完整复频谱，保留相位，编辑幅值后直接逆变换。

## 图片重建

原图与四点校正只显示一个标题。未生成结果时展开，生成后默认折叠，中栏显示重建对比。结果标明使用整图还是四点透视校正，并显示输入尺寸。

1. 桌面选择图片目录，或者点击“截取屏幕”。截图会自动隐藏工具箱，在当前显示器直接依次选择左上、右上、右下、左下四个角，按 Enter 完成。Backspace 或右键撤销一点，R 重选，Esc 取消；结束后恢复原窗口。请先让目标语谱图在工具箱后方可。网页使用项目内已上传的图片，系统截图先保存为文件再上传。支持 PNG、JPEG、BMP，原图保留。
2. 截图与角点一起载入，无需再次选四角。导入图片若包含坐标、边框或透视变形，点击“选择四个角点”，依次选择左上、右上、右下、左下。已有角点也可重选。四点在任务子进程内执行透视校正，重置后使用整图。
3. 填写图内真实的时长（s）、频率起止点（Hz）、窗长（ms），以及白色对应的最小 dB、黑色对应的最大 dB。彩色图或反色图需先转换为符合该标度的灰度图，不会自动猜测色图。
4. 默认窗长10 ms、32次迭代、种子0，输出采样率默认频率终点×2，例如0–5000 Hz对应10000 Hz。可手动选择其他输出采样率。
5. 开始重建后原图引用、哈希、四点及所有设置固定在任务快照中。关闭模块不会删除任务，刷新/重开可查看。失败或中断可重试，重试沿用原任务快照。修改设置后再次开始会建立新任务。
6. 左栏设定标定参数，中栏对比校正图和重建图并试听，右栏查看任务和导出。桌面“保存重建结果”一次保存 WAV、两张 PNG 和来源 JSON；已有不同内容的文件另名保存。网页分别下载四份结果，受项目归属、配额与到期规则约束。

重建方法与结果：

- 新任务使用20log10幅度灰度映射、Hann窗、四分之一帧移和快速Griffin–Lim，输出保持标定时长（按整采样点取整）。Aoki初始化可自动判断或手动开启/关闭。
- 旧任务快照保留原算法，重试不会切换到新计算路径。
- 重建对比图只显示所填频率范围，时间坐标和像素长宽与输入一致，采用各自相对灰度比较结构。修改标定后仍显示旧任务结果时，页面会明确提示，并可展开查看原参数快照。

图片预算：输入 16 MB，原图最多 2500 万像素，实际重建区域最多 100 万像素；像素数 × 迭代数最多 2.56 亿。时长最多 30 秒，FFT 最多 16384 点，迭代最多 256 次。Windows 子进程内存预算默认约 1 GB，启用 BigVGAN 时约 3 GB，运行最多 240 秒；超限时报错，请缩小材料或调整参数后重试。

## 可选声码器

Windows 桌面图片模式的左栏提供声码器选项。默认使用现有重建方法。点击下载 BigVGAN，完成下载、校验和试运行后，可选择 BigVGAN 再合成，再开始新任务。下载约 296.4 MB，安装后约占 848.2 MB，与主程序分开保存。首次下载需要联网。CPU推理可能较慢，也可选择已有GPU Python环境，检查兼容性后启用GPU。

BigVGAN 从现有重建音频提取 Mel 频谱并再合成，部分材料的音色和噪声会有变化，改善程度随图片而异。可以用相同图片和参数分别生成两种结果，试听后选择。模型输出保持现有重建的采样率与样本数，结果 JSON 记录模型版本、增益和处理方法。下载完成后仍保留默认方法，需要主动选择 BigVGAN；音频藏信息保留原始相位，不使用声码器。

## 图片涂鸦重建

选择图片或截图，填写左栏标定并选择四角。点击应用校正并绘图，画布显示拉正后的图片。在此画布绘制，再点击右栏生成涂鸦音频。修改四角或底图后，需要重新载入画布，旧笔迹会清空。此模式继续使用 Griffin–Lim 估计相位。

## 音频藏信息

打开音频目录，再选择文件。仅有一个音频时自动载入。支持 WAV、MP3、FLAC，最大 64 MB，8–96 kHz，单/双声道，最长 30 秒。此模式隐藏左侧图片标定栏，时间与频率直接来自原音频。双声道可选择编辑左声道或右声道，另一声道保持原样。频谱精度可选 512、1024、2048，修改后点击载入频谱。画面高频在上、时间向右，默认显示峰值以下 60 dB。

绘制后点击生成藏信息音频。程序对笔迹覆盖的时频单元修改幅值，保留原始 STFT 相位，以逆 STFT 直接合成，不运行 Griffin–Lim。未覆盖单元保留原始幅值，避免整个频谱因显示灰度量化受损。输出保持原采样率、样本数、声道数，以 FLOAT WAV 保存。编辑声道超过满幅时统一降低该声道增益，结果显示实际增益。完全为零的单元没有确定相位，使用 0 弧度约定。

绘制的频谱未必满足短时傅里叶变换的一致性，实际音频重新分析后可能与绘制目标有差异。中栏两图使用相同灰度标度对比。本功能用于在频谱中绘制信息，不提供加密或压缩后保真的保证。

## 两种绘图模式的共同操作

- 黑色画笔增强、白色画笔减弱频谱。直径用滑块或数字框设为1–200 px，按校正图像素计算，画布等比例缩放。一笔的透明度仅合成一次。
- 点击加减按钮或 Ctrl + 滚轮放大至 800%，适合窗口恢复 100%。选择拖动画面，或按住 Shift 拖动，可平移。放大后也可使用滚动条。
- 撤销/重做按钮或 Ctrl + Z / Ctrl + Shift + Z。最多 256 笔、总计 8192 个笔迹点，达到上限会提示。
- 两种模式切换时各自保留当前画布与笔迹。关闭含未提交笔迹的标签时提示返回绘图或放弃。生成任务被接收后，笔迹与源引用固定保存，重试沿用同一版本。较大笔迹保存在任务关联文件中，完整内容也进入结果 JSON。
- 两种模式均使用底部统一播放条，桌面保存四份结果时不覆盖已有不同内容文件。原始音频和图片保持原样。


方法来源：Daniel W. Griffin 与 Jae S. Lim，1984，*Signal estimation from modified short-time Fourier transform*，DOI `10.1109/TASSP.1984.1164317`。实现由本项目 v2 迁入并作明确适配；NumPy/SciPy 提供数值工具，OpenCV 解码与透视校正，SoundFile 写出 WAV。方法与软件来源见统一来源说明。

公共[字体设置](settings.md)统一调整已打开页面，IPA 固定 Doulos SIL。字体用于显示和导图。

## 自动预测与频谱修复

先选择图片，填写时长、频率起止点和线性/对数轴，再点击“预测窗长与 dB 范围”。模型只预测窗长与动态范围，频率轴仍需手动选择。预测只填入一次，窗长与dB始终可编辑，重建保留当前值。两种算法均可使用内置预测。窗长取整数毫秒，帧移为四分之一窗长；Aoki短时窗初始化单独选择自动、开启脉冲或关闭使用随机相位，自动模式以15ms为界。GL默认32次，上限256。默认输出采样率为频率终点×2，重建频谱只显示所填频带，时间范围和像素长宽与输入一致。

Mel 谱 → NAFNet → BigVGAN 先通过GL生成波形，再提取80带Mel谱、修复和声码器合成。参数预测模型已内置。修复与声码器需下载模型组件，安装后可离线使用。CPU组件直接下载，推理可能较慢；GPU可选择已有Python环境中的python.exe，点击检查兼容性，通过后选择GPU推理。不会自动安装或修改所选环境。参数预测与GL仍在CPU上运行，GPU用于修复与声码器。当前完整修复组件尚未公开提供服务器下载。
