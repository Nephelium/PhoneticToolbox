# 参数显示

本模块直接读取已有参数表，不重新执行参数估计。桌面版选择 WAV 目录与参数目录，默认同目录。网页版先在项目文件页上传 WAV 和参数表，再进入工作台。

1. 选择音频。同名 `*.ptb.sqlite` / `*.ptb.sqlite3` 优先于 XLSX，也可手动关联其他参数表。重名歧义不自动猜测。没有参数表时仍能查看和试听 WAV。
2. 默认一个图窗，全部未校正参数曲线叠加在同一坐标区域，用颜色、线型和图例区分，波形单独显示在上方。曲线共用纵轴，保持原列名、原时间与原数值，不归一化。沿用 v2 自动双轴规则：可见原帧的各列平均绝对值均非零且最大/最小比值超过50时，将平均绝对值大于100的曲线放到右轴，图例标明左右轴。缺失/无穷值断线，不补零。
3. 右侧搜索并勾选多个参数，选择目标图窗后点击批量分配。可新建两个、三个或更多图窗。分配会将选中参数从旧图窗移到目标图窗，合并回首图保留参数。
4. reaper 与 correction 分别控制候选项是否显示。筛选不撤销已绘制曲线，也不清除已勾选项。新空图窗保留至少 300 CSS 像素绘图区；有曲线时共用300像素高的坐标区域，图例与标注另外占位，图面不会被公共图标样式压缩。
5. 波形与各图窗共享时间范围、选区。参数图内普通滚轮缩放时间轴、左键拖动平移、Shift＋拖动选区、双击回到全长。波形保留 Ctrl+滚轮缩放与直接拖动选区，也可输入时间窗起点与长度。选中的文字层在波形和参数图中显示区间标注。底部播放条可试听全段、精确选区、暂停、停止与定位。Praat 语谱图是可选显示。
6. 每个图窗可放大、还原。“保存当前图”沿用当前主题，将参数图及标注保存为 SVG。“保存整幅 PNG”导出白底300dpi图片，包含当前显示的声道波形、标注、已开启的Praat语谱图与此参数图，所有轨道按当前时间窗对齐。语谱图尚未完成时会提示等待或关闭后重试。图片尺寸过大时请缩小图窗。绘图配置可保存到本机，文件读取权限不会随配置永久保存。

整幅PNG于2026-09-12在开发入口完成限定Windows Qt/Chrome验证，见[验收报告](../testing/m02-png-closeout-report.md)。历史Research-Fix1.exe未重新打包，不包含此新增按钮。

图窗是统一宿主内的独立图面板，使用共同主题和播放系统，不另外打开浏览器弹窗。SVG 的 IPA 字符依赖阅读软件可用字体。

输入限制：16 MB、20 万单元格、256 列。支持原参数 XLSX 与普通 `params` SQLite 表，包含有效 `Time_s`。不执行 Excel 公式、链接、SQLite 函数或任意 SQL。不对损坏、乱序或非参数工作簿静默修复。

方法署名沿用原参数列对应的 Praat、REAPER、VoiceSauce 等来源。表读取使用 openpyxl 和 CPython SQLite，详见统一“方法与来源”。显示已计算参数不代表重新验证外部表的算法来源。
