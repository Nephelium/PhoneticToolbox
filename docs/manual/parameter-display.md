# 参数显示

本模块直接读取已有参数表，不重新执行参数估计。桌面版选择 WAV 目录与参数目录，默认同目录。网页版先在项目文件页上传 WAV 和参数表，再进入工作台。

1. 选择音频。同名 `*.ptb.sqlite` / `*.ptb.sqlite3` 优先于 XLSX，其后可自动关联同名 `.lip.json` / V2 `.pkl`，也可手动关联其他参数表或唇形记录。重名歧义不自动猜测。没有参数表时仍能查看和试听 WAV。
2. 首次读取默认一个空图窗，参数不勾选、不自动绘制。勾选并分配后，多条参数曲线叠加在同一坐标区域，用颜色、线型和图例区分，波形单独显示在上方。显式保存过的绘图配置继续恢复，保存的空配置也保持为空。曲线共用纵轴，保持原列名、原时间与原数值，不归一化。沿用 v2 自动双轴规则：可见原帧的各列平均绝对值均非零且最大/最小比值超过50时，将平均绝对值大于100的曲线放到右轴，图例标明左右轴。缺失/无穷值断线，不补零。
3. 右侧搜索并勾选多个参数，选择目标图窗后点击批量分配。可新建两个、三个或更多图窗。分配会将选中参数从旧图窗移到目标图窗，合并回首图保留参数。“清空选定图窗”移除目标图窗中的曲线、保留图窗；“删除选定图窗”移除图窗及其曲线分配，其他图窗不变。最后一个图窗也可删除，随后可新建；显式保存的零图窗配置可以恢复。每个图窗顶部也提供删除按钮。
4. reaper 与 correction 分别控制候选项是否显示。筛选不撤销已绘制曲线，也不清除已勾选项。新空图窗保留至少 300 CSS 像素绘图区；有曲线时共用300像素高的坐标区域，图例与标注另外占位，图面不会被公共图标样式压缩。
5. 波形与各图窗共享时间范围、选区。参数图内普通滚轮滚动内容、Ctrl＋滚轮缩放时间轴、左键拖动平移、Shift＋拖动选区、双击回到全长。波形保留 Ctrl＋滚轮缩放与直接拖动选区，也可输入时间窗起点与长度。选中的文字层在波形和参数图中显示区间标注。底部播放条可试听全段、精确选区、暂停、停止与定位。Praat 语谱图是可选显示。
6. 每个图窗可放大、还原。“保存当前图”默认沿用当前主题，将参数图及标注保存为300dpi PNG；可在图窗格式下拉框显式选择 SVG。“保存整幅 PNG”导出白底300dpi图片，包含当前显示的声道波形、标注、已开启的Praat语谱图与此参数图，所有轨道按当前时间窗对齐。语谱图尚未完成时会提示等待或关闭后重试。图片尺寸过大时请缩小图窗。绘图配置可保存到本机，文件读取权限不会随配置永久保存。

2026-10-01：桌面增加“包含子文件夹”，默认关闭，音频与参数目录一起应用此选项。递归文件显示相对路径并按路径匹配，最多10000条目、512目录。左侧列表受工作区高度限制，在列表内部滚动。长 WAV 可显示完整时长的多声道轻量预览，转换后会注明原始/预览格式，试听与预览语谱图使用这份预览，原文件及参数表不变。长录音边界与参数估计的[预览规则](parameter-estimation.md#波形语谱图与试听)一致。使用[当前源码入口](../../scripts/Start-M01-M02-Workbench.ps1)，旧 EXE 不包含本轮修复。证据见[试用修复报告](../testing/2026-10-01-m01-m02-repairs-report.md)。

整幅PNG于2026-09-12在开发入口完成限定Windows Qt/Chrome验证，见[验收报告](../testing/m02-png-closeout-report.md)。历史Research-Fix1.exe未重新打包，不包含此新增按钮。

2026-09-29：音频列表与参数栏通过拖动其与中间绘图区的边界调整宽度，原宽度滑块已移除。各模块分别自动记忆栏宽，窗口临时缩小时不会覆盖偏好。模块名称由顶部标签显示，保存配置和来源按钮在公共工具栏。见[公共布局验收](../testing/p04-resize-report.md)。

图窗是统一宿主内的独立图面板，使用共同主题和播放系统，不另外打开浏览器弹窗。SVG保留可编辑文字并嵌入Doulos SIL及OFL，其他所选字体仍需阅读设备安装且阅读软件支持。固定外观分享优先使用PNG。

参数表输入限制：16 MB、20 万单元格、256 列。支持原参数 XLSX 与普通 `params` SQLite 表，包含有效 `Time_s`。不执行 Excel 公式、链接、SQLite 函数或任意 SQL。不对损坏、乱序或非参数工作簿静默修复。

2026-10-02：新增直接读取唇形记录的 LipArea、LipWidth、LipOpen、LipCirc 四列。复用标注模块的受控读取与时间轴，保留检测缺口，手动偏移仅应用一次，唇形格式沿用其独立安全预算。桌面支持 V2 数值 PKL 及时间戳伴随文件，网页使用安全 `.lip.json`。候选文件需要显式选择，不能视为与 legacy 算法等价。见 [M05-R1 验证](../testing/2026-10-02-m05-r1-report.md)。

方法署名沿用原参数列对应的 Praat、REAPER、VoiceSauce 等来源。表读取使用 openpyxl 和 CPython SQLite，详见统一“方法与来源”。显示已计算参数不代表重新验证外部表的算法来源。

字体在公共[设置](settings.md)统一调整。IPA固定Doulos SIL。整幅PNG的刻度、音标、图例和分区标签使用同一基础字号，总标题稍大；字体加载完成后固定此次图形和文字，再生成300dpi图像。已有图片不追溯改变。
