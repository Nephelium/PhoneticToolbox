# 语音标注对齐

M12-R6 临时版包含图窗置顶、完整标注剪贴与 R5 编辑更新，见 [R6 报告](../testing/m12-r6-report.md)及 [R5 报告](../testing/m12-r5-report.md)。M12 已接入 V3 工作台，操作范围见[迁移验收报告](../testing/m12-report.md)、[R1 修复报告](../testing/m12-r1-report.md)、[R2 工作区报告](../testing/m12-r2-report.md)与[R3 编辑及缩放报告](../testing/m12-r3-report.md)。使用临时 M12 EXE 或开发入口，在侧栏选择语音标注对齐。

## 打开录音和标注

本机选择包含 WAV 的语料文件夹，扫描会包含子目录。按同名 WAV 配对，优先级为原名 `.TextGrid`、`_自动保存.TextGrid`、旧版 `_webedit.TextGrid`、`_post.TextGrid`、`_auto.TextGrid`。没有这些版本时，自动采用唯一的同名前缀标注，例如 `_初始定位.TextGrid`。有多个候选时，点击录音后在选择框明确关联。也可在打开录音后使用右侧当前 TextGrid 切换。中文路径、文件名及标注文字均可用。左列只显示音频名，绿色表示有关联 TextGrid，普通色表示没有；长名称悬停可查看完整内容。

没有 TextGrid、TextGrid 是零字节/纯空白文本，或者合法 TextGrid 没有层时，先加载 WAV。点击创建标注层，自己输入音节和音素层名。创建前不会自动写入标注文件。点击保存后写入实际 TextGrid，默认保留原始空文件。非空但损坏的 TextGrid 仍会报错，不自动清空已有内容。网页先上传 WAV 和可选的 TextGrid/其他资源，再进入工作台。

层名下拉框读取当前 TextGrid 的所有层，不再假定存在 `words`。优先采用文件中实际存在的同名偏好或 `syllables`、`phones` 等层；可改选任意可编辑区间层。两个编辑层需要为覆盖整段音频的 IntervalTier。点层、非全域层在菜单标注类型并保留，参考复用也可处理同名点层。新建音节 / 词层、新建音素层允许手动输入名称追加层，不会改名或覆盖已有层。总时间与音频不一致时提示核对，容许原 TextGrid 六位小数带来的 1 微秒误差，不伸缩标注时间。

R4 桌面标注支持读取最大 2 GB 的 WAV。超出 64 MB 或 3200 万采样值时，自动按块生成 PCM16、第一声道的轻量预览，选择满足预览预算的最高常用采样率，最低 8 kHz，不升采样。约半小时的 TonePerfect 会使用 16 kHz，较短文件可使用更高采样率。已满足预算的普通 WAV 保留原样。界面显示实际预览规格。波形、试听、语谱及强度贴合使用预览样本，其频率上限与细节受预览采样率/16 位量化约束；原 WAV 不改写，TextGrid 仍使用原始时长和秒数，保存继续核对原文件版本。

预览内存预算保持 64 MB、3200 万采样值，输入最多 8 声道、8–96 kHz。即使 8 kHz 第一声道仍超限时，需分段打开。网页和其他模块仍沿用原文件读取预算。TextGrid/词典/词表限 2 MB，词表最多 1 万项，每项 200 字符；TextGrid 最多 64 层、合计 10 万区间或点。递归扫描最多 512 目录、1 万个相关文件。网页沿用现有 1000 条资源列表预算，满额时需先清理旧版本。

R4 将秒数刻度放在词/音素标注层下方，与波形和语谱图共用时间窗，时间窗起点滑块保持在音频总览处。本次按用户要求仅修改和打包，未运行功能验证，详见[R4 构建记录](../plans/2026-09-15-m12-r4-long-audio.md)。

## 从零开始按拼音顺序标注

1. 打开 WAV，选择已有的音节/音素层，或自己输入层名创建两层。使用上传词表，或点击粘贴词表，将 `zhe4 shi4 shang4 ...` 这样的拼音序列粘入，按空格/换行分隔。在词表工具旁开启自动生成音节和音素。下一音节会显示当前位置，也可明确选择要继续的条目。
2. 在波形上普通双击一次确认起点，再普通双击终点。音节层填入下一条拼音，例如 `zhe4`，音素层先建立同起止点的一段 `zhe4`。
3. 在音节内部的波形或标注层双击，将音素层切为 `zh / e4`。工具栏的首次音素切分默认采用首个边界用双击位置，可选按音素数等分，选择会记忆。`shang4` 按 `sh / ang4` 切分，完整韵母保留韵尾。非拼音标签使用词典对应；多于两个音素时，后续音素均分首边界至音节终点。已经切分后，双击音素层只添加点击处的边界，保留原边界；也可拖动边界调整。顺序模式在波形或音节层内遇到零声母音节时保留一段，音素层可手工加边界。
4. 标下一音节时，普通双击从新的起点开始，允许保留中间停顿。Ctrl＋双击直接确定下一音节终点，起点沿用前一音节的当前终点。
5. Esc 或取消起点按钮撤销待定起点。撤销会恢复标注和词表进度。新段不能覆盖已有非空音节/音素，失败不消耗词表。关闭自动生成后，仍可在波形或空白音节层双击起点、终点，建立空白标注后输入文字。此普通模式不需要词表，加载已有 TextGrid 后同样可用。查看全段可将可视时长设为录音时长。

顺序模式的单区间文本修改会保留手工切分时间。普通编辑模式双击词层填充音素、全部替换仍沿用原词典均分规则，属于不同操作。

## 编辑、导航与试听

中央共用波形、语谱图、强度、唇形和标注时间轴。默认视窗为 3.2 秒，短录音显示全段。时间窗滑块及音量放在波形上方。可输入可视时长、切换前后窗，Ctrl＋滚轮缩放；在波形、语谱图或 TextGrid 内均可用 Shift＋滚轮同步平移时间窗，普通滚轮滚动页面。波形与语谱绘图区高度均为 175 px。波形显示音节与音素边界，振幅和左轴刻度随当前视窗内的实际峰值缩放；放大到细节视图后按真实采样时间连接原采样点，较长视窗保留峰值包络。只影响显示，原采样与音量不变。

- 单击词或音素后，在图下文本框输入。支持中文输入法、IPA 和带引号文本，也可在标注层获得焦点后直接输入字符。
- 拖动边界可调整时间。手工移动与插入不再限制为 5/15/20 ms 间距，只保持时间顺序、正时长和文件的 1 微秒保存精度。原本重合的音节/音素边界联动，相邻但独立的音素边界不会被吸附。在音节层按住 Shift＋左键拖动框选，松开后即可拖动选中音节整体平移。也支持 Ctrl 单击多选或从空白处拖动框选。
- 音节层选中后，左右方向键按微调步长整体移动，默认 1 ms，可改为 0.001–1000 ms。步长在右侧层级与保存中设置。移动音节时对应音素一起平移，保持内部边界的相对时间及每段时长，其他层保留。与未选标注重叠、越出录音或音素跨越所选外边界时拒绝整次操作，可撤销。输入框中的方向键保留文本/数值编辑用途。
- 普通模式双击已有文字的词按原词典均分填充音素。双击尚未切分的音素区间，采用工具栏的首次音素切分设置；已切分区间只在点击处加边界。选中边界时 Backspace 合并相邻区间，否则删除选中整段标注并在原位置留空，音节对应的音素一并删除。先单击标注或边界，使焦点离开文本框后使用快捷键。Ctrl＋Z 恢复，保留 50 步。
- Ctrl＋C 复制整段标注，Ctrl＋X 剪切。点击波形、语谱图或标注层的空白位置后 Ctrl＋V 粘贴，保留原文字、时长、内部音素边界和多选间距，不递增声调。粘贴范围与非空标注重叠、越界或目标层类型不符时拒绝整次操作。剪切和粘贴可分别用 Ctrl＋Z 撤销。此为模块内标注剪贴板；输入框仍使用系统文字剪贴板。
- 在波形或语谱图按住左键拖动选区，可从左向右或反向拖动；点击音节或音素时，三图同样同步显示对应范围。框选多音节时选区覆盖整组。焦点不在输入/选择控件内时，P 或空格播放当前选区，再按暂停，再按从暂停位置继续至选区末尾。改变选区后从新的起点播放。尚未选区时提示先选择，不自动播放全段。底部播放条已移除，音量在波形上方。

语谱图使用第一声道和可选毫秒 Hann 窗，默认 20 ms，保留 1024 点兼容选项与原相对幅度显示。强度为第一声道相对 RMS，不能当作校准声压级。唇开和唇宽各自按可见范围缩放，仅用于比较时间关系。图表与页面接公共字体配置，IPA 固定使用 Doulos SIL。

## 词典、词表、搜索与参考

词典每行格式为 `词 音素1 音素2 …`。内置词典沿用 V2，可上传 `.dict` 或 `.txt` 替换本页词典。词表 `.lab`/`.txt` 按空白分词，用于高亮与连续粘贴。两类资源相互独立。与 WAV 同名的 `.lab` 自动关联。

搜索在词层进行，可跳到上/下一项，单项或全部替换。全部替换先显示影响数量，可以撤销。替换词会按词典重新填充对应音素，音素均分属于编辑辅助，不代表模型强制对齐。

参考 TextGrid 支持区间之内、区间之外、起点之前、起点之后四种模式，作用于所有同名层。起点之后从起点延伸至文件末尾。类型或层时间范围不一致时拒绝复用。不同名层保留。可清除参考文件，复用可撤销。

强度贴合保留 V2 的 25 ms RMS、5 ms hop 及原平滑/边界规则。默认内收 10 ms，正数内收、负数外扩，范围 −50 至 80 ms。选定起止范围后执行，没有可信边界时给出提示。

## 唇形和保存

找到同名 `.pkl` 或 `.lip.json` 时自动关联，也可手动选择。唇开与唇宽分别开关，共用一个时间偏移。正值向更晚平移，左右按钮每次 1 ms，按住连续微调，Shift 为 10 ms；Alt＋左右方向键同效。保存唇偏独立更新原记录的 `metadata.lip_manual_offset`，保留其他字段和数组。网页仅使用 `ptb.lip/1` 安全 JSON。本机读取 PKL 采用有界符号解析，不支持任意 Python 对象。

保存 TextGrid 默认写为 WAV 同名的 `_自动保存.TextGrid`。可以修改后缀；本机后缀留空时会先显示覆盖原始 WAV 同名 TextGrid 的确认。原带后缀标注的文件名与实际保存目标均在右侧显示。旧默认 `_webedit` 偏好会更新为新名称，其他自定后缀保留。原来的 `_webedit.TextGrid` 继续兼容读取，不自动重命名或删除。

切换文件、返回网页项目前，以及每 60 秒自动保存到 `_自动保存.TextGrid`，唇偏分别保存。关闭模块时可保存、取消关闭或明确放弃。保存失败、文件被外部修改、保存途中出现新编辑，均保留当前编辑并阻止切换。文本框未按回车的文字也纳入未保存保护，自动保存等待中文输入法组字完成。窗口关闭另有未保存提示。预览页自动保存不触发下载。

本机保存会核对来源和目标版本，使用原子替换；冲突后可先用下载当前 TextGrid 保留编辑，再核对其他窗口的改动。下载安全唇形 JSON 可供网页使用。下载操作保持当前编辑状态，不替代原记录的唇偏保存。

网页保存为项目内新的不可变版本，原资源保留。扫描按同名资源的最新版本配对，下载不会延长有效期。全部保存继续受现有账号隔离、5 GB 空间和 7 天保留规则约束。

## R5 编辑操作更新

- 重新点击录音时优先读取同名原始 `.TextGrid`。即使 `_自动保存.TextGrid` 更新，也不抢占原始文件。原始文件不存在时才回退到恢复副本；右侧当前 TextGrid 可随时明确选择恢复文件。自动保存不会自动替代手动保存原始文件。
- 波形、语谱图、标注层的空白音节位置都可双击设置起点和终点，可以跨图窗完成一对起终点。已有音素内部的双击仍用于插入或初次切分音素。
- 波形图和标注层都可直接拖动边界。普通拖动联动公共边界，Ctrl＋拖动向左收缩左段的终点、向右收缩右段的起点，另一侧留在原时间，两者之间成为空白区间。音节对应的音素外边界跟随；不能跨过内部音素边界。
- 选中边界后直接按 Backspace 合并。选中区间但没有选中边界时，Backspace 删除整段标注及对应音素，原时间段留空；文本输入框中仍正常退格。Ctrl＋Z 撤销整个拖动。
- 图中的选区与强度起止框同步，手工修改时间框也更新选区。选区起止时间直接放在标注层下方，范围很窄时合并为一行以免重叠。原三行框选工具、重复选区提示和音频总览按钮已移除。Shift＋拖动仍框选音节，左右键仍按右侧设置的微调步长移动。
- 语谱图窗长可选 5、10、20、50、100 ms，默认 20 ms。使用实际采样率换算 Hann 窗采样数，FFT 只进行二次幂补零；1024 点兼容选项保留。窗长不改变标注时间、原音频或 30 ms 相对强度显示。
