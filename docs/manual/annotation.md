# 语音标注对齐

M12 已接入 V3 开发工作台，操作范围与验证见[验收报告](../testing/m12-report.md)。启动 `scripts/Start-Research-Workbench.ps1`，在侧栏选择语音标注对齐。本次没有生成 EXE。

## 打开录音和标注

本机选择包含 WAV 和 TextGrid 的语料文件夹，扫描会包含子目录。按同名 WAV 配对，优先级为 `_webedit.TextGrid`、`_post.TextGrid`、`_auto.TextGrid`、原名 `.TextGrid`。可筛选文件，也可在右侧明确选择其他 TextGrid。网页先在项目文件管理上传 WAV、TextGrid 和可选资源，再进入工作台。

默认词层 `words`、音素层 `phones`，可分别改名，偏好会记住。两个编辑层需要为覆盖整段音频的 IntervalTier。点层和其他层在文件中保留，参考复用也可处理同名点层。总时间与音频不一致时提示核对，容许原 TextGrid 六位小数带来的 1 微秒误差，不伸缩标注时间。

当前标注编辑预算：64 MB、最多 800 万帧、8 声道、8–96 kHz，全部声道合计最多 3200 万样本。TextGrid/词典/词表限 2 MB，TextGrid 最多 64 层、合计 10 万区间或点。递归扫描最多 512 目录、1 万个相关文件。网页沿用现有 1000 条资源列表预算，满额时需先清理旧版本。超限会提示缩小输入。

## 编辑、导航与试听

中央共用波形、语谱图、强度、唇形和标注时间轴。默认视窗为 3.2 秒，短录音显示全段。可输入可视时长、切换前后窗，Ctrl＋滚轮缩放，Shift＋滚轮平移标注视图，普通滚轮滚动页面。

- 单击词或音素后，在图下文本框输入。支持中文输入法、IPA 和带引号文本，也可在标注层获得焦点后直接输入字符。
- 拖动边界可调整时间，匹配的词/音素边界按原规则联动。拖动整词会一起移动其音素。Ctrl 单击多个词后可整组移动，也可从空白处拖动框选。
- 双击词按词典填充音素，双击音素区间插入边界。Backspace 清除文字，Alt＋Backspace 合并选中边界。Ctrl＋Z 或撤销按钮恢复，保留 50 步。
- Ctrl＋C 复制词，选中空白区间后 Ctrl＋V 连续粘贴。关联词表时按词表顺序推进，否则沿原版声调递增规则。空间不足时拒绝插入。
- 波形拖动选择试听区间，公共播放条播放所选片段。标注区获得焦点后，P 或空格从当前视窗起点试听，再次按键暂停。

语谱图保留第一声道、1024 点 Hann 窗与原相对幅度显示。强度为第一声道相对 RMS，不能当作校准声压级。唇开和唇宽各自按可见范围缩放，仅用于比较时间关系。图表与页面接公共字体配置，IPA 固定使用 Doulos SIL。

## 词典、词表、搜索与参考

词典每行格式为 `词 音素1 音素2 …`。内置词典沿用 V2，可上传 `.dict` 或 `.txt` 替换本页词典。词表 `.lab`/`.txt` 按空白分词，用于高亮与连续粘贴。两类资源相互独立。与 WAV 同名的 `.lab` 自动关联。

搜索在词层进行，可跳到上/下一项，单项或全部替换。全部替换先显示影响数量，可以撤销。替换词会按词典重新填充对应音素，音素均分属于编辑辅助，不代表模型强制对齐。

参考 TextGrid 支持区间之内、区间之外、起点之前、起点之后四种模式，作用于所有同名层。起点之后从起点延伸至文件末尾。类型或层时间范围不一致时拒绝复用。不同名层保留。可清除参考文件，复用可撤销。

强度贴合保留 V2 的 25 ms RMS、5 ms hop 及原平滑/边界规则。默认内收 10 ms，正数内收、负数外扩，范围 −50 至 80 ms。选定起止范围后执行，没有可信边界时给出提示。

## 唇形和保存

找到同名 `.pkl` 或 `.lip.json` 时自动关联，也可手动选择。唇开与唇宽分别开关，共用一个时间偏移。正值向更晚平移，左右按钮每次 1 ms，按住连续微调，Shift 为 10 ms；Alt＋左右方向键同效。保存唇偏独立更新原记录的 `metadata.lip_manual_offset`，保留其他字段和数组。网页仅使用 `ptb.lip/1` 安全 JSON。本机读取 PKL 采用有界符号解析，不支持任意 Python 对象。

保存 TextGrid 默认写为 WAV 同名的 `_webedit.TextGrid`。可以修改后缀；本机后缀留空时会先显示覆盖原始 WAV 同名 TextGrid 的确认。原带后缀标注的文件名与实际保存目标均在右侧显示。

切换文件、返回网页项目前，以及每 60 秒自动保存到 `_webedit`，唇偏分别保存。关闭模块时可保存、取消关闭或明确放弃。保存失败、文件被外部修改、保存途中出现新编辑，均保留当前编辑并阻止切换。文本框未按回车的文字也纳入未保存保护，自动保存等待中文输入法组字完成。窗口关闭另有未保存提示。预览页自动保存不触发下载。

本机保存会核对来源和目标版本，使用原子替换；冲突后可先用下载当前 TextGrid 保留编辑，再核对其他窗口的改动。下载安全唇形 JSON 可供网页使用。下载操作保持当前编辑状态，不替代原记录的唇偏保存。

网页保存为项目内新的不可变版本，原资源保留。扫描按同名资源的最新版本配对，下载不会延长有效期。全部保存继续受现有账号隔离、5 GB 空间和 7 天保留规则约束。

直接迁移来源为 V2 `web_praat_editor` 与文件服务，6 份原文件哈希见 `third_party/m12-migration.json`。源码、词典和 Praat 格式的来源分别为 ORIGIN-WEBEDITOR、PENDING-DICTIONARY、SRC-PRAAT，工作台方法与引用入口从同一登记生成。词典与早期代码的完整作者/许可链仍未确立，不将本次迁移当作公开发行许可核验。
