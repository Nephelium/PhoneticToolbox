# 汉字转国际音标

本模块在本机逐字转换汉字，并保存读音选择和排版草稿。

1. 重新打开模块时文本为空，转换标准默认 Standard Chinese (Beijing)，已选用的自定义字表会自动载入并选中。在汉字输入中输入汉字、标点或分行文本，左侧选择 11 个内置标准之一，结果实时更新。字符数显示在汉字输入标题右侧，输入与结果两栏默认等宽，可拖动边界调整，底边保持对齐。切换已有标签保留当前编辑。
2. 带蓝色小三角的字有多个字表读音。点击该字，在字旁的小方窗中人工选择；选择只作用于当前文本位置。窗口会避让屏幕边缘，读音较多时可在窗口内滚动。选择后自动关闭，也可按 Escape、点 × 或窗口外部关闭。
3. 汉字字号和音标字号彼此独立，字音间距、行距、粗体、斜体和下划线立即应用。样式下方可分别选择音标颜色、汉字颜色和汉字字体，颜色可恢复跟随主题。汉字字体只改变结果中的汉字层，系统默认跟随全局文字字体。桌面下拉菜单包含本机字体，自定义字体需已安装。IPA 始终使用内置 Doulos SIL。点击等宽排版后，各字组与标点按当前最宽字组对齐，字号、字体和读音改变后自动重算；再次点击恢复自然宽度。行距直接调整实际行间空隙。
4. 字音同显/仅音标和左右排布/上下排布只改变显示，不清空文本或读音选择。左侧设置栏始终显示，间距收紧，小窗口保留滚动。显示声调按钮默认开启，关闭时保留音段附加符号，仅移除声调显示。多音选择窗口仍列出各读音的声调编号供区分。
5. 保存本机草稿保留完整文本、标准、逐位置多音选择和排版。重新打开时不会自动加载旧文本，顶部恢复本机草稿可手动读回。未保存编辑时恢复按钮禁用。标签带圆点或保存按钮带星号时仍有未保存内容，关闭标签会先询问。
6. 点击保存为 PNG 打开导出设置。默认使用当前背景图、模糊和图片不透明度，没有背景图时使用当前背景色。可选图片或纯色，图片可替换并调整0–40 px高斯模糊及0–100%不透明度，点击使用当前背景恢复默认。核对预览后点击导出 PNG，再完成浏览器下载或桌面保存。背景与导出可单独调整，文字保持清晰；自选字色、字体、等宽排版、行距及声调随图导出，不含多音小三角或读音窗。图片、字体或编码失败时按导出窗提示修正后重试。

## 转写范围

转换按字表给出单字读音，多音字需逐位置选择。例如“银行”的“行”默认取字表第一条，可点击选择所需读音。连续语流的音变需结合实际发音校对。各标准的来源与适用范围见模块的方法与引用页。字表缺值显示 `?`，未收录字符、标点、拉丁字符和空白按原文本保留。

说明书正文和图片中的 IPA 使用 Doulos SIL 7.000。核对组合附加符号和上下标时，打开原始 PNG 查看。

选择Unt宽式或严式时显示儿化组合区，可自动组合、逐项手动组合或拆分，也可全部拆分。提示为自动组合后请核对独立的儿字，其他标准隐藏这些儿化控件。

## 自定义字表

在转换标准下点击导入自定义字表，选择汉字或拼音音节类型，读取 XLSX、UTF-8 CSV、TSV 或制表符 TXT。XLSX 可选工作表，公式需先粘贴为值。指定汉字或音节列、音标列和数据起始行，其他列不会导入。起始行包含在数据内，原表行号和前几行预览用于核对列及表头。预览后填写名称，点击保存字表并使用。

汉字可分行列出多个读音，完全重复项去重。拼音支持 ma、ma1、mā、nü3/nv3/nu:3，0与5表示轻声；带调条目优先，无调条目供该音节各调使用，音标不会根据拼音自动补调。未覆盖汉字显示问号。单文件8 MB/50,000条，最多32套字表/总存储8 MB，同名需换名。

声调处理默认保留原样。音标末尾使用五度调值时，选择五度调值 → 声调符号，1为最低、5为最高，例如 ma55 → ma˥˥、ma35 → ma˧˥、ma214 → ma˨˩˦，支持普通、上标及全角数字。已有声调符号保留。末尾数字表示调类时，选择调类，再选择保留原调类或逐类填写调值，例如调类1填33、调类2填21。映射使用自己字表的调值，不预设普通话对应。原始音标和转换结果并排预览。

保存后选中字表，点击声调映射即可修改，无需重新导入。设置随字表保存，下次打开继续使用，可随时恢复保留原样或原调类。调值或调类模式下关闭显示声调会隐藏相应末尾声调，保留音段和附加符号。

字表独立于文本草稿保存，重开模块或应用时自动载入并记住最近选用的自定义表。Windows、macOS与网页版操作相同，各设备分别保存，网页按账号隔离；更换设备或浏览器需重新导入原表。保存失败保留预览；另一窗口更新时先关闭导入窗，重新载入已存字表后重试。

选中已导入字表后，可点击替换字表，选择新文件、核对预览后替换，也可改名，不增加字表数量。点击删除字表并核对名称后确认，会从列表移除并切回内置标准，保留当前文本和其他字表。取消或保存失败保留原表。原始文件仍可重新导入。恢复旧草稿时，表已替换则清除旧的多音序号并提示重新校对；表已删除仍恢复文本与排版，再选择合适标准。
