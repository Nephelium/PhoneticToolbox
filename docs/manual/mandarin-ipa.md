# 汉字转国际音标（M13）

本模块在本机浏览器或桌面宿主中逐字转换。输入文本、读音选择和排版草稿不会发送给外部服务，也不会创建服务器科学计算任务。

1. 重新打开模块时文本为空，转换标准默认 Standard Chinese (Beijing)。在汉字输入中输入汉字、标点或分行文本，左侧选择 11 个旧标准之一，结果实时更新。切换已有标签保留当前编辑。
2. 带蓝色小三角的字有多个旧字表读音。点击该字，在字旁的小方窗中人工选择；选择只作用于当前文本位置。窗口会避让屏幕边缘，读音较多时可在窗口内滚动。选择后自动关闭，也可按 Escape、点 × 或窗口外部关闭。
3. 汉字字号和音标字号彼此独立，字音间距、行距、粗体、斜体和下划线立即应用。样式下方可分别选择音标颜色、汉字颜色和汉字字体，颜色可恢复跟随主题。汉字字体只改变结果中的汉字层，系统默认跟随全局文字字体。桌面下拉菜单包含本机字体，自定义字体需已安装。IPA 始终使用内置 Doulos SIL。
4. 字音同显/仅音标和左右排布/上下排布只改变显示，不清空文本或读音选择。左侧设置栏始终显示，间距收紧，小窗口保留滚动。显示声调按钮默认开启，关闭时保留音段附加符号，汉语拼音保留 ü，仅移除声调显示。多音选择窗口仍列出各读音的声调编号供区分。
5. 保存本机草稿保留完整文本、标准、逐位置多音选择和排版。重新打开时不会自动加载旧文本，顶部恢复本机草稿可手动读回。未保存编辑时恢复按钮禁用。标签带圆点或保存按钮带星号时仍有未保存内容，关闭标签会先询问。
6. 保存为 PNG 使用内置 Canvas 与字体生成白底图片，断网也可用。自选颜色、汉字字体和声调显示随图导出，默认汉字采用适合白底的深色。生成、字体加载或自定义字体不可用时，页面保留文本与结果，可修正后重试。

## 解释边界

这是旧字表的单字映射，不处理连续语流音变，也不根据词语上下文自动判定多音字。例如“银行”的“行”仍默认取旧数据第一条，需要人工选择。11 个选项名称沿用旧页面，名称本身不代表相关规范或出版来源已经核验。未收录汉字/缺失映射显示 `?`，标点、拉丁字符和空白按原文本保留。

图片中的 IPA 使用 Doulos SIL 7.000。组合附加符号和上下标已按浏览器与 Windows Qt 宿主验证；不同图片查看器仍可能采用不同缩放插值，判断字符内容时以原始 PNG 为准。
