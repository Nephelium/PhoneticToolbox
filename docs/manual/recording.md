# 本地录音

M16 在 Windows 开发态桌面内使用。当前默认请求 48 kHz、双声道音频、float32 原始存储。两路都可接麦克风或线路，EGG 仅在设备面板主动指定。普通网页版暂未开放采集工程，不会上传录音作为回退。

## 建立工程和选择设备

点击新建工程，选择一个空文件夹。工程保留原始采样、任务清单、每次 take、全部编辑历史和恢复记录。打开工程时选择包含 `project.json` 的文件夹。同一工程只能由一个窗口写入。

打开设备与录前检测，分别选择输入设备和扬声器/耳机。设备列表会显示声卡接口和可用通道数。默认是同声卡输入 1、2 的两路音频。单输入设备会明确回退单声道。EGG 与音频需要在同一声卡上采集，请按物理接线手工设置角色。设备刷新后身份变化必须重新选择，不会静默切到默认麦克风。

硬件增益请调声卡或麦克风旋钮。录前检测显示峰值、RMS、满幅、极低电平、DC 和通道相似性。单位是 dBFS，不是校准 dB SPL。检测数字增益可实时调整，但不会写进原始采样。原始满幅与数字增益后超幅分别标注。软件收到的原始值可能已经经过驱动/系统音效或 AGC，这些状态需要单独确认。

录前检测不会创建 take。检测可以跳过，实际设备打开或磁盘错误需要先处理。默认不实时外放，避免回授。录后试听通过所选输出设备和所选通道进行，每次试听一条所选声道；双声道采集、同步编辑与导出仍保留全部原始通道。

## 自由录音和任务清单

不填任务即可自由录音。开始后显示波形、可关闭的实时显示谱、收到/落盘帧数和磁盘剩余。停止后显示已存入本地工程，完成导出后才显示已导出。再次录制追加新 take，不覆盖旧录音。录制中切换模块会保留录音，工作台显示录制指示。M05 和 M16 的采集不能同时占用设备。

任务可逐条新增、编辑、复制、排序、停用、跳过和恢复。完成一条后默认停留，下一条需明确点击。移出清单只移除当前任务，录音和任务快照保留在完整 take 历史内。已有 take 的文本/编号/设备快照不会因后来修改任务而变化。

支持 UTF-8 CSV、TSV 和 XLSX，先选择工作表、映射列并预览，再确认导入。任务编号与文件名必须唯一，重复次数 1–100，展开后最多 10000 条。XLSX 公式会拒绝执行，需转为文字。格式化任务编号采用显示文本，保留表中显示的前导零。任务模板另存为 `录音任务清单.json`，可精确重新导入。导出清单 CSV 为阻止公式执行可能增加单引号，精确文本仍保留在工程和 JSON 中。

## 试听和剪辑

在波形拖动选择，或直接输入整数帧。选区统一为 `[起点,终点)`，同时作用于所有通道。可以放大选区、回整段总览；显示倍率只改变画面。

空格有选区时播放选区，无选区时播放整段，播放中再按空格立即停止。长按重复事件、输入框、输入法组字、非激活页和录音中不会拦截为空格播放，更不会改变录音状态。录音停止使用明确的停止按钮。

删除选区会拼接前后部分。剪切把片段引用存入模块音频剪贴板，支持相同采样率、通道数和角色的粘贴。保留选区和片段导出均保留原始 take。不自动淡化、归一化或重采样。全段删除/保留空选区拒绝生成空录音。聚焦波形时可使用 Delete/Backspace、Ctrl/Meta+X/C/V、Z/Y，其他输入保持原快捷键。

撤销、重做、版本下拉和恢复原始均可找回历史。完整 take 历史也包含已移出清单的任务。预听可选当前版本、原始录音或处理差分残余；差分仅支持与直接来源帧长一致的降噪/增益版本。

## 噪声样本与数字增益

先在音频通道选一段只有背景噪声的片段，再点击设为噪声样本。至少 3072 帧、最多 60 秒。界面记录来源 take、版本、通道和范围，统计变化明显时提示人工试听确认，不保证自动辨识出语音。

选择要处理的音频通道并设强度后，一键降噪会处理当前完整编辑版本。EGG 勾选项禁用，EGG 和未勾选通道保持逐样本不变。数字增益同样建立派生版本，不烙入原始。处理期间不能录音，可取消；失败/取消保留原始和此前可用版本。前后与差分预听后，再决定是否选用。

首版为可复现的噪声功率谱减法，参数和来源写入版本元数据。它可能改变气声、擦音、高频细节以及 HNR/CPP 等声学指标，也不能修复削波。科研分析优先保存和使用 raw，再显式选择处理版本。

## 保存、批量导出与恢复

保存/批量导出支持当前 take、当前选区、未跳过任务的选用 take、全部 take 或全部历史版本。选择原始或当前版本及 FLOAT/PCM24/PCM16 WAV 格式后，选择工程之外的目录。程序总会建立新的导出文件夹，附 JSON/CSV 清单、任务快照、帧数、通道、处理记录、哈希和质量提醒。缺录、停用、跳过写入清单，不生成伪造的空 WAV。

float32 WAV 可保留超出 ±1 的浮点值。PCM24/PCM16 超出目标量化范围时拒绝导出，需选择 float32 或显式生成减小增益的版本。长录音按连续帧索引导出不超过 256 MiB 的 WAV 分段。RF64 暂未开放。

批量部分失败时保留成功文件和逐项错误；可选择失败 take 重试，重试也进入新目录。取消不会删除已完成项。未通过回读校验或中途取消的输出使用 `.wav.partial` 扩展名，清单列出这些未完成文件。工程不自动删除原始、历史或恢复产物。

异常退出后再次打开工程可查看恢复条目。只有已落盘、尺寸和哈希通过的前缀能恢复，最后未落盘尾部可能缺失；恢复结果标明不完整，不会补零冒充连续录音。关闭页面/应用会先请求停止并提交，失败则保持窗口。若后台操作未结束，先等待或取消再关闭。

## 已验证边界

Windows 真实 Chrome/Qt 页面、独立本机处理、合成输入/输出设备、恢复与导出已有证据。受控加速 60 分钟数据流验证了分段、总帧数、逐字节内容和有界缓存。它不能替代实体声卡 60 分钟录音、EGG 接线、设备热插拔、模拟前级削波、人耳比较或实体 DPI。Linux 仅纯核心测试，macOS/浏览器采集/正式 EXE 未准入。详见[验收报告](../testing/m16-report.md)。
