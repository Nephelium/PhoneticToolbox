# 生理参数合成 · Windows v3

保存与自存构形共用 Plus 的完整扩展辅音矩阵，包含 14 个构音部位、13 类辅音、186 个辅音表项，并保留元音、其他辅音与下方自定义音标。弹窗加宽，辅音格内自动换行，符号默认 18 px、标签和说明最低 12 CSS px；窄窗口可横向查看全部列，纵向滚动查看下方内容。

自存构形加载时恢复声源设置和 F0；另可自行输入音标，显示在表下方的自定义音标区。模型与来源入口位于参数控制标题旁，右栏各页签支持独立滚轮滚动。

在 Windows 桌面工作台打开本模块，无需登录。

## 布局与观察

参数控制标题旁的模型与来源采用与其他模块方法与引用相同的按钮尺寸，点击查看模型说明及完整致谢。来源弹窗已移除布局选择。工作台默认随可用窗口宽度自动切换两列、三列，旧布局偏好继续保留。三列依次是模型、声学图、参数控制，不包含应用最左侧菜单。两列将声学图放到模型下方，参数列独立滚动；窄窗口下既有三列偏好可横向滚动查看。

生理参数合成的按钮、标签、提示与图表标注最低为 12 CSS px，正文和图表字号设置仍可将文字放大。参数行收紧标签到滑条及相邻行间距，滑条仍可拖动，较大字号的标签允许换行。

当前横截面采用固定 7 × 7 cm 视野，横纵等比例，标尺始终为 1 cm。同一图窗尺寸下，切换截面、构形或修改参数保持比例与原点，空截面也不重置缩放。调整图窗尺寸时等比例适配固定视野，侧缘控制点共用此坐标。

模型可切换正中矢状截面、三维，以及器官、气腔、叠加观察。头部、鼻腔、牙齿和标注可分别开关；空白拖动平移、滚轮缩放，三维可旋转。查看整头与重置视角只改变观察范围。深色主题同时应用于模型、声学图、实时图和放大的 F0 画布。

## 构形与发声

器官栏目连续展示嘴唇与下颌、舌头、舌根、舌骨、软腭、舌侧缘和腭咽口。可拖动模型上的圆点，也可用参数滑块。舌骨与舌根各有前后、高低两个控制量。舌根默认由 VTL 自动联动，拖动或调节舌根参数后自动启用手动舌根；取消勾选可恢复自动模式。

下颌开合默认联动唇开度，取消相应勾选后两者独立。唇部左右宽度独立于上下开度。选择器官后可局部重置，撤销、重做保留。右上角的恢复 /a/ 按钮已移除，底部的 /a/ 构形起点仍可选。引擎仍限制不可能的参数组合，控制点到达约束时会提示。

下方默认提供八个元音以及 /l/、/n/、/t/ 构形起点。打开自存构形可直接载入已点亮的内置构形，包括 /s/；点击设置常用，再点击构形加入或移出底部常用栏，★ 表示已选。/l/ 的舌尖侧缘初值为 -0.60，前部侧缘下降，中央可接触，两侧保留通路。可点击面积函数选择截面，用前、中、后侧缘控制继续调节。提高前侧缘可使两侧支撑、中央形成窄沟，降低可让中央保持接触、两侧开放；左右两侧仍联动。气腔按开放区域分别生成，扣除牙齿实体；关闭牙齿显示仍保留避让。口底附着以方形标记表示，单独改变舌尖不会使它沿口底滑动，下颌改变时随下颌运动。舌腹端可以活动，此处是几何约束参考，未建立个体舌系带力学模型。前侧缘拖动按实际高度映射，完整保留参数负向范围。舌背后移依据当前模型的咽壁、舌体半径和高度限位，抵达边界会停止后退。这些构形用于模型探索，实际音值需结合输出声音判断。

摆好姿势并设置声源后，点击下方保存构形，直接在紧凑国际音标元辅音表点击对应音标。当前器官参数、唇宽、舌根模式、全部声源参数和 F0 一并存入本机构形库。同一音标再次保存会更新该条构形。

表中没有的音标可点击弹窗右上方的输入音标，输入组合音标或附加符号，例如 `ã`、`ãː`，再点击保存构形或按 Enter。自定义音标显示在其他辅音下方，保存模式下点击它可更新对应构形。输入沿用单行 80 字限制，去除首尾空白并保留组合符号；输入已有表项时更新该表项。此前自行输入的 `t͡s`、`n̥` 等现在可直接在扩展表中加载，原构形记录继续保留。

点击自存构形按钮打开同一音标表，内置构形与已保存符号点亮。自存构形载入后恢复其声源与 F0；没有内置或保存记录的音标暂不可点击。自定义音标在表下方直接点击加载。旧的纯音标、斜线或方括号名称可在表中加载，其余旧名称并入自定义音标区。没有声源字段的历史构形保持当前声源。内置 VTL 起点继续保持当前声源和 F0。音标名称用于辨认保存的构形。

声音栏目选择输出设备、音量、监听增益、声源模式、气压、声门开度及后部缝隙。F0 未设置时默认为 150 Hz，已有明确数值保留。发声按钮左边为发声 1 秒，右边为持续发声，发声期间右侧变色并可停止。测试音保留，当前构形试听和 /a→i→u/ 试听按钮已移除。WASAPI 使用共享模式，设备采用 44.1 kHz 时由播放端转换；原生合成与导出仍为 48 kHz，无需改变声卡系统设置。清声模式关闭周期振动，F0 此时不起作用。耳语为模型近似，默认增加 24 dB 试听补偿，界面会显示；补偿应用于试听、动作播放和视频音轨，原生声学计算及声道面积不因此改变。

几何截面和声学面积是不同读数：VTL 会为数值计算和侧通路加入面积修正。口腔闭塞也可能仍有鼻通路。结合界面中的最窄声学面积、鼻腔通路和相关修正判断通路状态。口鼻均闭合、无振动的测试构形在稳态近于静音；开始或结束时仍可能有短暂瞬态。

舌叶与舌根之间增加舌面圆点，口底附着与舌尖之间增加舌底圆点。两点默认随其他舌头参数一起运动，也可单独拖动进行平滑局部调整。舌底继续避让下牙和下颌，口底附着点保持相对下颌固定。重置舌头会恢复随形状态，撤销与重做支持这两个点，保存构形和关键帧会保留其调整。

## 关键帧与 F0

保存当前姿势、播放动作与声音、停止均位于关键帧栏目，模型下方不再保留这一行。卡片无分页，也没有固定条数上限，超出可视范围用滚轮滚动。名字可直接修改，拖动卡片空白处或时间旁的拖动标记可上下排序，拖到列表边缘时自动滚动；也可使用卡片箭头或聚焦卡片后按 Alt+上/下键。排序后名称和时间区间同步更新，手绘 F0 仍位于全局时间轴。清空列表会同时清除关键帧和手绘 F0，可点击撤销清空恢复；开始其他编辑后结束该次撤销机会。点击卡片空白位置即可载入该姿势；名称输入、时长与按钮保持各自操作。

需要改变已存姿势时，点击卡片右侧编辑，可切换到器官或声音栏目调整，再回到关键帧点击保存。取消恢复编辑前构形，未保存的修改不会覆盖原卡片。编辑期间暂不允许切换到另一张卡片编辑，避免误存。关闭页签时会提示未保存编辑。列表与 F0 保存到 v3 的本机配置目录，原 v2 数据不回写。

一个关键帧即可播放和保存动作视频。仅有一个普通帧时，按该卡片的停留时长保持构形并发声；仅有一个静音帧时，保持构形并输出静音。单帧也可手绘 F0。

新添加的普通帧和静音帧默认 0.2 秒，单帧最短 0.05 秒、最长 3 秒。已有帧的明确时长保留。普通帧的时长表示到下一姿势的过渡，末帧表示停留时长。列表保存与播放限制分开：保存没有旧版 12 帧上限，单次合成仍限总计 12 秒，超出会明确提示。调整时长后 F0 按总时长等比例伸缩。

添加静音帧保存该段的起始构形。如果后面还有关键帧，器官在静音时长内按普通帧的平滑动程移至下一姿势，全段音频仍为静音；静音帧在末尾或只有一帧时保持构形。静音卡片可以改名、改时长、移动或移除，其 F0 区间呈灰色留白，鼠标与键盘均不能在其中绘制基频。静音类型随关键帧文件和本机草稿保存，视频也显示静音段并停止绘制 F0。静音段属于用户明确指定的时间轴编辑，与口腔闭塞时由模型计算是否仍有声输出分别处理。

点击添加送气帧，会在当前选中卡片后插入送气段，没有选中卡片时加在末尾。送气帧默认名为 ʰ，名称可以在卡片中直接修改，并同步到时间轴、文件和视频。它不单独保存姿势，默认时长 0.05 秒，允许 0.01–3 秒。放在两个构形帧之间时，器官沿前后构形连续移动，送气段暂时使用清声；放在首尾时沿用相邻构形。至少保留一个构形帧。送气段在 F0 图中留白，可排序、移除，并随文件和视频保存。

底部手绘 F0 支持放大绘制、撤销笔画、恢复逐帧基频。画布实时标出每个姿势名称、起止时间及分界线；重命名、改时长和调整顺序后同步更新。清声段的 F0 线保留为编辑轨迹，不产生周期振动。序列播放结束保留最后姿势。

关键帧缺省基频同样为 150 Hz。没有修改姿势、时长、声源和 F0 等内容时，再次点击播放会直接复用上次动作和音频。缓存保留在当前工作台会话中，重启后首次播放需要重新准备。监听音量和增益可以直接应用于已准备的音频。首次发声和静音后恢复发声时加入约 50 ms 的平滑振幅渐入，短声段自动缩短；连续发声的普通姿势之间不重新渐入。试听、持续发声与视频音轨共用这一输出处理。

清空列表会连同手绘 F0 一起清除，并使本次准备的动作音频失效；此时不能播放或保存动作视频。误清空可立即点击撤销清空恢复原顺序、选中的卡片和 F0。若清空后又新建或编辑，撤销清空入口结束。调整顺序后，卡片时段、播放合成及导出关键帧采用当前列表顺序，手绘 F0 仍沿整段归一化时间轴解释。

导出关键帧打开本机保存对话框，将姿势名称、顺序、时长、器官参数、声源和手绘 F0 一起保存为 `.ptb-vocal.json`。导入关键帧通过本机文件对话框读取，并整体替换当前序列；需要保留当前序列时先导出。无效版本、参数或损坏文件会报错并保留当前序列。文件只包含演示数据，不含音频缓存或可执行内容。当前导出版本 5，记录几何方法 m10/r18，保存局部舌形偏移与送气帧。旧版本 1–4 可读，导入后显示按新版几何重算的提示；同一组旧参数的面积和声音可能变化。合成仍采用 VTL 等效声管，三维侧通路用于描述几何形态。

## 保存动作视频

先准备至少一个关键帧，再在关键帧栏目点击保存动作视频。当前视图保留选中的二维/三维、器官/气腔/叠加模式及当前观察方向，导出 1280×720。六个视图导出 1920×1080，上排二维、下排三维，从左到右分别为器官、气腔、叠加观察。

视频默认保存为 30 fps 的 MP4（H.264 视频、AAC 音轨），包含同步音频、构形动作、关键帧名称与起止时间、F0 曲线和时间游标。音轨使用当前试听音量和增益，导出期间无需让扬声器发声。单帧最短 0.05 秒，单次动作仍限 12 秒。先选择保存位置，完成后才写入最终文件；取消或失败保留已有目标文件。生成视频后也可继续复用准备好的动作播放。

## 实时图与模型来源

面积函数上方的声道采样可选择 65、129、257 截面，默认 129，选择会随本机偏好保存。拖动卡顿时可先选 129，仍有压力再选 65；257 计算量更高，适合性能更好的电脑。播放或导出期间暂不可调整。切换后重新计算截面、中线、声学面积和传递函数，已准备的动作缓存也需重新生成。较低采样可能漏掉窄小通道或改变谱峰，定量比较请固定并记录截面数。这里的 129 和 257 是截面采样点数，对应 128 和 256 个间隔。

口腔声道面积函数、传递函数和当前截面来自实际引擎。口腔面积图不包含鼻腔分支。实线连接各真实截面处的几何面积，虚线呈阶梯状表示每个合成声管段的恒定面积；实线没有从虚线长方形的边界拟合。实时波形、语谱图使用实际合成输出，可调整时长、分析窗和帧移，也可展开查看。无数据时显示空态。深色语谱图使用亮纹表示较强能量，数据、时间与 90 dB 映射范围不变。

方法与引用列出 VTL 2.4 引擎、VTL 2.3 参考手册、Three.js、外部头部轮廓和平均鼻腔的来源。头部轮廓与鼻腔来自分别配准的参考模型。软腭控制鼻咽开口，舌侧通路和舌背限位随构形更新。
