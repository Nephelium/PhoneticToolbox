# 声道工作台 · Windows v3

本轮优先提供 Windows 本机录制入口。打开 `PhoneticToolbox-v3-M10-R4.exe` 后进入公共工作台中的声道页面，页脚为 2026.09 · 录制版 5。无需登录。网页服务器及 macOS/Linux 原生发声仍待迁移。

## 布局与观察

页顶的布局可选自动、两列、三列。三列依次是模型、声学图、参数控制，不包含应用最左侧菜单。两列将声学图放到模型下方，参数列独立滚动。窄窗口手动三列保留三个面板，可横向滚动查看。

模型可切换正中矢状截面、三维，以及器官、气腔、叠加观察。头部、鼻腔、牙齿和标注可分别开关；空白拖动平移、滚轮缩放，三维可旋转。查看整头与重置视角只改变观察范围。深色主题同时应用于模型、声学图、实时图和放大的 F0 画布。

## 构形与发声

器官栏目连续展示嘴唇与下颌、舌头、舌根、舌骨、软腭、舌侧缘和腭咽口。可拖动模型上的圆点，也可用参数滑块。舌骨与舌根各有前后、高低两个控制量。舌根默认由 VTL 自动联动，拖动或调节舌根参数后自动启用手动舌根；取消勾选可恢复自动模式。

下颌开合默认联动唇开度，取消相应勾选后两者独立。唇部左右宽度独立于上下开度。选择器官后可局部重置；撤销、重做及恢复 /a/ 保留。引擎仍限制不可能的参数组合，控制点到达约束时会提示。

下方提供八个元音以及 /l/、/n/、/t/ 构形起点，原 /s/ 示例已移除。/l/ 的舌尖侧缘初值为 -0.60，前部侧缘下降，中央可接触，两侧保留通路。可点击面积函数选择截面，用前、中、后侧缘控制继续调节。前侧缘拖动按实际高度映射，完整保留参数负向范围。舌背后移依据当前模型的咽壁、舌体半径和高度限位，抵达边界会停止后退。这些是 VTL 构形及本项目拟合起点，不代表普通话音值标准，也未经过人类听辨验收。

摆好姿势后点击下方保存构形，输入名称即可加入本机构形库。下拉列表载入自存构形，改名按钮修改选中名称；退出后仍保留。选择内置或自存构形均保持当前声源模式和 F0。关键帧载入则恢复该帧保存的声源，便于一个动作包含不同发声段。

声音栏目选择输出设备、音量、监听增益、声源模式、气压、声门开度及后部缝隙。F0 未设置时默认为 150 Hz，已有明确数值保留。发声按钮左边为发声 1 秒，右边为持续发声，发声期间右侧变色并可停止。保留测试音、当前构形试听和 /a→i→u/ 试听。清声模式关闭周期振动，F0 此时不起作用。耳语为模型近似，默认增加 24 dB 试听补偿，界面会显示；补偿应用于试听、动作播放和视频音轨，原生声学计算及声道面积不因此改变。

几何截面和声学面积是不同读数：VTL 会为数值计算和侧通路加入面积修正。口腔闭塞也可能仍有鼻通路。界面显示最窄声学面积、鼻腔通路和相关修正，不把空白横截面当成全部声道已封闭。口鼻均闭合、无振动的测试构形在稳态近于静音；开始或结束时仍可能有短暂瞬态。

## 关键帧与 F0

保存当前姿势、播放动作与声音、停止均位于关键帧栏目，模型下方不再保留这一行。卡片无分页，也没有固定条数上限，超出可视范围用滚轮滚动。名字可直接修改，拖动卡片空白处或时间旁的拖动标记可上下排序，拖到列表边缘时自动滚动；也可使用卡片箭头或聚焦卡片后按 Alt+上/下键。排序后名称和时间区间同步更新，手绘 F0 仍位于全局时间轴。清空列表会同时清除关键帧和手绘 F0，可点击撤销清空恢复；开始其他编辑后结束该次撤销机会。点击卡片空白位置即可载入该姿势；名称输入、时长与按钮保持各自操作。

需要改变已存姿势时，点击卡片右侧编辑，可切换到器官或声音栏目调整，再回到关键帧点击保存。取消恢复编辑前构形，未保存的修改不会覆盖原卡片。编辑期间暂不允许切换到另一张卡片编辑，避免误存。关闭页签时会提示未保存编辑。列表与 F0 保存到 v3 的本机配置目录，原 v2 数据不回写。

新添加的普通帧和静音帧默认 0.2 秒，单帧最短 0.05 秒、最长 3 秒。已有帧的明确时长保留。普通帧的时长表示到下一姿势的过渡，末帧表示停留时长。列表保存与播放限制分开：保存没有旧版 12 帧上限，单次合成仍限总计 12 秒，超出会明确提示。调整时长后 F0 按总时长等比例伸缩。

添加静音帧保存当前构形，并在该段保持构形、输出静音。静音卡片可以改名、改时长、移动或移除，其 F0 区间呈灰色留白，鼠标与键盘均不能在其中绘制基频。静音类型随关键帧文件和本机草稿保存，视频也显示静音段并停止绘制 F0。静音段属于用户明确指定的时间轴编辑，与口腔闭塞时由模型计算是否仍有声输出分别处理。

底部手绘 F0 支持放大绘制、撤销笔画、恢复逐帧基频。画布实时标出每个姿势名称、起止时间及分界线；重命名、改时长和调整顺序后同步更新。清声段的 F0 线保留为编辑轨迹，不产生周期振动。序列播放结束保留最后姿势。

关键帧缺省基频同样为 150 Hz。没有修改姿势、时长、声源和 F0 等内容时，再次点击播放会直接复用上次动作和音频。缓存保留在当前工作台会话中，重启后首次播放需要重新准备。监听音量和增益可以直接应用于已准备的音频。录制版 5 在首次发声和静音后恢复发声时加入约 50 ms 的平滑振幅渐入，短声段自动缩短；连续发声的普通姿势之间不重新渐入。试听、持续发声与视频音轨共用这一输出处理。

导出关键帧打开本机保存对话框，将姿势名称、顺序、时长、器官参数、声源和手绘 F0 一起保存为 `.ptb-vocal.json`。导入关键帧通过本机文件对话框读取，并整体替换当前序列；需要保留当前序列时先导出。无效版本、参数或损坏文件会报错并保留当前序列。文件只包含演示数据，不含音频缓存或可执行内容。

## 保存动作视频

先准备至少两个关键帧，再在关键帧栏目点击保存动作视频。当前视图保留选中的二维/三维、器官/气腔/叠加模式及当前观察方向，导出 1280×720。六个视图导出 1920×1080，上排二维、下排三维，从左到右分别为器官、气腔、叠加观察。

视频为 30 fps 的 WebM，包含同步音频、构形动作、关键帧名称与起止时间、F0 曲线和时间游标。音轨使用当前试听音量和增益，导出期间无需让扬声器发声。单次动作仍限 12 秒。先选择保存位置，完成后才写入最终文件；取消或失败保留已有目标文件。生成视频后也可继续复用准备好的动作播放。

## 实时图与模型来源

口腔声道面积函数、传递函数和当前截面来自实际引擎。口腔面积图不包含鼻腔分支。实时波形、语谱图使用实际合成输出，可调整时长、分析窗和帧移，也可展开查看。无数据时显示空态。深色语谱图使用亮纹表示较强能量，数据、时间与 90 dB 映射范围不变。

方法与来源入口保留 VTL 2.4 引擎、VTL 2.3 参考手册、Three.js、外部头壳和平均鼻腔的分别署名。鼻腔是参考配准，头壳不是 JD2 个体扫描。鼻腔多余长条来自开放截线错误封口，本轮修正截线连接，原鼻腔参考网格保留。绿色鼻咽连接在两种视图中共用几何，软腭独立控制开口，显示咽壁不再被其带入。唇部采用分离的光滑体积，移除旧牙龈连接面导致的交叠。舌侧通路拟合和舌背后移限位另会影响实际构形，详见[R3 迁移证据](../testing/m10-report.md)与[R4 验证和适配边界](../testing/m10-recording-features-report.md)。
