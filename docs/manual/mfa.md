# MFA 自动标注

MFA 将音频与已有转写强制对齐，输出词与音素的 TextGrid 边界。本功能不做语音识别。边界仍需人工校对。

## 正式入口

本轮开发入口为 `scripts/Start-M11-Workbench.ps1`，使用项目已有 `.venv/v3-dev` 与同一个工作台、持久任务服务。进入侧栏 **MFA 自动标注**。不启动旧 MFA GUI，不需要主程序环境安装 MFA。旧 EXE 没有更新。

```powershell
& 'D:\PhoneticToolbox\PhoneticToolbox_v3\scripts\Start-M11-Workbench.ps1'
```

默认组件目录为 `%LOCALAPPDATA%/PhoneticToolbox/v3/components/mfa`。便携位置可显式指定较短路径，只影响本次启动进程，退出恢复原进程环境：

```powershell
& 'D:\PhoneticToolbox\PhoneticToolbox_v3\scripts\Start-M11-Workbench.ps1' -ComponentRoot 'D:\PhoneticToolbox\PhoneticToolbox_v3\output\m11-components'
```

启动器复用已有项目任务库，只检查现有 schema，不运行现存库 DDL。当前开发入口依赖项目环境，不是面向新电脑的正式安装程序。

## 已有环境

1. 展开组件安装与环境检查，选择环境根目录或旧 `auto_alignment` 目录。
2. 分别选择声学模型 ZIP 与对应词典，不下载其他语言。
3. 点击检查已有环境与模型。当前固定 MFA **3.3.8 / Windows x86_64**。检查实际依赖、环境文件内容、模型／词典 hash，并执行公开合成小任务。首次完整校验可能需要数分钟。
4. 成功后才登记运行时与模型。模型／词典按内容摘要独立保存到组件目录的 `resources` 下；运行环境本身不修改、不升级，不修改全局 Python／PATH／Conda。

当前公开自检包含词典中 `a` 或 `啊` 的合成输入。其他语言需要相应公开探针，暂不伪装为通用模型已验证。

## 离线组件

选择组件 ZIP、独立可信发布清单 JSON，并填入从发布者独立可信渠道核对的清单 SHA-256。不要把 ZIP 内自带的摘要或下载后自行计算的摘要当成发布者真实性证明。

清单格式 `m11-component/1` 包含平台、架构、固定 MFA 版本、来源、依赖／许可记录、包长度／hash、展开总字节数及逐文件长度／hash。模型／词典与运行时分开选择。安装会检查平台、摘要、空间和路径，拒绝路径穿越、链接、大小／清单不一致，在新版本最终目录自检成功后切换。失败目录与旧版本保留；没有自动删除组件的操作。

本轮没有公开的 PTB 固定组件 URL，下载按钮明确显示待发布。已有下载实现只接受固定 HTTPS 来源、可信摘要及可验证 Range 续传，尚无真实公共端到端下载验收。不要使用 `latest`。

本地候选包由 `scripts/verify_m11_component.py` 生成，逐文件清单只证明本轮本地来源审计与完整性，**不等于互联网发布清单或完整再分发许可已经审核通过**。短路径导入用 `scripts/verify_m11_import.py` 验证。Windows 原生库有路径长度约束，过长安装位置会提前拒绝；不改系统长路径设置。

已安装组件、模型与词典可离线对齐，普通应用更新复用登记资源。当前版本是本地验证候选，不复制到 Linux 使用。主包只增加轻量 bootstrap；构建清单显式排除 MFA／kalpy，并未重打 EXE。

## 输入与运行

- WAV 与唯一同名 `.lab`、`.txt` 或 `.TextGrid` 配对。目录可以包含说话人子目录。缺少转写、空转写或同名多份转写会拒绝。
- TextGrid 使用独立的转写区间层。MFA 3.3.8 忽略 `notes` 以及以 `words`／`phones` 结尾的参考标注层。程序不会偷偷改层名或猜选转写。
- 转写格式必须符合词典。汉字词典配汉字，拼音词典配规定格式。自定义词典作为任务输入并计入网页额度；不接受网页任意上传模型执行。
- 默认 Beam=10、Retry beam=40。调高 Beam 时 Retry 至少升到四倍，调低 Beam 不自动降低 Retry；提交时 Retry≤Beam 才归一化为四倍。
- 接收上限：100 份音频、总输入 64,000,000 B、每份单／双声道 WAV 最长 120 秒。相对路径 UTF-8 长度最多 110 B。上限不是成功保证，见 [资源实测](../testing/m11-report.md)。
- 任务进度表示阶段，不估算剩余时间。可切换页面，从任务记录回看；保存参数草稿不保存浏览器 File 授权。重开页面后任务仍在，待提交文件需重新选择。
- 取消停止本任务及子进程，失败／超时／取消的部分文件保留在组件目录 `attempts/<job>-<generation>-<nonce>`。完整原始日志保留在其中，页面显示脱敏后的最后 256 KiB。本轮不自动清理这些本机诊断目录，空间会累积。
- 完成后可以逐个下载或保存全部成果。保存会新建 `MFA-任务号-随机串` 子目录，保留原始 TextGrid 和既有结果。溯源包括输入、参数、运行环境／模型／词典 hash、资源和实际 TextGrid 时间／标签。

## 网页和节点

已登录项目提供同一 MFA 页面，浏览器电脑无需 Python。服务器只接受管理员登记的运行时与模型 ID，上传、词典、结果等继续走账号隔离和 P07 的 1,000,000,000 B／259,200 秒政策，下载不续期。

当前正式远程执行桥、Linux MFA 环境与资源准入尚未完成。任务显示等待已验证节点，服务器回退关闭。没有登记模型时不能提交，也不会在网页端自动安装 Python。所需公共接线详见 [M11 交接](../specs/m11-remote-handoff.md)。
