# MFA 自动标注

MFA 将音频与已有转写强制对齐，输出词与音素的 TextGrid 边界。使用前准备对应转写，完成后人工校对边界。

## 打开模块

桌面侧栏打开 **MFA 自动标注**。首次使用时安装独立组件，其中包含 MFA 运行环境、声学模型与词典。

默认组件目录为 `%LOCALAPPDATA%/PhoneticToolbox/v3/components/mfa`。组件适用于 Windows x64。

## 安装组件

在组件安装与环境检查中选择一种方式即可：

1. **下载并安装组件**：从官网固定版本地址获取 ZIP，显示已下载大小、总大小、实时速度和进度条。下载后依次校验、解压、运行真实 MFA 自检，成功后自动应用配套模型与词典。校验和运行检查阶段显示活动进度条。
2. **选择组件压缩包**：从官网、百度网盘或夸克网盘取得原始组件 ZIP，直接选择它，无需自行解压。
3. **选择已解压文件夹**：先解压到固定的短路径，选择其中同时含 `env`、`models` 和 `component-manifest.json` 的根目录。程序校验全部文件并自检后直接使用该位置，请勿移动、删除或修改该文件夹。

使用时选择 `PhoneticToolbox-MFA-3.3.8-r1-windows-x64.zip`。其中包含 Python、MFA 3.3.8、Kaldi、`mandarin_mfa.zip` 与 `mandarin_mfa.dict`，配套转写使用词典所收录的汉字。安装后可离线对齐。需要拼音或其他语言时，可点击下载声学模型（官方）或下载发音词典（官方），在系统浏览器打开对应官方目录。下载兼容 MFA 3.3.8、语言与音素集匹配的资源，再从上方下拉框导入并检查。官方目录分别为 [声学模型](https://mfa-models.readthedocs.io/en/latest/acoustic/index.html) 和 [发音词典](https://mfa-models.readthedocs.io/en/latest/dictionary/index.html)。

下载体积 812,556,132 B，ZIP 展开文件长度合计 2,805,971,894 B。安装还需要下载缓存、复制登记的模型/词典和自检临时空间，建议目标磁盘至少预留 5 GB。路径过长时换用较短的安装位置。

程序自动校验组件文件，失败时保留原可用环境。下载中断后可重试；文件损坏或不完整时重新取得发布者提供的同版 ZIP。

固定地址为 `https://www.phonetictoolbox.com/releases/components/mfa/3.3.8-r1/PhoneticToolbox-MFA-3.3.8-r1-windows-x64.zip`。官网下载不可用时，可通过发布者提供的网盘取得同版 ZIP，再用选择组件压缩包安装。

## 重装与卸载

关闭应用后直接运行新版安装包，沿用原目录覆盖安装，设置、草稿、研究文件及已安装 MFA 保留，无需先卸载。卸载时可选择同时删除本应用下载或从 ZIP 安装的组件、其配套资源与下载缓存，默认保留；静默卸载也保留。自行选择的外部环境和原始文件保持原位置。无法确认归属或被占用的组件会保留并提示。

## 高级：已有环境

1. 在上方声学模型下拉框选择导入其他声学模型，选择 ZIP。在发音词典下拉框导入对应词典。
2. 已有已检查环境时直接复用。如需复用其他环境，展开组件安装与环境检查中的高级：使用其他已有环境，选择 MFA 3.3.8 / Windows x86_64 环境根目录。模型与词典统一在上方选择。
3. 点击上方检查并应用所选资源。当前固定 MFA **3.3.8 / Windows x86_64**。等待运行环境与配套资源检查完成。首次完整校验可能需要数分钟。
4. 新选文件显示待检查，检查前暂停提交，成功后登记并自动应用、记住模型与词典组合，清除此前的自定义词典覆盖。失败保留旧登记和待检查选择，可重选对应文件，或取消待检查选择返回已应用组合。
5. 模型与词典检查通过后会保存到组件目录，重开页面可继续选择。

当前资源检查要求词典含有 `a`、`啊` 或 `a1`。请选择含有其中词条的配套模型与词典。

本地旧版 `mandarin.zip` 与 `mandarin_pinyin_tab.dict` 的数字声调音素兼容。`mandarin_mfa.zip` 使用另一套音素，与这份拼音词典不能混配。分别检查转写词条覆盖和模型音素集兼容性。

## 输入与运行

- 打开音频目录递归读取 WAV 与同名转写，包括说话人子目录；导入音频与转写只读取手选文件，两者使用相同任务链。转写来源可选自动、LAB、TXT、TextGrid。自动模式要求唯一同名转写，显式选择格式后允许其他格式共存，只读取所选文件，不缺省回退到其他格式。更改来源后需重新读取，旧文件不会被删除。
- TextGrid 优先使用独立的转写区间层。若仅有一个非空 `words` 层，则将其词标签按顺序拼为整段转写重新对齐，旧边界不作为约束；`phones` 不作为词转写。多个 `words` 层且没有独立转写层时拒绝猜选。转换只修改任务目录中的副本，并写入溯源。
- 发音词典与声学模型一样使用下拉框。可选相同声学模型已经登记的配套词典、当前页面导入的词典，或导入其他词典。桌面新导入资源经实际检查后登记并应用，重开页面可从登记下拉框继续选择；网页自定义词典只作为本次任务输入。汉字词典配汉字，拼音词典配规定格式，音素集也须与声学模型匹配。已应用词典摘要对应实际选中词典，自定义词典计入网页额度。
- 新草稿默认 Beam=100、Retry beam=400，已有显式保存值和历史任务保留。调高 Beam 时 Retry 至少升到四倍，调低 Beam 不自动降低 Retry；提交时 Retry≤Beam 才归一化为四倍。更宽搜索可能提高难例的可对齐性，也可能增加计算耗时。
- 接收上限：100 份音频、总输入 64,000,000 B、每份单／双声道 WAV 最长 120 秒。相对路径 UTF-8 长度最多 110 B。对齐耗时与成功情况取决于输入和模型。
- 任务进度表示阶段，不估算剩余时间。可切换页面，从任务记录回看；保存参数草稿不保存浏览器 File 授权。重开页面后任务仍在，待提交文件需重新选择。
- 取消会停止当前任务。失败、超时或取消后可查看错误日志，再修正输入或重新提交。已完成任务的临时文件保留期限见[本机存储与自动清理](settings.md)。
- 完成后可以逐个下载或保存全部成果。TextGrid 与原音频同名，不添加前置序号，便于 TextGrid 标注工具自动匹配；不同子目录有同名音频时，后续重名结果仅在末尾补号。保存会新建 `MFA-任务号-随机串` 子目录，保留原始 TextGrid 和既有结果。溯源包括输入、参数、运行环境／模型／词典 hash、资源和实际 TextGrid 时间／标签。

## 本机速度与设备

当前 MFA 3.3.8 / Kaldi 与普通话 GMM-HMM 模型使用 CPU 对齐。

词典未收录的词会在任务运行前提示，具体词可在错误日志中查看。请补充对应发音词典，或选择覆盖这些词的模型与词典。

完整词典与模型在每任务仍重新初始化，几秒输入也有固定开销。多个短文件尽量在同一任务内提交，按当前 100 份和 64 MB 上限共享一次初始化。
