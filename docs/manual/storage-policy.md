# 网页文件空间和保留时间

新政策目标是每账号 **1 GB = 1,000,000,000 字节**，新数据默认最多 **3 天 = 259,200 秒**。所有项目共用额度，上传、结果、缓存、临时数据和写入预留都计入。共享安装的软件和模型不计入个人额度。

页面显示服务返回的实际总额度。若提示新政策尚未启用，管理员仍需完成迁移，新增写入暂停。代码和帮助更新不表示运行库已经切换。

新上传从上传最终确认开始计时，科学分析结果从生成成功开始计时。ZIP、展开、复制和切分等派生文件不晚于输入到期。访问、下载、刷新和改名均不续期。旧文件继续按列表显示的原到期时间保留。

旧账号占用和预留超过新额度时，可以下载仍有效的文件，也可以直接删除。新增上传或生成暂停，不会为了降到 1 GB 自动删除旧数据。无需先下载才能删除。

只有实际删除成功才释放占用。删除失败会显示删除未完成，可以重试；仍在的文件和预留继续计入额度。未完成上传最多保留 24 小时。任务引用的输入到期时，任务不能继续使用或发布依赖该输入的结果。

需要长期保存的文件请下载到自己的设备。到期后不能继续访问，异常或服务停机可能延迟物理清理，服务恢复时会核对清理。网页政策不删除电脑上的原文件，桌面本地研究文件不应用网页三天清理。

当前实现、共享接线待办及实际迁移边界见 [P07-POLICY 报告](../testing/p07-policy-report.md)。
