# 网页文件空间和保留时间

账号的各项目共用文件空间。页面显示总额度、已用空间和文件到期时间。上传、结果、缓存、临时数据和写入预留都计入占用，共享安装的软件和模型单独管理。

若页面提示暂时无法上传，可以继续下载或删除仍有效的文件。

新上传从上传最终确认开始计时，科学分析结果从生成成功开始计时。ZIP、展开、复制和切分等派生文件不晚于输入到期。访问、下载、刷新和改名均不续期。旧文件继续按列表显示的原到期时间保留。

空间已用满时，新增上传和生成会暂停。可以先下载需要保留的文件，再删除不再需要的内容；也可以直接删除。

只有实际删除成功才释放占用。删除失败会显示删除未完成，可以重试；仍在的文件和预留继续计入额度。未完成上传最多保留 24 小时。任务引用的输入到期时，任务不能继续使用或发布依赖该输入的结果。

需要长期保存的文件请在到期前下载到自己的设备。网页文件到期后无法继续访问，电脑上的原始文件及桌面本地研究文件由用户自行管理。
