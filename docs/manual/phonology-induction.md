# 音系归纳

## 启动与流程

在项目目录运行 `scripts/Start-M14-Workbench.ps1`，进入统一工作台的“音系归纳”。该入口使用项目专用 `.venv/m14` 和已构建前端，不安装环境、不执行数据库 DDL。

1. 选择 XLSX/XLS/CSV/TXT/TSV 或 DOCX 表格，先查看原始表格样例，再选择字头、IPA、备注所在列及数据开始行。列号和行号从 1 计数，默认第 1、2、3 列，从第 2 行开始，备注可选“不使用”。Excel 可选工作表，DOCX 可选表格。文本可选分隔符以及 UTF-8、GB18030/GBK、UTF-16 编码，自动模式识别 BOM 并默认 UTF-8。GBK 文件可在选择文件前设置 GB18030。改变工作表、编码、分隔符或开始行时刷新样例。单辅音默认作为韵母、声母记为 Ø，也可选择作为声母、韵母记为空。确认导入成功后才替换当前数据。
2. 调类页直接编辑名称和顺序。拖动交换，也可使用上下按钮。同名调类归组，空名回退原调值，表中显示记录数和例字。保存调类设置并继续，或还原本次编辑。切换步骤保留尚未保存的输入。
3. 声韵页在当前页面编辑双列表。Ctrl/⌘ 多选不连续项，Shift 连续选择，拖动任一选中项可整组移动，也可上移、下移。归并时单选源项、选择目标，在页内核对影响记录数和例字后确认。可取消本次归并、撤销单条归并、还原本次编辑。保存声韵设置后进入结果页。原始 IPA、字头和备注保留。
4. 结果页提供声母→韵母、韵母→声母、二维声韵表三个预览按钮。搜索字头或 IPA 覆盖全部记录，支持原始 IPA、归并后的声韵组合和 Unicode 等价形式。上下按钮或 Enter 切换命中，自动定位到对应页或矩阵单格。导入与归并审阅只出现在此步，展开可见来源行号、原字音、备注、声韵归并、调值与调类。生成三份文件：`同音字表_韵母到声母.docx`、`同音字表_声母到韵母.docx`、`同音字表_二维表.xlsx`。两份 Word 包含统计与不同主次顺序，Excel 的行是韵母、列是声母。三者保留全部重复字项与组内原记录顺序。
5. 桌面可选择目录保存全部，或逐项下载。网页复用平台任务/资产与完整 ZIP 下载接口，但是否可运行取决于平台能力验收，详见报告。目录已有任一同名结果会拒绝整组保存，请选新目录。取消目录选择保留生成结果。

## 审阅与恢复

- 导入失败保留原编辑和已有结果。成功导入新文件才替换工作数据。空文件、无有效记录、缺列、损坏、公式表格、错误编码或超预算均有明确失败反馈。
- 新导入使用 `m14/2`。各格式保留空字段和字面 NA，缺字头或 IPA 的行会跳过并列明。疑似多音节、只有调值或重音符号的行也会跳过，含 `?` 或替换字符的行提示核对。重复记录保留，未知 IPA 不自动纠正。
- `m14/2` 修复预组/组合鼻化元音、连音符、元音前的 ɹ/ɻ、重音标记、上标数字调值及 cç 规范分解形式。原始 IPA 保留，分类符号使用 Unicode NFD。单辅音和成音节辅音继续遵循所选策略。该规则不替代方言音系判断，结果页须人工核对。
- 文件上限 2,000,000 字节，读取最多 10,001 行记录、有效记录最多 10,000 条，64 列、每个单元格 512 字符。结果文档按每页 100 条显示，矩阵窗口为 12 行×10 列，每格 60 条分页，搜索仍覆盖全部记录。声韵矩阵最多 20,000 格，单格不得超过 Excel 32,767 字符，三文件总预算 16 MB。超预算拒绝，不截断语料。复杂表可能达到 60 秒执行期限，应按需要拆分输入。
- 生成后预览绑定本次设置。继续编辑会标记已有成果需要重新生成，并在保存设置前禁用生成。页面预览核对的是分组、顺序与内容，Word 纸张分页以实际 DOCX 为准。
- 编辑过程中保存草稿到本机当前账号/项目作用域。关闭标签可取消、放弃或保存后关闭；草稿写失败时标签保留。草稿含文件 ID 与审阅数据，服务器源文件到期后需重新导入。
- 页内保存更新当前工作草稿，顶部保存草稿将当前编辑持久保存到本机。待确认的归并须先确认或取消，待导入的新文件须先确认或取消。旧 `m14/1` 草稿可恢复查看，重新导入后才以新解析生成，历史结果不自动重算。
- 任务可取消，未完成的三件结果不发布。失败后保留已确认设置，修正输入或重试。任务执行期间仍使用公共宿主，不在 API 事件循环内做文档导出。
- 字体使用生成时设置。音标固定 Doulos SIL。DOCX/XLSX 不嵌入字体，在另一台机器阅读时需具备相应字体。Excel 行高上限内无法完整显示的大格，内容仍在编辑栏可见。

## 平台边界

本轮源码改版与解析修复见 [M14-R1 报告](../testing/2026-10-05-m14-r1-report.md)。原始迁移与平台证据保留于[历史验收报告](../testing/m14-report.md)。Windows/WSL 核心、实际 Chrome 与 Qt 分别登记，未通过能力门的平台仍明确不可用，Windows 浏览器访问某地址不等同 Linux 原生浏览器验收。旧 EXE 不包含本轮修改，需从上述源码入口重新启动。
