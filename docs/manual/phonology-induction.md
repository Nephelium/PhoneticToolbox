# 音系归纳

## 启动与流程

在项目目录运行 `scripts/Start-M14-Workbench.ps1`，进入统一工作台的“音系归纳”。该入口使用项目专用 `.venv/m14` 和已构建前端，不安装环境、不执行数据库 DDL。

1. 在导入页选择是否跳首行及单辅音策略，再用工具栏导入 XLSX/XLS/CSV/TXT/TSV。第一列字头、第二列 IPA、第三列可选备注。UTF-8 文本支持 BOM，Excel 读取第一个工作表。默认跳首行、单辅音按零声母字处理。选项只在下次导入生效。
2. 调类页进入编辑弹窗。拖一行到另一行交换顺序。为调值填写调类名称，同名即归组，空名回退调值。确认后生效，取消保留上次确认设置。
3. 声韵页编辑双列表。Ctrl 多选不连续项，Shift 连续选择；拖动任一选中项可整组移动。归并时单选源项→归并按钮→目标项；可取消本次归并或整个弹窗。确认后在映射和逐行审阅表检查结果。原始 IPA、字头和备注不被改写。
4. 结果页生成三份文件：`同音字表_韵母到声母.docx`、`同音字表_声母到韵母.docx`、`同音字表_二维表.xlsx`。两份 Word 包含统计与不同主次顺序，Excel 的行是韵母、列是声母。三者都保留重复字项与原分组内顺序。
5. 桌面可选择目录保存全部，或逐项下载。网页复用平台任务/资产与完整 ZIP 下载接口，但是否可运行取决于平台能力验收，详见报告。目录已有任一同名结果会拒绝整组保存，请选新目录。取消目录选择保留生成结果。

## 审阅与恢复

- 导入失败保留原编辑和已有结果。成功导入新文件才替换工作数据。空文件、无有效记录、缺列、损坏、公式表格、非 UTF-8 均有明确失败反馈。
- 缺字/音标与常见表头行按 V2 规则跳过并列明。重复行保留。TXT/TSV 的空字段和 NA 行为与 Excel/CSV 不同，见[功能映射](../modules/evidence/M14-source-map.md)。未知 IPA 不自动纠错，需人工核对预览。
- 原始记录预览最多 200 条，处理和导出使用全部记录。文件上限 2,000,000 字节，输入最多 10,000 条，声韵矩阵最多 20,000 格，单格不得超过 Excel 32,767 字符，三文件总预算 16 MB。达到预算会拒绝，绝不截断语料。复杂表可能达到 60 秒执行期限，应按需要拆分输入。
- 编辑过程中保存草稿到本机当前账号/项目作用域。关闭标签可取消、放弃或保存后关闭；草稿写失败时标签保留。草稿含文件 ID 与审阅数据，服务器源文件到期后需重新导入。
- 任务可取消，未完成的三件结果不发布。失败后保留已确认设置，修正输入或重试。任务执行期间仍使用公共宿主，不在 API 事件循环内做文档导出。
- 字体使用生成时设置。音标固定 Doulos SIL。DOCX/XLSX 不嵌入字体，在另一台机器阅读时需具备相应字体。Excel 行高上限内无法完整显示的大格，内容仍在编辑栏可见。

## 平台边界

核心和导出已具有 Windows/WSL 对照测试，正式桌面与 Linux 服务的证据分开登记于[验收报告](../testing/m14-report.md)。未通过能力门的平台明确不可用，不能把 Windows 浏览器访问某地址视为 Linux 原生浏览器验收。
