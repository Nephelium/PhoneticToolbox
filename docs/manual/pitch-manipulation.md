# 变速变调（M08）

当前已接入 Windows 正式开发工作台，实际 HTTP、Chrome 和 Qt 宿主验收范围见 [接线报告](../testing/m08-wiring-report.md)。使用项目源码开发入口 `scripts/Start-M08-Workbench.ps1`；旧安装 wheel 与 EXE 未更新。真实 PostgreSQL 网页和 Linux 正式计算仍未开放。入口显示尚未接入时不能靠刷新或更改科学参数绕过。

1. 选择音频目录或导入音频。科学处理要求宿主提供 M08 adapter。正式文件接口现已支持 WAV/MP3/FLAC，并由实际 Praat 解码；三格式已用本轮短合成文件验收。
2. 原波形和 F0 使用同一原始秒时间。波形放大、缩小与适合窗口控制当前视野。F0 图 Shift+拖动修改有声帧，Ctrl+拖动恢复；普通拖动平移，Ctrl+滚轮缩放，左右方向键平移。无声部分不手工补成有声。
3. 默认显示范围 50–350 Hz，可应用任意有效上下界；显示范围不限制 Praat 计算频率。参考线独立添加/清除。所有图采用公共字体与主题，IPA 固定 Doulos SIL。
4. 导入基频序列每行一个值，或每行“时间 F0”两列，时间列忽略。程序沿当前视野内唯一连续有声段均匀重采样。存在多段间断 F0 时先缩放到一段。不会重置视野或更改视野外曲线。
5. 语速 1.0 为原速，0.8 减速、1.2 加速。合成当前视野与合成整段是独立操作。合成音播放以实际输出时长为准；当前视野原音始终试听原音可见范围。页面改参数不会覆盖已有结果，结果标签保留源区间及配置快照。
6. 保存并编号由宿主在授权目录/项目分配 `<原名>_<起点>_<终点>_modified_<编号>.wav`，重复保存递增且不覆盖。桌面首次保存选择输出目录，已有编号参与最大尾号分配。保存编辑草稿仅保存原输入 hash、F0 与参数，不等于保存音频。输入变化不会套用旧 F0。标签关闭时保存草稿失败会保留标签和 dirty。导出失败时受管副本可能已保存，可查看历史后再次保存，不自动删除该副本。
7. 批量改变基频在拐点表填写起终点、频率列表与连接模式。中间行可添加/删除，起终点只能编辑不能删除。保存时按时间排序。顺序/逆序先排序频率，常量取首值，全连接按组合生成。顺序/逆序列表须等长。升降偏移表示相对原 F0 的 Hz 加法。默认使用直线插值，批量基频不使用单文件语速倍率。
8. 当前视野批次在文件管理中列出明确文件，确认后才删除。批量重命名替换共同前缀，非法路径与重名拒绝。正式宿主必须复核 owner 与目标 ID，网页不能操作本机任意目录。历史图是已保存音频重新提取的 F0，零起点对齐。保存对比图导出 PNG，包含版本文件名，曲线和文件配置均可追溯。
9. 批量变速变调页先选择文件，设置语速倍率、音高倍率、音高偏移。顺序为先变速、再乘倍率、最后加 Hz。逐文件任务有自己的成功/失败状态，损坏文件不掩盖为整批成功。停止剩余提交与取消已提交任务属于不同动作，后者由公共任务服务执行。

科学方法为 Praat/Parselmouth overlap-add（SRC-PRAAT）。保持原 Manipulation 0.01 s、75–600 Hz 与倍率差阈值 0.01。当前修正了旧版非零 Hz 偏移单位字符串错误，使用 Praat 接受的 Hertz。算法会改变时长和波形，不能将输出幅值视为校准声压。不同平台数值证据见报告，未核验平台不沿用 Windows 精确通过结论。

历史中的受管结果会持久保留至其有效期。本地导出副本与目录授权的管理关联限本次宿主会话，重启后管理旧历史不会扫描或删除外部目录文件。当前会话内导出副本被外部改动时停止管理并提示。下载不延长有效期；重命名、删除均限界面明确选择的结果 ID。

模块保护上限是输入 64 MB/800万帧/8声道，预计输出3200万帧、64控制点、256组合。超限明确拒绝，需拆分材料；不截断后伪称完成。服务器仍需平台实测的进程组预算和单槽准入。
