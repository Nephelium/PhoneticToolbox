# 变速变调


1. 打开音频目录或导入音频。支持 WAV、MP3、FLAC，由 Praat 解码。
2. 原波形和 F0 使用同一原始秒时间。波形放大、缩小与适合窗口控制当前视野。F0 图 Shift+拖动修改有声帧，Ctrl+拖动恢复；普通拖动平移，Ctrl+滚轮缩放，左右方向键平移。无声部分不手工补成有声。
3. 默认显示范围为 50–350 Hz，可应用有效上下界。显示轴控制图中 F0 的可见范围，提取沿用 Praat 默认设置。参考线独立添加/清除。所有图采用公共字体与主题，IPA 固定 Doulos SIL。
4. 导入基频序列每行一个值，或每行“时间 F0”两列，时间列忽略。程序沿当前视野内唯一连续有声段均匀重采样。存在多段间断 F0 时先缩放到一段。不会重置视野或更改视野外曲线。
5. 语速 1.0 为原速，0.8 减速、1.2 加速。合成当前视野与合成整段是独立操作。每次合成成功后自动进入历史 F0 对比，包括 Shift 手绘和导入基频序列得到的合成。图中显示实际输出 WAV 重新提取的 F0，横轴零起点对齐，编辑目标曲线用于合成控制。
6. 播放当前视野原音直接播放原始波形的可见范围，播放合成音直接播放当前版本完整输出。下面的播放选区使用最后鼠标选择的原音或合成音区间，与上方直接播放互不改写选区。试听此版本加载所选结果并立即播放完整音频。停止结束当前试听；语速变化后合成波形使用实际输出秒时间。改参数不会覆盖已有结果。
7. 批量改变基频与拐点默认展开。通过编辑拐点表填写起终点、频率列表与连接模式，中间行在表内添加/删除，起终点只能编辑不能删除。保存时按时间排序。顺序/逆序先排序频率，常量取首值，全连接按组合生成。顺序/逆序列表须等长。升降偏移表示相对原 F0 的 Hz 加法。默认直线插值，批量基频不使用单文件语速倍率。批量生成只提交生成任务，完成后可在右栏试听和保存。
8. 保存合成音导出当前版本；右栏本批次与历史文件中的批量保存位于删除本批次音频、批量重命名下方。确认勾选结果后只选择一次输出目录，逐项报告保存成功/失败。取消选目录保留全部生成结果。失败项保持勾选，可重试。保存不建立新的复制任务或重复历史记录。同名文件保留，新副本追加数字后缀，本次工作台会话中同一结果在同一目录的未变化副本可复用。网页单个结果下载 WAV，多个结果下载 UTF-8 文件名 ZIP，最多 256 个/64 MB，超限需减少勾选数量。

   生成结果先保留在应用的任务历史中。需要获得独立WAV文件时，点击保存合成音或批量保存，并在原生窗口选择输出目录。保存后右栏常驻显示最近保存的完整目录，展开查看保存文件名可核对实际文件名，包括同名冲突时的数字后缀。该提示记录本次最近成功保存，后续取消或失败时仍显示上一次成功保存，当前结果请结合本次状态核对。网页入口只能显示已发起下载，具体位置查看浏览器下载列表。

   本批次指同一源音频且生成区间与当前视野相符的结果，列表同时显示全部同源历史。删除和重命名只处理弹窗明确勾选的 ID，原始输入不在目标中。长文件名自动换行，选框保持16×16px。同名手绘版本重命名时保留 WAV 扩展名并分配不同后缀，非法路径和冲突会拒绝。保存对比图导出包含版本文件名的 PNG。保存编辑草稿仅保存原输入 hash、F0 和参数，音频另由保存合成音或批量保存导出。
9. 批量变速变调页先选择文件，设置语速倍率、音高倍率、音高偏移。顺序为先变速、再乘倍率、最后加 Hz。逐文件任务有自己的成功/失败状态，失败文件会单独列出原因。停止剩余提交与取消已提交任务属于不同动作，后者由公共任务服务执行。

数值框允许逐键输入小数，例如`0.`继续输入成为`0.3`，保留输入中的小数点和负号。点击应用、提交或保存时校验有效数字，空白和单独负号不能提交。时间显示仍采用全局秒5位小数规则，不改变任务的科学时间序列。历史F0图没有结果时显示公共空态，生成后显示实际输出曲线，图窗边界与同页其他图一致。

科学方法为 Praat/Parselmouth overlap-add（SRC-PRAAT）。保持原 Manipulation 0.01 s、75–600 Hz 与倍率差阈值 0.01。当前修正了旧版非零 Hz 偏移单位字符串错误，使用 Praat 接受的 Hertz。算法会改变时长和波形，声压比较需另行标定。

历史中的受管结果会持久保留至其有效期。本地导出副本与目录授权的管理关联限本次工作台会话，重启后管理旧历史不会扫描或删除外部目录文件。当前会话内导出副本被外部改动时停止管理或复用并提示。同一结果导出到多个目录时，各副本分别关联，明确删除/重命名会同时处理本会话内的这些关联副本。下载不延长有效期；重命名、删除均限界面明确选择的结果 ID。

模块保护上限是输入 64 MB/800万帧/8声道，预计输出3200万帧、64控制点、256组合。超限时请拆分材料后重试。
