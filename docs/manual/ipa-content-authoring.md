# 音标介绍内容维护

此工具供井井在源码项目中使用。普通 EXE 和网页构建只读取已编写内容，不提供维护入口或写入接口。

## 打开和保存

1. 在项目根目录双击[打开音标内容编辑器.cmd](../../打开音标内容编辑器.cmd)。它使用既有前端环境，在本机浏览器打开独立维护页面。
2. 搜索符号、名称或稳定 ID，选择一个音标。IPA、extIPA 和 VoQS 的 625 个入口都可选择。
3. 编辑中文名称、英文名称、含义、用法、区别及自写内容。这里的名称用于介绍页，表格与输入字符保持原目录定义。
4. 点击保存此音标。修改写入[源码内容文件](../../frontend/src/modules/ipa-plus/data/symbol-content.json)，重新打开维护工具可继续编辑。恢复该项原介绍后，还须点击保存才生效。
5. 关闭时点击页面右上角关闭维护工具，停止本轮本机服务。直接关闭浏览器标签不会停止服务。

未保存时切换条目或关闭页面会提醒。另一窗口已保存新版本时，当前编辑保留并提示冲突，避免覆盖。请重新打开后合并编辑。维护页面只显示纯文本，自写内容中的 HTML 标签按原文字显示。

开发界面读取源码内容。桌面源码工作台使用前端构建，因此保存后需重新构建并重启工作台；以后打包 EXE 或构建网页时会自动带入该内容。现有 EXE 不会随源码修改自动更新。维护工具本身不会构建、打包或发布。

## 音频和视频

把将来录制的素材放到 `frontend/public/m17-media/`，在维护页填写相对路径，例如 `m17-media/p.wav`、`m17-media/p.webm`。可只填音频、只填视频，或同时填写。两者同时填写时视频静音，声音由音频文件提供。素材随以后构建复制到静态资源。

允许的音频扩展名是 wav、mp3、ogg、m4a，视频是 mp4、webm。本轮实际验证为 WAV 与 WebM，其他格式和具体编码尚未逐项验收。路径支持中文、空格、字母、数字、下划线及连字符，使用 `/` 分隔，不能填写磁盘绝对路径、外部网址或 `..`。

普通界面顶部点击播放默认关闭。开启后，点击和 Enter 激活只播放演示，文本、选区与撤销历史保持。没有演示内容时显示提示。关闭该开关恢复点击输入。收起演示、再次点击、切换体系或离开音标模块时会停止当前播放。

## 实时动画接口

维护页可保存以下结构，留空表示未配置：

```json
{
  "renderer": "vocal-tract",
  "version": 1,
  "config": {}
}
```

`renderer` 是未来实现登记的接口名，`version` 是配置协议版本，`config` 保存构形、时间轨迹等轻量数据。只有已接入相应渲染器的动画才能播放，本轮未实现具体声道运动。配置无需保存预渲染视频，仍需渲染器和其必要模型资源。

代码接入使用[playback.ts](../../frontend/src/modules/ipa-plus/playback.ts)的 `registerSymbolAnimation`。渲染器接收条目、版本、配置、容器和 `AbortSignal`，可返回停止函数。收起或切换演示时，组件发送中止信号并调用停止函数，异步返回的旧渲染器也会清理。可同时配置动画与音频。现有声道科学引擎保持原实现，后续接入须单独明确运动和发声语义。

验证范围见[M17-R3 报告](../testing/2026-10-05-m17-r3-report.md)。
