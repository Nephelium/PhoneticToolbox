# 方法、参考文献与第三方致谢

PhoneticToolbox 集成语音学研究方法和开源工具，提供分析、编辑、可视化、合成及文件管理。各方法、代码、模型和素材的作者与来源可在软件中查看。

## 查看与复制引用

1. 在工具页面点击方法与引用，查看该工具使用的方法、作者和相关论文。
2. 点击复制引用，将书目信息用于研究报告或论文。
3. 点击来源链接，打开论文、项目主页或官方文档。
4. 在关于页查看全部学术来源、软件与代码来源，可按工具筛选或搜索作者和方法名称。

学术引用按 GB/T 7714—2015 整理，包含已核实的作者、出版信息和来源链接。图表的修订年份、论文的发表年份与软件版本分别列明。同一记录涉及多份资料时，各份资料分别引用，复制时保留换行。

引用文字可离线查看，打开外部来源链接需要网络。软件与代码来源同时列出已登记的版本和许可信息。

## 在研究中记录分析方法

研究报告应注明 PhoneticToolbox 版本、采样率、分析算法、窗长与帧移、参数范围、缺失值处理及预处理步骤。使用某项方法时，核对相应工具中的参数设置和方法说明。

基频、共振峰和声门事件的提取方法分别记录。合成控制参数与输出音频的实测参数也应分别说明。用于感知实验的合成刺激，先试听并检验目标特征和步长差异。
