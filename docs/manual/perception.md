# 感知实验：本机运行、恢复与导出

入口：统一工作台 → 标注与实验 → 感知实验。无需登录。文件、被试信息和结果不会自动上传，不占服务器 1 GB / 3 天额度。

## 建立项目

1. 选择 X、AX、ABX 或 AXB。X 可呈现音频、图片或 UTF-8 TXT；复杂范式按 A/X、A/B/X 分组选择音频。切换范式会询问是否重建序列与清除不兼容范围，素材与问卷保留。
2. 导入或拖入文件/目录。文件旁显示 SHA-256 前缀，同名不同内容可区分。试听可能产生声音。移除仅改变项目清单，不改原文件。
3. 序列默认按 X 数量与各组顺序配对。可改每试次关联、指导语、拖拽/上下移动、复制、移除、升降排序。已编辑的顺序不会因重新关联素材被静默重建。
4. 全局或指定范围洗牌。范围含首尾；重叠范围按列表顺序执行，范围外保持不变。随机种子为 32 位整数，配置与结果均保存算法版本和实际顺序。
5. 参数中设置 ISI、试次间隔、全局/分段按键、提示音、指导语、大字与文件名显示。0 ms 合法；负数、非数、越界范围不能开始。重叠按键段按列表首项优先，空段按键回退全局。支持字母、数字和空格，组合键、IME、长按重复不作为答案。
6. 配置文本、单选、多选问卷与必填规则。指导语支持安全的换行/加粗/斜体等静态 HTML，远程图片、脚本和任意样式不执行。

## XLSX 与项目文件

资源与恢复中可选择或拖入目录生成 XLSX 路径模板，配置路径前缀只是表格文本，浏览器不会按这个路径访问磁盘。File_A/File_B/File_X（或 A/B/X）、File_Path、Instruction/展示语是兼容列。新导出同时含 SHA256_A/B/X。缺失或同名歧义须在序列表中明确关联。

保存本机项目会写入此设备、此浏览器、此站点的 IndexedDB。刺激 Blob 按 hash 独立保存。导出项目 JSON 保存配置/问卷/序列/清单，不包含刺激。转移到另一设备时同时保留原素材，载入 JSON 后重新选择原文件，再预检。旧 JSON 未保存下来的复杂范式角色无法恢复。

预算：2000 素材、10000 试次、单文件 64 MiB、原始总量 512 MiB、解码缓存 128 MiB、TXT 1 MiB、图片 1600 万像素；目录最多 16 层/4000 扫描条目；XLSX 输入 16 MiB、解压总量 64 MiB、2000 ZIP 条目。超预算明确拒绝，不自动裁剪、重采样转换、归一化或改声道。浏览器可能在解码时重采样，结果记录原 WAV 采样率和实际播放率；未可靠提取的压缩音频原率记为不可用。

## 正式运行

点击预检与试音，完成音频解锁、格式/解码、素材完整性和字体检查。确认试音可听见，手动暂停其他录制、播放和重型任务。程序不调整系统音量/默认设备，不终止其他进程。

小项目全部预解码，大项目在试次之间分块准备，刺激未就绪不会开放计时。配置修改、另一次预览或恢复后必须重新检查。填写问卷后建立独立被试 UUID 和会话 UUID，再阅读指导语开始。

专注视图中，工作台快捷键与主题变化不会抢走实验输入。自动推进遵守试次间隔；手动推进需按键进入下一阶段；关闭自动播放后需明确播放当前试次。阶段继续事件不能同时成为答案。

音频 RT 定义：整段刺激序列结束、作答窗口开放后至按键处理的 performance.now 差值。图片/TXT 预载入/解码后，呈现经过两次 requestAnimationFrame 开放作答。任何这些字段都不能视为实际耳机发声/物理屏幕显现或物理键盘延迟测量。有效按键仅表示允许的反应键，不等同答案正确。

## 中断和恢复

失焦、隐藏标签、音频 context 中断、可观测 devicechange、退出全屏和长调度间隙会记录并暂停。浏览器不一定能够检测物理断线、蓝牙故障或所有休眠形式，无法检测的情况不能由软件保证。

每次呈现前保存 running 边界，每个完成/异常结果确认落盘后才推进。写入失败停在本地保存失败，可导出内存中的已有记录，随后重试保存。不要在失败后直接关闭。强制结束保留部分结果。

点击结束实验，先保存会话再返回初始素材设计页。当前设置和素材保留，最近会话结果仍可导出或查看。本地保存失败时留在实验页，重试成功后再结束。返回后下一位被试的信息清空，需重新预检、确认试音与实验环境。自然完成的会话仍记为 completed，提前结束记为 ended。

刷新后重新打开感知实验 → 资源与恢复 → 恢复/导出会话。仅恢复已提交边界，旧活动 attempt 标 interrupted，不跨页面 timeOrigin 延续 RT。已有结果可以直接导出，即使素材丢失。继续实验需复核刺激和试音，明确重新呈现会保留此前 attempt 并建立新 attempt。

同一会话只允许一个标签拥有。另一标签会提示已占用；先在原标签退出运行视图或关闭原标签。不会合并不同被试结果。

## 结果交付

结果导出集中在一处：选择结果格式，再点击导出结果。JSON 保留完整溯源，XLSX/CSV 提供分析表格。实验中导出会暂停当前活动试次并留下中断记录。自然完成及首次提前结束自动发出 XLSX 下载请求，恢复已结束会话不会再次自动下载。返回初始页后，最近会话结果栏沿用同一导出入口。项目 JSON 只保存设计配置，和结果文件分别使用。

JSON 包含配置/方法版本、被试/会话 ID、问卷、范式、种子与最终顺序、全部 A/B/X 角色/hash、attempt、状态、答案、RT 定义、多时钟调度诊断和异常。CSV/XLSX 保留旧前置列并增加溯源列，分析时筛选 status=completed；不要把 interrupted/invalid 当有效回答。

下载请求已发出不表示已经成功保存。请检查文件后点确认导出文件已保存。新增反应、中断或恢复活动会话后，旧文件不能确认当前结果，需重新导出。未确认导出或保存失败时，正常标签关闭会提示并保留页面。返回设计页保留最近结果的关闭保护。beforeunload 也提供保护，但无法阻止强制关闭、浏览器崩溃或存储被清理。请求持久化存储可能被浏览器拒绝，因此显式导出文件是必要步骤。

## 离线范围

A：页面、字体/分包和刺激预检完成后可断网完成与导出。C：当前 Qt 内置 ptbapp 资源实测可运行。B：浏览器关闭后的断网冷启动暂未提供，须在线重新载入页面；后续限定作用域缓存方案见 [ADR](../decisions/ADR-M15-client.md)。不承诺 file:// 双击通用运行。

操作与软件证据见 [验收报告](../testing/m15-report.md)。没有回环或外部测量设备，物理声音/键盘端到端时延未验。
