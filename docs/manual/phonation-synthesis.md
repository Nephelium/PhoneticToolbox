# M07 发声类型连续统使用说明

入口：运行 `scripts/Start-M07-Workbench.ps1`，在统一工作台选择合成与操控 → 发声类型合成。使用当前源码及前端构建，未生成EXE。网页在已配置账号、任务、文件服务且通过M07能力检查的Windows验证宿主使用；Linux服务与公网服务器尚未准入。

模块三栏工作区下方常驻来源与致谢栏，横跨三栏，显示作者署名、2026-09-10 邮件许可与完整论文引用。论文、原始仓库可直接打开，复制引用保留 DOI。改写说明明确 REAPER 是 PhoneticToolbox 新增的嘎裂声 F0 提取选项，介绍 MATLAB 到 Python 的许可改写及 v3 交互适配。若效果不理想，改写和适配可能仍有不足，不能据此判断原论文效果，说明中提供官方代码入口。来源登记与[许可摘要](../../third_party/evidence/SRC-ZAIWA/permission-summary.md)共用同一授权范围，私人邮件全文和联系方式不展示。

1. 桌面打开目录，分别选择源音频、目标音频。网页先在项目上传WAV。角色始终由文字标明。默认不全选音频，拖动任一波形后只保留该音频选区，空格播放，再按停止。源、目标及生成音频共用此互斥选择方式，播放按钮使用当前选区。
2. 选择Parselmouth或REAPER并设置F0范围/间隔，点击提取F0。当前每输入最多10秒、480000帧、8MB，目标11025Hz。帧长/帧移单位是采样点，F0间隔单位是毫秒。
3. 选择归一化有声时长或有声起点对齐，设置20–200控制点，在表内编辑。空白按0处理。点击应用编辑后才能生成；应用保留既有LPC、残差和脉冲。切换输入或分析参数会使旧分析失效。
4. 选择三种连续统之一、方向和2–50步。周期能量匹配、输出响度匹配源音频分别控制，峰值限制独立。当前生成一组，全部生成三类型×双方向共六组，使用当前对齐模式。
5. 中间固定四图：左上源音频、右上目标音频、左下 F0、右下合成音频。结果逐组完整发布，刚完成时默认显示整组波形。右栏任务历史最多约 84 px 高，可上下滚动，显示任务 ID、方向、变化类型、步数和创建时间。连续统控件与历史采用紧凑间距，栏内可用宽度达到 240 px 时生成按钮分成两列。点击哪个生成任务，下方就只显示该组。分析任务不显示合成组。点击整组试听或 step 按钮，同时切换波形并直接试听，共用选区、停止与空格播放。试听、导出和参数清单绑定该组快照，后改参数不改既有结果。

   F0 图例区分源、目标及各合成步骤，步骤仅标为 step01 等编号。点单步只叠加该步，点整组叠加该组所有步骤，每一步独立归一化或有声起点对齐。整组播放期间，根据实际 PCM 位置加粗当前步骤的曲线并突出对应图例，暂停、停止、播放结束或其他音频接管时清除高亮。合成曲线读取该任务快照并复用原合成插值，是生成控制 F0，未从输出 WAV 重新测量。仅发声类型变化时各步 F0 相同，曲线可重合。历史组使用其保存的配置，当前 F0 表编辑不改旧组。网页入口暂未接合成曲线读取。

   左栏 F0 图窗纵轴可设下限和上限，上限留空时自动计算，也可点击自动范围恢复。范围只调整显示，独立保存在本机，不使分析失效或修改合成参数。无效范围会提示并保留最近有效图窗。F0 窗右上角导出图片，PNG 使用导出点击时的图窗范围和所选曲线，完整包含所有图例，保存为 300 dpi 图片。显示范围之外的曲线会裁剪到图框内。
6. 桌面保存完整组到所选位置的 `M07-任务ID` 子目录，已有不同内容文件保留。网页下载一个ZIP。每组包括各步PCM16单声道WAV、combined_steps.wav、完整1ms轨迹CSV和m07.ptb.json。CSV无导入入口，参数JSON无任意对象加载入口。
7. 取消会停止当前任务和后续提交，完整成功组保留。刷新任务历史找回结果，失败任务可重试。批次ID、组序号/计划组数在清单记录，未提交组不能当成功。重新全部生成会建立新批次。
8. 保存参数草稿并关闭会保留未应用控制点。重开后重新选择匹配的原输入并分析，只有哈希、分析配置、点数和对齐匹配才恢复草稿控制点，仍需显式应用。草稿不保存长期文件授权。

高级分析参数完整保留窗函数、LPC阶数、窗长/移、预加重、负峰阈值、脉冲内外范围、静音裁剪/阈值/留白、有声区边界。模块帮助解释原算法和来源，IPA采用公共Doulos SIL。

科学含义：周期能量匹配实际匹配残差周期绝对峰值，输出响度匹配实际匹配全段平均绝对振幅。原音频F0和残差F0用途不同。内部正值间插值、原合成目标F0重采样规则均保留。该实验刺激生成器未证明发声类别知觉效度、连续统知觉等距或临床适用性。

网页额度使用公共政策：每账号1,000,000,000字节，新计算成功结果默认最多259,200秒，下载不续期。原输入、历史成果按既有政策状态处理，M07不自动迁移或删除旧数据。本机文件无账号TTL。
