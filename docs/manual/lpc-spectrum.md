# LPC 谱图

当前源码已完成[P17 M04-R2布局与PNG保存修复](../testing/p17-m04-r2-report.md)。[M04-R1 修复报告](../testing/m04-r1-report.md)记录空白 TextGrid 尾段、直接拖选和左栏操作修复。使用 `scripts/Start-M04-Workbench.ps1` 启动源码工作台；既有 EXE 不会自动获得本轮修改。尚未完成的网页验收见[M04-E专项报告](../testing/m04-e-report.md)。

## 文件、标注与选区

从左侧打开WAV目录，网页项目先上传WAV和可选TextGrid，再刷新文件。选择音频后显示原始波形，同名TextGrid自动关联，也可手动选择。默认使用第一层，使用层级下拉框或“下一层”切换；标注轨按实际时间对齐，点击区间即可选中。

直接用鼠标左键拖动波形框选片段，反向拖动同样支持，无需按 Shift。也可在右栏“谱图参数”的时间范围中输入起点、终点。勾选“显示语谱图（Praat）”后，语谱图紧贴波形下方；可直接在语谱图上拖动框选，反向拖动也可，波形、时间输入和下一次LPC计算共用这段范围。语谱图是供定位的Praat预览，不参与LPC计算；预览读取失败会单独提示，仍可在波形上选区和分析。点击“清除选区”后，分析范围改为当前可见的波形时间窗。Ctrl＋滚轮缩放，图下按钮适合窗口，滑动条平移时间。大窗口的常用内容可在一页查看，小窗口和较长的右栏记录可滚动。切到频谱后，时间范围仍然保留，不会将Hz坐标用于音频切片。

TextGrid 的空白区间可以超出音频末尾，界面会提示，不影响有效选区分析。点击这样的标注区间只选择其与 WAV 的交集；原 TextGrid 不会被修改。非空标签超出音频范围仍会拒绝分析，请关联正确的标注，或明确选择“不关联”后计算。

左栏放文件、TextGrid层和试听，中区放波形或LPC频谱，右栏“谱图参数”集中放阶数、频率/dB、时间范围、清除选区、开始/取消分析及预算提示，下方为结果保存和任务记录。两侧可调宽，右栏可折叠。波形和频谱随视口增大，但仅占视口高度的一部分；开启语谱图时仍保留标注轨空间。窄窗口自动堆叠。

音频文件最多64MB、800万帧、8声道，采样率8–96kHz。公共预览还限制所有声道合计3200万样本。单次LPC最多48,000样本，例如48kHz时1秒。超出时请缩小选区，或放大波形并清除选区以分析可见范围；程序不会自动截断。50阶至少需要52样本。

## 参数与计算

默认50阶、频率上限8000Hz、纵轴−5至35dB。勾选“动态纵轴”后，按该频率范围内谱值的最小/最大值各留5dB余量，手动dB控件暂不可编辑。频率上限可高于Nyquist，实际没有采样的频率区域保持空白。

“开始分析”固定当前文件、TextGrid、时间、参数和图表字体快照。任务在后台计算，支持取消、重试和重开后查看历史。若导出环境缺字体，页面保留选区并提示调整工作台图表字体；IPA固定Doulos SIL。

“波形”和“LPC频谱”切换不重新计算。频谱内Ctrl＋滚轮缩放、拖动或左右方向键平移，Home、双击或“适合频率范围”复位。编辑参数或选区后，旧图会提示尚未更新；重新分析才能得到新结果。无效或空参数不能提交，也不能保存为草稿。标签关闭前可以保存参数草稿，历史任务结果独立保留。

## 试听与保存

波形模式试听当前时间范围内所选原始声道；频谱模式试听所显示任务的单声道分析片段。LPC将多个声道取算术均值，保留原比例，未做峰值归一化。切换文件、显示模式、模块或关闭页面会停止试听。

结果完成后点击“保存 PNG 图片”，本机会打开图像保存窗口，可选择文件名和位置或取消。此入口保存任务原先生成的300 DPI PNG，不受当前频谱缩放、窗口尺寸或后续参数编辑影响。浏览器交给自身下载管理。界面的“已打开保存窗口”仅说明已交给保存窗口，不代表用户已经确认写入。

本机“选择目录保存完整结果”仍保存三份文件，已有不同内容的同名文件另名保存。网页分别下载PNG、选区WAV和JSON。PNG固定2400×1350像素、300DPI、白底黑线，名称包含原文件名、标签与选区时间；WAV为实际半开样本区间的FLOAT64单声道数据；JSON包含全部1024点谱值、参数、真实样本边界、来源与字体快照。历史结果始终按该任务原来的参数保存，后续编辑不会改写旧结果。

## 方法与引用

沿用V2的0.97预加重、Hamming窗、直接自相关、Toeplitz求解及单位分子频率响应。曲线是LPC谱包络，不是FFT实测幅度，dB未经声压校准，也未乘预测误差增益。标签拼接保留V2的末端区间排除规则，详见[源码映射](../modules/evidence/M04-source-map.md)。

方法参考Makhoul（1975）及依赖信息已进入统一“方法与引用”。直接迁移来源是本项目V2，更早代码出处仍为unknown；不将论文方法引用当作代码作者证据。
