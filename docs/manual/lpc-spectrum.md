# LPC 谱图

当前为V3开发态页面，原LPC核心、文件与任务导出范围见[阶段报告](../testing/m04-jobs-report.md)。EXE暂不打包，完整模块收口仍在进行。

## 文件、标注与选区

从左侧打开WAV目录，网页项目先上传WAV和可选TextGrid，再刷新文件。选择音频后显示原始波形，同名TextGrid自动关联，也可手动选择。默认使用第一层，使用层级下拉框或“下一层”切换；标注轨按实际时间对齐，点击区间即可选中。

按住Shift拖动波形框选片段，或输入起点、终点。点击“清除选区”后，分析范围改为当前可见的波形时间窗。Ctrl＋滚轮缩放，图下按钮适合窗口，滑动条平移时间。普通滚轮上下滚动工作台内容。切到频谱后，时间范围仍然保留，不会将Hz坐标用于音频切片。

音频文件最多64MB、800万帧、8声道，采样率8–96kHz。公共预览还限制所有声道合计3200万样本。单次LPC最多48,000样本，例如48kHz时1秒。超出时请缩小选区，或放大波形并清除选区以分析可见范围；程序不会自动截断。50阶至少需要52样本。

## 参数与计算

默认50阶、频率上限8000Hz、纵轴−5至35dB。勾选“动态纵轴”后，按该频率范围内谱值的最小/最大值各留5dB余量，手动dB控件暂不可编辑。频率上限可高于Nyquist，实际没有采样的频率区域保持空白。

“开始分析”固定当前文件、TextGrid、时间、参数和图表字体快照。任务在后台计算，支持取消、重试和重开后查看历史。若导出环境缺字体，页面保留选区并提示调整工作台图表字体；IPA固定Doulos SIL。

“波形”和“LPC频谱”切换不重新计算。频谱内Ctrl＋滚轮缩放、拖动或左右方向键平移，Home、双击或“适合频率范围”复位。编辑参数或选区后，旧图会提示尚未更新；重新分析才能得到新结果。无效或空参数不能提交，也不能保存为草稿。标签关闭前可以保存参数草稿，历史任务结果独立保留。

## 试听与保存

波形模式试听当前时间范围内所选原始声道；频谱模式试听所显示任务的单声道分析片段。LPC将多个声道取算术均值，保留原比例，未做峰值归一化。切换文件、显示模式、模块或关闭页面会停止试听。

本机“选择目录保存完整结果”保存三份文件，已有不同内容的同名文件另名保存。网页分别下载PNG、选区WAV和JSON。PNG固定2400×1350像素、300DPI、白底黑线，名称包含原文件名、标签与选区时间；WAV为实际半开样本区间的FLOAT64单声道数据；JSON包含全部1024点谱值、参数、真实样本边界、来源与字体快照。历史结果始终按该任务原来的参数保存，后续编辑不会改写旧结果。

## 方法与引用

沿用V2的0.97预加重、Hamming窗、直接自相关、Toeplitz求解及单位分子频率响应。曲线是LPC谱包络，不是FFT实测幅度，dB未经声压校准，也未乘预测误差增益。标签拼接保留V2的末端区间排除规则，详见[源码映射](../modules/evidence/M04-source-map.md)。

方法参考Makhoul（1975）及依赖信息已进入统一“方法与引用”。直接迁移来源是本项目V2，更早代码出处仍为unknown；不将论文方法引用当作代码作者证据。
