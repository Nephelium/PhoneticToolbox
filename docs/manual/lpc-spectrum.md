## 文件、标注与选区

从左侧打开WAV目录，网页项目先上传WAV和可选TextGrid，再刷新文件。选择音频后显示原始波形，同名TextGrid自动关联，也可手动选择。默认使用第一层，使用层级下拉框或“下一层”切换；标注轨按实际时间对齐，点击区间即可选中。

直接用鼠标左键拖动波形框选片段，反向拖动同样支持，无需按 Shift。也可在底部公共播放栏的“时间选区”中输入起点、终点，单位为秒，表达方式与参数估计一致。“全部”选择整段音频。清除选区按钮已移除。勾选“显示语谱图（Praat）”后，语谱图紧贴波形下方；可直接拖动框选，波形、时间输入和下一次 LPC 计算共用这段范围。修改选区不会重新计算未改变的可见时间窗。缩放、平移和切换音频会刷新预览，迟到的旧响应不进入新时间窗；读取失败会单独提示并提供重试。语谱图仅供定位，不参与 LPC 计算。Ctrl＋滚轮缩放，图下按钮适合窗口，滑动条平移时间。窄窗工作区可滚动，底部播放栏保持可见。切到频谱后仍保留音频时间选区，不会将 Hz 坐标用于切片。

TextGrid 的空白区间可以超出音频末尾，界面会提示，不影响有效选区分析。点击这样的标注区间只选择其与 WAV 的交集；原 TextGrid 不会被修改。非空标签超出音频范围仍会拒绝分析，请关联正确的标注，或明确选择“不关联”后计算。

左栏放文件、TextGrid 层、试听声道及谱图参数，中区放波形或 LPC 频谱，右栏放开始/取消分析、预算提示、结果保存和任务记录。底部统一放时间选区、全部、播放选区、停止、播放进度与音量。两侧可调宽，右栏可折叠。波形和频谱随视口增大；开启语谱图时保留标注轨空间，窄窗口自动堆叠。

音频文件最多64MB、800万帧、8声道，采样率8–96kHz。公共预览还限制所有声道合计3200万样本。单次 LPC 最多48,000样本，例如48kHz时1秒。超出时请拖选更短的片段或修改底部时间选区，程序不会自动截断。50阶至少需要52样本。

## 参数与计算

默认50阶、频率上限8000Hz、固定纵轴−5至35dB。频谱图下方按顺序排列“适合频率范围”“动态纵轴”“固定纵轴”。点击动态纵轴，立即按该任务完整频率范围内谱值的最小/最大值各留5dB余量，手动 dB 控件暂不可编辑。点击固定纵轴，立即采用左栏的 dB 下限和上限，保留此前手动值。两种模式切换和修改固定纵轴均无需重新分析，选中按钮显示高亮。频率上限可高于 Nyquist，没有采样的频率区域保持空白。

“开始分析”固定当前文件、TextGrid、时间、参数和图表字体快照。任务在后台计算，支持取消、重试和重开后查看历史。若导出环境缺字体，页面保留选区并提示调整工作台图表字体；IPA固定Doulos SIL。

“波形”和“LPC频谱”切换不重新计算。频谱内Ctrl＋滚轮缩放、拖动或左右方向键平移，Home、双击或“适合频率范围”复位。编辑阶数、频率上限、文件、标注层或选区后，旧图提示尚未更新，重新分析才会得到新谱值。纵轴模式及 dB 范围即时应用。无效或空参数不能提交，也不能保存为草稿。标签关闭前可以保存参数草稿，历史任务结果独立保留。

## 试听与保存

已加载原音频时，公共播放栏在波形与频谱两种模式下都试听当前音频选区内的原始声道，时间为原音频的绝对秒数；左栏可选择试听声道。未加载原音频而直接打开历史结果时，保留任务单声道分析片段试听，播放栏时间相对于该片段，不能用于提交新分析。LPC 分析及任务导出的 WAV 仍将多个声道取算术均值，保留原比例，未做峰值归一化。切换文件、显示模式、模块或关闭页面会停止试听。

结果完成后点击“保存 PNG 图片”，本机会打开图像保存窗口，可选择文件名和位置或取消。此入口从已加载的1024点谱值绘图，使用点击保存时选定的纵轴模式与范围，无需重新分析。图片仍覆盖任务的完整频率范围，不受界面水平缩放、窗口尺寸或深浅主题影响。字体沿用任务字体快照，IPA 使用 Doulos SIL。浏览器交给自身下载管理，网页单独的 PNG 下载入口同样使用当前纵轴。界面的“已打开保存窗口”仅说明已交给保存窗口，不代表已经确认写入。

PNG 固定2400×1350像素、300DPI、白底黑线，名称包含原文件名、标签与选区时间。本机“选择目录保存完整结果”保存任务生成时的三件套快照，其中 PNG 使用任务原来的纵轴，已有不同内容的同名文件另名保存。需要当前纵轴图片时使用独立的“保存 PNG 图片”。WAV 为实际半开样本区间的 FLOAT64 单声道数据，JSON 包含全部1024点谱值、原任务参数、真实样本边界、来源与字体快照；显示调整不会改写历史文件。

## 方法与引用

沿用V2的0.97预加重、Hamming窗、直接自相关、Toeplitz求解及单位分子频率响应。曲线是LPC谱包络，不是FFT实测幅度，dB未经声压校准，也未乘预测误差增益。标签拼接保留V2的末端区间排除规则，详见[源码映射](../modules/evidence/M04-source-map.md)。

方法参考Makhoul（1975）及依赖信息已进入统一“方法与引用”。直接迁移来源是本项目V2，更早代码出处仍为unknown；不将论文方法引用当作代码作者证据。
