# 工程文档 — 工作规则

继承[根规则](../AGENTS.md)，结构见[本目录架构](ARCHITECTURE.md)。这里只补充本目录约束。

- 每项信息有唯一维护位置，按 [导航](README.md)查找。规则写约束，架构写职责，计划写目标，报告写事实；不复制整段交付记录到多个入口。
- 不把历史 v2 文档、设计图、旧阶段状态当成当前实现证据。被替代方案标明历史用途，当前状态从台账和对应报告核对。
- 文档改动检查 UTF-8、相关本地链接和信息一致性；不为文字整理跑产品全套测试。说明书内容与作者素材遵循 manual 的保留边界。

- 每次实际修改或清理同步更新任务台账的对应条目，记录状态、证据和未完成项；已有条目原位维护，不追加重复日期流水。
