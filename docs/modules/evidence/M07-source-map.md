## 保留的科学语义

- 原音频 F0 用于确定 LPC 分析区间，残差的 F0 用于脉冲与连续统。结果 F0 与原音频音高估计不可混称。
- 有效正值间插值，内部空白区可能被填补，区间外为零；两种对齐的控制点取样及回插逐位保留。
- 合成仍将目标有效 F0 重采样到源分析区间；起点对齐不会改写该原合成规则。
- 尾部补帧、截取长度、含终点样本边界、源滤波器重合成、拼接次序均有原独立数组/WAV字节证据。
- 编辑 F0 只替换轨迹，不重新检测脉冲或重新计算 LPC。正反方向选择各自源模型。

## 明确行为差异

1. 新增显式反向当前生成。旧帮助描述有方向选择，但旧当前生成代码只走正向。
2. 选定两输入后显式提取 F0，代替旧说明书的自动启动，避免切换文件无意提交正式任务。
3. 未应用编辑阻止生成；参数变化明确失效。输入、任务及读取代际绑定，取消后迟到回调不应用。
4. CSV仍是完整1ms轨迹，不虚构旧版没有的 CSV 导入。安全分析 JSON 是内部正式产物，只从同账号/项目成功分析或应用任务读取；无任意对象反序列化入口。
5. 原REAPER包装器可能自动改用Python。本迁移只接受已登记原生二进制，失败明确提示，未做静默降级。纯正弦样例被该原生后端判无声，有多谐波样例的实际成功证据。
6. 非有限输入/控制点/结果直接拒绝，不能使用NaN转零掩盖错误。输入、步数与进程预算明确限制，未静默降低参数。
7. 各组独立目录/ZIP及不可变 metadata，取消已发布组保留。保存遇到已有不同内容文件生成保护名称，原文件不覆盖。
