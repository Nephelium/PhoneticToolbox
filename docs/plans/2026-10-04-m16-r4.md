# M16-R4 录音设备与显示修订

2026-10-04，井井按七张截图授权实施。状态：verified，限定 Windows 开发态与 WSL 纯核心，详见[报告](../testing/2026-10-04-m16-r4-report.md)。

- Windows 列表只保留 WASAPI 当前启用端点，避免 MME / DirectSound / WDM-KS 重复与断开入口。保留原生索引与身份校验，不按设备名合并不同实体。设备失效清空选项，录音时不刷新。
- 默认显示第一个采样声道，显示语谱图右侧增加显示所有声道。多通道按比例分配图高，不再出现波形内部纵向滚动条，所有通道的采集、编辑和导出语义保留。
- 语谱改用既有 Parselmouth/Praat，Gaussian 5 ms、50 dB 相对灰度、6 dB/oct 显示预加重与 0–5000 Hz。实时 128 / 录后 640 个有界中心时间窗，保持流式读取与时间选区，不改采样、降噪或增益算法。记录为 m16-praat-display/1，旧 Hann 纯核心实现保留。
- 正常提示与导出结果进入左侧栏。导入表格改为导入任务，保存清单模板改为保存任务模板并解释 JSON 往返。界面 take 改为录音条目，补工程分块与 WAV 导出说明，工程格式不迁移。

主要文件：RecordingPage.vue、RecordingWave.vue、recording/devices.py、录音实时/录后显示接线、新 Praat 显示核心、定向验证、手册与来源登记。保留同期外观/M03 及图标差异。

验证：前端 typecheck/test/build，M16 桌面与显示核心 pytest，新增设备过滤/真实 Praat 对照，独立 Chrome / 实际 Qt 浅深色与窄窗、WAV 和模板往返，WSL 纯核心。原设备只做枚举，不打开物理采集/播放。无 EXE、push、DDL、环境安装、删除用户文件或改写旧工程。
