# M12-R2 标注工作区与三图联动

状态：verified，限定 [R2 报告](../testing/m12-r2-report.md) 中 Windows 开发态与临时 EXE 实测范围。井井 2026-09-14 六张试用截图及明确修改要求授权本轮。

## 行为

- 文件列表只显示完整可悬停查看的音频名，以颜色及顶部图例区分关联 TextGrid，按钮不被纵向压缩。歧义关联在独立选择框处理。
- 读取当前文件所有层名，区间编辑行从实际有效层中选择，点层及非全域层显示类型并保留。缺失、空白、零层文件先展示音频，由用户输入名称并显式创建区间层，不再自动写入 words/phones。
- 字典表示标签到音素的映射，词表表示顺序标注条目。自动生成选项合并到资源工具栏。
- 总览、平移和音量在波形上方。移除底部时间输入和播放条，空格播放所选范围、暂停及续播，未选区时提示选择。
- 三图共享时间窗和选区，波形绘制当前编辑层边界。振幅及左轴按可见原始采样范围缩放，仅改变显示。
- 去掉嵌套 main 造成的多余滚动容器，保留页面正常内容访问及文件列表滚动。

## 文件与边界

AnnotationPage.vue、AnnotationTracks.vue、format.ts、editor.mjs 及新增 layers.ts；公共 WaveformViewport.vue 仅通过可选属性启用顶部总览和自动振幅，其他模块保留默认行为。增加纯函数、独立 Chrome 和隐藏 Qt 回归；如更新试用 EXE 使用独立 R2 路径，保留 R1。现有标注、v2、科研算法与数据库不修改。

## 验收

`npm --prefix frontend run typecheck`、`npm --prefix frontend test`、`npm --prefix frontend run build`；M12 原功能与 R1 顺序标注回归、R2 长文件名/层创建及切换/三图像素对齐与选区/空格播放实际节点/视窗振幅/浅深主题/小窗口；隐藏 Qt 实际本机入口与新建保存回读。结果与未测范围写入 docs/testing/m12-r2-report.md。
