# P04 统一工作台实施

2026-09-09，井井在 P03 后确认继续。状态：verified（公共界面和 Windows 定向范围；井井反馈当前界面无明显问题，致谢分组修订已落实）。

沿用已确认 U2/K2，使用 Vue 3 与原有依赖；系统中文字体优先，IPA 复用 P01 已核验的 Doulos SIL 7.000 原文件及其 OFL，不安装系统字体。本轮不新增下载依赖、图表或图标库。K2 原图直接引用，手写简单线条功能图标。首页三列工具分组、15 个明确入口、空的最近使用、底部帮助/设置/关于及主题选择。

文件：frontend/src/app、design、components、platform、state、generated；frontend/tests 与 scripts 生成清单；desktop/experiments/p04_host.py。公共状态每个标签独立保存文件、选区与参数草稿；主题/折叠/真实最近工具本地持久化，不保存私人音频。未保存草稿关闭需保存本机草稿/放弃/取消。页面共用文件预览、波形、选区和播放器，分析与任务 API 尚未接入时明确标识，无假曲线和进度。

采用统一 WebAudio 播放器、跨窗口 BroadcastChannel 停播协调。WAV 预览读取真实 PCM/FLOAT 样本，双声道保持分轨；EGG 音频角色可显式选择，试听只使用所选声道。浏览器和 Qt 宿主使用同一前端；Qt 演示加载同一静态构建，不引入第二 HTTP 服务。文件能力只暴露 File/字节，不透出本地路径。

验收：npm --prefix frontend run typecheck / test / build；真实浏览器测试空首页、15 模块、主题/标签保留草稿、关闭提示、损坏输入、真实波形/选区播放、参数应用/取消、引用、窄屏与焦点；1280×800、1440×900、1920×1080 及缩放截图；Qt 静态构建载入检查。不把浏览器缩放等同 Windows 原生 DPI 实测。P04 的最终视觉门由井井审阅，未获反馈前不标整个任务 verified。
