# P11-PERF 统一准入与限定负载计划

2026-09-27，限定合成输入的统一准入与 30 分钟服务器负载 verified，详见专项报告的未测范围。本轮授权为既有项目专用测试目录、公开合成数据、临时受限进程。不改数据库 schema、系统配置、生产服务、V2、M10/M14 模块、根文档和总台账。

## 已核实起点

P11 既有报告确认 M01/M03/M04 实际 Linux 受限合成任务及下载链路；独立 API/worker/预览仍能同时开组。P07-POLICY 现存运行库迁移未完成，M04-E 网页联合门仍阻断。M08 Linux capability 未验收，M09 未开放。不重新调查 BLAS 或安装环境。

## 文件归属与设计决策

- 新建 `backend/src/ptb_worker/resource_profiles.py`：server-small / desktop-local / trusted-worker 明确分离。服务端一槽、1 GiB 为待测上限，绝非峰值；桌面保留模块预算，远程配置明确拒绝。
- 新建 `backend/src/ptb_worker/native/admission.py`：同一专用 Unix 账号、固定 `/run/user/<uid>/ptb-resource-admission-v1` 的跨进程 flock、有界 FIFO 日志。队列最多 128、等待最多 300 秒。顺序按进入共享准入的请求，现有持久任务 owner 单运行规则继续负责账号并发。FIFO 不声称加权账号公平。
- 最小接入 `native/posix.py`：所有科学/预览/字体/后台科学导出必须在 spawn 前持有共享槽，清理进程组后释放。锁传给保留文件描述符的 launch_guard，再等待 systemd-run 客户端，API 崩溃也不能让仍运行的组提前失去槽；后续调用只恢复日志记录的自身 unit。状态损坏或清理失败关闭准入。
- `native/linux_runtime.py` 按 profile 限制进程预算，desktop-local 不套用云端 1 GiB。算法参数/输入字节不变。超预算以明确失败结束，不截断/降采样。未测的大输入仍不能靠短样例开放。
- `file_executor.py`、`files.py`：server-small 对尚未受限的通用 ZIP/解压任务在读取输入前明确拒绝 `server_export_unavailable`，desktop-local 保留原流式实现。既有代码无当前 diff，按最小能力门修改，不新增协议/数据库。
- `backend/tests/test_p11_admission.py`、`scripts/benchmark_modules.py`、`docs/testing/p11-perf-report.md` 为独占验证/交付文件。必要的公开错误映射和能力门按当前 diff 最小接线。

采用应用内文件准入，复用现有 systemd 受限执行器，无新守护进程、基础设施或业务数据库。仅 Python 内存 semaphore 无法跨进程；新增 PG 调度表需要 schema 授权且不能涵盖无数据库预览，因此本轮不采用。不同 Unix 用户、多机器和多个容器不属于该单机部署边界，需要未来统一 broker 或共享数据库协议。

## 验收顺序

1. Windows profile/原执行器回归；WSL 原生多进程 FIFO、队列满/超时、取消、父进程异常退出、继承锁、恢复与失败关闭。WSL 无 systemd 时不冒充 cgroup 验收。
2. 确认远程安全连接、目标目录、实际可用内存/磁盘、unit 归属。复用现有 Python、runtime、字体、合成 SQLite 模板，无 DDL。修改源码必须生成新 hash-bound runtime/receipt，不能沿用旧 capability 证书。
3. 逐级短测 M01/M03/M04/公共语谱/参数表/字体和科学导出，记录输入 hash、版本、线程、参数、字体及冷/至少五次热运行。纯计算和端到端分列，缺测保持 null。
4. 短测通过后至少 1800 秒混合负载：10 人轻交互、1 计算+9 交互、突发排队/取消/恢复。服务端 middleware 耗时、loopback 客户端耗时与公网 RTT 分开。采集原始样本和 p95/p99、失败/预期拒绝、cgroup memory.current/peak/events、API PSS、整机 MemAvailable/PSI、磁盘用量。
5. 停止条件：MemAvailable < 700 MiB 持续 10 秒、memory full PSI avg10 > 1 持续 10 秒、OOM 事件增加、磁盘空闲 < 10 GiB、连续服务异常、未知 unit 归属。只停止本轮负载/其自有组，保留失败证据。不得以 RSS 相加冒充整机峰值。

实际命令、样本数、失败率及未测范围在专项报告记录。目标 p95 500 ms 是验收目标，未测前不承诺。30 分钟服务端 HTTP 负载不代表真实浏览器/公网/PG/生产验收。根 README/台账/ADR 仅提交更新建议。
