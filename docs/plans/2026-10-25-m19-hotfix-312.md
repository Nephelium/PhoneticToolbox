# 语言地图 3.1.2 紧急修复实施计划

**目标：** 修复背景图片模式下的地图遮挡及固定海岸轮廓重复绘制，完成 Windows 最终 EXE 与网页版验收及授权发布。Mac 本轮不构建，保留 3.1.1 下载。

**架构：** 继续使用现有 GeoMap/OpenLayers、统一宿主及发布入口。地图容器提供单一底色，地图各 Canvas 透明合成。当前行政级别提供海岸与内部轮廓，固定国界、争议、港澳线及独立符号保留。只改变绘制选择，原始资料、调查值、坐标、工程格式不改。

**环境：** Vue 3、OpenLayers 10、Qt WebEngine、既有 Windows 紧凑发行构建与 HTTPS 前端。

## 1. 定向修复与回归

- `frontend/src/design/background.css`：排除地图叠加 Canvas 的不透明背景规则。`GeoMap.vue`：地图容器标记为完整绘图面，避免壁纸透过海面。
- `map-paint.ts`：固定省界与固定海岸轮廓不参与当前绘制；当前行政层与用户明确叠加的层级仍按选择绘制。Canvas 与 SVG/PNG 共用同一规则。
- 先补投影与实际 SFC 回归，确认失败后修复。更新现有真实数据图层验收的明确数量及线种预期，不降低断言。
- 新增真实 Qt/EXE 背景图片回归：同一几何视图，浅深主题、背景开关、连续滚轮/拖动、双 Canvas 合成、单/双/四图，检查截图中的底图与透明背景。

## 2. 扩大检查

- 现有完整 M19 工作流、交互及绘制/导出回归，使用 3.1.1 已冻结且逐成员核验的16资料，不使用当前 local-data 旧候选。
- 覆盖自动/手动省市县、额外边界、筛选恢复930点、选点与地名、表格、全屏/Esc、来源窗、保存重开、SVG/PNG、浅深主题及背景图片模式。
- 前端完整测试、类型/契约/UI数据检查；Windows 最终字节完成严格打包要求的科学、绘制、缓存、安装/卸载与两类换版验收。

- 冻结仅本次业务改动；排除同期官网设计、资料加工与说明书截图改动。版本使用3.1.2，科学运行时沿用已验原字节。
