# 变速变调多参数与批次保存实施计划

**目标：** 单文件和文件夹均可输入多个语速及多个音高值，倍率与 Hz 偏移二选一，按笛卡尔积生成版本；完成后可跨原音一次保存，并从任务切换结果。

**实现：** Windows、macOS、网页使用同一 Vue 页面与 M08Port。前端展开参数组合，仍提交原 m08/1 单参数任务，不改变协议、数据库及既有 Praat 算法。单文件将所选音高应用到编辑 F0 的有声帧；拐点生成保持原科学语义。输出命名增加语速/音高标签。批次结束打开结果保存选择，桌面选择一次目录，网页复用 WAV/ZIP 下载。

1. `frontend/src/modules/pitch-manipulation/state.ts` 添加多值解析、互斥音高、组合预算、F0 控制和参数标签，单测覆盖空/无效/重复/负值/超限。
2. `PitchManipulationPage.vue` 共用参数表单、批次状态和跨来源保存；任务逐项可选择，切换来源保留草稿确认，异步结果不抢占手动选择。
3. `backend/src/ptb_worker/m08_jobs.py` 仅补充输出名参数标签，保留旧单一默认合成名和 Praat 数学步骤，增加真实合成检查。
4. 独立 Chrome 经实际桌面适配/本机服务/Praat，实际 Qt 检查多组合、音高二选一、跨原音任务、保存取消与重试、原始文件保留及浅深/窄窗；临时材料放 scratch 并清理。
5. 更新模块 README、说明书正文/索引和阅读资源、CHANGELOG、当前状态及 M08 台账，完成类型/相关测试/契约/UI 数据/保留旧资源构建及文档检查。

未授权公开部署或重建发行成品。Mac 实机、Safari 和最终 EXE/Mac 包须单列验证边界。

状态：当前范围 verified。75 项 Python、27 项前端、独立 Chrome 11 组和实际 Qt 4 组通过，类型/契约/UI 数据/本地构建、说明书读取与严格生成、工程文档和架构检查通过。实际范围及未验项见[验收记录](../testing/m08-multi-variants.md)。
