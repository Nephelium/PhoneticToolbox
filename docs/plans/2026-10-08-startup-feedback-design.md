# P19 每次启动反馈与内容校验提速

2026-10-08，井井授权改善非首次启动，并要求所有启动都显示进度条。状态 verified，限定 Windows 本机源码、实际原生卡片、Qt 与最终免安装 EXE，见[验收](../testing/2026-10-08-startup-feedback-report.md)。

- 沿用原生启动卡片，普通冷启动、复用、更新和修复均从引导入口显示。可计算的准备和校验显示真实阶段进度，主界面初始化显示活动进度条。主窗口、字体及两次网页动画帧就绪后，通过本次启动专属 Windows 事件关闭卡片。命令行验证、工作进程及更新辅助进程沿用原分流。
- 每次仍检查全部文件内容及路径，不保存跨启动的散列豁免。四个读取线程重叠文件打开等待，同一操作内硬链接只读一次，失败后等待所有读者结束再修复。保留租约、清理、复制回退和内容身份规则。
- 修改公共启动模块及统一冻结入口，`--compact-onefile` 自动启用持久启动器，后续构建继承公共实现。当前旧 EXE 不会自行更新。新增每组件计时，诊断完整准备时间。
- 验证涵盖冷暖和损坏进度、同长度与同时间戳损坏、跨进程就绪隔离、迟到回调、失败读者收尾、实际原生卡片及实际 Qt 就绪。成品遵循当前严格打包规则，构建和验证分开记录。
