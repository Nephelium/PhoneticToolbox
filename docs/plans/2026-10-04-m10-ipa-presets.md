# M10-R6 音标构形库与紧凑布局

2026-10-04，井井明确授权本模块实现。实施状态 verified，限定 Windows 源码，见[验收报告](../testing/2026-10-04-m10-r6-report.md)。

- 保存构形直接打开紧凑 IPA 元辅音表，点击符号保存当前构形、声源全部参数与 F0，同一符号再次保存更新原条目。
- 自存构形改为按钮，打开同一图表，只有已保存符号可加载。旧的自由名称条目仍可从展开区加载，未包含声源的历史条目保持当前声源。
- 图表派生自 M17 已有目录，使用同一中文名称与固定 Doulos 字体，不新增外部图像或复制另一套音标数据。
- 移除顶栏与页脚，模型与来源放进现有参数标题栏，原布局选择移入模型与来源窗口。
- 器官、声音和关键帧三个面板分别内部滚动，保留模型与分析可视区域。

文件范围：M10 Vue 宿主、静态 app/platform/presets/index/v3 样式、定向回归与本模块说明。原生引擎和模型数据不变，现有本机 JSON 协议已支持声源字段，无数据库或文件格式迁移。

验收：前端类型、全量既有测试、构建；独立 Windows Qt 配置的音标点击保存、三种声源跨切换与重开恢复、同音标更新、旧名称条目、写入失败、取消及滚轮、浅深/两三列/短窄窗口截图。测试不使用现存用户构形库，不启用音频设备。本轮没有 EXE、push 或发行请求。
