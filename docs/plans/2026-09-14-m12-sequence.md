# M12-R1 · 从空白开始的拼音顺序标注

空白文件自动命名建层部分已被 [M12-R2](2026-09-14-m12-workspace-r2.md) 取代（Superseded）；顺序起终点、内部切分与整体微调继续保留。

状态：verified，限定 Windows 本机开发态和临时 EXE 的已列检查，见[R1 报告](../testing/m12-r1-report.md)。依据井井在临时 EXE 试用后的报错及逐音节操作要求实施。

1. 无同名 TextGrid 的 WAV 也进入列表。缺文件、零字节/纯空白文件和合法零层 TextGrid 在内存建立覆盖录音全时域的词/音素两层。非空损坏文件仍明确报错，不能冒充空白覆盖。读取失败结束加载提示。
2. 上传或粘贴空白分隔的拼音词表，显式开启自动生成音节和音素。普通双击空白时间先定起点、再定终点，消耗一个词表条目，两层先建立相同边界。Ctrl＋双击用前一已标音节的实际终点作为起点。禁止覆盖已有非空词/音素，失败不消耗词表。
3. 波形或标注层内双击已有音节，按点击时间切分音素。拼音使用声母/完整韵母（如 zhe4→zh/e4、shang4→sh/ang4）；无声母保留一段，其他标签沿词典。已切分的音素不因再次双击被重置。原来的音素自动填充保留在普通编辑模式。
4. 显示下一条词表与待定起点，允许选择下一条位置。Esc 取消待定起点。撤销同时恢复文档与词表进度；换词表后不得套用旧词表进度。文件切换和关闭延续现有保存保护。
5. 桌面首次保存可用建目标时绑定的同一 WAV 及其 hash 作为来源。空文件继续以原文件版本为来源；保存后使用新 TextGrid 版本。沿用目标版本、锁、原子替换、网页版本上传。无数据库 schema 变更。

文件：annotation/{format.ts,sequence.ts,editor.mjs,editor.d.mts,AnnotationPage.vue,AnnotationTracks.vue}、公共 WaveformViewport.vue 的显式可选事件、desktop annotation.py 与针对性测试。验收：前端 typecheck/test/build，M12 Python 文件测试，独立 Chrome 的空白与顺序标注操作，以及临时 EXE 回读。旧 EXE 保留。

来源：沿用已登记原 M12 实现；此次顺序交互和声母/韵母分段是用户要求的新规则，与 V2 原有均分音素行为分开记录。

井井随后追加：检查 E 盘 prepared 中的中文长录音和恢复 TextGrid，并增加左键框选后的整体拖动、左右键可配置步长，默认 1 ms。已实查录音为单声道 FLOAT32、44100 Hz、13784432 帧、312.57215419501136 秒，TextGrid 为同域四层。R1 匹配唯一同名前缀候选，歧义时提供关联选择；M12 改为沿公共 64 MB/3200 万采样值预算，不提高公共解码上限。平移以固定偏移量处理选中词和对应音素，不缩放内部时间，越界/重叠整次拒绝。默认波形手势及其他模块行为保持。
