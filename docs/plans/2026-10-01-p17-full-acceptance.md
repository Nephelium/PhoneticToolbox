# P17 全模块严格检验与修复计划

**Goal:** 对 M01–M09、M11–M15 共 14 模块建立逐控件、逐状态验收，修复统一风格、1920×1080 单页布局、实时反馈与图形显示问题，交付本机 EXE 人工验收。
**Architecture:** 公共外壳、布局令牌、波形、语谱图、播放和输入读取由主代理集中维护。模块代理只维护自己模块的状态、布局接入、科学适配与验收材料，公共缺陷回报主代理。
**Tech Stack:** 现有 Vue/TypeScript、Python、Qt WebEngine、锁定科学环境与 PyInstaller，不安装全局依赖。
**Status:** 本轮Windows修复及R1本机验收包已交付，完整边界/设备/平台矩阵仍in_progress，详见[总报告](../testing/2026-10-01-p17-report.md)。用户于 2026-10-01 明确授权 GitHub 当前代码快照、GPT-6 Astra/high 子代理、逐项检验修复及最终 EXE。此授权覆盖旧文档的模块停止点；不包含现存数据库迁移、生产部署或更改系统设置。

1. 每模块建立 `docs/testing/p17/Mxx-rules.md` 和 `Mxx-report.md`。表格每行含稳定 ID、手册章节、V2 路径/函数、V3 入口/控件、前置状态、操作、预期、证据、实际状态。必须读真实 V2 手册 `../PhoneticToolbox_v2/Phonetic_Export/index.html` 及源码，旧映射只作索引。
2. 枚举每个按钮、输入、下拉、复选框、键盘命令、拖动、滚轮、弹窗、页签、批次和导出。正常、空输入、边界、取消、失败后恢复、重复点击、切换文件/页签及迟到结果分别覆盖。不可用/硬件缺失标 blocked 并解释，不能标通过。文档与代码有冲突，记录现行用户要求、代码和手册差异，不擅改算法。
3. 音频输入只可来自 `C:\Users\13680\Desktop\project\音频数据`。只读原文件，建立私有清单记录相对路径、SHA-256、采样率、声道、长度。需要保存/编辑的输入复制到忽略的本轮验证目录。禁止生成正弦、噪声或其他人工音频替代真实录音。合成模块的正常产品输出可检验，但不能冒充自然录音或用于替代本轮输入来源。无音频的纯状态/几何单元测试可用标量/小数组，不声称真实音频验收。
4. 所有证据写 `output/validation/p17/` 下按模块独立目录。私有路径和内容不进 GitHub。只可操作任务明确拥有的进程。禁止写回 V2 或用户原始音频。新测试库仅遵循既有 `prepare_workspace` 新建独占目录方式，不迁移现存库。

## 4. 科学、输出和异常门

- 与 V2 对照默认参数、单位、选区半开区间、采样率、声道、时间数组、NaN/无声、算法版本、实际后端。已批准的 acoustic/2 等修正独立保留，不退回错误基线。
- 真正运行计算/导出并回读 WAV、CSV/XLSX/SQLite、PNG、TextGrid、DOCX/项目配置等适用产物，核对数量、字段、数值/时间及图形。按钮存在或任务成功状态不足以通过。
- 输入缺失/无效范围/中文文件名/长录音/错误取消/快速切换/晚返回/重复保存/关闭未保存保护逐项记录；受控故障注入明确标记。
- 设备和环境不具备时单列阻断。不得声称已验证未接摄像头、麦克风、Linux/Mac、远程服务或感知物理时序。既有环境可只读探测，禁止自行安装或改全局配置。
- 每个 defect 记录 owner=shared 或 Mxx、严重度、复现、修复、复验。相同公共问题只修一次，由所有受影响模块复验。
