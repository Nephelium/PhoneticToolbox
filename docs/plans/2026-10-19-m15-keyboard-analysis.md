# 感知实验键盘流程与成绩分析实施计划

**Goal:** 逐项编辑问卷选项，支持被试全程键盘操作、自定义作答提示和逐被试成绩分析，同步三端共用源码与说明书。

**Architecture:** 保持纯客户端运行器、IndexedDB 和现有项目/会话格式。新增可选字段，不升级数据库、不修改已有会话。设计、分析及导出共用标准答案与统计函数，Windows、macOS 和网页使用同一前端。

**Tech Stack:** Vue、TypeScript、Web Audio、IndexedDB、现有 SheetJS。

## 实施与验收

1. `model.ts` / `formats.ts`：每试次可选标准反应键，问卷空白/重复校验，逐项编辑保留标点。项目 JSON 与序列 XLSX 保留标准答案；旧文件缺省为未评分。
2. `runner.ts` / `PerceptionPage.vue`：空格/回车开始、阶段继续、进入试次和手动播放；明确屏幕提示。消费阶段键、忽略长按/组合键，保留原反应键、RT 起点及输入控件操作。问卷使用 Tab、方向键、空格与回车。
3. 参数增加作答页提示语和显示开关，旧项目默认不显示。网页设置白名单同步新增两个偏好字段，不保存研究数据到偏好。
4. `analysis.ts` / `AnalysisPanel.vue`：当前项目每会话一行，保留被试 UUID 与问卷身份，不按重名合并。每试次取最后完成作答，RT 只用有限且非负的完成值，列出缺失数、中断数。提供 N、均值、中位数、Q1/Q3/IQR、样本 SD、最小/最大；四分位数使用 R type 7 线性插值。准确率=正确/有标准答案的完成作答，同时显示分母、无答案数及未完成数。默认按会话快照评分，可显式选择当前设计补设答案，仅匹配相同试次 ID 和角色刺激摘要，且键须在原会话有效键内。当前设计重评分不回写会话。
5. 分析 CSV/XLSX 包含身份、计数、方法及答案来源。原结果表仅末尾追加标准答案和正确性列，JSON 保留完整设计快照。
6. 定向单元测试覆盖统计解析例、空值/零/单样本、重复/中断、不计分和旧格式、标准答案洗牌与表格往返。独立 Chrome/Edge 完成实际编辑、键盘、真实媒体、多人分析和导出回读，浅深/窄屏；实际 Windows Qt 键盘检查另验。macOS、实体声音/端到端时延、最终 EXE、生产部署单列未验。
7. 原位更新说明书章节、模块 README、ADR、状态与台账、CHANGELOG，严格校验并重建阅读资源；类型、契约、UI 数据、构建、架构及文档检查按实际执行记录。

统计方法来源：[R quantile 官方文档](https://stat.ethz.ch/R-manual/R-devel/library/stats/html/quantile.html)。统计不自动剔除离群值，不改变原始反应时。
