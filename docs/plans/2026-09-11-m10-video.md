# M10 录制增强 R4

状态：verified（限定 Windows 本机录制），完成后暂时冻结。井井在 R3 Windows 迁移验收后明确授权本轮功能和修正，R3 历史验证保留。实现、单文件运行及视频解码证据见 [R4 验收报告](../testing/m10-recording-features-report.md)。本任务不更新其他模块范围，其他任务按各自计划推进。

## 范围与实现

- frontend/public/vocal-tract：保存/导入版本化关键帧文件，命名本机构形库，移除内置 s 按钮，选择构形保留声源。基频窗口实色隔离，三维按需绘制，修正唇部表面及鼻咽连接显示。面积图明确口腔范围。
- desktop/src/ptb_desktop/vocal_tract：归一化动作及 F0 指纹缓存。原生文件选择、严格输入校验、原子保存、拥有窗口范围内的视频导出会话。无新 HTTP 服务，无任意路径前端接口。
- 视频默认 WebM（VP8/Opus），使用现有 Qt Chromium 的 WebCodecs 编码能力，先进行真实能力探测。逐帧给定时间戳，不录屏、不依赖墙钟、不在导出时播放扬声器。当前视角或六视图，两行二维/三维、三列器官/气腔/叠加。视频叠加姿势名、起止点、F0、播放游标。导出支持取消，完整文件才替换用户选择的目标。
- packages/phonetic_core：耳语增加显式 24 dB 试听补偿，保留原生波形。舌背/舌根目标依据 speaker 文件咽壁和舌体椭圆限位。前侧缘按实际高度反向映射拖动，默认 F0 改为 150 Hz，已保存的明确值不覆盖。声音栏目拆分发声 1 秒和持续发声。
- 本轮追加：单帧最短 0.05 秒，新加普通帧与静音帧默认 0.2 秒。静音帧保持构形、驱动归零并显式置零该段输出；前后短淡变避免边界点击声。灰色静音区间不绘制 F0，鼠标/键盘均拦截，文件、缓存与视频保留类型。50 ms 帧产生非整 30 fps 结尾时写出末视频帧实际时长。

## 验收

新增定向回归：文件往返及畸形文件不改已有草稿，构形库重启持久化，缓存命中和逐项失效，耳语/浊声/闭塞输出对照，视频容器解码/时长/音画时间戳/六格实际内容、取消与失败原子性。真实 Qt 连续截图验证静止三维和展开 F0 不闪烁。
