# M11-R2 资源选择与拼音自检修复

2026-10-05。状态：Windows 源码及最终本机 EXE 的 MFA 流程 verified，见[报告](../testing/2026-10-05-m11-r2-report.md)。井井已授权修复，并明确要求在上方声学模型入口直接导入。

**目标：** 让顶部的声学模型、发音词典成为唯一资源选择入口，实际任务使用检查成功后选中的组合，支持本地 `mandarin.zip` 与 `mandarin_pinyin_tab.dict`。

**实现：** 沿用现有原生文件授权、组件检查与内容摘要登记。顶部模型下拉增加本地导入入口，顶部词典在桌面通过原生授权导入。选择的新文件先显示待检查状态，阻止误用旧组合提交；检查成功后原子切换前端选择并清除自定义覆盖，失败保留旧登记与待检查选择，允许取消本次选择。组件管理仅保留环境及离线包入口。已有登记环境/模型/词典可作为缺省检查资源，宿主按登记 ID 解析，前端不传任意路径。网页模型仍由管理员登记。

**自检：** 保留现有 `/a/` 类公开合成探针，明确支持词条 `a`、`啊`、`a1`，不猜选任意首词，不改写发音或原始词典。完整 MFA 自身检查继续拒绝模型音素不兼容。收据记录实际探针词条。

**步骤与验收：**

1. 添加词条选择、宿主登记资源回退、词典授权读取的回归用例，确认旧代码失败。
2. 修复探针、宿主原生资源解析与顶部选择流程。新选/取消/失败/成功，以及任务摘要必须一致。
3. 执行类型、前端、M11 后端/桌面/契约/边界检查与构建。
4. 使用既有 Windows MFA 环境和指定模型词典完成真实自检，使用新生成公开音频通过实际 Qt 顶部入口登记/切换/提交/保存，核对任务模型/词典摘要。检查失败不发布新登记，旧组合和历史任务保留。
5. 文档记录真实证据和边界，交付可用本机入口。若构建本机 EXE，使用新文件名，保留旧包并另记成品验收。

不执行数据库迁移、push、公开发布、全局安装或清理。原始语料只读，测试文件置于被忽略的 `output/validation/m11-r2/`，不把合成探针通过写成自然语料准确率。
