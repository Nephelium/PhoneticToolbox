# macOS 下载统计接入

目标：官网实时累计和历史曲线接入 Mac ZIP，保留既有 Windows、浏览、网页版与 Star 的实际记录。

1. Nginx 沿用匿名请求日志，为 `/releases/macos-arm64/<版本>/*.zip` 增加 macos 类型。采集器使用既有整文件或首段 Range 规则，续传、失败、空响应及测试 UA 不计数。
2. 公开汇总增加 downloads.windows / macos，total 为两平台之和。历史前五列数值和时间不改，第六列增加 macosDownloads，第二列明确为 windowsDownloads。旧历史缺失 Mac 时保留 null。
3. 在服务器原地读取保留的普通日志，仅回填可确认的 GET 200 整文件发起。普通日志未记录 Range 的 206 不回填。回填只运行一次，不导出 IP、UA 或原始日志；新匿名日志中已有的请求不重复补入。
4. 下载图使用两条有独立颜色和图例的阶梯曲线，共享时间轴与纵轴，滑条同时显示两平台的真实采样。读取旧五列数据兼容，失败保留原值。
5. 定向测试采集/轮转/旧状态兼容/历史回填和去重，以及独立 Chrome 多宽度、时间选择、缺失/零值/错误/无 JS。生成器连续运行检查幂等。
6. 只向线上增量发布统计相关首页、CSS、JS，以及采集器和统计 map。保留回退；检查 nginx -t、刷新服务、HTTPS、两平台链接、其他页面资产/论文目录/反馈服务。更新 CHANGELOG、现有统计台账、项目状态和官网验收。
