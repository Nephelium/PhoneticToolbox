# M10 Windows 声道迁移与录制修订

状态：verified（限定 Windows 本机声道迁移与录制），已迁移并暂时冻结。验证见 [M10 报告](../testing/m10-report.md)。2026-09-11 井井明确要求先只迁移声道工作台，并以 Windows EXE 录视频。完成后标注限定范围已迁移，暂时冻结。M01 保留 in_progress，39 项最终审阅暂停，M02 不启动。无数据库迁移、生产部署或公开发布。

## 接入方案

沿用公共 Vue 工作台、侧栏、标签与主题。迁入现有声道页面作为同源模块文档，保留 Three.js/二维几何逻辑，通过平台接口与应用拥有的原生子进程通信。子进程使用有界 JSON 消息，不新增 HTTP 服务。科学核心迁至 phonetic_core.vocal_tract，设备与用户存储放在 ptb_desktop.vocal_tract。资源迁至 resources/vocal_tract 与 frontend/public/vocal-tract，新入口不导入历史包或相邻 v2。Windows 本机限定迁移不代表服务器、多用户或 Mac/Linux 原生验收。

## 文件与行为

- packages/phonetic_core/src/phonetic_core/vocal_tract：VTL ABI、轨迹、声源、监视算法原样迁入后单独修订。自动舌根默认保留，新增显式手动舌根模式。原生桥接新增模式开关，舌骨/舌根参数使用实际控制坐标。
- desktop/src/ptb_desktop/vocal_tract、host.py 与 frontend/src/platform：每个窗口独立 native worker、退出/取消/故障恢复。v3 独立配置目录，旧序列只读兼容，不回写 v2。
- frontend/public/vocal-tract、frontend/src/modules/vocal-tract：器官全列展示、紧凑无分页姿势列表、名称可编辑、可放大 F0 画布、姿势名称和起止时间实时标注、舌骨/舌根拖动、舌叶反馈与软腭残片修订。
- VTL 原有齿龈 lateral/fricative/closure 构形作为可解释的 /l/、/s/、/n/ 起点，明确是模型初值，非听辨验证。几何空白不能直接等同声学闭合，显示声学最窄面积/鼻腔与面积修正。
- 本轮追加：两列/三列仅计算模块内部三面板；卡片点击载入，显式编辑/保存/取消，编辑跨栏目保留；下颌联动唇开度；鼻腔截线按真实开口连接，避免开放路径自动封闭成额外长条；嘴唇和舌下共享平滑显示曲面，保留声学接触面与来源边界。
- 侧通路拟合检查发现原生侧缘下降在 TS=-0.15 后停止，而更负值主要改变声学修正。本轮检验在桥接层扩展负侧缘的实际下降，中央最多抬高 0.08 cm、最外侧最多降低 0.60 cm，面积仍从同一变形后模型求得。必须以真实截面出现中央接触、左右通路和闭塞对照验证后才采用，不凭音色或图形宣称完成。
- scripts 与 desktop/packaging：本机录制用单文件 EXE，独立于 v2 环境与发行物，不标正式 v3 全模块发行。
- docs/modules/evidence/M10-source-map.md、docs/manual/vocal-tract.md、docs/testing/m10-report.md、task-ledger、来源与资源清单：实现、验证与冻结范围一致。

## 验证门

先保存旧引擎元音/齿龈闭塞/边音/擦音/鼻化构形和音频基准。新增回归覆盖名称与旧序列、超过 12 帧存储、参数/轨迹一致性、负 TS3、鼻口闭塞与有通路输出区别、手动舌根实际生效、舌骨拖动与快速舌叶连续更新。运行 Python 定向测试、node 模块测试、npm typecheck/build、独立浏览器/Qt 真实操作。EXE 从非项目目录启动并核查原生资源、输出设备与退出子进程。报告保留未测项，不以按钮或截图代替真实发声验证。

## 最终退出

Windows 单文件 EXE 从非项目目录完成实际联合验证，状态与产物哈希见报告。最后采用 nasal/3 显示配准，前端下降并检查 ±5 mm 截面不越出头壳；原始鼻腔三角面保留，不影响声学鼻管。M10 本机迁移完成后冻结，M01 最终审阅与 M02 等待井井后续指令。
