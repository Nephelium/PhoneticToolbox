# GitHub 后续分发与自然例音边界

本轮仅授权服务器上传，GitHub 不发布。自然录音及其处理结果获准随软件分发，明确不得上传公开 GitHub。当前三个服务器软件包均含这些材料，不能原样作为 GitHub Release 附件。

当前更新器将同版本、同包装类型的大小或 SHA-256 差异视为跨源冲突，拒绝换版；下载失败时只在相同摘要和大小的镜像之间切换。这项保护已验证，但不能把未来经过媒体过滤的不同包直接声明为同一镜像。

后续 GitHub 发行前须明确渠道包身份和例音取得方式。若选择不同媒体内容的分发版，应显式记录分发版身份、各自可信摘要与允许的切换关系，并验证地区自动选择、回退、已有例音保留和缺少例音时的说明。若选择共同程序包与独立媒体补充包，则媒体补充包只放获准渠道，另行验证离线阅读和升级保留。不能删除一致性保护后直接混用两个包。

这属于下一次 GitHub 发行准备，当前状态为 planned，未实现或验证不同媒体分发版之间的自动更新。本轮已验收的换版使用相同最终内容的受控 ZIP/安装包，服务器公共版本清单仍待具体许可与对应源码验收后发布。
