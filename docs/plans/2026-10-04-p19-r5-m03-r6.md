# P19-R5 / M03-R6 配色、字体、时间精度与音频选区

日期：2026-10-04。状态：verified，限定 [报告](../testing/2026-10-04-p19-r5-m03-r6-report.md) 中 Windows 源码、Chrome 与实际 Qt 范围。井井明确要求直接调整配色、字体和持续自动 dB，随后追加全局时间精度、图表占位及多音频互斥选区，EXE 构建与成品检查单列。

## 范围与设计

- 波形默认跟随主题强调色，默认配色 Codex。现有显式配色、蓝色与自定义波形偏好保留。
- 配色列表每项有含背景的 Aa 色样。悬停和键盘浏览展示同一个小窗，包含背景、文字、波形、按钮和状态，按当前深浅模式渲染，预览不写设置。实际选择时才即时应用并保存。
- 中英文字体及独立图表字体使用可编辑输入加完整列表，不按已有输入值筛选。继续提供本机字体读取、手输、取消、预览和应用，固定 IPA 与内置代码字体沿用。
- 独立图表默认 SimSun / Times New Roman，历史空值在内存采用此默认，已有具体字体保留。
- 自动 dB 是默认开启的显示开关，状态使用 aria-pressed、边框/底色及文字提示。当前 PSD 建议用于 50 dB 色阶，拖动、缩放及谱窗修改后的最新结果持续更新。关闭后手动值保持。静音保持有限色阶并提示。
- 继续使用既有交互预览接口。新时间窗先取得实际 PSD 范围，再请求同窗口色阶图。两次请求间均核对来源、视口和开关，迟到响应不回填。只保存显示开关至本机偏好，不修改历史任务和计算契约。

## 修改与验证

修改限于前端选择器、默认偏好和 EGG 显示更新，相关使用说明及定向脚本。原科学核心、输入录音、V2、现存数据库和运行环境不变。

执行类型检查、前端测试和构建，Chrome 独立进程的列表/29配色深浅预览/键盘/缩放与窄窗，合成有强弱差异音频的真实 EGG 预览/拖动/缩放/手动开关/静音/迟到响应，以及实际 Qt 内的设置和 EGG 定向检查。WSL单列纯前端模块读取，不冒充 Linux GUI。本轮未获新的 push 授权。

## 追加范围

时间输入框秒最多 5 位小数，毫秒最多 2 位，只格式化程序带入的显示，不回写科研数值。用户输入/粘贴超长小数时四舍五入，非时间数值不受影响。所有原生时间输入及 M10 关键帧秒数覆盖，标注微调的输入下限为 0.01 ms。

模块内音频选区共用归属，加载多条音频时不默认全选，拖动或编辑某条选区会清除其他选区。空格只交给所选音频播放/停止，鼠标选择波形后转移焦点以避开旧按钮。M08 原音试听沿用实际鼠标选区，合成计算范围仍取当前视野。波形空态复用真实波形的尺寸和控件，F0 与其他图像空态按实际图框占位。

追加定向验证：272 前端测试、Chrome 原生输入与实际 M07/M08 组件/静音 WebAudio、Qt 真实鼠标与空格，记录空态/实际图表几何。EXE 不执行成品启动验收，平台和硬件范围继续按报告限定。
