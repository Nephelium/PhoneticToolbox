# 手机和平板采用桌面工作台布局

井井反馈窄屏下栏位重叠、图窗尺寸变化且难以操作，明确要求手机和平板使用电脑显示方式。采用浏览器端桌面画布，不增加服务器设备指纹记录或独立科学入口。

- 仅服务器研究工作台启用，登录页继续适配设备宽度；退出或离开工作台恢复原viewport。桌面与原生宿主保持现状。
- 结合移动UA、触摸能力、主/任意指针识别手机和平板，覆盖iPad的Mac桌面UA和触控板。分类是布局启发式，不作为鉴权、设备身份或安全判断。
- 工作台最小1440 CSS像素，屏幕本身更宽时保留其宽度。由浏览器初始适配，不设置禁止缩放或最大缩放；允许双指放大和平移。横屏更适合操作宽图窗。已有账号字体、配色、布局及页面缩放不重置。
- 沿用全部模块的原桌面组件和绘图语义，不复制页面或科学算法。保留模块自身的桌面尺寸适配，不能声称所有屏幕/缩放下图形像素尺寸固定。

验收：设备判定定向测试；实际服务器前端的Chrome/WebKit手机和平板模拟视窗验证桌面宽度、七模块入口、六种工作台主栏无交叠及退出恢复登录viewport。Windows WebKit不代替实体Safari，具体设备手势和听感留待井井复测。[当前验收](../testing/web-private-repair.md#2026-10-17--生理合成背景重复试听与移动端桌面布局)维护实际结果。
