# 汉字转国际音标 PNG 背景

点击保存为 PNG 后打开共用导出窗，先核对预览再导出。图片/颜色二选一，打开时读取当前工作台背景图及模糊、不透明度，没有图片则读取当前主题背景色。导出可替换本机 PNG/JPG/WebP，模糊0–40 px、不透明度0–100%，使用当前背景恢复默认。设置只作用于本次导出，不写全局外观、账号设置或草稿。

导出窗沿用原 Canvas 布局、Doulos 字体、逐位置读音与 PNG 下载/原生保存路径，预览与保存共用同一 Blob。背景等比居中铺满并保留模糊外扩，不拉伸；只模糊背景，之后绘制标题和文字。默认字色按背景明暗选择，用户明确指定的字色保持。无 Canvas filter 的引擎使用有界像素模糊回退，输出总像素不超过2400万，过长内容沿用分段导出提示。

三端共用同一前端源码。验证纯背景参数/裁切/像素回退，实际生产浏览器的纯色与图片像素、默认继承、替换/取消、模糊/透明度、错误恢复、清晰文字、预览与下载一致、浅深/窄窗，以及不显示到桌面的隔离 Qt 原生保存。同步说明书正文/目录/搜索、模块 README、状态/台账与修改记录。用户禁止桌面操控，测试只使用独立无界面浏览器与隐藏隔离 Qt，不操作正在使用的窗口。

实现与验证已完成，网页版按本对话的三端同步及直接上线授权发布，仅叠加本次M13导出源码与章节。具体范围及未验平台见[验收](../testing/m13-png-background.md)。
