# P07 第三批：任务文件、ZIP 与到期联合设计

2026-09-09，planned。本文件细化已授权 P07 的剩余实现；数据库实际扩展另见 [004 审阅](../testing/p07-job-assets-review.md)，当前尚未执行。第二批单文件数据通路保持独立，不因第三批未通过而夸大或否认已取得证据。

## 数据与事务边界

- 沿用同一 Storage 与 P06 JobStore，不增加新的网页宿主。004 关联表使每个输入/输出同时受账号和项目联合外键限制；任务参数快照冻结输入 ID/hash/截止，重试必须重新校验输入可读，不刷新旧资源寿命。
- P06 原来的 pipeline_check 仍返回有界元数据。新增受控存储探针、ZIP 归档和 ZIP 展开使用明确操作类型，不能给旧 pipeline_check 静默加文件副作用，也不能把探针显示为声学分析。
- 涉及文件的事务锁顺序固定为目录 OS 锁 → 存储 PG session lock 577707 → 调度 transaction lock 577606。原 JobStore 只取得调度锁的路径不能反向请求文件锁，避免取消、心跳和清理互锁。
- 输入登记和任务排队在同一个 PG 事务内完成，校验文件 ready、同账号同项目及剩余寿命。新文件任务进入 claim 前再次核对输入；预计运行超过输入时限直接拒绝。
- 每个输出用新 UUID 独立文件，登记 production generation，写入前检查当前 worker/代数/租约/状态/输入期限，短事务持久预留后写入。物理锁持续覆盖磁盘操作与结算；运行状态改变时，已预留的在途块仍必须计量，不能因取消清零。旧 worker 不得新建/追加后续块或提交 manifest。
- 文件达到完整尺寸与 hash 后保持暂存不可下载。结果全批提交与任务 succeeded/事件/manifest 在同一个事务内完成，最后重新检查代数、取消和输入期限。任何一个输出失败，不能提交其余文件为完整结果；失败批次的实有字节在确认物理删除前继续计费。
- 纯生成结果的截止从全批成功提交起算 7 天；ZIP、复制及展开得到的同内容资源截止不晚于依赖输入最早期限。temporary 永远不可作为最终结果下载；未成功批次的截止最多 24 小时且受任务/输入截止约束。

## ZIP 与原生工具

- ZIP 输入仍是私有资源；只通过受控读接口读取。严格限制输入数、条目数、文件名长度/深度和单块内存；拒绝绝对路径、驱动器、..、反斜杠绕过、链接、加密和不支持的压缩方法。
- 不调用 extractall，不让 ZIP 条目名成为磁盘路径。中央目录声明大小仅用于提前拒绝，实际每块展开数据都先做配额预留；压缩比、真实累计字节和条目数量均设上限。任何限制触发则整批失败并清理已生成测试资源，释放额度必须在物理删除后。
- ZIP 输出写入受控不可寻址 writer，计入头、数据描述符、中央目录与全部输出字节；不先写系统临时 ZIP 再搬入。输出超预算立即失败；保留原输入与完整错误状态。
- 未具备总目录强制字节上限的 MFA/FFmpeg 等原生输出路径继续拒绝，不使用定期扫描或逐文件大小检查冒充严格配额支持。

## 接口、前端与恢复

- 前端列出输入、结果、归档和未完成资源；批次结果只在 manifest 完成时展示下载。用户删除之前显示资源数量/字节及活跃任务影响，不要求先下载。
- 清理/主动删除输入先使其不可读并请求取消引用的活动任务；不等 worker 无限退出才禁读。每块输入读取仍重新校验截止，残余输出保持不可见并由同一账本清理。
- 重启先恢复任务与文件引用、核对生成代数和实有字节，再开放文件任务/下载。未知物理文件仍冻结写入，不自动删除未知对象。旧 worker 在恢复后不得复活失败批次。
- 本地桌面文件流程不导入网页账号、5 GB 与 7 天约束；本批新增联合能力仅在明确配置的服务器模式开放。
