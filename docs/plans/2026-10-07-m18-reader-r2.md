# M18-R2 阅读交互与说明书

状态：verified，限定 Windows 当前源码和实际 Qt，详见 [验收报告](../testing/2026-10-08-m18-r2-report.md)。井井授权折叠论文信息、全屏、PDF 页面直接复制、连续滚动、左右键翻页、批注/荧光笔、原译 PDF 导出、帮助跳转和多种引用格式，并同步手册。未重打 EXE 或公开发布。

保持既有 QtPdf 和服务器分发边界。页面图像叠加原生 PDF 文本几何用于选字，连续页面按视野加载并限制渲染缓存。批注按 PDF SHA 分开持久保存，采用版本检测避免多窗口覆盖；原文件保持不变。增加仅项目环境的 pypdf 纯 Python 依赖用于保留原文内容的标准 PDF 批注导出，保存位置经原生对话框选择。阅读器全屏通过 Qt WebEngine 全屏请求恢复既有窗口状态。

默认折叠详细标题、作者和导读，紧凑栏保留题名及许可入口。工具分阅读、标记和导出，文本选区可创建荧光笔或附带批注。引用提供 GB/T 7714—2015、ASA（美国社会学会）、MLA 9、APA 7 和 BibTeX，按 arXiv 预印本引用原文，明确版本和访问日期。

验证覆盖真实原译 PDF 的选区几何和复制、连续滚动/左右键/全屏恢复、批注保存重开及冲突失败、原文件摘要与含批注 PDF 回读、帮助定位和更新后的手册资源、浅深色布局。未授权本轮软件发布或全局依赖安装。
