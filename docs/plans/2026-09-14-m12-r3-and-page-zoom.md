# M12-R3 与 P04 页面缩放

状态：verified，限定 Windows 本机开发态与实际 R3 EXE；见[验收记录](../testing/m12-r3-report.md)。井井明确授权本轮 M12 修订及整个 v3 的页面缩放设置，并在实施中追加第 6、7 项，其他功能不改。

1. 手工边界移动/插点取消 20/15 ms 门槛，密集边界命中选择最近的实际边界，删除精确相邻边界；保留正时长、时间顺序和 TextGrid 微秒保存精度。词/音素只同步原先真正重合的边界，避免 40 ms 近邻被误拉动。声学强度估计的帧长/hop 不变。
2. 删除清空文本/删除边界按钮，保留 Backspace 清空与 Alt＋Backspace 合并，以及撤销。
3. 普通模式下已有 TextGrid 的空白音节区也可通过波形/音节层两次双击建立空白标注并选中输入文字。顺序模式仍按词表填入拼音，已有音节的自动音素/内部切分规则保留，新增不能覆盖已有非空内容。
4. 自动保存采用 `_自动保存.TextGrid`；新默认后缀同名，旧默认偏好升级，用户自定后缀保留。扫描优先新自动保存，兼容已有 `_webedit` 文件，不移动/重命名旧文件。
5. 整个 v3 通过公共页面设置提供缩小、放大、恢复 100% 按钮及本机记忆。阻止 Ctrl＋滚轮的浏览器整页默认缩放，不停止事件传播，保留各图表 Ctrl＋滚轮缩放。
6. 本轮追加：M12 波形支持 Shift＋滚轮平移，沿用语谱/TextGrid 的同一 offset 与步幅；波形绘图区与语谱 canvas 同为 175 px。细节视图按真实采样时间连接相邻采样点，较长视窗继续峰值包络，避免放大后独立极值竖线散开。公共组件通过显式属性启用，其他模块维持原显示与手势。验证 10/40/80 ms 的连续采样线、时间坐标及三图平移联动。
7. 第二次追加：语谱图支持左键拖动/反向拖动选区、捕获鼠标并同步波形/TextGrid/空格选区试听；添加音素首个切分点设置，默认双击位置，可选音素等分。适用于未切分的音节在音素层双击，以及顺序模式的首次内部切分；多于两个音素时，后续音素均分剩余范围。已切分时只在双击点加边界，保留现有边界。旧主动音素自动填充按钮仍表示整段词典均分。
