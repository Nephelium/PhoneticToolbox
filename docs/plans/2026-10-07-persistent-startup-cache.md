# P19 持久启动缓存与完整缓存清理

状态：verified，限定 Windows 本机成品功能和下述已执行边界。首次启动性能回退单列，不标性能合格。井井于 2026-10-07 明确授权首次展开后保留、后续校验复用、设置新增清除全部缓存、安装阶段准备、卸载清理，以及跨版本复用和首次等待提示。最终交付身份、实际验证和未验范围见[报告](../testing/2026-10-07-persistent-startup-cache-report.md)。

## 决定与边界

- 单个分发 EXE 使用轻量启动器和冻结的同一套应用。启动器自身的小型 Python 引导文件仍由 PyInstaller 临时展开，体积大的业务应用、Qt 和科学库保留在当前用户专属缓存中。
- 应用、科学运行文件、Qt 等主程序原生文件分别按内容清单 SHA 寻址。版本号不作为复用凭据。科学库未变时，界面或 Qt 更新不强迫重新展开科学库。
- 首次准备显示原生等待窗及真实阶段进度。准备成功才发布完成目录。损坏缓存重新准备，未完成目录不作为成功缓存。全部缓存访问使用进程锁，活动应用持有租约。
- 每次启动验证实际文件内容；跨目录同一硬链接只读取一次。硬链接不支持时复制并校验。不得用修改日期代替内容身份，不跟随符号链接或重解析点。
- 安装时调用同一启动器准备缓存，启动快捷方式继续指向安装目录 EXE。卸载调用专用清理入口；有活动实例时明确阻止清理并提示关闭。
- 设置中的清除全部缓存走安全退出。关闭被取消时不提交清理。清理仅限程序运行文件、可重建临时缓存与内部处理结果副本，保留设置、草稿、用户正式导出、录音与工程，以及归属不明/唯一原始资料。
- 保留两种真实更新流程；更新来源保持外部分发 EXE，科学子进程沿用内部冻结入口，不另写科研实现。

## 验收

内容变更/相同内容跨版本、冷暖启动、真实锁竞争/同时启动、损坏与中断恢复、空间/权限失败、硬链接复制回退、取消关闭与活动任务、工程外完整模块任务、TextGrid、两类更新、安装预热与卸载、全部缓存清理后重开，以及研究资料摘要保留。启动计时区分首次准备和已有缓存，不声称所有 Windows 电脑均已验证。

上述功能按报告中的源码测试与实际成品层次完成。首次三轮中位数 35.392 秒，旧方案 26.068 秒，回退记录保留；后续三轮复用中位数 6.521 秒。安装时准备及跨构建复用已验，不将首次等待成本隐去，也不修改原性能检查阈值。

先前 R2 安装更新的 WinError 5 发生在临时运行文件目录 rename。相同 rename 随后成功，阻塞者未确认。有限重试已加入并有定向测试；新架构仍保留失败诊断，不据旧成功覆盖该失败。
