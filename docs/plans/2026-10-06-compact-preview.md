# Preview 包体缩减与独立运行验收

井井已指定：免安装版必须双击直接启动，安装版与免安装 EXE 均不超过 500,000,000 字节。MFA 环境与模型不进入包，其他模块无需 Python 或开发环境。说明书正文、图片和音频冻结，后续由井井单独修改。

## 必要资源边界

1. 主进程保留 Qt Widgets/WebEngine、应用前后端、声道模型、字体、Praat/REAPER、音频设备及各模块实际使用的计算和导出依赖。
2. EGG/LPC 保留既有独立 Python、原 NumPy/SciPy 及完整 MKL 处理器分派 DLL。不为缩包替换科学版本。
3. 唇形提取保留 FaceMesh 图与检测/关键点模型、OpenCV、NumPy、PyAV、绘图与录制所需依赖。通过实际入口与处理结果确认不需要的 JAX、SciPy、其他模型和开发组件。
4. 不打包 MFA 环境、声学模型和词典。MFA 的界面及后续用户自行配置能力保留。
5. 排除开发头文件、链接库、调试符号、测试、缓存和重复安装归档，保留对应许可文本。两个科学环境的文件版本不混用。
6. 说明书只选择现有正文实际引用的资源进入构建快照。正文与媒体原始字节不修改，作者原工程与未引用素材完整保留。

## 单文件与更新

主程序采用真正的 PyInstaller 单文件，独立科学环境先做逐文件 SHA256 清单，再压缩为不参与 PE 依赖分析的 tar.xz 数据。启动时在本次启动器拥有的临时目录内校验并展开，直接显示应用，不出现解压目录或安装向导。退出后的临时目录由单文件启动器管理，用户设置、工程与正式导出仍使用原固定目录。

主宿主的 Qt 和第三方原生扩展同样保存原字节后采用更有效的压缩。在标准 Qt 启动钩子之前执行限定解包，CPython、解压所需标准库扩展及其 DLL 保持在最小启动层。构建和成品分别核验宿主 Qt 摘要，避免科学环境的 Qt 混入主界面。唇形实时预览的网页模型、WASM 与离线 FaceMesh 环境同时保留，两个入口各有所需。

安装版安装同一个单文件程序至当前用户应用目录。更新逻辑增加显式 onefile/1 布局，验证单 EXE 的大小和 SHA256，兼容既有 onedir/1 更新包。便携程序可单独移动，不依赖旁边的 Python 目录。

## 验收

- 新 stage 与原独立环境数值/导出结果对照，记录文件选择、剔除理由、版本和精确体积。
- 在工程目录之外启动成品，清空开发环境绑定与 Python 搜索路径，限制 PATH，仅依赖包内运行时和 Windows 系统文件。
- 成品实际运行 EGG、LPC、参数估计、重合成、变速变调、语谱转音频、唇形视频处理，检验导出摘要及结果可回读。
- 原生 Qt 验证其他模块入口、声道原生引擎、录音模拟设备处理与保存、音系表格导出、字体/文本导出和标注/感知实验关键行为。
- 核验真正无控制台双击启动、安装与便携更新交接、旧版与固定用户数据保留。
- 两个 EXE 分别实测不超过 500 MB；达不到则继续分析具体冗余，不能称已完成或保证随意删库后功能完整。

全部输出使用新目录，不覆盖或删除旧包与原环境。服务器上传使用新暂存目录并校验，GitHub 不上传。公开发行仍遵循具体组件的许可与对应源码要求。
