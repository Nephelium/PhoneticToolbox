# P19-R4 波形颜色设置

井井要求在设置中选择波形线颜色，允许跟随主题或自行指定。范围为 Windows 开发工作台的显示偏好，不改音频样本、科研计算、数据库和历史结果，不生成 EXE。

- 外观设置提供默认蓝色、跟随主题色、自定义颜色三项。默认保持现有深浅蓝色，主题模式取当前强调色，自定义通过色盘或 HEX 输入选择并在本机保存。
- 独立波形令牌覆盖公共音频波形、录音波形、EGG 音频微观/逆滤波图中的音频轨道、唇形偏移对齐音频图和声道监视音频画布。频谱、F0、CQ、EGG 和 IF 等曲线保留原有色义。
- 参数整幅图和 EGG 逆滤波图的前端导图采用显式选择的主题/自定义颜色，默认蓝色沿用既有印刷蓝色。后端已生成结果和历史 PNG 不重写。
- 验证类型/构建、偏好与颜色解析、Chrome 实际组件与主题/窄窗、前端 PNG 回读、实际 Qt 设置与 iframe 桥接。WSL 仅静态资源一致性，实体 DPI、硬件及 Linux GUI 不纳入。

结果见[限定验收报告](../testing/2026-10-04-p19-r4-waveform-color-report.md)。
