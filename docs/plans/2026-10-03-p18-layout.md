# P18 跨模块视觉统一

日期：2026-10-03。状态：`verified`，限定 Windows 开发态 Chrome 中本报告所列布局与交互检查；构建、真实 Qt 和音频预览由同轮集成验收补充。

井井已授权直接实施。布局由同一负责人统一修改，国际音标 Plus 的内容扩展独立进行。目标是统一侧栏宽度、外轮廓、工具栏和常用动作的位置，保留用户自定义宽度和每个科研模块的交互语义。

## 范围与规范

覆盖 M01–M09、M11–M16，排除 M10 和 M17 的整体布局。沿用 U2 主题和现有字体。默认左右侧栏各 300 CSS px，控件沿用当前 30px 高度令牌，模块/卡片内边距 10px、模块间隔 8px、控制组间隔 6px。外框等高，内部内容不强行拉伸。

工具栏资源操作靠左，保存草稿/帮助/引用靠右。参数优先左栏，分析/生成/任务优先右栏。两栏模块的单一操作栏移左。逐图导出、录音采集、标注保存等根据当前操作对象保留位置例外，逐页表见 [报告](../testing/2026-10-03-p18-layout-report.md)。

## 实施顺序与结果

1. `verified`：审阅实际页面模板、共享组件、令牌和宽度持久化。发现文档中历史 34px 与当前代码 30px 不同，本轮保留代码当前令牌并更新规范。
2. `verified`：共享外观显式 opt-in，M01–M09/M11–M16 接入，M10/M17 不接入。ModuleWorkbench 为真实存在的插槽注册拖宽，左右外框统一边界和滚动。
3. `verified`：逐模块移动同类操作。M01 全列表分析、M09 重建、M11 对齐移至右侧；M04 参数移左、执行和结果在右；M05/M12 补齐工具栏；M03 右操作栏整体移左；M13 上下排布时操作栏靠左。
4. `verified`：保留历史宽度。M03 原页面误用 M01 布局键，本轮仅以旧值作为独立 M03 键的首读回退。旧记录同时含 left/right 时读取实际旧右宽，拖宽后 M01 旧记录不变。M12 保留旧最小宽度 180/210px，已有窄栏偏好不被新默认值覆盖。
5. `verified`：修复本轮缩放矩阵暴露的 ScientificPlot ResizeObserver 同步反馈循环。仅把尺寸测量回写合并到下一动画帧，卸载取消等待帧，图形公式和事件不变。单独检查尺寸收敛、固定字体、0.75 秒定位、缩放和平移事件。
6. `verified`：Windows Chrome 15 页默认栏宽/浅深主题、70/100/150% 和窄窗、旧宽度迁移及 5 组图表几何回归。最终构建和 Qt/真实音频由主代理统一运行，避免两个任务抢写构建目录。

## 不变边界

不修改算法、科研参数默认值、音频样本、任务生命周期、文件保存确认、图表手势、原生采集协议或全局主题字体。用户音频只读，不把私有音频提交到仓库。未打包 EXE、未 push、未安装依赖、未执行数据库 DDL 或改写已有记录。

布局源码负责人独占共享布局和上述模块页面；M17 数据、渲染与内容属于另一个实现任务。根 README/AGENTS、整体集成脚本及最终构建归主代理。
