# M07-R3 图窗、播放联动与紧凑右栏

状态：**verified，限定 Windows 源码工作台**。井井于 2026-10-05 授权本轮界面修改。交付与验证见[报告](../testing/2026-10-05-m07-r3-report.md)。

- 来源底栏沿用三栏下方位置，按指定句式修改日期与许可说明。改写说明明确 REAPER 是 PhoneticToolbox 新增的嘎裂声 F0 提取选项，并谦逊说明改写不足可能影响合成效果，提供官方仓库入口。
- F0 图窗统一框线、背景与空态，步骤图例仅保留 step 编号。左栏添加显示纵轴上下限与自动范围，设置独立保存，不参与科学任务快照、失效判断或未应用编辑。
- 整组按已生成 PCM 的实际帧数与步骤数定位当前步骤，仅在本组播放期间高亮对应 F0 曲线。单步、暂停、停止、切换任务、其他音频接管和选区跨段均跟随公共播放状态。
- F0 图窗导出 PNG，快照使用当前纵轴范围与当前所选曲线，完整导出图例。沿用公共字体与 300 dpi 编码，不改变科学序列。
- 右栏缩短参数与历史间距，宽栏两列生成按钮，保留局部滚动与窄窗可达性，取消音频已载入提示。

验证：前端类型、测试、构建和来源生成一致性；实际桌面宿主 Chrome 的九步播放、边界跳转、单步/整组、纵轴与导图、历史选择与多布局；实际 Qt 的原生点击、导出与浅深布局。保留输入与科学文件哈希。实体听辨、物理 DPI、Linux GUI、旧 EXE 不在本轮验收范围。无删除、push、发布、DDL 或安装。
