# M05-R1 唇形采集、回放和互通修复

2026-10-02，verified（限定 Windows 开发态及[修复报告](../testing/2026-10-02-m05-r1-report.md)列明的证据，完整模块仍 in_progress）。井井本轮明确授权截图所列布局、连续录制、离线回放、MP4 保存、V2/下游数据兼容及模块审查修复。使用用户指定视频只读复现，私有路径及证据仅放忽略的 output/validation。无 EXE、push、现存库 DDL、全局依赖变化。

1. 将采集状态与保存动作放入左栏。中央画面按实际宽高比排版，数值均匀分布，紧接 area、outer_width、open、circularity 四条曲线。
2. 停止后的推理取消不报失败，状态与异步请求按会话归属。保存完成可连续开始，未保存时提供保存后继续，取消保存保留原会话。
3. 离线回放用逐帧媒体回调与完整记录的有界分段读取。曲线预览抽点与动画完整帧分离。验证拖动、暂停、末尾重播、结果切换与历史恢复。
4. 桌面录制保存到独立目录，输出 H.264/AAC MP4、PCM WAV、采集与候选记录，保留实际 PTS 和方法身份。候选记录不冒充 legacy 正式计算。没有 MP4 编码能力的浏览器给出明确能力说明。
5. 核对原 V2 录制结构与现有受控 PKL 读取，验证 M01、M02、M12 共用唇形时间轴。修复保存 offset 与自动关联文件不一致，确保音频及参数配套。
6. 定向单元测试、原 V2 数值基线、真实用户视频完整分析/保存/回读、Chrome/实际 Qt 布局与交互，WSL 能力单列。真实摄像头/麦克风新录制与物理同步不以模拟测试代替。

已定位：`timeupdate` 低频驱动、最多约 241 帧展示抽点参与动画、停止关闭 Worker 后的迟到异常、双重保存 dirty 门禁、offset 只存入不被自动关联的文件、固定视口高度造成视频下方空白。
