# M06-R2 AV 修正与保形发声预设

2026-10-02，verified（限定 [验收报告](../testing/2026-10-02-m06-r2-report.md) 的 Windows 开发态与 WSL 纯核心）。井井已审阅 R1 的 AV 修订方案并明确授权直接修复现有错误，以及 F0 保形平移，不提供旧错误算法切换。

1. 计算配置升级为 m06/2，任务传输仍为 m06/1。AV/AH 为独立 0–80 dB 声源控制，0 关闭对应源。修复噪声累加器，取消由 HNR 推导 AH 及逐段自动增益/峰值归一化。采用明确、可复现的数字参考标尺，不声称与 Klatt 1980 全实现逐位一致或对应物理 SPL。保留 tdklatt 来源标记，科学行为变化记入 ADR。
2. 内部 20 kHz 避免最高 6 kHz 共振峰混叠。固定参考周期声源、理论噪声 RMS 标定增益，最终只在超出 PCM 安全幅度时整体衰减，记录该衰减。HNR/H1H2/Slope 保留为项目扩展处理，与原生控制区分。提取 AV 用相对能量初始化并明确为估计，AH 独立初始化。
3. 五类预设移除 F0 常数。假声按基础曲线平均值整体上移到至少 300 Hz，嘎裂整体下移到约 70 Hz，受最低 20 Hz 限制，不能逐点截平。记录平移量和类型，重复应用不累计；常态/耳语/气声撤销偏移。平移后编辑保留，切回时同样减去偏移。图轴自动包含新曲线，草稿和参数文件保存平移状态。
4. 旧版 AV200 不可无损换算。旧配置导入明确拒绝并保留文件及当前编辑，提示使用新版参数；不静默截断或把旧音频当成新结果。原 V2 源码与历史基准证据保留，旧逐位门由本次批准的科学修正验收替代，记录差异，不放宽旧断言。
5. 验证源开关、增益步长、有限输出、预设/元音/F0/时长矩阵，以及曲线平移、重复应用、编辑后回切、草稿/CSV往返和真实任务/浏览器/Qt。Windows 与 WSL 分别记录。无 EXE、数据库迁移、push 或环境安装。
