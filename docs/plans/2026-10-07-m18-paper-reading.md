# M18-R1 语音学论文精读

状态：verified，限定 Windows 当前源码、实际 Qt 阅读与服务器论文内容分发。井井已授权实现、论文上传及清理服务器旧部署，确认以首次启动软件日期作为默认订阅起点，指定模块名称并要求显示论文许可。详见 [验收报告](../testing/2026-10-07-m18-paper-reading-report.md)。本轮未重打 EXE，未验跨平台、另一实体电脑或长期运行。

## 实现范围

- 在现有公共工作台登记 M18，左侧按栏目发布日期显示论文及数量，右侧提供导读、原文和译文、翻页和缩放。沿用主题、字体和公共按钮。
- 桌面启动时在持久用户目录首次记录日期。打开模块检查服务器目录并下载起点当日及之后的内容。升级不重置起点，历史内容由用户按日期主动获取，下载前显示篇数及大小。
- 通过独立原生 papers 能力获取固定 HTTPS 站点目录及 PDF。前端无任意文件路径和网络权限。复用现有 Qt PDF，逐页渲染与文本查看；限制下载大小、路径、校验和、页面尺寸，失败保持可重试。
- 原文和中文译文均在服务器分发，不加入应用资源、EXE 或运行时快照。目录保存作者、固定版本、原文链接、许可链接和译文说明。首篇为 arXiv:2610.00735v1，CC BY 4.0。
- 保留 www.phonetictoolbox.com 静态首页及 HTTPS/系统服务，逐项清理确认归属的旧部署与发行暂存。发布内容目录独立维护。
