# M16-R3 录音工作区打磨

状态：verified，限定 [验收报告](../testing/2026-10-04-m16-r3-report.md) 中的 Windows 开发态与 WSL 核心范围。2026-10-04，按井井五张截图与明确修改要求实施。

## 范围

- 主操作进入提示卡右侧，排列为录音、停止、播放、下一条、跳过。删除顶部任务清单按钮，侧栏常驻。
- 任务提供明确删除入口，立即持久化并切到相邻任务；失败保留草稿与原选择。已有 take、任务快照和原始块保留。
- 导入前提供中文格式说明、可下载 CSV 示例，导入映射使用中文字段名。
- 剪辑操作放在清空选区后，处理声道使用紧凑复选框；双声道明确左/右声道，EGG/其他角色独立标识。
- 后台进度仅用细线表示，取消入口保留为带无障碍名称的图标。
- 录后语谱覆盖完整可见时间窗，0–5000 Hz。使用有界、均匀分布的 Hann 1024 帧窗口显示，时间单元边界与波形共用起终点；长窗为时间抽样预览，放大查看细节。原始音频、降噪算法与导出不变。
