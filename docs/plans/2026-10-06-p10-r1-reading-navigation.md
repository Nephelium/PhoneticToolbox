# P10-R1 说明书阅读目录

2026-10-06。状态：verified，限定 Windows 源码、当前前端构建、独立 Chrome 与实际隐藏 Qt 的本轮阅读交互。井井授权修复目录高亮并按点击与正文阅读位置自动收展三级目录。

- 默认保留全书一级、二级标题。当前二级标题有三级标题时，仅展开这一组，切换二级标题或章节后收起旧组。向上阅读同样重新展开当前组。
- 当前章节、二级标题及正在阅读的三级标题保持高亮。四级及更深标题、搜索命中的正文节点沿用所属二级与三级标题。
- 点击跳转立即生效，跳转产生的滚动事件不覆盖点击目标。用户继续滚动后按正文顶部阅读线更新，目录仅在当前项离开可见范围时滚动到它。
- 恢复阅读位置、章节加载失败、快速跨章导航、空章节和窄窗沿用既有边界。

代码范围：`frontend/src/manual/ManualReader.vue`、`navigation.ts`、`manual.css` 与 `frontend/tests/manual-reader*.test.ts`。说明书工程 JSON、已冻结正文、宿主及科研模块不改。

验证：目录状态回归，前端类型/全量测试/构建/生成一致；独立 Chrome 的真实目录点击、正文滚动、浅深布局；实际隐藏 Qt 的原生按键、滚动及章节切换。新测试输出保留在独立目录，不清理旧包。EXE 重打和上传不属于本轮。
