# M01-E 界面修订与功能覆盖

状态：verified（限定 Windows UI 修订，完整 M01 仍待 F/G；见[本轮报告](../testing/m01-layout-report.md)）。井井 2026-09-10 明确要求修订布局、独立滚动、时间轴、鼠标缩放和长音频进度；允许不同于 v2 的设计，但不能遗漏功能。

## 设计与边界

采用紧凑工具栏与三列工作区。宽屏每列独立滚动；三个内容列均溢出时改为工作区内共同滚动。侧栏、标签栏、播放条固定。窄屏改为自然纵向布局，避免三条狭小滚动区。比整页滚动更容易保留上下文；相比固定高度裁切，不隐藏功能。目录与输出控件同一工具栏按实际宽度换行。

公共 WaveformViewport 的时间刻度紧贴每条波形；Ctrl+滚轮以指针为锚点缩放，普通滚轮滚动所在列；缩放后可拖动时间窗滑块，双击回到全长。公共 AudioTransport 增加当前选区内的连续播放进度拖动，暂停时定位，播放时从新位置继续；显示播放游标。读取期间使用不伪造百分比的不定进度指示。

仅 M01 使用本轮三列容器及紧凑头部。全局主题令牌、波形与播放组件影响所有使用它们的页面，不把 M01 布局复制到其他模块。
