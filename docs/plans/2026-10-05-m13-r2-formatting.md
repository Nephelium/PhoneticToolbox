# M13-R2 汉字转国际音标显示与启动行为

状态：verified，限定 Windows 源码、Chrome 与实际隐藏 Qt 宿主。井井于 2026-10-05 授权本模块修改与相关缺陷修复。证据与限制见[报告](../testing/2026-10-05-m13-r2-report.md)。

- 删除输入框下方的转换设置按钮，设置栏始终可见，不读取旧折叠偏好。
- 每次重新打开时文本为空、转换标准为 Standard Chinese (Beijing)。保存的旧草稿保留，并通过顶部恢复按钮显式加载。切换工作台标签时保留当前编辑。
- 汉字样式下方增加音标颜色、汉字颜色与汉字字体下拉菜单。颜色默认跟随主题，汉字字体默认跟随全局设置，桌面列出已安装字体。IPA 固定内置 Doulos SIL。
- 声调默认显示。隐藏声调只影响显示及 PNG，保留音段附加符号、原始字表、多音候选与选择。
- 设置分组与滑条收紧，侧栏保留滚动。PNG 沿用颜色、汉字字体及声调选择。
- 检查旧草稿兼容、字体与导出失败、长文本、多音选择与修改文本后的选择位置。

文件范围：`frontend/src/modules/mandarin-ipa/`、M13 定向验证及说明。复用公共字体下拉组件与桌面字体接口，无新依赖、数据库变更或 EXE 构建。

验证：前端类型、全量既有单元检查、构建与生成一致性；独立 Chrome 本模块功能/浅深色/大小窗口/导出；实际隐藏 Qt 宿主。本轮证据与限制写入 `docs/testing/2026-10-05-m13-r2-report.md`。
