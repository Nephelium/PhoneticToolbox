# 网页版上线计划：首期服务器计算

2026-10-16。按用户最新要求重新编写，方案已确认，功能实施为 `in_progress`。首期计算由现有云服务器承担；浏览器算法迁移放到后续优化，Windows/Linux外接计算电脑仅保留扩展接口，不假设设备可获得。已开始注册、临时工作区与共用工作台的首批实现，验证范围见[实施验收](../testing/web-launch-foundation.md)。

本计划是网页版的当前执行入口，接替2026-09-26服务器统筹方案及本页此前的浏览器优先方案。产品约束见[需求](../requirements.md)，账号与清理的唯一规格见[账号、空间和任务](../specs/accounts-storage-jobs.md)，架构取舍见[网页版决策](../decisions/ADR-web-ephemeral-client-first.md)，状态见[任务台账](task-ledger.json)。

## 1. 首期目标和不变要求

- 使用同一套Vue工作台，保留本地版的侧栏、标签、主题、图表和模块布局。增加注册登录、任务排队/进度、连接状态与临时保存提示；浏览器文件选择/下载替代桌面目录授权，无需重设计整套页面。
- 未接通的模块或操作保留桌面版设置界面，以当前主题的半透明遮罩阻止操作并说明可用的Windows版入口。录音复用同一页面，仅替换设备/文件端口。跨平台科学结果允许合理浮点差异，不要求逐采样或逐字节相同；需保持参数、单位、时间网格和结果含义，按方法预先定义误差指标，不把所有差异自动归因于舍入。
- 开放自助注册、邮箱验证和密码找回，复用已有登录、Cookie、CSRF与资源归属校验。
- **主动点击退出立即关闭工作区、取消任务并启动清理。直接关页、断网或崩溃，从服务器记录的最后一次有效心跳起保留1800秒，期限内可恢复。** 刷新、后台切换和关闭部分标签不提前删除；另一设备的独立工作区不受影响。
- 工作区到期覆盖服务器输入、输出、任务历史、派生缓存和未完成暂存；任务运行或成功不会延长恢复期。已下载文件、用户原文件和桌面项目保持原有保留规则。
- MFA首期不支持线上推理，前后端均禁止对齐任务，提示下载实际支持平台的桌面应用。当前下载标明Windows版，macOS用户不显示不存在的安装包。
- 每账号默认1,000,000,000字节（1 GB），覆盖其全部活跃工作区与预留，不预分配。管理员可调整默认额度或单独账号额度，用户可申请扩容；全站磁盘、单文件、队列和计算预算独立控制。
- 已有纯客户端功能继续复用。汉字转IPA、音标表、绘图/播放和感知实验无需反向迁到服务器；感知实验刺激时序与反应时仍由本机时钟处理。

旧storage_policy.py的policy_version=2/259200秒保留兼容；新增显式启用的workspace_policy_version=1管理1800秒会话寿命，注册和MFA限制已进入本地验证。现存库与线上应用尚未启用新策略。

## 2. 首期运行方式

```mermaid
flowchart LR
    UI[浏览器：共用工作台] -->|同源HTTPS：文件与任务| API[账号与工作区 API]
    API --> Storage[临时存储与配额]
    API --> Queue[有界任务队列]
    Queue --> Worker[服务器计算进程]
    Worker --> Core[现有Python与原生科学核心]
    Core -->|受控输出| Storage
    Worker -->|校验结果并发布| API
    API -->|进度、结果与下载| UI
```

1. 浏览器在用户选择文件并提交操作后，将所需材料上传至当前工作区；纯客户端功能沿用不上传行为。服务器核对账号、工作区、格式、大小与剩余配额。
2. API保存参数、输入摘要与任务快照，进入有界队列。服务器worker调用现有固定科学入口，算法、默认值、采样率、单位、时间网格和缺失值语义保持。
3. 完成后，服务器在同一发布流程中核对工作区仍有效、任务未取消、执行代数有效及输出额度，再发布可下载结果。用户退出或到期后的迟到结果拒收并清理。
4. 页面显示排队/执行/失败/取消及真实进度；连接恢复后查询同一工作区和任务，不能重复创建同一提交。下载按账号和资源归属鉴权。
5. 浏览器只连接公开同源API，不直接连接数据库或计算子进程。不同用户输入、临时目录、执行上下文与输出隔离；外部程序的进程树、内存、CPU、时间和磁盘受实际硬限制约束。

首期以单台云服务器上的API、PostgreSQL、存储、清理器和worker为基线，沿用现有工程。服务器计算、交互预览和文档/归档导出共同受准入限制。是否拆分服务或增加资源由压测结果决定。

## 3. 功能接入与首批候选

### 录音、生理合成与论文精读完整迁移

井井2026-10-16明确要求三个模块完整迁移，不能以界面占位或单次smoke作为完成。最新分工：本任务仅继续录音，生理合成和论文精读由井井交给其他任务，保留现有候选与缺口，不在本任务继续修改。沿用同一Vue页面和既有科学/文档核心，网页设备、受管文件与有界服务器任务作为适配层，不更改桌面默认值。允许合理浮点差异，科研含义与设置保持。

1. 录音逐项覆盖设备与录前检测、自由/任务采集、任务清单与选用历史、全部声道、Praat语谱/缩放选区、剪切/复制/粘贴/删除/只留选区、原始恢复/撤销/重做/版本切换、噪声样本/谱减/数字增益及直接来源差分试听、当前/选区/选用/全部/历史导出与FLOAT/PCM24/PCM16、任务/处理/质量清单、保存/恢复及中断处理。采集使用浏览器实际可提供的通道和输出设备，不把声明约束等同硬件能力。计算复用既有录音核心，正式处理走既有受管任务/取消/配额/工作区期限。浏览器文件夹授权不足时使用明确的工程导入/下载方式保留对应功能。
2. 生理合成覆盖构型与全部参数、截面/三维与分析、预置/常用/自定义配置、声源与试听、关键帧/基频曲线、生成/播放/停止、文档与音视频导出。Linux无头引擎放有界执行环境，每用户状态隔离；浏览器负责播放服务器生成的采样，不在服务器声卡发声。不能因为原生候选成功就提前解除尚未接通操作的遮罩。
3. 论文精读覆盖推荐/往期/栏目说明、日期筛选/勾选获取/删除与恢复、个人PDF及收藏夹导入/移动/删除、连续阅读/缩放/全文选择/本页文字、原译文/解读、笔记/荧光笔/批注冲突恢复、原件和带批注PDF导出、引用与设置。个人PDF及批注的网页服务器副本遵循当前临时工作区政策，保留下载与本机原件；浏览器缓存按账号隔离。复用既有目录许可校验、PDF解析和注释语义。

每项按源代码操作清单、自动化、真实隔离服务器流程和浏览器视觉证据记录；权限拒绝、断线恢复、任务取消、额度满、退出/到期及跨账号边界一并覆盖。实体设备与macOS证据单列。原EXE和正式官网/反馈服务不因网页迁移替换；工作台继续私有内测。

## 5. 服务器容量与降载策略

- 不把历史服务器配置当作现时容量。首期科学计算/预览/重导出初始合计最多1槽，每账号最多1个运行任务；全局队列、每账号待排任务与请求频率设上限，具体数值经实测冻结。
- 工作区模式已增加原子队列保护：每账号最多8个、全站最多128个未结束任务（含运行与批次预留子任务），满额返回429并提示稍后重试。它们是开发阶段的保护值，不能据此推算并发用户容量；最终服务器须重新测量并冻结。
- 所有任务设置输入/输出字节、样本/帧数、时长、CPU/内存及执行时间预算；排队不能越过工作区有效期。超过能力的请求在计算前说明限制，可提示缩短输入或使用桌面应用，不降低算法精度制造通过。
- 10人交互为首档测试，再按25/50/100阶梯寻找边界，达到资源/错误率门即停止增压。这些是测试档位，不是同时计算槽数或已承诺人数。另测一个科学任务运行时其他用户登录、交互和下载。
- 对耗时计算显示排队/取消，预览按参数与输入版本去重、合并和取消过时请求；缓存只在有效工作区内复用并计量，不建立永久研究结果缓存。
- 记录排队/计算/传输时间、p50/p95/p99、CPU/内存/磁盘/带宽峰值、错误率和公平性。登录/心跳/取消/清理保留资源预算，不能被大任务挤占到无法退出或清理。
- 只有服务器预算内验证通过的操作开放。MFA继续关闭，服务器没有可用GPU时不启用依赖GPU的任务；未通过的重任务不自动转到未知外接电脑。

### 在线人数、容量与上传限制

- 登录直接进入默认项目工作台。内部项目继续隔离文件、任务和草稿，不要求用户先建项目；默认项目在原事务内创建/复用，刷新或多标签不重复创建。保留文件与空间管理入口，集中下载/删除，文件和任务分开查看，补充上传和项目分组折叠；常规窗口默认内容尽量一屏可见，长列表在管理窗内部滚动。
- 展示配置的后台任务槽位、运行/等待数以及可获得的整机CPU/内存百分比，繁忙时提醒等待且不重复提交。服务端聚合负载5秒缓存、前端30秒刷新，首个CPU样本或不可采样平台显示暂不可用。没有可靠最高在线人数结论时不填写人数上限，25档突发失败仍需后续准入/性能处理，提示不能替代服务端限额。

- 在线人数统计最近90秒有有效心跳的不同账号，页面每30秒刷新；同账号多标签/设备去重，30分钟恢复窗口不算在线。只公开总数，服务不可用时显示未知。
- 默认1 GB，支持管理员调默认额度和单独账号额度。申请包含所需总额度、用途和当日/7天/30天期限，审批可修改额度与期限并留言回复；当日截至审批当天北京时间24点，7/30天从批准时起算，过期恢复常规额度，已接受的预留可完成，超额禁止新预留。同账号仅一个待审申请；管理员核对全站实际已用、预留、安全水位后批准。额度不预分配物理空间，不提高任务内存、单文件或计算上限。
