# 网页版上线计划

2026-10-16。需求已按用户本轮要求更新，实施状态为 `planned`。用户确认开放自助注册，并最终确认主动点击退出立即清理，直接关页、断网或崩溃统一按最后一次心跳后30分钟清理。本轮执行源码 GitHub 同步与需求/任务梳理，没有实施网页功能、迁移现存库或部署应用服务。

本计划接替 2026-09-26 服务器统筹计划中的网页目标。规范以[用户需求](../requirements.md)与[账号、空间和任务规格](../specs/accounts-storage-jobs.md)为准，取舍见[网页版决策](../decisions/ADR-web-ephemeral-client-first.md)，实际进度在[台账](task-ledger.json)。历史桌面、Linux 与服务测试保留原验证范围。

## 上线目标

- 用户自行注册，经邮箱验证后使用工作台，提供密码找回。既有登录、Cookie、CSRF 和资源归属校验继续复用。
- 服务器仅存本次工作的临时数据。主动点击退出立即关闭工作区并启动清理；直接关闭页面、断网或崩溃均按最后心跳后30分钟清理。刷新、返回、隐藏标签与另一标签仍活跃不得触发误删。
- 30 分钟内重连可恢复同一工作区。到期后清空服务器文件、结果、任务历史及派生缓存，账号仍可登录。具体事务、物理删除和重启行为按规格实现。
- MFA 网页仅保留说明与桌面下载入口，前后端均不允许线上推理。
- Windows 与 macOS 浏览器优先本机计算，服务器只承担身份、静态分发及已准入的必要任务。首期功能按操作粒度开放，不以模块菜单存在当作上线验收。
- 现有每账号 1,000,000,000 字节作为暂定上限保留，覆盖其所有活跃工作区及预留，不预分配。全站水位、单文件大小、任务数量和并发预算另经目标机器实测确定。

| EGG 分析 | Python/原生科学路径及专用交互会话 | 客户端负责轨迹与交互；数值分析暂走已准入服务器 | 浏览器移植需覆盖接触商、逆滤波、缺失值及时间网格 |
| LPC 谱图 | 后端计算返回数值快照 | 客户端绘图；局部 FFT/LPC 是 Worker/WASM 候选 | 与现有算法、窗函数及样本索引对照后才开放本地正式计算 |

| TextGrid 标注 | [format.ts](../../frontend/src/modules/annotation/format.ts)与 [portableAnnotation](../../frontend/src/platform/annotation.ts)已有前端解析/编辑 | 本地导入、关联播放、区间/点层编辑与下载优先 | 目前 serverFiles 保存仍会上传，需新增本地文件适配、长录音预算与账号隔离 |
| 汉字转国际音标 | [state.ts](../../frontend/src/modules/mandarin-ipa/state.ts)直接读本地 JSON 规则，导出在前端 | 首批纯客户端功能，不上传待转换文字 | 去除桌面字体枚举依赖，验证字体/儿化/多音字及图片导出 |

| 感知实验 | [ADR-M15](../decisions/ADR-M15-client.md)：Web Audio、IndexedDB、计时和导出已在客户端 | 保持刺激、随机化、计时、回答和结果在用户设备，不默认上传 | 补网页账号/工作区命名空间与切换保护；后台/中断恢复、Safari 及物理时序另验 |
| 录音 | [recording port](../../frontend/src/platform/recording.ts)当前由桌面宿主注入 | 用浏览器媒体 API 实现基础录音、波形与下载 | 安全上下文、权限拒绝、设备切换、PCM/编码、采样率与 AGC/降噪/回声消除实值验证；浏览器不能满足的多通道科研采集给出具体限制 |

## 执行阶段与验收

| 顺序 / 任务 | 具体工作 | 完成条件 |
| --- | --- | --- |
| 1 · WEB-REGISTRATION | 复用账号体系，注册、邮箱验证、找回密码、一次性令牌、过期/重放防护、邮件重试和限流 | 未验证账号不能创建服务工作区；注册/重发/找回不泄露账号存在性；重置后旧会话失效；邮件服务的配置与真实发信另按授权实施 |
| 2 · P07-POLICY | 将网页登录存储切换为会话工作区；定义租约/代数/清理状态与新政策版本 | 主动退出、关页/断线后以最后心跳计1800秒的边界、刷新/多标签、服务器重启、删除失败及迟到结果均有证据；现存库迁移方案须单独审阅 |
| 3 · WEB-ACCOUNT-BOUNDARIES | 本地浏览器文件适配、账号/工作区隔离、能力显示和缓存生命周期 | A退出后B不能通过界面或迟到响应读取A的数据；不自动认领旧无主实验；本机已下载文件保持 |
| 4 · WEB-MFA-DESKTOP | 网页说明、平台准确下载入口，关闭后端 MFA 准入 | 绕过界面直调也不能提交/恢复 MFA 推理；TextGrid 本地编辑仍可用 |
| 5 · WEB-CLIENT-COMPUTE | 先音标转换/音标表/感知实验，再 TextGrid/波形/参数图与基本录音；后续按表移植 | 各纯客户端操作实测没有研究数据上传/科学计算请求，低配置设备可取消，失败不静默转服务器 |
| 6 · WEB-CAPACITY | 更新目标主机盘点，统一有界队列/上传/预览/导出预算与全站磁盘水位 | 先10，再25/50/100并发交互阶梯，测出容量边界后决定实际准入；不承诺这些档位全部通过。计算槽初始最多1个，无后台预览绕过 |
| 7 · P15-STAGING | 最终 Linux 环境、真实同源 HTTPS/PG、生命周期/隔离/负载、部署回退演练 | Windows Chrome/Edge 与 macOS Safari/Chrome 均按首期操作实测；生产上线需具体目标与部署授权 |

本地计算基线采用 Worker 与必要的 WASM，WebGPU 作为可选加速，不能成为所有 Mac/Windows 用户的硬依赖。设备不支持时明确显示本机限制，先提供本地 CPU/WASM 方案；需要服务器处理时由用户明确提交，并受服务器能力/配额控制。[Web Workers](https://developer.mozilla.org/en-US/docs/Web/API/Web_Workers_API)、[WebGPU](https://developer.mozilla.org/en-US/docs/Web/API/WebGPU_API)与[媒体采集](https://developer.mozilla.org/en-US/docs/Web/API/MediaDevices/getUserMedia)的实际支持按测试浏览器记录。

浏览器处理不继承操作系统的本机路径权限。文件选择/下载作为通用入口，File System Access、WebCodecs 等仅在能力探测成功时增强。保持原采样率、声道、时间单位、缺失值、随机种子和算法身份；Web Audio 的重采样播放结果不能回写为科研原输入。移植算法复用同一核心/生成资源或建立独立固定基准，避免长期维护两份无对照实现。

## 用户可见文字

- 进入工作台：服务器仅临时保存本次工作。点击退出后清空；直接关闭网页或意外断线，可在30分钟内恢复。请及时下载需要保留的结果。
- 正在恢复：连接已恢复，继续本次工作。
- 已到期：本次工作已清空，请重新导入文件。
- MFA：由于服务器性能限制，网页版暂不支持 MFA 在线对齐。请下载桌面应用，在本机完成对齐。
- MFA 下载入口当前应标明 Windows 版。macOS 用户可阅读说明；在 macOS 安装包实际交付前，不展示不存在的对应下载，也不暗示 Windows 应用可在 Mac 直接运行。

## 尚待实施时核定

目标服务器当前资源/磁盘余量、邮件发送服务与域名验证、实测准入人数及各任务大小上限、首批服务器科学操作白名单、Windows/macOS 测试设备。它们均不改变本轮已确认的自助注册、30分钟断线保留、MFA桌面推理与浏览器优先原则。暂不增加云端长期保存、后台无人值守计算、付费配额、公开实验分发或强制可信节点依赖。
