# 网页论文精读实施计划

**目标：** 网页复用桌面同一论文目录、连续阅读、批注与导出界面，接通全部操作。

**实现：** 将既有论文分发、个人库与 PDF 实现原样移入 独立的共享文档包 ptb_documents（随 desktop Python 包提供），桌面保留兼容入口。网页通过同源、账号及项目鉴权接口调用有界子进程。个人文件、推荐缓存、设置和批注作为既有受管资产保存，沿用配额、工作区期限与退出清理，无数据库迁移。

1. 抽取共享文档服务，运行既有桌面论文测试，确认科研/阅读语义保持。
2. 增加受管论文快照与请求接口，覆盖推荐/往期/说明、文件夹/导入/移动/回收恢复、PDF/批注/导出、取消、并发冲突与失效工作区。临时解析目录仅在请求存续期内存在。
3. 注入网页 papers port，移除论文遮罩。文件选择与下载使用浏览器入口，桌面继续使用原生窗口；服务器副本遵循临时工作区规则。
4. 运行账号/配额/到期及多窗口冲突测试、真实 PDF 渲染与注释导出回读、前端类型/相关测试/build及独立 Chrome 浅深主题操作。
5. 原位更新台账、状态、架构、模块说明、CHANGELOG 与验证报告，明确本机、Linux、生产及 EXE 证据范围。

本任务不更改公开网站、现存数据库 schema 或发行成品。对既有共享论文代码只调整包位置，不引入新的 PDF 引擎。井井补充服务器登录条件后，接续既有私有 Linux 内测实例，使用独立项目文档运行时；先核对现有实例，再合并论文入口并执行实际 HTTP/浏览器验收。
