# 项目路线与实施入口

本文件保留旧链接位置，按主题维护路线，不追加日期进度。当前任务先看[实现与后续清单](../project-status.md)，具体编号查询[台账](task-ledger.json)，从[模块导航](../modules/module-migration.md)进入具体模块。

| 领域 | 目标与入口 |
| --- | --- |
| 架构和基础 | [总架构](../../ARCHITECTURE.md)、[开发入口](../development.md)、版本化契约与科学基准。 |
| 科研模块 | 保留 v2 功能，按当前任务逐模块对照、实现和验证。 |
| 公共界面和说明书 | [UI_SPEC](../design/UI_SPEC.md)、正式 manual/ 与共用阅读器。 |
| 网页、任务与节点 | [存储规格](../specs/accounts-storage-jobs.md)、[远程协议](../specs/remote-protocol-v1.md)、平台资源与实际验收。 |
| 发行与来源 | [严格 Windows 打包](../../release/PACKAGING_RULES.md)、分平台验收、来源和对应源码准备。 |
| 清理与维护 | 根规则、仓库内容管理、可生成产物生命周期，保留科研原件及当前依赖。 |

每项任务确定对象、预期行为、兼容风险和退出条件，先进行必要检查再实施，记录实际平台与验证范围。重大架构/科研语义/数据或授权范围变化更新相应 ADR；不根据旧计划自动推进下一模块或数据库操作。

[原始迁移计划](v3-migration-baseline.md)保存 P00–P16 的原目标、路径、验收与历史阶段，按需查询，不用其旧环境、配额或下一步覆盖当前规范。
