# 声道工作台集成与单屏布局

井井已要求把现有 P2 工作台集成到主应用，并明确说明书最后编辑。本轮在已有动程、唇宽与软腭修正基础上集成，不重做声学模型。

## 实施顺序

1. 将原型迁入 Core（原生引擎、轨迹算法）、Services（HTTP、音频、子进程与用户配置）、Models（启动结果）、GUI（按钮与网页资源）。生产代码不导入 prototypes。
2. 主程序按钮经 API 异步启动自身 EXE 的专用工作进程。随机 loopback 端口；只复用本实例拥有的服务。正常退出主动关闭；Windows Job Object 和父进程存活监测覆盖异常退出。取消原型的十分钟空闲退出。
3. 用户配置写入 LocalAppData/PhoneticToolbox/vocal_tract；资源只读。关键帧使用应用配置持久化，不依赖随机端口的浏览器存储。
4. 桌面单屏：中央模型与三个分析图常驻；右侧器官/声音/关键帧切换；器官子面板；关键帧分页；全局保存姿势与播放入口。优先验证 1366×768、1920×1080 与较小内嵌浏览器。
5. 原生计算、HTTP 会话、配置、启动复用、关闭与强制父进程退出、GUI 入口、布局和交互测试。自动验证不发出声音。
6. 更新架构、层级 README 与打包资源说明。最后补说明书章节与导航，再验证本地 EXE。

## 边界与取舍

- 独立工作进程隔离 VTL 原生库与 Qt 主界面，生命周期仍归主应用；浏览器关闭只停止发声，主应用退出关闭整个服务。
- 鼻腔与头壳仍是不同来源的参考配准，不提升为个体解剖测量模型。
- 本地构建包含 VTL GPL 源码与许可、鼻腔 CC BY 署名、Three.js MIT 与头壳 CC0 说明；第三方条款单独列出，不宣称整个分发物仅适用 MIT。
- 原型目录和既有修改保留；不公开发布、不推送。

## 本轮追加交互与显示

1. 矢状面空白拖动平移、滚轮缩放；面积图直接点选/拖动截面。显示导线由当前气腔截面的上下边界求中点，计算坐标保持不变。
2. 软腭背缘按后咽壁轮廓计算显示间隙；唇部组织显示与门齿边缘作局部避让，二维和三维共享显示数据。
3. 实际输出 PCM 的有限环形缓冲，独立于声学合成锁；纯 Core 窗函数 FFT 分析，前端显示可折叠的波形和灰度语谱图。分析无麦克风访问，测试不播放音频。
4. 宽屏三栏：模型、分析、控制。普通窗口两栏，以分析页签切换声学图/输出监测；展开监测可查看更大图幅。
5. 关键帧增加归一化时间上的手绘 F0 曲线、重画/撤销/恢复逐帧基频；保存曲线与姿势。音频和缓存画面使用同一条 F0 轨迹；修改总时长按比例伸缩曲线。
6. 功能与视觉验证完成后再重写说明书并刷新导入包，最后重新构建并检查 EXE。

## 声源追加

井井追加授权清声/耳语控制。使用实际 VTL 几何声门相对振动幅度与压力/膜部开度/后部缝隙，不另加白噪声冒充生理源。源设置随关键帧插值，F0 对零振动片段不生效；监听弱音可选增益独立于物理驱动。完整声带/喉部视图与自主起振另列后续路线，当前不声称完成。新增功能仍按代码、静音测试、说明书、EXE 验证的顺序收尾。
