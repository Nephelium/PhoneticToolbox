# M03-R5：REAPER F0 与 30–800 Hz

井井已授权新增 EGG 的 REAPER F0，并把 REAPER / Praat 搜索范围设为 30–800 Hz。复用既有原生 REAPER、进程预算与选区模型，不安装依赖、不修改 V2。

1. 新工作台请求使用 `audio-f0/2`，Praat AC / REAPER 均为 30–800 Hz、10 ms。旧请求缺少修订字段按 `legacy/1` 保留 75–600 Hz Praat 计算，历史文件不重写。GCI / CQ / IF 方法不变。
2. REAPER 取同一归一化音频声道，保留原生时间和无声 NaN。默认关闭，预览首次启用计算并缓存，切换声道时重算。后端不可用时明确报错，不用其他算法冒名替代。
3. 左栏与批次弹窗增加 REAPER 开关；当前动态 F0 轴涵盖勾选曲线。选中 REAPER 时单文件/批次 CSV 与三图导出包含该曲线，元数据记录真实引擎和二进制哈希。
4. 定向检查搜索参数、低/高 F0、无声、开关缓存、历史兼容、CSV/PNG、真实原生进程与 Qt/Chrome 接线，WSL 单列可验证边界。
