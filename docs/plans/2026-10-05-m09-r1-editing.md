# M09-R1 频谱绘制与四点校正

状态：限定 Windows 源码、Chrome/实际 Qt、本地真实任务 verified。2026-10-05 井井明确授权当前 Windows 工作台修复与两种涂鸦重建，追加指定按钮顺序为图片重建、图片涂鸦重建、音频藏信息。完整证据与未验边界见[报告](../testing/2026-10-05-m09-r1-report.md)。

- 图片重建：原图标题仅一处，沿用 h2 字号。空态展开，结果后折叠。追踪原始四点直到校正 PNG，加入倾斜四边形回归与实际宿主验证。
- 音频藏信息：顶部模式切换，隐藏图片标定栏。读取真实音频得到 Hann STFT，以黑强白弱显示，保留原始复数相位。可选编辑声道，其他声道保持原数组。使用原始网格绘制，逆 STFT 保留采样率和样本数；不经过 Griffin–Lim。
- 图片涂鸦：先四点校正，再编辑校正图，保留左侧标定；以已有 Griffin–Lim 重建。改角点后需重新载入画布，禁止笔迹映射到不同底图。
- 画布：主题化紧凑工具行、黑白画笔、粗细、不透明度、缩放、平移、撤销重做。编辑命令快照绑定源哈希、四点与模式；单笔透明度一次合成。
- 复用同一 Job/文件/播放/导出链，不增加数据库 schema。新字段兼容旧任务，原图无涂改保留旧算法；原始输入不写回。不新增依赖、EXE、push 或发布。

核心与契约、前端、桌面适配、独立验收脚本、说明书与来源登记为本轮修改范围。验证：旧 M09 parity，新增核心与契约边界，前端 typecheck/test/build，实际 Qt 隐藏窗口及 Chrome 浅深/窄窗证据。测试使用独占复制的既有测试 schema，不执行现存库 DDL。
