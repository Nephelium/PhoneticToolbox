# M03-R3 EGG 布局、图形与参数审查

2026-10-04，verified，限定 Windows 开发态及 [验收报告](../testing/2026-10-04-m03-r3-report.md) 的范围。井井授权实现截图所列布局、逆滤波分组、PNG 导出、EGG 全段查看、dB 自动按钮，并调研逆滤波及峰谷阈值。

1. 左栏紧凑表单按可用宽度排一或两对字段，文件选择器移入左栏，交换声道、导出及 LP 阶数移入顶栏。
2. 逆滤波按三个信号分组生成 6 / 4 / 4 / 2 图。双信号保留左右轴，三信号叠加按各自峰值归一化并明确标识，原始数据不变。音频实线、IF 虚线、EGG 点线，屏幕和白底 PNG 分别使用适合背景的颜色。
3. 公共 ScientificPlot PNG 路径只导出居中小标题、坐标和图形，移除彩色文本图例。其他导出入口逐项核查，不删除必要色标、单位或曲线身份。
4. 结果操作统一置顶，全段 EGG 来自同次任务的滤波数组。新增可选协议字段，旧任务缺少全段 EGG 时明确提示，禁止用当前源文件冒充历史结果。
5. dB 自动为一次性按钮，使用同一 PSD 的当前 ROI / 0–5000 Hz 峰值及 50 dB 动态范围，实际数值回填，可继续编辑。静音不猜范围。
6. 逆滤波与事件算法进行源码、原始论文及数值敏感性审查。保留历史科学公式，不把未经真值验证的参数称为最优值。若建议更换科学方法，另列可审阅方案。
7. 井井追加：F0 纵轴根据可见的有效值动态显示，界面和新导出一致。逆滤波上下图共用左右边距和横向绘图长度，避免双纵轴导致时间轴错位。

验收：类型、前端测试/构建、协议生成一致性；受影响 Python 与原计算对照；Chrome 浅深色、窄宽侧栏、四模式 PNG 和全段 EGG；实际 Qt 文件保存与任务回读；WSL 可运行部分单列。原输入只读，输出位于忽略目录。本轮不打 EXE，不 push，不改数据库或环境。
