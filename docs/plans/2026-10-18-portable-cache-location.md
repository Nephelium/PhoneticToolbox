# 免安装版手动选择缓存目录

2026-10-18。井井要求免安装版首次明确选择缓存目录，覆盖 EXE 更新后沿用，并在设置中显示路径、支持打开目录。当前状态：verified，限定当前 Windows 源码、原生选择与实际 Qt，成品另验。证据见[验收](../testing/portable-cache-location.md)。

## 实现范围

- Windows 免安装启动器在展开大组件之前选择目录。取消即退出，不回落到隐藏默认目录。
- 用户选择的父目录下使用专用 `PhoneticToolbox-cache` 文件夹，仅存可重建缓存。位置记录留在既有用户设置目录，不随 EXE 名称、版本、位置或缓存删除而消失。
- 缓存目录统一容纳运行文件、更新下载及更新辅助文件、普通浏览器缓存。更新偏好、Qt 持久草稿、设置、研究任务资料、录音、论文批注及 MFA 组件保持既有位置。
- 实际 Qt 6.11 验证发现 GPUCache/Dawn 图形缓存与 persistentStoragePath 绑定。井井追加确认保留 GPU 磁盘缓存，设置单独显示实际路径并支持核对后安全退出清理；不关闭 GPU 磁盘缓存、不移动草稿数据。
- 井井追加要求检查旧缓存：仅盘点应用已知默认位置与已记录的历史专用目录，显示路径、文件大小合计和占用，用户亲自核对并确认才清理。图形缓存沿用未保存/录音收尾保护，等最后一个使用窗口退出后执行；清理失败保留请求并重试。
- 现有缓存不自动搬动或删除。目录不可写、被替换为联接或归属不明时给出选择/重试入口，禁止静默使用别处。
- 安装版保留现行默认缓存及安装预热/卸载清理；源码入口继续保留既有工作区身份。
- 设置页通过桌面能力读取实际目录并打开，网页不接收任意路径打开能力。路径、说明和打开失败均有实际反馈。

## 验证

- 目录选择取消、持久记录、覆盖更新、缓存删除重建、中文/空格目录、拒绝研究目录及联接、配置损坏、只读路径、多实例与安装版隔离。
- 更新缓存与偏好分离后，删除缓存仍可读取原偏好；原有完整性、更新应用及缓存租约回归保持。
- 前端类型/契约/UI 数据检查、定向测试、构建，以及隔离 Windows Qt 实际路径与打开操作、浅深和窄窗口检查。
- 本轮交付当前源码并启动统一源码工作台。最终 EXE 构建、真实覆盖换版和安装卸载属于后续成品验收，不从源码结论推定通过。
- 既有最终包 QA 为其独立 profile 显式写入真实缓存位置偏好，更新检测到的缓存/下载路径；没有增加生产跳过选择或免校验开关。首次原生选择仍单独验收。

## 探索与取舍

独立后台和计划任务会增加退出后的系统对象；每次退出解包缓存会牺牲再次启动速度。采用井井提出的显式目录和可见入口，沿用已有内容校验、原子准备和活动租约。研究任务文件不整体迁入可手动删除的缓存目录。
