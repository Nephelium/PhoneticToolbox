# M10-R11 生理参数与几何一致性

状态：限定 Windows 源码 verified。原始需求及后续小舌止抵、尺寸保持、口鼻连续参考和灰色显示要求已实现，最终证据见[验证记录](../testing/2026-10-06-m10-r11-report.md)。首轮含穿模的截图已标为诊断材料，不能用作最终通过证据。实体听辨、跨平台和冻结 EXE 未验。

## 实施边界

采用现有 VTL 科学核心与本机宿主。保留原始头壳、平均鼻腔、speaker 与官方 API DLL，修改有源码的几何桥接和显示配准。鼻腔和 JD2 非同一个体，MRI 仅作解剖关系参考，不宣称重建了个体医学模型。源数据原文件保留。

相比单纯遮盖拼接，优先连续连接网格和统一截面来源。相比取消全部约束，仅去除门齿前方虚拟封墙与舌叶过严的构造限制，保留硬腭、牙齿、口底及后咽壁边界。独立喉部位移重算几何、中线、截面和合成管道，舌骨参数不变。新自由度需贯通撤销、构形、关键帧、文件和音频，不作仅显示的假控制。

三维所有气腔/组织共用正中裁切，只有显式勾选显示完整模型才解除。二维继续使用同一三维几何的截线。面积检查区分正中接触、仍有侧通路与全截面闭塞，保留计算所需数值下限并如实标注。
