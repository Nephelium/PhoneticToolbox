# M19 语言地图实施计划

**目标：** 共同呈现两套核心资料：Huang 等（2024）Zenodo 数据包的 930 个调查点、510 个语言特征及论文结果，以及井韶子本人整理的县级方言分布、方言岛和分类体系。两者分别提供语言特征与地域分类的完整浏览入口，并可在同一地图中关联查看。已完成本地试用，按2026-10-23最新授权同步Windows、macOS与网页，准备3.0.5。

**架构：** 接现有 Vue 工作台、统一主题、文件端口和模块生命周期。调查点、语言特征、行政边界、方言分类和用户编辑分别保存，通过有来源的关联表连接。数据预处理离线完成，运行时本地按需加载；不建立第二套页面服务，不把图书扫描件塞进 EXE。

**技术方向：** Vue/TypeScript，OpenLayers 离线矢量图层作为首选候选，Python 负责数据审计与构建转换。依赖在 Qt 兼容性小样验证后固定版本并登记许可。

### 分类编码与图例释义的缺口（2026-10-22 复核）

[Zenodo 压缩包在线目录](https://zenodo.org/records/10697975/preview/data_and_codes.zip?include_deleted=0) 包含分类主表、坐标、MDS/FCM 结果、距离矩阵、调色板、边界和两个分析脚本，未列出独立类别释义表。本机 `all_china.xlsx` 和 `cn_tax.xlsx` 各有一个工作表，均无批注；前者是主 CSV 的本机表格副本，当前在线压缩包目录并未列出它。README 将编码方法指向论文第 2.2 节。2026-10-22 再次下载 ZIP 返回 HTTP 403，所以未声称完成远端 ZIP 与本机资料的逐字节同一性验证。

[论文第 2.1–2.2 节](https://pure-oai.bham.ac.uk/ws/portalfiles/portal/231902238/LING-62-4-10.1515_ling-2021-0138.pdf) 说明：原图的颜色类别转为大写字母，同色的符号子类转为数字；`A1#B2` 保留同一地点的多个变体。语法第 36、37 图由论文作者重新划为三级，小写字母表示第三级。此规则解释编码的结构，未提供 510 张图逐项编码到音值、词形和语法解释的完整字典。不同图中的同一编码不能视为相同语言学内容。

现有导出中的 `A · 617` 表示 A 类及其地点数，`B2` 中的 2 表示子类；二者不能混为序号或音标。当前只有 F1_P 的声调数量标签已接入，其他类别大多仍显示编码。标题和完整原页已核对并不代表类别释义已经补齐，此项继续列为未完成。

后续优先寻找作者的原始编码对照表。如果没有现成表，在原 PDF 上逐图读取图例和必要脚注，整理类别释义、IPA、例字、原符号及证据位置；用已知地点的原图符号与主表编码交叉核对对应关系，不按图例排列顺序猜配。第 36、37 语法图单独核对作者重分类规则，不能由 OCR 自动还原。识别有疑义时向用户提供具体图号、页码与原图，由用户确认。已有 930×510 观测及论文结果继续直接使用，不重新统计原书全部调查点。

## 2. 导入前需要处理的实际问题

### 主表

- 474,300 个特征单元格无空值，但不能由此推断全部有效。发现 197 个格式异常，涉及 189 个地点、24 个特征。其中 196 个混入 `0 ... Name: ..., dtype: object`，另一个是古田 `F56_L` 的 `C1C1`。
- 229 个单元格带首尾空白；5343 个单元格用 `#` 记录多个变体，每格最多 3 个。顺序保留，不能任意排序，也不能把并存变体绘成未经调查的人口比例。
- 保留输入原值。空白规范化、可确定的程序文本解包、待核实异常分别记录。`C1C1` 必须核对原图，禁止猜成 C1 或两个 C1。
- 编码在每个特征内部解释。`F1_P:A1` 与 `F117_P:A1` 是不同类别，不共用全局的 A1 含义。
- `A10` 是一个完整亚类编号，不能用“字符串第二个字符”建立层级。语法小类还可能有字母后缀。
- 独立转写所附脚本后抽查 4 对地点，与附带距离矩阵均有差异。例如 S1—S2 为 0.2103408029878618，矩阵为 0.210830999。当前只确认本地表、脚本操作和结果不完全一致，尚未定位成因。
- 第一版展示附带论文结果时原样使用原矩阵；按已校订特征进行的新分析另设数据版本和算法版本，未经核验不覆盖论文结果。只显示单特征或多个特征时，不把全 510 特征的距离改称“当前所选特征距离”。

### 分类表

- 合并表 3666 条中有 3615 个完全不同的整行；重复记录保留出处并核对，不能默默累加为更多方言。
- “省编码”中可见县级值，例如安徽 340102；“方言岛”的第五列表头为“邮政编码”，实际用途需核对。`#N/A` 作为缺失处理，不作有效行政代码。
- 合并表与两个分表记录数不简单相加，不能凭文件名或行号推断方言岛身份。须按地点、完整分类路径及原表来源建立可追溯关联。
- 追加逐行核对：规范空白和数值表示后，合并表相对“方言区”多出 471 条匹配计数，同时后者有 86 条未在合并表完全匹配；356 条方言岛记录中 355 条能在合并表完全匹配。以上是记录差异，不能直接解释为新增/删除方言岛，也不直接据此更正原表。
- 湖南“片”的叶名称有 15 个，完整分类路径有 17 个。正式统计使用有父级的身份，同时提供原始名称，先核对可能的分类差异，不直接宣布哪一个数字正确。
- 一个县可能包含多个方言或方言岛。调查点到县的关系需要空间匹配与旧地名核对，不把县表直接当作 930 点的分类真值。

## 3. 地图完整性结论与补齐策略

文章引用的 GaryBikini/ChinaAdminDivisonSHP 最新 release 为 `v24.02.06`。2026-10-22 检查 master 树 `ae72417fee2a63f453e6b2717e40655e87e26887` 的 DBF 属性，得到：

| 层级 | 条目数 | 覆盖情况 |
| --- | --- | --- |
| 省级 | 34 | 包含台湾、香港、澳门条目 |
| 市级 | 372 | 台湾、香港、澳门各以整体条目出现，不能当作统一地级市制度 |
| 县区级 | 2877 | 香港 18 区、澳门 8 个单元；台湾仍只有整个台湾的 1 个条目 |

**该仓库不能单独满足全国各地区完整下钻到县的目标。** README 明确说明缺少详细海陆边境线，且实际坐标为 GCJ-02，文件声明为 WGS84。不能直接与论文经纬度混用。当前核验覆盖属性层级和源说明，未完成全部行政多边形的拓扑及边界真实性审查。

Zenodo 本地包另外提供一个含 4395 个部分、627166 个顶点的国土面，以及 10 条海上断续线，声明 WGS84。它们能提供论文原图的制图参照，但没有省、市、县层级属性。包围盒覆盖岛屿区域不能替代逐区地图完整性核验。

实施采用分离图层：世界陆地和地理背景、中国国土及必要边界表达、省市县行政边界、方言观察数据。中国完整性验收包含台湾、港澳、海南、主要岛屿和南海显示，以及不同缩放级别与导出后的保留情况。

- 世界地图首选 Natural Earth 公开领域数据；仅作为地理背景，不凭世界底图自动引入另一套方言数据。
- 中国详细行政边界优先检查天地图等明确来源的完整数据，补齐台湾市县层级、行政区版本和坐标依据。GaryBikini 数据可作为历史候选对照，不能以县级覆盖完整的名义直接启用。
- 以一个标准坐标系统保存科学地点。源坐标系不明时标记待核，不凭几百米偏移直接修改原调查位置。
- 地图更新版本与调查年份分别保存。撤县设区、县市合并和同名地点通过映射表处理。
- 完整底图是 EXE 验收条件。检索、表格、原书映射和论文结果页面可以先推进，不把未补齐层级画成虚假的县界。

## 4. 用户进入模块后的操作

模块名称暂定“语言地图”，内部编号 M19，入口放“文献与学习”。主页面提供“语言特征”“方言分布”“论文结果”“我的地图”四个工作入口，共用地图、选区和表格。“方言分布”直接打开井韶子的整理成果，无须先选 Zenodo 特征：

```text
语言特征 / 方言分布 / 论文结果 / 我的地图
世界 / 中国    地点或语言特征搜索    当前区域路径    对照 / 编辑 / 导出
┌─────────────┬────────────────────────┬──────────────┐
│ 语音 / 词汇 / 语法 │                        │ 当前图例与释义 │
│ 搜索与主题目录      │        交互地图          │ 地点资料卡     │
│ 近期项目 / 收藏     │                        │ 原书与论文来源 │
│ 行政区、方言区图层  │                        │ 比较篮         │
├─────────────┴────────────────────────┴──────────────┤
```

面板可缩放、收起。切换模块或切换特征保留视野和选点；重开工程恢复状态。普通界面以名称和可执行动作表达功能，原始字段编号放到详细资料中。

### 地图缩放和地域选择

- 支持滚轮缩放、拖动、双击定位、搜索跳转、适合当前选区和回到全国。
- 世界与中国视野各记忆一次。世界模式仍能查看这 930 个点，也可承载用户导入的其他国家调查点。
- 中国范围提供“全国 → 省 → 市 → 县 → 调查点”路径。既能逐级点击，也能直接输入怀宁、古田等地点。
- 边界、标注、调查点按缩放级别逐步加载和避让，县界不在全国视图一次性密集绘制。允许用户固定显示某一级边界。
- 密集调查点支持展开和选点列表。同县多点、多方言点维持各自身份，不合并成一个城市标记。
- 点击行政区可选择“定位到此处”或“筛选此区域”。仅缩放不自动改变统计分母。

### 510 张特征地图

目录分语音、词汇、语法三个入口。保留原书图号和顺序，另增加经核对的主题标签，不能用猜测分类替代原书。

| 入口 | 用户可以做什么 | 已从原书确认的示例 |
| --- | --- | --- |
| 语音 | 按声母、韵母、韵尾、声调、分合关系、例字和已录入的 IPA 检索 | 图 1 调类的数目；图 117 撮口呼韵母；图 120 阳声韵尾的演变；图 123 入声韵尾的演变；图 136 歌—过韵母异同；图 168 三—山韵母异同 |
| 词汇 | 搜索一个概念，查看不同词形和词根类别的地理分布 | 图 1 太阳 |
| 语法 | 按原书项目检索人称、构词和语法表达，显示类别及并存形式 | 图 1 第一人称单数代词 |

选项目后立即更新地图、图例和统计，不增加重复的“生成地图”按钮。主类可用颜色，亚类辅以符号，提供完整类别与主类概览两种粒度。原书配色和清晰配色可以切换，类别颜色不随地域筛选重排。

点击图例仅高亮/筛选相应类别，并显示地点数。多变体点使用兼有标记与展开列表，列出原始顺序和释义。某项的缺失、待核和未调查分别显示。

“某个韵母在不同方言中的类别”通过原书项目、例字及分类规则呈现。只有原书提供并完成核对的音值才显示 IPA，不把 A1 等分类号自动翻译为某个发音。对以分合关系为单位的地图，显示原关系和条件，保留文白、声母条件等必要说明。

### 点选、框选和多图比较

- 点一下地点：显示原调查名、经纬度、所属行政区域、当前特征的类别/释义及来源。可展开完整 510 特征表。
- 将 2—8 个地点加入比较篮：默认展示不同项目，也能切换全部项目、只看语音/词汇/语法。点击差异项目切回地图。
- 框选或画区域：地图和表格同步选择，可保存研究区域。类别频数明确计数对象是调查点，兼有类别可能使类别计数之和大于点数。
- 两图或四图并排：选择不同特征，视野和选点联动，图例独立。适合比较鼻音韵尾与入声韵尾，或同一范围的语音、词汇、语法图。
- 对一个点选择“查看论文中的相近地点”：按原距离矩阵排序，并可查看所比较点的特征详情。默认显示距离，不把数值描述为互通程度或人口相似百分比。

## 5. 让论文的分析结果可以探索

“论文结果”是与特征地图互通的视图，直接利用现有文件，先忠实展示作者保存的输出。

| 论文材料 | 交互形式 | 数据约束 |
| --- | --- | --- |
| MDS d1/d2/d3 | 三维度地图切换、二维散点图与地理选点联动 | 用附带坐标；维度不自动命名为某种语言学因子 |
| MDS RGB | 查看综合地理渐变、点选读出三维坐标 | 色标按全部 930 点固定；筛选省份不重新归一化 |
| FCM C=2…10 | 拖动类别数，查看各点类别变化；切换 Type I 与 Type II 过渡区图 | `cn_tax.csv` 没有完整隶属度矩阵，只显示已有 sharp/heat 类别，不能捏造混合百分比 |
| 主距离矩阵 | 选点查看相近地点、所选点子矩阵、热图与地图联动 | 用完整特征条件下的论文原结果，保留 S 编号映射 |
| 四种权重设置 | 同一选点下切换方案，比较邻近次序和距离变化 | 标明论文方案 A—D 的依据，读取已有矩阵；不重新训练模型 |
| 绘图颜色表 | 对照论文颜色与交互高亮 | 主色固定，高亮不改写原类别颜色 |

论文使用的 Voronoi 区域可作为可选显示模式，称“最近调查点示意区”，与原始点图随时切换。它不代替真实方言边界。没有调查点的大片区域不自动被最近一个点填成已知分布。

## 6. 井韶子整理数据的独立工作入口

井韶子的整理数据与 Zenodo 同为第一版的核心交付。界面明确显示整理者、原书、整理数据版本和原始表位置；原书作者与数据整理者分别署名。两个文件属于同一整理成果，不因 CSV/XLSX 双份存储而重复计算。

| 工作方式 | 实际操作 |
| --- | --- |
| 从地点看方言 | 点击省、市或县，显示当地完整分类清单和下属地域；同县多个方言保留多条记录，点击任一分类高亮相关地域 |
| 从方言找地域 | 展开“大区 → 区 → 片 → 小片”分类树，地图定位其分布，并列出涉及省市县和整理记录 |
| 方言岛浏览 | 单独查看方言岛清单，切换显示已核对的岛记录；与主分布并存，缺少精确位置时以所属行政区和文本说明呈现 |
| 地域多样性 | 比较省、市、县或自选区域，切换统计层级与纳入方言岛的口径；地图和排序表联动，点击数量展开实际计入的完整分类路径及出处 |
| 整理表工作台 | 搜索、筛选、定位原行，查看原值与校订记录，批量修改先预览；保存用户工程及导出整理表 |
| 与特征图联动 | 在已匹配的地点上叠加某个韵母/词汇/语法项目，查看同一方言片内部差异，或一个特征跨方言片的分布 |

县级分类表用于按“方言大区 → 区 → 片 → 小片”筛选及浏览。一个县有多个类别时展示并存列表、分布标记或纹理，不任选一条填满全县。

图层命名区分“县级方言归属”和“方言边界”。当前表只提供归属，不能据此宣称恢复了原书的精确边界。方言岛可单独开关；缺少位置或范围的记录在县卡片列出，不虚构村镇位置。需要精确边界时另行引入有来源的矢量区划。

选中一个片或小片，可以高亮对应的已确认调查点，同时查看该范围内某个语音、词汇或语法特征的分布。不同来源间的地点对应保存匹配方式、版本和人工确认状态。

地域比较是第一版正式功能，不预设省份名次。每次统计固定来源版本、范围、层级、重复项处理与岛记录口径，按完整分类路径计数，并让用户打开实际计数清单。分类条数、不同类别数、有资料的行政区数和 Zenodo 调查点数分开显示。无人口/使用人数数据时不计算人口加权的多样性。跨书比较保持各自分类体系，不建立未经论证的等同关系。

整理表中的“方言区+方言岛”“方言区”“方言岛”分别保存源表身份。由于三表存在实际差异，首轮保留可选原表视图，先形成差异清单，再建立经核对的合并视图与岛开关。未确定的记录只进入有明确口径的原表统计。

## 7. 用户编辑、保存与导出

- 用户可增加调查点、修改名称与坐标、填写 IPA/类别/备注、添加自定义特征、关联本地录音和文献。
- 支持绘制研究区域、标注线、文字和自行提出的分界；用户图层可与文献图层一起查看。
- 编辑保存为个人项目中的覆盖记录，原始资料可随时回看；撤销/重做、批量编辑预览和恢复原值是基本能力。
- 导入 CSV/TSV/XLSX 时先选地点与坐标字段、特征列、类别释义和坐标系统，预览后导入。重名地点不靠名称单独合并。
- 工程文件保存数据版本、地图视野、筛选条件、个人数据和样式。原书通过用户选择的本地 PDF 关联，路径保存在本机设置中。
- 导出 PNG、SVG 和筛选后的表格；提供标题、图例、比例尺、调查年代、资料来源、字体/符号大小及南海附图设置。SVG 保留矢量线条和可选择文字。
- 对比地图支持统一尺寸、统一视野和拼图导出。输出附带特征、类别层级、过滤条件与数据版本，便于论文和课堂复用。

## 11. 首版范围与按需释义
