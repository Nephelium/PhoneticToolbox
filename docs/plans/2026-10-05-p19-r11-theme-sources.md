# P19-R11：逐主题来源与许可登记

日期：2026-10-05。井井授权补齐现有配色的各主题上游来源和许可。

## 范围与验收

- 对照 `frontend/src/design/themes.ts` 的 29 个 ID，逐项登记公开上游、作者、许可原文、固定查验版本、使用位置与适配关系。
- 保留此前从 Codex 截图和安装包元数据得到的历史来源记录。此次公开上游核对不能倒推为最初引入版本，也不能替代对历史获取方式的条款判断。
- 保存已取得的上游许可原文和 SHA-256。只有许可声明或公开同类实现的项目另列证据缺口，找不到明确许可的项目标待确认。
- 从既有单一来源登记生成应用软件致谢，并同步设置说明与审计表。配色值、名称、偏好和算法保持现状。
- 验证 29 项一一覆盖、记录唯一性、固定链接和许可哈希、应用生成数据一致性、受影响前端检查以及文档本地链接。未决许可不标为已取得授权。
