# M10-R13 轮廓连接修复

状态 verified，限 Windows 当前源码与实际 Qt。井井明确要求修复 R12 后卷舌尖尖角及小舌上方残余尖突，结果见[验证报告](../testing/2026-10-07-m10-r13-report.md)。

定位：舌叶实际控制点改变了原切线方向，舌尖圆弧只有少量等弧长采样；软腭背侧过早向硬腭转弯，与口鼻连接面之间留下假凹口。初次尝试调整鼻腔连接切线未消除凹口，并在 /i/ 大开口出现交叉，已撤回该尝试。

实现范围：原生舌叶端点切线连续、稳定辅助切线高度、后卷舌尖采样及腹面回接；显示软腭背侧以两段相切曲线连接到腭咽口前缘与硬腭。保留牙齿刚性、声门常驻、原始鼻腔资源、原始 VTL API、speaker 及数据格式。原生构形变动同步进入声管，显示连接不改变鼻腔声学参数。

验证：放大二维/三维截图、曲线转角及连续性、轮廓自交与牙齿约束、R12 连续控制和保存回读、前端必需检查、来源及资源摘要。不开新 EXE，不扩展为医学或听辨验证。
