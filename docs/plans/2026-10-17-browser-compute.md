# 浏览器计算迁移实施计划

2026-10-17，井井明确授权按语谱图、参数表、EGG的顺序，将适合的计算下放浏览器，保持计算结果，继续仅本人私测，并在服务器网页版验证。

**目标：** 减少交互时的服务器科学进程与网络往返，保持现有算法、时间网格、单位、缺失值和资源/账号边界。

**架构：** 新增平台层有界Worker执行器，优先运行现有core和相同版本的上游算法。Vue只传输入和契约，不承载算法。运行库同源、按需加载，页面退出销毁进程内数据，不把研究数据放入持久缓存。未通过原有科学门槛的操作继续使用原服务器执行器，不伪称已迁移。

**取舍：** 采用同源Worker/WASM及现有Python核心的复用方案；不采用独立重写近似FFT/滤波和跨平台原生二进制直接运行。先查证版本、许可和编译条件，再决定每条操作是否具备可交付的保持科研语义的实现。

## 1. 原生可行性和基准

- 固定当前perf1运行时与合成输入，保留完整响应和科学数组基准，不读取井井会话或研究文件。
- 查证Praat/Parselmouth 0.4.7原始源码、Pyodide及数值依赖版本。工具链只放本任务目录，不改全局环境或CI。
- 语谱图首先覆盖公共预览与录音两个不同的Praat取窗规则，不能互换。

## 2. 公共执行器与语谱图

- 新建core browser适配与构建脚本，构建输入可追溯，生成输出带SHA。前端platform层管理单Worker、有界队列、取消/超时/代次、账号退出和错误回退。
- 语谱图仍调用相同版本Praat，Python灰度及时间网格复用原core。验证采样率、声道、静音/噪声/多频/短选区/边界和重复缩放。
- serverFiles与录音live/saved预览优先浏览器；文件首次读取与身份校验保留，重复使用仅限同账号/项目/资产摘要。

## 3. 参数表

- 在Worker运行原legacy_parameters/parameter_exports/limits读取器，XLSX用相同openpyxl，SQLite只读内存。
- 与服务器逐项精确对照列顺序、类型、null、Infinity、TextGrid文本、Unicode和SHA；公式、外链、异常结构、输入预算保持拒绝。

## 4. EGG及其他候选

- 先测相同core及冻结数组，保持旧版重复局部滤波与时间边界。井井已明确允许微小浮点差异，浏览器按数组精度记录容差；保留旧原生精确回归。整数窗长、采样率、声道、形状、NaN掩码与算法语义仍须相同。
- 按相同标准检查录音剪切/声道/增益、图片预测及重建。已在浏览器的绘制、采集和唇形推理不重复建设。
- 原生VTL、REAPER、长批次及大模型按实际可移植性保留服务器路径，不能替换算法或放开MFA线上推理。

## 5. 服务器验证与交付

- source-registry及许可、资源manifest、架构/契约、类型/测试/build、文档/台账同步。
- 冻结候选后先验证实际Linux服务器九类科学能力仍保持，再部署本人私测。从实际HTTPS页面测试浏览器真实计算，与真实服务器基准对比，记录请求次数、取消、CPU节流/弱设备、浅深主题。
- 官网入口/注册/找回仍关闭，仅nephelium有效，不新增测试账号或读取现有会话。回退保留，不推送、不重打桌面成品。

## 6. 当前执行分工与服务器保护

按需复用原core的公共/录音语谱图、SQLite/XLSX参数表、EGG交互、CNN参数预测、录音编辑/增益/降噪/导出，以及小型GL和图片/音频涂鸦。交互与重建各使用独立串行Worker，避免重建阻塞滚轮；重建四个结果和恢复记录经原受管资产API保存，沿用工作区期限，不在服务器伪造运行任务。

小型重建门槛为设备报告至少4线程/4 GB，时长不超过5秒、GL不超过64次、图片不超过1 MB或音频WAV不超过4 MB及配置16 KB。超预算、原生VTL/REAPER、长批次、尚未移植的原生算法保留服务器；MFA/神经重建原网页准入不扩大。CNN接近半整数窗长时转回服务器，自动GL同样先执行取整检查。核心ZIP和Praat WASM以固定SHA校验并带版本查询参数。

2026-10-17追加井井明确要求的CPU隔离。实际服务器2核，P11所有科学任务进入ptbscience.slice，合计CPUQuota=100%，进程亲和性为CPU 1；生理合成在启动原生线程前按管理员配置同样绑定CPU 1。API自身保留两核可调度范围和较高CPUWeight，避免它与自身声道子进程共享的配额阻塞网页，批任务仍只有一个计算槽。配置针对本次2核部署，不作为任意服务器默认。

登录与工作台先显示，不再等待11张图标素材共21,867,453字节下载并裁剪。先异步加载当前图标，完整31图标在图标设置激活后按两条通道读取；桌面保持启动时完整加载的既有视觉行为。

## 7. 首轮c2交付边界

c2已完成九类Linux回归并私测激活，36组浏览器科学对照、41组二进制解码及实际HTTPS前端合成账号/存储夹具流程通过。账号仍仅nephelium，公开入口/注册/找回关闭。详细指标、压力测试失败边界与各模块计算位置见[验收记录](../testing/web-private-repair.md#浏览器计算迁移与cpu资源隔离)。

国际音标Plus、汉字转国际音标、感知实验的前端处理原已在浏览器。首轮没有迁移音系归纳的表格解析、归纳和文档生成，已在下节追加迁移，也没有迁移其余批任务的主要计算，不能把页面编辑与绘制等同于整个模块的计算下放。后续迁移候选须继续复用同一读取器/算法并通过真实服务器科学对照。设备/跨浏览器、真实账号项目和长期多用户容量仍需共同测试。

## 8. 追加迁移实施

井井明确要求继续迁移音系归纳和其他适合计算，允许微小浮点差异，继续仅本人私测并在服务器网页验证。沿用现有同源Worker，不新建算法或HTTP计算入口，原服务器为不可用时的回退。

1. `scripts/prepare_browser_science.py`加入锁定的pandas/lxml、python-docx 1.2.0及xlrd 2.0.2，补完整许可和来源。`browser_compute.py`固定入口复用`m14_jobs.execute`及原请求模型，保留所有输入/输出预算。
2. `platform/browser-m14.ts`包裹原M14Port：原上传和身份检查保持，inspect/preview/export改用Worker，三份结果经原受管上传保存；取消不触发回退，过期资产拒绝，下载校验/页面设置/源码桌面端口保持。定向测试取消、失败回退、保存失败和源身份。
3. 检查并迁移M06元音生成/有界Klatt合成，复用`m06_child.compute`，参数导出、随机种子和lib整型转换保持；提取所需尚未移植的Praat/REAPER不改算法。检查LPC原core与完整输出/字体链路，满足同算法对照后接入，未通过时不标迁移。
4. 用真实Linux生成CSV/GB18030/UTF16/XLSX/XLS/DOCX、多工作表/列映射/Unicode/归并顺序等合成基准，逐字段对照归纳结果、解包DOCX/XLSX内容和格式，不以压缩时间戳作科研差异。M06固定同seed比较PCM/曲线/谱栅格；LPC比较时间边界、数值、标签和导出。
5. 类型/定向测试/构建/来源/架构/文档通过后冻结c3，先验证服务器九类科学回退能力，再激活并在实际HTTPS页面运行端到端。保持nephelium唯一有效账号，官网入口/注册/找回关闭，CPU隔离保持，保留c2回退，不重打EXE或公开发布。

本节已在c3-r2私测交付，31组真实HTTPS科学比较及各模块独立首次启动、实际前端受管导出/恢复通过。新读取器实测约18 MB，Pandas/NumPy按实际功能加载。当前环境、旧v2基准的既有失败及跨平台未验边界见验收记录。构建运行库需提供与服务器同SHA的Noto Sans SC字体/OFL目录：`python scripts/prepare_browser_science.py --output <网页运行库目录> --render-font-directory <已核对字体目录>`，既有输出目录可复用已验证字体。工具链/库/字体缓存不进入桌面成品或Git。
