# M12-R4：长 WAV 轻量读取与时间轴位置

2026-09-15，井井授权直接修改并生成新 EXE，明确要求本轮不做验证。

范围：桌面 M12 的音频读取适配、保存来源核对、秒数刻度位置和独立 R4 单文件包。原 WAV、TextGrid、旧 EXE 保留。沿用当前工作树与 m09-ui 项目环境，不推进其他模块。

实现约定：

- 原生文件能力继续核对授权目录、句柄身份和文件版本。仅 M12 大 WAV 使用有界分块预览，输出 PCM16，取第一声道，并选择不高于原始采样率且满足 64 MB / 3200 万采样值预算的最高常用采样率（最低 8 kHz）。小文件保持原读取方式。
- 重采样使用既有 SoundFile / SciPy 依赖，抗混叠滤波、相邻块上下文和共同样本时间原点。原始时长独立传给前端，避免重采样尾部不足一个采样点导致 TextGrid 时间范围校验失败。
- 前端持续显示实际预览采样率、位深和声道。波形、试听、语谱及强度贴合使用预览样本，原录音不写回。原 SHA256 按块计算，首次无 TextGrid 保存也能核对大 WAV 来源。
- 将波形秒数刻度移到词/音素标注层下方，保留时间窗起点滑块位置；其他模块默认时间轴位置保持。
- 包装为 `dist/m12-preview-r4/PhoneticToolbox-v3-M12-R4.exe`。只执行前端构建、项目 wheel 构建/安装和 PyInstaller 打包，不执行测试、音频试读或 EXE 启动检查。构建状态与未验证状态分别记录。
