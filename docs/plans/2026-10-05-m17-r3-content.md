# M17-R3：介绍定位、播放接口与内容维护

日期：2026-10-05。当前状态：verified，限定 Windows 源码和定向验收，见[报告](../testing/2026-10-05-m17-r3-report.md)。授权为井井本轮音标表修改请求。

- 浮窗在当前符号及指针附近，优先侧向放置，空间不足时上下避让。保留进入浮窗阅读、滚动、右键和 Alt+Enter。覆盖边角、搜索、大字号、浅深色与页面缩放。
- 清理聊天图片编号、用户指定及名称优先规则等过程说明。保留科学含义、码位、文献书目、具体页码。条目身份、输入字符、矩阵和固定字体保持。
- 顶部提供默认关闭的点击播放开关。开启后符号激活只播放，不修改文字、选区或撤销历史。缺少素材明确提示，不回退输入。
- 每项内容另存源码 JSON，支持文字、补充说明、项目内音频/视频路径和版本化实时动画配置。普通应用只读。媒体仅在主动播放时载入。实时动画预留可注册渲染器接口，本轮不制作声道动画、不将示意运动作为科学实现。
- 本机内容维护工具复用 Vite 开发环境，单独启动并绑定回环地址。会话访问凭据、同源检查、定向文件写入和并发版本核对保护保存。编辑页面和写入服务不进入普通构建，不增加产品后台或账号权限系统。
- 验证类型、前端测试、生产构建、目录生成一致性、实际 Chrome、隐藏原生 Qt及维护工具实际保存/重开/错误边界。未打 EXE、部署、push、DDL、安装依赖或修改现有用户数据。
