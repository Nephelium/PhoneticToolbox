# 唇形提取与语音标注对齐小幅修订设计

## 范围

- 不改变唇形参数算法、TextGrid 编辑模型和现有文件格式。
- 修清两个直接影响数据可靠性的交互细节：唇形偏移独立保存状态、pkl 安全写回。
- 说明书第 7、13 章只使用真实录音及其真实唇形数据截图；原始语料只读，截图从副本生成。

## 设计

1. 网页编辑器分别维护 `dirty`（TextGrid）和 `lipDirty`（唇形偏移）。切换文件和每分钟自动保存时，两者分别保存；任一失败都保留当前文件并明确报错。
2. `save_lip_offset` 先在 pkl 同目录写入临时文件，完整落盘后用 `os.replace` 替换原文件。写入失败时保留原 pkl。
3. 唇形偏移对话框把“应用并保存 / 不应用直接保存”改成更明确的“应用偏移并保存 / 保存但不应用偏移”，并在提示中说明后者保存为 0 ms。
4. 网页曲线图例改为中文；说明书删去“任何档位都不会拖慢”等绝对表述，补充偏移值的含义、自动保存边界和数据备份建议。

## 验证

- 服务端测试覆盖 pkl 原子写入失败时原文件不变。
- Qt 测试覆盖偏移对话框按钮含义及两个保存分支。
- 浏览器实测 TextGrid 与唇形偏移的独立保存、切换文件和自动保存路径。
- 用真实语料副本重做图 7-7、图 13-1，并检查导出说明书的高 DPI 页面。
