# P18 / M17-R1 视觉统一与音标扩充

日期：2026-10-03。状态：verified，限定 [联合验收报告](../testing/2026-10-03-visual-and-ipa-report.md) 中的 Windows 开发态及 WSL 目录生成范围。

## 本轮授权

井井明确要求开始调整各模块的布局一致性，并扩充国际音标 Plus 的 IPA / extIPA 及中文说明。允许使用 `C:/Users/13680/Desktop/project/音频数据` 内的真实音频验证，原材料只读。两个子代理分别负责全局排版与 M17，秋叶统筹规范、集成检查及交付。

## 设计与文件边界

- P18：保留 U2 蓝白 / 蓝灰主题与公共字体。统一三栏默认宽度、外轮廓、卡片间距、控件高度、文件操作及帮助/方法入口的位置。二栏页将操作栏放左侧。用户拖动后的宽度记忆继续有效，内容超长时在对应栏滚动。
- M10 声道工作台排除本轮视觉改造。M17 排除公共改造，只调整已指定的音标目录、附加符号和中文解释。
- M17-R1：核对用户 iOS 截图可辨识内容及吕佳 PDF。采用独立的现有工作台设计，不复制第三方界面图像。区分基本表项、组合示例及非标准符号，保留实际 Unicode 输入和来源；VoQS 的既有指定译名保留。
- 主要代码：`frontend/src/components/`、公共布局/样式和 M01–M09 / M11–M16 页面；M17 独立限定在 `frontend/src/modules/ipa-plus/` 和对应目录、来源、验证资料。
- 保留分析算法、参数单位/科学默认值、图窗/选区/任务语义、所有既有功能。此次不包含现存数据库迁移、全局依赖安装、EXE 打包、push 或公开发布。

## 验收

1. `npm --prefix frontend run typecheck`、`npm --prefix frontend test`、`npm --prefix frontend run build`，来源生成及检查按 M17 实际变化执行。
2. 独立 Chrome 浅深色、多尺寸空态与加载态验证：侧栏默认宽度、位置、栏底对齐、按钮尺寸、文本换行、内滚动和拖动/恢复。
3. Windows 实际 Qt 对最终构建执行代表页面与 M17 符号/编辑框验证。只使用当前任务拥有的隐藏/offscreen 测试窗口，避免桌面弹窗。
4. 真实音频从本轮授权目录挑选，记录来源哈希并保持只读。验证 UI 加载和交互不宣称重新证明科学算法。
5. 核对 M10 / VoQS 排除边界及 IPA 非 BMP / 附加符号的插入、撤销、保存，检查新增中文解释与资料依据。
6. Windows、WSL、浏览器模拟尺寸、实体 DPI/音频硬件分别报告。截图不替代功能证据，不将旧验证直接扩大为新范围。

井井同轮追加要求附加/韵律内容平常仅显示名称与符号，解释悬浮显示，并采用紧凑多列及清晰上下滚动。已纳入最终构建并通过Chrome和实际Qt复验。

详细设计与证据分别记录在 [P18排版报告](../testing/2026-10-03-p18-layout-report.md) 和 [M17扩充报告](../testing/2026-10-03-m17-expansion-report.md)，联合报告汇总最终实际结果及既有文档检查问题。旧EXE未更新，后续EXE打包和实体硬件/跨平台完整验收不在本次授权中。
