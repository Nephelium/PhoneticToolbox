# M03-R7 长录音与 10 秒逆滤波 Implementation Plan

**Goal:** EGG 工作台支持最长 1800 秒、8–96 kHz 双声道 WAV，逆滤波选区最长 10 秒，长文件按需计算且不将原始录音整段传入浏览器。

**Architecture:** 保留旧短文件科学路径。长文件流式输入，全局扫描两声道峰值和线性趋势，科学核心通过数组读取端口按 20 秒块及重叠上下文计算。会话缓存有上限。时间索引按全局采样点生成，四图仅读取当前视窗，试听传递原采样率选区。长文件实时 F0 仅计算当前视野并缓存，完整 F0 和导出按块执行，长路径使用独立方法版本并记录边界差异。

**Tech Stack:** 已有 Python / 原生 RIFF 流式读取 / NumPy / SciPy / Parselmouth（宿主既有 SoundFile 用于输入登记） / 原生 REAPER / Qt / Vue / 版本化契约，无新全局依赖或数据库 schema。

状态：verified，限定 2026-10-07 Windows 本地源码、实际科学子进程及 Qt 的合成输入范围，见[验收报告](../testing/2026-10-07-m03-r7-report.md)。用户于本会话批准上一轮 30 分钟方案，并追加 10 秒逆滤波。保留同期修改，不打包、发布、push、迁移数据库或读取未授权自然语料。

## 实施与验收

1. `phonetic_core/egg/bounded.py`：全局预扫描、虚拟时间/信号数组、滤波缓存、事件及 F0 块归属。测试全局峰值/趋势、块接缝、缺失周期和尾端。
2. `ptb_worker/egg_recording.py`、实时会话与本地预览接口：流式源文件、受控临时目录、轻量总览、选区试听、实际原采样率元数据、退出/取消回收。输入仍同时受 2 GB、1800 秒、8–96 kHz 双声道约束。
3. 长文件任务：输入与结果分块传输；数值轨迹及 pandas 外连接表受固定最长时长和结果预算约束，CSV 仍在科学子进程内序列化。全段图采用有界读取，不分配全长 PSD 或逐采样绘图数组。新本地清单 m03/2 允许最多 256 MB 结果集，大 CSV 原生流式保存，显示文件仍限 64 MB。保留原科研时间网格，显示压缩单列来源。
4. `EggTaskConfig` / IF 核心：10 秒及 960000 帧，按 LPC 所需滞后计算自相关，完整 WAV 原采样率输出，显示数组有界。测试 10 秒边界、超限、96 kHz、静音/短周期和旧短结果。
5. M03 页面：原始采样率与时长校验，长总览与原采样率选区试听的全局坐标，末尾导航、最新请求胜出、导出与旧结果恢复。更新生成契约和说明。
6. 执行受影响 Python 回归、前端 test/typecheck/build/contracts 检查。用自建短/30 分钟合成输入测试实际科学子进程、内存/时延、Qt 四图/参数/试听/10 秒 IF/保存回读；报告实测范围和未测项。

命令：`.venv/m09-ui/Scripts/python.exe -m pytest` 定向核心/接口/桌面回归；M03 锁定科学环境运行实际计算；`npm --prefix frontend run typecheck` / `test` / `build`；`scripts/generate_contracts.py` 与前端生成；`scripts/manual/validate.py` / `build.py`。

补充验收：长路径的全局及局部滤波均使用 SOS 形式，局部 CQ、微观事件及波形保留各自 padding 规则。96 kHz / 1 Hz 高通须保留有界波形及合理周期，短路径冻结回归须不变。
