# M03-E3 字体预检

井井授权继续。仅补齐 EGG 导出字体预检，不修改科学核心、数据库或发行环境。

复用现有 jobs 的本机令牌/Origin 与服务器会话/CSRF，新增只读字体快照检查。使用同一 EGG 兼容 Python、固定 bootstrap 和字体解析器；Windows Job 限制进程 1 GB、20 秒，单进程一个预检槽，繁忙立即返回。请求只有有界字体名和字号，不读取音频、创建持久任务或接收路径。结果只含请求字体、可用性、实际家族与摘要。

单文件三图和批次带图在提交前冻结字体并检查；纯 CSV、交互分析、IF 不依赖后台图中文字。缺失时显示角色和字体名，批次保留选择、参数和原处理记录。预检只证明当时的环境，执行时仍在科学计算前严格复核，重试保持原任务快照。

预计修改 backend 字体模型/解析器/受控预检/路由、desktop TaskBridge、frontend 平台接口与 EGG 页面和批次提示、生成契约与文档。验收：字体解析/缺失/鉴权/资源回收测试，真实兼容进程，Chrome 与 Qt 的导出/缺失提示；前端 test/typecheck/build，contracts:check，文档及架构检查。完整 M03 与全平台字体专项仍 in_progress。
