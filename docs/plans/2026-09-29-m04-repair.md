# M04-R1 LPC 失败与选区、窄栏修复

2026-09-29，井井明确授权修复 LPC 全部失败、波形左键拖选、常用操作移入左栏及关联缺陷。状态：verified（限定本轮 Windows 源码 / Chrome / Qt / 自然文件，详见[验证报告](../testing/m04-r1-report.md)）。

## 已定位原因

截图对应自然 WAV 为 169728 帧 / 44100 Hz，即 3.848707482993197 秒。关联 TextGrid 的两个层有空白尾段延伸至 9.085419501133787 秒。任务将全部区间一律与 WAV 长度比较，导致任何合法内部 ROI 都被 `lpc_textgrid_range` 拒绝。原始文件只读，路径与哈希保存在忽略的本机验证证据。

## 变更边界

- `backend/src/ptb_worker/lpc_child.py`：空白区间不承载标签，允许位于音频外；非空标签的范围仍按现有一个采样点边界检查。不改源 TextGrid，不改核心求解、标签拼接规则或样本映射。
- `frontend/src/modules/lpc-spectrum/{LpcSpectrumPage.vue,state.ts}`：直接左键拖选，标注点击取区间与音频的交集，提示空白越界；时间、参数、提交/取消和试听移入左栏。保留既有可调栏宽。
- 测试：`backend/tests/test_m04_exports.py`、`frontend/tests/lpc-state.test.ts`、`tests/e2e/m04.cjs` 及本机自然文件只读复验。补关联输入与迟到错误的回归。
