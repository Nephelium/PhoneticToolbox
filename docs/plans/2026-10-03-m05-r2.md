# M05-R2 本地实时录制修复

状态：verified，限定 [M05-R2 报告](../testing/2026-10-03-m05-r2-report.md) 的 Windows 源码/合成采集范围。2026-10-03，井井报告误选立体声混音、直接保存入口不清楚，并要求放大面部动画。

## 授权与实现边界

修改 M05 采集、页面、网格显示、录制导出和定向测试。保留工作区已有差异。优先本地保存，不部署服务器、不修改现存数据库、不打包或推送。科研指标、滤波和模型不变。

1. 默认自动选择名称可识别的麦克风，授权后重新枚举。显式选择保留，失效设备报错，禁止静默改用其他设备。显示实际音轨名称和实时电平，缺少音轨拒绝录制，低信号给出可操作提示。
2. 停止后直接保存 MP4、WAV、实时唇形和完整计时记录。保存完成允许另存，增加录制直接回放。不依赖离线分析任务。
3. 配套 `audio_recording.lip.json` 允许下游自动关联，保留候选副本与方法来源。安全格式增加可选、有界的 `source_backend` / `source_status` 字段，旧格式不受影响。实时模型仍为 browser Face Landmarker candidate，不标成 V2 legacy 等价结果。
4. 独立网格动画按结果脸部范围居中放大，同一结果使用固定变换。相机叠加保留同帧原坐标，不改变科研数据。

## 交互决策

离线 legacy 分析作为获取旧模型逐帧结果的可选步骤，与保存解耦。实时保存的格式互通不等于模型等价。本轮不引入原生实时 legacy 推理这一独立架构变化。网页算力问题单独解释，不自动迁移其他模块。

## 验收

- `node --test frontend/tests/m05*.test.ts`、`npm --prefix frontend test`、`npm --prefix frontend run typecheck`、`npm --prefix frontend run build`。
- 既有 `.venv/m05/Scripts/python.exe -m pytest -c tests/pytest.ini` 执行 M05 导出/时间轴/基线及新增回归。核对实际 WAV 样本、电平、媒体帧时间和配套文件方法来源。
- 独立 Chrome 与实际 Qt：合成设备、自动/显式输入、权限/缺轨、低信号提示、停止直接保存/另存/取消/继续、自动关联、浅深色和网格放大。
- 仅使用公开 fixture / 合成输入。实体麦克风的人声、物理同步、DPI 与 Linux 媒体链另列，不能由合成测试替代。
