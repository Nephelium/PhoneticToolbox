# Preview 更新、安装与本机存储交付计划

状态：in_progress。井井于2026-10-05授权在全部说明书完成后修改、验证并上传服务器，明确暂不上传GitHub。服务器凭据仅用于当次连接，不写入工程、日志或产物。

## 交付顺序

1. 各模块独立代理完成说明书与README，主代理统一图音、格式、引用和实际最大化窗口截图。M10正文空白，M05视频待作者录制，M15已定稿。
2. 接入启动检查与手动检查更新，双源查询版本、正确比较Preview次序，询问后下载，校验大小与SHA-256后升级。
3. 固定用户数据路径，沿用已有设置和工作台存储。免安装与当前用户安装共用同一份兼容设置，程序目录更换不改变数据位置。
4. 本机清理新增超过期限的未导出结果及可重建缓存，保留录音、项目、标注、用户导出目录及进行中的任务。用户已明确选择此范围。
5. 构建并验证免安装包与当前用户安装包。现有本机Preview依赖外部科学环境，必须独立处理这些环境再交付，不能直接将旧本机包称为通用发行包。
6. 在服务器现有HTTPS静态站点下增加独立版本目录，先上传完整文件并核对摘要，再发布latest.json。旧包保留，Github不发布。

## 版本与更新协议

- 首版使用 `3.0.0-preview.1`。旧 `3.0.0a1` 按alpha版本兼容比较，不按字符串排序。
- 服务器站点为 `https://www.phonetictoolbox.com/`，清单路径预定 `releases/windows-x64/preview/latest.json`。
- GitHub读取 `Nephelium/PhoneticToolbox` 的Release列表，覆盖preview且忽略draft，不在本轮创建Release。
- 双源结果分别显示可用、无公开发行、错误和超时。最高可信版本决定更新，版本相同要求资产摘要一致。
- 国内优先服务器，其他地区优先GitHub。网络国家查询失败时使用系统地区作为后备，并可手动切换。GitHub尚未发布时使用服务器。
- 下载是后台流式写入，仅写入应用自己的更新目录。取消/中断不运行半包，下载完成须校验大小和SHA-256。升级前处理未保存编辑和正在运行的采集。
- 安装版启动当前用户安装程序完成更新。免安装版升级到新的版本目录，保留旧程序与共用设置，验证成功后再提供清理旧版本的明确操作。

## 安装与用户数据

- 每用户安装，默认 `%LOCALAPPDATA%/Programs/PhoneticToolbox`，无需管理员权限，生成桌面/开始菜单入口及卸载信息。
- 独立用户目录保存设置、Qt工作台存储、任务库和托管媒体。保留原v3已使用路径，路径与显示版本号和EXE文件名无关。
- 旧用户目录仅作兼容定位或备份复制，不删除或覆盖原数据。安装、更新、卸载不删除研究数据。
- 成品必须在非工程目录和隔离用户目录中验证启动、科学运行时绑定及更新后设置保留。

## 清理政策

- 默认未导出处理结果保留30天，设置中可关闭或调整期限。以本机已确认的时间记录为依据，旧记录缺少时间时首次登记保留期，不能推断为已过期立即删除。
- 成功保存/导出时标记该任务的导出状态，失败或取消不标记。正在运行的任务、其输入及任务链依赖不进入清理候选。
- 自动清理仅作用于本应用登记的托管目录和有身份校验的文件，不扫描用户磁盘或源语料目录。
- 临时文件、过期预览和旧更新下载可以独立清理。结果清理保留最少任务元数据并明确显示已清理，允许重新计算。
- 开启时定期执行，并在设置中显示占用、保留期、可清理范围和手动清理入口。清理失败如实记录，不把部分删除标成全部成功。

## 验收门

版本次序、双源失败、下载取消/损坏、安装路径/升级与设置保留、清理时间边界/导出状态/依赖保护/路径逃逸均需定向验证。全书结构、引用与私有媒体分发规则验证通过后，再冻结打包快照。仅服务器发布，实际HTTPS下载摘要回读后才更新发布状态。

构建中还要核对实际包含组件的许可文本、对应源码及总许可证，未核实项列明，不用Preview标签代替发行义务。
