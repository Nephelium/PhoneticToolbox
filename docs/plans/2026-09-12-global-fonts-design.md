依赖：P04共同工作台、现有平台偏好接口和各模块图像导出适配。对应R17、[UI_SPEC第2.1节](../design/UI_SPEC.md)、[ADR-036](../decisions/ADR.md)。不改变U2/K2、模块科学算法或现有历史验收结论，不在本轮安装字体、改数据库或打包EXE。

## 1. 初始设计的源码依据与方案选择（历史）

- `frontend/src/design/tokens.css`已有全局`--font`，等宽文字和IPA另有规则，IPA资源为已登记的ASSET-DOULOS。
- `frontend/src/app/AppShell.vue`已有主题设置与偏好读写入口，可作为统一字体入口的接入位置，尚无本计划中的字体设置。
- `frontend/src/modules/parameter-display/export.ts`会复制图中文字的计算样式，整幅PNG从独立SVG快照栅格化。需要补齐字体解析、加载、资源携带和排版验证，不能只改CSS变量。
- M03-C规划包括后台三PNG与批次图片，实际代码正处于另一项实施工作中。本计划只补充依赖，不把在途实现作为字体功能证据。

已比较三种方案：仅改全局CSS成本较低但无法覆盖独立导出；各模块独立设置会造成默认与行为分裂；采用统一字体角色和解析规则，各渲染端作有界适配。后者作为本次设计，布局、颜色和科学数据继续遵守原规范。

## 2. 设置与应用范围

| 字体角色 | 默认与候选 | 作用 |
| --- | --- | --- |
| 中文 | 默认现有系统无衬线；候选宋体、楷体、思源宋体 | 应用自绘中文控件、表格、帮助与普通标签 |
| 英文与数字 | 默认保留当前行为；候选Times New Roman等 | 普通拉丁文字与数字，中文标点随中文角色，科学符号单独验证 |
| 代码/等宽文字 | 默认现有等宽回退；候选Consolas、JetBrains Mono、Cascadia Code | 代码、显式等宽文本；默认关闭会合并代码符号的装饰连字 |
| IPA | 固定随包Doulos SIL 7.000，不允许替换 | 明确的音标字段、音标预览与标注，不被普通英文字体整体覆盖 |
| 图表与导出 | 默认跟随全局，可独立选择中文、英文及字号 | 所有应用图表及新生成图片，IPA固定Doulos SIL |

候选仅为名称与用户意图，不表示当前设备安装状态或发行许可结论。用户可以使用已安装且当前渲染端可用的字体，不强制只从内置的少量字体中选择。

设置在工作台提供可输入和筛选的字体候选、预览按钮、应用、取消与恢复默认。预览至少包含中文、`PhoneticToolbox 0123456789`、`[aː tʰ ɕ ŋ ə ã n̩]`、`−12.5 Hz / ɑ²`和一段代码，以及标明预览的坐标轴标签样例。样例标明预览，不产生假科研结果。

编辑设置只改变设置预览，应用后更新所有已打开页面和图表，取消保留旧配置。字体应用和恢复默认不丢失未保存编辑、选区、当前任务及播放状态。图表独立配置关闭后恢复继承规则；重新开启时明确显示将使用的配置。字号使用带单位的值，界面与导出在适配边界转换，不以PNG的dpi改变字号含义。

覆盖应用自绘导航、页面、表格、弹层、帮助和图中文字。系统原生文件选择框、系统标题栏及外部程序按平台能力处理，在设置说明中写明范围。旧PNG、既有导出文件和嵌入图片中的文字不被追溯修改。此需求不新增PDF导出格式，不改变CSV、音频或科研数据。

## 3. 字体获取、保存与渲染边界

前端通过公共字体角色/令牌与状态服务消费配置，不在各页写不同的候选链。混合文本需明确中文、普通拉丁、语义IPA与缺字回退顺序，不简单依赖中文字体同时覆盖英文的偶然行为。普通自由文本缺少语义时保留字符及组合序列，不能靠正则改写原始标注内容。

桌面由宿主提供受控字体目录信息，前端不能读取系统路径。网页提供预设和可用性状态，本机字体枚举只在平台支持且用户主动授权时使用，拒绝权限或不支持时仍可操作设置。无法可靠确认时显示无法确认，不把有回退字形等同于目标字体已存在。

偏好使用版本化的公共配置，保存候选标识、角色、继承方式和字号。旧配置缺少新字段时沿用现有默认。桌面存于v3独立偏好空间；网页按账号隔离，本阶段不承诺跨设备同步，不为字体设置新增数据库迁移。退出或切换网页账号后不得把上一账号的字体快照注入任务。物理字体路径只保留在适配器内部。

建议配置语义为`schema_version`、`ui.zh/latin/mono/ipa`、`figure.follow_ui/zh/latin/font_size`。这是设计字段，最终接口要在实施前与既有偏好/任务模型核对并生成契约，不据此手写第二套协议。

后台生成图片时由任务携带导出字体快照，记录请求角色、解析后的字体、替代情况、渲染器版本，以及可获得的字体版本或资源哈希。服务端不能假定浏览器安装的字体也存在于服务器。服务器提交前可用性预检仍随M03页面接入，当前不宣称已实现。现有适配在执行时精确解析，若不可用则返回font_unavailable，不静默改变字体或发布不完整结果。首期不自动上传本机字体。

渲染适配器负责字体解析及字形检查，科学核心只返回科学数据。Matplotlib等渲染器不得使用跨用户可变全局字体状态，应在应用拥有的隔离渲染上下文/子进程内应用快照。重试沿用原快照，用户主动使用新字体重新导出时形成新的导出记录。

## 4. 图片导出规则

字体加载并完成目标文本的排版检查后冻结配置与图形，字体切换或跨标签操作不得混入正在生成的图片。异步加载期间状态可见，失败可重试。页面字体可用不直接证明独立SVG图像、Canvas或后台渲染器能访问同一字体资源。

- PNG：在实际使用的渲染链中固定字体资源和文字布局，再生成像素。重新打开PNG检查中文、英文、IPA、组合符、上下标及负号，同时保留既有分辨率、dpi、白底、选区、图例与时间轴约束。
- SVG：保留现有可编辑文字导出能力，明确其可能依赖接收设备字体。若提供固定外观的便携模式，需在实施计划中选择并验证字形转路径或许可允许的字体嵌入，不能仅保存font-family名称后宣称跨设备一致。无法支持便携模式时保持planned，给出已验证的PNG入口。
- 后台/批次：所有图共同使用冻结配置，单图字体失败仍按原完整产物发布规则处理。字体只影响图片，不改变科学数组、NaN、时间网格、导出数值与文件数量约定。

整幅导出中，坐标刻度、IPA、图例、分区标签共用基础字号，总标题最多1.2倍。计算样式优先于SVG历史font-size属性，避免某一分区独立放大。字体更改可能改变字宽、基线和行高。必须重新测量坐标留白、图例、色条及长标签，避免改变字体后裁切。验收判断字形和布局是否正确，不要求不同渲染器达到逐像素相同。
