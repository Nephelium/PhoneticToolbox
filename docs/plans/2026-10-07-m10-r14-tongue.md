# M10-R14 舌尖厚度与舌叶贴附

状态 verified，限 Windows 当前源码与实际 Qt，见[报告](../testing/2026-10-07-m10-r14-report.md)。井井要求加厚后卷舌尖，并让舌叶控制点固定在实际舌面。

范围：在原生舌尖圆弧、限位与回接中使用一致的连续厚度补偿，后卷舌叶接入圆弧后侧；原生导出舌叶曲线中部对应的表面站位，二维与三维从该站位插值放置圆点，拖动补偿曲线控制量的位移增益。保留已修复的牙齿刚性、软腭连接、声门常驻及旧构形存储格式。

井井随后追加灰色窄片、柔顺性与截面加密，并明确选择默认 257 个截面。前部口腔剖面用真实组织切面补足横截面重建的空隙，后部保留焊接口鼻参考；原生纵向截面 129→257，横向 96 点不变。截面数量由原生查询，前端及运行时不再固定到 128 的末端。保留 129 档独立基准 DLL，只作计算耗时与数值差异对照。

验证：用户后卷构形的厚度、舌叶点贴面与上下前后拖动、无跳位、撤销及保存回读；连续原生构形、牙齿接触、前端必需检查与实际隐藏 Qt 浅深色截图。几何参数属于模型调整，不作为医学测量结果。只更新源码与本地前端构建，无 EXE 发布。
