# TextGrid 三层、关联与浮动音标键盘

井井要求最多三层同时标注，可选择层间吸附和是否关联，加入可移动/调整大小的紧凑国际音标键盘，同步三端共用实现、说明书与模块 README。

- 编辑角色保留音节/词、音素，新增自定义第三层。最多显示三个全域区间层；输入文件原有其他层、点层和各自时间域完整保留。角色存于本机视图，不写入 TextGrid 格式或迁移数据库。
- 吸附独立开关，默认关闭，拖动/插入边界在六个显示像素内吸附到其他可见层。关联按三个层对选择，默认保留词与音素的既有关系，第三层独立。关联通过已显示层传递，双向移动重合边界，所有关联层共同约束边界不可穿越邻居。
- 词层的整体移动、删除和剪贴携带关联层选区，音素/第三层的区间内容操作独立，避免细粒度操作抹去词标签。关闭词音素关联后，词典改字、手动定界、词表顺序和强度贴合不再隐式改变独立音素层。显式参考复用继续处理所有同名层。
- 键盘按需加载，从 Plus 权威 catalog 生成精简投影，共用字符插入规则和字体。默认 IPA，可切换 extIPA / VoQS，仅保留紧凑表格、符号和必要操作。拖动/调整面板大小通过单个 requestAnimationFrame 直接更新容器样式，字号在 60–180% 调整，列表静态记忆；无每键磨砂、壁纸、阴影或动画。
- 验证：标注/Unicode/精简数据定向测试，类型、契约、来源数据、工作台构建；隔离 Chrome 真实三层编辑、取消关联、吸附、键盘输入/选区/组合符号、拖动/尺寸/字号/页面缩放/主题、零额外主图绘制；实际 Qt 原生保存/重开与键盘；说明书 strict 校验、生成、帮助打开、文档与架构检查。

Windows/macOS/网页维护同一前端与编辑器，网页偏好白名单同步修改。Mac 实机、Safari、最终安装包与公开部署需单列证据，本轮不根据本机结果扩大验证结论。
