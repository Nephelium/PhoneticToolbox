## 解释与边界

- 网页沿用现有Vue工作台的布局、主题和模块界面，补注册登录、文件上传/下载、任务状态与浏览器设备适配。首期不以科学算法的浏览器移植或外接计算电脑为前提；具体可开放操作由服务器实测和验收白名单决定。
- 1 GB 使用十进制字节，断线保留30分钟为1800秒，按服务器最后一次有效心跳计算。额度覆盖上传、结果、缓存和临时占用，共享安装模型除外。账号/必要偏好及最少安全审计与研究历史分开，具体数据边界见[账号规格](specs/accounts-storage-jobs.md)。
- 本机桌面不套用网页登录、配额和到期清理。既有服务端数据变更须按专门迁移授权处理，不根据新规范直接删除旧数据。
- 10 人作为首档基线，继续以25/50/100并发交互阶梯测出边界后确定实际准入，不预先宣称承载人数。重计算槽与进程树预算按实际机器冻结，历史配置不代替本次实测。
- Windows 保持双击单文件直用及安装版，同一应用、当前字节上限和验证要求见[打包规则](../release/PACKAGING_RULES.md)。macOS 各架构与 Linux 桌面分别构建、测量和说明限制。
- 自助注册/邮箱验证/邮件恢复已纳入首期需求；实施细节见[上线计划](plans/2026-10-16-web-launch.md)。实际发信配置、现存库迁移、生产部署及公开分发另按具体目标授权执行。旧1 GB/3天代码仍需版本化迁移，本轮需求更新不表示政策已生效。
- 说明书内容可持续追加，正式素材/历史当前保留；测试临时数据、旧包与 Git 上传边界统一按根规则，不在此重复日期记录。
